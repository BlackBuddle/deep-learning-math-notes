# 예제: 오즈와 로짓

개념 노트: [M11_오즈와_로짓](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/04_%ED%99%95%EB%A5%A0%EA%B3%BC_%EC%A0%95%EB%B3%B4/M11_%EC%98%A4%EC%A6%88%EC%99%80_%EB%A1%9C%EC%A7%93.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. e는 약 2.718인 수, ln은 e를 몇 번 곱해야 그 수가 되는지를 나타내며, 값은 계산기나 `np.exp`, `np.log`로 구한다.

## 기본 (직접 대입)

### 문제 1

어떤 일이 일어날 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 $p = 0.6$이다. [오즈](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#odds-%EC%98%A4%EC%A6%88)를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p = 0.6$ (일어날 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))

**풀이**
1. 식을 그대로 쓴다: $\text{오즈} = \frac{p}{1-p}$
2. 값을 대입한다: $\text{오즈} = \frac{0.6}{1 - 0.6}$
3. 분모를 계산한다 (안 일어날 몫): 1 − 0.6 = 0.4 이므로 $\text{오즈} = \frac{0.6}{0.4}$
4. 나눗셈을 한다: 0.6 ÷ 0.4 = 1.5 이므로 $\text{오즈} = 1.5$

**답**: [오즈](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#odds-%EC%98%A4%EC%A6%88) = 1.5 (일어나는 쪽이 3 : 2)

</details>

### 문제 2

[오즈](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#odds-%EC%98%A4%EC%A6%88)가 0.25일 때 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) $p$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\text{오즈} = 0.25$ (일어날 몫 ÷ 안 일어날 몫)

**풀이**
1. 식을 그대로 쓴다: $p = \frac{\text{오즈}}{1 + \text{오즈}}$
2. 값을 대입한다: $p = \frac{0.25}{1 + 0.25}$
3. 분모를 더한다: 1 + 0.25 = 1.25 이므로 $p = \frac{0.25}{1.25}$
4. 나눗셈을 한다: 0.25 ÷ 1.25 = 0.2 이므로 $p = 0.2$

**답**: $p = 0.2$ ([오즈](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#odds-%EC%98%A4%EC%A6%88) 1 : 4는 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 0.2와 같다)

</details>

### 문제 3

$p = 0.25$일 때 [오즈](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#odds-%EC%98%A4%EC%A6%88)와 [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93)을 차례로 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p = 0.25$ ([확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))

**풀이**
1. [오즈](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#odds-%EC%98%A4%EC%A6%88) 식을 쓴다: $\text{오즈} = \frac{p}{1-p}$
2. 값을 대입한다: $\text{오즈} = \frac{0.25}{1 - 0.25}$
3. 분모를 계산한다: 1 − 0.25 = 0.75 이므로 $\text{오즈} = \frac{0.25}{0.75}$
4. 약분한다: 0.25 ÷ 0.75 = $\frac{1}{3}$ = 0.3333 이므로 [오즈](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#odds-%EC%98%A4%EC%A6%88) = $\frac{1}{3}$
5. [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93) 식을 쓴다: $\text{로짓} = \ln(\text{오즈})$
6. 값을 대입한다: $\text{로짓} = \ln\frac{1}{3}$
7. 분수의 ln은 분모의 ln에 마이너스를 붙인 것이다: $\text{로짓} = -\ln 3$
8. ln 3을 구한다: ln 3 = 1.0986 이므로 $\text{로짓} = -1.0986$

**답**: [오즈](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#odds-%EC%98%A4%EC%A6%88) = $\frac{1}{3} \approx 0.3333$, [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93) = −1.0986 (p < 0.5이므로 음수)

</details>

### 문제 4

[로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93) $z = -1$을 [시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C)에 넣어 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) $\sigma(-1)$을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $z = -1$ ([로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93))

**풀이**
1. 식을 그대로 쓴다: $\sigma(z) = \frac{1}{1 + e^{-z}}$
2. 값을 대입한다: $\sigma(-1) = \frac{1}{1 + e^{-(-1)}}$
3. 부호를 정리한다: −(−1) = 1 이므로 $\sigma(-1) = \frac{1}{1 + e^{1}}$
4. e의 값을 쓴다: $e^{1} = 2.7183$ 이므로 $\sigma(-1) = \frac{1}{1 + 2.7183}$
5. 분모를 더한다: 1 + 2.7183 = 3.7183 이므로 $\sigma(-1) = \frac{1}{3.7183}$
6. 나눗셈을 한다: 1 ÷ 3.7183 = 0.2689 이므로 $\sigma(-1) = 0.2689$

**답**: $\sigma(-1) = 0.2689$ ([로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93)이 음수라 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 0.5보다 작다)

</details>

[로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93) $z = 3$일 때 [오즈](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#odds-%EC%98%A4%EC%A6%88) $e^{z}$와 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) $p = \frac{e^{z}}{1 + e^{z}}$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $z = 3$ ([로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93))

2. 값을 대입한다: $\text{오즈} = e^{3}$
3. e의 거듭제곱을 구한다 (e를 세 번 곱한 값): $e^{3} = 20.0855$ 이므로 [오즈](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#odds-%EC%98%A4%EC%A6%88) = 20.0855

### 문제 6

$p = 0.3$과 $p = 0.7$ (서로 반대쪽 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))의 [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93)을 각각 구하고 관계를 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p = 0.3$, $p = 0.7$ (합이 1)

**풀이**
1. 식을 그대로 쓴다: $\text{로짓} = \ln\frac{p}{1-p}$
2. p = 0.3을 대입한다: $\text{로짓} = \ln\frac{0.3}{1 - 0.3}$
3. 분모를 계산한다: 1 − 0.3 = 0.7 이므로 $\text{로짓} = \ln\frac{0.3}{0.7}$
4. 나눗셈을 한다: 0.3 ÷ 0.7 = $\frac{3}{7}$ = 0.4286 이므로 $\text{로짓} = \ln\frac{3}{7}$
5. ln을 구한다: ln(3/7) = −0.8473 이므로 p = 0.3의 [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93) = −0.8473
6. p = 0.7을 대입한다: $\text{로짓} = \ln\frac{0.7}{1 - 0.7}$
7. 분모를 계산한다: 1 − 0.7 = 0.3 이므로 $\text{로짓} = \ln\frac{0.7}{0.3}$
8. 나눗셈을 한다: 0.7 ÷ 0.3 = $\frac{7}{3}$ = 2.3333 이므로 $\text{로짓} = \ln\frac{7}{3}$
9. ln을 구한다: ln(7/3) = 0.8473 이므로 p = 0.7의 [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93) = 0.8473

**답**: p = 0.3의 [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93)은 −0.8473, p = 0.7의 [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93)은 0.8473. 부호만 반대다

</details>

### 문제 8

[로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93) $z$가 0에서 1로 1만큼 커지면 [오즈](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#odds-%EC%98%A4%EC%A6%88) $e^{z}$는 몇 배가 되는가? [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) $\sigma(z)$는 얼마에서 얼마로 바뀌는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $z$: 0 → 1 ([로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93)이 1만큼 커진다)

1. [오즈](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#odds-%EC%98%A4%EC%A6%88) 식을 쓴다: $\text{오즈} = e^{z}$
2. z = 0을 대입한다: $\text{오즈} = e^{0}$, e를 0번 곱한 값은 1 이므로 [오즈](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#odds-%EC%98%A4%EC%A6%88) = 1
3. z = 1을 대입한다: $\text{오즈} = e^{1}$ = 2.7183
4. 배수를 구한다: 2.7183 ÷ 1 = 2.7183
5. [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 식을 쓴다: $\sigma(z) = \frac{1}{1 + e^{-z}}$
6. z = 0을 대입한다: $\sigma(0) = \frac{1}{1 + e^{0}} = \frac{1}{1 + 1}$ = 1 ÷ 2 = 0.5
7. z = 1을 대입한다: $\sigma(1) = \frac{1}{1 + e^{-1}}$
8. e의 음수 거듭제곱을 구한다 (1을 e로 나눈다): $e^{-1}$ = 1 ÷ 2.7183 = 0.3679 이므로 $\sigma(1) = \frac{1}{1 + 0.3679}$
9. 분모를 더한다: 1 + 0.3679 = 1.3679 이므로 $\sigma(1) = \frac{1}{1.3679}$
10. 나눗셈을 한다: 1 ÷ 1.3679 = 0.7311 이므로 $\sigma(1) = 0.7311$

**답**: [오즈](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#odds-%EC%98%A4%EC%A6%88)는 2.7183배, [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은 0.5에서 0.7311로 바뀐다

</details>

### 문제 9

[Lec01 5.3](../../Lec01_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%86%8C%EA%B0%9C.md#53-%EB%B9%84%EC%84%A0%ED%98%95-%ED%99%9C%EC%84%B1%ED%99%94-%ED%95%A8%EC%88%98)의 [시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C)는 [선형층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#linear-layer-%EC%84%A0%ED%98%95%EC%B8%B5)의 [가중합](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weighted-sum-%EA%B0%80%EC%A4%91%ED%95%A9) $z = \mathbf{x}^\top \mathbf{w} + b$를 [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93)으로 읽고 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)로 바꾼다. 입력 $\mathbf{x} = (2, 1)$, [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) $\mathbf{w} = (1, -2)$, [편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5) $b = 0.5$일 때 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) $\sigma(z)$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{x} = (2, 1)$ (입력 벡터)
- $\mathbf{w} = (1, -2)$ ([가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) 벡터)
- $b = 0.5$ ([편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5))

**풀이**
1. [가중합](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weighted-sum-%EA%B0%80%EC%A4%91%ED%95%A9) 식을 쓴다: $z = \mathbf{x}^\top \mathbf{w} + b$
2. 값을 대입한다 ([내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)을 칸끼리 곱해 더하는 꼴로 펼친다): $z = 2 \times 1 + 1 \times (-2) + 0.5$
3. 곱셈을 한다: 2 × 1 = 2, 1 × (−2) = −2 이므로 $z = 2 + (-2) + 0.5$
4. 더한다: 2 + (−2) = 0, 0 + 0.5 = 0.5 이므로 $z = 0.5$
5. [시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C) 식을 쓴다: $\sigma(z) = \frac{1}{1 + e^{-z}}$
6. 값을 대입한다: $\sigma(0.5) = \frac{1}{1 + e^{-0.5}}$
7. e의 음수 거듭제곱을 구한다: $e^{-0.5}$ = 0.6065 이므로 $\sigma(0.5) = \frac{1}{1 + 0.6065}$
8. 분모를 더한다: 1 + 0.6065 = 1.6065 이므로 $\sigma(0.5) = \frac{1}{1.6065}$
9. 나눗셈을 한다: 1 ÷ 1.6065 = 0.6225 이므로 $\sigma(0.5) = 0.6225$

**답**: $z = 0.5$, [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) $\sigma(0.5) = 0.6225$ (z가 양수라 0.5보다 크다)

### 문제 10

[Lec10 6절](../../Lec10_%EA%B8%B0%EC%96%B5%EA%B3%BC_%EC%8B%9C%ED%80%80%EC%8A%A4.md#6-lstm)의 [LSTM](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#lstm-long-short-term-memory-%EC%9E%A5%EB%8B%A8%EA%B8%B0-%EB%A9%94%EB%AA%A8%EB%A6%AC) 망각 [게이트](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gate-%EA%B2%8C%EC%9D%B4%ED%8A%B8)는 [시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C) 값을 이전 [셀 상태](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cell-state-%EC%85%80-%EC%83%81%ED%83%9C)에 곱해 얼마나 남길지 정한다. 망각 [게이트](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gate-%EA%B2%8C%EC%9D%B4%ED%8A%B8)의 [가중합](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weighted-sum-%EA%B0%80%EC%A4%91%ED%95%A9)이 $z = -2$이고 이전 [셀 상태](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cell-state-%EC%85%80-%EC%83%81%ED%83%9C)가 $C = 2$일 때, [게이트](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gate-%EA%B2%8C%EC%9D%B4%ED%8A%B8) 값 $f = \sigma(z)$와 남는 값 $f \times C$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $z = -2$ (망각 [게이트](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gate-%EA%B2%8C%EC%9D%B4%ED%8A%B8)의 [가중합](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weighted-sum-%EA%B0%80%EC%A4%91%ED%95%A9), [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93))
- $C = 2$ (이전 [셀 상태](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cell-state-%EC%85%80-%EC%83%81%ED%83%9C))

**풀이**
1. 식을 그대로 쓴다: $f = \sigma(z) = \frac{1}{1 + e^{-z}}$
2. 값을 대입한다: $f = \frac{1}{1 + e^{-(-2)}}$
3. 부호를 정리한다: −(−2) = 2 이므로 $f = \frac{1}{1 + e^{2}}$
4. e의 거듭제곱을 구한다 (e를 두 번 곱한 값): $e^{2} = 7.3891$ 이므로 $f = \frac{1}{1 + 7.3891}$
5. 분모를 더한다: 1 + 7.3891 = 8.3891 이므로 $f = \frac{1}{8.3891}$
6. 나눗셈을 한다: 1 ÷ 8.3891 = 0.1192 이므로 $f = 0.1192$
7. 남는 값을 구한다 ([게이트](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gate-%EA%B2%8C%EC%9D%B4%ED%8A%B8) × 이전 [셀 상태](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cell-state-%EC%85%80-%EC%83%81%ED%83%9C)): $f \times C = 0.1192 \times 2$
8. 곱셈을 한다: 0.1192 × 2 = 0.2384

**답**: $f = 0.1192$, 남는 값 0.2384 (z가 음수라 거의 잊는다)

</details>
