# 예제: 확률의 연쇄법칙과 빔 서치

개념 노트: [MM39_확률의_연쇄법칙과_빔_서치](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/04_%ED%99%95%EB%A5%A0%EA%B3%BC_%EC%A0%95%EB%B3%B4/MM39_%ED%99%95%EB%A5%A0%EC%9D%98_%EC%97%B0%EC%87%84%EB%B2%95%EC%B9%99%EA%B3%BC_%EB%B9%94_%EC%84%9C%EC%B9%98.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 쓰는 규칙은 둘이다: 문장 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은 "앞 단어가 주어졌을 때 다음 단어의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)"을 차례로 곱한 것이고, 곱은 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 씌우면 합이 된다. $\log$는 자연로그(ln)로, "$e$(약 2.718)를 몇 제곱해야 그 수가 되나"이며 1보다 작은 수의 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)는 음수다.

## 기본 (직접 대입)

### 문제 1

세 단어 문장 "I like cats"에서 $p(\text{I}) = 0.5$, $p(\text{like} \mid \text{I}) = 0.4$, $p(\text{cats} \mid \text{I like}) = 0.1$이다. 문장 전체의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p(\text{I}) = 0.5$ (첫 단어 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $p(\text{like} \mid \text{I}) = 0.4$ (I 다음에 like가 올 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $p(\text{cats} \mid \text{I like}) = 0.1$ (I like 다음에 cats가 올 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))

**풀이**
1. 식을 그대로 쓴다: $p(x_1, x_2, x_3) = \prod_{i=1}^{3} p(x_i \mid x_1, \dots, x_{i-1})$
2. 값을 대입한다: $p(\text{I like cats}) = 0.5 \times 0.4 \times 0.1$
3. 앞의 두 개를 곱한다: 0.5 × 0.4 = 0.2 이므로 $0.2 \times 0.1$
4. 남은 하나를 곱한다: 0.2 × 0.1 = 0.02

**답**: $p(\text{I like cats}) = 0.02$

</details>

### 문제 2

[조건부 확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#conditional-probability-%EC%A1%B0%EA%B1%B4%EB%B6%80-%ED%99%95%EB%A5%A0)이 $0.5,\ 0.25,\ 0.5$인 세 단어 문장의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 곱으로 구하고, [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8) 합으로도 구해 둘이 이어지는지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p_1 = 0.5$, $p_2 = 0.25$, $p_3 = 0.5$ (단계별 [조건부 확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#conditional-probability-%EC%A1%B0%EA%B1%B4%EB%B6%80-%ED%99%95%EB%A5%A0))

**풀이**
1. 식을 그대로 쓴다: $p = \prod_{i=1}^{3} p_i$, $\log p = \sum_{i=1}^{3} \log p_i$
2. 곱으로 대입한다: $p = 0.5 \times 0.25 \times 0.5$
3. 앞의 두 개를 곱한다: 0.5 × 0.25 = 0.125 이므로 $0.125 \times 0.5$
4. 남은 하나를 곱한다: 0.125 × 0.5 = 0.0625 이므로 $p = 0.0625$
5. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8) 합으로 대입한다: $\log p = \log 0.5 + \log 0.25 + \log 0.5$
6. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 하나씩 계산한다: $\log 0.5 = -0.6931$, $\log 0.25 = -1.3863$, $\log 0.5 = -0.6931$
7. 더한다: $-0.6931 - 1.3863 - 0.6931 = -2.7725$ (정확한 값으로 더하면 −2.7726)
8. 확인한다: $\log 0.0625 = -2.7726$ 으로 같다

**답**: $p = 0.0625$, $\log p = -2.7726$. 곱의 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)가 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)의 합이다.

</details>

### 문제 3

[정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) 문장의 두 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)에 모델이 준 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 $p(x_1) = 0.9$, $p(x_2 \mid x_1) = 0.5$이다. [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $\mathcal{L} = -\sum_i \log p(x_i \mid x_{<i})$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p(x_1) = 0.9$ (1번 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)에 준 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $p(x_2 \mid x_1) = 0.5$ (2번 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)에 준 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $n = 2$ ([토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 수)

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L} = -\sum_{i=1}^{2} \log p(x_i \mid x_{<i})$
2. 값을 대입한다: $\mathcal{L} = -(\log 0.9 + \log 0.5)$
3. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 하나씩 계산한다: $\log 0.9 = -0.1054$, $\log 0.5 = -0.6931$
4. 더한다: $-0.1054 - 0.6931 = -0.7985$
5. 마이너스를 붙인다: $\mathcal{L} = 0.7985$

**답**: $\mathcal{L} = 0.7985$

</details>

### 문제 4

첫 단어 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 $p(a) = 0.6$, $p(b) = 0.4$이고, a 다음 단어가 $p(x \mid a) = 0.5$, $p(y \mid a) = 0.3$이다. 매 단계 가장 큰 것만 고르는 탐욕 선택이 만드는 두 단어 문장과 그 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은?

<details><summary>풀이와 답</summary>

**주어진 값**
- $p(a) = 0.6$, $p(b) = 0.4$ (첫 단어 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $p(x \mid a) = 0.5$, $p(y \mid a) = 0.3$ (a 다음 단어 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))

**풀이**
1. 식을 그대로 쓴다: $\text{score}(y_1, y_2) = p(y_1)\, p(y_2 \mid y_1)$
2. 첫 단계에서 1등을 고른다: 0.6 > 0.4 이므로 a
3. a 다음에서 1등을 고른다: 0.5 > 0.3 이므로 x
4. 값을 대입한다: $p(a\ x) = 0.6 \times 0.5$
5. 곱한다: 0.6 × 0.5 = 0.3

**답**: 문장 **a x**, [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) **0.3**

</details>

### 문제 5

첫 단어 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은 A 0.5, B 0.3, C 0.2다. 다음 단어 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은 A 뒤에 x 0.4, y 0.3, B 뒤에 x 0.9, z 0.1, C 뒤에 x 1.0이다. (가) 탐욕 선택의 결과, (나) 빔 너비 $k = 2$의 결과, (다) $k = 3$으로 키우면 결과가 바뀌는지 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p(A) = 0.5$, $p(B) = 0.3$, $p(C) = 0.2$ (첫 단어 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $p(x \mid A) = 0.4$, $p(y \mid A) = 0.3$, $p(x \mid B) = 0.9$, $p(z \mid B) = 0.1$, $p(x \mid C) = 1.0$ (다음 단어 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $k$ (빔 너비, 들고 갈 후보 수)

**풀이**
1. 식을 그대로 쓴다: $\text{score}(y_1, y_2) = p(y_1)\, p(y_2 \mid y_1)$
2. (가) 탐욕: 첫 단계 1등은 0.5로 A, A 다음 1등은 0.4로 x
3. (가) 값을 대입한다: $\text{score}(A, x) = 0.5 \times 0.4$
4. (가) 곱한다: 0.5 × 0.4 = 0.2
5. (나) 첫 단계 상위 2개 A, B를 모두 들고 간다. 후보 네 개를 대입해 곱한다: A x = 0.5 × 0.4 = 0.2, A y = 0.5 × 0.3 = 0.15, B x = 0.3 × 0.9 = 0.27, B z = 0.3 × 0.1 = 0.03
6. (나) 가장 큰 것을 고른다: 0.27 > 0.2 > 0.15 > 0.03 이므로 B x
7. (다) 상위 3개 A, B, C를 들고 간다. 새로 생기는 후보를 계산한다: C x = 0.2 × 1.0 = 0.2
8. (다) 비교한다: 0.27 > 0.2 이므로 여전히 B x

**답**: (가) A x (**0.2**), (나) B x (**0.27**), (다) k = 3에서도 B x (**0.27**). 바뀌지 않는다.

</details>

### 문제 6

다섯 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) 문장에 모델이 준 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 $0.5,\ 0.8,\ 0.9,\ 0.4,\ 0.25$이다. 문장 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)과 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $\mathcal{L}$을 구하고, $\mathcal{L}$이 $-\log$(문장 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))과 같은지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p_1 = 0.5$, $p_2 = 0.8$, $p_3 = 0.9$, $p_4 = 0.4$, $p_5 = 0.25$ (토큰별 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $n = 5$ ([토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 수)

**풀이**
1. 식을 그대로 쓴다: $p = \prod_{i=1}^{5} p_i$, $\mathcal{L} = -\sum_{i=1}^{5} \log p_i$
2. 곱으로 대입한다: $p = 0.5 \times 0.8 \times 0.9 \times 0.4 \times 0.25$
3. 차례로 곱한다: 0.5 × 0.8 = 0.4, 0.4 × 0.9 = 0.36, 0.36 × 0.4 = 0.144, 0.144 × 0.25 = 0.036 이므로 $p = 0.036$
4. [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)로 대입한다: $\mathcal{L} = -(\log 0.5 + \log 0.8 + \log 0.9 + \log 0.4 + \log 0.25)$
5. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 하나씩 계산한다: $-0.6931,\ -0.2231,\ -0.1054,\ -0.9163,\ -1.3863$
6. 더한다: $-0.6931 - 0.2231 - 0.1054 - 0.9163 - 1.3863 = -3.3242$
7. 마이너스를 붙인다: $\mathcal{L} = 3.3242$
8. 확인한다: $-\log 0.036 = 3.3242$ 로 같다

**답**: $p = 0.036$, $\mathcal{L} = 3.3242$. [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은 문장 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)의 $-\log$다.

</details>

### 문제 7

(가) [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8) [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 합([빔 서치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#beam-search-%EB%B9%94-%EC%84%9C%EC%B9%98)의 점수)으로 어느 쪽이 높은가? (나) 토큰당 평균 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8) [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)(길이로 나눈 값)로는 어느 쪽이 높은가?

<details><summary>풀이와 답</summary>

**주어진 값**
- S: $T = 2$, [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 0.7 (짧은 문장)
- L: $T = 5$, [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 0.85 (긴 문장)

**풀이**
1. 식을 그대로 쓴다: $\text{score} = \sum_{t=1}^{T} \log p_t$, 평균 $= \text{score} / T$
2. (가) S를 대입한다: $\text{score}_S = 2 \times \log 0.7$
3. (가) S를 계산한다: $\log 0.7 = -0.3567$ 이므로 $2 \times (-0.3567) = -0.7133$ (정확한 값으로 곱한 뒤 반올림)
4. (가) L을 대입한다: $\text{score}_L = 5 \times \log 0.85$
5. (가) L을 계산한다: $\log 0.85 = -0.1625$ 이므로 $5 \times (-0.1625) = -0.8126$
6. (가) 비교한다: $-0.7133 > -0.8126$ 이므로 S가 높다
7. (나) S의 평균: $-0.7133 / 2 = -0.3567$
8. (나) L의 평균: $-0.8126 / 5 = -0.1625$
9. (나) 비교한다: $-0.1625 > -0.3567$ 이므로 L이 높다

**답**: (가) 합으로는 S(**−0.7133**)가 높고, (나) 평균으로는 L(**−0.1625**)이 높다. 합은 길수록 음수가 더해져 작아지므로 [빔 서치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#beam-search-%EB%B9%94-%EC%84%9C%EC%B9%98)는 짧은 문장을 편애하고, 그래서 길이로 나눠 정규화하기도 한다.

</details>

[확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 0.5인 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)이 50개 이어진 문장이 있다. [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)의 곱과 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8) 합을 구하고, 왜 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8) 합을 쓰는지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 0.5 (매 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 같음)
- $n = 50$ ([토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 수)

**풀이**
1. 식을 그대로 쓴다: $p = \prod_{i=1}^{n} p_i$, $\log p = \sum_{i=1}^{n} \log p_i$
2. 곱으로 대입한다: $p = 0.5 \times 0.5 \times \cdots \times 0.5$ (50개) $= 0.5^{50}$

5. 곱한다: $50 \times (-0.6931) = -34.6574$ (정확한 값으로 곱한 뒤 반올림)

**답**: 곱은 $8.88 \times 10^{-16}$, [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8) 합은 **−34.6574**. 곱은 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)이 늘수록 금방 0에 가까워져 다루기 어렵지만, [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8) 합은 보통 크기의 수라 다루기 쉽다.

</details>

### 문제 9

Lec10 7.2는 $p(\text{Once upon a time})$을 [연쇄법칙](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#chain-rule-%EC%97%B0%EC%87%84%EB%B2%95%EC%B9%99)으로 푼다. $p(\text{Once}) = 0.2$, $p(\text{upon} \mid \text{Once}) = 0.5$, $p(\text{a} \mid \text{Once upon}) = 0.8$, $p(\text{time} \mid \text{Once upon a}) = 0.9$일 때 문장 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0), [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8) [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0), [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p(\text{Once}) = 0.2$, $p(\text{upon} \mid \text{Once}) = 0.5$ (앞 두 단어)
- $p(\text{a} \mid \text{Once upon}) = 0.8$, $p(\text{time} \mid \text{Once upon a}) = 0.9$ (뒤 두 단어)
- $n = 4$ (단어 수)

**풀이**
1. 식을 그대로 쓴다: $p(x_1, \dots, x_4) = \prod_{i=1}^{4} p(x_i \mid x_{<i})$, $\mathcal{L} = -\sum_{i=1}^{4} \log p(x_i \mid x_{<i})$
2. 곱으로 대입한다: $p = 0.2 \times 0.5 \times 0.8 \times 0.9$
3. 차례로 곱한다: 0.2 × 0.5 = 0.1, 0.1 × 0.8 = 0.08, 0.08 × 0.9 = 0.072 이므로 $p = 0.072$
4. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8) 합으로 대입한다: $\log p = \log 0.2 + \log 0.5 + \log 0.8 + \log 0.9$
5. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 하나씩 계산한다: $-1.6094,\ -0.6931,\ -0.2231,\ -0.1054$
6. 더한다: $-1.6094 - 0.6931 - 0.2231 - 0.1054 = -2.6310$
7. 마이너스를 붙인다: $\mathcal{L} = 2.6310$
8. 확인한다: $\log 0.072 = -2.6311$ 로 거의 같다 (위 합은 넷째 자리에서 반올림한 값을 더해 0.0001 차이가 난다)

**답**: $p = 0.072$, $\log p = -2.6310$, $\mathcal{L} = 2.6310$

</details>
