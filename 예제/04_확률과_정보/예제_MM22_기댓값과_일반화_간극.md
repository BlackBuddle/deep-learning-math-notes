# 예제: 기댓값과 일반화 간극

개념 노트: [MM22_기댓값과_일반화_간극](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/04_%ED%99%95%EB%A5%A0%EA%B3%BC_%EC%A0%95%EB%B3%B4/MM22_%EA%B8%B0%EB%8C%93%EA%B0%92%EA%B3%BC_%EC%9D%BC%EB%B0%98%ED%99%94_%EA%B0%84%EA%B7%B9.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다.

## 기본 (직접 대입)

### 문제 1

어떤 가게에서 하루에 팔리는 케이크가 1개일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 0.5, 2개일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 0.3, 3개일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 0.2이다. 하루 판매 개수 $X$의 [기댓값](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#expectation-%EA%B8%B0%EB%8C%93%EA%B0%92) $\mathbb{E}[X]$를 구하라. ([기댓값](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#expectation-%EA%B8%B0%EB%8C%93%EA%B0%92)은 '값 × 그 값이 나올 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)'을 모두 더한 것이라 $\mathbb{E}[X] = \sum_x p(x)\, x$ 를 쓴다.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $x = 1, 2, 3$ (하루 판매 개수)
- $p(1) = 0.5$, $p(2) = 0.3$, $p(3) = 0.2$ (각 개수가 나올 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0), 합 1)

**풀이**
1. 식을 그대로 쓴다: $\mathbb{E}[X] = \sum_x p(x)\, x$
2. 값을 대입한다 (Σ는 x = 1, 2, 3 세 항을 더하라는 뜻): $\mathbb{E}[X] = 0.5 \times 1 + 0.3 \times 2 + 0.2 \times 3$
3. 곱셈을 한다: 0.5 × 1 = 0.5, 0.3 × 2 = 0.6, 0.2 × 3 = 0.6 이므로 $\mathbb{E}[X] = 0.5 + 0.6 + 0.6$
4. 더한다: 0.5 + 0.6 = 1.1, 1.1 + 0.6 = 1.7 이므로 $\mathbb{E}[X] = 1.7$

**답**: $\mathbb{E}[X] = 1.7$ (하루에 평균 1.7개 팔린다. 실제 하루 판매량이 1.7개인 날은 없어도 된다)

</details>

### 문제 2

데이터 4개 $(x, y) = (0, 1), (1, 3), (2, 3), (3, 5)$가 있고 모형은 $f(x) = 2x + 1$, [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은 제곱 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $(\hat{y} - y)^2$이다. [경험적 위험](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#empirical-risk-%EA%B2%BD%ED%97%98%EC%A0%81-%EC%9C%84%ED%97%98) $\hat{\mathcal{R}}$을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $N = 4$ (데이터 개수)
- $\mathbf{x}_i = 0, 1, 2, 3$ (입력)
- $\mathbf{y}_i = 1, 3, 3, 5$ ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5))
- $f(x) = 2x + 1$ (모형)
- $\mathcal{L}(\hat{y}, y) = (\hat{y} - y)^2$ (예측에서 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)을 뺀 값의 제곱)

**풀이**
1. 식을 그대로 쓴다: $\hat{\mathcal{R}} = \frac{1}{N}\sum_{i=1}^{N} \mathcal{L}(f(\mathbf{x}_i), \mathbf{y}_i)$
2. 값을 대입한다 (Σ는 i = 1, 2, 3, 4 네 항을 더하라는 뜻): $\hat{\mathcal{R}} = \frac{1}{4}\big[(f(0) - 1)^2 + (f(1) - 3)^2 + (f(2) - 3)^2 + (f(3) - 5)^2\big]$
3. 모형으로 예측을 구한다: $f(0) = 2 \times 0 + 1 = 1$, $f(1) = 3$, $f(2) = 5$, $f(3) = 7$ 이므로 $\hat{\mathcal{R}} = \frac{1}{4}\big[(1 - 1)^2 + (3 - 3)^2 + (5 - 3)^2 + (7 - 5)^2\big]$
4. 괄호 안 뺄셈을 한다: $0$, $0$, $2$, $2$ 이므로 $\hat{\mathcal{R}} = \frac{1}{4}\big[0^2 + 0^2 + 2^2 + 2^2\big]$
5. 제곱한다: $0$, $0$, $4$, $4$ 이므로 $\hat{\mathcal{R}} = \frac{1}{4}\big[0 + 0 + 4 + 4\big]$
6. 더한다: $0 + 0 + 4 + 4 = 8$ 이므로 $\hat{\mathcal{R}} = \frac{1}{4} \times 8$
7. 나눈다: $8 \div 4 = 2$ 이므로 $\hat{\mathcal{R}} = 2$

**답**: $\hat{\mathcal{R}} = 2$

</details>

### 문제 3

어떤 모형의 [경험적 위험](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#empirical-risk-%EA%B2%BD%ED%97%98%EC%A0%81-%EC%9C%84%ED%97%98)이 $\hat{\mathcal{R}} = 2$, [모집단 위험](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#population-risk-%EB%AA%A8%EC%A7%91%EB%8B%A8-%EC%9C%84%ED%97%98)이 $\mathcal{R} = 7.5$이다. [일반화 간극](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#generalization-gap-%EC%9D%BC%EB%B0%98%ED%99%94-%EA%B0%84%EA%B7%B9)을 구하라. ([일반화 간극](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#generalization-gap-%EC%9D%BC%EB%B0%98%ED%99%94-%EA%B0%84%EA%B7%B9)은 [모집단 위험](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#population-risk-%EB%AA%A8%EC%A7%91%EB%8B%A8-%EC%9C%84%ED%97%98)에서 [경험적 위험](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#empirical-risk-%EA%B2%BD%ED%97%98%EC%A0%81-%EC%9C%84%ED%97%98)을 뺀 값이다.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $\hat{\mathcal{R}} = 2$ (가진 데이터에서 잰 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)의 평균)
- $\mathcal{R} = 7.5$ (세상 전체에서 잰 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)의 [기댓값](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#expectation-%EA%B8%B0%EB%8C%93%EA%B0%92))

**풀이**
1. 식을 그대로 쓴다: [일반화 간극](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#generalization-gap-%EC%9D%BC%EB%B0%98%ED%99%94-%EA%B0%84%EA%B7%B9) $= \mathcal{R} - \hat{\mathcal{R}}$
2. 값을 대입한다: [일반화 간극](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#generalization-gap-%EC%9D%BC%EB%B0%98%ED%99%94-%EA%B0%84%EA%B7%B9) $= 7.5 - 2$
3. 뺄셈을 한다: $7.5 - 2 = 5.5$

**답**: [일반화 간극](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#generalization-gap-%EC%9D%BC%EB%B0%98%ED%99%94-%EA%B0%84%EA%B7%B9) = 5.5 (양수: 가진 데이터에서보다 세상에서 더 많이 틀린다)

</details>

### 문제 4

입력 4가지가 모두 같은 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)로 나오고, 어떤 모형의 입력별 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 $(1, 3, 5, 7)$이다. [모집단 위험](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#population-risk-%EB%AA%A8%EC%A7%91%EB%8B%A8-%EC%9C%84%ED%97%98) $\mathcal{R}$을 구하라. ([확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 모두 같으면 [기댓값](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#expectation-%EA%B8%B0%EB%8C%93%EA%B0%92)은 그냥 평균이다.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $p(x) = 0.25$ (네 입력 모두 같은 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $\mathcal{L}(x) = 1, 3, 5, 7$ (입력별 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98))

**풀이**
1. 식을 그대로 쓴다: $\mathcal{R} = \sum_x p(x)\, \mathcal{L}(x)$
2. 값을 대입한다 (Σ는 네 항을 더하라는 뜻): $\mathcal{R} = 0.25 \times 1 + 0.25 \times 3 + 0.25 \times 5 + 0.25 \times 7$
3. 곱셈을 한다: $0.25$, $0.75$, $1.25$, $1.75$ 이므로 $\mathcal{R} = 0.25 + 0.75 + 1.25 + 1.75$
4. 더한다: 0.25 + 0.75 = 1, 1 + 1.25 = 2.25, 2.25 + 1.75 = 4 이므로 $\mathcal{R} = 4$

**답**: $\mathcal{R} = 4$ (확인: $(1 + 3 + 5 + 7) / 4 = 16 / 4 = 4$ 로 평균과 같다)

</details>

### 문제 5

입력 $x = 0, 1, 2, 3$이 나올 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 $(0.1, 0.2, 0.3, 0.4)$이고 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)은 $y = 2x$이다. 모형 $f(x) = x$, [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은 제곱 오차일 때 [모집단 위험](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#population-risk-%EB%AA%A8%EC%A7%91%EB%8B%A8-%EC%9C%84%ED%97%98) $\mathcal{R}$을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p(x) = 0.1, 0.2, 0.3, 0.4$ (입력 0, 1, 2, 3이 나올 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $y = 2x$ ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) 규칙)
- $f(x) = x$ (모형)
- $\mathcal{L}(\hat{y}, y) = (\hat{y} - y)^2$ ([손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98))

**풀이**
1. 식을 그대로 쓴다: $\mathcal{R} = \sum_x p(x)\, \mathcal{L}(f(x), y)$
2. 값을 대입한다 (Σ는 x = 0, 1, 2, 3 네 항을 더하라는 뜻): $\mathcal{R} = 0.1 \times (0 - 2 \times 0)^2 + 0.2 \times (1 - 2 \times 1)^2 + 0.3 \times (2 - 2 \times 2)^2 + 0.4 \times (3 - 2 \times 3)^2$
3. 괄호 안 곱셈을 먼저 한다 ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)): $2 \times 0 = 0$, $2$, $4$, $6$ 이므로 $\mathcal{R} = 0.1 \times (0 - 0)^2 + 0.2 \times (1 - 2)^2 + 0.3 \times (2 - 4)^2 + 0.4 \times (3 - 6)^2$
4. 괄호 안 뺄셈을 한다: $0$, $-1$, $-2$, $-3$ 이므로 $\mathcal{R} = 0.1 \times 0^2 + 0.2 \times (-1)^2 + 0.3 \times (-2)^2 + 0.4 \times (-3)^2$
5. 제곱한다: $0$, $1$, $4$, $9$ 이므로 $\mathcal{R} = 0.1 \times 0 + 0.2 \times 1 + 0.3 \times 4 + 0.4 \times 9$
6. 곱셈을 한다: $0$, $0.2$, $1.2$, $3.6$ 이므로 $\mathcal{R} = 0 + 0.2 + 1.2 + 3.6$
7. 더한다: $0 + 0.2 + 1.2 + 3.6 = 5$ 이므로 $\mathcal{R} = 5$

**답**: $\mathcal{R} = 5$ ([확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 같을 때의 3.5보다 크다: 틀리는 폭이 큰 x = 3이 더 자주 나오기 때문)

</details>

### 문제 6

[정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) $y = 2x$, 입력 $x = 0, 1, 2, 3$이 모두 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) $0.25$로 나오는 세상이다. [학습 데이터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-data-test-data-%ED%95%99%EC%8A%B5-%EB%8D%B0%EC%9D%B4%ED%84%B0%EC%99%80-%EC%8B%9C%ED%97%98-%EB%8D%B0%EC%9D%B4%ED%84%B0)는 $(0, 0), (1, 2)$ 두 개뿐이고 모형은 '무엇이 들어와도 1을 내놓는다' $f(x) = 1$이다. [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 제곱 오차일 때 [경험적 위험](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#empirical-risk-%EA%B2%BD%ED%97%98%EC%A0%81-%EC%9C%84%ED%97%98), [모집단 위험](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#population-risk-%EB%AA%A8%EC%A7%91%EB%8B%A8-%EC%9C%84%ED%97%98), [일반화 간극](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#generalization-gap-%EC%9D%BC%EB%B0%98%ED%99%94-%EA%B0%84%EA%B7%B9)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $f(x) = 1$ (모형: 입력과 상관없이 예측이 1)
- [학습 데이터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-data-test-data-%ED%95%99%EC%8A%B5-%EB%8D%B0%EC%9D%B4%ED%84%B0%EC%99%80-%EC%8B%9C%ED%97%98-%EB%8D%B0%EC%9D%B4%ED%84%B0) $(x, y) = (0, 0), (1, 2)$, $N = 2$
- $p(x) = 0.25$ (네 입력 모두 같은 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)), $y = 2x$

**풀이**
1. 먼저 입력별 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 구한다. 식: $\mathcal{L}(x) = (f(x) - y)^2$. 값을 대입하면 $x = 0, 1, 2, 3$에서 $(1 - 0)^2,\ (1 - 2)^2,\ (1 - 4)^2,\ (1 - 6)^2$
2. 계산한다: $1^2 = 1$, $(-1)^2 = 1$, $(-3)^2 = 9$, $(-5)^2 = 25$ 이므로 입력별 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은 $1, 1, 9, 25$
3. [경험적 위험](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#empirical-risk-%EA%B2%BD%ED%97%98%EC%A0%81-%EC%9C%84%ED%97%98)은 [학습 데이터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-data-test-data-%ED%95%99%EC%8A%B5-%EB%8D%B0%EC%9D%B4%ED%84%B0%EC%99%80-%EC%8B%9C%ED%97%98-%EB%8D%B0%EC%9D%B4%ED%84%B0) 두 점(x = 0, 1)의 평균이다: $\hat{\mathcal{R}} = \frac{1}{2}(1 + 1) = \frac{1}{2} \times 2 = 1$
4. [모집단 위험](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#population-risk-%EB%AA%A8%EC%A7%91%EB%8B%A8-%EC%9C%84%ED%97%98)은 네 입력의 [기댓값](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#expectation-%EA%B8%B0%EB%8C%93%EA%B0%92)이다: $\mathcal{R} = 0.25 \times 1 + 0.25 \times 1 + 0.25 \times 9 + 0.25 \times 25$
5. 곱셈을 한다: $0.25$, $0.25$, $2.25$, $6.25$ 이므로 $\mathcal{R} = 0.25 + 0.25 + 2.25 + 6.25 = 9$
6. [일반화 간극](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#generalization-gap-%EC%9D%BC%EB%B0%98%ED%99%94-%EA%B0%84%EA%B7%B9)을 구한다: $\mathcal{R} - \hat{\mathcal{R}} = 9 - 1 = 8$

**답**: $\hat{\mathcal{R}} = 1$, $\mathcal{R} = 9$, [일반화 간극](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#generalization-gap-%EC%9D%BC%EB%B0%98%ED%99%94-%EA%B0%84%EA%B7%B9) $= 8$

</details>

### 문제 7

캐비닛(외운 x = 0, 1만 맞히고 나머지는 0을 내놓는 모형)의 입력별 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은 $(0, 0, 16, 36)$이다. [시험 데이터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-data-test-data-%ED%95%99%EC%8A%B5-%EB%8D%B0%EC%9D%B4%ED%84%B0%EC%99%80-%EC%8B%9C%ED%97%98-%EB%8D%B0%EC%9D%B4%ED%84%B0)로 $x = 0, 1, 2, 2$ 네 개를 뽑았을 때 경험적 시험 위험을 구하고, [모집단 위험](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#population-risk-%EB%AA%A8%EC%A7%91%EB%8B%A8-%EC%9C%84%ED%97%98) 13과 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $M = 4$ ([시험 데이터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-data-test-data-%ED%95%99%EC%8A%B5-%EB%8D%B0%EC%9D%B4%ED%84%B0%EC%99%80-%EC%8B%9C%ED%97%98-%EB%8D%B0%EC%9D%B4%ED%84%B0) 개수)
- $x_j = 0, 1, 2, 2$ (뽑힌 입력)
- $\mathcal{L}(x) = 0, 0, 16, 36$ (입력별 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98), x = 0, 1, 2, 3 순서)

**풀이**
1. 식을 그대로 쓴다: $\hat{\mathcal{R}}_{\text{test}} = \frac{1}{M}\sum_{j=1}^{M} \mathcal{L}(x_j)$
2. 값을 대입한다 (Σ는 j = 1, 2, 3, 4 네 항을 더하라는 뜻): $\hat{\mathcal{R}}_{\text{test}} = \frac{1}{4}\big[\mathcal{L}(0) + \mathcal{L}(1) + \mathcal{L}(2) + \mathcal{L}(2)\big]$
3. 표에서 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 찾아 넣는다: $\mathcal{L}(0) = 0$, $\mathcal{L}(1) = 0$, $\mathcal{L}(2) = 16$ 이므로 $\hat{\mathcal{R}}_{\text{test}} = \frac{1}{4}\big[0 + 0 + 16 + 16\big]$
4. 더한다: $0 + 0 + 16 + 16 = 32$ 이므로 $\hat{\mathcal{R}}_{\text{test}} = \frac{1}{4} \times 32$
5. 나눈다: $32 \div 4 = 8$
6. 비교한다: $8$ 과 $13$ 은 다르다 (13 − 8 = 5 만큼 낮게 추정)

**답**: $\hat{\mathcal{R}}_{\text{test}} = 8$. 시험 표본이 네 개뿐이고 어려운 x = 3이 한 번도 안 뽑혀서 [모집단 위험](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#population-risk-%EB%AA%A8%EC%A7%91%EB%8B%A8-%EC%9C%84%ED%97%98) 13보다 낮게 나왔다

</details>

### 문제 10

[Lec06 1](../../Lec06_%EC%9D%BC%EB%B0%98%ED%99%94_%EC%9D%B4%EB%A1%A0.md#1-%EA%B7%BC%EC%82%AC-%EC%B5%9C%EC%A0%81%ED%99%94-%EC%9D%BC%EB%B0%98%ED%99%94)처럼 [일반화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#generalization-%EC%9D%BC%EB%B0%98%ED%99%94)는 '[경험적 위험](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#empirical-risk-%EA%B2%BD%ED%97%98%EC%A0%81-%EC%9C%84%ED%97%98)과 [모집단 위험](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#population-risk-%EB%AA%A8%EC%A7%91%EB%8B%A8-%EC%9C%84%ED%97%98)이 얼마나 다른가'를 묻는다. 어떤 분류기가 [학습](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5) 이미지에서는 하나도 틀리지 않았다([경험적 위험](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#empirical-risk-%EA%B2%BD%ED%97%98%EC%A0%81-%EC%9C%84%ED%97%98) 0). 시험 이미지 10,000장([학습](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5)에 쓰지 않은 것)에서는 1,200장을 틀렸고, [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은 맞으면 0, 틀리면 1이다. [시험 데이터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-data-test-data-%ED%95%99%EC%8A%B5-%EB%8D%B0%EC%9D%B4%ED%84%B0%EC%99%80-%EC%8B%9C%ED%97%98-%EB%8D%B0%EC%9D%B4%ED%84%B0)로 추정한 [모집단 위험](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#population-risk-%EB%AA%A8%EC%A7%91%EB%8B%A8-%EC%9C%84%ED%97%98)과 [일반화 간극](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#generalization-gap-%EC%9D%BC%EB%B0%98%ED%99%94-%EA%B0%84%EA%B7%B9)을 구하라. (숫자는 연습용으로 정한 값이다.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $M = 10000$ (시험 이미지 수)
- 틀린 이미지 1,200장 ([손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) 1), 맞힌 이미지 8,800장 ([손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) 0)
- $\hat{\mathcal{R}} = 0$ ([학습 데이터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-data-test-data-%ED%95%99%EC%8A%B5-%EB%8D%B0%EC%9D%B4%ED%84%B0%EC%99%80-%EC%8B%9C%ED%97%98-%EB%8D%B0%EC%9D%B4%ED%84%B0)의 평균 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98))

**풀이**
1. 식을 그대로 쓴다: $\hat{\mathcal{R}}_{\text{test}} = \frac{1}{M}\sum_{j=1}^{M} \mathcal{L}_j$
2. 값을 대입한다 (Σ는 틀린 장의 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) 1을 1,200번, 맞힌 장의 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) 0을 8,800번 더한다는 뜻): $\hat{\mathcal{R}}_{\text{test}} = \frac{1}{10000}\big[1200 \times 1 + 8800 \times 0\big]$
3. 곱셈을 한다: $1200 \times 1 = 1200$, $8800 \times 0 = 0$ 이므로 $\hat{\mathcal{R}}_{\text{test}} = \frac{1}{10000} \times 1200$
4. 나눈다: $1200 \div 10000 = 0.12$ 이므로 $\hat{\mathcal{R}}_{\text{test}} = 0.12$
5. [일반화 간극](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#generalization-gap-%EC%9D%BC%EB%B0%98%ED%99%94-%EA%B0%84%EA%B7%B9)을 구한다: $0.12 - 0 = 0.12$

**답**: [모집단 위험](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#population-risk-%EB%AA%A8%EC%A7%91%EB%8B%A8-%EC%9C%84%ED%97%98)의 추정값 $0.12$, [일반화 간극](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#generalization-gap-%EC%9D%BC%EB%B0%98%ED%99%94-%EA%B0%84%EA%B7%B9) $0.12$ ([학습 데이터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-data-test-data-%ED%95%99%EC%8A%B5-%EB%8D%B0%EC%9D%B4%ED%84%B0%EC%99%80-%EC%8B%9C%ED%97%98-%EB%8D%B0%EC%9D%B4%ED%84%B0)에서는 완벽해도 새 데이터에서 12%를 틀린다)

</details>
