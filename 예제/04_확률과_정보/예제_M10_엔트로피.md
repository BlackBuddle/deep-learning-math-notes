# 예제: 엔트로피

개념 노트: [M10_엔트로피](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/04_%ED%99%95%EB%A5%A0%EA%B3%BC_%EC%A0%95%EB%B3%B4/M10_%EC%97%94%ED%8A%B8%EB%A1%9C%ED%94%BC.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. ln은 e(약 2.718)를 몇 번 곱해야 그 수가 되는지를 나타내며, 값은 계산기나 `np.log`로 구한다.

## 기본 (직접 대입)

### 문제 1

[확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) $p = 0.25$인 일이 일어났다. 자기 정보량 $-\ln p$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p = 0.25$ (그 일이 일어날 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))

**풀이**
1. 식을 그대로 쓴다: $I = -\ln p$
2. 값을 대입한다: $I = -\ln 0.25$
3. ln을 구한다 (0.25는 1보다 작아 ln이 음수다): ln 0.25 = −1.3863 이므로 $I = -(-1.3863)$
4. 마이너스를 붙인다: −(−1.3863) = 1.3863 이므로 $I = 1.3863$

**답**: $I = 1.3863$ (p = 0.5일 때의 0.6931보다 크다. 드문 일일수록 더 놀랍다)

</details>

### 문제 2

앞면이 나올 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 0.6, 뒷면이 나올 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 0.4인 동전의 [엔트로피](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#entropy-%EC%97%94%ED%8A%B8%EB%A1%9C%ED%94%BC) $H(p)$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p_1 = 0.6$ (앞면 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $p_2 = 0.4$ (뒷면 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))

**풀이**
1. 식을 그대로 쓴다: $H(p) = \sum_k p_k \times (-\ln p_k)$
2. 값을 대입한다 (Σ를 k = 1, 2 두 항으로 펼친다): $H(p) = 0.6 \times (-\ln 0.6) + 0.4 \times (-\ln 0.4)$
3. 앞면의 자기 정보량을 구한다: ln 0.6 = −0.5108 이므로 $H(p) = 0.6 \times 0.5108 + 0.4 \times (-\ln 0.4)$
4. 뒷면의 자기 정보량을 구한다: ln 0.4 = −0.9163 이므로 $H(p) = 0.6 \times 0.5108 + 0.4 \times 0.9163$
5. 앞면 몫을 곱한다: 0.6 × 0.5108 = 0.3065 이므로 $H(p) = 0.3065 + 0.4 \times 0.9163$
6. 뒷면 몫을 곱한다: 0.4 × 0.9163 = 0.3665 이므로 $H(p) = 0.3065 + 0.3665$
7. 더한다: 0.3065 + 0.3665 = 0.6730 이므로 $H(p) = 0.6730$

**답**: $H(p) = 0.6730$ (공정한 동전의 0.6931보다 조금 작다)

</details>

### 문제 3

결과가 두 개이고 $p = [0.7,\ 0.3]$인 분포의 [엔트로피](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#entropy-%EC%97%94%ED%8A%B8%EB%A1%9C%ED%94%BC) $H(p)$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p_1 = 0.7$ (첫째 결과 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $p_2 = 0.3$ (둘째 결과 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))

**풀이**
1. 식을 그대로 쓴다: $H(p) = \sum_k p_k \times (-\ln p_k)$
2. 값을 대입한다 (Σ를 두 항으로 펼친다): $H(p) = 0.7 \times (-\ln 0.7) + 0.3 \times (-\ln 0.3)$
3. 첫째 자기 정보량을 구한다: ln 0.7 = −0.3567 이므로 $H(p) = 0.7 \times 0.3567 + 0.3 \times (-\ln 0.3)$
4. 둘째 자기 정보량을 구한다: ln 0.3 = −1.2040 이므로 $H(p) = 0.7 \times 0.3567 + 0.3 \times 1.2040$
5. 첫째 몫을 곱한다: 0.7 × 0.3567 = 0.2497 이므로 $H(p) = 0.2497 + 0.3 \times 1.2040$
6. 둘째 몫을 곱한다: 0.3 × 1.2040 = 0.3612 이므로 $H(p) = 0.2497 + 0.3612$
7. 더한다: 0.2497 + 0.3612 = 0.6109 이므로 $H(p) = 0.6109$

**답**: $H(p) = 0.6109$

</details>

### 문제 4

[정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)이 [원-핫](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#one-hot-encoding-%EC%9B%90-%ED%95%AB-%EC%9D%B8%EC%BD%94%EB%94%A9) $p = [0,\ 0,\ 1]$(3번 칸이 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5))이고 모델이 $q = [0.1,\ 0.3,\ 0.6]$을 냈다. [교차 엔트로피](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cross-entropy-%EA%B5%90%EC%B0%A8-%EC%97%94%ED%8A%B8%EB%A1%9C%ED%94%BC) $H(p, q)$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p = [0, 0, 1]$ ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) 분포: 3번 칸만 1)
- $q = [0.1, 0.3, 0.6]$ (모델의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0), [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) 칸 $q_{\text{정답}} = 0.6$)

**풀이**
1. 식을 그대로 쓴다: $H(p, q) = \sum_k p_k \times (-\ln q_k)$
2. 값을 대입한다 (Σ를 세 항으로 펼친다): $H(p, q) = 0 \times (-\ln 0.1) + 0 \times (-\ln 0.3) + 1 \times (-\ln 0.6)$
3. 1번 칸 몫을 곱한다 (0에 무엇을 곱해도 0): 0 × (−ln 0.1) = 0 이므로 $H(p, q) = 0 + 0 \times (-\ln 0.3) + 1 \times (-\ln 0.6)$
4. 2번 칸 몫을 곱한다: 0 × (−ln 0.3) = 0 이므로 $H(p, q) = 0 + 0 + 1 \times (-\ln 0.6)$
5. [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) 칸의 자기 정보량을 구한다: ln 0.6 = −0.5108 이므로 $H(p, q) = 0 + 0 + 1 \times 0.5108$
6. [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) 칸 몫을 곱한다: 1 × 0.5108 = 0.5108 이므로 $H(p, q) = 0 + 0 + 0.5108$
7. 더한다: 0 + 0 + 0.5108 = 0.5108

**답**: $H(p, q) = -\ln q_{\text{정답}} = 0.5108$

</details>

### 문제 5

진짜 분포가 $p = [0.6,\ 0.4]$이고 모델이 $q = [0.7,\ 0.3]$을 냈다. [교차 엔트로피](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cross-entropy-%EA%B5%90%EC%B0%A8-%EC%97%94%ED%8A%B8%EB%A1%9C%ED%94%BC) $H(p, q)$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p = [0.6, 0.4]$ ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)(진짜) 분포)
- $q = [0.7, 0.3]$ (모델의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))

**풀이**
1. 식을 그대로 쓴다: $H(p, q) = \sum_k p_k \times (-\ln q_k)$ (곱하는 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은 p, 자기 정보량은 모델의 q로 잰다)
2. 값을 대입한다: $H(p, q) = 0.6 \times (-\ln 0.7) + 0.4 \times (-\ln 0.3)$
3. 모델의 첫째 자기 정보량을 구한다: ln 0.7 = −0.3567 이므로 $H(p, q) = 0.6 \times 0.3567 + 0.4 \times (-\ln 0.3)$
4. 모델의 둘째 자기 정보량을 구한다: ln 0.3 = −1.2040 이므로 $H(p, q) = 0.6 \times 0.3567 + 0.4 \times 1.2040$
5. 첫째 몫을 곱한다: 0.6 × 0.3567 = 0.21402 이므로 $H(p, q) = 0.21402 + 0.4 \times 1.2040$
6. 둘째 몫을 곱한다: 0.4 × 1.2040 = 0.4816 이므로 $H(p, q) = 0.21402 + 0.4816$
7. 더한다: 0.21402 + 0.4816 = 0.69562 이므로 $H(p, q) \approx 0.6956$

**답**: $H(p, q) = 0.6956$

</details>

### 문제 6

문제 2에서 $H(p) = 0.6730$, 문제 5에서 $H(p, q) = 0.6956$을 구했다 (같은 $p = [0.6, 0.4]$, $q = [0.7, 0.3]$). 두 분포가 얼마나 다른지를 나타내는 [KL 발산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#kl-divergence-kl-%EB%B0%9C%EC%82%B0) $H(p, q) - H(p)$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $H(p, q) = 0.6956$ (모델의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)로 잰 [교차 엔트로피](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cross-entropy-%EA%B5%90%EC%B0%A8-%EC%97%94%ED%8A%B8%EB%A1%9C%ED%94%BC))
- $H(p) = 0.6730$ (진짜 분포의 [엔트로피](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#entropy-%EC%97%94%ED%8A%B8%EB%A1%9C%ED%94%BC))

**풀이**
1. 식을 그대로 쓴다: $\text{KL} = H(p, q) - H(p)$
2. 값을 대입한다: $\text{KL} = 0.6956 - 0.6730$
3. 뺄셈을 한다: 0.6956 − 0.6730 = 0.0226 이므로 $\text{KL} = 0.0226$

**답**: $\text{KL} = 0.0226$ (0 이상이고, q가 p와 같을 때만 0이다. 작으니 모델이 진짜에 꽤 가깝다)

</details>

### 문제 7

5등급 [분류](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#regression-classification-%ED%9A%8C%EA%B7%80%EC%99%80-%EB%B6%84%EB%A5%98) 모델이 [학습](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5) 직전에 모든 칸에 같은 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 준다. [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)이 원-핫일 때 이 모델의 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)([교차 엔트로피](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cross-entropy-%EA%B5%90%EC%B0%A8-%EC%97%94%ED%8A%B8%EB%A1%9C%ED%94%BC))은 얼마인가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $K = 5$ (등급 수)
- $q_k = \frac{1}{K}$ (모든 칸에 같은 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $p$ = [원-핫](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#one-hot-encoding-%EC%9B%90-%ED%95%AB-%EC%9D%B8%EC%BD%94%EB%94%A9) ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) 칸만 1, 나머지 0)

**풀이**
1. 칸마다의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 식을 쓴다: $q = \frac{1}{K}$
2. 값을 대입한다: $q = \frac{1}{5}$
3. 나눗셈을 한다: 1 ÷ 5 = 0.2 이므로 $q = 0.2$
4. [교차 엔트로피](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cross-entropy-%EA%B5%90%EC%B0%A8-%EC%97%94%ED%8A%B8%EB%A1%9C%ED%94%BC) 식을 쓴다: $H(p, q) = \sum_k p_k \times (-\ln q_k)$
5. 값을 대입한다 ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) 칸의 p는 1, 나머지 4칸의 p는 0이라 그 몫이 0): $H(p, q) = 1 \times (-\ln 0.2) + 0 + 0 + 0 + 0$
6. ln을 구한다: ln 0.2 = −1.6094 이므로 $H(p, q) = 1 \times 1.6094$
7. 곱셈을 한다: 1 × 1.6094 = 1.6094 이므로 $H(p, q) = 1.6094$

**답**: $\ln 5 = 1.6094$ (2등급은 0.6931, 3등급은 1.0986과 같은 방식)

</details>

### 문제 8

결과 3개짜리 분포 두 개의 [엔트로피](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#entropy-%EC%97%94%ED%8A%B8%EB%A1%9C%ED%94%BC)를 비교하라. (가) 균등 $p = [\frac{1}{3}, \frac{1}{3}, \frac{1}{3}]$, (나) 쏠림 $p = [0.8,\ 0.1,\ 0.1]$.

<details><summary>풀이와 답</summary>

**주어진 값**
- (가) $p_1 = p_2 = p_3 = \frac{1}{3}$
- (나) $p_1 = 0.8$, $p_2 = 0.1$, $p_3 = 0.1$

**풀이**
1. 식을 그대로 쓴다: $H(p) = \sum_k p_k \times (-\ln p_k)$
2. (가)에 값을 대입한다 (Σ를 세 항으로 펼친다): $H(p) = \frac{1}{3} \times (-\ln \tfrac{1}{3}) + \frac{1}{3} \times (-\ln \tfrac{1}{3}) + \frac{1}{3} \times (-\ln \tfrac{1}{3})$
3. 자기 정보량을 구한다: ln(1/3) = −1.0986 이므로 $H(p) = \frac{1}{3} \times 1.0986 + \frac{1}{3} \times 1.0986 + \frac{1}{3} \times 1.0986$
4. 몫 하나를 곱한다: 1/3 × 1.0986 = 0.3662 이므로 $H(p) = 0.3662 + 0.3662 + 0.3662$
5. 더한다: 0.3662 + 0.3662 + 0.3662 = 1.0986 이므로 (가)의 $H(p) = 1.0986$
6. (나)에 값을 대입한다: $H(p) = 0.8 \times (-\ln 0.8) + 0.1 \times (-\ln 0.1) + 0.1 \times (-\ln 0.1)$
7. 자기 정보량을 구한다: ln 0.8 = −0.22314, ln 0.1 = −2.30259 이므로 $H(p) = 0.8 \times 0.22314 + 0.1 \times 2.30259 + 0.1 \times 2.30259$
8. 몫을 곱한다: 0.8 × 0.22314 = 0.17851, 0.1 × 2.30259 = 0.23026 이므로 $H(p) = 0.17851 + 0.23026 + 0.23026$
9. 더한다: 0.17851 + 0.23026 + 0.23026 = 0.63903 이므로 (나)의 $H(p) = 0.6390$
10. 비교한다: 1.0986 > 0.6390

**답**: (가) 1.0986 (= ln 3), (나) 0.6390. 균등할수록 [엔트로피](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#entropy-%EC%97%94%ED%8A%B8%EB%A1%9C%ED%94%BC)가 크다

</details>

### 문제 9

[Lec09 14.2](../../Lec09_%ED%95%B4%EC%BB%A4%EC%9D%98_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EA%B0%80%EC%9D%B4%EB%93%9C.md#142-%EB%A1%9C%EA%B7%B8-%EC%86%90%EC%8B%A4-%EC%88%AB%EC%9E%90-%EC%99%B8%EC%9A%B0%EA%B8%B0)는 "10개 클래스 [분류](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#regression-classification-%ED%9A%8C%EA%B7%80%EC%99%80-%EB%B6%84%EB%A5%98)의 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 2.3이면 찍기 수준"이라고 알려 준다. 같은 방식으로 100등급 [분류](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#regression-classification-%ED%9A%8C%EA%B7%80%EC%99%80-%EB%B6%84%EB%A5%98) 모델의 찍기 수준 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)(모든 칸에 같은 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $K = 100$ (등급 수)
- $q = \frac{1}{K}$ (모든 칸에 같은 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $p$ = [원-핫](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#one-hot-encoding-%EC%9B%90-%ED%95%AB-%EC%9D%B8%EC%BD%94%EB%94%A9) ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) 칸만 1)

**풀이**
1. 식을 그대로 쓴다: $H(p, q) = \sum_k p_k \times (-\ln q_k)$ ([원-핫](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#one-hot-encoding-%EC%9B%90-%ED%95%AB-%EC%9D%B8%EC%BD%94%EB%94%A9)이라 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) 칸만 남아 $-\ln q$가 된다)
2. 값을 대입한다: $H(p, q) = -\ln \frac{1}{100}$
3. 분수를 소수로 바꾼다: 1/100 = 0.01 이므로 $H(p, q) = -\ln 0.01$
4. ln을 구한다: ln 0.01 = −4.6052 이므로 $H(p, q) = -(-4.6052)$
5. 마이너스를 붙인다: −(−4.6052) = 4.6052 이므로 $H(p, q) = 4.6052$
6. 10등급과 비교한다: 4.6052 ÷ 2.3026 = 2 (등급 수가 10배면 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 ln 10 = 2.3026만큼 커진다)

**답**: $\ln 100 = 4.6052$. [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 이 근처면 아직 찍는 수준이다

</details>
