# 예제: 조건부 확률과 독립

개념 노트: [MM58_조건부_확률과_독립](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/04_%ED%99%95%EB%A5%A0%EA%B3%BC_%EC%A0%95%EB%B3%B4/MM58_%EC%A1%B0%EA%B1%B4%EB%B6%80_%ED%99%95%EB%A5%A0%EA%B3%BC_%EB%8F%85%EB%A6%BD.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 쓰는 식은 넷이다. [조건부 확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#conditional-probability-%EC%A1%B0%EA%B1%B4%EB%B6%80-%ED%99%95%EB%A5%A0) $p(y\mid x) = p(x, y)/p(x)$, [독립](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#independence-%EB%8F%85%EB%A6%BD)이면 $p(x_1, \dots, x_n) = \prod_i p(x_i)$, [확률의 연쇄법칙](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#chain-rule-of-probability-%ED%99%95%EB%A5%A0%EC%9D%98-%EC%97%B0%EC%87%84%EB%B2%95%EC%B9%99) $p(x_1, x_2, x_3) = p(x_1)\,p(x_2\mid x_1)\,p(x_3\mid x_1, x_2)$, [베이즈 정리](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bayes-rule-%EB%B2%A0%EC%9D%B4%EC%A6%88-%EC%A0%95%EB%A6%AC) $p(x\mid c) = p(c\mid x)\,p(x)/p(c)$이다.

## 기본 (직접 대입)

### 문제 1

사진 속 물체가 개이면서 갈색일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 0.15이고, 물체가 개일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 0.5이다. 개라는 것을 알 때 갈색일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p(x, y) = 0.15$ (개이면서 갈색일 결합 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $p(x) = 0.5$ (개일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0), 조건)

**풀이**
1. 식을 그대로 쓴다: $p(y\mid x) = \dfrac{p(x, y)}{p(x)}$
2. 값을 대입한다: $p(\text{갈색}\mid \text{개}) = \dfrac{0.15}{0.5}$
3. 나눗셈을 한다: $0.15 \div 0.5 = 0.3$

**답**: **0.3**. 전체 사진 중에서는 15%지만, 개 사진만 놓고 보면 30%가 갈색이다

</details>

### 문제 2

두 픽셀의 [결합 분포](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#joint-distribution-%EA%B2%B0%ED%95%A9-%EB%B6%84%ED%8F%AC)가 아래 표와 같다. 픽셀 1이 청록일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) $p(x_1 = \text{청록})$과, 픽셀 1이 청록일 때 픽셀 2도 청록일 [조건부 확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#conditional-probability-%EC%A1%B0%EA%B1%B4%EB%B6%80-%ED%99%95%EB%A5%A0)을 구하라.

| | 픽셀 2 = 청록 | 픽셀 2 = 분홍 |
|---|---|---|
| 픽셀 1 = 청록 | 0.3 | 0.2 |
| 픽셀 1 = 분홍 | 0.1 | 0.4 |

<details><summary>풀이와 답</summary>

**주어진 값**
- $p(\text{청록}, \text{청록}) = 0.3$, $p(\text{청록}, \text{분홍}) = 0.2$ (첫 행)
- $p(\text{분홍}, \text{청록}) = 0.1$, $p(\text{분홍}, \text{분홍}) = 0.4$ (둘째 행)

**풀이**
1. 식을 그대로 쓴다: $p(x_2\mid x_1) = \dfrac{p(x_1, x_2)}{p(x_1)}$
2. 값을 대입한다: $p(\text{청록}\mid \text{청록}) = \dfrac{0.3}{p(x_1 = \text{청록})}$
3. 첫 행을 모두 더해 분모를 구한다 (주변 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)): $0.3 + 0.2 = 0.5$
4. 나눗셈을 한다: $0.3 \div 0.5 = 0.6$

**답**: $p(x_1 = \text{청록}) = $ **0.5**, [조건부 확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#conditional-probability-%EC%A1%B0%EA%B1%B4%EB%B6%80-%ED%99%95%EB%A5%A0) **0.6**. 한 픽셀이 청록이면 이웃도 60% [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)로 청록이다

</details>

### 문제 3

문제 2의 표에서 두 픽셀은 독립인가? (청록, 청록) 칸으로 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p(\text{청록}, \text{청록}) = 0.3$ (표의 칸)
- 표는 문제 2와 같다

**풀이**
1. 식을 그대로 쓴다: $p(x_1, x_2) \overset{?}{=} p(x_1)\,p(x_2)$
2. 값을 대입한다: $0.3 \overset{?}{=} p(x_1 = \text{청록}) \times p(x_2 = \text{청록})$
3. 첫 행을 더해 픽셀 1의 주변 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구한다: $0.3 + 0.2 = 0.5$
4. 첫 열을 더해 픽셀 2의 주변 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구한다: $0.3 + 0.1 = 0.4$
5. 두 주변 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 곱한다: $0.5 \times 0.4 = 0.2$
6. 실제 값과 비교한다: $0.3 \ne 0.2$

**답**: **[독립](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#independence-%EB%8F%85%EB%A6%BD)이 아니다**. 둘 다 청록일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 독립일 때(0.2)보다 높다

</details>

### 문제 4

셔츠 픽셀 4개가 서로 [독립](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#independence-%EB%8F%85%EB%A6%BD)이고 각각 청록일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 0.5라고 (잘못) 가정한 모델이 있다. 네 픽셀이 모두 청록일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은?

<details><summary>풀이와 답</summary>

**주어진 값**
- $n = 4$ (픽셀 수)
- $p(x_i = \text{청록}) = 0.5$ (픽셀마다 청록일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))

**풀이**
1. 식을 그대로 쓴다: $p(x_1, x_2, x_3, x_4) = \prod_{i=1}^{4} p(x_i)$
2. 값을 대입한다: $\prod_{i=1}^{4} 0.5$
3. ∏를 풀어 쓴다 ($i = 1, 2, 3, 4$를 차례로 곱함): $0.5 \times 0.5 \times 0.5 \times 0.5$
4. 앞의 둘을 곱한다: $0.5 \times 0.5 = 0.25$
5. 다음 수를 곱한다: $0.25 \times 0.5 = 0.125$
6. 마지막 수를 곱한다: $0.125 \times 0.5 = 0.0625$

**답**: **0.0625**. 픽셀이 늘수록 곱이 빠르게 작아진다

</details>

### 문제 5

데이터에서 노랑 배경은 30%, 분홍 배경은 70%이다. 글 설명이 "노랑 배경"이라고 할 때 실제로 노랑일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은? 글은 노랑일 때 0.8, 분홍일 때 0.2의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)로 "노랑"이라고 쓴다.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p(\text{노랑}) = 0.3$, $p(\text{분홍}) = 0.7$ (사전 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $p(c\mid \text{노랑}) = 0.8$ (노랑일 때 "노랑"이라 쓸 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $p(c\mid \text{분홍}) = 0.2$ (분홍일 때 잘못 "노랑"이라 쓸 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))

**풀이** (조건이 생긴 뒤의 믿음을 구하므로 [베이즈 정리](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bayes-rule-%EB%B2%A0%EC%9D%B4%EC%A6%88-%EC%A0%95%EB%A6%AC)를 쓴다)
1. 식을 그대로 쓴다: $p(x\mid c) = \dfrac{p(c\mid x)\,p(x)}{p(c)}$, $p(c) = \sum_x p(c\mid x)\,p(x)$
2. 값을 대입한다: $p(\text{노랑}\mid c) = \dfrac{0.8 \times 0.3}{0.8 \times 0.3 + 0.2 \times 0.7}$
3. 분자의 곱셈을 한다: $0.8 \times 0.3 = 0.24$
4. 분모 둘째 항의 곱셈을 한다: $0.2 \times 0.7 = 0.14$
5. 분모를 더한다: $0.24 + 0.14 = 0.38$
6. 나눗셈을 한다: $0.24 \div 0.38 = 0.6316$

**답**: **0.6316**. 사전 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 0.3에서 크게 올랐다

</details>

### 문제 6

세 픽셀에서 $p(x_1 = \text{청록}) = 0.5$, 첫 픽셀이 청록일 때 둘째도 청록일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 0.8, 앞의 둘이 모두 청록일 때 셋째도 청록일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 0.9이다. 세 픽셀이 모두 청록일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p(x_1) = 0.5$ (첫 픽셀이 청록일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $p(x_2\mid x_1) = 0.8$ (첫째가 청록일 때 둘째가 청록일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $p(x_3\mid x_1, x_2) = 0.9$ (앞의 둘이 청록일 때 셋째가 청록일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))

**풀이** (앞의 값을 조건으로 넣어 곱하는 [확률의 연쇄법칙](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#chain-rule-of-probability-%ED%99%95%EB%A5%A0%EC%9D%98-%EC%97%B0%EC%87%84%EB%B2%95%EC%B9%99)을 쓴다. [독립](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#independence-%EB%8F%85%EB%A6%BD) 가정이 필요 없다)
1. 식을 그대로 쓴다: $p(x_1, x_2, x_3) = p(x_1)\,p(x_2\mid x_1)\,p(x_3\mid x_1, x_2)$
2. 값을 대입한다: $p(x_1, x_2, x_3) = 0.5 \times 0.8 \times 0.9$
3. 앞의 둘을 곱한다: $0.5 \times 0.8 = 0.4$
4. 남은 수를 곱한다: $0.4 \times 0.9 = 0.36$

**답**: **0.36**. [독립](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#independence-%EB%8F%85%EB%A6%BD) 모델이었다면 $0.5^3 = 0.125$였을 값이다

</details>

### 문제 7

두 픽셀의 진짜 [결합 분포](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#joint-distribution-%EA%B2%B0%ED%95%A9-%EB%B6%84%ED%8F%AC)가 아래 표와 같다. 각 픽셀의 주변 분포는 둘 다 (청록 0.5, 분홍 0.5)이다. [독립](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#independence-%EB%8F%85%EB%A6%BD)을 가정한 모델이 "두 픽셀이 같은 색"일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)에 주는 값과 진짜 값을 구하고 비교하라.

| | 픽셀 2 = 청록 | 픽셀 2 = 분홍 |
|---|---|---|
| 픽셀 1 = 청록 | 0.45 | 0.05 |
| 픽셀 1 = 분홍 | 0.05 | 0.45 |

<details><summary>풀이와 답</summary>

**주어진 값**
- 진짜 결합: (청록, 청록) 0.45, (분홍, 분홍) 0.45, 어긋난 두 칸 0.05씩
- 주변 분포: 픽셀 1, 픽셀 2 모두 청록 0.5, 분홍 0.5

**풀이**
1. 진짜 값의 식을 쓴다: 같은 색일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) $= p(\text{청록}, \text{청록}) + p(\text{분홍}, \text{분홍})$
2. 값을 대입하고 더한다: $0.45 + 0.45 = 0.9$
3. [독립](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#independence-%EB%8F%85%EB%A6%BD) 모델의 식을 쓴다: $p(x_1, x_2) = p(x_1)\,p(x_2)$
4. 값을 대입한다: $p(\text{청록}, \text{청록}) = 0.5 \times 0.5$, $p(\text{분홍}, \text{분홍}) = 0.5 \times 0.5$
5. 곱한다: $0.5 \times 0.5 = 0.25$ (두 칸 모두)
6. 같은 색인 두 칸을 더한다: $0.25 + 0.25 = 0.5$
7. 비교한다: $0.5 < 0.9$

**답**: [독립](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#independence-%EB%8F%85%EB%A6%BD) 모델 **0.5**, 진짜 **0.9**. 주변 분포가 둘 다 맞는데도 [결합 분포](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#joint-distribution-%EA%B2%B0%ED%95%A9-%EB%B6%84%ED%8F%AC)는 크게 어긋난다. 어긋난 셔츠에 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)의 절반을 새게 한다

</details>

### 문제 8

데이터에서 노랑 배경은 10%, 분홍은 90%이다. 글은 노랑일 때 0.9, 분홍일 때 0.3의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)로 "노랑"이라고 쓴다. $p(c\mid \text{노랑})$과 $p(\text{노랑}\mid c)$를 각각 구하고 둘이 같은지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p(\text{노랑}) = 0.1$, $p(\text{분홍}) = 0.9$ (사전 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $p(c\mid \text{노랑}) = 0.9$, $p(c\mid \text{분홍}) = 0.3$ (글이 "노랑"이라 쓸 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))

**풀이** ($p(c\mid \text{노랑})$은 주어졌고, 방향을 뒤집은 $p(\text{노랑}\mid c)$를 구한다)
1. 식을 그대로 쓴다: $p(\text{노랑}\mid c) = \dfrac{p(c\mid \text{노랑})\,p(\text{노랑})}{p(c)}$
2. 값을 대입한다: $p(\text{노랑}\mid c) = \dfrac{0.9 \times 0.1}{0.9 \times 0.1 + 0.3 \times 0.9}$
3. 분자의 곱셈을 한다: $0.9 \times 0.1 = 0.09$
4. 분모 둘째 항의 곱셈을 한다: $0.3 \times 0.9 = 0.27$
5. 분모를 더한다: $0.09 + 0.27 = 0.36$
6. 나눗셈을 한다: $0.09 \div 0.36 = 0.25$

**답**: $p(c\mid \text{노랑}) = $ **0.9**, $p(\text{노랑}\mid c) = $ **0.25**. 서로 다르다. 노랑 배경이 원래 드물어서 글이 "노랑"이라 해도 노랑일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은 25%에 그친다. 조건의 방향을 헷갈리면 안 된다

</details>

### 문제 9

([Lec16 2.2](../../Lec16_%EC%A1%B0%EA%B1%B4%EB%B6%80_%EC%83%9D%EC%84%B1_%EB%AA%A8%EB%8D%B8.md#22-%ED%94%BD%EC%85%80%EB%A7%88%EB%8B%A4-%EB%94%B0%EB%A1%9C-%EB%B6%84%EB%A5%98%ED%95%98%EB%A9%B4)) 진짜 셔츠는 전체가 청록이거나 전체가 분홍이고 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 반반이다. 픽셀 10개를 [독립](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#independence-%EB%8F%85%EB%A6%BD)으로 취급하는 모델이 "모두 같은 색"에 주는 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구하고, 진짜 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)의 몇 분의 1인지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $n = 10$ (픽셀 수)
- 픽셀마다 청록 0.5, 분홍 0.5 (주변 분포, [독립](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#independence-%EB%8F%85%EB%A6%BD) 모델이 쓰는 값)
- 진짜 "모두 같은 색" [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) $= 0.5 + 0.5 = 1$ (셔츠는 늘 한 색)

**풀이** (모두 같은 색은 "모두 청록" 또는 "모두 분홍"이다)
1. 식을 쓴다: $P(\text{모두 같은 색}) = \prod_{i=1}^{n} p(\text{청록}) + \prod_{i=1}^{n} p(\text{분홍}) = 2 \times 0.5^{n}$
2. 값을 대입한다: $2 \times 0.5^{10}$
3. 거듭제곱을 계산한다: $0.5^{10} = 1 / 2^{10} = 1 / 1024 = 0.000977$
4. 곱한다: $2 \times 0.000977 = 0.001953$
5. 진짜 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)과 비교한다: 진짜 셔츠는 늘 한 색이므로 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 1, $1 / 0.001953 = 512$

**답**: [독립](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#independence-%EB%8F%85%EB%A6%BD) 모델은 **0.00195**(약 0.002)를 준다. 진짜(1)의 약 **512분의 1**이다. 거의 모든 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 얼룩덜룩한 셔츠에 새어 나간다

</details>

### 문제 10

([Lec16 8.3](../../Lec16_%EC%A1%B0%EA%B1%B4%EB%B6%80_%EC%83%9D%EC%84%B1_%EB%AA%A8%EB%8D%B8.md#83-%EC%A1%B0%EA%B1%B4%EB%B6%80-%ED%99%95%EC%82%B0-%EB%AA%A8%EB%8D%B8)) 배경색이 노랑·파랑·초록 셋 중 하나이고 사전 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은 $(0.5, 0.3, 0.2)$이다. 글 설명 $c$ = "밝은 색"이 나올 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은 색마다 $(0.6, 0.2, 0.1)$이다. 글을 본 뒤 각 색의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)(사후 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))을 구하고 합이 1인지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p(x) = (0.5, 0.3, 0.2)$ (노랑, 파랑, 초록의 사전 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $p(c\mid x) = (0.6, 0.2, 0.1)$ (색마다 글이 "밝은 색"일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))

**풀이**
1. 식을 그대로 쓴다: $p(x\mid c) = \dfrac{p(c\mid x)\,p(x)}{p(c)}$, $p(c) = \sum_x p(c\mid x)\,p(x)$
2. 색마다 분자를 구한다: 노랑 $0.6 \times 0.5 = 0.30$, 파랑 $0.2 \times 0.3 = 0.06$, 초록 $0.1 \times 0.2 = 0.02$
3. 분모를 구한다 (Σ를 풀어 더함): $p(c) = 0.30 + 0.06 + 0.02 = 0.38$
4. 노랑을 나눈다: $0.30 / 0.38 = 0.7895$
5. 파랑을 나눈다: $0.06 / 0.38 = 0.1579$
6. 초록을 나눈다: $0.02 / 0.38 = 0.0526$
7. 합을 확인한다: $0.7895 + 0.1579 + 0.0526 = 1.0000$

**답**: 노랑 **0.7895**, 파랑 **0.1579**, 초록 **0.0526**, 합 1. 글을 본 뒤 노랑의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 0.5에서 0.79로 올랐다

</details>
