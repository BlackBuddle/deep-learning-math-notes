# 예제: 베이즈 규칙과 사전 확률 보정

개념 노트: [MM64_베이즈_규칙과_사전_확률_보정](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/04_%ED%99%95%EB%A5%A0%EA%B3%BC_%EC%A0%95%EB%B3%B4/MM64_%EB%B2%A0%EC%9D%B4%EC%A6%88_%EA%B7%9C%EC%B9%99%EA%B3%BC_%EC%82%AC%EC%A0%84_%ED%99%95%EB%A5%A0_%EB%B3%B4%EC%A0%95.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 세 식을 쓴다. 베이즈 규칙 $P(y \mid x) = \dfrac{P(x \mid y)P(y)}{\sum_{y'} P(x \mid y')P(y')}$, 사전 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 보정 $P_{\text{new}}(y \mid x) \propto P_{\text{old}}(y \mid x)\,q(y)/p(y)$, 두 분포 합치기 $P(y \mid I, \mathbf{x}) \propto P(y \mid I)\,P(y \mid \mathbf{x})$. "$\propto$"는 곱한 뒤 합이 1이 되도록 나눈다는 뜻이다.

## 기본 (직접 대입)

### 문제 1

너구리가 밤에 찍힐 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은 $0.6$, 고양이는 $0.2$이다. 두 동물이 반반으로 산다. 밤 사진이 너구리일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $P(\text{밤} \mid \text{너구리}) = 0.6$, $P(\text{밤} \mid \text{고양이}) = 0.2$ (가능도)
- $P(\text{너구리}) = 0.5$, $P(\text{고양이}) = 0.5$ (사전 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))

**풀이**
1. 식을 그대로 쓴다: $P(\text{너구리} \mid \text{밤}) = \dfrac{P(\text{밤} \mid \text{너구리})P(\text{너구리})}{P(\text{밤} \mid \text{너구리})P(\text{너구리}) + P(\text{밤} \mid \text{고양이})P(\text{고양이})}$ (분모의 Σ를 두 항으로 펼침)
2. 값을 대입한다: $\dfrac{0.6 \times 0.5}{0.6 \times 0.5 + 0.2 \times 0.5}$
3. 곱셈을 한다: $0.6 \times 0.5 = 0.3$, $0.2 \times 0.5 = 0.1$
4. 분모를 더한다: $0.3 + 0.1 = 0.4$
5. 나눈다: $0.3 / 0.4 = 0.75$

**답**: $0.75$. 사전 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 같으면 가능도의 비 $0.6 : 0.2$가 그대로 판단이 된다.

</details>

### 문제 2

문제 1과 같은 가능도($0.6$, $0.2$)인데 이 동네는 너구리가 10%, 고양이가 90%이다. 밤 사진이 너구리일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $P(\text{밤} \mid \text{너구리}) = 0.6$, $P(\text{밤} \mid \text{고양이}) = 0.2$ (가능도)
- $P(\text{너구리}) = 0.1$, $P(\text{고양이}) = 0.9$ (사전 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))

**풀이**
1. 식을 그대로 쓴다: $P(\text{너구리} \mid \text{밤}) = \dfrac{P(\text{밤} \mid \text{너구리})P(\text{너구리})}{P(\text{밤} \mid \text{너구리})P(\text{너구리}) + P(\text{밤} \mid \text{고양이})P(\text{고양이})}$
2. 값을 대입한다: $\dfrac{0.6 \times 0.1}{0.6 \times 0.1 + 0.2 \times 0.9}$
3. 곱셈을 한다: $0.6 \times 0.1 = 0.06$, $0.2 \times 0.9 = 0.18$
4. 분모를 더한다: $0.06 + 0.18 = 0.24$
5. 나눈다: $0.06 / 0.24 = 0.25$

**답**: $0.25$. 문제 1의 $0.75$에서 사전 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)만 바뀌었는데 판단이 고양이 쪽으로 뒤집혔다.

</details>

### 문제 3

반반으로 학습한 분류기가 어떤 사진에 (너구리 $0.7$, 고양이 $0.3$)을 냈다. 이 카메라 위치의 비율은 너구리 20%, 고양이 80%이다. 고친 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구하라.

<details><summary>풀이와 답</summary>

[학습](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5) 때의 사전 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) $p$와 배포 장소의 사전 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) $q$가 다르고 겉모습 $P(x \mid y)$는 같으므로 사전 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 보정을 쓴다.

**주어진 값**
- $P_{\text{old}} = (0.7, 0.3)$ (분류기 출력: 너구리, 고양이)
- $p = (0.5, 0.5)$ ([학습](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5) 비율), $q = (0.2, 0.8)$ (이 카메라의 비율)

**풀이**
1. 식을 그대로 쓴다: $P_{\text{new}}(y \mid x) = \dfrac{P_{\text{old}}(y \mid x)\, q(y)/p(y)}{\sum_{y'} P_{\text{old}}(y' \mid x)\, q(y')/p(y')}$
2. 값을 대입한다: $P_{\text{new}}(\text{너구리} \mid x) = \dfrac{0.7 \times 0.2/0.5}{0.7 \times 0.2/0.5 + 0.3 \times 0.8/0.5}$
3. 배율을 나눈다: $0.2 / 0.5 = 0.4$, $0.8 / 0.5 = 1.6$
4. 곱한다: $0.7 \times 0.4 = 0.28$, $0.3 \times 1.6 = 0.48$
5. 분모를 더한다: $0.28 + 0.48 = 0.76$
6. 너구리를 나눈다: $0.28 / 0.76 = 0.3684$
7. 고양이를 나눈다: $0.48 / 0.76 = 0.6316$

**답**: $(0.3684, 0.6316)$. 다시 학습하지 않고 예측이 너구리에서 고양이로 바뀌었다.

</details>

### 문제 4

사진 분류기의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 $P(y \mid I) = (0.6, 0.4)$이고, 촬영 장소·시간으로 본 종의 사전 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 $P(y \mid \mathbf{x}) = (0.2, 0.8)$이다. 두 정보를 합친 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구하라.

<details><summary>풀이와 답</summary>

두 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 서로 다른 증거에서 나왔으므로 칸마다 곱한 뒤 합이 1이 되게 나눈다 ($P(y \mid I, \mathbf{x}) \propto P(y \mid I)\,P(y \mid \mathbf{x})$).

**주어진 값**
- $P(y \mid I) = (0.6, 0.4)$ (사진 분류기)
- $P(y \mid \mathbf{x}) = (0.2, 0.8)$ (장소·시간 사전)

**풀이**
1. 식을 그대로 쓴다: $P(y \mid I, \mathbf{x}) = \dfrac{P(y \mid I)\,P(y \mid \mathbf{x})}{\sum_{y'} P(y' \mid I)\,P(y' \mid \mathbf{x})}$
2. 값을 대입한다: $P(\text{종 1}) = \dfrac{0.6 \times 0.2}{0.6 \times 0.2 + 0.4 \times 0.8}$
3. 곱한다: $0.6 \times 0.2 = 0.12$, $0.4 \times 0.8 = 0.32$
4. 분모를 더한다: $0.12 + 0.32 = 0.44$
5. 나눈다: $0.12 / 0.44 = 0.2727$, $0.32 / 0.44 = 0.7273$

**답**: $(0.2727, 0.7273)$. 사진 분류기는 종 1을 골랐지만(0.6) 장소·시간 정보가 종 2를 가리켜 결론이 종 2로 바뀐다.

</details>

### 문제 5

종 3개의 분류기 출력이 $P_{\text{old}} = (0.5, 0.3, 0.2)$이고 [학습](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5) 비율은 $p = (0.5, 0.25, 0.25)$이다. 배포 장소의 비율이 $q = (0.2, 0.4, 0.4)$일 때 고친 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $P_{\text{old}} = (0.5, 0.3, 0.2)$ (분류기 출력)
- $p = (0.5, 0.25, 0.25)$ ([학습](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5) 비율), $q = (0.2, 0.4, 0.4)$ (배포 비율)

**풀이**
1. 식을 그대로 쓴다: $P_{\text{new}}(y \mid x) = \dfrac{P_{\text{old}}(y \mid x)\, q(y)/p(y)}{\sum_{y'} P_{\text{old}}(y' \mid x)\, q(y')/p(y')}$
2. 값을 대입한다 (Σ를 세 항으로 펼침): 분모 $= 0.5 \times 0.2/0.5 + 0.3 \times 0.4/0.25 + 0.2 \times 0.4/0.25$
3. 배율을 나눈다: $0.2/0.5 = 0.4$, $0.4/0.25 = 1.6$, $0.4/0.25 = 1.6$
4. 출력에 곱한다: $0.5 \times 0.4 = 0.2$, $0.3 \times 1.6 = 0.48$, $0.2 \times 1.6 = 0.32$
5. 분모를 더한다: $0.2 + 0.48 + 0.32 = 1.0$
6. 각 칸을 나눈다: $0.2 / 1.0 = 0.2$, $0.48 / 1.0 = 0.48$, $0.32 / 1.0 = 0.32$

**답**: $(0.2, 0.48, 0.32)$. 1등이 종 1(0.5)에서 종 2(0.48)로 바뀐다. 이번에는 우연히 합이 1이라 나눗셈이 값을 바꾸지 않았다.

</details>

### 문제 6

어떤 병의 유병률은 1%이다. 검사는 병이 있으면 90%, 병이 없으면 10%의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)로 양성이 나온다. 양성이 나온 사람이 실제로 병이 있을 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구하라.

<details><summary>풀이와 답</summary>

"양성이라는 관찰을 보고 원인을 거꾸로 추정"하는 문제라서 베이즈 규칙을 쓴다. 사전 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은 유병률이다.

**주어진 값**
- $P(\text{양성} \mid \text{병}) = 0.9$, $P(\text{양성} \mid \text{건강}) = 0.1$ (가능도)
- $P(\text{병}) = 0.01$, $P(\text{건강}) = 0.99$ (사전 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))

**풀이**
1. 식을 그대로 쓴다: $P(\text{병} \mid \text{양성}) = \dfrac{P(\text{양성} \mid \text{병})P(\text{병})}{P(\text{양성} \mid \text{병})P(\text{병}) + P(\text{양성} \mid \text{건강})P(\text{건강})}$
2. 값을 대입한다: $\dfrac{0.9 \times 0.01}{0.9 \times 0.01 + 0.1 \times 0.99}$
3. 곱셈을 한다: $0.9 \times 0.01 = 0.009$, $0.1 \times 0.99 = 0.099$
4. 분모를 더한다: $0.009 + 0.099 = 0.108$
5. 나눈다: $0.009 / 0.108 = 0.0833$

**답**: 약 $0.0833$ (8.3%). 검사가 90% 정확해도 병이 드물면 양성의 대부분이 건강한 사람이다. 사전 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 이렇게 크게 작용한다.

</details>

### 문제 7

양성 비율 90%, 음성 비율 10%로 학습한 분류기가 어떤 입력에 (양성 $0.6$, 음성 $0.4$)을 냈다. 시험 장소에서는 두 범주가 반반이다. 고친 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구하고 예측이 바뀌는지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $P_{\text{old}} = (0.6, 0.4)$ (분류기 출력: 양성, 음성)
- $p = (0.9, 0.1)$ ([학습](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5) 비율), $q = (0.5, 0.5)$ (시험 비율)

**풀이**
1. 식을 그대로 쓴다: $P_{\text{new}}(y \mid x) = \dfrac{P_{\text{old}}(y \mid x)\, q(y)/p(y)}{\sum_{y'} P_{\text{old}}(y' \mid x)\, q(y')/p(y')}$
2. 값을 대입한다: $P_{\text{new}}(\text{양성} \mid x) = \dfrac{0.6 \times 0.5/0.9}{0.6 \times 0.5/0.9 + 0.4 \times 0.5/0.1}$
3. 배율을 나눈다: $0.5 / 0.9 = 0.5556$, $0.5 / 0.1 = 5$
4. 곱한다: $0.6 \times 0.5556 = 0.3333$, $0.4 \times 5 = 2$
5. 분모를 더한다: $0.3333 + 2 = 2.3333$
6. 양성을 나눈다: $0.3333 / 2.3333 = 0.1429$
7. 음성을 나눈다: $2 / 2.3333 = 0.8571$

**답**: $(0.1429, 0.8571)$. 예측이 양성(0.6)에서 음성(0.8571)으로 바뀐다. [학습](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5) 때 흔했던 양성 쪽으로 치우친 분류기를 시험 장소의 비율에 맞춰 고친 것이다.

</details>

### 문제 8

반반으로 학습한 분류기의 출력이 (고양이 $0.4$, 너구리 $0.6$)이다. 배포 장소의 비율이 $q = (0.6, 0.4)$ (고양이, 너구리)일 때 고친 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구하라. 판단이 어떻게 되는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $P_{\text{old}} = (0.4, 0.6)$ (분류기 출력: 고양이, 너구리)
- $p = (0.5, 0.5)$ ([학습](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5) 비율), $q = (0.6, 0.4)$ (배포 비율)

**풀이**
1. 식을 그대로 쓴다: $P_{\text{new}}(y \mid x) = \dfrac{P_{\text{old}}(y \mid x)\, q(y)/p(y)}{\sum_{y'} P_{\text{old}}(y' \mid x)\, q(y')/p(y')}$
2. 값을 대입한다: $P_{\text{new}}(\text{고양이} \mid x) = \dfrac{0.4 \times 0.6/0.5}{0.4 \times 0.6/0.5 + 0.6 \times 0.4/0.5}$
3. 배율을 나눈다: $0.6 / 0.5 = 1.2$, $0.4 / 0.5 = 0.8$
4. 곱한다: $0.4 \times 1.2 = 0.48$, $0.6 \times 0.8 = 0.48$
5. 분모를 더한다: $0.48 + 0.48 = 0.96$
6. 나눈다: $0.48 / 0.96 = 0.5$ (두 칸 모두)

**답**: $(0.5, 0.5)$. 정확히 비긴다. 분류기가 너구리 쪽으로 기울어 있던 정도($0.4$ 대 $0.6$)가, 고양이가 더 흔한 배포 장소의 비율($0.6$ 대 $0.4$)과 정확히 상쇄된 것이다. 고양이 비율이 $0.6$보다 높으면 고양이로 뒤집힌다.

</details>

### 문제 9

Lec17 10.3의 [하위 집단 이동](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#subpopulation-shift-%ED%95%98%EC%9C%84-%EC%A7%91%EB%8B%A8-%EC%9D%B4%EB%8F%99)이다. 반반으로 학습한 분류기가 어느 사진에 (너구리 $0.3$, 고양이 $0.7$)을 냈다. 이 카메라는 너구리가 많이 오는 곳으로 너구리 90%, 고양이 10%이다. 추가 [학습](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5) 없이 고친 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구하라 (Lec17 12.1의 베이즈 재보정).

<details><summary>풀이와 답</summary>

범주 비율만 바뀌고 겉모습은 그대로인 [하위 집단 이동](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#subpopulation-shift-%ED%95%98%EC%9C%84-%EC%A7%91%EB%8B%A8-%EC%9D%B4%EB%8F%99)이므로 사전 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 보정을 쓴다.

**주어진 값**
- $P_{\text{old}} = (0.3, 0.7)$ (분류기 출력: 너구리, 고양이)
- $p = (0.5, 0.5)$ ([학습](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5) 비율), $q = (0.9, 0.1)$ (이 카메라의 비율)

**풀이**

3. 배율을 나눈다: $0.9 / 0.5 = 1.8$, $0.1 / 0.5 = 0.2$
4. 곱한다: $0.3 \times 1.8 = 0.54$, $0.7 \times 0.2 = 0.14$
5. 분모를 더한다: $0.54 + 0.14 = 0.68$
6. 너구리를 나눈다: $0.54 / 0.68 = 0.7941$
7. 고양이를 나눈다: $0.14 / 0.68 = 0.2059$

**답**: $(0.7941, 0.2059)$. 분류기는 고양이(0.7)라고 했지만 이 카메라에서는 너구리일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 0.7941이다.

### 문제 10

Lec17 12.1의 시공간 사전이다. 종이 3개이고 사진 분류기의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 $P(y \mid I) = (0.4, 0.4, 0.2)$, 촬영 장소·시간의 사전이 $P(y \mid \mathbf{x}) = (0.1, 0.5, 0.4)$이다. 합친 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $P(y \mid I) = (0.4, 0.4, 0.2)$ (사진 분류기)
- $P(y \mid \mathbf{x}) = (0.1, 0.5, 0.4)$ (장소·시간 사전)

**풀이**
1. 식을 그대로 쓴다: $P(y \mid I, \mathbf{x}) = \dfrac{P(y \mid I)\,P(y \mid \mathbf{x})}{\sum_{y'} P(y' \mid I)\,P(y' \mid \mathbf{x})}$
2. 값을 대입한다 (Σ를 세 항으로 펼침): 분모 $= 0.4 \times 0.1 + 0.4 \times 0.5 + 0.2 \times 0.4$
3. 칸마다 곱한다: $0.4 \times 0.1 = 0.04$, $0.4 \times 0.5 = 0.2$, $0.2 \times 0.4 = 0.08$
4. 분모를 더한다: $0.04 + 0.2 + 0.08 = 0.32$
5. 각 칸을 나눈다: $0.04 / 0.32 = 0.125$, $0.2 / 0.32 = 0.625$, $0.08 / 0.32 = 0.25$

**답**: $(0.125, 0.625, 0.25)$. 사진 분류기는 종 1과 종 2를 비슷하게 봤지만(0.4, 0.4) 장소·시간 정보가 종 2를 밀어 종 2가 0.625로 뚜렷해진다.

</details>
