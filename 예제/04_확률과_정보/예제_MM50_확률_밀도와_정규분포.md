# 예제: 확률 밀도와 정규분포

개념 노트: [MM50_확률_밀도와_정규분포](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/04_%ED%99%95%EB%A5%A0%EA%B3%BC_%EC%A0%95%EB%B3%B4/MM50_%ED%99%95%EB%A5%A0_%EB%B0%80%EB%8F%84%EC%99%80_%EC%A0%95%EA%B7%9C%EB%B6%84%ED%8F%AC.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. [정규분포](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#normal-distribution-%EC%A0%95%EA%B7%9C%EB%B6%84%ED%8F%AC) 밀도는 $\mathcal{N}(x; \mu, \sigma^2) = \dfrac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left(-\dfrac{(x - \mu)^2}{2\sigma^2}\right)$이고 $\pi = 3.1416$이다.

## 기본 (직접 대입)

### 문제 1

값이 1, 2, 3, 4 중 하나인 [확률 변수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#random-variable-%ED%99%95%EB%A5%A0-%EB%B3%80%EC%88%98)의 [확률 질량 함수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-mass-function-%ED%99%95%EB%A5%A0-%EC%A7%88%EB%9F%89-%ED%95%A8%EC%88%98)가 $p(1) = 0.1$, $p(3) = 0.35$, $p(4) = 0.25$이다. $p(2)$는 얼마여야 하는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $p(1) = 0.1$, $p(3) = 0.35$, $p(4) = 0.25$ (알려진 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $p(2)$ (구할 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))

**풀이**
1. 식을 그대로 쓴다: $\sum_x p(x) = 1$
2. 값을 대입한다 (Σ를 네 항으로 풀어 썼다): $p(1) + p(2) + p(3) + p(4) = 0.1 + p(2) + 0.35 + 0.25 = 1$
3. 아는 값을 더한다: $0.1 + 0.35 + 0.25 = 0.7$ 이므로 $0.7 + p(2) = 1$
4. 뺀다: $p(2) = 1 - 0.7 = 0.3$

**답**: $p(2) = 0.3$ (0과 1 사이이고 합이 1이므로 조건을 만족한다)

</details>

### 문제 2

0과 0.25 사이에서 고르게 나오는 값(균등 분포)이 있다. 밀도 $p(x)$는 얼마이고, 0.05와 0.15 사이에 들어갈 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은 얼마인가?

<details><summary>풀이와 답</summary>

**주어진 값**
- 값의 범위 $[0, 0.25]$ (그 밖에서는 밀도 0)
- 구간 $[0.05, 0.15]$ ([확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 묻는 범위)

**풀이**
1. 식을 그대로 쓴다: $\int p(x)\, dx = 1$. 높이가 일정하면 곡선 아래 넓이는 높이 × 폭이다
2. 값을 대입한다: $p \times (0.25 - 0) = 1$
3. 폭을 구한다: $0.25 - 0 = 0.25$ 이므로 $p \times 0.25 = 1$
4. 나눈다: $p = 1 / 0.25 = 4$
5. 질문 구간의 폭을 구한다: $0.15 - 0.05 = 0.1$
6. 높이와 폭을 곱한다: $4 \times 0.1 = 0.4$

**답**: 밀도 $p(x) = 4$, [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은 $0.4$ (밀도가 1보다 커도 넓이가 1이면 된다)

</details>

### 문제 3

표준 [정규분포](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#normal-distribution-%EC%A0%95%EA%B7%9C%EB%B6%84%ED%8F%AC) $\mathcal{N}(0, 1)$의 밀도를 $x = 1$에서 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x = 1$ (밀도를 잴 위치)
- $\mu = 0$ (평균)
- $\sigma = 1$ (표준편차)

**풀이**
1. 식을 그대로 쓴다: $\mathcal{N}(x; \mu, \sigma^2) = \dfrac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left(-\dfrac{(x - \mu)^2}{2\sigma^2}\right)$
2. 값을 대입한다: $\mathcal{N}(1; 0, 1^2) = \dfrac{1}{\sqrt{2\pi \times 1^2}} \exp\!\left(-\dfrac{(1 - 0)^2}{2 \times 1^2}\right)$
3. 앞 인수의 루트 안을 곱한다: $2 \times 3.1416 \times 1 = 6.2832$
4. 제곱근을 구한다. $\sqrt{a}$는 제곱해서 $a$가 되는 양수다: $\sqrt{6.2832} = 2.5066$
5. 나눈다: $1 / 2.5066 = 0.3989$
6. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98) 안을 계산한다: $(1 - 0)^2 = 1$, $2 \times 1 = 2$ 이므로 $-1/2 = -0.5$
7. $\exp$를 계산한다. $\exp(a) = e^a$이고 $e$는 약 2.718이다: $e^{-0.5} = 0.6065$
8. 곱한다: $0.3989 \times 0.6065 = 0.2420$ (반올림 전 값으로 계산)

**답**: 밀도 $0.2420$ (꼭대기 0.3989보다 낮다. 평균에서 한 표준편차 떨어진 자리다)

</details>

### 문제 4

[정규분포](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#normal-distribution-%EC%A0%95%EA%B7%9C%EB%B6%84%ED%8F%AC) $\mathcal{N}(\mu, \sigma^2)$에서 표본을 만든다. $\mu = -1$, $\sigma = 3$이고 표준 정규 표본 $\epsilon = 0.4$를 뽑았다. 표본 $x = \mu + \sigma\epsilon$을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mu = -1$ (평균)
- $\sigma = 3$ (표준편차)
- $\epsilon = 0.4$ (표준 정규에서 뽑은 값)

**풀이**
1. 식을 그대로 쓴다: $x = \mu + \sigma\epsilon$
2. 값을 대입한다: $x = -1 + 3 \times 0.4$
3. 곱셈을 먼저 한다: $3 \times 0.4 = 1.2$ 이므로 $x = -1 + 1.2$
4. 더한다: $-1 + 1.2 = 0.2$

**답**: $x = 0.2$ (표준 정규 값을 $\sigma$배로 늘리고 $\mu$만큼 옮긴 것이다)

</details>

### 문제 5

$\mathcal{N}(0, 2^2)$(평균 0, 표준편차 2)의 밀도를 $x = 2$에서 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x = 2$ (밀도를 잴 위치)
- $\mu = 0$ (평균)
- $\sigma = 2$ (표준편차), $\sigma^2 = 4$

**풀이**
1. 식을 그대로 쓴다: $\mathcal{N}(x; \mu, \sigma^2) = \dfrac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left(-\dfrac{(x - \mu)^2}{2\sigma^2}\right)$
2. 값을 대입한다: $\mathcal{N}(2; 0, 2^2) = \dfrac{1}{\sqrt{2\pi \times 4}} \exp\!\left(-\dfrac{(2 - 0)^2}{2 \times 4}\right)$
3. 루트 안을 곱한다: $2 \times 3.1416 \times 4 = 25.1327$
4. 제곱근을 구한다: $\sqrt{25.1327} = 5.0133$
5. 나눈다: $1 / 5.0133 = 0.1995$
6. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98) 안을 계산한다: $(2 - 0)^2 = 4$, $2 \times 4 = 8$ 이므로 $-4/8 = -0.5$
7. $\exp$를 계산한다: $e^{-0.5} = 0.6065$
8. 곱한다: $0.1995 \times 0.6065 = 0.1210$

**답**: 밀도 $0.1210$ (한 표준편차 떨어진 자리라 꼭대기 0.1995의 0.6065배다)

</details>

### 문제 6

[범주 분포](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#categorical-distribution-%EB%B2%94%EC%A3%BC-%EB%B6%84%ED%8F%AC) $p = (0.25, 0.25, 0.5)$에서 표본을 뽑는다. 0과 1 사이 균등 난수가 $u = 0.2$일 때와 $u = 0.62$일 때 몇 번 칸이 뽑히는가? (규칙: 누적 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 처음으로 $u$ 이상이 되는 칸)

<details><summary>풀이와 답</summary>

**주어진 값**
- $p = (0.25, 0.25, 0.5)$ (세 칸의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $u = 0.2$ 와 $u = 0.62$ (난수)

**풀이**
1. 식을 그대로 쓴다: $u \le \sum_{j=1}^{k} p_j$ 를 처음 만족하는 $k$
2. 값을 대입한다: $\sum_{j=1}^{k} p_j$ 는 $k = 1, 2, 3$에서 $0.25,\ 0.25 + 0.25,\ 0.25 + 0.25 + 0.5$
3. 누적 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 계산한다: $0.25,\ 0.5,\ 1.0$
4. $u = 0.2$ 를 비교한다: $0.2 \le 0.25$ 이므로 첫 칸에서 멈춘다
5. $u = 0.62$ 를 비교한다: $0.62 \le 0.25$? 아니다. $0.62 \le 0.5$? 아니다. $0.62 \le 1.0$? 그렇다

**답**: $u = 0.2$ 이면 **1번** 칸, $u = 0.62$ 이면 **3번** 칸. 3번 칸의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 0.5라 구간 $(0.5, 1.0]$ 전체가 3번에 대응한다.

</details>

### 문제 7

[회귀](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#regression-classification-%ED%9A%8C%EA%B7%80%EC%99%80-%EB%B6%84%EB%A5%98) 모델이 평균 $\mu = 2.2$, 표준편차 1인 [정규분포](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#normal-distribution-%EC%A0%95%EA%B7%9C%EB%B6%84%ED%8F%AC)로 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)을 예측한다. [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)이 $y = 3$일 때 음의 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8) 밀도 $-\ln \mathcal{N}(y; \mu, 1)$을 구하라. (공식: $-\ln \mathcal{N}(y; \mu, 1) = \tfrac{1}{2}(y - \mu)^2 + \tfrac{1}{2}\ln 2\pi$, 두 번째 항은 0.9189)

<details><summary>풀이와 답</summary>

**주어진 값**
- $y = 3$ ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5))
- $\mu = 2.2$ (모델의 예측 평균)
- $\tfrac{1}{2}\ln 2\pi = 0.9189$ (상수)

**풀이**
1. 식을 그대로 쓴다: $-\ln \mathcal{N}(y; \mu, 1) = \tfrac{1}{2}(y - \mu)^2 + \tfrac{1}{2}\ln 2\pi$
2. 값을 대입한다: $-\ln \mathcal{N}(3; 2.2, 1) = \tfrac{1}{2}(3 - 2.2)^2 + 0.9189$
3. 괄호 안을 뺀다: $3 - 2.2 = 0.8$
4. 제곱한다: $0.8^2 = 0.64$
5. 절반을 취한다: $0.5 \times 0.64 = 0.32$
6. 더한다: $0.32 + 0.9189 = 1.2389$

**답**: $1.2389$. 상수 0.9189를 빼면 제곱 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $0.64$의 절반이다. 그래서 제곱 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)를 줄이는 것은 이 [정규분포](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#normal-distribution-%EC%A0%95%EA%B7%9C%EB%B6%84%ED%8F%AC)에서 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)의 밀도를 높이는 것과 같다.

</details>

### 문제 8

$\mathcal{N}(0, \sigma^2)$의 $\sigma = 0.05$일 때 꼭대기($x = 0$) 밀도를 구하라. 밀도가 1보다 큰데 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 1을 넘지 않는 이유도 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mu = 0$, $x = 0$ (꼭대기)
- $\sigma = 0.05$ (표준편차), $\sigma^2 = 0.0025$

**풀이**
1. 식을 그대로 쓴다: $\mathcal{N}(x; \mu, \sigma^2) = \dfrac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left(-\dfrac{(x - \mu)^2}{2\sigma^2}\right)$
2. 값을 대입한다: $\mathcal{N}(0; 0, 0.05^2) = \dfrac{1}{\sqrt{2\pi \times 0.0025}} \exp\!\left(-\dfrac{(0 - 0)^2}{2 \times 0.0025}\right)$
3. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98) 안을 계산한다: $(0 - 0)^2 = 0$ 이므로 $-0/0.005 = 0$
4. $\exp$를 계산한다. 0제곱은 1이다: $e^{0} = 1$
5. 루트 안을 곱한다: $2 \times 3.1416 \times 0.0025 = 0.0157$
6. 제곱근을 구한다: $\sqrt{0.0157} = 0.1253$
7. 나눈다: $1 / 0.1253 = 7.9788$ (반올림 전 값으로 계산)
8. 곱한다: $7.9788 \times 1 = 7.9788$

**답**: 꼭대기 밀도 $7.9788$. 밀도는 "한 점의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)"이 아니라 높이이고 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은 구간의 넓이다. 곡선이 아주 좁아서(폭이 0.05 정도) 넓이는 $[-0.05, 0.05]$에서 0.6827이고 전체가 1이다.

</details>

## 강의와 연결

### 문제 9

[Lec14 2.2](../../Lec14_%EC%83%9D%EC%84%B1_%EB%AA%A8%EB%8D%B8_%EA%B8%B0%EC%B4%88.md#22-%ED%99%95%EB%A5%A0-%EB%B3%80%EC%88%98%EC%99%80-%EC%A7%88%EB%9F%89%EB%B0%80%EB%8F%84-%ED%95%A8%EC%88%98)에서 "밀도가 무한대로 갈 수 있는데 어떻게 넓이가 1인가"라는 질문이 나온다. 0과 0.01 사이 균등 분포의 밀도 $p$를 구하고, $[0, 0.005]$에 들어갈 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 값의 범위 $[0, 0.01]$ (폭 0.01)
- 구간 $[0, 0.005]$ ([확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 묻는 범위)

**풀이**
1. 식을 그대로 쓴다: 넓이 $=$ 높이 × 폭 $= 1$
2. 값을 대입한다: $p \times 0.01 = 1$
3. 나눈다: $p = 1 / 0.01 = 100$
4. 질문 구간의 폭: $0.005 - 0 = 0.005$
5. 곱한다: $100 \times 0.005 = 0.5$

**답**: 밀도 $p = 100$, [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) $0.5$. 폭이 좁아질수록 높이는 얼마든지 커질 수 있지만 높이 × 폭(넓이)은 늘 1이다. 폭이 0에 가까우면 밀도는 무한대로 간다.

</details>
