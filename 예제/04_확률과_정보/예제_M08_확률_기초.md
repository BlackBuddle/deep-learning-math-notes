### 문제 1

스팸 [필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0)가 어떤 메일을 보고 "스팸일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 0.3"이라고 했다. 스팸이 아닐 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은 얼마인가? (일어날 수 있는 경우를 전부 더하면 1이라는 규칙을 쓴다.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $p = 0.3$ (모델이 낸 스팸일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))

**풀이**
1. 식을 그대로 쓴다: $p + (\text{스팸 아닐 확률}) = 1$, 곧 $\text{스팸 아닐 확률} = 1 - p$
2. 값을 대입한다: $\text{스팸 아닐 확률} = 1 - 0.3$
3. 뺄셈을 한다: 1 − 0.3 = 0.7 이므로 $\text{스팸 아닐 확률} = 0.7$

**답**: 0.7

</details>

### 문제 2

3등급 [분류](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#regression-classification-%ED%9A%8C%EA%B7%80%EC%99%80-%EB%B6%84%EB%A5%98) 모델의 [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4) 출력이 $[0.6,\ 0.25,\ ?]$이다. 빈칸의 값은 얼마인가? ([소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4) 출력은 모든 칸을 더하면 1이다.)

<details><summary>풀이와 답</summary>

**주어진 값**
- 첫째 칸 0.6, 둘째 칸 0.25 (아는 두 칸)
- $?$ (셋째 칸, 구할 값)

**풀이**
1. 식을 그대로 쓴다: (첫째 칸) + (둘째 칸) + (셋째 칸) = 1
2. 값을 대입한다: $0.6 + 0.25 + ? = 1$
3. 아는 두 칸을 먼저 더한다: 0.6 + 0.25 = 0.85 이므로 $0.85 + ? = 1$
4. 양변에서 0.85를 뺀다: $? = 1 - 0.85$
5. 뺄셈을 한다: 1 − 0.85 = 0.15 이므로 $? = 0.15$
6. 합을 확인한다: 0.6 + 0.25 + 0.15 = 1.0

**답**: 0.15

</details>

### 문제 3

주사위를 두 번 던진다. 두 번 모두 6이 나올 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은 얼마인가? 소수 넷째 자리까지 구하라. (두 번의 결과는 서로 영향이 없으니 각각의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 곱한다: $P(A \text{ 그리고 } B) = P(A) \times P(B)$.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $P(A) = \frac{1}{6}$ (첫 번째에 6이 나올 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0), 주사위 눈 6개 중 하나)
- $P(B) = \frac{1}{6}$ (두 번째에 6이 나올 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))

**풀이**
1. 식을 그대로 쓴다: $P(A \text{ 그리고 } B) = P(A) \times P(B)$
2. 값을 대입한다: $P(A \text{ 그리고 } B) = \frac{1}{6} \times \frac{1}{6}$
3. 분수끼리 곱한다 (분자는 분자끼리, 분모는 분모끼리): 1 × 1 = 1, 6 × 6 = 36 이므로 $P(A \text{ 그리고 } B) = \frac{1}{36}$
4. 나눗셈을 한다: 1 ÷ 36 = 0.02777… 이므로 소수 넷째 자리에서 반올림하면 0.0278

**답**: $\frac{1}{36} \approx 0.0278$

</details>

### 문제 4

[시험 데이터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-data-test-data-%ED%95%99%EC%8A%B5-%EB%8D%B0%EC%9D%B4%ED%84%B0%EC%99%80-%EC%8B%9C%ED%97%98-%EB%8D%B0%EC%9D%B4%ED%84%B0) 200장 중 모델이 170장을 맞혔다. [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84)를 구하고, "새 그림 한 장을 맞힐 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)"로 읽으면 몇 %인지 말하라. ([확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은 맞힌 수를 전체 수로 나눈 비율이다.)

<details><summary>풀이와 답</summary>

**주어진 값**
- 맞힌 수 = 170 (맞힌 그림 장수)
- 전체 수 = 200 ([시험 데이터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-data-test-data-%ED%95%99%EC%8A%B5-%EB%8D%B0%EC%9D%B4%ED%84%B0%EC%99%80-%EC%8B%9C%ED%97%98-%EB%8D%B0%EC%9D%B4%ED%84%B0) 장수)

**풀이**
1. 식을 그대로 쓴다: $\text{정확도} = \frac{\text{맞힌 수}}{\text{전체 수}}$
2. 값을 대입한다: $\text{정확도} = \frac{170}{200}$
3. 나눗셈을 한다: 170 ÷ 200 = 0.85 이므로 $\text{정확도} = 0.85$
4. 퍼센트로 바꾼다 (100을 곱한다): 0.85 × 100 = 85

**답**: [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84) 0.85, 새 그림을 맞힐 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 약 85%

</details>

### 문제 5

[드롭아웃](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dropout-%EB%93%9C%EB%A1%AD%EC%95%84%EC%9B%83) 비율이 0.2이다 (칸마다 따로 20% [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)로 꺼진다). 세 칸이 모두 켜져 있을 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은 얼마인가?

<details><summary>풀이와 답</summary>

**주어진 값**
- 꺼질 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) = 0.2 (칸마다)
- 칸 3개 (서로 따로 꺼지므로 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 곱할 수 있다)

**풀이**
1. 식을 그대로 쓴다: $P(\text{모두 켜짐}) = P(\text{켜짐}) \times P(\text{켜짐}) \times P(\text{켜짐})$, 한 칸이 켜질 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은 $1 - (\text{꺼질 확률})$
2. 값을 대입한다: $P(\text{모두 켜짐}) = (1 - 0.2) \times (1 - 0.2) \times (1 - 0.2)$
3. 괄호를 계산한다 (한 칸이 켜질 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)): 1 − 0.2 = 0.8 이므로 $P(\text{모두 켜짐}) = 0.8 \times 0.8 \times 0.8$
4. 앞의 둘을 곱한다: 0.8 × 0.8 = 0.64 이므로 $P(\text{모두 켜짐}) = 0.64 \times 0.8$
5. 마지막으로 곱한다: 0.64 × 0.8 = 0.512 이므로 $P(\text{모두 켜짐}) = 0.512$

**답**: 0.512

</details>

### 문제 6

같은 [드롭아웃](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dropout-%EB%93%9C%EB%A1%AD%EC%95%84%EC%9B%83)(꺼질 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 0.2)에서 두 칸 중 **첫째 칸만 꺼지고 둘째 칸은 켜져 있을** [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은 얼마인가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $P(\text{첫째 꺼짐}) = 0.2$ (꺼질 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $P(\text{둘째 켜짐}) = 1 - 0.2$ (켜질 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은 1에서 꺼질 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 뺀다)

**풀이**
1. 식을 그대로 쓴다: $P(A \text{ 그리고 } B) = P(A) \times P(B)$ (두 칸은 따로 꺼지므로 곱한다)
2. 값을 대입한다: $P = 0.2 \times (1 - 0.2)$
3. 괄호를 계산한다: 1 − 0.2 = 0.8 이므로 $P = 0.2 \times 0.8$
4. 곱셈을 한다: 0.2 × 0.8 = 0.16 이므로 $P = 0.16$

**답**: 0.16

</details>

### 문제 7

[드롭아웃](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dropout-%EB%93%9C%EB%A1%AD%EC%95%84%EC%9B%83)(꺼질 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 0.2)을 쓰고, 남은 값을 $\frac{1}{1 - 0.2}$배로 키운다. 원래 값이 3일 때 평균([확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) × 값을 더한 것)이 얼마인지 구하라. 이 노트 6절의 식을 쓴다.

<details><summary>풀이와 답</summary>

**주어진 값**
- 꺼질 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) = 0.2
- 원래 값 = 3
- 꺼진 칸의 값 = 0

**풀이**
1. 식을 그대로 쓴다: $\text{평균} = (\text{남을 확률}) \times (\text{원래 값} \times \text{배수}) + (\text{꺼질 확률}) \times 0$, 남을 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은 $1 - (\text{꺼질 확률})$, 배수는 $\frac{1}{1 - (\text{꺼질 확률})}$
2. 값을 대입한다: $\text{평균} = (1 - 0.2) \times \left(3 \times \frac{1}{1 - 0.2}\right) + 0.2 \times 0$
3. 괄호 속 뺄셈을 한다: 1 − 0.2 = 0.8 (두 곳 모두) 이므로 $\text{평균} = 0.8 \times \left(3 \times \frac{1}{0.8}\right) + 0.2 \times 0$
4. 배수를 구한다 (1을 0.8로 나눈다): 1 ÷ 0.8 = 1.25 이므로 $\text{평균} = 0.8 \times (3 \times 1.25) + 0.2 \times 0$
5. 남은 값을 키운다 (원래 값 × 배수): 3 × 1.25 = 3.75 이므로 $\text{평균} = 0.8 \times 3.75 + 0.2 \times 0$
6. 남는 쪽 몫을 구한다: 0.8 × 3.75 = 3 이므로 $\text{평균} = 3 + 0.2 \times 0$
7. 꺼지는 쪽 몫을 구한다: 0.2 × 0 = 0 이므로 $\text{평균} = 3 + 0$
8. 더한다: 3 + 0 = 3

**답**: 평균 = 3 (원래 값 3과 같다)

</details>

### 문제 8

5등급 [분류](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#regression-classification-%ED%9A%8C%EA%B7%80%EC%99%80-%EB%B6%84%EB%A5%98) 모델의 [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4) 출력이 $[0.4,\ 0.2,\ x,\ x,\ 0.1]$이다 (셋째·넷째 칸이 같은 값 $x$). $x$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 0.4, 0.2, 0.1 (아는 세 칸)
- $x$ (같은 값인 두 칸, 구할 값)

**풀이**
1. 식을 그대로 쓴다: (모든 칸의 합) = 1
2. 값을 대입한다: $0.4 + 0.2 + x + x + 0.1 = 1$
3. 아는 칸을 더한다: 0.4 + 0.2 + 0.1 = 0.7 이므로 $0.7 + 2x = 1$
4. 양변에서 0.7을 뺀다: 1 − 0.7 = 0.3 이므로 $2x = 0.3$
5. 양변을 2로 나눈다: 0.3 ÷ 2 = 0.15 이므로 $x = 0.15$
6. 합을 확인한다: 0.4 + 0.2 + 0.15 + 0.15 + 0.1 = 1.0

**답**: $x = 0.15$

</details>

### 문제 9

[Lec09 2.4](../../Lec09_%ED%95%B4%EC%BB%A4%EC%9D%98_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EA%B0%80%EC%9D%B4%EB%93%9C.md#24-%ED%81%B4%EB%9E%98%EC%8A%A4-%EB%B6%88%EA%B7%A0%ED%98%95%EA%B3%BC-%EC%9A%B0%EC%97%B0-%EC%88%98%EC%A4%80)는 데이터의 99%가 양성이면 입력을 보지 않고 "늘 양성"이라고만 답해도 [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84)가 99%라고 알려 준다. 사진 1000장 중 양성이 990장일 때, 늘 양성이라고 답하는 모델의 [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84)를 구하고, [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84) 0.97인 모델이 이 기준보다 나은지 판단하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 전체 수 = 1000 (사진 장수)
- 양성 수 = 990 (늘 "양성"이라고 답하면 이만큼 맞는다)
- 비교할 모델의 [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84) = 0.97

**풀이**
1. 식을 그대로 쓴다: $\text{정확도} = \frac{\text{맞힌 수}}{\text{전체 수}}$ (늘 양성이라고 답하면 맞히는 수는 양성 수와 같다)
2. 값을 대입한다: $\text{정확도} = \frac{990}{1000}$
3. 나눗셈을 한다: 990 ÷ 1000 = 0.99 이므로 기준 [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84)는 0.99
4. 비교한다: 0.97 < 0.99 이므로 [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84) 0.97인 모델은 아무것도 안 보고 찍는 방법보다 못하다.

**답**: 기준 [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84) 0.99. 0.97인 모델은 기준보다 나쁘다 ([정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84)만 보면 속는다)

</details>

### 문제 10

[Lec06 7절](../../Lec06_%EC%9D%BC%EB%B0%98%ED%99%94_%EC%9D%B4%EB%A1%A0.md#7-vc-%EC%9D%B4%EB%A1%A0%EA%B3%BC-%EA%B7%B8-%ED%95%9C%EA%B3%84)의 VC 이론은 [가설 공간](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#hypothesis-space-%EA%B0%80%EC%84%A4-%EA%B3%B5%EA%B0%84)에 서로 다른 함수가 몇 개 있는지 세는 데서 출발한다. 비슷하게, 점 4개에 0 또는 1 라벨을 붙이는 방법은 모두 몇 가지인가? 라벨이 점마다 따로 공정한 동전처럼(0일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 0.5, 1일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 0.5) 정해진다면, 라벨 배치 $(1, 0, 1, 1)$ 하나가 나올 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은 얼마인가?

<details><summary>풀이와 답</summary>

**주어진 값**
- 점 4개 (점마다 라벨이 0 또는 1)
- 라벨마다 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 0.5 (공정한 동전처럼, 점끼리 서로 영향 없음)

**풀이**
1. 경우의 수 식을 쓴다: (경우의 수) = (점 1의 경우 수) × (점 2의 경우 수) × (점 3의 경우 수) × (점 4의 경우 수)
2. 값을 대입한다 (점마다 0 또는 1, 곧 2가지): (경우의 수) = 2 × 2 × 2 × 2
3. 앞의 둘을 곱한다: 2 × 2 = 4 이므로 (경우의 수) = 4 × 2 × 2
4. 이어서 곱한다: 4 × 2 = 8, 8 × 2 = 16 이므로 (경우의 수) = 16
5. [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 식을 쓴다: $P(1, 0, 1, 1) = P(1) \times P(0) \times P(1) \times P(1)$
6. 값을 대입한다: $P(1, 0, 1, 1) = 0.5 \times 0.5 \times 0.5 \times 0.5$
7. 앞의 둘을 곱한다: 0.5 × 0.5 = 0.25 이므로 $P = 0.25 \times 0.5 \times 0.5$
8. 이어서 곱한다: 0.25 × 0.5 = 0.125, 0.125 × 0.5 = 0.0625 이므로 $P = 0.0625$
9. 확인한다: 16가지가 모두 같은 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이면 1 ÷ 16 = 0.0625 로 같다.

**답**: 경우의 수 16가지, [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 0.0625 ($= \frac{1}{16}$)

</details>
