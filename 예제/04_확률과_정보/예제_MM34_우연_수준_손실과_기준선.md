### 문제 1

5개 클래스 [분류](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#regression-classification-%ED%9A%8C%EA%B7%80%EC%99%80-%EB%B6%84%EB%A5%98)에서 모델이 모든 클래스에 같은 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 줄 때 [교차 엔트로피](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cross-entropy-%EA%B5%90%EC%B0%A8-%EC%97%94%ED%8A%B8%EB%A1%9C%ED%94%BC) [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $K = 5$ (클래스 수)
- 각 클래스에 준 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) $\dfrac{1}{K} = 0.2$

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_{\text{chance}} = -\ln \dfrac{1}{K} = \ln K$
2. 값을 대입한다: $\mathcal{L}_{\text{chance}} = -\ln \dfrac{1}{5}$
3. 분수를 계산한다: $1 \div 5 = 0.2$ 이므로 $-\ln 0.2$
4. $\ln$의 뜻: $e$(약 2.718)를 몇 제곱하면 그 수가 되는지다. 계산기의 ln 키로 구하면 $\ln 0.2 = -1.6094$
5. 부호를 바꾼다: $-(-1.6094) = 1.6094$

**답**: $\mathcal{L}_{\text{chance}} = 1.6094$ ($= \ln 5$). [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 1.61 근처에서 내려가지 않으면 모델은 찍고 있는 것이다

</details>

### 문제 2

클래스가 3개이고 각 클래스가 같은 비율로 있는 데이터에서 찍기([우연 수준](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#chance-level-%EC%9A%B0%EC%97%B0-%EC%88%98%EC%A4%80)) [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84)는 얼마인가? 모델의 [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84)가 0.40이면 찍기보다 얼마나 높은가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $K = 3$ (균형 잡힌 클래스 수)
- 모델 [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84) $= 0.40$

**풀이**
1. 식을 그대로 쓴다: [우연 수준](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#chance-level-%EC%9A%B0%EC%97%B0-%EC%88%98%EC%A4%80) [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84) $= \dfrac{1}{K}$ (아무 클래스나 고르면 $K$번 중 한 번 맞는다)
2. 값을 대입한다: $\dfrac{1}{3}$
3. 나눗셈을 한다: $1 \div 3 = 0.3333$
4. 모델과 비교한다: $0.40 - 0.3333 = 0.0667$

**답**: 찍기 [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84)는 $0.3333$이고 모델은 그보다 $0.0667$ 높다. [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84) 0.40만 보고는 잘 배웠다고 말하기 어렵다

</details>

### 문제 3

정상 180개, 이상 20개인 데이터에서 늘 "정상"이라고 답하는 모델의 [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84)와 이상 재현율을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 정상 180개 (모두 맞힘)
- 이상 20개 (하나도 못 맞힘)
- 전체 $200$개

**풀이**
1. 식을 그대로 쓴다: [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84) $= \dfrac{\text{맞힌 수}}{\text{전체 수}}$, 재현율 $= \dfrac{\text{맞힌 이상 수}}{\text{이상 수}}$
2. [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84)에 대입한다: $\dfrac{180 + 0}{200}$
3. 덧셈과 나눗셈을 한다: $180 + 0 = 180$, $180 \div 200 = 0.9$
4. 재현율에 대입한다: $\dfrac{0}{20}$
5. 나눗셈을 한다: $0 \div 20 = 0$

**답**: [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84) $0.9$, 이상 재현율 $0$. [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84)는 높아 보이지만 찾아야 할 이상은 하나도 못 찾는다

</details>

### 문제 4

[회귀](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#regression-classification-%ED%9A%8C%EA%B7%80%EC%99%80-%EB%B6%84%EB%A5%98) [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)이 $(2, 4, 6, 8)$일 때, 늘 평균을 답하는 모델과 늘 0을 답하는 모델의 [MSE](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#mse-mean-squared-error-%ED%8F%89%EA%B7%A0-%EC%A0%9C%EA%B3%B1-%EC%98%A4%EC%B0%A8)를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $t = (2, 4, 6, 8)$ ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)), $N = 4$
- 모델 A: 늘 평균을 답함, 모델 B: 늘 0을 답함

**풀이**
1. 식을 그대로 쓴다: $\text{MSE} = \dfrac{1}{N}\sum_i (t_i - c)^2$ ($c$는 늘 내놓는 값)
2. 평균을 구한다: $(2 + 4 + 6 + 8) \div 4 = 20 \div 4 = 5$ 이므로 모델 A는 $c = 5$
3. 모델 A에 대입한다: $\text{MSE}_A = \dfrac{1}{4}\big((2 - 5)^2 + (4 - 5)^2 + (6 - 5)^2 + (8 - 5)^2\big)$
4. 뺄셈과 제곱을 한다: $(-3)^2 = 9$, $(-1)^2 = 1$, $1^2 = 1$, $3^2 = 9$ 이므로 $\dfrac{1}{4}(9 + 1 + 1 + 9)$
5. 덧셈과 나눗셈을 한다: $9 + 1 + 1 + 9 = 20$, $20 \div 4 = 5$
6. 모델 B에 대입한다 ($c = 0$): $\text{MSE}_B = \dfrac{1}{4}\big(2^2 + 4^2 + 6^2 + 8^2\big)$
7. 제곱을 한다: $4$, $16$, $36$, $64$ 이므로 $\dfrac{1}{4}(4 + 16 + 36 + 64)$
8. 덧셈과 나눗셈을 한다: $4 + 16 + 36 + 64 = 120$, $120 \div 4 = 30$

**답**: $\text{MSE}_A = 5$ ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)과 같다), $\text{MSE}_B = 30$. [회귀](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#regression-classification-%ED%9A%8C%EA%B7%80%EC%99%80-%EB%B6%84%EB%A5%98)의 기준선은 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)이고, 이보다 큰 [MSE](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#mse-mean-squared-error-%ED%8F%89%EA%B7%A0-%EC%A0%9C%EA%B3%B1-%EC%98%A4%EC%B0%A8)는 평균만 답하는 것보다도 못하다

</details>

### 문제 5

정상 90%, 이상 10%인 데이터에서 입력을 보지 않고 비율 $p = 0.9$를 그대로 예측하는 모델의 평균 [교차 엔트로피](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cross-entropy-%EA%B5%90%EC%B0%A8-%EC%97%94%ED%8A%B8%EB%A1%9C%ED%94%BC) [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $H(p)$를 구하고 균등 예측의 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $\ln 2$와 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p = 0.9$ (다수 클래스 비율)
- $1 - p = 0.1$ (소수 클래스 비율)

**풀이**
1. 식을 그대로 쓴다: $H(p) = -\big(p \ln p + (1-p)\ln(1-p)\big)$
2. 값을 대입한다: $H(0.9) = -\big(0.9 \ln 0.9 + 0.1 \ln 0.1\big)$
3. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 구한다 (계산기의 ln 키): $\ln 0.9 = -0.1054$, $\ln 0.1 = -2.3026$ 이므로 $-\big(0.9 \times (-0.1054) + 0.1 \times (-2.3026)\big)$
4. 곱셈을 한다: $0.9 \times (-0.1054) = -0.0948$, $0.1 \times (-2.3026) = -0.2303$ (반올림 전 값으로 곱한다) 이므로 $-\big(-0.0948 + (-0.2303)\big)$
5. 괄호 안을 더한다: $-0.0948 + (-0.2303) = -0.3251$ 이므로 $-(-0.3251)$
6. 부호를 바꾼다: $0.3251$
7. 비교한다: $\ln 2 = 0.6931$ 이므로 $0.3251 < 0.6931$

**답**: $H(0.9) = 0.3251$. 이 데이터의 찍기 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은 균등 예측의 $0.6931$이 아니라 $0.3251$이다. [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 0.4라도 찍기보다 못한 것일 수 있다

</details>

### 문제 6

10개 클래스 [분류](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#regression-classification-%ED%9A%8C%EA%B7%80%EC%99%80-%EB%B6%84%EB%A5%98)에서 (a) [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 $2.50$일 때, (b) [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 $0.40$일 때를 찍기 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)과 비교해 판단하라. (b)에서는 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) 클래스에 준 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)의 대략적인 크기 $e^{-L}$도 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $K = 10$ (클래스 수)
- (a) 관측 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $= 2.50$, (b) 관측 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $= 0.40$

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_{\text{chance}} = \ln K$, [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)의 크기 $p \approx e^{-L}$ ([손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 $-\ln p$이므로)
2. 찍기 수준을 구한다: $\ln 10 = 2.3026$ (계산기의 ln 키)
3. (a) 차이를 구한다: $2.50 - 2.3026 = 0.1974$
4. (a) 부호를 본다: $0.1974 > 0$ 이므로 찍기보다 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 크다
5. (b) 차이를 구한다: $0.40 - 2.3026 = -1.9026$
6. (b) 부호를 본다: $-1.9026 < 0$ 이므로 찍기보다 훨씬 낫다
7. (b) [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)의 크기를 구한다: $e^{-0.40} = 0.6703$ ($e$는 약 2.7183, 코드 `np.exp(-0.4)`)

**답**: (a) 찍기(2.3026)보다 높아 아직 아무것도 배우지 못했거나 버그다. ### 문제 7

8개 클래스의 찍기 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $\ln 8$은 자연로그로 $2.0794$이다. 밑이 2인 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)(비트 단위)로 바꾸면 얼마인가? 클래스가 2개일 때의 찍기 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)도 비트로 구하라. (밑 바꾸기: $\log_2 x = \ln x \div \ln 2$)

<details><summary>풀이와 답</summary>

**풀이**
1. 식을 그대로 쓴다: $\text{비트} = \dfrac{\text{자연로그 값}}{\ln 2}$
2. 값을 대입한다: $\dfrac{2.0794}{0.6931}$

4. 확인한다: $\log_2 8$은 2를 몇 번 곱하면 8인지이고 $2 \times 2 \times 2 = 8$ 이므로 3이다
5. 클래스 2개의 찍기 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 구한다: 자연로그로 $\ln 2 = 0.6931$
6. 비트로 바꾼다: $0.6931 \div 0.6931 = 1$

**답**: $K = 8$의 찍기 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은 $3$비트이고, [이진 분류](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#binary-classification-%EC%9D%B4%EC%A7%84-%EB%B6%84%EB%A5%98)의 찍기 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은 $1$비트다. [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)이 $(0, 2, 2, 4)$일 때 평균을 답하는 기준선의 [MSE](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#mse-mean-squared-error-%ED%8F%89%EA%B7%A0-%EC%A0%9C%EA%B3%B1-%EC%98%A4%EC%B0%A8)(= [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0))를 구하고, [MSE](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#mse-mean-squared-error-%ED%8F%89%EA%B7%A0-%EC%A0%9C%EA%B3%B1-%EC%98%A4%EC%B0%A8)가 $1.5$인 모델과 $2.5$인 모델이 기준선보다 나은지 판단하라. 나은 모델은 기준선 대비 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 몇 배인지도 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $t = (0, 2, 2, 4)$ ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)), $N = 4$
- 모델 P: [MSE](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#mse-mean-squared-error-%ED%8F%89%EA%B7%A0-%EC%A0%9C%EA%B3%B1-%EC%98%A4%EC%B0%A8) $= 1.5$, 모델 Q: [MSE](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#mse-mean-squared-error-%ED%8F%89%EA%B7%A0-%EC%A0%9C%EA%B3%B1-%EC%98%A4%EC%B0%A8) $= 2.5$

**풀이**
1. 식을 그대로 쓴다: 기준선 [MSE](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#mse-mean-squared-error-%ED%8F%89%EA%B7%A0-%EC%A0%9C%EA%B3%B1-%EC%98%A4%EC%B0%A8) $= \dfrac{1}{N}\sum_i (t_i - \bar{t})^2$ ($\bar{t}$는 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)의 평균)
2. 평균을 구한다: $(0 + 2 + 2 + 4) \div 4 = 8 \div 4 = 2$
3. 값을 대입한다: $\dfrac{1}{4}\big((0 - 2)^2 + (2 - 2)^2 + (2 - 2)^2 + (4 - 2)^2\big)$
4. 뺄셈과 제곱을 한다: $(-2)^2 = 4$, $0^2 = 0$, $0^2 = 0$, $2^2 = 4$ 이므로 $\dfrac{1}{4}(4 + 0 + 0 + 4)$
5. 덧셈과 나눗셈을 한다: $4 + 0 + 0 + 4 = 8$, $8 \div 4 = 2$
6. 모델 P를 비교한다: $1.5 < 2$ 이므로 기준선보다 낫다. 비율은 $1.5 \div 2 = 0.75$
7. 모델 Q를 비교한다: $2.5 > 2$ 이므로 기준선보다 못하다

**답**: 기준선 [MSE](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#mse-mean-squared-error-%ED%8F%89%EA%B7%A0-%EC%A0%9C%EA%B3%B1-%EC%98%A4%EC%B0%A8)는 $2$이다. 모델 P는 기준선의 $0.75$배로 낫고, 모델 Q는 평균만 답하는 것보다도 못하다

</details>

### 문제 11

[Lec17 11.2](../../Lec17_%EB%B6%84%ED%8F%AC_%EB%B0%96_%EC%9D%BC%EB%B0%98%ED%99%94.md#112-%EC%86%8C%EC%88%98-%EA%B7%B8%EB%A3%B9%EA%B3%BC-%ED%81%B4%EB%9E%98%EC%8A%A4-%EB%B6%88%EA%B7%A0%ED%98%95)의 소수 그룹 문제를 숫자로 본다. 다수 그룹 950명 중 940명, 소수 그룹 50명 중 10명을 맞힌 모델의 전체 평균 [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84), 그룹별 [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84), 최악 그룹 [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84)를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 다수 그룹 $950$명 중 $940$명 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)
- 소수 그룹 $50$명 중 $10$명 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)
- 전체 $950 + 50 = 1000$명

**풀이**
1. 식을 그대로 쓴다: [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84) $= \dfrac{\text{맞힌 수}}{\text{전체 수}}$
2. 전체 평균에 대입한다: $\dfrac{940 + 10}{1000}$
3. 덧셈과 나눗셈을 한다: $940 + 10 = 950$, $950 \div 1000 = 0.95$
4. 다수 그룹에 대입한다: $\dfrac{940}{950} = 0.9895$
5. 소수 그룹에 대입한다: $\dfrac{10}{50} = 0.2$
6. 최악 그룹을 고른다: $\min(0.9895,\ 0.2) = 0.2$ (가장 작은 값)

**답**: 전체 평균 [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84) $0.95$, 다수 그룹 $0.9895$, 소수 그룹 $0.2$이므로 최악 그룹 [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84)는 $0.2$다. 평균 $0.95$가 소수 그룹의 실패를 가린다

</details>
