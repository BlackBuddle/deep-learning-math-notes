# 예제: 순환 일관성 손실

개념 노트: [MM60_순환_일관성_손실](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/11_%EC%83%9D%EC%84%B1_%EB%AA%A8%EB%8D%B8/MM60_%EC%88%9C%ED%99%98_%EC%9D%BC%EA%B4%80%EC%84%B1_%EC%86%90%EC%8B%A4.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 쓰는 식은 $\mathcal{L}_{\text{cyc}} = \mathbb{E}_x|F(G(x)) - x| + \mathbb{E}_y|G(F(y)) - y|$이다. $G$는 도메인 $X$에서 $Y$로, $F$는 $Y$에서 $X$로 가는 변환이다. 앞의 항을 정방향 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8), 뒤의 항을 역방향 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)라 부르고 각각 데이터에 대한 평균을 낸다.

## 기본 (직접 대입)

### 문제 1

$G(x) = 2x$, $F(y) = y/2 + 1$이다. $x = 3$에서 정방향 순환 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $|F(G(x)) - x|$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x = 3$ (도메인 $X$의 값)
- $G(x) = 2x$ (정방향), $F(y) = y/2 + 1$ (역방향)

**풀이**
1. 식을 그대로 쓴다: $e(x) = |F(G(x)) - x|$
2. 값을 대입한다: $e(3) = |F(G(3)) - 3|$
3. 정방향을 계산한다: $G(3) = 2 \times 3 = 6$ 이므로 $e(3) = |F(6) - 3|$
4. 역방향을 계산한다: $F(6) = 6/2 + 1 = 3 + 1 = 4$ 이므로 $e(3) = |4 - 3|$
5. 뺀 뒤 절댓값을 취한다: $|4 - 3| = 1$

**답**: **1**. 왕복하면 제자리(3)가 아니라 4가 되어 1만큼 어긋난다

</details>

### 문제 2

$G(x) = x + 2$이고 $x = 5$이다. 역방향 후보 $F_1(y) = y - 2$와 $F_2(y) = y - 1$의 정방향 순환 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)를 각각 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x = 5$, $G(x) = x + 2$
- $F_1(y) = y - 2$, $F_2(y) = y - 1$ (역방향 두 후보)

**풀이**
1. 식을 그대로 쓴다: $e(x) = |F(G(x)) - x|$
2. 정방향을 계산한다: $G(5) = 5 + 2 = 7$
3. 값을 대입한다 ($F_1$): $e = |F_1(7) - 5|$
4. 되돌린다: $F_1(7) = 7 - 2 = 5$ 이므로 $e = |5 - 5| = 0$
5. 값을 대입한다 ($F_2$): $e = |F_2(7) - 5|$
6. 되돌린다: $F_2(7) = 7 - 1 = 6$ 이므로 $e = |6 - 5| = 1$

**답**: $F_1$은 **0**, $F_2$는 **1**. $F_1$이 $G$의 정확한 역함수다

</details>

### 문제 3

$X = \{0, 1, 2\}$, $Y = \{1, 2, 3\}$, $G(x) = x + 1$, $F(y) = y$이다. [순환 일관성](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cycle-consistency-%EC%88%9C%ED%99%98-%EC%9D%BC%EA%B4%80%EC%84%B1) [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $\mathcal{L}_{\text{cyc}}$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x \in \{0, 1, 2\}$, $y \in \{1, 2, 3\}$ (두 도메인 데이터 3개씩)
- $G(x) = x + 1$ (정방향), $F(y) = y$ (역방향, 아무것도 안 바꿈)

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_{\text{cyc}} = \mathbb{E}_x|F(G(x)) - x| + \mathbb{E}_y|G(F(y)) - y|$
2. 값을 대입한다: $\mathcal{L}_{\text{cyc}} = \frac{1}{3}\sum_{x \in \{0,1,2\}} |(x + 1) - x| + \frac{1}{3}\sum_{y \in \{1,2,3\}} |(y + 1) - y|$
3. 정방향을 하나씩 계산한다 ($x = 0$): $G(0) = 1$, $F(1) = 1$, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $|1 - 0| = 1$
4. $x = 1$: $G(1) = 2$, $F(2) = 2$, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $|2 - 1| = 1$
5. $x = 2$: $G(2) = 3$, $F(3) = 3$, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $|3 - 2| = 1$
6. 정방향 평균을 낸다: $(1 + 1 + 1) / 3 = 1$
7. 역방향을 하나씩 계산한다 ($y = 1$): $F(1) = 1$, $G(1) = 2$, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $|2 - 1| = 1$
8. $y = 2$: $F(2) = 2$, $G(2) = 3$, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $|3 - 2| = 1$
9. $y = 3$: $F(3) = 3$, $G(3) = 4$, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $|4 - 3| = 1$
10. 역방향 평균을 낸다: $(1 + 1 + 1) / 3 = 1$
11. 두 방향을 더한다: $1 + 1 = 2$

**답**: **2**. $F$가 $G$의 "+1"을 되돌리지 못해서 양쪽 모두 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 1이다

</details>

### 문제 4

문제 3의 $\mathcal{L}_{\text{cyc}}$에 $\lambda = 10$을 곱한 순환 항을 구하라. $F(y) = y - 1$로 고치면 순환 항은 얼마가 되는가? ($Y$는 그대로, $G(F(y)) = (y - 1) + 1 = y$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathcal{L}_{\text{cyc}} = 2$ (문제 3의 값)
- $\lambda = 10$ (순환 항의 무게)
- 고친 역방향 $F(y) = y - 1$

**풀이**
1. 식을 그대로 쓴다: 순환 항 $= \lambda\,\mathcal{L}_{\text{cyc}}$
2. 값을 대입한다: $10 \times 2$
3. 곱한다: $10 \times 2 = 20$
4. 고친 $F$의 정방향을 계산한다: $F(G(x)) = F(x + 1) = (x + 1) - 1 = x$ 이므로 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $|x - x| = 0$
5. 고친 $F$의 역방향을 계산한다: $G(F(y)) = (y - 1) + 1 = y$ 이므로 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $|y - y| = 0$
6. 순환 항을 구한다: $10 \times (0 + 0) = 0$

**답**: 처음 **20**, 고친 뒤 **0**. 정확한 역함수면 순환 항이 사라진다

</details>

### 문제 5

$X = \{0, 1, 2\}$, $Y = \{1, 3, 5\}$, $G(x) = 2x + 1$, $F(y) = 0.5y - 0.25$이다. $\mathcal{L}_{\text{cyc}}$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x \in \{0, 1, 2\}$, $y \in \{1, 3, 5\}$
- $G(x) = 2x + 1$, $F(y) = 0.5y - 0.25$

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_{\text{cyc}} = \mathbb{E}_x|F(G(x)) - x| + \mathbb{E}_y|G(F(y)) - y|$
2. 값을 대입한다: $\mathcal{L}_{\text{cyc}} = \frac{1}{3}\sum_{x} |0.5(2x + 1) - 0.25 - x| + \frac{1}{3}\sum_{y} |2(0.5y - 0.25) + 1 - y|$
3. 정방향 $x = 0$: $G(0) = 1$, $F(1) = 0.5 - 0.25 = 0.25$, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $|0.25 - 0| = 0.25$
4. $x = 1$: $G(1) = 3$, $F(3) = 1.5 - 0.25 = 1.25$, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $|1.25 - 1| = 0.25$
5. $x = 2$: $G(2) = 5$, $F(5) = 2.5 - 0.25 = 2.25$, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $|2.25 - 2| = 0.25$
6. 정방향 평균: $(0.25 + 0.25 + 0.25) / 3 = 0.25$
7. 역방향 $y = 1$: $F(1) = 0.25$, $G(0.25) = 2 \times 0.25 + 1 = 1.5$, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $|1.5 - 1| = 0.5$
8. $y = 3$: $F(3) = 1.25$, $G(1.25) = 2.5 + 1 = 3.5$, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $|3.5 - 3| = 0.5$
9. $y = 5$: $F(5) = 2.25$, $G(2.25) = 4.5 + 1 = 5.5$, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $|5.5 - 5| = 0.5$
10. 역방향 평균: $(0.5 + 0.5 + 0.5) / 3 = 0.5$
11. 두 방향을 더한다: $0.25 + 0.5 = 0.75$

**답**: **0.75**. 정확한 역함수는 $F(y) = 0.5y - 0.5$이고, 상수가 0.25만큼 모자라 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)가 남는다

</details>

### 문제 6

$X = Y = \{0, 1, 2\}$이다. 대응 A: $G(x) = x$, $F(y) = y$. 대응 B: $G'(x) = 2 - x$, $F'(y) = 2 - y$. 두 대응의 $\mathcal{L}_{\text{cyc}}$를 구하고, B가 $X$의 각 값을 어디로 보내는지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $X = Y = \{0, 1, 2\}$
- A: $G(x) = x$, $F(y) = y$ / B: $G'(x) = 2 - x$, $F'(y) = 2 - y$

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_{\text{cyc}} = \mathbb{E}_x|F(G(x)) - x| + \mathbb{E}_y|G(F(y)) - y|$
2. A를 대입한다: $F(G(x)) = F(x) = x$, $G(F(y)) = G(y) = y$
3. A의 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8): $|x - x| = 0$, $|y - y| = 0$ 이므로 $\mathcal{L}_{\text{cyc}} = 0 + 0 = 0$
4. B의 정방향을 대입한다: $F'(G'(x)) = 2 - (2 - x)$
5. 괄호를 푼다: $2 - 2 + x = x$ 이므로 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $|x - x| = 0$
6. B의 역방향을 대입한다: $G'(F'(y)) = 2 - (2 - y) = y$ 이므로 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $0$
7. B의 순환 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98): $0 + 0 = 0$
8. B가 보내는 곳: $G'(0) = 2$, $G'(1) = 1$, $G'(2) = 0$

**답**: A도 B도 $\mathcal{L}_{\text{cyc}} = $ **0**. B는 $0 \to 2$, $1 \to 1$, $2 \to 0$으로 순서를 뒤집는다. 순환 손실만으로는 두 대응을 구별하지 못한다

</details>

### 문제 7

$X = \{0, 1, 2\}$, $Y = \{4, 5, 6\}$이고 $G$와 $F$가 모두 항등 함수($G(x) = x$, $F(y) = y$)이다. $\mathcal{L}_{\text{cyc}}$를 구하고, $G$의 출력이 도메인 $Y$에 속하는지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $X = \{0, 1, 2\}$, $Y = \{4, 5, 6\}$
- $G(x) = x$, $F(y) = y$ (아무것도 안 바꿈)

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_{\text{cyc}} = \mathbb{E}_x|F(G(x)) - x| + \mathbb{E}_y|G(F(y)) - y|$
2. 값을 대입한다: $F(G(x)) = F(x) = x$, $G(F(y)) = G(y) = y$
3. [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)를 구한다: $|x - x| = 0$, $|y - y| = 0$
4. 더한다: $0 + 0 = 0$
5. 출력을 확인한다: $G(0), G(1), G(2) = 0, 1, 2$ 이고 $\{0, 1, 2\} \ne \{4, 5, 6\}$

**답**: $\mathcal{L}_{\text{cyc}} = $ **0**이지만 출력 $\{0, 1, 2\}$는 $Y$가 아니다. 순환 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은 "입력과 엮였는지"만 보므로, "$Y$답게 보이는지"를 보는 판별자 항이 따로 필요하다

</details>

### 문제 8

$X = \{1, 2, 3\}$, $Y = \{2, 4, 6\}$, $G(x) = 2x$, $F(y) = 0.4y$이다. $\mathcal{L}_{\text{cyc}}$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x \in \{1, 2, 3\}$, $y \in \{2, 4, 6\}$
- $G(x) = 2x$, $F(y) = 0.4y$

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_{\text{cyc}} = \mathbb{E}_x|F(G(x)) - x| + \mathbb{E}_y|G(F(y)) - y|$
2. 값을 대입한다: $\mathcal{L}_{\text{cyc}} = \frac{1}{3}\sum_{x} |0.4(2x) - x| + \frac{1}{3}\sum_{y} |2(0.4y) - y|$
3. 정방향 $x = 1$: $G(1) = 2$, $F(2) = 0.8$, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $|0.8 - 1| = 0.2$
4. $x = 2$: $G(2) = 4$, $F(4) = 1.6$, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $|1.6 - 2| = 0.4$
5. $x = 3$: $G(3) = 6$, $F(6) = 2.4$, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $|2.4 - 3| = 0.6$
6. 정방향 평균: $(0.2 + 0.4 + 0.6) / 3 = 1.2 / 3 = 0.4$
7. 역방향 $y = 2$: $F(2) = 0.8$, $G(0.8) = 1.6$, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $|1.6 - 2| = 0.4$
8. $y = 4$: $F(4) = 1.6$, $G(1.6) = 3.2$, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $|3.2 - 4| = 0.8$
9. $y = 6$: $F(6) = 2.4$, $G(2.4) = 4.8$, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $|4.8 - 6| = 1.2$
10. 역방향 평균: $(0.4 + 0.8 + 1.2) / 3 = 2.4 / 3 = 0.8$
11. 두 방향을 더한다: $0.4 + 0.8 = 1.2$

**답**: **1.2**. 정확한 역함수는 $F(y) = 0.5y$이고, $0.4$배라 왕복하면 $0.8$배로 줄어든다. 값이 클수록 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)도 커진다

</details>

## 강의와 연결

### 문제 9

([Lec16 9.3](../../Lec16_%EC%A1%B0%EA%B1%B4%EB%B6%80_%EC%83%9D%EC%84%B1_%EB%AA%A8%EB%8D%B8.md#93-%EC%88%9C%ED%99%98-%EC%9D%BC%EA%B4%80%EC%84%B1)) CycleGAN의 전체 목적은 $\mathcal{L}_{\text{GAN}}(G, D_Y) + \mathcal{L}_{\text{GAN}}(F, D_X) + \lambda\,\mathcal{L}_{\text{cyc}}$이다. $\mathcal{L}_{\text{GAN}}(G, D_Y) = -0.7$, $\mathcal{L}_{\text{GAN}}(F, D_X) = -0.8$, $\mathcal{L}_{\text{cyc}} = 0.2$, $\lambda = 10$일 때 전체 값을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathcal{L}_{\text{GAN}}(G, D_Y) = -0.7$ (사진 → 그림 쪽 [GAN](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gan-generative-adversarial-network-%EC%83%9D%EC%84%B1%EC%A0%81-%EC%A0%81%EB%8C%80-%EC%8B%A0%EA%B2%BD%EB%A7%9D) 항)
- $\mathcal{L}_{\text{GAN}}(F, D_X) = -0.8$ (그림 → 사진 쪽 [GAN](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gan-generative-adversarial-network-%EC%83%9D%EC%84%B1%EC%A0%81-%EC%A0%81%EB%8C%80-%EC%8B%A0%EA%B2%BD%EB%A7%9D) 항)
- $\mathcal{L}_{\text{cyc}} = 0.2$, $\lambda = 10$ (CycleGAN 논문의 값)

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L} = \mathcal{L}_{\text{GAN}}(G, D_Y) + \mathcal{L}_{\text{GAN}}(F, D_X) + \lambda\,\mathcal{L}_{\text{cyc}}$
2. 값을 대입한다: $\mathcal{L} = -0.7 + (-0.8) + 10 \times 0.2$
3. 곱셈을 먼저 한다: $10 \times 0.2 = 2$ 이므로 $\mathcal{L} = -0.7 + (-0.8) + 2$
4. 앞의 둘을 더한다: $-0.7 + (-0.8) = -1.5$
5. 더한다: $-1.5 + 2 = 0.5$

**답**: **0.5**. 순환 항이 $\lambda$ 때문에 판별자 항보다 크게 반영된다

</details>

### 문제 10

([Lec16 9.4](../../Lec16_%EC%A1%B0%EA%B1%B4%EB%B6%80_%EC%83%9D%EC%84%B1_%EB%AA%A8%EB%8D%B8.md#94-%EC%99%9C-%EC%97%89%EB%9A%B1%ED%95%9C-%EB%8C%80%EC%9D%91%EC%9D%84-%EC%B0%BE%EC%A7%80-%EC%95%8A%EB%82%98)) $X = \{0, 1, 2\}$, $Y = \{0, 10, 20\}$이다. 대응 A: $G(x) = 10x$, $F(y) = y/10$. 대응 B: $G'(x) = 20 - 10x$, $F'(y) = (20 - y)/10$. 두 대응의 $\mathcal{L}_{\text{cyc}}$를 구하고, 출력 집합이 $Y$와 같은지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $X = \{0, 1, 2\}$, $Y = \{0, 10, 20\}$
- A: $G(x) = 10x$, $F(y) = y/10$ / B: $G'(x) = 20 - 10x$, $F'(y) = (20 - y)/10$

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_{\text{cyc}} = \mathbb{E}_x|F(G(x)) - x| + \mathbb{E}_y|G(F(y)) - y|$
2. A의 정방향을 대입한다: $F(G(x)) = 10x / 10 = x$ 이므로 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $|x - x| = 0$
3. A의 역방향을 대입한다: $G(F(y)) = 10 \times (y / 10) = y$ 이므로 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $|y - y| = 0$
4. A의 순환 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98): $0 + 0 = 0$
5. B의 정방향을 대입한다: $F'(G'(x)) = \big(20 - (20 - 10x)\big)/10$
6. 괄호를 푼다: $20 - 20 + 10x = 10x$, $10x / 10 = x$ 이므로 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $0$
7. B의 역방향을 대입한다: $G'(F'(y)) = 20 - 10 \times \dfrac{20 - y}{10} = 20 - (20 - y) = y$ 이므로 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $0$
8. B의 순환 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98): $0 + 0 = 0$
9. 출력 집합을 확인한다: A는 $G(0), G(1), G(2) = 0, 10, 20$, B는 $G'(0), G'(1), G'(2) = 20, 10, 0$

**답**: 둘 다 $\mathcal{L}_{\text{cyc}} = $ **0**이고 출력 집합이 $\{0, 10, 20\} = Y$로 같다. 판별자도 순환 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)도 A와 B를 구별하지 못한다. 어느 쪽을 찾을지는 신경망이 단순한 함수(A)를 더 쉽게 배우는 성질에 달렸다

</details>
