# 예제: 조건부 GAN 목적 함수

개념 노트: [MM59_조건부_GAN_목적_함수](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/11_%EC%83%9D%EC%84%B1_%EB%AA%A8%EB%8D%B8/MM59_%EC%A1%B0%EA%B1%B4%EB%B6%80_GAN_%EB%AA%A9%EC%A0%81_%ED%95%A8%EC%88%98.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 판별자 $d$는 "이 쌍이 가짜일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)"을 낸다(강의의 약속). 판별자의 점수는 $V = \ln d(\text{가짜 쌍}) + \ln(1 - d(\text{진짜 쌍}))$이고 판별자는 키우고 생성자는 줄인다. $\ln a$는 $e$(약 2.718)를 몇 제곱해야 $a$가 되는지를 뜻하며, 1보다 작은 수의 $\ln$은 음수이다. L1 항은 픽셀별 절댓값 차이의 평균이다.

## 기본 (직접 대입)

### 문제 1

판별자가 가짜 쌍에 0.9, 진짜 쌍에 0.4의 "가짜 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)"을 주었다. 이 한 쌍씩에 대한 판별자의 점수 $V$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $d(\text{가짜 쌍}) = 0.9$ (가짜 쌍을 가짜라고 볼 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $d(\text{진짜 쌍}) = 0.4$ (진짜 쌍을 가짜라고 볼 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))

**풀이**
1. 식을 그대로 쓴다: $V = \ln d(\text{가짜 쌍}) + \ln\big(1 - d(\text{진짜 쌍})\big)$
2. 값을 대입한다: $V = \ln 0.9 + \ln(1 - 0.4)$
3. 괄호 안 뺄셈을 한다: $1 - 0.4 = 0.6$ 이므로 $V = \ln 0.9 + \ln 0.6$
4. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 계산한다: $\ln 0.9 = -0.1054$, $\ln 0.6 = -0.5108$
5. 더한다: $-0.1054 + (-0.5108) = -0.6162$

**답**: $V = $ **-0.6162**. 균형값 $2\ln 0.5 = -1.3863$보다 크다. 판별자가 아직 잘 가려내고 있다

</details>

### 문제 2

판별자가 완전히 반대로 판단해서 가짜 쌍에 0.1, 진짜 쌍에 0.9를 주었다. 점수 $V$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $d(\text{가짜 쌍}) = 0.1$ (가짜를 진짜로 착각)
- $d(\text{진짜 쌍}) = 0.9$ (진짜를 가짜로 착각)

**풀이**
1. 식을 그대로 쓴다: $V = \ln d(\text{가짜 쌍}) + \ln\big(1 - d(\text{진짜 쌍})\big)$
2. 값을 대입한다: $V = \ln 0.1 + \ln(1 - 0.9)$
3. 괄호 안 뺄셈을 한다: $1 - 0.9 = 0.1$ 이므로 $V = \ln 0.1 + \ln 0.1$
4. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 계산한다: $\ln 0.1 = -2.3026$
5. 더한다: $-2.3026 + (-2.3026) = -4.6052$

**답**: $V = $ **-4.6052**. 판별자에게 가장 나쁜 점수다. 판별자는 이 값을 키우려고 배운다

</details>

### 문제 3

생성자의 출력이 픽셀 4개에서 $(0.4, 0.1, 0.7, 0.8)$이고 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)은 $(0.5, 0.1, 0.4, 0.8)$이다. L1 항(픽셀 평균)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $g(\mathbf{x}) = (0.4, 0.1, 0.7, 0.8)$ (생성 출력)
- $\mathbf{y} = (0.5, 0.1, 0.4, 0.8)$ ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5))

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_{L1} = \dfrac{1}{n}\sum_{i=1}^{n} |y_i - g_i|$
2. 값을 대입한다: $\mathcal{L}_{L1} = \dfrac{1}{4}\big(|0.5 - 0.4| + |0.1 - 0.1| + |0.4 - 0.7| + |0.8 - 0.8|\big)$
3. 칸별로 뺀다: $0.1,\ 0,\ -0.3,\ 0$
4. 절댓값을 취한다 (부호를 없앰): $0.1,\ 0,\ 0.3,\ 0$
5. 더한다: $0.1 + 0 + 0.3 + 0 = 0.4$
6. 픽셀 수 4로 나눈다: $0.4 / 4 = 0.1$

**답**: **0.1**

</details>

### 문제 4

어떤 쌍이 진짜 데이터에서 나올 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 $p_{\text{data}} = 0.2$, 생성자에서 나올 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 $p_g = 0.6$이다. 최적 판별자 $d^*$는 이 쌍에 "가짜 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)"을 얼마로 주는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $p_{\text{data}} = 0.2$ (진짜 데이터에서 이 쌍이 나올 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $p_g = 0.6$ (생성자에서 이 쌍이 나올 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))

**풀이** (두 출처 중 "가짜 쪽에서 왔을" [조건부 확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#conditional-probability-%EC%A1%B0%EA%B1%B4%EB%B6%80-%ED%99%95%EB%A5%A0)이다)
1. 식을 그대로 쓴다: $d^* = \dfrac{p_g}{p_g + p_{\text{data}}}$
2. 값을 대입한다: $d^* = \dfrac{0.6}{0.6 + 0.2}$
3. 분모를 더한다: $0.6 + 0.2 = 0.8$
4. 나눗셈을 한다: $0.6 \div 0.8 = 0.75$

**답**: **0.75**. 이 쌍은 생성자가 데이터보다 3배 자주 만드는 쌍이라 가짜로 의심받는다

</details>

### 문제 5

생성자가 줄이려는 전체 값은 (판별자 항 $\ln d(\text{가짜 쌍})$) + $\lambda\,\mathcal{L}_{L1}$이다. $d(\text{가짜 쌍}) = 0.5$, $\mathcal{L}_{L1} = 0.1$(문제 3의 값), $\lambda = 10$일 때 이 값을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $d(\text{가짜 쌍}) = 0.5$ (판별자가 낸 값)
- $\mathcal{L}_{L1} = 0.1$ (L1 항)
- $\lambda = 10$ (L1 항의 무게)

**풀이**
1. 식을 그대로 쓴다: $\ln d(\text{가짜 쌍}) + \lambda\,\mathcal{L}_{L1}$
2. 값을 대입한다: $\ln 0.5 + 10 \times 0.1$
3. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 계산한다: $\ln 0.5 = -0.6931$
4. 곱셈을 한다: $10 \times 0.1 = 1$
5. 더한다: $-0.6931 + 1 = 0.3069$

**답**: **0.3069**

</details>

### 문제 6

생성자가 좋아져서 판별자가 가짜 쌍에 주는 "가짜 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)"이 0.9에서 0.6으로 내려갔다. 생성자가 줄이려는 항 $\ln d(\text{가짜 쌍})$은 얼마나 변했는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $d$: 전 $0.9$, 후 $0.6$ (가짜 쌍에 준 가짜 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))

**풀이**
1. 식을 그대로 쓴다: 변화 $= \ln d_{\text{후}} - \ln d_{\text{전}}$
2. 값을 대입한다: 변화 $= \ln 0.6 - \ln 0.9$
3. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 계산한다: $\ln 0.6 = -0.5108$, $\ln 0.9 = -0.1054$
4. 뺀다: $-0.5108 - (-0.1054) = -0.5108 + 0.1054 = -0.4055$ (반올림 전 값)

**답**: **-0.4055**. 생성자가 줄이려는 값이 작아졌으니 생성자가 이기고 있다

</details>

### 문제 7

[패치 판별자](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#patchgan-%ED%8C%A8%EC%B9%98-%ED%8C%90%EB%B3%84%EC%9E%90)가 패치 3개에 $d = (0.5, 0.8, 0.2)$를 주었다. 패치마다 $\ln d$를 구하고 평균을 내라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $d_1 = 0.5$, $d_2 = 0.8$, $d_3 = 0.2$ (패치별 가짜 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- 패치 수 3

**풀이**
1. 식을 그대로 쓴다: 평균 $= \dfrac{1}{3}\sum_{j=1}^{3}\ln d_j$
2. 값을 대입한다: $\dfrac{1}{3}\big(\ln 0.5 + \ln 0.8 + \ln 0.2\big)$
3. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 계산한다: $\ln 0.5 = -0.6931$, $\ln 0.8 = -0.2231$, $\ln 0.2 = -1.6094$
4. 더한다: $-0.6931 + (-0.2231) = -0.9162$, $-0.9162 + (-1.6094) = -2.5256$
5. 3으로 나눈다: $-2.5256 / 3 = -0.8419$

**답**: **-0.8419**. 패치마다 따로 판단한 값을 평균해서 한 숫자로 만든다

</details>

### 문제 8

생성자 후보 G1, G2와 판별자 후보 D1, D2가 있고 $\mathcal{L}_{\text{cGAN}}$ 값이 아래 표와 같다. $\arg\min_\theta \max_\phi$로 어느 생성자를 고르는가?

| | D1 | D2 |
|---|---|---|
| G1 | -0.6 | -1.0 |
| G2 | -0.9 | -0.7 |

<details><summary>풀이와 답</summary>

**주어진 값**
- G1: D1이면 $-0.6$, D2이면 $-1.0$
- G2: D1이면 $-0.9$, D2이면 $-0.7$

**풀이** (먼저 각 생성자에 대해 가장 좋은 판별자를 찾고, 그 값이 가장 작은 생성자를 고른다)
1. 식을 그대로 쓴다: $g^* = \arg\min_\theta \max_\phi \mathcal{L}_{\text{cGAN}}(\theta, \phi)$
2. G1에 대해 판별자가 고른 값: $\max(-0.6,\ -1.0) = -0.6$ (D1)
3. G2에 대해 판별자가 고른 값: $\max(-0.9,\ -0.7) = -0.7$ (D2)
4. 그 값이 가장 작은 생성자를 고른다: $\min(-0.6,\ -0.7) = -0.7$ (G2)

**답**: **G2**. 아무 판별자가 아니라 가장 좋은 판별자를 상대로 가장 덜 들키는 생성자를 고른다. G2는 D1에는 더 잘 속이지만 D2에는 덜 속이는데, 판별자가 D2를 고르면 $-0.7$이다

</details>

### 문제 9

([Lec16 4.3](../../Lec16_%EC%A1%B0%EA%B1%B4%EB%B6%80_%EC%83%9D%EC%84%B1_%EB%AA%A8%EB%8D%B8.md#43-l1-%EC%86%90%EC%8B%A4-%EB%8D%94%ED%95%98%EA%B8%B0)) 생성자가 픽셀 3개를 $(0.1, 0.7, 0.3)$으로 그렸고 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)은 $(0.3, 0.7, 0.6)$이다. 판별자 항이 $\ln 0.8$이고 $\lambda = 100$일 때 생성자가 줄이려는 전체 값을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $g_\theta(\mathbf{x}) = (0.1, 0.7, 0.3)$ (생성자가 그린 픽셀 값)
- $\mathbf{y} = (0.3, 0.7, 0.6)$ ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) 픽셀 값)
- 판별자 항 $= \ln 0.8$ (생성자가 바꿀 수 있는 부분)
- $\lambda = 100$ (L1 항의 무게)

**풀이**
1. 식을 그대로 쓴다: $\ln d + \lambda\,\|\mathbf{y} - g_\theta(\mathbf{x})\|_1$ (L1은 픽셀 평균)
2. 값을 대입한다: $\ln 0.8 + 100 \times \dfrac{1}{3}\big(|0.3 - 0.1| + |0.7 - 0.7| + |0.6 - 0.3|\big)$
3. 칸별로 뺀다: $0.2,\ 0,\ 0.3$ (이미 양수라 절댓값을 취해도 같다)
4. 더한다: $0.2 + 0 + 0.3 = 0.5$
5. 픽셀 수로 나눈다: $0.5 / 3 = 0.1667$
6. $\lambda$를 곱한다: $100 \times 0.1667 = 16.6667$ (반올림 전 값으로 곱함)
7. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 계산한다: $\ln 0.8 = -0.2231$
8. 더한다: $-0.2231 + 16.6667 = 16.4436$ (반올림 전 값으로는 16.4435)

**답**: 약 **16.4435**. L1 항이 판별자 항보다 훨씬 커서 생성자는 먼저 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) 근처로 끌려간다

</details>

### 문제 10

([Lec16 4.2](../../Lec16_%EC%A1%B0%EA%B1%B4%EB%B6%80_%EC%83%9D%EC%84%B1_%EB%AA%A8%EB%8D%B8.md#42-%ED%8C%90%EB%B3%84%EC%9E%90%EA%B0%80-%EC%9E%85%EB%A0%A5%EA%B3%BC-%EC%B6%9C%EB%A0%A5%EC%9D%84-%ED%95%A8%EA%BB%98-%EB%B3%B8%EB%8B%A4)) 진짜처럼 생겼지만 입력과 맞지 않는 쌍은 가짜 쌍이다. 출력만 보는 판별자는 이 쌍에 $d = 0.2$("진짜 같다")를 주고, 입력도 함께 보는 판별자는 $d = 0.9$("가짜")를 준다. 판별자 점수의 가짜 항 $\ln d$를 각각 구하고 어느 판별자의 점수가 더 높은지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 출력만 보는 판별자: $d = 0.2$
- 입력도 보는 판별자: $d = 0.9$
- 이 쌍은 가짜 쌍 (입력과 맞지 않음)

**풀이** (판별자는 가짜 쌍에 대한 $\ln d$를 키우려 한다. 0에 가까울수록 높다)
1. 식을 그대로 쓴다: 가짜 항 $= \ln d(\text{가짜 쌍})$
2. 값을 대입한다: $\ln 0.2$ 와 $\ln 0.9$
3. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 계산한다: $\ln 0.2 = -1.6094$, $\ln 0.9 = -0.1054$
4. 비교한다: $-0.1054 > -1.6094$
