# 예제: 분류기 없는 가이던스

개념 노트: [MM61_분류기_없는_가이던스](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/11_%EC%83%9D%EC%84%B1_%EB%AA%A8%EB%8D%B8/MM61_%EB%B6%84%EB%A5%98%EA%B8%B0_%EC%97%86%EB%8A%94_%EA%B0%80%EC%9D%B4%EB%8D%98%EC%8A%A4.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 쓰는 식은 둘이다. 섞은 잡음 예측 $\tilde\epsilon = \epsilon_\varnothing + s\,(\epsilon_c - \epsilon_\varnothing)$ ($\epsilon_\varnothing$는 조건 없는 예측, $\epsilon_c$는 조건 있는 예측, $s$는 가이던스 배율)과 점수로 쓴 가이던스 $\nabla_x \ln p(x) + s\,\big(\nabla_x \ln p(x\mid c) - \nabla_x \ln p(x)\big)$이다. 벡터는 칸마다 따로 계산한다.

## 기본 (직접 대입)

### 문제 1

조건 없는 예측이 $(1, 2)$, 조건 있는 예측이 $(3, 1)$이다. $s = 0$과 $s = 1$일 때 섞은 예측을 각각 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\epsilon_\varnothing = (1, 2)$ (조건 없는 예측)
- $\epsilon_c = (3, 1)$ (조건 있는 예측)
- $s = 0$, $s = 1$ (가이던스 배율)

**풀이**
1. 식을 그대로 쓴다: $\tilde\epsilon = \epsilon_\varnothing + s\,(\epsilon_c - \epsilon_\varnothing)$
2. 값을 대입한다: $\tilde\epsilon = (1, 2) + s \times \big((3, 1) - (1, 2)\big)$
3. 괄호 안을 칸별로 뺀다: $(3 - 1,\ 1 - 2) = (2, -1)$
4. $s = 0$을 대입한다: $\tilde\epsilon = (1, 2) + 0 \times (2, -1)$
5. 곱한다: $0 \times (2, -1) = (0, 0)$ 이므로 $\tilde\epsilon = (1, 2) + (0, 0) = (1, 2)$
6. $s = 1$을 대입한다: $\tilde\epsilon = (1, 2) + 1 \times (2, -1)$
7. 칸별로 더한다: $(1 + 2,\ 2 + (-1)) = (3, 1)$

**답**: $s = 0$이면 **(1, 2)**(조건 무시), $s = 1$이면 **(3, 1)**(보통의 조건부 예측)

</details>

### 문제 2

문제 1과 같은 예측에서 $s = 2$일 때 섞은 예측을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\epsilon_\varnothing = (1, 2)$, $\epsilon_c = (3, 1)$
- $s = 2$

**풀이**
1. 식을 그대로 쓴다: $\tilde\epsilon = \epsilon_\varnothing + s\,(\epsilon_c - \epsilon_\varnothing)$
2. 값을 대입한다: $\tilde\epsilon = (1, 2) + 2 \times \big((3, 1) - (1, 2)\big)$
3. 괄호 안을 칸별로 뺀다: $(3 - 1,\ 1 - 2) = (2, -1)$
4. $s$를 칸별로 곱한다: $(2 \times 2,\ 2 \times (-1)) = (4, -2)$
5. 칸별로 더한다: $(1 + 4,\ 2 + (-2)) = (5, 0)$

**답**: **(5, 0)**. 조건 방향 $(2, -1)$으로 보통 조건부 예측 $(3, 1)$보다 한 번 더 나아갔다

</details>

### 문제 3

3차원 예측이다. $\epsilon_\varnothing = (0, 1, 2)$, $\epsilon_c = (1, 1, 0)$이고 $s = 4$이다. 섞은 예측을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\epsilon_\varnothing = (0, 1, 2)$, $\epsilon_c = (1, 1, 0)$
- $s = 4$

**풀이**
1. 식을 그대로 쓴다: $\tilde\epsilon = \epsilon_\varnothing + s\,(\epsilon_c - \epsilon_\varnothing)$
2. 값을 대입한다: $\tilde\epsilon = (0, 1, 2) + 4 \times \big((1, 1, 0) - (0, 1, 2)\big)$
3. 괄호 안을 칸별로 뺀다: $(1 - 0,\ 1 - 1,\ 0 - 2) = (1, 0, -2)$
4. $s$를 칸별로 곱한다: $(4 \times 1,\ 4 \times 0,\ 4 \times (-2)) = (4, 0, -8)$
5. 칸별로 더한다: $(0 + 4,\ 1 + 0,\ 2 + (-8)) = (4, 1, -6)$

**답**: **(4, 1, -6)**. 둘째 칸은 두 예측이 같아서 변하지 않는다

</details>

### 문제 4

1차원에서 비조건 분포는 $\mathcal{N}(0, 1)$, 조건부 분포는 $\mathcal{N}(3, 1)$이다. 위치 $x = 1$에서 $s = 2$의 가이던스 점수를 구하라. (비조건 점수는 $-x$, 조건부 점수는 $-(x - 3)$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $\nabla_x \ln p(x) = -x$ (비조건 점수), $\nabla_x \ln p(x\mid c) = -(x - 3)$ (조건부 점수)
- $x = 1$, $s = 2$

**풀이**
1. 식을 그대로 쓴다: $\nabla_x \ln p(x) + s\,\big(\nabla_x \ln p(x\mid c) - \nabla_x \ln p(x)\big)$
2. 점수를 구한다: 비조건 $-1$, 조건부 $-(1 - 3) = -(-2) = 2$
3. 값을 대입한다: $-1 + 2 \times \big(2 - (-1)\big)$
4. 괄호 안 뺄셈을 한다: $2 - (-1) = 3$
5. 곱셈을 한다: $2 \times 3 = 6$
6. 덧셈을 한다: $-1 + 6 = 5$

**답**: **5**. 보통의 조건부 점수(2)보다 훨씬 세게 조건 쪽(평균 3)으로 끈다

</details>

## 응용

### 문제 5

Ho와 Salimans 논문은 가이던스를 $(1 + w)\,\epsilon_c - w\,\epsilon_\varnothing$로 쓴다. $w = 2$, $\epsilon_\varnothing = (0.2, 0.4)$, $\epsilon_c = (0.5, 0.1)$일 때 값을 구하고, 이 노트의 식에서 $s$가 얼마일 때와 같은지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $w = 2$ (논문의 배율)
- $\epsilon_\varnothing = (0.2, 0.4)$, $\epsilon_c = (0.5, 0.1)$

**풀이**
1. 식을 그대로 쓴다: $(1 + w)\,\epsilon_c - w\,\epsilon_\varnothing$
2. 값을 대입한다: $(1 + 2) \times (0.5, 0.1) - 2 \times (0.2, 0.4)$
3. 괄호를 계산한다: $1 + 2 = 3$
4. 칸별로 곱한다: $3 \times (0.5, 0.1) = (1.5, 0.3)$, $2 \times (0.2, 0.4) = (0.4, 0.8)$
5. 칸별로 뺀다: $(1.5 - 0.4,\ 0.3 - 0.8) = (1.1, -0.5)$
6. 같은 $s$를 찾는다: $s = 1 + w = 1 + 2 = 3$ 이고, 개념 노트의 $s = 3$ 값이 $(1.1, -0.5)$이다

**답**: **(1.1, -0.5)**. $s = 1 + w = $ **3**일 때와 같다. 두 식은 같은 식을 다르게 쓴 것이다

</details>

### 문제 6

$\epsilon_\varnothing = (0.5, 0.3)$, $\epsilon_c = (0.5, 0.7)$이고 $s = 5$이다. 섞은 예측을 구하고, 첫째 칸이 왜 변하지 않는지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\epsilon_\varnothing = (0.5, 0.3)$, $\epsilon_c = (0.5, 0.7)$
- $s = 5$

**풀이**
1. 식을 그대로 쓴다: $\tilde\epsilon = \epsilon_\varnothing + s\,(\epsilon_c - \epsilon_\varnothing)$
2. 값을 대입한다: $\tilde\epsilon = (0.5, 0.3) + 5 \times \big((0.5, 0.7) - (0.5, 0.3)\big)$
3. 괄호 안을 칸별로 뺀다: $(0.5 - 0.5,\ 0.7 - 0.3) = (0, 0.4)$
4. $s$를 칸별로 곱한다: $(5 \times 0,\ 5 \times 0.4) = (0, 2)$
5. 칸별로 더한다: $(0.5 + 0,\ 0.3 + 2) = (0.5, 2.3)$

**답**: **(0.5, 2.3)**. 첫째 칸은 조건이 있든 없든 예측이 같아서 차이가 0이다. 가이던스는 조건이 영향을 주는 칸만 키운다

</details>

### 문제 7

$\epsilon_\varnothing = (0.2, 0.4)$, $\epsilon_c = (0.5, 0.1)$이고 $s = 0.5$이다. 섞은 예측을 구하고, $s < 1$이면 무슨 일이 생기는지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\epsilon_\varnothing = (0.2, 0.4)$, $\epsilon_c = (0.5, 0.1)$
- $s = 0.5$

**풀이**
1. 식을 그대로 쓴다: $\tilde\epsilon = \epsilon_\varnothing + s\,(\epsilon_c - \epsilon_\varnothing)$
2. 값을 대입한다: $\tilde\epsilon = (0.2, 0.4) + 0.5 \times \big((0.5, 0.1) - (0.2, 0.4)\big)$
3. 괄호 안을 칸별로 뺀다: $(0.5 - 0.2,\ 0.1 - 0.4) = (0.3, -0.3)$
4. $s$를 칸별로 곱한다: $(0.5 \times 0.3,\ 0.5 \times (-0.3)) = (0.15, -0.15)$
5. 칸별로 더한다: $(0.2 + 0.15,\ 0.4 + (-0.15)) = (0.35, 0.25)$

**답**: **(0.35, 0.25)**. 조건 없는 예측 $(0.2, 0.4)$와 조건 있는 예측 $(0.5, 0.1)$의 한가운데다. $s < 1$이면 조건을 약하게 반영한다

</details>

### 문제 8

$\epsilon_\varnothing = (0.2, 0.4)$, $\epsilon_c = (0.5, 0.1)$이다. 섞은 예측의 둘째 칸이 정확히 0이 되는 $s$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\epsilon_\varnothing$의 둘째 칸 $0.4$, $\epsilon_c$의 둘째 칸 $0.1$
- 목표: $\tilde\epsilon$의 둘째 칸 $= 0$

**풀이**
1. 둘째 칸만 식으로 쓴다: $\tilde\epsilon_2 = \epsilon_{\varnothing,2} + s\,(\epsilon_{c,2} - \epsilon_{\varnothing,2})$
2. 값을 대입한다: $\tilde\epsilon_2 = 0.4 + s\,(0.1 - 0.4)$
3. 괄호 안을 계산한다: $0.1 - 0.4 = -0.3$ 이므로 $\tilde\epsilon_2 = 0.4 - 0.3\,s$
4. 0과 같다고 놓는다: $0.4 - 0.3\,s = 0$
5. $0.3\,s$를 옮긴다: $0.4 = 0.3\,s$
6. 0.3으로 나눈다: $s = 0.4 / 0.3 = 1.3333$

**답**: $s = $ **1.3333**. $s$를 이보다 키우면 둘째 칸이 음수가 된다

</details>

### 문제 9

([Lec16 8.3](../../Lec16_%EC%A1%B0%EA%B1%B4%EB%B6%80_%EC%83%9D%EC%84%B1_%EB%AA%A8%EB%8D%B8.md#83-%EC%A1%B0%EA%B1%B4%EB%B6%80-%ED%99%95%EC%82%B0-%EB%AA%A8%EB%8D%B8)) 학습할 때 배치 256장 중 10%의 글을 빈 조건 $\varnothing$으로 바꾼다. 한 배치에서 빈 조건으로 학습하는 장수의 [기댓값](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#expectation-%EA%B8%B0%EB%8C%93%EA%B0%92)을 구하라. [샘플링](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sampling-%EC%83%98%ED%94%8C%EB%A7%81)이 50단계이고 매 단계 신경망을 조건 있음·없음으로 두 번 돌린다면 이미지 한 장에 신경망을 몇 번 돌리는가? 가이던스를 안 쓰면?

<details><summary>풀이와 답</summary>

**주어진 값**
- 배치 256장, 조건을 떨어뜨리는 비율 $0.1$
- [샘플링](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sampling-%EC%83%98%ED%94%8C%EB%A7%81) 단계 $T = 50$

**풀이**
1. 식을 그대로 쓴다: [기댓값](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#expectation-%EA%B8%B0%EB%8C%93%EA%B0%92) $= \text{배치 크기} \times \text{비율}$
2. 값을 대입한다: $256 \times 0.1$
3. 곱한다: $256 \times 0.1 = 25.6$
4. 가이던스를 쓸 때의 횟수: $\text{단계 수} \times 2 = 50 \times 2$
5. 곱한다: $50 \times 2 = 100$
6. 가이던스를 안 쓸 때의 횟수: 단계마다 한 번이므로 $50 \times 1 = 50$

**답**: 빈 조건 [기댓값](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#expectation-%EA%B8%B0%EB%8C%93%EA%B0%92) **25.6장**, 가이던스를 쓰면 **100번**, 안 쓰면 **50번**. [샘플링](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sampling-%EC%83%98%ED%94%8C%EB%A7%81) 계산이 두 배가 된다

</details>

### 문제 10

([Lec16 8.3](../../Lec16_%EC%A1%B0%EA%B1%B4%EB%B6%80_%EC%83%9D%EC%84%B1_%EB%AA%A8%EB%8D%B8.md#83-%EC%A1%B0%EA%B1%B4%EB%B6%80-%ED%99%95%EC%82%B0-%EB%AA%A8%EB%8D%B8)) 1차원에서 비조건 분포 $\mathcal{N}(0, 1)$, 조건부 분포 $\mathcal{N}(2, 1)$이다. 위치 $x = 1$에서 $s = 1$과 $s = 3$의 가이던스 점수를 구하고, $s = 1$이 보통의 조건부 모델과 같은지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\nabla_x \ln p(x) = -x$, $\nabla_x \ln p(x\mid c) = -(x - 2)$
- $x = 1$, $s = 1$ 과 $s = 3$

**풀이**
1. 식을 그대로 쓴다: $\nabla_x \ln p(x) + s\,\big(\nabla_x \ln p(x\mid c) - \nabla_x \ln p(x)\big)$
2. 점수를 구한다: 비조건 $-1$, 조건부 $-(1 - 2) = 1$
3. 숨은 분류기 점수를 구한다: $1 - (-1) = 2$
4. $s = 1$을 대입한다: $-1 + 1 \times 2$
5. 계산한다: $-1 + 2 = 1$
6. $s = 3$을 대입한다: $-1 + 3 \times 2$
7. 계산한다: $3 \times 2 = 6$, $-1 + 6 = 5$
8. $s = 1$의 값을 조건부 점수와 비교한다: $1 = 1$

**답**: $s = 1$이면 **1**(조건부 점수와 같다), $s = 3$이면 **5**. $s = 1$은 보통의 조건부 모델이고, $s > 1$일 때만 조건을 과장한다

</details>
