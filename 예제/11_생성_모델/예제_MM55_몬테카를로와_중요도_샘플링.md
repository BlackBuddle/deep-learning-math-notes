# 예제: 몬테카를로와 중요도 샘플링

개념 노트: [MM55_몬테카를로와_중요도_샘플링](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/11_%EC%83%9D%EC%84%B1_%EB%AA%A8%EB%8D%B8/MM55_%EB%AA%AC%ED%85%8C%EC%B9%B4%EB%A5%BC%EB%A1%9C%EC%99%80_%EC%A4%91%EC%9A%94%EB%8F%84_%EC%83%98%ED%94%8C%EB%A7%81.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 쓰는 식은 둘이다. 몬테카를로 $\mathbb{E}_{p}[f(z)] \approx \frac{1}{M}\sum_j f(z_j)$ ($z_j \sim p$)와 [중요도 샘플링](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#importance-sampling-%EC%A4%91%EC%9A%94%EB%8F%84-%EC%83%98%ED%94%8C%EB%A7%81) $\frac{1}{M}\sum_j \frac{p(z_j)}{q(z_j)} f(z_j)$ ($z_j \sim q$)이다. 모델은 $z \sim \mathcal{N}(0, 1)$, $p(x\mid z) = \mathcal{N}(x; 2z, 1)$이고 $x = 1$일 때 참값은 $p(1) = 0.1614$이다. [정규분포](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#normal-distribution-%EC%A0%95%EA%B7%9C%EB%B6%84%ED%8F%AC) 밀도 $\mathcal{N}(x; m, v) = e^{-(x-m)^2/(2v)} / \sqrt{2\pi v}$를 쓴다.

## 기본 (직접 대입)

### 문제 1

$z \sim \mathcal{N}(0, 1)$에서 표본 $1, -2, 0, 1$을 뽑았다. $\mathbb{E}[z^2]$의 몬테카를로 추정값을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $z_1 = 1$, $z_2 = -2$, $z_3 = 0$, $z_4 = 1$ (표본)
- $M = 4$ (표본 개수), $f(z) = z^2$ (평균 내려는 값)

**풀이**
1. 식을 그대로 쓴다: $\mathbb{E}[z^2] \approx \dfrac{1}{M}\sum_{j=1}^{M} z_j^2$
2. 값을 대입한다: $\mathbb{E}[z^2] \approx \dfrac{1}{4}\sum_{j=1}^{4} z_j^2$
3. Σ를 풀어 쓴다: $\dfrac{1}{4}\big(1^2 + (-2)^2 + 0^2 + 1^2\big)$
4. 제곱한다: $1,\ 4,\ 0,\ 1$
5. 더한다: $1 + 4 = 5$, $5 + 0 = 5$, $5 + 1 = 6$
6. 4로 나눈다: $6 / 4 = 1.5$

**답**: **1.5** (참값은 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) 1). 표본이 4개뿐이라 0.5만큼 어긋난다

</details>

### 문제 2

몬테카를로로 $p(1)$을 추정한다. 표본 하나가 내는 값의 표준편차는 $\sigma = 0.1464$이다. 표본을 $M = 400$개 쓰면 추정값의 표준오차는 얼마인가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $\sigma = 0.1464$ (표본 하나 값의 표준편차)
- $M = 400$ (표본 개수)

**풀이** (평균의 표준편차는 $\sigma / \sqrt{M}$이다)
1. 식을 그대로 쓴다: $\text{표준오차} = \dfrac{\sigma}{\sqrt{M}}$
2. 값을 대입한다: $\text{표준오차} = \dfrac{0.1464}{\sqrt{400}}$
3. 제곱근을 구한다 ($\sqrt{400}$은 제곱해서 400이 되는 수): $\sqrt{400} = 20$
4. 나눈다: $0.1464 / 20 = 0.00732$

**답**: 약 **0.0073**. 표본을 4배로 늘리면 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)는 절반이 된다

</details>

### 문제 3

표본 $z = -0.5,\ 0.5,\ 1$로 $p(1)$의 몬테카를로 추정값을 구하라. ($p(1\mid z) = \mathcal{N}(1; 2z, 1)$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $z_1 = -0.5$, $z_2 = 0.5$, $z_3 = 1$ ([사전 분포](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#prior-posterior-%EC%82%AC%EC%A0%84-%EB%B6%84%ED%8F%AC%EC%99%80-%EC%82%AC%ED%9B%84-%EB%B6%84%ED%8F%AC)에서 뽑은 표본), $M = 3$
- $f(z) = p(1\mid z) = \mathcal{N}(1; 2z, 1)$

**풀이**
1. 식을 그대로 쓴다: $\hat{p}(1) = \dfrac{1}{M}\sum_{j=1}^{M} p(1\mid z_j)$
2. 값을 대입한다: $\hat{p}(1) = \dfrac{1}{3}\big(\mathcal{N}(1; -1, 1) + \mathcal{N}(1; 1, 1) + \mathcal{N}(1; 2, 1)\big)$
3. $z = -0.5$: 평균 $-1$, 거리 제곱 $(1 + 1)^2 = 4$, 반으로 $2$, $e^{-2} = 0.1353$ ($e$는 약 2.718), $\sqrt{2\pi} = 2.5066$ 이므로 $0.1353 / 2.5066 = 0.0540$
4. $z = 0.5$: 평균 1, 거리 0, $e^{0} = 1$, $1 / 2.5066 = 0.3989$
5. $z = 1$: 평균 2, 거리 제곱 1, 반으로 $0.5$, $e^{-0.5} = 0.6065$, $0.6065 / 2.5066 = 0.2420$
6. 더한다: $0.0540 + 0.3989 = 0.4529$, $0.4529 + 0.2420 = 0.6949$
7. 3으로 나눈다: $0.6949 / 3 = 0.2316$

**답**: **0.2316** (참값 0.1614). 표본이 3개라 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)가 크다

</details>

### 문제 4

원래 분포 $p$ 대신 $q$에서 표본 두 개를 뽑았다. 표본 1: $p = 0.1$, $q = 0.4$, $f = 2$. 표본 2: $p = 0.3$, $q = 0.2$, $f = 1$. [중요도 샘플링](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#importance-sampling-%EC%A4%91%EC%9A%94%EB%8F%84-%EC%83%98%ED%94%8C%EB%A7%81) 추정값을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 표본 1: $p(z_1) = 0.1$, $q(z_1) = 0.4$, $f(z_1) = 2$
- 표본 2: $p(z_2) = 0.3$, $q(z_2) = 0.2$, $f(z_2) = 1$
- $M = 2$

**풀이** ($q$에서 뽑았으므로 무게 $p/q$를 곱한 값을 평균한다)
1. 식을 그대로 쓴다: $\hat{\mu} = \dfrac{1}{M}\sum_{j=1}^{M} \dfrac{p(z_j)}{q(z_j)}\, f(z_j)$
2. 값을 대입한다: $\hat{\mu} = \dfrac{1}{2}\Big(\dfrac{0.1}{0.4} \times 2 + \dfrac{0.3}{0.2} \times 1\Big)$
3. 무게를 구한다: $0.1 / 0.4 = 0.25$, $0.3 / 0.2 = 1.5$
4. 무게에 $f$를 곱한다: $0.25 \times 2 = 0.5$, $1.5 \times 1 = 1.5$
5. 더한다: $0.5 + 1.5 = 2$
6. 2로 나눈다: $2 / 2 = 1$

**답**: **1**. $q$가 드물게 뽑는 곳(표본 2)은 무게가 1.5로 커지고, 자주 뽑는 곳(표본 1)은 0.25로 줄어든다

</details>

### 문제 5

$q = \mathcal{N}(0.5, 0.36)$에서 $z = 0.5$ 하나를 뽑았다. $p(1)$의 [중요도 샘플링](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#importance-sampling-%EC%A4%91%EC%9A%94%EB%8F%84-%EC%83%98%ED%94%8C%EB%A7%81) 추정값을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $z_1 = 0.5$ ($q$에서 뽑은 표본), $M = 1$
- $p(z) = \mathcal{N}(z; 0, 1)$ ([사전 분포](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#prior-posterior-%EC%82%AC%EC%A0%84-%EB%B6%84%ED%8F%AC%EC%99%80-%EC%82%AC%ED%9B%84-%EB%B6%84%ED%8F%AC))
- $q(z) = \mathcal{N}(z; 0.5, 0.36)$ (제안 분포)
- $f(z) = \mathcal{N}(1; 2z, 1)$

**풀이**
1. 식을 그대로 쓴다: $\hat{p} = \dfrac{1}{M}\sum_{j=1}^{M} \dfrac{p(z_j)}{q(z_j)}\, f(z_j)$
2. 값을 대입한다: $\hat{p} = \dfrac{1}{1}\cdot\dfrac{\mathcal{N}(0.5; 0, 1)}{\mathcal{N}(0.5; 0.5, 0.36)}\, \mathcal{N}(1; 1, 1)$
3. 사전 밀도: $0.5^2 = 0.25$, 반으로 $0.125$, $e^{-0.125} = 0.8825$, $0.8825 / 2.5066 = 0.3521$
4. $q$ 밀도: 거리 0 이므로 $e^{0} = 1$, [정규화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#normalization-%EC%A0%95%EA%B7%9C%ED%99%94) 상수 $\sqrt{2\pi \times 0.36} = \sqrt{2.2619} = 1.5040$, $1 / 1.5040 = 0.6649$
5. $f$: 평균 $2 \times 0.5 = 1$, 거리 0 이므로 $1 / 2.5066 = 0.3989$
6. 무게를 구한다: $0.3521 / 0.6649 = 0.5295$
7. $f$를 곱한다: $0.5295 \times 0.3989 = 0.2112$

**답**: **0.2112** (참값 0.1614). 표본이 [사후 분포](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#prior-posterior-%EC%82%AC%EC%A0%84-%EB%B6%84%ED%8F%AC%EC%99%80-%EC%82%AC%ED%9B%84-%EB%B6%84%ED%8F%AC)의 중심(0.4)에서 조금 벗어나서 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)가 남는다

</details>

### 문제 6

문제 5와 같은 설정에서 $q$에서 표본 $z = 0.2$와 $z = 0.8$ 두 개를 뽑았다. 추정값을 구하라. (표본마다 $\frac{p}{q}f$를 따로 구한 뒤 평균한다.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $z_1 = 0.2$, $z_2 = 0.8$ ($q$에서 뽑은 표본), $M = 2$
- $p = \mathcal{N}(0, 1)$, $q = \mathcal{N}(0.5, 0.36)$, $f(z) = \mathcal{N}(1; 2z, 1)$

**풀이**
1. 식을 그대로 쓴다: $\hat{p} = \dfrac{1}{2}\Big(\dfrac{p(z_1)}{q(z_1)}f(z_1) + \dfrac{p(z_2)}{q(z_2)}f(z_2)\Big)$
2. 값을 대입한다: $\hat{p} = \dfrac{1}{2}\Big(\dfrac{\mathcal{N}(0.2; 0, 1)}{\mathcal{N}(0.2; 0.5, 0.36)}\mathcal{N}(1; 0.4, 1) + \dfrac{\mathcal{N}(0.8; 0, 1)}{\mathcal{N}(0.8; 0.5, 0.36)}\mathcal{N}(1; 1.6, 1)\Big)$
3. 표본 1의 사전 밀도: $0.2^2 = 0.04$, 반으로 $0.02$, $e^{-0.02} = 0.9802$, $0.9802 / 2.5066 = 0.3910$
4. 표본 1의 $q$ 밀도: $(0.2 - 0.5)^2 = 0.09$, $2 \times 0.36 = 0.72$로 나눠 $0.125$, $e^{-0.125} = 0.8825$, $0.8825 / 1.5040 = 0.5868$
5. 표본 1의 $f$: $(1 - 0.4)^2 = 0.36$, 반으로 $0.18$, $e^{-0.18} = 0.8353$, $0.8353 / 2.5066 = 0.3332$
6. 표본 1의 값: 무게 $0.3910 / 0.5868 = 0.6664$, 곱하면 $0.6664 \times 0.3332 = 0.2221$ (반올림 전 값으로 곱함)
7. 표본 2의 사전 밀도: $0.8^2 = 0.64$, 반으로 $0.32$, $e^{-0.32} = 0.7261$, $0.7261 / 2.5066 = 0.2897$
8. 표본 2의 $q$ 밀도: $(0.8 - 0.5)^2 = 0.09$, $0.09 / 0.72 = 0.125$, 표본 1과 같아서 $0.5868$
9. 표본 2의 $f$: $(1 - 1.6)^2 = 0.36$이라 표본 1과 같아서 $0.3332$
10. 표본 2의 값: 무게 $0.2897 / 0.5868 = 0.4937$, 곱하면 $0.4937 \times 0.3332 = 0.1645$
11. 평균한다: $(0.2221 + 0.1645) / 2 = 0.3866 / 2 = 0.1933$

**답**: **0.1933** (참값 0.1614). 표본마다 값이 0.2221, 0.1645로 다르다. 표본을 더 늘리면 참값에 모인다

</details>

### 문제 7

위 모델에서 $p(1)$의 표준오차를 0.006으로 줄이고 싶다. [사전 분포](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#prior-posterior-%EC%82%AC%EC%A0%84-%EB%B6%84%ED%8F%AC%EC%99%80-%EC%82%AC%ED%9B%84-%EB%B6%84%ED%8F%AC)에서 뽑는 몬테카를로($\sigma = 0.1464$)와 $q = \mathcal{N}(0.5, 0.36)$에서 뽑는 [중요도 샘플링](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#importance-sampling-%EC%A4%91%EC%9A%94%EB%8F%84-%EC%83%98%ED%94%8C%EB%A7%81)($\sigma = 0.0600$)은 각각 표본이 몇 개 필요한가?

<details><summary>풀이와 답</summary>

**주어진 값**
- 목표 표준오차 $0.006$
- $\sigma_{\text{MC}} = 0.1464$, $\sigma_{\text{IS}} = 0.0600$ (표본 하나 값의 표준편차)

**풀이** (표준오차 $\sigma/\sqrt{M}$를 목표로 맞추면 $M = (\sigma / \text{목표})^2$)
1. 식을 그대로 쓴다: $M = \Big(\dfrac{\sigma}{\text{목표 오차}}\Big)^2$
2. 값을 대입한다 (몬테카를로): $M = \Big(\dfrac{0.1464}{0.006}\Big)^2$
3. 나눈다: $0.1464 / 0.006 = 24.4$
4. 제곱한다: $24.4^2 = 595.36$, 올림하면 596
5. 값을 대입한다 ([중요도 샘플링](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#importance-sampling-%EC%A4%91%EC%9A%94%EB%8F%84-%EC%83%98%ED%94%8C%EB%A7%81)): $M = \Big(\dfrac{0.0600}{0.006}\Big)^2$
6. 나눈다: $0.0600 / 0.006 = 10$
7. 제곱한다: $10^2 = 100$

**답**: 몬테카를로 **596개**, [중요도 샘플링](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#importance-sampling-%EC%A4%91%EC%9A%94%EB%8F%84-%EC%83%98%ED%94%8C%EB%A7%81) **100개**. $q$를 잘 고르면 표본이 6분의 1로 준다

</details>

### 문제 8

참값이 $0.2$인 양을 표본 2개로 추정했더니 표본 하나하나의 추정값이 $0.1$과 $0.3$이었다. 평균의 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8) $\ln(\text{평균})$과 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)의 평균(각 값에 $\ln$을 씌운 뒤 평균)을 구해 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 추정값 $a_1 = 0.1$, $a_2 = 0.3$ (표본마다의 추정값)
- 참값 $0.2$

**풀이** (평균에 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 씌우는 것과 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 먼저 씌우고 평균하는 것은 다르다)
1. 식을 쓴다: $\ln\!\Big(\dfrac{a_1 + a_2}{2}\Big)$ 와 $\dfrac{\ln a_1 + \ln a_2}{2}$
2. 값을 대입한다: $\ln\!\Big(\dfrac{0.1 + 0.3}{2}\Big)$ 와 $\dfrac{\ln 0.1 + \ln 0.3}{2}$
3. 평균을 먼저 낸다: $(0.1 + 0.3) / 2 = 0.2$
4. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 씌운다 ($\ln a$는 $e$를 몇 제곱해야 $a$가 되는지): $\ln 0.2 = -1.6094$
5. 각 값의 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8): $\ln 0.1 = -2.3026$, $\ln 0.3 = -1.2040$
6. 더하고 2로 나눈다: $-2.3026 + (-1.2040) = -3.5066$, $-3.5066 / 2 = -1.7533$
7. 비교한다: $-1.6094 > -1.7533$

### 문제 9

([Lec15 6.1](../../Lec15_%EB%B3%80%EB%B6%84_%EC%98%A4%ED%86%A0%EC%9D%B8%EC%BD%94%EB%8D%94.md#61-%EA%B3%A0%EC%B0%A8%EC%9B%90%EC%97%90%EC%84%9C%EB%8A%94-%ED%91%9C%EB%B3%B8%EC%9D%B4-%EB%AA%A8%EC%9E%90%EB%9E%80%EB%8B%A4)) 고차원에서는 표본의 90%가 $f = 0$이고 10%만 $f = 10$을 낸다고 하자. 표본 하나 값의 평균과 표준편차를 구하고, $M = 100$일 때 몬테카를로의 표준오차와 평균 대비 비율을 구하라. ($\sigma^2 = \mathbb{E}[f^2] - (\mathbb{E}[f])^2$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $P(f = 0) = 0.9$, $P(f = 10) = 0.1$ (값과 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $M = 100$ (표본 개수)

**풀이**
1. 평균의 식을 쓴다: $\mathbb{E}[f] = \sum f \cdot P(f)$
2. 값을 대입한다: $\mathbb{E}[f] = 0 \times 0.9 + 10 \times 0.1 = 0 + 1 = 1$
3. 제곱의 평균의 식을 쓴다: $\mathbb{E}[f^2] = \sum f^2 \cdot P(f)$
4. 값을 대입한다: $\mathbb{E}[f^2] = 0^2 \times 0.9 + 10^2 \times 0.1 = 0 + 10 = 10$
5. [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 구한다: $\sigma^2 = 10 - 1^2 = 9$
6. 표준편차를 구한다: $\sigma = \sqrt{9} = 3$
7. 표준오차의 식을 쓰고 대입한다: $\sigma / \sqrt{M} = 3 / \sqrt{100}$
8. 계산한다: $\sqrt{100} = 10$, $3 / 10 = 0.3$
9. 평균 대비 비율을 구한다: $0.3 / 1 = 0.3$

**답**: 평균 **1**, 표준편차 **3**, 표준오차 **0.3**(평균의 30%). 평균은 1인데 표준편차가 3배라 표본 100개로도 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)가 크다. 표본의 90%가 0을 내기 때문이다

</details>

### 문제 10

([Lec15 7](../../Lec15_%EB%B3%80%EB%B6%84_%EC%98%A4%ED%86%A0%EC%9D%B8%EC%BD%94%EB%8D%94.md#7-%EC%9A%94%EB%A0%B9-2-%EC%A4%91%EC%9A%94%EB%8F%84-%EC%83%98%ED%94%8C%EB%A7%81)) $z \in \{1, 2, 3\}$이고 $p = (0.5, 0.3, 0.2)$, $f = (1, 2, 5)$이다. 최적의 제안 분포 $q(z) = p(z)f(z) / \sum p f$를 구하고, 세 점 모두에서 무게 × $f$가 같은 값이 됨을 보여라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p(1) = 0.5$, $p(2) = 0.3$, $p(3) = 0.2$ (원래 분포)
- $f(1) = 1$, $f(2) = 2$, $f(3) = 5$ (평균 내려는 값)

**풀이**
1. 식을 그대로 쓴다: $q(z) = \dfrac{p(z)\,f(z)}{\sum_{z'} p(z')\,f(z')}$
2. 점마다 $p f$를 구한다: $0.5 \times 1 = 0.5$, $0.3 \times 2 = 0.6$, $0.2 \times 5 = 1.0$
3. 분모를 구한다 (Σ를 풀어 더함): $0.5 + 0.6 + 1.0 = 2.1$
4. $q$를 구한다: $q(1) = 0.5 / 2.1 = 0.2381$, $q(2) = 0.6 / 2.1 = 0.2857$, $q(3) = 1.0 / 2.1 = 0.4762$
5. $z = 1$의 무게 × $f$: $\dfrac{0.5}{0.2381} \times 1 = 2.1 \times 1 = 2.1$
6. $z = 2$의 무게 × $f$: $\dfrac{0.3}{0.2857} \times 2 = 1.05 \times 2 = 2.1$
7. $z = 3$의 무게 × $f$: $\dfrac{0.2}{0.4762} \times 5 = 0.42 \times 5 = 2.1$

**답**: $q = (0.2381, 0.2857, 0.4762)$이고 세 점 모두 **2.1**이다. 어느 $z$를 뽑아도 추정값이 참값 2.1과 같으므로 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)이 0이다. 값이 큰 곳($f = 5$)을 더 자주 뽑는다

</details>
