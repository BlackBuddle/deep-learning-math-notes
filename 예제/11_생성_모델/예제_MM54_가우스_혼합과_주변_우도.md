# 예제: 가우스 혼합과 주변 우도

개념 노트: [MM54_가우스_혼합과_주변_우도](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/11_%EC%83%9D%EC%84%B1_%EB%AA%A8%EB%8D%B8/MM54_%EA%B0%80%EC%9A%B0%EC%8A%A4_%ED%98%BC%ED%95%A9%EA%B3%BC_%EC%A3%BC%EB%B3%80_%EC%9A%B0%EB%8F%84.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 쓰는 식은 둘이다. [정규분포](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#normal-distribution-%EC%A0%95%EA%B7%9C%EB%B6%84%ED%8F%AC)의 밀도 $\mathcal{N}(x; m, v) = \dfrac{e^{-(x-m)^2/(2v)}}{\sqrt{2\pi v}}$ ($m$은 평균, $v$는 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0))와 주변화 $p(x) = \sum_z p(x\mid z)\,p(z)$이다.

## 기본 (직접 대입)

### 문제 1

성분이 둘인 가우스 혼합이 있다. [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)는 $(0.3, 0.7)$, 중심은 $(0, 2)$, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)은 둘 다 1이다. $x = 0$의 밀도 $p(0)$을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $w = (0.3, 0.7)$ (성분 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98))
- $\mu = (0, 2)$ (성분 중심)
- [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $v = 1$, $x = 0$ (밀도를 구할 위치)

**풀이**
1. 식을 그대로 쓴다: $p(x) = \sum_{i=1}^{2} w_i\, \mathcal{N}(x; \mu_i, 1)$
2. 값을 대입한다: $p(0) = \sum_{i=1}^{2} w_i\, \mathcal{N}(0; \mu_i, 1)$
3. Σ를 풀어 쓴다: $p(0) = 0.3\,\mathcal{N}(0; 0, 1) + 0.7\,\mathcal{N}(0; 2, 1)$
4. 첫 성분 밀도 ($e$는 약 2.718인 수, $\sqrt{2\pi} = 2.5066$): 거리 0 이므로 $e^{0} = 1$, $1 / 2.5066 = 0.3989$
5. 둘째 성분 밀도: 거리 제곱 $(0 - 2)^2 = 4$, 반으로 $2$, $e^{-2} = 0.1353$, $0.1353 / 2.5066 = 0.0540$
6. [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)를 곱한다: $0.3 \times 0.3989 = 0.1197$, $0.7 \times 0.0540 = 0.0378$
7. 더한다: $0.1197 + 0.0378 = 0.1575$

**답**: $p(0) = $ **0.1575**

</details>

### 문제 2

동전을 던져 앞면([확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 0.4)이면 $\mathcal{N}(0, 1)$에서, 뒷면([확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 0.6)이면 $\mathcal{N}(3, 1)$에서 $x$를 뽑는다. $x = 2$의 [주변 우도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#marginal-likelihood-%EC%A3%BC%EB%B3%80-%EC%9A%B0%EB%8F%84)를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p(z = \text{앞}) = 0.4$, $p(z = \text{뒤}) = 0.6$ (동전 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) = [사전 분포](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#prior-posterior-%EC%82%AC%EC%A0%84-%EB%B6%84%ED%8F%AC%EC%99%80-%EC%82%AC%ED%9B%84-%EB%B6%84%ED%8F%AC))
- $p(x\mid \text{앞}) = \mathcal{N}(x; 0, 1)$, $p(x\mid \text{뒤}) = \mathcal{N}(x; 3, 1)$ (성분)
- $x = 2$

**풀이** (숨은 동전 $z$를 더해 없애는 주변화이므로 $p(x) = \sum_z p(x\mid z)\,p(z)$를 쓴다)
1. 식을 그대로 쓴다: $p(x) = \sum_{z} p(x\mid z)\, p(z)$
2. 값을 대입한다: $p(2) = \sum_{z \in \{\text{앞}, \text{뒤}\}} p(2\mid z)\, p(z)$
3. Σ를 풀어 쓴다: $p(2) = p(2\mid \text{앞}) \times 0.4 + p(2\mid \text{뒤}) \times 0.6$
4. 앞면 성분 밀도: 거리 제곱 $(2 - 0)^2 = 4$, 반으로 $2$, $e^{-2} = 0.1353$, $0.1353 / 2.5066 = 0.0540$
5. 뒷면 성분 밀도: 거리 제곱 $(2 - 3)^2 = 1$, 반으로 $0.5$, $e^{-0.5} = 0.6065$, $0.6065 / 2.5066 = 0.2420$
6. [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 곱한다: $0.0540 \times 0.4 = 0.0216$, $0.2420 \times 0.6 = 0.1452$
7. 더한다: $0.0216 + 0.1452 = 0.1668$

**답**: $p(2) = $ **0.1668**

</details>

### 문제 3

3차원 데이터에 성분 4개짜리 가우스 혼합을 맞춘다. 공분산을 전부 쓸 때 매개변수는 모두 몇 개인가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $k = 4$ (성분 개수)
- $d = 3$ (데이터 차원)

**풀이** (성분 하나가 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) 1개, 평균 $d$개, 공분산 $d \times d$개를 가진다)
1. 식을 그대로 쓴다: $\#\theta = k\,(1 + d + d^2)$
2. 값을 대입한다: $\#\theta = 4\,(1 + 3 + 3^2)$
3. 제곱을 먼저 한다: $3^2 = 9$ 이므로 $\#\theta = 4\,(1 + 3 + 9)$
4. 괄호 안을 더한다: $1 + 3 + 9 = 13$
5. 곱한다: $4 \times 13 = 52$

**답**: **52**개

</details>

### 문제 4

[가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) $(0.6, 0.4)$인 혼합이다. 첫 성분은 $\mathcal{N}(0, 1)$, 둘째 성분은 $\mathcal{N}(1, 4)$(평균 1, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) 4)이다. $x = 1$의 밀도를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $w = (0.6, 0.4)$ ([가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98))
- 성분 1: 평균 0, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) 1 / 성분 2: 평균 1, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) 4
- $x = 1$

**풀이**
1. 식을 그대로 쓴다: $p(x) = \sum_{i} w_i\, \mathcal{N}(x; \mu_i, v_i)$
2. 값을 대입한다: $p(1) = 0.6\,\mathcal{N}(1; 0, 1) + 0.4\,\mathcal{N}(1; 1, 4)$
3. 첫 성분 밀도: 거리 제곱 $(1 - 0)^2 = 1$, 반으로 $0.5$, $e^{-0.5} = 0.6065$, $0.6065 / 2.5066 = 0.2420$
4. 둘째 성분 밀도의 [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98): 거리 $(1 - 1)^2 = 0$ 이므로 $e^{0} = 1$
5. 둘째 성분의 [정규화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#normalization-%EC%A0%95%EA%B7%9C%ED%99%94) 상수: $2\pi \times 4 = 25.1327$, $\sqrt{25.1327} = 5.0133$
6. 나눈다: $1 / 5.0133 = 0.1995$
7. [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)를 곱한다: $0.6 \times 0.2420 = 0.1452$, $0.4 \times 0.1995 = 0.0798$
8. 더한다: $0.1452 + 0.0798 = 0.2250$

**답**: $p(1) = $ **0.2250**. [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)이 큰 성분은 봉우리가 낮고 넓어서, 중심에 있어도 밀도가 0.1995에 그친다

</details>

### 문제 5

$z \sim \mathcal{N}(0, 1)$이고 $x\mid z \sim \mathcal{N}(3z, 1)$이다. $g$가 직선이라서 $p(x) = \mathcal{N}(x; 0,\ 3^2 \times 1 + 1)$이 된다. $p(1)$을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $z \sim \mathcal{N}(0, 1)$ ([잠재 변수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#latent-variable-%EC%9E%A0%EC%9E%AC-%EB%B3%80%EC%88%98)의 [사전 분포](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#prior-posterior-%EC%82%AC%EC%A0%84-%EB%B6%84%ED%8F%AC%EC%99%80-%EC%82%AC%ED%9B%84-%EB%B6%84%ED%8F%AC))
- $x\mid z \sim \mathcal{N}(3z, 1)$ (신경망 $g^\mu(z) = 3z$, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) 1)
- $x = 1$

**풀이** (직선이면 결과가 [정규분포](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#normal-distribution-%EC%A0%95%EA%B7%9C%EB%B6%84%ED%8F%AC)이고, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)은 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) 제곱 × $z$의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) + 잡음 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)이다)
1. [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 구한다: $v = 3^2 \times 1 + 1$
2. 제곱과 곱셈을 한다: $3^2 = 9$, $9 \times 1 = 9$ 이므로 $v = 9 + 1 = 10$
3. 식을 쓴다: $p(x) = \mathcal{N}(x; 0, 10) = \dfrac{e^{-(x-0)^2/(2 \times 10)}}{\sqrt{2\pi \times 10}}$
4. 값을 대입한다: $p(1) = \dfrac{e^{-1^2/20}}{\sqrt{2\pi \times 10}}$
5. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $1 / 20 = 0.05$, $e^{-0.05} = 0.9512$
6. [정규화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#normalization-%EC%A0%95%EA%B7%9C%ED%99%94) 상수: $2\pi \times 10 = 62.8319$, $\sqrt{62.8319} = 7.9267$
7. 나눈다: $0.9512 / 7.9267 = 0.1200$

**답**: $p(1) = $ **0.1200**

</details>

### 문제 6

$z \sim \mathcal{N}(0, 1)$, $x\mid z \sim \mathcal{N}(2z, 1)$인 모델에서 $p(1) = \int p(z)\,p(1\mid z)\,dz$를 [리만 합](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#riemann-sum-%EB%A6%AC%EB%A7%8C-%ED%95%A9)으로 어림하려 한다. $z$ 격자는 $-1, 0, 1$(간격 1)이다. 참값은 0.1614이다. 어림값을 구하고 참값과 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $z \in \{-1, 0, 1\}$ (격자점), 간격 $\Delta z = 1$
- $p(z) = \mathcal{N}(z; 0, 1)$ ([사전 분포](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#prior-posterior-%EC%82%AC%EC%A0%84-%EB%B6%84%ED%8F%AC%EC%99%80-%EC%82%AC%ED%9B%84-%EB%B6%84%ED%8F%AC))
- $p(1\mid z) = \mathcal{N}(1; 2z, 1)$ (성분)

**풀이**
1. 식을 그대로 쓴다: $p(1) \approx \sum_{j} p(z_j)\, p(1\mid z_j)\, \Delta z$
2. 값을 대입한다: $p(1) \approx \sum_{z \in \{-1, 0, 1\}} \mathcal{N}(z; 0, 1)\, \mathcal{N}(1; 2z, 1) \times 1$
3. Σ를 풀어 쓴다: $\mathcal{N}(-1; 0, 1)\,\mathcal{N}(1; -2, 1) + \mathcal{N}(0; 0, 1)\,\mathcal{N}(1; 0, 1) + \mathcal{N}(1; 0, 1)\,\mathcal{N}(1; 2, 1)$
4. 사전 밀도: $z = \pm 1$이면 $e^{-0.5} / 2.5066 = 0.2420$, $z = 0$이면 $1 / 2.5066 = 0.3989$
5. $z = -1$의 성분: 평균 $-2$, 거리 제곱 $(1 + 2)^2 = 9$, 반으로 $4.5$, $e^{-4.5} = 0.0111$, $0.0111 / 2.5066 = 0.0044$
6. $z = 0$의 성분: 평균 0, 거리 제곱 1, $e^{-0.5} / 2.5066 = 0.2420$
7. $z = 1$의 성분: 평균 2, 거리 제곱 $(1 - 2)^2 = 1$, $e^{-0.5} / 2.5066 = 0.2420$
8. 점마다 곱한다: $0.2420 \times 0.0044 = 0.0011$, $0.3989 \times 0.2420 = 0.0965$, $0.2420 \times 0.2420 = 0.0586$
9. 더한다: $0.0011 + 0.0965 + 0.0586 = 0.1562$
10. 참값과 비교한다: $0.1614 - 0.1562 = 0.0052$

**답**: 어림값 **0.1562**, 참값보다 0.0052 작다. 격자를 촘촘히 하면(간격 0.1이면 0.1614) 참값에 붙는다

</details>

### 문제 7

혼합 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)가 $(0.6, 0.6)$인 두 성분 혼합이 있다. 이 밀도의 전체 넓이는 얼마인가? 넓이가 1인 진짜 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 밀도로 만들려면 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)를 어떻게 고쳐야 하는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $w_1 = 0.6$, $w_2 = 0.6$ ([가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98))
- 각 성분 $\mathcal{N}(x; \mu_i, \Sigma_i)$의 넓이는 1 ([정규분포](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#normal-distribution-%EC%A0%95%EA%B7%9C%EB%B6%84%ED%8F%AC) 하나는 늘 넓이 1)

**풀이** (혼합의 넓이는 $\int p(x)\,dx = \sum_i w_i \int \mathcal{N}\,dx$ 이므로 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)의 합과 같다)
1. 식을 그대로 쓴다: 넓이 $= \sum_{i} w_i \times 1$
2. 값을 대입한다: 넓이 $= 0.6 \times 1 + 0.6 \times 1$
3. 더한다: $0.6 + 0.6 = 1.2$
4. 고치는 방법을 정한다: [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)를 합 1.2로 나누면 합이 1이 된다
5. 나눈다: $0.6 / 1.2 = 0.5$ (두 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) 모두)

**답**: 넓이 **1.2**. [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)를 $(0.5, 0.5)$로 고치면 넓이가 1이 된다

</details>

### 문제 8

문제 2의 동전 혼합(앞면 0.4 → $\mathcal{N}(0, 1)$, 뒷면 0.6 → $\mathcal{N}(3, 1)$)에서 $x = 2$가 나왔다. 이 값이 앞면 성분에서 나왔을 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) $p(\text{앞}\mid x = 2)$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p(\text{앞}) = 0.4$, $p(\text{뒤}) = 0.6$ (사전 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $p(2\mid \text{앞}) = 0.0540$, $p(2\mid \text{뒤}) = 0.2420$ (문제 2에서 구한 성분 밀도)

**풀이** (조건을 뒤집는 [베이즈 정리](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bayes-rule-%EB%B2%A0%EC%9D%B4%EC%A6%88-%EC%A0%95%EB%A6%AC): $p(z\mid x) = p(x\mid z)\,p(z) / p(x)$)
1. 식을 그대로 쓴다: $p(\text{앞}\mid x) = \dfrac{p(x\mid \text{앞})\,p(\text{앞})}{p(x)}$
2. 값을 대입한다: $p(\text{앞}\mid 2) = \dfrac{0.0540 \times 0.4}{0.0540 \times 0.4 + 0.2420 \times 0.6}$
3. 분자의 곱셈을 한다: $0.0540 \times 0.4 = 0.0216$
4. 분모 둘째 항의 곱셈을 한다: $0.2420 \times 0.6 = 0.1452$
5. 분모를 더한다 (이것이 문제 2의 [주변 우도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#marginal-likelihood-%EC%A3%BC%EB%B3%80-%EC%9A%B0%EB%8F%84)): $0.0216 + 0.1452 = 0.1668$
6. 나눈다: $0.0216 / 0.1668 = 0.1295$

**답**: **0.1295**. 사전에는 앞면이 0.4였지만, $x = 2$가 뒷면 중심 3에 더 가까워서 앞면일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 0.13으로 내려간다

</details>

### 문제 9

([Lec15 4.1](../../Lec15_%EB%B3%80%EB%B6%84_%EC%98%A4%ED%86%A0%EC%9D%B8%EC%BD%94%EB%8D%94.md#41-%EC%8B%A0%EA%B2%BD%EB%A7%9D%EC%9C%BC%EB%A1%9C-%EB%AC%B4%ED%95%9C-%ED%98%BC%ED%95%A9-%EB%A7%8C%EB%93%A4%EA%B8%B0)) 다이얼 $z \sim \mathcal{N}(0, 1)$을 돌리면 신경망이 평균 $g^\mu(z) = z + 1$을 내고, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)은 0.25로 고정이다. $g$가 직선이므로 $p(x)$는 평균 1, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $1^2 \times 1 + 0.25$인 [정규분포](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#normal-distribution-%EC%A0%95%EA%B7%9C%EB%B6%84%ED%8F%AC)이다. $p(1)$을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $z \sim \mathcal{N}(0, 1)$ (다이얼의 분포)
- $g^\mu(z) = z + 1$, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) 0.25 (신경망이 내는 더미의 위치와 퍼짐)
- $x = 1$

**풀이** (평균은 $g^\mu(0) = 1$, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)은 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) 제곱 × $z$의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) + 성분 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)이다)
1. [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 구한다: $v = 1^2 \times 1 + 0.25 = 1.25$
2. 식을 쓴다: $p(x) = \mathcal{N}(x; 1, 1.25) = \dfrac{e^{-(x-1)^2/(2 \times 1.25)}}{\sqrt{2\pi \times 1.25}}$
3. 값을 대입한다: $p(1) = \dfrac{e^{-(1-1)^2/2.5}}{\sqrt{2\pi \times 1.25}}$
4. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: 거리 0 이므로 $e^{0} = 1$
5. [정규화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#normalization-%EC%A0%95%EA%B7%9C%ED%99%94) 상수: $2\pi \times 1.25 = 7.8540$, $\sqrt{7.8540} = 2.8025$
6. 나눈다: $1 / 2.8025 = 0.3568$

**답**: $p(1) = $ **0.3568**. [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)이 작아서(1.25) 문제 5의 0.1200보다 봉우리가 높다

### 문제 10

([Lec15 5](../../Lec15_%EB%B3%80%EB%B6%84_%EC%98%A4%ED%86%A0%EC%9D%B8%EC%BD%94%EB%8D%94.md#5-%EB%AA%A9%EC%A0%81-%ED%95%A8%EC%88%98%EC%99%80-%EB%8B%A4%EB%A3%A8%EA%B8%B0-%ED%9E%98%EB%93%A0-%EC%A0%81%EB%B6%84)) [잠재 변수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#latent-variable-%EC%9E%A0%EC%9E%AC-%EB%B3%80%EC%88%98) $z$가 10차원이면 적분을 [리만 합](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#riemann-sum-%EB%A6%AC%EB%A7%8C-%ED%95%A9)으로 할 때 격자점이 몇 개 필요한가? 각 축에서 $-6$부터 $6$까지 간격 1로 잡는다.

<details><summary>풀이와 답</summary>

**주어진 값**
- 한 축의 범위 $-6$ ~ $6$, 간격 1 (격자 간격)
- 차원 $d = 10$ ($z$의 차원)

**풀이** (축마다 점의 수를 세고, 모든 축의 조합이 필요하므로 곱한다)
1. 한 축의 점 수를 센다: $-6, -5, \dots, 6$ 이므로 $6 - (-6) + 1 = 13$개
2. 식을 쓴다: 전체 점 수 $= 13^{d}$
3. 값을 대입한다: $13^{10}$
4. 5제곱을 먼저 한다: $13^2 = 169$, $13^3 = 2197$, $13^4 = 28561$, $13^5 = 371293$
5. 한 번 더 제곱한다: $13^{10} = 371293^2 = 137{,}858{,}491{,}849$

**답**: 약 $1.4 \times 10^{11}$개(1380억 개 가까이). 점 하나마다 신경망을 한 번 돌려야 하므로 불가능하다. 그래서 [VAE](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variational-autoencoder-vae-%EB%B3%80%EB%B6%84-%EC%98%A4%ED%86%A0%EC%9D%B8%EC%BD%94%EB%8D%94)는 이 적분을 표본으로 어림한다

</details>
