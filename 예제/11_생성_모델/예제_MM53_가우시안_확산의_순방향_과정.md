# 예제: 가우시안 확산의 순방향 과정

개념 노트: [MM53_가우시안_확산의_순방향_과정](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/11_%EC%83%9D%EC%84%B1_%EB%AA%A8%EB%8D%B8/MM53_%EA%B0%80%EC%9A%B0%EC%8B%9C%EC%95%88_%ED%99%95%EC%82%B0%EC%9D%98_%EC%88%9C%EB%B0%A9%ED%96%A5_%EA%B3%BC%EC%A0%95.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 한 단계 식은 $x_t = \sqrt{1 - \beta}\, x_{t-1} + \sqrt{\beta}\, \epsilon_t$이고, 여러 단계를 한 번에 쓰는 식은 $x_t = \sqrt{\bar\alpha_t}\, x_0 + \sqrt{1 - \bar\alpha_t}\, \epsilon$($\bar\alpha_t = (1 - \beta)^t$)이다.

## 기본 (직접 대입)

### 문제 1

$x_{t-1} = 5$, $\beta = 0.36$이고 뽑힌 잡음이 $\epsilon_t = 1$일 때 $x_t$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x_{t-1} = 5$ (한 단계 전 값)
- $\beta = 0.36$ (더하는 잡음의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0))
- $\epsilon_t = 1$ (표준 정규에서 뽑힌 잡음)

**풀이**
1. 식을 그대로 쓴다: $x_t = \sqrt{1 - \beta}\, x_{t-1} + \sqrt{\beta}\, \epsilon_t$
2. 값을 대입한다: $x_t = \sqrt{1 - 0.36} \times 5 + \sqrt{0.36} \times 1$
3. 루트 안을 뺀다: $1 - 0.36 = 0.64$
4. 제곱근을 구한다. $\sqrt{a}$는 제곱해서 $a$가 되는 양수다: $\sqrt{0.64} = 0.8$
5. $\sqrt{0.36} = 0.6$
6. 앞 항을 곱한다: $0.8 \times 5 = 4$
7. 뒤 항을 곱한다: $0.6 \times 1 = 0.6$
8. 더한다: $4 + 0.6 = 4.6$

**답**: $x_t = 4.6$ (데이터는 0.8배로 줄고 잡음 0.6이 더해졌다)

</details>

### 문제 2

$x_{t-1} = -2$, $\beta = 0.36$, $\epsilon_t = 0.5$일 때 $x_t$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x_{t-1} = -2$ (한 단계 전 값)
- $\beta = 0.36$ (잡음의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0))
- $\epsilon_t = 0.5$ (잡음)

**풀이**
1. 식을 그대로 쓴다: $x_t = \sqrt{1 - \beta}\, x_{t-1} + \sqrt{\beta}\, \epsilon_t$
2. 값을 대입한다: $x_t = \sqrt{1 - 0.36} \times (-2) + \sqrt{0.36} \times 0.5$
3. 루트 안을 뺀다: $1 - 0.36 = 0.64$, 제곱근 $\sqrt{0.64} = 0.8$
4. $\sqrt{0.36} = 0.6$
5. 앞 항을 곱한다: $0.8 \times (-2) = -1.6$
6. 뒤 항을 곱한다: $0.6 \times 0.5 = 0.3$
7. 더한다: $-1.6 + 0.3 = -1.3$

**답**: $x_t = -1.3$

</details>

### 문제 3

$\beta = 0.2$로 3단계를 갔을 때 $\bar\alpha_3$, 데이터 배율 $\sqrt{\bar\alpha_3}$, 잡음 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $1 - \bar\alpha_3$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\beta = 0.2$ (모든 단계의 잡음 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0))
- $t = 3$ (단계 수)

**풀이**
1. 식을 그대로 쓴다: $\bar\alpha_t = \prod_{s=1}^{t}(1 - \beta_s)$
2. 값을 대입한다: $\bar\alpha_3 = (1 - 0.2)(1 - 0.2)(1 - 0.2)$ (곱 기호를 세 항으로 풀어 썼다)
3. 괄호 안을 뺀다: $1 - 0.2 = 0.8$ 이므로 $\bar\alpha_3 = 0.8 \times 0.8 \times 0.8$
4. 곱한다: $0.8 \times 0.8 = 0.64$, $0.64 \times 0.8 = 0.512$
5. 데이터 배율: $\sqrt{0.512} = 0.7155$
6. 잡음 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0): $1 - 0.512 = 0.488$

**답**: $\bar\alpha_3 = 0.512$, 데이터 배율 $0.7155$, 잡음 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $0.488$

</details>

### 문제 4

$x_0 = 3$에 $\beta = 0.2$로 2단계 잡음을 더한 결과를 한 번에 구한다. 합친 잡음이 $\epsilon = -0.5$일 때 $x_2$는?

<details><summary>풀이와 답</summary>

**주어진 값**
- $x_0 = 3$ (원래 데이터 값)
- $\beta = 0.2$, $t = 2$
- $\epsilon = -0.5$ (합친 표준 정규 잡음)

**풀이**
1. 식을 그대로 쓴다: $x_t = \sqrt{\bar\alpha_t}\, x_0 + \sqrt{1 - \bar\alpha_t}\, \epsilon$, $\bar\alpha_t = \prod_{s=1}^{t}(1 - \beta_s)$
2. 값을 대입한다: $x_2 = \sqrt{\bar\alpha_2} \times 3 + \sqrt{1 - \bar\alpha_2} \times (-0.5)$, $\bar\alpha_2 = (1 - 0.2)(1 - 0.2)$
3. 곱한다: $0.8 \times 0.8 = 0.64$
4. 제곱근을 구한다: $\sqrt{0.64} = 0.8$
5. 1에서 뺀다: $1 - 0.64 = 0.36$, 제곱근 $\sqrt{0.36} = 0.6$
6. 앞 항을 곱한다: $0.8 \times 3 = 2.4$
7. 뒤 항을 곱한다: $0.6 \times (-0.5) = -0.3$
8. 더한다: $2.4 + (-0.3) = 2.1$

**답**: $x_2 = 2.1$

</details>

### 문제 5

$\beta = 0.36$으로 두 단계를 갈 때 한 번에 쓰는 식의 데이터 배율이 한 단계 배율을 두 번 곱한 값과 같은지 확인하라. $\bar\alpha_2$, $\sqrt{\bar\alpha_2}$, 한 단계 배율 $\sqrt{1 - \beta}$의 제곱을 구하고, 합쳐진 잡음 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $1 - \bar\alpha_2$도 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\beta = 0.36$ (모든 단계의 잡음 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0))
- $t = 2$ (단계 수)
- 한 단계 배율 $\sqrt{1 - \beta} = \sqrt{0.64} = 0.8$

**풀이**
1. 식을 그대로 쓴다: $\bar\alpha_2 = (1 - \beta)(1 - \beta)$
2. 값을 대입한다: $\bar\alpha_2 = (1 - 0.36)(1 - 0.36)$
3. 괄호 안을 뺀다: $1 - 0.36 = 0.64$ 이므로 $\bar\alpha_2 = 0.64 \times 0.64$
4. 곱한다: $0.64 \times 0.64 = 0.4096$
5. 제곱근을 구한다: $\sqrt{0.4096} = 0.64$
6. 한 단계 배율을 두 번 곱한다: $0.8 \times 0.8 = 0.64$ → 같다
7. 합쳐진 잡음 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 구한다: $1 - 0.4096 = 0.5904$
8. 검산한다. 첫 단계 잡음([분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) 0.36)은 둘째 단계에서 $0.8$배가 되어 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)이 $0.8^2 = 0.64$배, 거기에 둘째 단계 잡음 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $0.36$이 더해진다: $0.64 \times 0.36 + 0.36 = 0.2304 + 0.36 = 0.5904$ → 같다

**답**: $\bar\alpha_2 = 0.4096$, $\sqrt{\bar\alpha_2} = 0.64 = 0.8 \times 0.8$, 잡음 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $0.5904$. 두 단계를 한 번에 쓰는 식이 단계별 계산과 일치한다.

</details>

### 문제 6

데이터의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)이 $v_0 = 9$이고 $\beta = 0.1$이다. 매 단계 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)이 $v_t = (1 - \beta)\, v_{t-1} + \beta$로 바뀔 때 3단계 뒤 $v_3$을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $v_0 = 9$ (처음 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0))
- $\beta = 0.1$ (잡음 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0))
- $t = 3$ (단계 수)

**풀이**
1. 식을 그대로 쓴다: $v_t = (1 - \beta)\, v_{t-1} + \beta$
2. 값을 대입한다 ($t = 1$): $v_1 = (1 - 0.1) \times 9 + 0.1$
3. 곱하고 더한다: $0.9 \times 9 = 8.1$, $8.1 + 0.1 = 8.2$
4. 값을 대입한다 ($t = 2$): $v_2 = 0.9 \times 8.2 + 0.1$
5. 곱하고 더한다: $0.9 \times 8.2 = 7.38$, $7.38 + 0.1 = 7.48$
6. 값을 대입한다 ($t = 3$): $v_3 = 0.9 \times 7.48 + 0.1$
7. 곱하고 더한다: $0.9 \times 7.48 = 6.732$, $6.732 + 0.1 = 6.832$

**답**: $v_3 = 6.832$ (9 → 8.2 → 7.48 → 6.832로 1을 향해 줄어든다)

</details>

### 문제 7

데이터가 상수라 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)이 $v_0 = 0$이다. $\beta = 0.1$로 3단계 가면 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $v_1, v_2, v_3$은? ($v_t = (1 - \beta)\, v_{t-1} + \beta$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $v_0 = 0$ (처음 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0))
- $\beta = 0.1$ (잡음 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0))

**풀이**
1. 식을 그대로 쓴다: $v_t = (1 - \beta)\, v_{t-1} + \beta$
2. 값을 대입한다 ($t = 1$): $v_1 = 0.9 \times 0 + 0.1$
3. 계산한다: $0 + 0.1 = 0.1$
4. 값을 대입한다 ($t = 2$): $v_2 = 0.9 \times 0.1 + 0.1$
5. 계산한다: $0.09 + 0.1 = 0.19$

</details>

### 문제 8

$\beta = 0.1$로 $t = 20$단계 간 뒤 $\bar\alpha_{20}$, 데이터 배율, 잡음 배율 $\sqrt{1 - \bar\alpha_{20}}$를 구하라. ($0.9^{10} = 0.3487$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $\beta = 0.1$ (잡음 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0))
- $t = 20$ (단계 수)
- $0.9^{10} = 0.3487$ (계산을 줄이기 위한 값)

**풀이**
1. 식을 그대로 쓴다: $\bar\alpha_t = (1 - \beta)^t$
2. 값을 대입한다: $\bar\alpha_{20} = (1 - 0.1)^{20}$
3. 괄호 안을 뺀다: $1 - 0.1 = 0.9$ 이므로 $\bar\alpha_{20} = 0.9^{20}$
4. 반으로 나눠 쓴다: $0.9^{20} = 0.9^{10} \times 0.9^{10}$
5. 곱한다: $0.3487 \times 0.3487 = 0.1216$
6. 데이터 배율: $\sqrt{0.1216} = 0.3487$ (정확히 $0.9^{10}$)
7. 잡음 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0): $1 - 0.1216 = 0.8784$
8. 잡음 배율: $\sqrt{0.8784} = 0.9372$

**답**: $\bar\alpha_{20} = 0.1216$, 데이터 배율 $0.3487$, 잡음 배율 $0.9372$. 20단계 뒤에는 원래 데이터가 약 35%만 남는다.

</details>

### 문제 9

[Lec14 8.2](../../Lec14_%EC%83%9D%EC%84%B1_%EB%AA%A8%EB%8D%B8_%EA%B8%B0%EC%B4%88.md#82-%EA%B0%80%EC%9A%B0%EC%8B%9C%EC%95%88-%ED%99%95%EC%82%B0%EC%9D%98-%EC%88%98%EC%8B%9D)의 $q(x_t \mid x_{t-1}) = \mathcal{N}\big(\sqrt{1 - \beta_t}\, x_{t-1},\ \beta_t\big)$를 쓴다. $x_{t-1} = 5$, $\beta_t = 0.36$일 때 이 [정규분포](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#normal-distribution-%EC%A0%95%EA%B7%9C%EB%B6%84%ED%8F%AC)의 평균과 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 구하고, $x_t = 4.6$에서의 밀도를 구하라. (정규 밀도: $\dfrac{1}{\sqrt{2\pi\sigma^2}}\exp\!\Big(-\dfrac{(x - \mu)^2}{2\sigma^2}\Big)$, $\pi = 3.1416$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $x_{t-1} = 5$ (한 단계 전 값)
- $\beta_t = 0.36$ ([분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0))
- $x_t = 4.6$ (밀도를 잴 위치)

**풀이**
1. 식을 그대로 쓴다: $q(x_t \mid x_{t-1}) = \mathcal{N}\big(\sqrt{1 - \beta_t}\, x_{t-1},\ \beta_t\big)$
2. 값을 대입한다: $q(x_t \mid 5) = \mathcal{N}\big(\sqrt{1 - 0.36} \times 5,\ 0.36\big)$
3. 평균을 구한다: $\sqrt{0.64} = 0.8$, $0.8 \times 5 = 4$
4. [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)은 $0.36$, 표준편차는 $\sqrt{0.36} = 0.6$
5. 밀도 식을 쓴다: $\dfrac{1}{\sqrt{2\pi\sigma^2}}\exp\!\Big(-\dfrac{(x - \mu)^2}{2\sigma^2}\Big)$ 에 $x = 4.6$, $\mu = 4$, $\sigma^2 = 0.36$을 넣는다: $\dfrac{1}{\sqrt{2\pi \times 0.36}}\exp\!\Big(-\dfrac{(4.6 - 4)^2}{2 \times 0.36}\Big)$
6. 앞 인수: $2 \times 3.1416 \times 0.36 = 2.2619$, $\sqrt{2.2619} = 1.5040$, $1 / 1.5040 = 0.6649$
7. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98) 안: $(4.6 - 4)^2 = 0.36$, $2 \times 0.36 = 0.72$ 이므로 $-0.36/0.72 = -0.5$
8. $\exp$를 계산한다: $e^{-0.5} = 0.6065$ ($e$는 약 2.718)
9. 곱한다: $0.6649 \times 0.6065 = 0.4033$ (반올림 전 값으로 계산)

**답**: 평균 $4$, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $0.36$, $x_t = 4.6$에서의 밀도 $0.4033$. 이전 값 5가 $0.8$배로 줄어 4 근처에 모이고 잡음이 폭 $0.6$으로 퍼진다.

</details>

### 문제 10

[Lec14 8.1](../../Lec14_%EC%83%9D%EC%84%B1_%EB%AA%A8%EB%8D%B8_%EA%B8%B0%EC%B4%88.md#81-%EB%8D%B0%EC%9D%B4%ED%84%B0%EB%A5%BC-%EC%9E%A1%EC%9D%8C%EC%9C%BC%EB%A1%9C-%EC%9E%A1%EC%9D%8C%EC%9D%84-%EB%8D%B0%EC%9D%B4%ED%84%B0%EB%A1%9C)은 충분히 많은 단계 뒤 데이터가 순수 잡음이 된다고 한다. $\beta = 0.1$, $t = 100$에서 $\bar\alpha_{100} = 0.9^{100} = 0.0000266$($2.66 \times 10^{-5}$)이다. $x_0 = 2$, $\epsilon = 0.5$일 때 $x_{100}$을 구하고 거의 $\epsilon$ 그대로인지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x_0 = 2$ (원래 데이터 값)
- $\bar\alpha_{100} = 0.0000266$ (남은 데이터 몫)
- $\epsilon = 0.5$ (합친 잡음)

**풀이**
1. 식을 그대로 쓴다: $x_t = \sqrt{\bar\alpha_t}\, x_0 + \sqrt{1 - \bar\alpha_t}\, \epsilon$
2. 값을 대입한다: $x_{100} = \sqrt{0.0000266} \times 2 + \sqrt{1 - 0.0000266} \times 0.5$
3. 데이터 배율: $\sqrt{0.0000266} = 0.0052$
4. 앞 항을 곱한다: $0.0052 \times 2 = 0.0103$ (반올림 전 값으로 계산)
5. 잡음 배율: $1 - 0.0000266 = 0.9999734$, 제곱근 $\sqrt{0.9999734} = 1.0$ (소수 넷째 자리까지)
6. 뒤 항을 곱한다: $1.0 \times 0.5 = 0.5$
7. 더한다: $0.0103 + 0.5 = 0.5103$

**답**: $x_{100} = 0.5103$. 값 0.5103 중 데이터가 만든 몫은 $0.0103$뿐이고 나머지는 잡음 $\epsilon = 0.5$다. 데이터는 거의 지워져 $\mathcal{N}(0, 1)$ 잡음만 남는다. 그래서 표본을 만들 때 $\mathcal{N}(0, 1)$에서 출발할 수 있다.

</details>
