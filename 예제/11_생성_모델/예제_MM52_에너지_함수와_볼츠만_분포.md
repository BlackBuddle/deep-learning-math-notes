# 예제: 에너지 함수와 볼츠만 분포

개념 노트: [MM52_에너지_함수와_볼츠만_분포](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/11_%EC%83%9D%EC%84%B1_%EB%AA%A8%EB%8D%B8/MM52_%EC%97%90%EB%84%88%EC%A7%80_%ED%95%A8%EC%88%98%EC%99%80_%EB%B3%BC%EC%B8%A0%EB%A7%8C_%EB%B6%84%ED%8F%AC.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. [볼츠만 분포](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#boltzmann-distribution-%EB%B3%BC%EC%B8%A0%EB%A7%8C-%EB%B6%84%ED%8F%AC)는 $p(x) = e^{-E(x)}/Z$, $Z = \sum_x e^{-E(x)}$이고 $e$는 약 2.718이다($e^{-a} = 1/e^{a}$).

## 기본 (직접 대입)

### 문제 1

상태가 두 개이고 에너지가 $E = (0, 2)$이다. [분할 함수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#partition-function-%EB%B6%84%ED%95%A0-%ED%95%A8%EC%88%98) $Z$와 각 상태의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $E(x_1) = 0$, $E(x_2) = 2$ (두 상태의 에너지)

**풀이**
1. 식을 그대로 쓴다: $p(x) = \dfrac{e^{-E(x)}}{Z}$, $Z = \sum_x e^{-E(x)}$
2. 값을 대입한다: $p(x_1) = \dfrac{e^{-0}}{e^{-0} + e^{-2}}$, $p(x_2) = \dfrac{e^{-2}}{e^{-0} + e^{-2}}$ (Σ를 두 항으로 풀어 썼다)
3. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다. 0제곱은 1이다: $e^{-0} = 1$
4. $e^{-2} = 1/2.718^2 = 0.1353$
5. 더해서 $Z$를 구한다: $Z = 1 + 0.1353 = 1.1353$
6. 첫 상태를 나눈다: $1 / 1.1353 = 0.8808$
7. 둘째 상태를 나눈다: $0.1353 / 1.1353 = 0.1192$

**답**: $Z = 1.1353$, $p = (0.8808,\ 0.1192)$. 에너지가 낮은 상태가 더 그럴듯하다.

</details>

### 문제 2

상태가 세 개이고 에너지가 모두 같아 $E = (1, 1, 1)$이다. 각 상태의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $E(x_1) = E(x_2) = E(x_3) = 1$ (세 상태의 에너지)

**풀이**
1. 식을 그대로 쓴다: $p(x) = \dfrac{e^{-E(x)}}{Z}$, $Z = \sum_x e^{-E(x)}$
2. 값을 대입한다: $p(x_1) = \dfrac{e^{-1}}{e^{-1} + e^{-1} + e^{-1}}$ ($x_2$, $x_3$도 같다)
3. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^{-1} = 0.3679$
4. 더해서 $Z$를 구한다: $0.3679 + 0.3679 + 0.3679 = 1.1036$
5. 나눈다: $0.3679 / 1.1036 = 0.3333$

**답**: $p = (0.3333,\ 0.3333,\ 0.3333)$. 에너지가 모두 같으면 모든 상태가 똑같이 그럴듯하다.

</details>

### 문제 3

"내일 맑음"의 에너지는 1, "내일 폭설"의 에너지는 4이다. $Z$를 모를 때 맑음이 폭설보다 몇 배 그럴듯한가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $E(x_1) = 1$ (맑음의 에너지)
- $E(x_2) = 4$ (폭설의 에너지)

**풀이**
1. 식을 그대로 쓴다: $\dfrac{p(x_1)}{p(x_2)} = e^{E(x_2) - E(x_1)}$
2. 값을 대입한다: $\dfrac{p(x_1)}{p(x_2)} = e^{4 - 1}$
3. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98) 안을 뺀다: $4 - 1 = 3$
4. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다 ($e^3 = 2.718 \times 2.718 \times 2.718$): $e^3 = 20.0855$

**답**: 맑음이 폭설보다 **20.0855배** 그럴듯하다. $Z$는 쓰지 않았다.

</details>

### 문제 4

에너지를 $E = (0, 1)$에서 $E = (2, 3)$으로 모두 2씩 올려도 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 그대로인지 $E = (2, 3)$의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구해 확인하라. ($E = (0, 1)$의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은 $(0.7311,\ 0.2689)$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $E(x_1) = 2$, $E(x_2) = 3$ (올린 에너지)
- 비교 대상 $p = (0.7311,\ 0.2689)$ ($E = (0, 1)$일 때)

**풀이**
1. 식을 그대로 쓴다: $p(x) = \dfrac{e^{-E(x)}}{Z}$, $Z = \sum_x e^{-E(x)}$
2. 값을 대입한다: $p(x_1) = \dfrac{e^{-2}}{e^{-2} + e^{-3}}$, $p(x_2) = \dfrac{e^{-3}}{e^{-2} + e^{-3}}$
3. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^{-2} = 0.1353$, $e^{-3} = 0.0498$
4. 더해서 $Z$를 구한다: $0.1353 + 0.0498 = 0.1851$
5. 첫 상태를 나눈다: $0.1353 / 0.1851 = 0.7311$
6. 둘째 상태를 나눈다: $0.0498 / 0.1851 = 0.2689$

**답**: $p = (0.7311,\ 0.2689)$로 그대로다. 에너지 전체를 올리거나 내려도 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 변하지 않는다. 에너지의 차이만 중요하다.

</details>

### 문제 5

상태가 세 개이고 에너지가 $E = (0, 0.5, 2)$이다. 각 상태의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $E(x_1) = 0$, $E(x_2) = 0.5$, $E(x_3) = 2$ (세 상태의 에너지)

**풀이**
1. 식을 그대로 쓴다: $p(x) = \dfrac{e^{-E(x)}}{Z}$, $Z = \sum_x e^{-E(x)}$
2. 값을 대입한다: $p(x_1) = \dfrac{e^{-0}}{e^{-0} + e^{-0.5} + e^{-2}}$ (Σ를 세 항으로 풀어 썼다. $x_2$, $x_3$도 분자만 바뀐다)
3. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^{-0} = 1$
4. $e^{-0.5} = 0.6065$
5. $e^{-2} = 0.1353$
6. 더해서 $Z$를 구한다: $1 + 0.6065 + 0.1353 = 1.7418$
7. 첫 상태를 나눈다: $1 / 1.7418 = 0.5741$
8. 둘째 상태를 나눈다: $0.6065 / 1.7418 = 0.3482$
9. 셋째 상태를 나눈다: $0.1353 / 1.7418 = 0.0777$

**답**: $p = (0.5741,\ 0.3482,\ 0.0777)$. 세 값을 더하면 1이다.

</details>

### 문제 6

문제 5의 에너지 $E = (0, 0.5, 2)$에서 상태 1이 상태 3보다 몇 배 그럴듯한지를 (가) 에너지 차이로, (나) 문제 5의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) $(0.5741,\ 0.3482,\ 0.0777)$로 각각 구해 같음을 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $E(x_1) = 0$, $E(x_3) = 2$ (에너지)
- $p(x_1) = 0.5741$, $p(x_3) = 0.0777$ (문제 5의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))

**풀이**
1. (가) 식을 그대로 쓴다: $\dfrac{p(x_1)}{p(x_3)} = e^{E(x_3) - E(x_1)}$
2. 값을 대입한다: $\dfrac{p(x_1)}{p(x_3)} = e^{2 - 0}$
3. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98) 안을 뺀다: $2 - 0 = 2$
4. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^2 = 7.3891$
5. (나) [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 직접 나눈다: $\dfrac{p(x_1)}{p(x_3)} = \dfrac{0.5741}{0.0777}$
6. 나눈다: $0.5741 / 0.0777 = 7.389$

**답**: 두 방법 모두 약 **7.389배**. [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)로 계산하려면 $Z$가 필요하지만 에너지 차이로는 $Z$ 없이 같은 값을 얻는다.

</details>

### 문제 7

[분류](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#regression-classification-%ED%9A%8C%EA%B7%80%EC%99%80-%EB%B6%84%EB%A5%98) 모델의 [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93)이 $(2, 1, 0)$이다. [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93)을 "마이너스 에너지"($E = -\text{로짓}$)로 보고 [볼츠만 분포](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#boltzmann-distribution-%EB%B3%BC%EC%B8%A0%EB%A7%8C-%EB%B6%84%ED%8F%AC)로 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구하라. ([소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)와 같은지 확인한다.)

<details><summary>풀이와 답</summary>

**주어진 값**
- [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93) $(2, 1, 0)$
- $E = -\text{로짓} = (-2, -1, 0)$ (에너지)

**풀이**
1. 식을 그대로 쓴다: $p(x) = \dfrac{e^{-E(x)}}{Z}$, $Z = \sum_x e^{-E(x)}$
2. 값을 대입한다: $p(x_1) = \dfrac{e^{2}}{e^{2} + e^{1} + e^{0}}$ ($-E = $ [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93)이므로 [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)는 [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93) 그대로다)
3. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^{2} = 7.3891$, $e^{1} = 2.7183$, $e^{0} = 1$
4. 더해서 $Z$를 구한다: $7.3891 + 2.7183 + 1 = 11.1073$
5. 첫 상태를 나눈다: $7.3891 / 11.1073 = 0.6652$
6. 둘째 상태를 나눈다: $2.7183 / 11.1073 = 0.2447$
7. 셋째 상태를 나눈다: $1 / 11.1073 = 0.0900$

**답**: $p = (0.6652,\ 0.2447,\ 0.0900)$. [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)(각 $e^{\text{로짓}}$을 합으로 나눈 값)와 똑같다. [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)의 [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93)이 마이너스 에너지다.

</details>

### 문제 8

상태마다 에너지 매개변수를 하나씩 둔다($E(x_k) = \theta_k$). 지금 $\theta = (0, 0, 0)$이고 [학습 데이터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-data-test-data-%ED%95%99%EC%8A%B5-%EB%8D%B0%EC%9D%B4%ED%84%B0%EC%99%80-%EC%8B%9C%ED%97%98-%EB%8D%B0%EC%9D%B4%ED%84%B0)의 비율은 $f = (0.5, 0.25, 0.25)$이다. 평균 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8) [우도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#likelihood-%EC%9A%B0%EB%8F%84)의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $\partial/\partial\theta_k = -f_k + p_\theta(x_k)$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\theta = (0, 0, 0)$ (현재 에너지)
- $f = (0.5, 0.25, 0.25)$ (데이터에서 각 상태의 비율)

**풀이**
1. 식을 그대로 쓴다: $\dfrac{\partial}{\partial \theta_k} = -f_k + p_\theta(x_k)$
2. 모델 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구한다: 에너지가 모두 0이라 $e^{-0} = 1$ 세 개, $Z = 1 + 1 + 1 = 3$
3. 나눈다: $p_\theta(x_k) = 1/3 = 0.3333$ (세 상태 모두)
4. 값을 대입한다: $\dfrac{\partial}{\partial \theta_1} = -0.5 + 0.3333$, $\dfrac{\partial}{\partial \theta_2} = -0.25 + 0.3333$, $\dfrac{\partial}{\partial \theta_3} = -0.25 + 0.3333$
5. 상태 1을 더한다: $-0.5 + 0.3333 = -0.1667$
6. 상태 2를 더한다: $-0.25 + 0.3333 = 0.0833$
7. 상태 3을 더한다: $-0.25 + 0.3333 = 0.0833$

**답**: [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $(-0.1667,\ 0.0833,\ 0.0833)$. 경사 상승은 $\theta_1$을 줄이고(상태 1의 에너지를 낮춰 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 올림) $\theta_2$, $\theta_3$을 늘린다(에너지를 높여 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 내림). 데이터 비율이 모델 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)보다 큰 상태 1이 더 그럴듯해지도록 움직인다.

</details>

### 문제 9

[Lec14 6.1](../../Lec14_%EC%83%9D%EC%84%B1_%EB%AA%A8%EB%8D%B8_%EA%B8%B0%EC%B4%88.md#61-%EB%B3%BC%EC%B8%A0%EB%A7%8C-%EB%B6%84%ED%8F%AC%EC%99%80-%EC%97%90%EB%84%88%EC%A7%80-%EB%B9%84%EC%9C%A8)은 [분할 함수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#partition-function-%EB%B6%84%ED%95%A0-%ED%95%A8%EC%88%98) $Z$가 모든 $x$를 훑어야 해서 고차원에서 계산할 수 없다고 한다. 흑백 칸이 $n$개인 이미지는 $2^n$가지다. $n = 10$, $n = 20$일 때 $Z$의 항 개수를 구하고, $28 \times 28 = 784$칸이면 항이 약 $10^{k}$개일 때의 $k$를 구하라. ($\log_{10} 2 = 0.30103$)

<details><summary>풀이와 답</summary>

**주어진 값**
- 칸 개수 $n = 10$, $20$, $784$
- 항 개수 $= 2^n$ (각 칸이 흑 또는 백)
- $\log_{10} 2 = 0.30103$ ($2$를 $10$의 몇 제곱으로 쓰는가)

**풀이**
1. 식을 그대로 쓴다: 항 개수 $= 2^n$
2. 값을 대입한다 ($n = 10$): $2^{10}$
3. 곱한다: $2 \times 2 \times \cdots \times 2$ (열 번) $= 1024$
4. 값을 대입한다 ($n = 20$): $2^{20} = 2^{10} \times 2^{10}$
5. 곱한다: $1024 \times 1024 = 1048576$
6. 값을 대입한다 ($n = 784$): $2^{784} = 10^{784 \times \log_{10} 2}$
7. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 곱한다: $784 \times 0.30103 = 236.0$

**답**: $n = 10$이면 $1024$개, $n = 20$이면 $1048576$개, $n = 784$이면 약 $10^{236}$개. 칸 20개만 늘어도 백만 항이니 784칸은 어떤 컴퓨터로도 $Z$를 직접 더할 수 없다. 그래서 $Z$를 지우는 에너지 비율을 쓴다.

</details>

### 문제 10

[Lec14 6.2](../../Lec14_%EC%83%9D%EC%84%B1_%EB%AA%A8%EB%8D%B8_%EA%B8%B0%EC%B4%88.md#62-%EB%8C%80%EC%A1%B0-%EB%B0%9C%EC%82%B0)의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)로 한 걸음 학습해 보자. $\theta = (0, 1)$이고 모델 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은 $(0.7311,\ 0.2689)$, 데이터 비율은 $f = (0.5, 0.5)$이다. [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $-f_k + p_k$를 구하고, [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0) $0.5$로 $\theta_{\text{새}} = \theta + 0.5 \times \text{기울기}$를 구해 새 모델 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 데이터 비율에 가까워졌는지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\theta = (0, 1)$ (현재 에너지)
- $p_\theta = (0.7311,\ 0.2689)$ (현재 모델 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $f = (0.5, 0.5)$ (데이터 비율)
- [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0) $0.5$

**풀이**
1. 식을 그대로 쓴다: $\dfrac{\partial}{\partial \theta_k} = -f_k + p_\theta(x_k)$, $\theta_{\text{새}} = \theta + 0.5 \times \text{기울기}$
2. 값을 대입한다: $\dfrac{\partial}{\partial \theta_1} = -0.5 + 0.7311$, $\dfrac{\partial}{\partial \theta_2} = -0.5 + 0.2689$
3. 상태 1을 더한다: $-0.5 + 0.7311 = 0.2311$
4. 상태 2를 더한다: $-0.5 + 0.2689 = -0.2311$
5. [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0)을 곱한다: $0.5 \times 0.2311 = 0.1155$, $0.5 \times (-0.2311) = -0.1155$
6. 더한다: $\theta_{\text{새}} = (0 + 0.1155,\ 1 - 0.1155) = (0.1155,\ 0.8845)$
7. 새 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구한다: $e^{-0.1155} = 0.8909$, $e^{-0.8845} = 0.4129$
8. 더해서 $Z$를 구한다: $0.8909 + 0.4129 = 1.3038$
9. 나눈다: $0.8909 / 1.3038 = 0.6833$, $0.4129 / 1.3038 = 0.3167$

**답**: [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $(0.2311,\ -0.2311)$, 새 $\theta = (0.1155,\ 0.8845)$, 새 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) $(0.6833,\ 0.3167)$. 처음의 $(0.7311,\ 0.2689)$보다 데이터 비율 $(0.5, 0.5)$에 가까워졌다. 모델 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 데이터 비율과 같아지면 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 0이 되어 멈춘다.

</details>
