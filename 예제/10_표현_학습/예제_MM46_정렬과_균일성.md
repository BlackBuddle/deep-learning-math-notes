## 기본 (직접 대입)

### 문제 1

양성 쌍 하나의 표현이 $f(x) = (1, 0)$, $f(y) = (0.8, 0.6)$이다. $\alpha = 2$일 때 정렬 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $\mathcal{L}_{\text{align}}$을 구하라. (쌍이 하나뿐이면 평균은 그 쌍의 값 자체다.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $f(x) = (1, 0)$ (쌍의 앞 표현)
- $f(y) = (0.8, 0.6)$ (쌍의 뒤 표현)
- 쌍 개수 1 (그래서 평균 $\mathbb{E}$ = 그 쌍의 값)

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_{\text{align}} = \mathbb{E}\big[\|f(x) - f(y)\|_2^2\big]$
2. 값을 대입한다: $\mathcal{L}_{\text{align}} = \|(1, 0) - (0.8, 0.6)\|_2^2$
3. 칸별로 뺀다: $(1 - 0.8,\ 0 - 0.6) = (0.2, -0.6)$
4. 칸별로 제곱한다: $0.2^2 = 0.04$, $(-0.6)^2 = 0.36$
5. 더한다: $0.04 + 0.36 = 0.4$

**답**: $\mathcal{L}_{\text{align}} = 0.4$ (0에 가까울수록 두 표현이 붙어 있다)

</details>

### 문제 2

양성 쌍 4개가 다음과 같다. 정렬 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $\mathcal{L}_{\text{align}}$을 구하라.

- 쌍 A: $(1, 0)$, $(0.6, 0.8)$
- 쌍 B: $(0, 1)$, $(0, 1)$
- 쌍 C: $(0, -1)$, $(0.6, -0.8)$
- 쌍 D: $(-1, 0)$, $(-0.6, -0.8)$

<details><summary>풀이와 답</summary>

**주어진 값**
- 쌍 A, B, C, D (위 네 쌍)
- $n = 4$ (양성 쌍 개수)

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_{\text{align}} = \dfrac{1}{n}\sum_{k=1}^{n}\|f(x_k) - f(y_k)\|^2$
2. 값을 대입한다: $\mathcal{L}_{\text{align}} = \dfrac{1}{4}\sum_{k=1}^{4}\|f(x_k) - f(y_k)\|^2$
3. Σ를 네 항으로 풀어 쓴다: $\dfrac{1}{4}\big(d_A + d_B + d_C + d_D\big)$ ($d$는 각 쌍의 거리 제곱)
4. 쌍 A를 칸별로 뺀다: $(1 - 0.6,\ 0 - 0.8) = (0.4, -0.8)$ → 제곱해 더하면 $0.16 + 0.64 = 0.8$
5. 쌍 B를 칸별로 뺀다: $(0 - 0,\ 1 - 1) = (0, 0)$ → $d_B = 0$
6. 쌍 C를 칸별로 뺀다: $(0 - 0.6,\ -1 - (-0.8)) = (-0.6, -0.2)$ → 제곱해 더하면 $0.36 + 0.04 = 0.4$
7. 쌍 D를 칸별로 뺀다: $(-1 - (-0.6),\ 0 - (-0.8)) = (-0.4, 0.8)$ → 제곱해 더하면 $0.16 + 0.64 = 0.8$
8. 네 값을 더한다: $0.8 + 0 + 0.4 + 0.8 = 2.0$
9. 쌍 개수로 나눈다: $2.0 / 4 = 0.5$

**답**: $\mathcal{L}_{\text{align}} = 0.5$

</details>

### 문제 3

균일성 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)에 쓰는 가우스 퍼텐셜 $e^{-t\|f(x) - f(y)\|^2}$을 구하라. 두 표본 사이 거리 제곱이 $0.5$, $t = 2$이다.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\|f(x) - f(y)\|^2 = 0.5$ (두 표현 사이 거리의 제곱)
- $t = 2$ (퍼텐셜의 [날카로움](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sharpness-%EB%82%A0%EC%B9%B4%EB%A1%9C%EC%9B%80))

**풀이**
1. 식을 그대로 쓴다: $G_t = e^{-t\|f(x) - f(y)\|^2}$
2. 값을 대입한다: $G_t = e^{-2 \times 0.5}$
3. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98) 안을 곱한다: $-2 \times 0.5 = -1$ 이므로 $G_t = e^{-1}$
4. $e$의 거듭제곱을 계산한다. $e$는 약 2.718이고 $e^{-1} = 1 / e$이다: $1 / 2.718 = 0.3679$

**답**: $G_t = 0.3679$ (거리가 0이면 1, 멀수록 0에 가깝다. 지금은 꽤 가까운 쌍이라 0.37이다)

</details>

### 문제 4

단위 원 위에 점이 두 개뿐이고 사이각이 $60°$이다. 점은 $(1, 0)$과 $(\cos 60°, \sin 60°) = (0.5, 0.8660)$이다. $t = 2$일 때 균일성 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $\mathcal{L}_{\text{uniform}}$을 구하라. (서로 다른 쌍은 하나뿐이다.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $f_1 = (1, 0)$, $f_2 = (0.5, 0.8660)$ (두 점)
- $t = 2$ (퍼텐셜의 [날카로움](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sharpness-%EB%82%A0%EC%B9%B4%EB%A1%9C%EC%9B%80))

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_{\text{uniform}} = \log \mathbb{E}\big[e^{-t\|f(x) - f(y)\|_2^2}\big]$
2. 값을 대입한다: $\mathcal{L}_{\text{uniform}} = \log \mathbb{E}\big[e^{-2\|(1, 0) - (0.5, 0.8660)\|_2^2}\big]$
3. 쌍이 하나뿐이라 평균은 그 값 하나다
4. 칸별로 뺀다: $(1 - 0.5,\ 0 - 0.8660) = (0.5, -0.8660)$
5. 칸별로 제곱해 더한다: $0.5^2 + (-0.8660)^2 = 0.25 + 0.75 = 1$
6. $-t$를 곱한다: $-2 \times 1 = -2$ 이므로 $\mathbb{E} = e^{-2}$
7. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 계산한다. $\ln$은 "$e$를 몇 제곱해야 그 수가 되는가"이므로 $\ln e^{-2} = -2$

**답**: $\mathcal{L}_{\text{uniform}} = -2$

</details>

### 문제 5

단위 원 위의 점 3개가 $0°$, $60°$, $120°$에 있다. 점은 $(1, 0)$, $(0.5, 0.8660)$, $(-0.5, 0.8660)$이다. $t = 1$일 때 $\mathcal{L}_{\text{uniform}}$을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $f_1 = (1, 0)$, $f_2 = (0.5, 0.8660)$, $f_3 = (-0.5, 0.8660)$ (세 점)
- $t = 1$ (퍼텐셜의 [날카로움](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sharpness-%EB%82%A0%EC%B9%B4%EB%A1%9C%EC%9B%80))
- 서로 다른 쌍 3개: (1, 2), (2, 3), (1, 3)

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_{\text{uniform}} = \log \dfrac{1}{\#\text{쌍}}\sum_{i<j} e^{-t\|f_i - f_j\|^2}$
2. 값을 대입한다: $\mathcal{L}_{\text{uniform}} = \log \dfrac{1}{3}\sum_{i<j} e^{-1 \times \|f_i - f_j\|^2}$
3. 쌍 (1, 2)의 거리 제곱: $(1 - 0.5)^2 + (0 - 0.8660)^2 = 0.25 + 0.75 = 1$
4. 쌍 (2, 3)의 거리 제곱: $(0.5 - (-0.5))^2 + (0.8660 - 0.8660)^2 = 1 + 0 = 1$
5. 쌍 (1, 3)의 거리 제곱: $(1 - (-0.5))^2 + (0 - 0.8660)^2 = 2.25 + 0.75 = 3$
6. 퍼텐셜을 계산한다: $e^{-1} = 0.3679$, $e^{-1} = 0.3679$, $e^{-3} = 0.0498$
7. Σ를 풀어 더한다: $0.3679 + 0.3679 + 0.0498 = 0.7856$
8. 쌍 개수로 나눈다: $0.7856 / 3 = 0.2619$
9. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 계산한다: $\ln 0.2619 = -1.3400$ (1보다 작은 수의 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)는 음수)

**답**: $\mathcal{L}_{\text{uniform}} = -1.3400$

</details>

### 문제 6

단위 원 위의 두 점이 $90°$ 떨어져 있다. 퍼텐셜의 [날카로움](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sharpness-%EB%82%A0%EC%B9%B4%EB%A1%9C%EC%9B%80) $t = 0.5$일 때와 $t = 2$일 때 $\mathcal{L}_{\text{uniform}}$을 각각 구하고, $t$가 클수록 값이 어떻게 달라지는지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 두 점 $(1, 0)$, $(0, 1)$ (사이각 $90°$)
- $t = 0.5$ 와 $t = 2$ (비교할 두 [날카로움](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sharpness-%EB%82%A0%EC%B9%B4%EB%A1%9C%EC%9B%80))

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_{\text{uniform}} = \log \mathbb{E}\big[e^{-t\|f(x) - f(y)\|^2}\big]$
2. 값을 대입한다 ($t = 0.5$): $\mathcal{L}_{\text{uniform}} = \log \mathbb{E}\big[e^{-0.5\|(1, 0) - (0, 1)\|^2}\big]$
3. 칸별로 뺀다: $(1 - 0,\ 0 - 1) = (1, -1)$
4. 칸별로 제곱해 더한다: $1^2 + (-1)^2 = 2$
5. $t = 0.5$를 곱한다: $-0.5 \times 2 = -1$ 이므로 $\ln e^{-1} = -1$
6. $t = 2$를 곱한다: $-2 \times 2 = -4$ 이므로 $\ln e^{-4} = -4$

**답**: $t = 0.5$일 때 $-1$, $t = 2$일 때 $-4$. $t$가 클수록 같은 거리도 "가깝지 않다"고 더 엄하게 보아 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 더 작아진다. $t$는 비교할 때 같은 값으로 고정해야 한다.

</details>

### 문제 7

단위 원 위의 점 4개가 $0°$, $90°$, $180°$, $270°$에 놓였다. $t = 1$일 때 $\mathcal{L}_{\text{uniform}}$을 구하라. (이웃한 쌍 4개는 거리 제곱 2, 마주 보는 쌍 2개는 거리 제곱 4이다.)

<details><summary>풀이와 답</summary>

**주어진 값**
- 점 4개: $(1, 0)$, $(0, 1)$, $(-1, 0)$, $(0, -1)$
- 서로 다른 쌍 6개: 이웃 4개(거리 제곱 2), 마주 보기 2개(거리 제곱 4)
- $t = 1$

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_{\text{uniform}} = \log \dfrac{1}{\#\text{쌍}}\sum_{i<j} e^{-t\|f_i - f_j\|^2}$
2. 값을 대입한다: $\mathcal{L}_{\text{uniform}} = \log \dfrac{1}{6}\sum_{i<j} e^{-1 \times \|f_i - f_j\|^2}$
3. Σ를 묶어 쓴다: $\dfrac{1}{6}\big(4 \times e^{-2} + 2 \times e^{-4}\big)$
4. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^{-2} = 0.1353$, $e^{-4} = 0.0183$
5. 곱한다: $4 \times 0.1353 = 0.5413$, $2 \times 0.0183 = 0.0366$
6. 더한다: $0.5413 + 0.0366 = 0.5779$
7. 쌍 개수로 나눈다: $0.5779 / 6 = 0.0963$
8. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 계산한다: $\ln 0.0963 = -2.3400$

**답**: $\mathcal{L}_{\text{uniform}} = -2.3400$ ($t = 2$일 때의 $-4.3963$보다 큰 이유는 $t$가 작아 벌이 약하기 때문이다)

</details>

### 문제 8

어떤 인코더가 모든 입력을 같은 점 $(1, 0)$으로 보낸다(붕괴). 입력 4개의 서로 다른 쌍 6개로 $t = 2$에서 $\mathcal{L}_{\text{uniform}}$을 구하고, 같은 인코더의 양성 쌍 정렬 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)도 말하라. 이 인코더는 좋은가?

<details><summary>풀이와 답</summary>

**주어진 값**
- 모든 표현 $f = (1, 0)$ (한 점)
- 서로 다른 쌍 6개
- $t = 2$

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_{\text{uniform}} = \log \dfrac{1}{\#\text{쌍}}\sum_{i<j} e^{-t\|f_i - f_j\|^2}$
2. 값을 대입한다: $\mathcal{L}_{\text{uniform}} = \log \dfrac{1}{6}\sum_{i<j} e^{-2\|(1, 0) - (1, 0)\|^2}$
3. 칸별로 뺀다: $(1 - 1,\ 0 - 0) = (0, 0)$
4. 거리 제곱: $0^2 + 0^2 = 0$
5. 퍼텐셜을 계산한다. 0제곱은 1이다: $e^{-2 \times 0} = e^{0} = 1$ (여섯 쌍 모두 같다)
6. Σ를 풀어 더한다: $1 + 1 + 1 + 1 + 1 + 1 = 6$
7. 쌍 개수로 나눈다: $6 / 6 = 1$
8. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 계산한다: $\ln 1 = 0$
9. 정렬: 양성 쌍의 두 표현도 같은 점이라 거리 제곱 0, 평균 $\mathcal{L}_{\text{align}} = 0$

**답**: $\mathcal{L}_{\text{uniform}} = 0$, $\mathcal{L}_{\text{align}} = 0$. 정렬은 최고인데 균일성은 가장 나쁜 값(0)이다. 모두 한 점이라 반끼리 구분이 안 되는 쓸모없는 표현이다. 같은 4개 점을 90° 간격으로 퍼뜨리면 $t = 2$에서 $-4.3963$이다.

</details>

### 문제 9

[Lec12 7.3](../../Lec12_%EC%9C%A0%EC%82%AC%EB%8F%84_%EA%B8%B0%EB%B0%98_%ED%91%9C%ED%98%84_%ED%95%99%EC%8A%B5.md#73-%EC%9D%8C%EC%84%B1-%ED%91%9C%EB%B3%B8%EC%9D%B4-%EB%AC%B4%ED%95%9C%ED%95%A0-%EB%95%8C)은 음성이 무한히 많을 때 대조 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 "정렬 항 + 균일성 항"으로 나뉜다고 한다. 두 인코더의 값이 아래와 같다. 두 항을 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) 없이 더한 점수(작을수록 좋다)로 비교해 어느 쪽이 나은지 말하라.

| 인코더 | $\mathcal{L}_{\text{align}}$ | $\mathcal{L}_{\text{uniform}}$ ($t = 2$) |
|---|---|---|
| 가 | 0.3 | -3.0 |
| 나 | 0.5 | -4.0 |

<details><summary>풀이와 답</summary>

**주어진 값**
- 인코더 가: 정렬 $0.3$, 균일성 $-3.0$
- 인코더 나: 정렬 $0.5$, 균일성 $-4.0$
- 점수 = 정렬 + 균일성 (대조 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 단순화한 비교용 값)

**풀이**
1. 식을 그대로 쓴다: 점수 $= \mathcal{L}_{\text{align}} + \mathcal{L}_{\text{uniform}}$
2. 값을 대입한다 (가): 점수 $= 0.3 + (-3.0)$
3. 더한다: $0.3 - 3.0 = -2.7$
4. 값을 대입한다 (나): 점수 $= 0.5 + (-4.0)$
5. 더한다: $0.5 - 4.0 = -3.5$
6. 비교한다: $-3.5 < -2.7$

**답**: 인코더 **나**가 낫다(점수 $-3.5$ 대 $-2.7$). 정렬은 조금 나쁘지만 균일성이 더 크게 좋아졌다. 실제 대조 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)에서는 두 항에 곱해지는 계수가 다를 수 있어서 이 합은 대략적인 비교용이다.

</details>

### 문제 10

[Lec12 8.3](../../Lec12_%EC%9C%A0%EC%82%AC%EB%8F%84_%EA%B8%B0%EB%B0%98_%ED%91%9C%ED%98%84_%ED%95%99%EC%8A%B5.md#83-%EB%B0%B0%EC%B9%98-%ED%81%AC%EA%B8%B0%EC%99%80-%EA%B1%B0%EC%A7%93-%EC%9D%8C%EC%84%B1)의 거짓 음성은 같은 반의 두 표본을 음성으로 취급해 서로 밀어내는 일이다. 단위 원 위에서 같은 반 두 점의 거리 제곱이 $0.2$였는데, 밀어내서 $90°$($(1, 0)$과 $(0, 1)$)가 되었다. $t = 2$에서 두 점만 놓고 본 $\mathcal{L}_{\text{uniform}}$이 얼마에서 얼마로 바뀌는지 구하고, 왜 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 줄었는데도 해가 되는지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 밀기 전 거리 제곱 $0.2$
- 민 뒤 두 점 $(1, 0)$, $(0, 1)$
- $t = 2$, 점 두 개이므로 쌍 하나

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_{\text{uniform}} = \log e^{-t\|f_1 - f_2\|^2}$ (쌍이 하나라 평균 생략)
2. 값을 대입한다 (밀기 전): $\mathcal{L}_{\text{uniform}} = \log e^{-2 \times 0.2}$
3. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98) 안을 곱한다: $-2 \times 0.2 = -0.4$ 이므로 $\ln e^{-0.4} = -0.4$
4. 값을 대입한다 (민 뒤): $\mathcal{L}_{\text{uniform}} = \log e^{-2\|(1, 0) - (0, 1)\|^2}$
5. 칸별로 뺀다: $(1 - 0,\ 0 - 1) = (1, -1)$
6. 칸별로 제곱해 더한다: $1^2 + (-1)^2 = 2$
7. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98) 안을 곱한다: $-2 \times 2 = -4$ 이므로 $\ln e^{-4} = -4$
8. 변화량을 구한다: $-4 - (-0.4) = -3.6$

**답**: $-0.4$에서 $-4$로 바뀌어 $3.6$ 줄었다. 균일성 항은 가까운 쌍에 벌을 주므로 같은 반 두 점도 멀리 밀수록 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 줄어든다. 그런데 이 쌍은 원래 가까워야 하므로(정렬이 나빠진다) 거짓 음성이 해가 된다.

</details>
