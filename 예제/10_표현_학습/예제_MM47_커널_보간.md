# 예제: 커널 보간과 RBF 커널

개념 노트: [MM47_커널_보간](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/10_%ED%91%9C%ED%98%84_%ED%95%99%EC%8A%B5/MM47_%EC%BB%A4%EB%84%90_%EB%B3%B4%EA%B0%84.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 따로 말이 없으면 커널은 $k(x, x') = e^{-(x - x')^2}$($2\ell^2 = 1$)이다.

## 기본 (직접 대입)

### 문제 1

커널 $k(x, x') = e^{-(x - x')^2}$에서 $k(1, 3)$을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x = 1$, $x' = 3$ (두 입력)
- $k(x, x') = e^{-(x - x')^2}$ (커널)

**풀이**
1. 식을 그대로 쓴다: $k(x, x') = e^{-(x - x')^2}$
2. 값을 대입한다: $k(1, 3) = e^{-(1 - 3)^2}$
3. 괄호 안을 뺀다: $1 - 3 = -2$
4. 제곱한다: $(-2)^2 = 4$ 이므로 $k(1, 3) = e^{-4}$
5. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다. $e$는 약 2.718이고 $e^{-4} = 1 / e^{4}$이다: $1 / 54.598 = 0.0183$

**답**: $k(1, 3) = 0.0183$ (거리 2만 떨어져도 0에 가깝다)

</details>

### 문제 2

데이터 입력이 $x_1 = 0$, $x_2 = 0.5$일 때 [커널 행렬](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#kernel-matrix-%EC%BB%A4%EB%84%90-%ED%96%89%EB%A0%AC) $K$를 구하라. ($K_{ji} = k(x_j, x_i)$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $x_1 = 0$, $x_2 = 0.5$ (데이터 입력 두 개)
- $k(x, x') = e^{-(x - x')^2}$

**풀이**
1. 식을 그대로 쓴다: $K_{ji} = k(x_j, x_i) = e^{-(x_j - x_i)^2}$
2. 값을 대입한다: $K = \begin{pmatrix} e^{-(0-0)^2} & e^{-(0-0.5)^2} \\ e^{-(0.5-0)^2} & e^{-(0.5-0.5)^2} \end{pmatrix}$
3. 대각 칸을 계산한다. 0제곱은 1이다: $e^{0} = 1$ (두 칸 모두)
4. 비대각 칸의 거리 제곱: $(0 - 0.5)^2 = 0.25$
5. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^{-0.25} = 0.7788$ (두 비대각 칸이 같다)

**답**: $K = \begin{pmatrix} 1 & 0.7788 \\ 0.7788 & 1 \end{pmatrix}$ (대칭이고 대각은 항상 1이다)

</details>

### 문제 3

데이터가 하나, $(x_1, y_1) = (1, 4)$이다. 커널 [보간](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#interpolation-%EB%B3%B4%EA%B0%84) 함수 $f(x)$를 구하고 $f(1.5)$를 계산하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x_1 = 1$, $y_1 = 4$ (데이터 하나)
- $n = 1$ (데이터 수)
- $k(x, x') = e^{-(x - x')^2}$

**풀이**
1. 식을 그대로 쓴다: $K\boldsymbol{\alpha} = \mathbf{y}$, $f(x) = \sum_{i=1}^{n}\alpha_i\, k(x, x_i)$
2. 값을 대입한다: $k(1, 1)\,\alpha_1 = 4$, $f(x) = \sum_{i=1}^{1}\alpha_1\, e^{-(x - 1)^2}$
3. $k(1, 1)$을 계산한다: $e^{-(1-1)^2} = e^0 = 1$
4. 높이를 구한다: $1 \times \alpha_1 = 4$ 이므로 $\alpha_1 = 4$
5. Σ를 풀어 쓴다 (항이 하나): $f(x) = 4\, e^{-(x - 1)^2}$
6. $x = 1.5$를 넣는다: $(1.5 - 1)^2 = 0.25$, $e^{-0.25} = 0.7788$
7. 곱한다: $4 \times 0.7788 = 3.1152$

**답**: $f(x) = 4e^{-(x-1)^2}$, $f(1.5) = 3.1152$

</details>

### 문제 4

[제곱 지수 커널](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#squared-exponential-kernel-%EC%A0%9C%EA%B3%B1-%EC%A7%80%EC%88%98-%EC%BB%A4%EB%84%90) $k(x, x') = e^{-(x - x')^2 / (2\ell^2)}$에서 폭이 $\ell = 2$이다. 거리가 2인 두 점의 커널 값을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x - x' = 2$ (거리)
- $\ell = 2$ (폭)

**풀이**
1. 식을 그대로 쓴다: $k(x, x') = e^{-(x - x')^2 / (2\ell^2)}$
2. 값을 대입한다: $k = e^{-2^2 / (2 \times 2^2)}$
3. 분자를 제곱한다: $2^2 = 4$
4. 분모를 계산한다: $2 \times 2^2 = 2 \times 4 = 8$
5. 나눈다: $4 / 8 = 0.5$ 이므로 $k = e^{-0.5}$
6. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^{-0.5} = 0.6065$

**답**: $k = 0.6065$ (폭이 넓으면 거리 2도 꽤 비슷하다고 본다)

</details>

### 문제 5

데이터가 $(x_1, y_1) = (0, 2)$, $(x_2, y_2) = (1, 0)$이다. 높이 $\boldsymbol{\alpha}$를 구하라. [커널 행렬](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#kernel-matrix-%EC%BB%A4%EB%84%90-%ED%96%89%EB%A0%AC)은 $K = \begin{pmatrix} 1 & 0.3679 \\ 0.3679 & 1 \end{pmatrix}$이다.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{y} = (2, 0)$ (목표값)
- $K = \begin{pmatrix} 1 & 0.3679 \\ 0.3679 & 1 \end{pmatrix}$ ([커널 행렬](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#kernel-matrix-%EC%BB%A4%EB%84%90-%ED%96%89%EB%A0%AC), $e^{-1} = 0.3679$)

**풀이**
1. 식을 그대로 쓴다: $K\boldsymbol{\alpha} = \mathbf{y}$
2. 값을 대입한다: $\begin{pmatrix} 1 & 0.3679 \\ 0.3679 & 1 \end{pmatrix}\begin{pmatrix}\alpha_1 \\ \alpha_2\end{pmatrix} = \begin{pmatrix} 2 \\ 0 \end{pmatrix}$
3. [행렬 곱](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#matrix-multiplication-%ED%96%89%EB%A0%AC-%EA%B3%B1)을 두 식으로 펼친다: (식 1) $\alpha_1 + 0.3679\,\alpha_2 = 2$, (식 2) $0.3679\,\alpha_1 + \alpha_2 = 0$
4. 식 2에서 $\alpha_2$를 구한다: $\alpha_2 = -0.3679\,\alpha_1$
5. 식 1에 넣는다: $\alpha_1 + 0.3679 \times (-0.3679\,\alpha_1) = 2$
6. 곱한다: $0.3679 \times 0.3679 = 0.1353$ 이므로 $\alpha_1 - 0.1353\,\alpha_1 = 2$
7. 묶는다: $(1 - 0.1353)\,\alpha_1 = 0.8647\,\alpha_1 = 2$
8. 나눈다: $\alpha_1 = 2 / 0.8647 = 2.3130$
9. $\alpha_2$를 구한다: $-0.3679 \times 2.3130 = -0.8509$
10. 검산한다 (식 1): $2.3130 + 0.3679 \times (-0.8509) = 2.3130 - 0.3130 = 2$

**답**: $\boldsymbol{\alpha} = (2.3130,\ -0.8509)$ (두 번째 혹은 음수다. 첫 혹이 $x = 1$에서도 올라와 있어 그만큼 깎아 내야 하기 때문이다)

</details>

### 문제 6

문제 5의 데이터와 높이 $\boldsymbol{\alpha} = (2.3130, -0.8509)$로 사이 점 $f(0.5)$를 구하라. ($x_1 = 0$, $x_2 = 1$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $\boldsymbol{\alpha} = (2.3130, -0.8509)$ (혹의 높이)
- $x_1 = 0$, $x_2 = 1$ (혹의 위치)
- $x = 0.5$ (알고 싶은 점)

**풀이**
1. 식을 그대로 쓴다: $f(x) = \sum_{i=1}^{2}\alpha_i\, k(x, x_i)$
2. 값을 대입한다: $f(0.5) = \alpha_1\, e^{-(0.5 - 0)^2} + \alpha_2\, e^{-(0.5 - 1)^2}$
3. Σ를 풀어 쓴다: $f(0.5) = 2.3130 \times e^{-0.25} + (-0.8509) \times e^{-0.25}$
4. 두 혹과의 거리가 모두 0.5라 커널 값이 같다: $e^{-0.25} = 0.7788$
5. 곱한다: $2.3130 \times 0.7788 = 1.8014$, $0.8509 \times 0.7788 = 0.6627$
6. 더한다: $1.8014 - 0.6627 = 1.1387$

**답**: $f(0.5) = 1.1387$ (두 데이터의 값 2와 0 사이에서 1.1387이다)

</details>

### 문제 7

데이터가 $(0, 3)$, $(1, 3)$이다(높이가 같다). 높이 $\boldsymbol{\alpha}$와 $f(0.5)$를 구하라. [커널 행렬](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#kernel-matrix-%EC%BB%A4%EB%84%90-%ED%96%89%EB%A0%AC)은 $K = \begin{pmatrix} 1 & 0.3679 \\ 0.3679 & 1 \end{pmatrix}$이다.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{y} = (3, 3)$ (목표값)
- $K = \begin{pmatrix} 1 & 0.3679 \\ 0.3679 & 1 \end{pmatrix}$
- $x_1 = 0$, $x_2 = 1$, $x = 0.5$

**풀이**
1. 식을 그대로 쓴다: $K\boldsymbol{\alpha} = \mathbf{y}$, $f(x) = \sum_{i=1}^{2}\alpha_i\, k(x, x_i)$
2. 값을 대입한다: $\begin{pmatrix} 1 & 0.3679 \\ 0.3679 & 1 \end{pmatrix}\begin{pmatrix}\alpha_1 \\ \alpha_2\end{pmatrix} = \begin{pmatrix} 3 \\ 3 \end{pmatrix}$
3. 두 식이 대칭이라 $\alpha_1 = \alpha_2 = a$로 둔다: $1 \times a + 0.3679 \times a = 3$
4. 묶는다: $1.3679\,a = 3$
5. 나눈다: $a = 3 / 1.3679 = 2.1931$
6. $f(0.5)$의 Σ를 푼다: $f(0.5) = 2.1931 \times e^{-0.25} + 2.1931 \times e^{-0.25}$
7. 커널 값을 넣는다: $e^{-0.25} = 0.7788$
8. 곱해서 더한다: $2 \times 2.1931 \times 0.7788 = 3.4161$ (반올림 전 값으로 계산)

**답**: $\boldsymbol{\alpha} = (2.1931,\ 2.1931)$, $f(0.5) = 3.4161$. 두 데이터가 모두 3인데 가운데가 3보다 높다. 두 혹이 가운데에서 겹쳐 더해지기 때문이다.

</details>

### 문제 8

[MM47_커널_보간](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/10_%ED%91%9C%ED%98%84_%ED%95%99%EC%8A%B5/MM47_%EC%BB%A4%EB%84%90_%EB%B3%B4%EA%B0%84.md)의 데이터 $(0, 1)$, $(1, 2)$에서 높이는 $\boldsymbol{\alpha} = (0.3056, 1.8876)$이었다. 이 높이가 맞는지 $x = 1$에서 $f(1)$이 목표값 2가 되는지로 검산하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\boldsymbol{\alpha} = (0.3056, 1.8876)$ (검산할 높이)
- $x_1 = 0$, $x_2 = 1$ (혹의 위치)
- $x = 1$ (검산할 점), 목표값 $y_2 = 2$

**풀이**
1. 식을 그대로 쓴다: $f(x) = \sum_{i=1}^{2}\alpha_i\, e^{-(x - x_i)^2}$
2. 값을 대입한다: $f(1) = 0.3056\, e^{-(1 - 0)^2} + 1.8876\, e^{-(1 - 1)^2}$
3. 괄호 안을 계산한다: $(1 - 0)^2 = 1$, $(1 - 1)^2 = 0$
4. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^{-1} = 0.3679$, $e^{0} = 1$
5. 곱한다: $0.3056 \times 0.3679 = 0.1124$, $1.8876 \times 1 = 1.8876$
6. 더한다: $0.1124 + 1.8876 = 2.0000$

**답**: $f(1) = 2$로 목표값과 같다. [보간](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#interpolation-%EB%B3%B4%EA%B0%84) 함수는 데이터 점을 정확히 지난다.

</details>

### 문제 9

[Lec13 5.4](../../Lec13_%ED%91%9C%ED%98%84_%ED%95%99%EC%8A%B5_%EC%9D%B4%EB%A1%A0.md#54-%EB%84%93%EC%9C%BC%EB%A9%B4-%EA%B3%BC%EC%A0%81%ED%95%A9%ED%95%98%EC%A7%80-%EC%95%8A%EB%82%98-%EC%99%9C-%EC%BB%A4%EB%84%90%EC%9D%84-%EC%93%B0%EC%A7%80-%EC%95%8A%EB%82%98)는 [커널 방법](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#kernel-method-%EC%BB%A4%EB%84%90-%EB%B0%A9%EB%B2%95)의 풀이 비용이 데이터 수 $n$의 세제곱에 비례한다고 한다. 비용을 $n^3$으로 보고, $n = 1000$일 때와 $n = 10000$일 때 비용을 구하라. 데이터가 10배가 되면 비용은 몇 배가 되는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- 비용 $= n^3$ (연산 횟수의 크기)
- $n = 1000$ 과 $n = 10000$

**풀이**
1. 식을 그대로 쓴다: 비용 $= n^3$
2. 값을 대입한다 ($n = 1000$): 비용 $= 1000^3$
3. 세제곱을 계산한다: $1000 \times 1000 \times 1000 = 10^9$
4. 값을 대입한다 ($n = 10000$): 비용 $= 10000^3$
5. 세제곱을 계산한다: $10000 \times 10000 \times 10000 = 10^{12}$
6. 비율을 구한다: $10^{12} / 10^{9} = 1000$

**답**: $n = 1000$이면 $10^9$, $n = 10000$이면 $10^{12}$. 데이터가 10배가 되면 비용은 **1000배**($10^3$)가 된다. 신경망 [학습](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5)이 데이터 수에 비례하는 것과 대비된다.

</details>

### 문제 10

[Lec13 4.4](../../Lec13_%ED%91%9C%ED%98%84_%ED%95%99%EC%8A%B5_%EC%9D%B4%EB%A1%A0.md#44-%EA%B3%B5%EB%B6%84%EC%82%B0-%ED%95%A8%EC%88%98)의 [공분산 함수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#covariance-function-%EA%B3%B5%EB%B6%84%EC%82%B0-%ED%95%A8%EC%88%98)는 이 노트의 커널이다. [제곱 지수 커널](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#squared-exponential-kernel-%EC%A0%9C%EA%B3%B1-%EC%A7%80%EC%88%98-%EC%BB%A4%EB%84%90) $e^{-(x - x')^2/(2\ell^2)}$에서 거리가 2인 두 점의 값이 $e^{-2} = 0.1353$이 되도록 하는 폭 $\ell$을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x - x' = 2$ (거리)
- 원하는 커널 값 $e^{-2}$

**풀이**
1. 식을 그대로 쓴다: $k = e^{-(x - x')^2/(2\ell^2)}$
2. 값을 대입한다: $e^{-2} = e^{-2^2/(2\ell^2)}$
3. 제곱한다: $2^2 = 4$ 이므로 $e^{-2} = e^{-4/(2\ell^2)}$
4. 밑이 같으니 지수끼리 같다: $-2 = -4/(2\ell^2)$
5. 부호를 없애고 $2\ell^2$을 구한다: $2\ell^2 = 4 / 2 = 2$
6. 2로 나눈다: $\ell^2 = 1$
7. 제곱근을 구한다. $\sqrt{a}$는 제곱해서 $a$가 되는 양수다: $\ell = \sqrt{1} = 1$
8. 검산한다: $\ell = 1$이면 $e^{-4/2} = e^{-2} = 0.1353$

**답**: $\ell = 1$

</details>
