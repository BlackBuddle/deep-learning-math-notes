# 예제: 중심극한정리와 아크코사인 커널

개념 노트: [MM49_중심극한정리와_아크코사인_커널](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/10_%ED%91%9C%ED%98%84_%ED%95%99%EC%8A%B5/MM49_%EC%A4%91%EC%8B%AC%EA%B7%B9%ED%95%9C%EC%A0%95%EB%A6%AC%EC%99%80_%EC%95%84%ED%81%AC%EC%BD%94%EC%82%AC%EC%9D%B8_%EC%BB%A4%EB%84%90.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. [아크코사인 커널](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#arc-cosine-kernel-%EC%95%84%ED%81%AC%EC%BD%94%EC%82%AC%EC%9D%B8-%EC%BB%A4%EB%84%90)은 $h(t) = \dfrac{1}{\pi}\Big[\sqrt{1 - t^2} + t\,(\pi - \arccos t)\Big]$이고 $\pi = 3.1416$이다. $\arccos t$는 코사인이 $t$인 각도(라디안)다.

## 기본 (직접 대입)

### 문제 1

동전 9개를 던졌다. 앞면을 $+1$, 뒷면을 $-1$로 하고 앞면이 6개, 뒷면이 3개였다. 합을 $\sqrt{n}$으로 나눈 값 $z = \frac{1}{\sqrt{n}}\sum_j s_j$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $n = 9$ (동전 개수)
- 앞면 6개 ($+1$), 뒷면 3개 ($-1$)

**풀이**
1. 식을 그대로 쓴다: $z = \dfrac{1}{\sqrt{n}}\sum_{j=1}^{n} s_j$
2. 값을 대입한다: $z = \dfrac{1}{\sqrt{9}}\sum_{j=1}^{9} s_j$
3. Σ를 묶어 쓴다: 앞면 6개는 $+1$씩, 뒷면 3개는 $-1$씩 더한다: $6 \times (+1) + 3 \times (-1)$
4. 계산한다: $6 - 3 = 3$
5. 제곱근을 구한다. $\sqrt{a}$는 제곱해서 $a$가 되는 양수다: $\sqrt{9} = 3$
6. 나눈다: $z = 3 / 3 = 1$

**답**: $z = 1$

</details>

### 문제 2

독립인 값 $s_j$가 각각 평균 0, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $\sigma^2 = 4$이다. $n = 100$개를 더해 $\sqrt{100}$으로 나눈 $z = \frac{1}{\sqrt{n}}\sum_j s_j$의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 구하라. (독립인 값을 더하면 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)도 더해지고, $a$배하면 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)은 $a^2$배가 된다.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $\sigma^2 = 4$ (각 $s_j$의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0))
- $n = 100$ (더하는 개수)
- 배율 $1/\sqrt{100}$

**풀이**
1. 식을 그대로 쓴다: $\text{Var}(z) = \Big(\dfrac{1}{\sqrt{n}}\Big)^2 \times n\,\sigma^2$
2. 값을 대입한다: $\text{Var}(z) = \Big(\dfrac{1}{\sqrt{100}}\Big)^2 \times 100 \times 4$
3. 합의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0): $100 \times 4 = 400$ ([독립](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#independence-%EB%8F%85%EB%A6%BD)이라 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)이 더해진다)
4. 배율을 구한다: $\sqrt{100} = 10$, 배율은 $1/10$
5. 배율을 제곱한다: $(1/10)^2 = 0.01$
6. 곱한다: $0.01 \times 400 = 4$

**답**: $\text{Var}(z) = 4$. $\sqrt{n}$으로 나누면 $n$에 상관없이 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)이 $\sigma^2$로 유지된다. 이것이 [중심극한정리](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#central-limit-theorem-%EC%A4%91%EC%8B%AC%EA%B7%B9%ED%95%9C%EC%A0%95%EB%A6%AC)의 $\mathcal{N}(0, \sigma^2)$이다.

</details>

### 문제 3

$\phi(u) = \sqrt{2}\,\mathrm{relu}(u)$일 때 $u = -0.5$, $u = 0.5$, $u = 2$에서 $\phi(u)$를 각각 구하라. ($\mathrm{relu}(u)$는 $u$가 양수면 $u$, 아니면 0이고 $\sqrt{2} = 1.4142$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $u = -0.5,\ 0.5,\ 2$ (입력 세 개)
- $\sqrt{2} = 1.4142$ ([분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 지키는 배율)

**풀이**
1. 식을 그대로 쓴다: $\phi(u) = \sqrt{2}\,\mathrm{relu}(u)$
2. 값을 대입한다: $\phi(-0.5) = \sqrt{2}\,\mathrm{relu}(-0.5)$, $\phi(0.5) = \sqrt{2}\,\mathrm{relu}(0.5)$, $\phi(2) = \sqrt{2}\,\mathrm{relu}(2)$
3. relu를 계산한다: $\mathrm{relu}(-0.5) = 0$ (음수는 0), $\mathrm{relu}(0.5) = 0.5$, $\mathrm{relu}(2) = 2$
4. 곱한다: $1.4142 \times 0 = 0$
5. 곱한다: $1.4142 \times 0.5 = 0.7071$
6. 곱한다: $1.4142 \times 2 = 2.8284$

**답**: $\phi(-0.5) = 0$, $\phi(0.5) = 0.7071$, $\phi(2) = 2.8284$

</details>

### 문제 4

입력 상관이 $t = 0.8$일 때 [아크코사인 커널](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#arc-cosine-kernel-%EC%95%84%ED%81%AC%EC%BD%94%EC%82%AC%EC%9D%B8-%EC%BB%A4%EB%84%90) $h(0.8)$을 구하라. ($\arccos 0.8 = 0.6435$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $t = 0.8$ (입력 상관)
- $\arccos 0.8 = 0.6435$ (코사인이 0.8인 각도)
- $\pi = 3.1416$

**풀이**
1. 식을 그대로 쓴다: $h(t) = \dfrac{1}{\pi}\Big[\sqrt{1 - t^2} + t\,(\pi - \arccos t)\Big]$
2. 값을 대입한다: $h(0.8) = \dfrac{1}{\pi}\Big[\sqrt{1 - 0.8^2} + 0.8\,(\pi - 0.6435)\Big]$
3. 제곱한다: $0.8^2 = 0.64$
4. 루트 안을 뺀다: $1 - 0.64 = 0.36$
5. 제곱근을 구한다: $\sqrt{0.36} = 0.6$
6. 괄호 안을 뺀다: $3.1416 - 0.6435 = 2.4981$
7. 곱한다: $0.8 \times 2.4981 = 1.9985$
8. 대괄호 안을 더한다: $0.6 + 1.9985 = 2.5985$
9. $\pi$로 나눈다: $2.5985 / 3.1416 = 0.8271$

**답**: $h(0.8) = 0.8271$ (입력 상관 0.8이 [ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8) [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)을 지나며 0.83으로 조금 커진다)

</details>

### 문제 5

같은 두 입력($t = 1$)과 정반대인 두 입력($t = -1$)이 [ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8) [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)을 지나면 상관이 각각 얼마가 되는가? $h(1)$과 $h(-1)$을 구하라. ($\arccos 1 = 0$, $\arccos(-1) = \pi$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $t = 1$ (같은 입력), $t = -1$ (정반대 입력)
- $\arccos 1 = 0$, $\arccos(-1) = \pi$

**풀이**
1. 식을 그대로 쓴다: $h(t) = \dfrac{1}{\pi}\Big[\sqrt{1 - t^2} + t\,(\pi - \arccos t)\Big]$
2. 값을 대입한다 ($t = 1$): $h(1) = \dfrac{1}{\pi}\Big[\sqrt{1 - 1^2} + 1 \times (\pi - 0)\Big]$
3. 루트 안을 계산한다: $1 - 1 = 0$, $\sqrt{0} = 0$
4. 둘째 항: $1 \times (\pi - 0) = \pi$
5. 대괄호 안을 더하고 나눈다: $(0 + \pi) / \pi = 1$
6. 값을 대입한다 ($t = -1$): $h(-1) = \dfrac{1}{\pi}\Big[\sqrt{1 - (-1)^2} + (-1) \times (\pi - \pi)\Big]$
7. 루트 안을 계산한다: $1 - 1 = 0$, $\sqrt{0} = 0$
8. 둘째 항: $\pi - \pi = 0$ 이므로 $(-1) \times 0 = 0$
9. 대괄호 안을 더하고 나눈다: $(0 + 0) / \pi = 0$

**답**: $h(1) = 1$, $h(-1) = 0$. 같은 입력은 상관 1을 유지한다([분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) 보존). 정반대 입력은 [ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8)가 음수를 0으로 만들어 한쪽만 살아남기 때문에 상관 0이 된다.

</details>

### 문제 6

[가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $2/n$으로 초기화한 [ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8) [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)에서 fan-in(앞 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5) 너비) $n = 100$이다. 앞 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)의 활성값에 대해 $\mathbb{E}[\mathrm{relu}(u)^2] = 0.5$일 때 $z = \sum_{j=1}^{n} W_j\,\mathrm{relu}(u_j)$의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 구하라. (독립인 항을 더하면 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)도 더해진다.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $n = 100$ (더하는 개수, fan-in)
- $\text{Var}(W) = 2/100 = 0.02$ ([가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0))
- $\mathbb{E}[\mathrm{relu}(u)^2] = 0.5$ (활성값 제곱의 평균)

**풀이**
1. 식을 그대로 쓴다: $\text{Var}(z) = n \times \text{Var}(W) \times \mathbb{E}[\mathrm{relu}(u)^2]$ (항 하나의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $\text{Var}(W) \times \mathbb{E}[\mathrm{relu}(u)^2]$를 $n$번 더한다)
2. 값을 대입한다: $\text{Var}(z) = 100 \times 0.02 \times 0.5$
3. 앞 두 개를 곱한다: $100 \times 0.02 = 2$
4. 곱한다: $2 \times 0.5 = 1$

**답**: $\text{Var}(z) = 1$. [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 $2/n$으로 두면 [ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8)가 절반을 0으로 만드는 것을 보충해 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)을 지나도 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)이 1로 유지된다.

</details>

### 문제 7

입력 상관이 $t = 0.5$이다. [ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8) [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)을 두 번 지났을 때 상관, 곧 $h(h(0.5))$를 구하라. ($h(0.5) = 0.6090$이다. $\arccos 0.609 = 0.9160$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $h(0.5) = 0.6090$ (첫 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)을 지난 상관)
- $\arccos 0.609 = 0.9160$
- $\pi = 3.1416$

**풀이**
1. 식을 그대로 쓴다: $h(t) = \dfrac{1}{\pi}\Big[\sqrt{1 - t^2} + t\,(\pi - \arccos t)\Big]$
2. 값을 대입한다 (둘째 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5), $t = 0.6090$): $h(0.609) = \dfrac{1}{\pi}\Big[\sqrt{1 - 0.609^2} + 0.609\,(\pi - 0.9160)\Big]$
3. 제곱한다: $0.609^2 = 0.3709$
4. 루트 안을 뺀다: $1 - 0.3709 = 0.6291$
5. 제곱근을 구한다: $\sqrt{0.6291} = 0.7932$
6. 괄호 안을 뺀다: $3.1416 - 0.9160 = 2.2256$
7. 곱한다: $0.609 \times 2.2256 = 1.3554$
8. 대괄호 안을 더한다: $0.7932 + 1.3554 = 2.1486$
9. $\pi$로 나눈다: $2.1486 / 3.1416 = 0.6839$

**답**: $h(h(0.5)) = 0.6839$. [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)을 쌓을수록 상관이 1에 가까워진다.

</details>

### 문제 8

동전 $n = 400$개를 던져 앞면 $+1$, 뒷면 $-1$의 합이 $40$이었다. $z = \frac{1}{\sqrt{n}}\sum_j s_j$를 구하고, [중심극한정리](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#central-limit-theorem-%EC%A4%91%EC%8B%AC%EA%B7%B9%ED%95%9C%EC%A0%95%EB%A6%AC)로 $z$가 표준 [정규분포](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#normal-distribution-%EC%A0%95%EA%B7%9C%EB%B6%84%ED%8F%AC)를 따른다고 볼 때 $|z| < 2$일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)(약 0.9545)을 기준으로 이 결과가 흔한 결과인지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $n = 400$ (동전 개수)
- 합 $= 40$ (앞면 수 − 뒷면 수)
- 표준 정규에서 $|z| < 2$일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) $= 0.9545$ (표준 [정규분포](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#normal-distribution-%EC%A0%95%EA%B7%9C%EB%B6%84%ED%8F%AC)의 알려진 값)

**풀이**
1. 식을 그대로 쓴다: $z = \dfrac{1}{\sqrt{n}}\sum_{j=1}^{n} s_j$
2. 값을 대입한다: $z = \dfrac{1}{\sqrt{400}} \times 40$
3. 제곱근을 구한다: $\sqrt{400} = 20$
4. 나눈다: $z = 40 / 20 = 2$
5. 비교한다: $z = 2$는 $|z| < 2$의 경계다. 이 안에 들어올 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 0.9545이므로 $|z| \ge 2$인 경우는 $1 - 0.9545 = 0.0455$

**답**: $z = 2$. 400번 던져 합이 $\pm 40$ 이상 벗어나는 일은 약 4.6%라서 드물지만 아주 이상하지는 않다.

</details>

### 문제 9

[Lec13 7](../../Lec13_%ED%91%9C%ED%98%84_%ED%95%99%EC%8A%B5_%EC%9D%B4%EB%A1%A0.md#7-%EC%98%88-relu-mlp%EC%99%80-%EC%95%84%ED%81%AC%EC%BD%94%EC%82%AC%EC%9D%B8-%EC%BB%A4%EB%84%90)에서 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)을 쌓으면 입력 상관에 $h$를 거듭 적용한 것이 된다. 직교한 두 입력($t = 0$)에서 시작해 $h$를 세 번 적용한 상관을 구하라. 필요한 값: $\arccos 0.3183 = 1.2469$, $\arccos 0.4937 = 1.0545$.

<details><summary>풀이와 답</summary>

**주어진 값**
- $t_0 = 0$ (시작 상관, 직교)
- $\arccos 0.3183 = 1.2469$, $\arccos 0.4937 = 1.0545$
- $\pi = 3.1416$

**풀이**
1. 식을 그대로 쓴다: $t_{k+1} = h(t_k) = \dfrac{1}{\pi}\Big[\sqrt{1 - t_k^2} + t_k\,(\pi - \arccos t_k)\Big]$
2. 첫째 적용을 대입한다: $h(0) = \dfrac{1}{\pi}\Big[\sqrt{1 - 0^2} + 0 \times (\pi - \arccos 0)\Big]$
3. 루트 안을 계산한다: $\sqrt{1} = 1$, 둘째 항은 0을 곱하므로 0. 대괄호 안은 $1 + 0 = 1$
4. 나눈다: $t_1 = 1 / 3.1416 = 0.3183$
5. 둘째 적용을 대입한다: $h(0.3183) = \dfrac{1}{\pi}\Big[\sqrt{1 - 0.3183^2} + 0.3183\,(\pi - 1.2469)\Big]$
6. 루트: $0.3183^2 = 0.1013$, $1 - 0.1013 = 0.8987$, $\sqrt{0.8987} = 0.9480$
7. 둘째 항: $3.1416 - 1.2469 = 1.8947$, $0.3183 \times 1.8947 = 0.6031$
8. 더하고 나눈다: $(0.9480 + 0.6031) / 3.1416 = 1.5511 / 3.1416 = 0.4937$
9. 셋째 적용을 대입한다: $h(0.4937) = \dfrac{1}{\pi}\Big[\sqrt{1 - 0.4937^2} + 0.4937\,(\pi - 1.0545)\Big]$
10. 루트: $0.4937^2 = 0.2437$, $1 - 0.2437 = 0.7563$, $\sqrt{0.7563} = 0.8696$
11. 둘째 항: $3.1416 - 1.0545 = 2.0871$, $0.4937 \times 2.0871 = 1.0304$
12. 더하고 나눈다: $(0.8696 + 1.0304) / 3.1416 = 1.9000 / 3.1416 = 0.6048$

**답**: 0.3183 → 0.4937 → **0.6048**. 직교로 시작해도 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)을 쌓을수록 두 입력의 표현이 닮아 가 상관이 1로 다가간다.

</details>

### 문제 10

[Lec13 9](../../Lec13_%ED%91%9C%ED%98%84_%ED%95%99%EC%8A%B5_%EC%9D%B4%EB%A1%A0.md#9-%ED%8C%AC%EC%9D%B8-%EC%B4%88%EA%B8%B0%ED%99%94%EC%99%80-%EC%98%81%EA%B3%B5%EA%B0%84)의 $1/\text{fan-in}$ 초기화를 확인한다. fan-in $n = 512$인 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)에서 $z = \sum_{j=1}^{n} W_j\,\phi(u_j)$이고 $\mathbb{E}[\phi(u)^2] = 1$이다. [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)이 (가) $1/512$일 때와 (나) $0.01$일 때 $z$의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 각각 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $n = 512$ (fan-in)
- $\mathbb{E}[\phi(u)^2] = 1$ (활성값 제곱의 평균)
- [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) (가) $1/512$, (나) $0.01$

**풀이**
1. 식을 그대로 쓴다: $\text{Var}(z) = n \times \text{Var}(W) \times \mathbb{E}[\phi(u)^2]$ (독립인 항의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)이 더해진다)
2. 값을 대입한다 (가): $\text{Var}(z) = 512 \times \dfrac{1}{512} \times 1$
3. 곱한다: $512 \times \dfrac{1}{512} = 1$, 거기에 $1$을 곱해도 $1$
4. 값을 대입한다 (나): $\text{Var}(z) = 512 \times 0.01 \times 1$
5. 곱한다: $512 \times 0.01 = 5.12$

**답**: (가) $1$, (나) $5.12$. $1/\text{fan-in}$이면 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)마다 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)이 1로 유지된다. 0.01처럼 크게 두면 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)마다 5.12배씩 커져 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)이 깊어질수록 폭발한다.

</details>
