# 예제: k-평균과 평균

개념 노트: [MM41_k평균과_평균](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/10_%ED%91%9C%ED%98%84_%ED%95%99%EC%8A%B5/MM41_k%ED%8F%89%EA%B7%A0%EA%B3%BC_%ED%8F%89%EA%B7%A0.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 쓰는 규칙은 셋이다: 점들을 한 점 $c$로 대표할 때 제곱 거리 합 $\sum(x_i - c)^2$을 가장 작게 하는 점은 평균이다. 점마다 가장 가까운 중심을 고르는 것이 배정, 중심을 자기 무리의 평균으로 옮기는 것이 갱신이다. 둘을 번갈아 하는 것이 로이드 알고리즘이다. 2차원 점의 제곱 거리는 $\|\mathbf{x} - \mathbf{c}\|^2 = (x_1 - c_1)^2 + (x_2 - c_2)^2$이다.

## 기본 (직접 대입)

### 문제 1

1차원 점 $1,\ 5,\ 9$의 평균을 구하고, 평균 $c = 5$와 다른 후보 $c = 4$의 제곱 거리 합을 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x_1 = 1$, $x_2 = 5$, $x_3 = 9$ (1차원 점, $n = 3$)
- 비교할 후보 $c = 4$

**풀이**
1. 평균 식을 그대로 쓴다: $\bar{x} = \frac{1}{n}(x_1 + x_2 + x_3)$
2. 값을 대입한다: $\bar{x} = \frac13(1 + 5 + 9)$
3. 괄호 안을 더한다: 1 + 5 + 9 = 15 이므로 $\bar{x} = 15 / 3$
4. 나눈다: $\bar{x} = 5$
5. 제곱 거리 합 식을 쓴다: $S(c) = (x_1 - c)^2 + (x_2 - c)^2 + (x_3 - c)^2$
6. $c = 5$를 대입한다: $S(5) = (1 - 5)^2 + (5 - 5)^2 + (9 - 5)^2$
7. 뺄셈을 한다: $(-4)^2 + 0^2 + 4^2$
8. 제곱하고 더한다: 16 + 0 + 16 = 32 이므로 $S(5) = 32$
9. $c = 4$를 대입한다: $S(4) = (1 - 4)^2 + (5 - 4)^2 + (9 - 4)^2$
10. 뺄셈, 제곱, 덧셈을 한다: $(-3)^2 + 1^2 + 5^2 = 9 + 1 + 25 = 35$
11. 비교한다: $32 < 35$

**답**: 평균 **5**, $S(5) = 32$가 $S(4) = 35$보다 작다.

</details>

### 문제 2

2차원 점 $(0, 0)$, $(2, 0)$, $(1, 3)$으로 이루어진 무리의 중심(평균)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 점 $(0, 0)$, $(2, 0)$, $(1, 3)$ (한 무리, $n = 3$)

**풀이**
1. 식을 그대로 쓴다: $\boldsymbol\mu = \frac{1}{n}\sum_{i=1}^{n} \mathbf{x}_i$ (칸마다 따로 평균)
2. 값을 대입한다: $\boldsymbol\mu = \frac13\big((0, 0) + (2, 0) + (1, 3)\big)$
3. 첫째 칸을 더한다: 0 + 2 + 1 = 3
4. 둘째 칸을 더한다: 0 + 0 + 3 = 3 이므로 $\boldsymbol\mu = \frac13(3, 3)$
5. 3으로 나눈다: 3 / 3 = 1 (두 칸 모두) 이므로 $\boldsymbol\mu = (1, 1)$

**답**: $\boldsymbol\mu = (1, 1)$

</details>

### 문제 3

중심이 $\boldsymbol\mu_1 = (0, 0)$, $\boldsymbol\mu_2 = (6, 6)$일 때 점 $\mathbf{x} = (4, 5)$는 어느 무리에 배정되는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $\boldsymbol\mu_1 = (0, 0)$, $\boldsymbol\mu_2 = (6, 6)$ (두 중심)
- $\mathbf{x} = (4, 5)$ (배정할 점)

**풀이**
1. 식을 그대로 쓴다: $k^* = \arg\min_k \|\mathbf{x} - \boldsymbol\mu_k\|^2$
2. 값을 대입한다: $\|(4, 5) - (0, 0)\|^2$ 과 $\|(4, 5) - (6, 6)\|^2$ 중 작은 쪽
3. 칸별로 뺀다: $(4, 5)$ 와 $(-2, -1)$
4. 제곱합을 펼친다: $4^2 + 5^2$ 와 $(-2)^2 + (-1)^2$
5. 제곱하고 더한다: 16 + 25 = 41 과 4 + 1 = 5
6. 작은 쪽을 고른다: 5 < 41 이므로 $k^* = 2$

**답**: **2번 무리**

</details>

### 문제 4

[k-평균](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#k-means-k-%ED%8F%89%EA%B7%A0)을 [오토인코더](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#autoencoder-%EC%98%A4%ED%86%A0%EC%9D%B8%EC%BD%94%EB%8D%94)로 보자. 중심 $\boldsymbol\mu_1 = (1, 1)$, $\boldsymbol\mu_2 = (5, 3)$, 디코더 $M = \begin{pmatrix}1&5\\1&3\end{pmatrix}$ (중심을 열로 세운 행렬)이다. 점 $\mathbf{x} = (4, 3)$의 코드 $f(\mathbf{x})$, 복원 $M f(\mathbf{x})$, 복원 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\boldsymbol\mu_1 = (1, 1)$, $\boldsymbol\mu_2 = (5, 3)$ (중심)
- $M = \begin{pmatrix}1&5\\1&3\end{pmatrix}$ (디코더, 1열이 $\boldsymbol\mu_1$, 2열이 $\boldsymbol\mu_2$)
- $\mathbf{x} = (4, 3)$ (데이터 점)

**풀이**
1. 식을 그대로 쓴다: $k^* = \arg\min_k \|\mathbf{x} - \boldsymbol\mu_k\|^2$, $f(\mathbf{x}) = \mathbf{e}_{k^*}$, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $= \|\mathbf{x} - M f(\mathbf{x})\|^2$
2. 값을 대입한다: $\|(4, 3) - (1, 1)\|^2$ 과 $\|(4, 3) - (5, 3)\|^2$ 중 작은 쪽
3. 칸별로 뺀다: $(3, 2)$ 와 $(-1, 0)$
4. 제곱하고 더한다: $3^2 + 2^2 = 9 + 4 = 13$ 과 $(-1)^2 + 0^2 = 1$
5. 작은 쪽을 고른다: 1 < 13 이므로 $k^* = 2$, 코드 $f(\mathbf{x}) = \mathbf{e}_2 = (0, 1)$
6. 디코더에 대입한다: $M\mathbf{e}_2 = \begin{pmatrix}1&5\\1&3\end{pmatrix}\begin{pmatrix}0\\1\end{pmatrix}$
7. 행마다 펼친다: $(1\times0 + 5\times1,\ 1\times0 + 3\times1) = (5, 3)$ (M의 2열을 골라냈다)
8. [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)에 대입한다: $\|(4, 3) - (5, 3)\|^2 = (-1)^2 + 0^2 = 1$

**답**: 코드 **(0, 1)**, 복원 **(5, 3)**, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) **1**.

</details>

### 문제 5

1차원 점 $1,\ 3,\ 8,\ 10$에 $K = 2$, 처음 중심 $\mu_1 = 1$, $\mu_2 = 3$으로 로이드 알고리즘을 돌려 $J$의 변화와 멈추는 곳을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 점 $x = 1, 3, 8, 10$ (1차원 데이터)
- 처음 중심 $\mu_1 = 1$, $\mu_2 = 3$, $K = 2$

**풀이**
1. 식을 그대로 쓴다: 배정은 $|x - \mu_k|$가 작은 쪽, 갱신은 무리 평균, $J = \sum_i (x_i - \mu_{k(i)})^2$
2. 1회차 배정: 1은 $|1-1| = 0$ 대 $|1-3| = 2$ → 1번, 3은 2 대 0 → 2번, 8은 7 대 5 → 2번, 10은 9 대 7 → 2번
3. 1회차 $J$에 대입한다: $J = (1-1)^2 + (3-3)^2 + (8-3)^2 + (10-3)^2$
4. 제곱하고 더한다: 0 + 0 + 25 + 49 = 74 이므로 $J = 74$
5. 1회차 갱신: $\mu_1 = 1/1 = 1$, $\mu_2 = (3 + 8 + 10)/3 = 21/3 = 7$
6. 2회차 배정: 3은 $|3-1| = 2$ 대 $|3-7| = 4$ → 1번, 8은 7 대 1 → 2번, 10은 9 대 3 → 2번, 1은 1번
7. 2회차 $J$에 대입한다: $J = (1-1)^2 + (3-1)^2 + (8-7)^2 + (10-7)^2$
8. 제곱하고 더한다: 0 + 4 + 1 + 9 = 14 이므로 $J = 14$
9. 2회차 갱신: $\mu_1 = (1 + 3)/2 = 2$, $\mu_2 = (8 + 10)/2 = 9$
10. 3회차 $J$에 대입한다 (배정은 그대로 1, 1, 2, 2): $J = (1-2)^2 + (3-2)^2 + (8-9)^2 + (10-9)^2$
11. 제곱하고 더한다: 1 + 1 + 1 + 1 = 4 이므로 $J = 4$. 배정이 바뀌지 않으므로 멈춘다

**답**: $J$는 **74 → 14 → 4**로 줄고, 중심 **2와 9**에서 멈춘다.

</details>

### 문제 6

2차원 점 $(0, 0)$, $(2, 0)$, $(8, 8)$, $(10, 8)$을 (가) 중심 둘 $(1, 0)$, $(9, 8)$로 대표할 때, (나) 중심 하나(전체 평균)로 대표할 때 제곱 거리 합 $J$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 점 $(0,0)$, $(2,0)$, $(8,8)$, $(10,8)$ (데이터)
- (가) 중심 $(1, 0)$, $(9, 8)$ (앞 두 점은 첫째, 뒤 두 점은 둘째 중심으로 배정)
- (나) 중심 하나: 전체 평균

**풀이**
1. 식을 그대로 쓴다: $J = \sum_i \|\mathbf{x}_i - \boldsymbol\mu_{k(i)}\|^2$
2. (가) 값을 대입한다: $J = \|(0,0) - (1,0)\|^2 + \|(2,0) - (1,0)\|^2 + \|(8,8) - (9,8)\|^2 + \|(10,8) - (9,8)\|^2$
3. (가) 칸별로 뺀다: $(-1, 0)$, $(1, 0)$, $(-1, 0)$, $(1, 0)$
4. (가) 제곱하고 더한다: 1 + 1 + 1 + 1 = 4 이므로 $J = 4$
5. (나) 전체 평균을 구한다: 첫째 칸 $(0 + 2 + 8 + 10)/4 = 20/4 = 5$, 둘째 칸 $(0 + 0 + 8 + 8)/4 = 16/4 = 4$ 이므로 $\boldsymbol\mu = (5, 4)$
6. (나) 점마다 제곱 거리를 구한다: $(0,0)$은 $(-5)^2 + (-4)^2 = 25 + 16 = 41$, $(2,0)$은 $(-3)^2 + (-4)^2 = 9 + 16 = 25$, $(8,8)$은 $3^2 + 4^2 = 9 + 16 = 25$, $(10,8)$은 $5^2 + 4^2 = 25 + 16 = 41$
7. (나) 더한다: 41 + 25 + 25 + 41 = 132 이므로 $J = 132$

**답**: (가) $J = $ **4**, (나) $J = $ **132**. 중심을 둘로 늘리면 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)가 크게 준다.

</details>

### 문제 7

점 $0,\ 1,\ 8$을 한 점 $c$로 대표한다. $c = 3$(평균)과 $c = 1$(중앙값)에 대해 (가) 제곱 거리 합 $\sum(x_i - c)^2$, (나) 거리 합 $\sum|x_i - c|$를 구하고, 각각 어느 쪽이 작은지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x_1 = 0$, $x_2 = 1$, $x_3 = 8$ (1차원 점)
- 후보 $c = 3$ (평균 $= (0 + 1 + 8)/3 = 3$), $c = 1$ (가운데 값)

**풀이**
1. 식을 그대로 쓴다: (가) $S_2(c) = \sum_i (x_i - c)^2$, (나) $S_1(c) = \sum_i |x_i - c|$ ($|\cdot|$는 부호를 뗀 값)
2. (가) $c = 3$을 대입한다: $(0-3)^2 + (1-3)^2 + (8-3)^2$
3. (가) 뺄셈, 제곱, 덧셈을 한다: $9 + 4 + 25 = 38$
4. (가) $c = 1$을 대입한다: $(0-1)^2 + (1-1)^2 + (8-1)^2 = 1 + 0 + 49 = 50$
5. (가) 비교한다: $38 < 50$ 이므로 평균이 작다
6. (나) $c = 3$을 대입한다: $|0-3| + |1-3| + |8-3| = 3 + 2 + 5 = 10$
7. (나) $c = 1$을 대입한다: $|0-1| + |1-1| + |8-1| = 1 + 0 + 7 = 8$
8. (나) 비교한다: $8 < 10$ 이므로 가운데 값이 작다

**답**: (가) 평균 $c = 3$이 **38**로 더 작고(1은 50), (나) $c = 1$이 **8**로 더 작다(3은 10). 평균이 최선인 것은 제곱 거리(L2)일 때뿐이다.

</details>

### 문제 8

중심이 $\boldsymbol\mu_1 = (0, 0)$, $\boldsymbol\mu_2 = (2, 2)$, $\boldsymbol\mu_3 = (4, 6)$이고 디코더가 $M = \begin{pmatrix}0&2&4\\0&2&6\end{pmatrix}$일 때, 점 $\mathbf{x} = (3, 5)$를 인코딩하고 복원하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\boldsymbol\mu_1 = (0,0)$, $\boldsymbol\mu_2 = (2,2)$, $\boldsymbol\mu_3 = (4,6)$ (중심 셋)
- $M = \begin{pmatrix}0&2&4\\0&2&6\end{pmatrix}$ (디코더, k열이 $\boldsymbol\mu_k$)
- $\mathbf{x} = (3, 5)$ (데이터 점)

**풀이**
1. 식을 그대로 쓴다: $k^* = \arg\min_k \|\mathbf{x} - \boldsymbol\mu_k\|^2$, $f(\mathbf{x}) = \mathbf{e}_{k^*}$
2. 값을 대입한다: $\|(3,5) - (0,0)\|^2$, $\|(3,5) - (2,2)\|^2$, $\|(3,5) - (4,6)\|^2$
3. 칸별로 뺀다: $(3, 5)$, $(1, 3)$, $(-1, -1)$
4. 제곱하고 더한다: $9 + 25 = 34$, $1 + 9 = 10$, $1 + 1 = 2$
5. 가장 작은 것을 고른다: 2 이므로 $k^* = 3$, 코드 $f(\mathbf{x}) = \mathbf{e}_3 = (0, 0, 1)$
6. 디코더에 대입한다: $M\mathbf{e}_3 = \begin{pmatrix}0&2&4\\0&2&6\end{pmatrix}\begin{pmatrix}0\\0\\1\end{pmatrix}$
7. 행마다 펼친다: $(0\times0 + 2\times0 + 4\times1,\ 0\times0 + 2\times0 + 6\times1) = (4, 6)$
8. [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)를 구한다: $\|(3,5) - (4,6)\|^2 = 1 + 1 = 2$

**답**: 코드 **(0, 0, 1)**, 복원 **(4, 6)**, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) **2**.

</details>

## 강의와 연결

### 문제 9

Lec11 9.2는 "[k-평균](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#k-means-k-%ED%8F%89%EA%B7%A0)은 L2 [오토인코더](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#autoencoder-%EC%98%A4%ED%86%A0%EC%9D%B8%EC%BD%94%EB%8D%94)"라고 한다. 점 $(0,0)$, $(0,2)$, $(6,0)$, $(6,2)$에 중심 $\boldsymbol\mu_1 = (0, 1)$, $\boldsymbol\mu_2 = (6, 1)$이 있다. 점마다 인코더가 내놓는 번호와 디코더가 복원하는 점을 구하고, 전체 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $J$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 점 $(0,0)$, $(0,2)$, $(6,0)$, $(6,2)$ (데이터)
- $\boldsymbol\mu_1 = (0, 1)$, $\boldsymbol\mu_2 = (6, 1)$ (중심, 디코더 $M$의 열)

**풀이**
1. 식을 그대로 쓴다: $f(\mathbf{x}) = \mathbf{e}_{k^*}$, $k^* = \arg\min_k \|\mathbf{x} - \boldsymbol\mu_k\|^2$, $J = \sum_i \|\mathbf{x}_i - M f(\mathbf{x}_i)\|^2$
2. $(0,0)$을 대입한다: $\|(0,0) - (0,1)\|^2 = 0 + 1 = 1$ 대 $\|(0,0) - (6,1)\|^2 = 36 + 1 = 37$ → $k^* = 1$, 복원 $(0, 1)$, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 1
3. $(0,2)$를 대입한다: $\|(0,2) - (0,1)\|^2 = 0 + 1 = 1$ 대 $\|(0,2) - (6,1)\|^2 = 36 + 1 = 37$ → $k^* = 1$, 복원 $(0, 1)$, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 1
4. $(6,0)$을 대입한다: $\|(6,0) - (0,1)\|^2 = 36 + 1 = 37$ 대 $\|(6,0) - (6,1)\|^2 = 0 + 1 = 1$ → $k^* = 2$, 복원 $(6, 1)$, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 1
5. $(6,2)$를 대입한다: $\|(6,2) - (0,1)\|^2 = 36 + 1 = 37$ 대 $\|(6,2) - (6,1)\|^2 = 0 + 1 = 1$ → $k^* = 2$, 복원 $(6, 1)$, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 1
6. 더한다: $J = 1 + 1 + 1 + 1 = 4$

**답**: 번호 **1, 1, 2, 2**, 복원 $(0,1)$, $(0,1)$, $(6,1)$, $(6,1)$, $J = $ **4**. 디코더가 내놓은 점은 각 무리의 평균이다.

</details>

### 문제 10

Lec11 9.2에서 로이드 알고리즘은 배정과 갱신 두 단계 모두 $J$를 늘리지 않아서 반드시 멈춘다고 했다. 한 무리가 점 $1,\ 2,\ 6$이고 지금 중심이 $c = 4$일 때, 갱신 단계(중심을 평균으로 옮기기) 전후의 $J$를 구해 줄어드는지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 한 무리의 점 $1, 2, 6$ ($n = 3$)
- 지금 중심 $c = 4$

**풀이**
1. 식을 그대로 쓴다: $J(c) = \sum_i (x_i - c)^2$, 갱신 후 중심 $= \bar{x} = \frac{1}{n}\sum_i x_i$
2. 갱신 전 $J$에 대입한다: $J(4) = (1-4)^2 + (2-4)^2 + (6-4)^2$
3. 뺄셈, 제곱, 덧셈을 한다: $9 + 4 + 4 = 17$
4. 새 중심(평균)을 구한다: $\bar{x} = (1 + 2 + 6)/3 = 9/3 = 3$
5. 갱신 후 $J$에 대입한다: $J(3) = (1-3)^2 + (2-3)^2 + (6-3)^2$
6. 뺄셈, 제곱, 덧셈을 한다: $4 + 1 + 9 = 14$
7. 비교한다: $14 < 17$

**답**: $J$가 **17 → 14**로 줄었다. 평균이 제곱 거리 합을 가장 작게 하는 점이라서 갱신 단계는 $J$를 절대 늘리지 않는다.

</details>
