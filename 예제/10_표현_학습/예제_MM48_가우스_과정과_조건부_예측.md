# 예제: 가우스 과정과 조건부 예측

개념 노트: [MM48_가우스_과정과_조건부_예측](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/10_%ED%91%9C%ED%98%84_%ED%95%99%EC%8A%B5/MM48_%EA%B0%80%EC%9A%B0%EC%8A%A4_%EA%B3%BC%EC%A0%95%EA%B3%BC_%EC%A1%B0%EA%B1%B4%EB%B6%80_%EC%98%88%EC%B8%A1.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 따로 말이 없으면 [공분산 함수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#covariance-function-%EA%B3%B5%EB%B6%84%EC%82%B0-%ED%95%A8%EC%88%98)는 $\Sigma(x, x') = e^{-(x - x')^2}$이고, 예측 공식은 평균 $\mathbf{k}_*^\top K^{-1}\mathbf{f}$, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $\Sigma(x_*, x_*) - \mathbf{k}_*^\top K^{-1}\mathbf{k}_*$이다.

## 기본 (직접 대입)

### 문제 1

평균 0, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) 1인 두 값의 상관이 $\rho = 0.6$이다. 첫째 값이 $a = 1.5$임을 알았을 때 둘째 값의 조건부 평균과 표준편차를 구하라. (공식: $f_2 \mid f_1 = a \sim \mathcal{N}(\rho a,\ 1 - \rho^2)$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $\rho = 0.6$ (두 값의 상관)
- $a = 1.5$ (알게 된 첫째 값)

**풀이**
1. 식을 그대로 쓴다: $f_2 \mid f_1 = a \sim \mathcal{N}(\rho a,\ 1 - \rho^2)$
2. 값을 대입한다: $\mathcal{N}(0.6 \times 1.5,\ 1 - 0.6^2)$
3. 평균을 곱한다: $0.6 \times 1.5 = 0.9$
4. 제곱한다: $0.6^2 = 0.36$
5. [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 뺀다: $1 - 0.36 = 0.64$
6. 제곱근을 구한다. $\sqrt{a}$는 제곱해서 $a$가 되는 양수다: $\sqrt{0.64} = 0.8$

**답**: 평균 $0.9$, 표준편차 $0.8$ (모를 때의 표준편차 1보다 줄었다)

</details>

### 문제 2

상관 $\rho = 0.5$인 두 표준 정규 값에서 첫째가 $a = -2$이다. 둘째의 조건부 평균과 표준편차를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\rho = 0.5$ (두 값의 상관)
- $a = -2$ (알게 된 첫째 값)

**풀이**
1. 식을 그대로 쓴다: $f_2 \mid f_1 = a \sim \mathcal{N}(\rho a,\ 1 - \rho^2)$
2. 값을 대입한다: $\mathcal{N}(0.5 \times (-2),\ 1 - 0.5^2)$
3. 평균을 곱한다: $0.5 \times (-2) = -1$
4. 제곱한다: $0.5^2 = 0.25$
5. [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 뺀다: $1 - 0.25 = 0.75$
6. 제곱근을 구한다: $\sqrt{0.75} = 0.8660$

**답**: 평균 $-1$, 표준편차 $0.8660$ (첫째가 음수면 둘째 평균도 음수 쪽으로 간다)

</details>

### 문제 3

데이터가 $x_1 = 0$에서 $f(0) = 1$ 하나다. $x_* = 2$에서 예측 평균과 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x_1 = 0$, $\mathbf{f} = (1)$ (데이터 하나)
- $x_* = 2$ (예측할 입력)
- $\Sigma(x, x') = e^{-(x - x')^2}$

**풀이**
1. 식을 그대로 쓴다: 평균 $\mathbf{k}_*^\top K^{-1}\mathbf{f}$, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $\Sigma(x_*, x_*) - \mathbf{k}_*^\top K^{-1}\mathbf{k}_*$
2. 값을 대입한다: 평균 $\Sigma(2, 0)\,\Sigma(0, 0)^{-1}\,1$, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $\Sigma(2, 2) - \Sigma(2, 0)\,\Sigma(0, 0)^{-1}\,\Sigma(2, 0)$
3. $K$를 계산한다: $\Sigma(0, 0) = e^{0} = 1$, 역수 $1$
4. $\mathbf{k}_*$를 계산한다: $(2 - 0)^2 = 4$, $e^{-4} = 0.0183$ ($e$는 약 2.718)
5. 평균을 곱한다: $0.0183 \times 1 \times 1 = 0.0183$
6. [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)의 곱 부분: $0.0183 \times 1 \times 0.0183 = 0.0003$
7. 뺀다: $\Sigma(2, 2) = 1$ 이므로 $1 - 0.0003 = 0.9997$

**답**: 평균 $0.0183$, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $0.9997$. 데이터에서 멀어서 거의 아무것도 모를 때(평균 0, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) 1)와 같다.

</details>

### 문제 4

데이터가 $x_1 = 0$에서 $f(0) = 2$ 하나다. $x_* = 1$에서 예측 평균과 표준편차를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x_1 = 0$, $\mathbf{f} = (2)$ (데이터 하나)
- $x_* = 1$ (예측할 입력)
- $\Sigma(x, x') = e^{-(x - x')^2}$

**풀이**
1. 식을 그대로 쓴다: 평균 $\mathbf{k}_*^\top K^{-1}\mathbf{f}$, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $\Sigma(x_*, x_*) - \mathbf{k}_*^\top K^{-1}\mathbf{k}_*$
2. 값을 대입한다: 평균 $\Sigma(1, 0)\,\Sigma(0, 0)^{-1}\,2$, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $\Sigma(1, 1) - \Sigma(1, 0)\,\Sigma(0, 0)^{-1}\,\Sigma(1, 0)$
3. $K$를 계산한다: $\Sigma(0, 0) = 1$, 역수 $1$
4. $\mathbf{k}_*$를 계산한다: $(1 - 0)^2 = 1$, $e^{-1} = 0.3679$
5. 평균을 곱한다: $0.3679 \times 1 \times 2 = 0.7358$
6. [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)의 곱 부분: $0.3679 \times 1 \times 0.3679 = 0.1353$
7. 뺀다: $1 - 0.1353 = 0.8647$
8. 제곱근을 구한다: $\sqrt{0.8647} = 0.9299$

**답**: 평균 $0.7358$, 표준편차 $0.9299$

</details>

### 문제 5

데이터가 $x = (0, 1)$, $\mathbf{f} = (1, 2)$이다. 데이터 위의 점 $x_* = 0$에서 예측 평균과 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 구하라. [커널 행렬](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#kernel-matrix-%EC%BB%A4%EB%84%90-%ED%96%89%EB%A0%AC)은 $K = \begin{pmatrix} 1 & 0.3679 \\ 0.3679 & 1 \end{pmatrix}$이다.

<details><summary>풀이와 답</summary>

**주어진 값**
- $K = \begin{pmatrix} 1 & 0.3679 \\ 0.3679 & 1 \end{pmatrix}$ (데이터끼리 공분산)
- $\mathbf{f} = (1, 2)$ (데이터 값)
- $x_* = 0$ (데이터 점 하나와 같은 위치)

**풀이**
1. 식을 그대로 쓴다: 평균 $= \mathbf{z}^\top\mathbf{f}$, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $= \Sigma(x_*, x_*) - \mathbf{k}_*^\top\mathbf{z}$ (여기서 $\mathbf{z} = K^{-1}\mathbf{k}_*$, 즉 $K\mathbf{z} = \mathbf{k}_*$)
2. 값을 대입한다: $\mathbf{k}_* = (\Sigma(0, 0),\ \Sigma(0, 1)) = (1,\ e^{-1})$
3. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^{-1} = 0.3679$ 이므로 $\mathbf{k}_* = (1,\ 0.3679)$
4. $\mathbf{k}_*$는 $K$의 첫째 열과 똑같다. 그래서 $\mathbf{z} = (1, 0)$을 넣어 본다: $K\mathbf{z} = (1 \times 1 + 0.3679 \times 0,\ 0.3679 \times 1 + 1 \times 0) = (1, 0.3679)$ → $\mathbf{k}_*$와 같다
5. 평균을 곱해 더한다: $\mathbf{z}^\top\mathbf{f} = 1 \times 1 + 0 \times 2 = 1$
6. [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)의 곱 부분을 계산한다: $\mathbf{k}_*^\top\mathbf{z} = 1 \times 1 + 0.3679 \times 0 = 1$
7. 뺀다: $\Sigma(0, 0) = 1$ 이므로 $1 - 1 = 0$

**답**: 평균 $1$, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $0$. 데이터가 있는 점에서는 값을 정확히 알고(평균 = 데이터 값) 불확실성이 없다.

</details>

### 문제 6

데이터가 $x = (0, 2)$, $\mathbf{f} = (1, 1)$이다. 가운데 $x_* = 1$에서 예측 평균, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0), 표준편차를 구하라. [커널 행렬](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#kernel-matrix-%EC%BB%A4%EB%84%90-%ED%96%89%EB%A0%AC)은 $K = \begin{pmatrix} 1 & 0.0183 \\ 0.0183 & 1 \end{pmatrix}$이다.

<details><summary>풀이와 답</summary>

**주어진 값**
- $K = \begin{pmatrix} 1 & 0.0183 \\ 0.0183 & 1 \end{pmatrix}$ ($e^{-4} = 0.0183$)
- $\mathbf{f} = (1, 1)$
- $x_* = 1$ (예측할 입력, 두 데이터와 거리 1)

**풀이**
1. 식을 그대로 쓴다: 평균 $= \mathbf{z}^\top\mathbf{f}$, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $= \Sigma(x_*, x_*) - \mathbf{k}_*^\top\mathbf{z}$ ($K\mathbf{z} = \mathbf{k}_*$)
2. 값을 대입한다: $\mathbf{k}_* = (\Sigma(1, 0),\ \Sigma(1, 2)) = (e^{-1},\ e^{-1}) = (0.3679,\ 0.3679)$
3. $K\mathbf{z} = \mathbf{k}_*$를 푼다. 대칭이라 $z_1 = z_2 = z$: $1 \times z + 0.0183 \times z = 0.3679$
4. 묶는다: $1.0183\, z = 0.3679$
5. 나눈다: $z = 0.3679 / 1.0183 = 0.3613$
6. 평균을 곱해 더한다: $0.3613 \times 1 + 0.3613 \times 1 = 0.7225$
7. [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)의 곱 부분을 펼친다: $0.3679 \times 0.3613 + 0.3679 \times 0.3613$
8. 곱한다: $0.1329 + 0.1329 = 0.2658$
9. 뺀다: $1 - 0.2658 = 0.7342$
10. 제곱근을 구한다: $\sqrt{0.7342} = 0.8569$

**답**: 평균 $0.7225$, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $0.7342$, 표준편차 $0.8569$. 데이터가 모두 1인데 가운데는 평균 0.72로 꺼지고 불확실성도 크다. 두 데이터가 멀어서 가운데를 충분히 알려 주지 못한다.

</details>

### 문제 7

데이터가 $x = (0, 1)$, $\mathbf{f} = (0, 0)$이다(값이 모두 0). $x_* = 0.5$에서 예측 평균과 표준편차를 구하라. $K = \begin{pmatrix} 1 & 0.3679 \\ 0.3679 & 1 \end{pmatrix}$, $\mathbf{k}_* = (0.7788, 0.7788)$이다.

<details><summary>풀이와 답</summary>

**주어진 값**
- $K = \begin{pmatrix} 1 & 0.3679 \\ 0.3679 & 1 \end{pmatrix}$
- $\mathbf{k}_* = (0.7788, 0.7788)$ ($e^{-0.25} = 0.7788$)
- $\mathbf{f} = (0, 0)$

**풀이**
1. 식을 그대로 쓴다: 평균 $= \mathbf{k}_*^\top K^{-1}\mathbf{f}$, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $= \Sigma(x_*, x_*) - \mathbf{k}_*^\top K^{-1}\mathbf{k}_*$
2. 값을 대입한다 (평균): $\mathbf{k}_*^\top K^{-1}\begin{pmatrix}0\\0\end{pmatrix}$
3. $\mathbf{f}$가 0 벡터이니 $K^{-1}\mathbf{f} = (0, 0)$이고, 평균은 $0.7788 \times 0 + 0.7788 \times 0 = 0$
4. [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)은 $\mathbf{f}$와 무관하다. $K\mathbf{z} = \mathbf{k}_*$를 푼다 (대칭이라 $z_1 = z_2 = z$): $1.3679\, z = 0.7788$
5. 나눈다: $z = 0.7788 / 1.3679 = 0.5693$
6. 곱해서 더한다: $0.7788 \times 0.5693 + 0.7788 \times 0.5693 = 0.4434 + 0.4434 = 0.8868$
7. 뺀다: $1 - 0.8868 = 0.1132$
8. 제곱근을 구한다: $\sqrt{0.1132} = 0.3364$

**답**: 평균 $0$, 표준편차 $0.3364$. [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)(불확실성)은 데이터 값이 아니라 데이터의 위치만으로 정해진다.

</details>

### 문제 8

데이터가 $x_1 = 0$에서 $f(0) = 1$ 하나일 때 $x_* = 0.5$와 $x_* = 2$ 중 어디의 예측이 더 확실한지 표준편차를 비교해 답하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x_1 = 0$, $\mathbf{f} = (1)$
- 비교할 두 점 $x_* = 0.5$, $x_* = 2$
- $\Sigma(x, x') = e^{-(x - x')^2}$

**풀이**
1. 식을 그대로 쓴다: [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $= \Sigma(x_*, x_*) - \Sigma(x_*, 0)^2 / \Sigma(0, 0)$ (데이터 하나라 $K = (1)$)
2. 값을 대입한다 ($x_* = 0.5$): [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $= 1 - e^{-(0.5 - 0)^2}\,\times e^{-(0.5 - 0)^2}$
3. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^{-0.25} = 0.7788$
4. 곱한다: $0.7788 \times 0.7788 = 0.6065$
5. 뺀다: $1 - 0.6065 = 0.3935$, 제곱근 $\sqrt{0.3935} = 0.6273$
6. 값을 대입한다 ($x_* = 2$): [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $= 1 - e^{-(2 - 0)^2}\,\times e^{-(2 - 0)^2}$
7. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^{-4} = 0.0183$
8. 곱한다: $0.0183 \times 0.0183 = 0.0003$
9. 뺀다: $1 - 0.0003 = 0.9997$, 제곱근 $\sqrt{0.9997} = 0.9998$

**답**: $x_* = 0.5$는 표준편차 **0.6273**, $x_* = 2$는 **0.9998**. 데이터에 가까운 $x_* = 0.5$가 더 확실하다. 멀어지면 표준편차가 처음 값 1로 돌아간다.

</details>

## 강의와 연결

### 문제 9

[Lec13 4.3](../../Lec13_%ED%91%9C%ED%98%84_%ED%95%99%EC%8A%B5_%EC%9D%B4%EB%A1%A0.md#43-%EC%A0%95%EC%8B%9D-%EC%A0%95%EC%9D%98)의 정의대로 입력 $0, 1, 2$에서 함수 값 $(f(0), f(1), f(2))$이 $\mathcal{N}(\mathbf{0}, K)$를 따른다. $\Sigma(x, x') = e^{-(x - x')^2}$로 $3 \times 3$ [공분산 행렬](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#covariance-matrix-%EA%B3%B5%EB%B6%84%EC%82%B0-%ED%96%89%EB%A0%AC) $K$를 만들라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 입력 $x_1 = 0$, $x_2 = 1$, $x_3 = 2$
- $\Sigma(x, x') = e^{-(x - x')^2}$

**풀이**
1. 식을 그대로 쓴다: $K_{ij} = \Sigma(x_i, x_j) = e^{-(x_i - x_j)^2}$
2. 값을 대입한다: $K_{ij} = e^{-(x_i - x_j)^2}$, $x = (0, 1, 2)$ ($3 \times 3$ 칸을 하나씩 채운다)
3. 대각 칸 ($i = j$): 거리 0, $e^{0} = 1$ (세 칸 모두)
4. 거리 1인 칸 $(1, 2)$, $(2, 3)$: $e^{-1^2} = e^{-1} = 0.3679$
5. 거리 2인 칸 $(1, 3)$: $e^{-2^2} = e^{-4} = 0.0183$
6. 대칭이다: $K_{ij} = K_{ji}$이므로 나머지 칸도 같은 값으로 채운다

**답**: $K = \begin{pmatrix} 1 & 0.3679 & 0.0183 \\ 0.3679 & 1 & 0.3679 \\ 0.0183 & 0.3679 & 1 \end{pmatrix}$. 가까운 입력일수록 값이 함께 움직인다(공분산이 크다).

</details>

### 문제 10

[Lec13 4.5](../../Lec13_%ED%91%9C%ED%98%84_%ED%95%99%EC%8A%B5_%EC%9D%B4%EB%A1%A0.md#45-%EB%8D%B0%EC%9D%B4%ED%84%B0%EB%A1%9C-%EC%A1%B0%EA%B1%B4-%EA%B1%B8%EA%B8%B0-%EC%98%88%EC%B8%A1)의 예측 평균은 [MM47_커널_보간](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/10_%ED%91%9C%ED%98%84_%ED%95%99%EC%8A%B5/MM47_%EC%BB%A4%EB%84%90_%EB%B3%B4%EA%B0%84.md)의 커널 [보간](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#interpolation-%EB%B3%B4%EA%B0%84) 함수와 같다고 한다. 데이터 $x = (0, 1)$, $\mathbf{f} = (0, 1)$에서 $x_* = 0.5$의 예측 평균을 (가) 높이 $K^{-1}\mathbf{f}$를 풀어 [가우스 과정](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gaussian-process-%EA%B0%80%EC%9A%B0%EC%8A%A4-%EA%B3%BC%EC%A0%95) 식으로, (나) 커널 [보간](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#interpolation-%EB%B3%B4%EA%B0%84) $f(0.5) = \sum_i \alpha_i k(0.5, x_i)$로 각각 구해 같음을 확인하라. $K = \begin{pmatrix} 1 & 0.3679 \\ 0.3679 & 1 \end{pmatrix}$, $\mathbf{k}_* = (0.7788, 0.7788)$이다.

<details><summary>풀이와 답</summary>

**주어진 값**
- $K = \begin{pmatrix} 1 & 0.3679 \\ 0.3679 & 1 \end{pmatrix}$, $\mathbf{f} = (0, 1)$
- $\mathbf{k}_* = (0.7788, 0.7788)$ ($x_* = 0.5$와 두 데이터의 공분산)

**풀이**
1. (가) 식을 그대로 쓴다: 평균 $= \mathbf{k}_*^\top K^{-1}\mathbf{f}$. 먼저 $\boldsymbol{\alpha} = K^{-1}\mathbf{f}$, 즉 $K\boldsymbol{\alpha} = \mathbf{f}$를 푼다
2. 값을 대입해 두 식으로 펼친다: $\alpha_1 + 0.3679\,\alpha_2 = 0$, $0.3679\,\alpha_1 + \alpha_2 = 1$
3. 첫 식에서 $\alpha_1 = -0.3679\,\alpha_2$
4. 둘째 식에 넣는다: $0.3679 \times (-0.3679\,\alpha_2) + \alpha_2 = 1$, 곧 $(1 - 0.1353)\,\alpha_2 = 0.8647\,\alpha_2 = 1$
5. 나눈다: $\alpha_2 = 1 / 0.8647 = 1.1565$
6. $\alpha_1$을 구한다: $-0.3679 \times 1.1565 = -0.4255$
7. 평균을 구한다: $\mathbf{k}_*^\top\boldsymbol{\alpha} = 0.7788 \times (-0.4255) + 0.7788 \times 1.1565$
8. 곱한다: $-0.3314 + 0.9007$
9. 더한다: $0.5693$
10. (나) 식을 쓴다: $f(0.5) = \alpha_1\,k(0.5, 0) + \alpha_2\,k(0.5, 1)$
11. 값을 대입한다: $f(0.5) = -0.4255 \times e^{-0.25} + 1.1565 \times e^{-0.25}$, $e^{-0.25} = 0.7788$ 이므로 같은 계산이 되어 $0.5693$

**답**: 두 방법 모두 **0.5693**. $\mathbf{k}_*^\top K^{-1}\mathbf{f}$의 $K^{-1}\mathbf{f}$가 [보간](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#interpolation-%EB%B3%B4%EA%B0%84)의 높이 $\boldsymbol{\alpha}$이기 때문이다. 이 데이터에서 조건부 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)은 $0.1132$(표준편차 $0.3364$)로, [보간](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#interpolation-%EB%B3%B4%EA%B0%84)에는 없는 불확실성 정보를 [가우스 과정](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gaussian-process-%EA%B0%80%EC%9A%B0%EC%8A%A4-%EA%B3%BC%EC%A0%95)이 더 준다.

</details>
