# 예제: 온도 소프트맥스와 지식 증류

개념 노트: [MM65_온도_소프트맥스와_지식_증류](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/12_%EA%B0%95%EA%B1%B4%EC%84%B1%EA%B3%BC_%EC%A0%84%EC%9D%B4/MM65_%EC%98%A8%EB%8F%84_%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4%EC%99%80_%EC%A7%80%EC%8B%9D_%EC%A6%9D%EB%A5%98.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 쓰는 식은 셋이다. 온도 [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4) $p_i(T) = e^{z_i/T} / \sum_j e^{z_j/T}$, [KL 발산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#kl-divergence-kl-%EB%B0%9C%EC%82%B0) $D_{KL}(p \,\|\, q) = \sum_i p_i \ln(p_i/q_i)$, 증류 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $\mathcal{L}_{\text{KD}} = (1-\alpha)\big(-\ln q_y(1)\big) + \alpha\,T^2 D_{KL}\big(p(T) \,\|\, q(T)\big)$. $e$는 약 2.718인 수이고 $e^{a}$는 그 $a$제곱이다. $\ln x$는 $e$를 몇 제곱해야 $x$가 되는지다 (계산기·코드로 구한다).

## 기본 (직접 대입)

### 문제 1

[로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93)이 $\mathbf{z} = (2, 1, 0)$일 때 보통 [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)($T = 1$)의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{z} = (2, 1, 0)$ ([로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93))
- $T = 1$ (온도)

**풀이**
1. 식을 그대로 쓴다: $p_i(T) = \dfrac{e^{z_i/T}}{\sum_j e^{z_j/T}}$
2. 값을 대입한다 (Σ를 세 항으로 펼침): $p_1 = \dfrac{e^{2/1}}{e^{2/1} + e^{1/1} + e^{0/1}}$ (나머지 둘은 분자만 바뀐다)
3. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98) 안의 나눗셈을 한다: $2/1 = 2$, $1/1 = 1$, $0/1 = 0$
4. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^{2} = 7.3891$, $e^{1} = 2.7183$, $e^{0} = 1$
5. 분모를 더한다: $7.3891 + 2.7183 + 1 = 11.1074$
6. 각 칸을 나눈다: $7.3891 / 11.1074 = 0.6652$, $2.7183 / 11.1074 = 0.2447$, $1 / 11.1074 = 0.0900$

**답**: $(0.6652, 0.2447, 0.0900)$.

</details>

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{z} = (2, 1, 0)$ ([로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93))
- $T = 2$ (온도)

**풀이**
1. 식을 그대로 쓴다: $p_i(T) = \dfrac{e^{z_i/T}}{\sum_j e^{z_j/T}}$
2. 값을 대입한다: $p_1 = \dfrac{e^{2/2}}{e^{2/2} + e^{1/2} + e^{0/2}}$
3. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98) 안의 나눗셈을 한다: $2/2 = 1$, $1/2 = 0.5$, $0/2 = 0$

5. 분모를 더한다: $2.7183 + 1.6487 + 1 = 5.3670$

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{z} = (2, 1, 0)$ ([로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93))

**풀이**
1. 식을 그대로 쓴다: $p_i(T) = \dfrac{e^{z_i/T}}{\sum_j e^{z_j/T}}$
2. 값을 대입한다: $p_1 = \dfrac{e^{2/0.5}}{e^{2/0.5} + e^{1/0.5} + e^{0/0.5}}$
3. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98) 안의 나눗셈을 한다: $2/0.5 = 4$, $1/0.5 = 2$, $0/0.5 = 0$

**답**: $(0.8668, 0.1173, 0.0159)$. 1등 칸의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은 $T = 0.5$에서 $0.8668$, $T = 1$에서 $0.6652$, $T = 2$에서 $0.5065$다. 온도가 낮을수록 분포가 뾰족해지고([원-핫](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#one-hot-encoding-%EC%9B%90-%ED%95%AB-%EC%9D%B8%EC%BD%94%EB%94%A9)에 가까워지고), 높을수록 평평해진다.

</details>

### 문제 4

학생이 $T = 1$에서 낸 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 $q = (0.7, 0.2, 0.1)$이다. [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)이 1번 칸일 때와 3번 칸일 때 하드 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $-\ln q_y$를 각각 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $q = (0.7, 0.2, 0.1)$ (학생의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0), $T = 1$)
- $y = 1$ 또는 $y = 3$ ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) 칸)

**풀이**
1. 식을 그대로 쓴다: 하드 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $= -\ln q_y$
2. $y = 1$을 대입한다: $-\ln q_1 = -\ln 0.7$
3. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 계산한다 ($\ln 0.7$은 $e$를 몇 제곱해야 $0.7$인지, 1보다 작은 수라서 음수): $\ln 0.7 = -0.3567$
4. 부호를 바꾼다: $-\ln 0.7 = 0.3567$
5. $y = 3$을 대입한다: $-\ln q_3 = -\ln 0.1$
6. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 계산한다: $\ln 0.1 = -2.3026$
7. 부호를 바꾼다: $-\ln 0.1 = 2.3026$

**답**: [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)이 1번이면 $0.3567$, 3번이면 $2.3026$. 학생이 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) 칸에 낮은 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 줄수록 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 크다.

</details>

### 문제 5

교사의 분포가 $p = (0.5, 0.5)$, 학생의 분포가 $q = (0.8, 0.2)$이다. [KL 발산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#kl-divergence-kl-%EB%B0%9C%EC%82%B0) $D_{KL}(p \,\|\, q)$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p = (0.5, 0.5)$ (교사의 분포)
- $q = (0.8, 0.2)$ (학생의 분포)

**풀이**
1. 식을 그대로 쓴다: $D_{KL}(p \,\|\, q) = \sum_i p_i \ln \dfrac{p_i}{q_i}$
2. 값을 대입한다 (Σ를 두 항으로 펼침): $D_{KL} = 0.5 \ln \dfrac{0.5}{0.8} + 0.5 \ln \dfrac{0.5}{0.2}$
3. 비율을 나눈다: $0.5 / 0.8 = 0.625$, $0.5 / 0.2 = 2.5$
4. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 씌운다: $\ln 0.625 = -0.4700$, $\ln 2.5 = 0.9163$
5. 교사 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 곱한다: $0.5 \times (-0.4700) = -0.2350$, $0.5 \times 0.9163 = 0.4582$
6. 더한다: $-0.2350 + 0.4582 = 0.2231$

**답**: $0.2231$. KL은 0 이상이고, 두 분포가 같을 때만 0이다.

</details>

### 문제 6

두 칸 문제에서 교사의 [소프트 타깃](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#soft-target-%EC%86%8C%ED%94%84%ED%8A%B8-%ED%83%80%EA%B9%83)이 $T = 2$에서 $p(2) = (0.8, 0.2)$이다. 학생의 [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93)은 $\mathbf{z} = (2, 0)$이고 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)은 1번 칸이다. $\alpha = 0.5$일 때 증류 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $\mathcal{L}_{\text{KD}}$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p(2) = (0.8, 0.2)$ (교사의 [소프트 타깃](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#soft-target-%EC%86%8C%ED%94%84%ED%8A%B8-%ED%83%80%EA%B9%83))
- $\mathbf{z} = (2, 0)$ (학생 [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93)), $y = 1$ ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) 칸)
- $T = 2$ (온도), $\alpha = 0.5$ (소프트 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) 비중)

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_{\text{KD}} = (1 - \alpha)\big(-\ln q_y(1)\big) + \alpha\,T^2 \sum_i p_i \ln \dfrac{p_i}{q_i(2)}$
2. 값을 대입한다: $\mathcal{L}_{\text{KD}} = (1 - 0.5)\big(-\ln q_1(1)\big) + 0.5 \times 2^2 \Big(0.8 \ln \dfrac{0.8}{q_1(2)} + 0.2 \ln \dfrac{0.2}{q_2(2)}\Big)$
3. 학생의 $T = 1$ [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구한다: $q_1(1) = \dfrac{e^{2}}{e^{2} + e^{0}} = \dfrac{7.3891}{8.3891} = 0.8808$
4. 하드 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 구한다: $-\ln 0.8808 = 0.12693$
5. 학생의 $T = 2$ [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구한다: $z/T = (1, 0)$ 이므로 $q_1(2) = \dfrac{e^{1}}{e^{1} + e^{0}} = \dfrac{2.7183}{3.7183} = 0.7311$, $q_2(2) = 1 - 0.7311 = 0.2689$
6. 비율을 나눈다: $0.8 / 0.7311 = 1.0943$, $0.2 / 0.2689 = 0.7437$
7. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 씌운다: $\ln 1.0943 = 0.09012$, $\ln 0.7437 = -0.29618$
8. 교사 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 곱한다: $0.8 \times 0.09012 = 0.07210$, $0.2 \times (-0.29618) = -0.05924$
9. Σ를 더한다: $0.07210 + (-0.05924) = 0.01286$ ([KL 발산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#kl-divergence-kl-%EB%B0%9C%EC%82%B0))
10. $T^2$를 곱한다: $2^2 = 4$ 이므로 $4 \times 0.01286 = 0.05144$
11. 비중을 곱한다: $(1 - 0.5) \times 0.12693 = 0.06347$, $0.5 \times 0.05144 = 0.02572$
12. 더한다: $0.06347 + 0.02572 = 0.08919$

**답**: $\mathcal{L}_{\text{KD}} = 0.0892$. KL 항이 작은 것은 학생의 $q(2) = (0.7311, 0.2689)$가 이미 교사의 $(0.8, 0.2)$에 가깝기 때문이다.

### 문제 7

어떤 [학습](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5) 단계에서 하드 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 $0.4$, $T^2 \times D_{KL}$이 $0.8$이다. $\alpha = 0.25$일 때 증류 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은? $\alpha$를 $0$과 $1$로 놓으면 각각 무엇이 되는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- 하드 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $= 0.4$, $T^2 D_{KL} = 0.8$ (두 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98))
- $\alpha = 0.25$ (소프트 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) 비중)

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_{\text{KD}} = (1 - \alpha) \times \text{하드 손실} + \alpha \times T^2 D_{KL}$
2. 값을 대입한다: $\mathcal{L}_{\text{KD}} = (1 - 0.25) \times 0.4 + 0.25 \times 0.8$
3. 괄호를 계산한다: $1 - 0.25 = 0.75$ 이므로 $\mathcal{L}_{\text{KD}} = 0.75 \times 0.4 + 0.25 \times 0.8$
4. 곱한다: $0.75 \times 0.4 = 0.3$, $0.25 \times 0.8 = 0.2$
5. 더한다: $0.3 + 0.2 = 0.5$
6. $\alpha = 0$을 대입한다: $(1 - 0) \times 0.4 + 0 \times 0.8 = 0.4$
7. $\alpha = 1$을 대입한다: $(1 - 1) \times 0.4 + 1 \times 0.8 = 0.8$

**답**: $\alpha = 0.25$에서 $0.5$. $\alpha = 0$이면 하드 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)만($0.4$, 보통의 [학습](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5)), $\alpha = 1$이면 소프트 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)만($0.8$)이 남는다. $\alpha$는 두 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 섞는 손잡이다.

</details>

### 문제 8

$T = 4$에서 교사의 분포가 $p = (0.4, 0.3, 0.2, 0.1)$이고 학생이 아무것도 모르고 $q = (0.25, 0.25, 0.25, 0.25)$를 낸다. [KL 발산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#kl-divergence-kl-%EB%B0%9C%EC%82%B0)과 $T^2 \times D_{KL}$을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p = (0.4, 0.3, 0.2, 0.1)$ (교사, $T = 4$)
- $q = (0.25, 0.25, 0.25, 0.25)$ (학생, 균등 분포)
- $T = 4$ (온도)

**풀이**
1. 식을 그대로 쓴다: $D_{KL}(p \,\|\, q) = \sum_i p_i \ln \dfrac{p_i}{q_i}$
2. 값을 대입한다 (Σ를 네 항으로 펼침): $0.4 \ln \dfrac{0.4}{0.25} + 0.3 \ln \dfrac{0.3}{0.25} + 0.2 \ln \dfrac{0.2}{0.25} + 0.1 \ln \dfrac{0.1}{0.25}$
3. 비율을 나눈다: $0.4/0.25 = 1.6$, $0.3/0.25 = 1.2$, $0.2/0.25 = 0.8$, $0.1/0.25 = 0.4$
4. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 씌운다: $\ln 1.6 = 0.47000$, $\ln 1.2 = 0.18232$, $\ln 0.8 = -0.22314$, $\ln 0.4 = -0.91629$
5. 교사 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 곱한다: $0.4 \times 0.47000 = 0.18800$, $0.3 \times 0.18232 = 0.05470$, $0.2 \times (-0.22314) = -0.04463$, $0.1 \times (-0.91629) = -0.09163$
6. 더한다: $0.18800 + 0.05470 - 0.04463 - 0.09163 = 0.10644$
7. $T^2$을 구한다: $4^2 = 16$
8. 곱한다: $16 \times 0.10644 = 1.703$

**답**: $D_{KL} = 0.1064$, $T^2 D_{KL} = 1.703$. 온도로 작아진 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)를 $T^2 = 16$배로 되살려 하드 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)과 크기를 맞춘다.

</details>

### 문제 9

Lec18 5.2의 "[소프트 타깃](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#soft-target-%EC%86%8C%ED%94%84%ED%8A%B8-%ED%83%80%EA%B9%83)이 주는 정보"다. 교사의 [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93)이 $\mathbf{z} = (3, 2, 0)$ (고양이, 호랑이, 개)이다. $T = 1$과 $T = 2$에서의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 각각 구하고, 개 칸이 호랑이 칸의 몇 분의 1인지 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{z} = (3, 2, 0)$ (교사 [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93): 고양이, 호랑이, 개)
- $T = 1$ 또는 $T = 2$ (온도)

**풀이**
1. 식을 그대로 쓴다: $p_i(T) = \dfrac{e^{z_i/T}}{\sum_j e^{z_j/T}}$
2. $T = 1$을 대입한다: $p_1 = \dfrac{e^{3}}{e^{3} + e^{2} + e^{0}}$ (나머지 둘은 분자만 바뀐다)
3. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^{3} = 20.0855$, $e^{2} = 7.3891$, $e^{0} = 1$
4. 더하고 나눈다: $20.0855 + 7.3891 + 1 = 28.4746$ 이므로 $(20.0855, 7.3891, 1) / 28.4746 = (0.7054, 0.2595, 0.0351)$
5. $T = 2$를 대입한다: [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93)을 나눈다 $z/T = (1.5, 1, 0)$ 이므로 $p_1 = \dfrac{e^{1.5}}{e^{1.5} + e^{1} + e^{0}}$
6. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^{1.5} = 4.4817$, $e^{1} = 2.7183$, $e^{0} = 1$
7. 더하고 나눈다: $4.4817 + 2.7183 + 1 = 8.2$ 이므로 $(4.4817, 2.7183, 1) / 8.2 = (0.5465, 0.3315, 0.1220)$
8. 호랑이 대 개의 비를 구한다: $T = 1$에서 $0.2595 / 0.0351 = 7.39$, $T = 2$에서 $0.3315 / 0.1220 = 2.72$

**답**: $T = 1$은 $(0.7054, 0.2595, 0.0351)$, $T = 2$는 $(0.5465, 0.3315, 0.1220)$. 개 칸이 호랑이 칸의 $1/7.39$에서 $1/2.72$로 올라와, "호랑이를 닮았고 개는 훨씬 덜 닮았다"는 순서 정보가 더 잘 보인다.

</details>

### 문제 10

Lec18 5.1에서 [원-핫](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#one-hot-encoding-%EC%9B%90-%ED%95%AB-%EC%9D%B8%EC%BD%94%EB%94%A9) [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) 라벨을 교사로 보면 보통의 [교차 엔트로피](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cross-entropy-%EA%B5%90%EC%B0%A8-%EC%97%94%ED%8A%B8%EB%A1%9C%ED%94%BC)가 증류의 특수한 경우다. 학생의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 $q = (0.5, 0.3, 0.2)$일 때 (a) [원-핫](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#one-hot-encoding-%EC%9B%90-%ED%95%AB-%EC%9D%B8%EC%BD%94%EB%94%A9) 교사 $p = (1, 0, 0)$의 $D_{KL}(p \,\|\, q)$와 하드 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $-\ln q_1$을 비교하라. (b) 소프트 교사 $p = (0.6, 0.3, 0.1)$의 $D_{KL}(p \,\|\, q)$를 구하라.

<details><summary>풀이와 답</summary>

$p_i = 0$인 칸의 항 $0 \times \ln(\cdot)$은 0으로 친다.

**주어진 값**
- $q = (0.5, 0.3, 0.2)$ (학생의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- (a) $p = (1, 0, 0)$ ([원-핫](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#one-hot-encoding-%EC%9B%90-%ED%95%AB-%EC%9D%B8%EC%BD%94%EB%94%A9) 교사), (b) $p = (0.6, 0.3, 0.1)$ (소프트 교사)

**풀이**
1. 식을 그대로 쓴다: $D_{KL}(p \,\|\, q) = \sum_i p_i \ln \dfrac{p_i}{q_i}$
2. (a)를 대입한다 (Σ를 세 항으로 펼침): $1 \times \ln \dfrac{1}{0.5} + 0 + 0$
3. 비율을 나누고 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 씌운다: $1 / 0.5 = 2$, $\ln 2 = 0.6931$ 이므로 $D_{KL} = 0.6931$
4. 하드 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 구한다: $-\ln 0.5 = 0.6931$ 으로 같다
5. (b)를 대입한다: $0.6 \ln \dfrac{0.6}{0.5} + 0.3 \ln \dfrac{0.3}{0.3} + 0.1 \ln \dfrac{0.1}{0.2}$
6. 비율을 나눈다: $0.6/0.5 = 1.2$, $0.3/0.3 = 1$, $0.1/0.2 = 0.5$
7. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 씌운다: $\ln 1.2 = 0.1823$, $\ln 1 = 0$, $\ln 0.5 = -0.6931$
8. 교사 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 곱한다: $0.6 \times 0.1823 = 0.1094$, $0.3 \times 0 = 0$, $0.1 \times (-0.6931) = -0.0693$
9. 더한다: $0.1094 + 0 - 0.0693 = 0.0401$

**답**: (a) $D_{KL} = 0.6931 = -\ln q_1$ ([원-핫](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#one-hot-encoding-%EC%9B%90-%ED%95%AB-%EC%9D%B8%EC%BD%94%EB%94%A9) 교사의 KL은 하드 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)과 같다), (b) $0.0401$. 소프트 교사는 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) 칸 말고도 2번, 3번 칸의 크기까지 학생이 따라가게 만든다.

</details>
