# 예제: 그래디언트 반전과 도메인 적대 학습

개념 노트: [MM66_그래디언트_반전과_도메인_적대_학습](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/12_%EA%B0%95%EA%B1%B4%EC%84%B1%EA%B3%BC_%EC%A0%84%EC%9D%B4/MM66_%EA%B7%B8%EB%9E%98%EB%94%94%EC%96%B8%ED%8A%B8_%EB%B0%98%EC%A0%84%EA%B3%BC_%EB%8F%84%EB%A9%94%EC%9D%B8_%EC%A0%81%EB%8C%80_%ED%95%99%EC%8A%B5.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 쓰는 식은 셋이다. 목적 함수 $E = \mathcal{L}_y - \lambda\,\mathcal{L}_d$, [그래디언트 반전 층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-reversal-layer-%EA%B7%B8%EB%9E%98%EB%94%94%EC%96%B8%ED%8A%B8-%EB%B0%98%EC%A0%84-%EC%B8%B5)을 지난 갱신 $w \leftarrow w - \eta\left(\dfrac{\partial \mathcal{L}_y}{\partial h} - \lambda \dfrac{\partial \mathcal{L}_d}{\partial h}\right)\dfrac{\partial h}{\partial w}$, 도메인 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $\mathcal{L}_d = -\dfrac{1}{N}\sum_n \big[d_n \ln \hat d_n + (1 - d_n)\ln(1 - \hat d_n)\big]$ ($\hat d_n = \sigma(u h_n + c)$). $\sigma(z) = 1/(1 + e^{-z})$이고 $e$는 약 2.718인 수, $\ln x$는 $e$를 몇 제곱해야 $x$가 되는지다 (계산기·코드로 구한다).

## 기본 (직접 대입)

### 문제 1

라벨 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 $\mathcal{L}_y = 0.4$, 도메인 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 $\mathcal{L}_d = 0.6$이고 $\lambda = 0.3$이다. 목적 함수 $E$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathcal{L}_y = 0.4$ (범주 예측 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98))
- $\mathcal{L}_d = 0.6$ (도메인 예측 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98))
- $\lambda = 0.3$ (도메인 항의 비중)

**풀이**
1. 식을 그대로 쓴다: $E = \mathcal{L}_y - \lambda\,\mathcal{L}_d$
2. 값을 대입한다: $E = 0.4 - 0.3 \times 0.6$
3. 곱셈을 먼저 한다: $0.3 \times 0.6 = 0.18$ 이므로 $E = 0.4 - 0.18$
4. 뺀다: $0.4 - 0.18 = 0.22$

**답**: $E = 0.22$.

</details>

### 문제 2

특징 $h$로 가는 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 라벨 쪽 $\partial \mathcal{L}_y/\partial h = 0.5$, 도메인 쪽 $\partial \mathcal{L}_d/\partial h = 0.9$이다. $\lambda = 0.4$일 때 [그래디언트 반전 층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-reversal-layer-%EA%B7%B8%EB%9E%98%EB%94%94%EC%96%B8%ED%8A%B8-%EB%B0%98%EC%A0%84-%EC%B8%B5)을 지난 뒤 특징으로 가는 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)를 구하고, 반전이 없을 때와 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\partial \mathcal{L}_y/\partial h = 0.5$ (라벨 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0))
- $\partial \mathcal{L}_d/\partial h = 0.9$ (도메인 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0))
- $\lambda = 0.4$ (반전 세기)

**풀이**
1. 식을 그대로 쓴다: [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $= \dfrac{\partial \mathcal{L}_y}{\partial h} - \lambda \dfrac{\partial \mathcal{L}_d}{\partial h}$
2. 값을 대입한다: [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $= 0.5 - 0.4 \times 0.9$
3. 곱셈을 먼저 한다: $0.4 \times 0.9 = 0.36$ 이므로 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $= 0.5 - 0.36$
4. 뺀다: $0.5 - 0.36 = 0.14$
5. 반전 없이 더하면: $0.5 + 0.9 = 1.4$

**답**: 반전 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)을 지나면 $0.14$, 반전이 없으면 $1.4$. 도메인 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 $-\lambda$배로 뒤집혀 들어오기 때문에 특징은 도메인을 맞히는 쪽의 반대로 움직인다.

</details>

### 문제 3

특징 추출기가 $h = w x$ 하나뿐이다. $w = 2$, $x = 3$, $\partial \mathcal{L}_y/\partial h = 0.5$, $\partial \mathcal{L}_d/\partial h = 0.9$, $\lambda = 0.4$, $\eta = 0.1$일 때 갱신한 $w$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $w = 2$ (지금 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)), $x = 3$ (입력)
- $\partial \mathcal{L}_y/\partial h = 0.5$, $\partial \mathcal{L}_d/\partial h = 0.9$ (두 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0))
- $\lambda = 0.4$ (반전 세기), $\eta = 0.1$ ([학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0))

**풀이**
1. 식을 그대로 쓴다: $w \leftarrow w - \eta\left(\dfrac{\partial \mathcal{L}_y}{\partial h} - \lambda \dfrac{\partial \mathcal{L}_d}{\partial h}\right)\dfrac{\partial h}{\partial w}$
2. 값을 대입한다 ($h = wx$라 $\partial h/\partial w = x = 3$): $w \leftarrow 2 - 0.1 \times (0.5 - 0.4 \times 0.9) \times 3$
3. 괄호 안 곱셈을 한다: $0.4 \times 0.9 = 0.36$ 이므로 $w \leftarrow 2 - 0.1 \times (0.5 - 0.36) \times 3$
4. 괄호 안 뺄셈을 한다: $0.5 - 0.36 = 0.14$ 이므로 $w \leftarrow 2 - 0.1 \times 0.14 \times 3$
5. 입력을 곱한다: $0.14 \times 3 = 0.42$ 이므로 $w \leftarrow 2 - 0.1 \times 0.42$
6. [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0)을 곱한다: $0.1 \times 0.42 = 0.042$ 이므로 $w \leftarrow 2 - 0.042$
7. 뺀다: $2 - 0.042 = 1.958$

**답**: $w = 1.958$. 반전이 없었다면 $2 - 0.1 \times 1.4 \times 3 = 1.58$로 훨씬 많이 움직였을 것이다.

</details>

### 문제 4

원천 표본과 목표 표본의 특징이 모두 $h = 2$이다. [판별기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#generator-discriminator-%EC%83%9D%EC%84%B1%EA%B8%B0%EC%99%80-%ED%8C%90%EB%B3%84%EA%B8%B0)가 $\hat d = \sigma(2h - 4)$일 때 도메인 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 구하라 (원천 $d = 0$, 목표 $d = 1$, $N = 2$).

<details><summary>풀이와 답</summary>

**주어진 값**
- $h_1 = 2$, $d_1 = 0$ (원천 표본)
- $h_2 = 2$, $d_2 = 1$ (목표 표본)
- $u = 2$, $c = -4$ ([판별기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#generator-discriminator-%EC%83%9D%EC%84%B1%EA%B8%B0%EC%99%80-%ED%8C%90%EB%B3%84%EA%B8%B0)), $N = 2$ (표본 수)

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_d = -\dfrac{1}{N}\sum_{n=1}^{N}\big[d_n \ln \hat d_n + (1 - d_n)\ln(1 - \hat d_n)\big]$
2. 값을 대입한다 (Σ를 두 항으로 펼침): $\mathcal{L}_d = -\dfrac{1}{2}\big[0 \cdot \ln \hat d_1 + (1 - 0)\ln(1 - \hat d_1) + 1 \cdot \ln \hat d_2 + (1 - 1)\ln(1 - \hat d_2)\big]$
3. 0을 곱한 항을 지운다: $\mathcal{L}_d = -\dfrac{1}{2}\big[\ln(1 - \hat d_1) + \ln \hat d_2\big]$
4. [판별기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#generator-discriminator-%EC%83%9D%EC%84%B1%EA%B8%B0%EC%99%80-%ED%8C%90%EB%B3%84%EA%B8%B0) 입력을 계산한다: $2 \times 2 - 4 = 0$ (두 표본 모두)
5. [시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C)를 계산한다: $\hat d_1 = \hat d_2 = \sigma(0) = \dfrac{1}{1 + e^{0}} = \dfrac{1}{1 + 1} = 0.5$
6. 1에서 뺀다: $1 - 0.5 = 0.5$ 이므로 $\mathcal{L}_d = -\dfrac{1}{2}\big[\ln 0.5 + \ln 0.5\big]$
7. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 계산한다: $\ln 0.5 = -0.6931$
8. 더한다: $-0.6931 + (-0.6931) = -1.3863$
9. $-\dfrac{1}{2}$을 곱한다: $-\dfrac{1}{2} \times (-1.3863) = 0.6931$

**답**: $\mathcal{L}_d = 0.6931 = \ln 2$. 두 도메인의 특징이 같아서 [판별기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#generator-discriminator-%EC%83%9D%EC%84%B1%EA%B8%B0%EC%99%80-%ED%8C%90%EB%B3%84%EA%B8%B0)가 찍기밖에 못 하는 [우연 수준](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#chance-level-%EC%9A%B0%EC%97%B0-%EC%88%98%EC%A4%80)이다.

</details>

### 문제 5

원천 표본의 특징이 $h = 0$, 목표 표본의 특징이 $h = 3$이다. [판별기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#generator-discriminator-%EC%83%9D%EC%84%B1%EA%B8%B0%EC%99%80-%ED%8C%90%EB%B3%84%EA%B8%B0)가 $\hat d = \sigma(h - 2)$ ($u = 1$, $c = -2$)일 때 도메인 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $h_1 = 0$, $d_1 = 0$ (원천 표본)
- $h_2 = 3$, $d_2 = 1$ (목표 표본)
- $u = 1$, $c = -2$ ([판별기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#generator-discriminator-%EC%83%9D%EC%84%B1%EA%B8%B0%EC%99%80-%ED%8C%90%EB%B3%84%EA%B8%B0)), $N = 2$

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_d = -\dfrac{1}{N}\sum_{n=1}^{N}\big[d_n \ln \hat d_n + (1 - d_n)\ln(1 - \hat d_n)\big]$
2. 값을 대입하고 0을 곱한 항을 지운다: $\mathcal{L}_d = -\dfrac{1}{2}\big[\ln(1 - \hat d_1) + \ln \hat d_2\big]$
3. [판별기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#generator-discriminator-%EC%83%9D%EC%84%B1%EA%B8%B0%EC%99%80-%ED%8C%90%EB%B3%84%EA%B8%B0) 입력을 계산한다: $1 \times 0 - 2 = -2$, $1 \times 3 - 2 = 1$
4. [시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C)를 계산한다: $\hat d_1 = \dfrac{1}{1 + e^{2}} = \dfrac{1}{1 + 7.3891} = 0.1192$, $\hat d_2 = \dfrac{1}{1 + e^{-1}} = \dfrac{1}{1 + 0.3679} = 0.7311$
5. 1에서 뺀다: $1 - \hat d_1 = 1 - 0.1192 = 0.8808$ 이므로 $\mathcal{L}_d = -\dfrac{1}{2}\big[\ln 0.8808 + \ln 0.7311\big]$
6. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 계산한다: $\ln 0.8808 = -0.1269$, $\ln 0.7311 = -0.3133$
7. 더한다: $-0.1269 + (-0.3133) = -0.4402$
8. $-\dfrac{1}{2}$을 곱한다: $-\dfrac{1}{2} \times (-0.4402) = 0.2201$

**답**: $\mathcal{L}_d = 0.2201$. [우연 수준](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#chance-level-%EC%9A%B0%EC%97%B0-%EC%88%98%EC%A4%80) $0.6931$보다 작으니 [판별기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#generator-discriminator-%EC%83%9D%EC%84%B1%EA%B8%B0%EC%99%80-%ED%8C%90%EB%B3%84%EA%B8%B0)가 도메인을 어느 정도 가려낸다.

</details>

### 문제 6

특징 추출기가 $h = w x$, $w = 1$, $x = 2$이다. $\partial \mathcal{L}_y/\partial h = 0.2$, $\partial \mathcal{L}_d/\partial h = 0.8$, $\lambda = 0.5$, $\eta = 0.1$이다. 갱신한 $w$를 구하고, $w$가 늘었는지 줄었는지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $w = 1$, $x = 2$ ([가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)와 입력)
- $\partial \mathcal{L}_y/\partial h = 0.2$, $\partial \mathcal{L}_d/\partial h = 0.8$ (두 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0))
- $\lambda = 0.5$, $\eta = 0.1$

**풀이**
1. 식을 그대로 쓴다: $w \leftarrow w - \eta\left(\dfrac{\partial \mathcal{L}_y}{\partial h} - \lambda \dfrac{\partial \mathcal{L}_d}{\partial h}\right)\dfrac{\partial h}{\partial w}$
2. 값을 대입한다 ($\partial h/\partial w = x = 2$): $w \leftarrow 1 - 0.1 \times (0.2 - 0.5 \times 0.8) \times 2$
3. 괄호 안 곱셈을 한다: $0.5 \times 0.8 = 0.4$ 이므로 $w \leftarrow 1 - 0.1 \times (0.2 - 0.4) \times 2$
4. 괄호 안 뺄셈을 한다: $0.2 - 0.4 = -0.2$ 이므로 $w \leftarrow 1 - 0.1 \times (-0.2) \times 2$
5. 입력을 곱한다: $(-0.2) \times 2 = -0.4$ 이므로 $w \leftarrow 1 - 0.1 \times (-0.4)$
6. [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0)을 곱한다: $0.1 \times (-0.4) = -0.04$ 이므로 $w \leftarrow 1 - (-0.04)$
7. 뺀다: $1 - (-0.04) = 1.04$

**답**: $w = 1.04$로 늘었다. 도메인 쪽 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 반전되어 라벨 쪽 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)보다 커지면 부호가 뒤집혀(괄호 안이 $-0.2$) $w$가 반대 방향으로 움직인다.

</details>

### 문제 7

$\partial \mathcal{L}_y/\partial h = 0.6$, $\partial \mathcal{L}_d/\partial h = 0.8$일 때, $\lambda = 0$, $0.5$, $1$에서 반전 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)을 지난 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)를 각각 구하라. 부호가 바뀌는 $\lambda$는 어디쯤인가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $\partial \mathcal{L}_y/\partial h = 0.6$, $\partial \mathcal{L}_d/\partial h = 0.8$
- $\lambda = 0$, $0.5$, $1$ (반전 세기 후보)

**풀이**
1. 식을 그대로 쓴다: [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $= \dfrac{\partial \mathcal{L}_y}{\partial h} - \lambda \dfrac{\partial \mathcal{L}_d}{\partial h}$
2. $\lambda = 0$을 대입한다: $0.6 - 0 \times 0.8$
3. 곱하고 뺀다: $0 \times 0.8 = 0$ 이므로 $0.6 - 0 = 0.6$
4. $\lambda = 0.5$를 대입한다: $0.6 - 0.5 \times 0.8$
5. 곱하고 뺀다: $0.5 \times 0.8 = 0.4$ 이므로 $0.6 - 0.4 = 0.2$
6. $\lambda = 1$을 대입한다: $0.6 - 1 \times 0.8$
7. 곱하고 뺀다: $1 \times 0.8 = 0.8$ 이므로 $0.6 - 0.8 = -0.2$
8. 부호가 바뀌는 곳을 찾는다: $0.6 - \lambda \times 0.8 = 0$ 이면 $\lambda = 0.6 / 0.8 = 0.75$

**답**: $\lambda = 0$에서 $0.6$, $0.5$에서 $0.2$, $1$에서 $-0.2$. $\lambda = 0.75$에서 0이 되고 그보다 크면 부호가 뒤집힌다. $\lambda$는 도메인 항을 얼마나 세게 거슬러 갈지 정하는 손잡이다.

</details>

### 문제 8

$\mathcal{L}_y = 0.3$, $\lambda = 0.5$로 고정하고, 특징 추출기가 두 도메인의 특징을 겹쳐 가는 과정에서 도메인 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 처음 $0.1269$(특징이 떨어져 있음)에서 나중 $0.6931$(겹침)로 바뀌었다. 두 시점의 $E$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathcal{L}_y = 0.3$ (라벨 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98), 고정)
- $\lambda = 0.5$ (도메인 항의 비중)
- $\mathcal{L}_d = 0.1269$ (처음), $0.6931$ (나중)

**풀이**
1. 식을 그대로 쓴다: $E = \mathcal{L}_y - \lambda\,\mathcal{L}_d$
2. 처음을 대입한다: $E = 0.3 - 0.5 \times 0.1269$
3. 곱한다: $0.5 \times 0.1269 = 0.06345$ 이므로 $E = 0.3 - 0.06345$
4. 뺀다: $0.3 - 0.06345 = 0.23655$
5. 나중을 대입한다: $E = 0.3 - 0.5 \times 0.6931$
6. 곱한다: $0.5 \times 0.6931 = 0.34655$ 이므로 $E = 0.3 - 0.34655$
7. 뺀다: $0.3 - 0.34655 = -0.04655$

**답**: 처음 $E \approx 0.2366$, 나중 $E \approx -0.0466$. 특징 추출기는 $E$를 줄이는 쪽이라, $\mathcal{L}_d$가 커질수록(도메인을 못 맞힐수록) $E$가 작아져 좋다. [판별기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#generator-discriminator-%EC%83%9D%EC%84%B1%EA%B8%B0%EC%99%80-%ED%8C%90%EB%B3%84%EA%B8%B0)는 반대로 $E$를 키우려고($\mathcal{L}_d$를 줄이려고) 한다.

</details>

### 문제 9

Lec18 4.1의 적대적 [도메인 적응](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#domain-adaptation-%EB%8F%84%EB%A9%94%EC%9D%B8-%EC%A0%81%EC%9D%91)이다. 표본 4개(원천 2개 $d = 0, 0$, 목표 2개 $d = 1, 1$)에 대해 [판별기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#generator-discriminator-%EC%83%9D%EC%84%B1%EA%B8%B0%EC%99%80-%ED%8C%90%EB%B3%84%EA%B8%B0)가 모두 $\hat d = 0.5$를 냈다. 도메인 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 구하고, 왜 이것이 "특징이 완전히 겹쳤을 때"의 값인지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $d = (0, 0, 1, 1)$ (도메인 라벨), $N = 4$
- $\hat d_n = 0.5$ (모든 표본)

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_d = -\dfrac{1}{N}\sum_{n=1}^{N}\big[d_n \ln \hat d_n + (1 - d_n)\ln(1 - \hat d_n)\big]$
2. 값을 대입한다 (Σ를 네 항으로 펼침): $\mathcal{L}_d = -\dfrac{1}{4}\big[(1 - 0)\ln 0.5 + (1 - 0)\ln 0.5 + 1 \cdot \ln 0.5 + 1 \cdot \ln 0.5\big]$ ($d = 0$인 표본은 $\ln(1 - 0.5)$, $d = 1$인 표본은 $\ln 0.5$ 항만 남는다)
3. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 계산한다: $\ln 0.5 = -0.6931$ (네 항 모두)
4. 더한다: $4 \times (-0.6931) = -2.7726$
5. $-\dfrac{1}{4}$을 곱한다: $-\dfrac{1}{4} \times (-2.7726) = 0.6931$

**답**: $\mathcal{L}_d = 0.6931 = \ln 2$. 원천과 목표의 특징이 같으면 [판별기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#generator-discriminator-%EC%83%9D%EC%84%B1%EA%B8%B0%EC%99%80-%ED%8C%90%EB%B3%84%EA%B8%B0)는 어느 도메인인지 단서가 없어 0.5로 찍을 수밖에 없고, 그때 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 이 값이다. 특징 추출기가 노리는 목표가 바로 이 상태다.

</details>

### 문제 10

Lec18 4.1의 비지도 [도메인 적응](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#domain-adaptation-%EB%8F%84%EB%A9%94%EC%9D%B8-%EC%A0%81%EC%9D%91)이다. 목표 도메인에는 범주 라벨이 없으므로 $\mathcal{L}_y$는 원천 표본으로만 계산한다. 원천 표본 2개에서 모형이 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) 칸에 준 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 $0.8$, $0.5$이고 $\mathcal{L}_y = -\frac{1}{2}\big[\ln 0.8 + \ln 0.5\big]$이다. 도메인 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은 문제 5의 값($\mathcal{L}_d = 0.22009$), $\lambda = 0.5$일 때 $E$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) 칸 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) $0.8$, $0.5$ (원천 표본 2개)
- $\mathcal{L}_d = 0.22009$ (문제 5의 값을 다섯째 자리까지 쓴 것)
- $\lambda = 0.5$ (도메인 항의 비중)

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_y = -\dfrac{1}{2}\big[\ln 0.8 + \ln 0.5\big]$, $E = \mathcal{L}_y - \lambda\,\mathcal{L}_d$
2. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 계산한다: $\ln 0.8 = -0.22314$, $\ln 0.5 = -0.69315$
3. 더한다: $-0.22314 + (-0.69315) = -0.91629$
4. $-\dfrac{1}{2}$을 곱한다: $-\dfrac{1}{2} \times (-0.91629) = 0.45815$ 이므로 $\mathcal{L}_y = 0.45815$
5. $E$의 식에 대입한다: $E = 0.45815 - 0.5 \times 0.22009$
6. 곱한다: $0.5 \times 0.22009 = 0.11005$ 이므로 $E = 0.45815 - 0.11005$
7. 뺀다: $0.45815 - 0.11005 = 0.3481$

**답**: $\mathcal{L}_y = 0.4581$, $E = 0.3481$. 목표 도메인의 범주 라벨은 쓰지 않았고, "목표에서 왔다"는 도메인 라벨만으로 $\mathcal{L}_d$를 계산했다.

</details>
