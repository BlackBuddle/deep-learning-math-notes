# 예제: 가지치기와 양자화

개념 노트: [MM68_가지치기와_양자화](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/12_%EA%B0%95%EA%B1%B4%EC%84%B1%EA%B3%BC_%EC%A0%84%EC%9D%B4/MM68_%EA%B0%80%EC%A7%80%EC%B9%98%EA%B8%B0%EC%99%80_%EC%96%91%EC%9E%90%ED%99%94.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 쓰는 식은 셋이다. 크기 기준 [가지치기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#pruning-%EA%B0%80%EC%A7%80%EC%B9%98%EA%B8%B0) $\tilde w_i = w_i$ ($|w_i| > \tau$), $0$ ($|w_i| \le \tau$) (문턱 $\tau$는 절댓값을 작은 순으로 놓았을 때 $k$번째 값), 대칭 [양자화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#quantization-%EC%96%91%EC%9E%90%ED%99%94) $s = \dfrac{\max_i |w_i|}{2^{b-1} - 1}$, $q_i = \operatorname{round}(w_i / s)$, $\hat w_i = s\,q_i$, 메모리 $N \times \dfrac{b}{8}$ 바이트.

## 기본 (직접 대입)

### 문제 1

[가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) $w = (0.6, -0.1, 0.3, -0.05)$의 절반을 크기 기준으로 지워라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $w = (0.6, -0.1, 0.3, -0.05)$ ([가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98))
- $k = 2$ (지울 개수, 4개의 50%)

**풀이**
1. 식을 그대로 쓴다: $\tilde w_i = w_i$ ($|w_i| > \tau$일 때), $0$ ($|w_i| \le \tau$일 때)
2. 절댓값을 구한다: $|0.6| = 0.6$, $|-0.1| = 0.1$, $|0.3| = 0.3$, $|-0.05| = 0.05$
3. 작은 순으로 늘어놓는다: $0.05, 0.1, 0.3, 0.6$
4. $k = 2$번째 값을 문턱으로 정한다: $\tau = 0.1$
5. 값을 대입한다: $\tilde w = \big(0.6\ (0.6 > 0.1),\ 0\ (0.1 \le 0.1),\ 0.3\ (0.3 > 0.1),\ 0\ (0.05 \le 0.1)\big)$

**답**: $\tilde w = (0.6, 0, 0.3, 0)$. 크기가 큰 두 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)만 남는다.

</details>

### 문제 3

[가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) $w = (0.7, -0.33, 0.24)$를 4비트로 양자화하고, 되돌린 값과 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $w = (0.7, -0.33, 0.24)$ ([가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98))
- $b = 4$ (비트 수), 그래서 $2^{b-1} - 1 = 7$

**풀이**
1. 식을 그대로 쓴다: $s = \dfrac{\max_i |w_i|}{2^{b-1} - 1}$, $q_i = \operatorname{round}(w_i / s)$, $\hat w_i = s\,q_i$
2. 값을 대입한다: $s = \dfrac{\max(0.7, 0.33, 0.24)}{2^{4-1} - 1}$
3. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $4 - 1 = 3$, $2^3 = 8$, $8 - 1 = 7$ 이므로 $s = \dfrac{0.7}{7}$
4. 나눈다: $0.7 / 7 = 0.1$
5. 간격으로 나눈다: $0.7 / 0.1 = 7$, $-0.33 / 0.1 = -3.3$, $0.24 / 0.1 = 2.4$
6. 반올림한다: $7 \to 7$, $-3.3 \to -3$, $2.4 \to 2$
7. 간격을 곱해 되돌린다: $0.1 \times 7 = 0.7$, $0.1 \times (-3) = -0.3$, $0.1 \times 2 = 0.2$
8. [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)를 뺀다 (원래 − 되돌린 값): $0.7 - 0.7 = 0$, $-0.33 - (-0.3) = -0.03$, $0.24 - 0.2 = 0.04$

**답**: 정수 $(7, -3, 2)$, 되돌린 값 $(0.7, -0.3, 0.2)$, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $(0, -0.03, 0.04)$. [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)는 모두 간격의 절반 $0.05$ 이하다.

</details>

### 문제 4

[파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0)가 $3 \times 10^9$개인 모델을 8비트로 저장할 때와 4비트로 저장할 때의 메모리를 구하라 ($10^9$ 바이트 = 1 GB).

<details><summary>풀이와 답</summary>

**주어진 값**
- $N = 3 \times 10^9$ ([파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0) 수)
- $b = 8$ 또는 $4$ (비트 수)

**풀이**
1. 식을 그대로 쓴다: 메모리 $= N \times \dfrac{b}{8}$ (바이트)
2. 값을 대입한다 (8비트): $3 \times 10^9 \times \dfrac{8}{8}$
3. 나누고 곱한다: $8/8 = 1$ 이므로 $3 \times 10^9 \times 1 = 3 \times 10^9$ 바이트 $= 3$ GB
4. 값을 대입한다 (4비트): $3 \times 10^9 \times \dfrac{4}{8}$
5. 나누고 곱한다: $4/8 = 0.5$ 이므로 $3 \times 10^9 \times 0.5 = 1.5 \times 10^9$ 바이트 $= 1.5$ GB

**답**: 8비트 $3$ GB, 4비트 $1.5$ GB. 비트 수가 절반이면 메모리도 절반이다.

</details>

### 문제 5

[가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) $w = (0.5, 0.2)$를 8비트(눈금 $-127 \sim 127$)로 양자화한다. $0.2$는 어떤 값으로 되돌아오고 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)는 얼마인가? [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 한계 $s/2$와 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $w = (0.5, 0.2)$ ([가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98))
- $b = 8$ (비트 수), 그래서 $2^{b-1} - 1 = 127$

**풀이**
1. 식을 그대로 쓴다: $s = \dfrac{\max_i |w_i|}{2^{b-1} - 1}$, $q_i = \operatorname{round}(w_i / s)$, $\hat w_i = s\,q_i$
2. 값을 대입한다: $s = \dfrac{0.5}{2^{8-1} - 1}$
3. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $8 - 1 = 7$, $2^7 = 128$, $128 - 1 = 127$ 이므로 $s = 0.5 / 127$
4. 나눈다: $0.5 / 127 = 0.003937$
5. 간격으로 나눈다: $0.2 / 0.003937 = 50.8$
6. 반올림한다: $\operatorname{round}(50.8) = 51$
7. 간격을 곱해 되돌린다: $0.003937 \times 51 = 0.2008$
8. [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)를 뺀다: $0.2 - 0.2008 = -0.0008$
9. [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 한계를 구한다: $s / 2 = 0.003937 / 2 = 0.00197$

**답**: $0.2$는 정수 $51$로 저장되어 $0.2008$로 되돌아오고 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)는 $-0.0008$이다. 한계 $0.00197$보다 작다. 8비트는 4비트(간격이 $0.5/7 = 0.0714$)보다 눈금이 훨씬 촘촘해 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)가 작다.

</details>

### 문제 6

[가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) $w = (0.9, -0.5, 0.2)$를 3비트로 양자화하고, 되돌린 값과 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)를 구하라. 가장 큰 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)가 간격의 절반을 넘는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $w = (0.9, -0.5, 0.2)$ ([가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98))
- $b = 3$ (비트 수), 그래서 $2^{b-1} - 1 = 3$

**풀이**
1. 식을 그대로 쓴다: $s = \dfrac{\max_i |w_i|}{2^{b-1} - 1}$, $q_i = \operatorname{round}(w_i / s)$, $\hat w_i = s\,q_i$
2. 값을 대입한다: $s = \dfrac{0.9}{2^{3-1} - 1}$
3. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $3 - 1 = 2$, $2^2 = 4$, $4 - 1 = 3$ 이므로 $s = 0.9 / 3$
4. 나눈다: $0.9 / 3 = 0.3$
5. 간격으로 나눈다: $0.9 / 0.3 = 3$, $-0.5 / 0.3 = -1.6667$, $0.2 / 0.3 = 0.6667$
6. 반올림한다: $3 \to 3$, $-1.6667 \to -2$, $0.6667 \to 1$
7. 간격을 곱해 되돌린다: $0.3 \times 3 = 0.9$, $0.3 \times (-2) = -0.6$, $0.3 \times 1 = 0.3$
8. [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)를 뺀다: $0.9 - 0.9 = 0$, $-0.5 - (-0.6) = 0.1$, $0.2 - 0.3 = -0.1$
9. [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 한계와 비교한다: $s / 2 = 0.15$ 이고 가장 큰 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)의 크기는 $0.1$

**답**: 정수 $(3, -2, 1)$, 되돌린 값 $(0.9, -0.6, 0.3)$, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $(0, 0.1, -0.1)$. 가장 큰 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $0.1$은 한계 $0.15$를 넘지 않는다. 3비트는 눈금이 거칠어 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)가 4비트 때보다 크다.

</details>

### 문제 7

가장 큰 절댓값이 $2.1$인 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)들을 4비트로 양자화한다. [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)의 한계 $s/2$를 구하고, [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) $1.0$이 되돌아오는 값과 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)가 그 한계 안인지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\max_i |w_i| = 2.1$ (가장 큰 절댓값)
- $b = 4$ (비트 수), 그래서 $2^{b-1} - 1 = 7$
- $w_i = 1.0$ (확인할 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98))

**풀이**
1. 식을 그대로 쓴다: $s = \dfrac{\max_i |w_i|}{2^{b-1} - 1}$, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 한계 $= s/2$, $\hat w_i = s \cdot \operatorname{round}(w_i / s)$
2. 값을 대입한다: $s = \dfrac{2.1}{7}$
3. 나눈다: $2.1 / 7 = 0.3$
4. [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 한계를 구한다: $s / 2 = 0.3 / 2 = 0.15$
5. [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)를 간격으로 나눈다: $1.0 / 0.3 = 3.3333$
6. 반올림한다: $\operatorname{round}(3.3333) = 3$
7. 되돌린다: $0.3 \times 3 = 0.9$
8. [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)를 구한다: $1.0 - 0.9 = 0.1$
9. 한계와 비교한다: $0.1 \le 0.15$

**답**: [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 한계 $0.15$, $1.0$은 $0.9$로 되돌아오고 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $0.1$은 한계 안이다. 가장 큰 값이 클수록 간격 $s$도 커져서 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 한계가 커진다.

</details>

### 문제 8

[가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) $w = (0.8, -0.05, 0.3, -0.6)$을 먼저 50% 가지치기한 뒤, 남은 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)를 4비트로 양자화하라 (눈금은 남은 값의 최대 절댓값으로 정한다).

<details><summary>풀이와 답</summary>

**주어진 값**
- $w = (0.8, -0.05, 0.3, -0.6)$ ([가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98))
- $k = 2$ (지울 개수), $b = 4$ (비트 수)

**풀이**
1. 식을 그대로 쓴다: [가지치기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#pruning-%EA%B0%80%EC%A7%80%EC%B9%98%EA%B8%B0) $\tilde w_i = w_i$ ($|w_i| > \tau$), $0$ ($|w_i| \le \tau$) 뒤, $s = \dfrac{\max_i |\tilde w_i|}{2^{b-1} - 1}$, $\hat w_i = s \cdot \operatorname{round}(\tilde w_i / s)$
2. 절댓값을 작은 순으로 늘어놓는다: $0.05, 0.3, 0.6, 0.8$
3. $k = 2$번째 값을 문턱으로 정한다: $\tau = 0.3$
4. 가지치기한다: $0.8 > 0.3$ 남김, $0.05 \le 0.3$ 지움, $0.3 \le 0.3$ 지움, $0.6 > 0.3$ 남김 이므로 $\tilde w = (0.8, 0, 0, -0.6)$
5. [양자화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#quantization-%EC%96%91%EC%9E%90%ED%99%94) 식에 값을 대입한다: $s = \dfrac{\max(0.8, 0, 0, 0.6)}{2^{4-1} - 1} = \dfrac{0.8}{7}$
6. 나눈다: $0.8 / 7 = 0.1143$
7. 간격으로 나눈다: $0.8 / 0.1143 = 7$, $0 / 0.1143 = 0$, $-0.6 / 0.1143 = -5.25$
8. 반올림한다: $7 \to 7$, $0 \to 0$, $-5.25 \to -5$
9. 간격을 곱해 되돌린다 ($s = 0.8/7$ 그대로 곱한다): $\dfrac{0.8}{7} \times 7 = 0.8$, $0$, $\dfrac{0.8}{7} \times (-5) = -0.5714$

**답**: [가지치기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#pruning-%EA%B0%80%EC%A7%80%EC%B9%98%EA%B8%B0) 뒤 $(0.8, 0, 0, -0.6)$, [양자화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#quantization-%EC%96%91%EC%9E%90%ED%99%94) 뒤 $(0.8, 0, 0, -0.5714)$. 0이 된 칸은 양자화해도 0이고, $-0.6$에서만 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $-0.0286$이 생긴다.

</details>

### 문제 9

Lec18 6의 압축이다. 700억($7 \times 10^{10}$) [파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0) 모델을 16비트로 저장할 때와 4비트로 저장할 때의 메모리를 구하고, 몇 배 줄었는지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $N = 7 \times 10^{10}$ ([파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0) 수)
- $b = 16$ 또는 $4$ (비트 수)

**풀이**
1. 식을 그대로 쓴다: 메모리 $= N \times \dfrac{b}{8}$ (바이트)
2. 값을 대입한다 (16비트): $7 \times 10^{10} \times \dfrac{16}{8}$
3. 나누고 곱한다: $16/8 = 2$ 이므로 $7 \times 10^{10} \times 2 = 14 \times 10^{10} = 1.4 \times 10^{11}$ 바이트 $= 140$ GB
4. 값을 대입한다 (4비트): $7 \times 10^{10} \times \dfrac{4}{8}$
5. 나누고 곱한다: $4/8 = 0.5$ 이므로 $7 \times 10^{10} \times 0.5 = 3.5 \times 10^{10}$ 바이트 $= 35$ GB
6. 줄어든 배수를 구한다: $140 / 35 = 4$

**답**: 16비트 $140$ GB, 4비트 $35$ GB로 $4$배 줄었다. 그래서 큰 [언어 모델](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#language-model-%EC%96%B8%EC%96%B4-%EB%AA%A8%EB%8D%B8)을 적은 수의 [GPU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#device-gpu-%EC%9E%A5%EC%B9%98%EC%99%80-gpu)에 올리려고 양자화한다.

</details>

### 문제 10

Lec18 6에서 압축([가지치기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#pruning-%EA%B0%80%EC%A7%80%EC%B9%98%EA%B8%B0), [양자화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#quantization-%EC%96%91%EC%9E%90%ED%99%94))은 큰 모델의 계산 비용을 직접 줄이고 증류는 작은 모델을 새로 학습한다고 비교한다. [파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0) $7 \times 10^9$개 모델의 90%를 가지치기하고 남은 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)를 16비트, 4비트로 저장할 때의 메모리를 구하라 (남은 값의 위치를 적는 색인 저장 공간은 무시한다).

<details><summary>풀이와 답</summary>

**주어진 값**
- $N = 7 \times 10^9$ (원래 [파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0) 수)
- 지우는 비율 90% (남는 비율 $1 - 0.9$)
- $b = 16$ 또는 $4$ (비트 수)

**풀이**
1. 식을 그대로 쓴다: 남은 개수 $= N \times (1 - 0.9)$, 메모리 $= (\text{남은 개수}) \times \dfrac{b}{8}$
2. 값을 대입한다: 남은 개수 $= 7 \times 10^9 \times (1 - 0.9)$
3. 괄호를 계산한다: $1 - 0.9 = 0.1$ 이므로 $7 \times 10^9 \times 0.1 = 7 \times 10^8$
4. 16비트를 대입한다: $7 \times 10^8 \times \dfrac{16}{8}$
5. 계산한다: $16/8 = 2$ 이므로 $7 \times 10^8 \times 2 = 14 \times 10^8 = 1.4 \times 10^9$ 바이트 $= 1.4$ GB
6. 4비트를 대입한다: $7 \times 10^8 \times \dfrac{4}{8}$
7. 계산한다: $4/8 = 0.5$ 이므로 $7 \times 10^8 \times 0.5 = 3.5 \times 10^8$ 바이트 $= 0.35$ GB

**답**: 16비트면 $1.4$ GB, 4비트면 $0.35$ GB. 원래 16비트 전체($7 \times 10^9 \times 2 = 14$ GB)의 $1/10$과 $1/40$이다. 실제로는 어느 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)가 남았는지 적는 색인이 더 들어서 이보다 크다.

</details>
