# 예제: 선형 보간과 잠재 방향

개념 노트: [MM69_선형_보간과_잠재_방향](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/03_%EC%84%A0%ED%98%95%EB%8C%80%EC%88%98/MM69_%EC%84%A0%ED%98%95_%EB%B3%B4%EA%B0%84%EA%B3%BC_%EC%9E%A0%EC%9E%AC_%EB%B0%A9%ED%96%A5.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 쓰는 식은 둘이다. 선형 [보간](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#interpolation-%EB%B3%B4%EA%B0%84) $z(t) = (1-t)\,z_0 + t\,z_1$ ($0 \le t \le 1$)과 [잠재 방향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#latent-direction-%EC%9E%A0%EC%9E%AC-%EB%B0%A9%ED%96%A5) $d = z_B - z_A$, $z' = z + \alpha\,d$. 벡터에 수를 곱하면 칸마다 곱하고, 벡터끼리 더하거나 빼면 같은 자리 칸끼리 계산한다.

## 기본 (직접 대입)

### 문제 1

출발점이 $z_0 = (4, 0)$, 도착점이 $z_1 = (0, 8)$이다. $t = 0.5$인 중간 점을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $z_0 = (4, 0)$ (출발점)
- $z_1 = (0, 8)$ (도착점)
- $t = 0.5$ (간 정도)

**풀이**
1. 식을 그대로 쓴다: $z(t) = (1 - t)\,z_0 + t\,z_1$
2. 값을 대입한다: $z(0.5) = (1 - 0.5)\,(4, 0) + 0.5\,(0, 8)$
3. 괄호를 계산한다: $1 - 0.5 = 0.5$ 이므로 $z = 0.5\,(4, 0) + 0.5\,(0, 8)$
4. 첫 벡터에 성분마다 곱한다: $0.5 \times 4 = 2$, $0.5 \times 0 = 0$ 이므로 $z = (2, 0) + 0.5\,(0, 8)$
5. 둘째 벡터에 성분마다 곱한다: $0.5 \times 0 = 0$, $0.5 \times 8 = 4$ 이므로 $z = (2, 0) + (0, 4)$
6. 성분끼리 더한다: $2 + 0 = 2$, $0 + 4 = 4$

**답**: $z(0.5) = (2, 4)$. 두 점의 한가운데다.

</details>

### 문제 2

같은 $z_0 = (4, 0)$, $z_1 = (0, 8)$에서 $t = 0.25$인 점을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $z_0 = (4, 0)$, $z_1 = (0, 8)$
- $t = 0.25$ (간 정도)

**풀이**
1. 식을 그대로 쓴다: $z(t) = (1 - t)\,z_0 + t\,z_1$
2. 값을 대입한다: $z(0.25) = (1 - 0.25)\,(4, 0) + 0.25\,(0, 8)$
3. 괄호를 계산한다: $1 - 0.25 = 0.75$ 이므로 $z = 0.75\,(4, 0) + 0.25\,(0, 8)$
4. 첫 벡터에 성분마다 곱한다: $0.75 \times 4 = 3$, $0.75 \times 0 = 0$ 이므로 $z = (3, 0) + 0.25\,(0, 8)$
5. 둘째 벡터에 성분마다 곱한다: $0.25 \times 0 = 0$, $0.25 \times 8 = 2$ 이므로 $z = (3, 0) + (0, 2)$
6. 성분끼리 더한다: $3 + 0 = 3$, $0 + 2 = 2$

**답**: $z(0.25) = (3, 2)$. 출발점 쪽에 더 가깝다.

</details>

### 문제 3

낮 사진의 잠재 벡터가 $z_A = (2, 1, 0)$, 같은 장면 밤 사진의 잠재 벡터가 $z_B = (2, 4, -1)$이다. [잠재 방향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#latent-direction-%EC%9E%A0%EC%9E%AC-%EB%B0%A9%ED%96%A5) $d$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $z_A = (2, 1, 0)$ (낮)
- $z_B = (2, 4, -1)$ (밤)

**풀이**
1. 식을 그대로 쓴다: $d = z_B - z_A$
2. 값을 대입한다: $d = (2, 4, -1) - (2, 1, 0)$
3. 성분끼리 뺀다: $2 - 2 = 0$, $4 - 1 = 3$, $-1 - 0 = -1$

**답**: $d = (0, 3, -1)$. 낮에서 밤으로 가려면 둘째 성분을 3 올리고 셋째 성분을 1 내린다.

</details>

### 문제 4

문제 3의 방향 $d = (0, 3, -1)$을 다른 사진의 잠재 벡터 $z = (1, 1, 1)$에 세기 $\alpha = 2$로 적용한 $z'$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $z = (1, 1, 1)$ (바꿀 사진)
- $d = (0, 3, -1)$ ([잠재 방향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#latent-direction-%EC%9E%A0%EC%9E%AC-%EB%B0%A9%ED%96%A5))
- $\alpha = 2$ (바꾸는 세기)

**풀이**
1. 식을 그대로 쓴다: $z' = z + \alpha\,d$
2. 값을 대입한다: $z' = (1, 1, 1) + 2\,(0, 3, -1)$
3. $\alpha$를 성분마다 곱한다: $2 \times 0 = 0$, $2 \times 3 = 6$, $2 \times (-1) = -2$ 이므로 $z' = (1, 1, 1) + (0, 6, -2)$
4. 성분끼리 더한다: $1 + 0 = 1$, $1 + 6 = 7$, $1 + (-2) = -1$

**답**: $z' = (1, 7, -1)$. $\alpha = 1$이면 "문제 3의 낮→밤 변화 그대로"이고, $\alpha = 2$는 그 두 배로 세게 바꾼 것이다.

</details>

### 문제 5

$z_0 = (1, 3)$, $z_1 = (5, -1)$이다. $t = 0$, $t = 1$에서 [보간](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#interpolation-%EB%B3%B4%EA%B0%84) 점을 구하고, $0 \le t \le 1$을 벗어난 $t = 1.5$에서는 어떤 점이 되는지 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $z_0 = (1, 3)$, $z_1 = (5, -1)$
- $t = 0$, $1$, $1.5$ (간 정도)

**풀이**
1. 식을 그대로 쓴다: $z(t) = (1 - t)\,z_0 + t\,z_1$
2. $t = 0$을 대입한다: $z(0) = (1 - 0)\,(1, 3) + 0\,(5, -1)$
3. 곱하고 더한다: $1 \times (1, 3) = (1, 3)$, $0 \times (5, -1) = (0, 0)$ 이므로 $z(0) = (1, 3)$
4. $t = 1$을 대입한다: $z(1) = (1 - 1)\,(1, 3) + 1\,(5, -1)$
5. 곱하고 더한다: $0 \times (1, 3) = (0, 0)$, $1 \times (5, -1) = (5, -1)$ 이므로 $z(1) = (5, -1)$
6. $t = 1.5$를 대입한다: $z(1.5) = (1 - 1.5)\,(1, 3) + 1.5\,(5, -1)$
7. 괄호를 계산한다: $1 - 1.5 = -0.5$ 이므로 $z = -0.5\,(1, 3) + 1.5\,(5, -1)$
8. 성분마다 곱한다: $-0.5 \times 1 = -0.5$, $-0.5 \times 3 = -1.5$, $1.5 \times 5 = 7.5$, $1.5 \times (-1) = -1.5$ 이므로 $z = (-0.5, -1.5) + (7.5, -1.5)$
9. 성분끼리 더한다: $-0.5 + 7.5 = 7$, $-1.5 + (-1.5) = -3$

**답**: $z(0) = (1, 3)$ (출발점), $z(1) = (5, -1)$ (도착점), $z(1.5) = (7, -3)$. $t > 1$이면 도착점을 지나 같은 직선 위로 더 나간다 ([외삽](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#extrapolation-%EC%99%B8%EC%82%BD)).

</details>

### 문제 6

$z_0 = (0, 4)$에서 $z_1 = (8, 0)$까지 $t = 0.25, 0.5, 0.75$인 세 점을 구하라. 이 점들은 같은 간격으로 놓이는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $z_0 = (0, 4)$, $z_1 = (8, 0)$
- $t = 0.25$, $0.5$, $0.75$

**풀이**
1. 식을 그대로 쓴다: $z(t) = (1 - t)\,z_0 + t\,z_1$
2. $t = 0.25$를 대입한다: $z = 0.75\,(0, 4) + 0.25\,(8, 0)$
3. 성분마다 곱한다: $0.75 \times 0 = 0$, $0.75 \times 4 = 3$, $0.25 \times 8 = 2$, $0.25 \times 0 = 0$ 이므로 $z = (0, 3) + (2, 0)$
4. 성분끼리 더한다: $0 + 2 = 2$, $3 + 0 = 3$ 이므로 $z(0.25) = (2, 3)$
5. $t = 0.5$를 대입한다: $z = 0.5\,(0, 4) + 0.5\,(8, 0)$
6. 성분마다 곱한다: $0.5 \times 0 = 0$, $0.5 \times 4 = 2$, $0.5 \times 8 = 4$, $0.5 \times 0 = 0$ 이므로 $z = (0, 2) + (4, 0)$
7. 성분끼리 더한다: $z(0.5) = (4, 2)$
8. $t = 0.75$를 대입한다: $z = 0.25\,(0, 4) + 0.75\,(8, 0)$
9. 성분마다 곱한다: $0.25 \times 0 = 0$, $0.25 \times 4 = 1$, $0.75 \times 8 = 6$, $0.75 \times 0 = 0$ 이므로 $z = (0, 1) + (6, 0)$
10. 성분끼리 더한다: $z(0.75) = (6, 1)$
11. 간격을 확인한다: $(0, 4) \to (2, 3) \to (4, 2) \to (6, 1) \to (8, 0)$ 에서 매번 $(+2, -1)$

**답**: $(2, 3)$, $(4, 2)$, $(6, 1)$. 같은 간격 $(2, -1)$씩 곧게 움직인다. $t$를 고르게 늘리면 점도 고르게 움직이는 것이 선형 [보간](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#interpolation-%EB%B3%B4%EA%B0%84)이다.

</details>

### 문제 7

단어 유추를 벡터로 보자 (개념도의 2차원 값). man $= (2, 1)$, woman $= (2, 4)$, king $= (5, 1)$이다. man에서 woman으로 가는 방향을 king에 더하면 어떤 점이 되는가? queen $= (5, 4)$와 비교하라.

<details><summary>풀이와 답</summary>

$d = z_B - z_A$로 방향을 구한 뒤 $z' = z + \alpha d$로 다른 점에 더한다 ($\alpha = 1$).

**주어진 값**
- $z_A = $ man $= (2, 1)$, $z_B = $ woman $= (2, 4)$
- $z = $ king $= (5, 1)$, $\alpha = 1$

**풀이**
1. 식을 그대로 쓴다: $d = z_B - z_A$, $z' = z + \alpha\,d$
2. 값을 대입한다: $d = (2, 4) - (2, 1)$, $z' = (5, 1) + 1 \times d$
3. 성분끼리 뺀다: $2 - 2 = 0$, $4 - 1 = 3$ 이므로 $d = (0, 3)$
4. $\alpha$를 곱한다: $1 \times (0, 3) = (0, 3)$ 이므로 $z' = (5, 1) + (0, 3)$
5. 성분끼리 더한다: $5 + 0 = 5$, $1 + 3 = 4$

**답**: $z' = (5, 4)$로 queen과 같다. "남성 → 여성" 방향 $(0, 3)$을 king에 더하면 queen이 나온다 (walking → walked 방향을 swimming에 더하면 swam이 나오는 것과 같은 계산).

</details>

### 문제 8

낮 사진 $z_A = (2, 3)$, 밤 사진 $z_B = (2, -1)$에서 [잠재 방향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#latent-direction-%EC%9E%A0%EC%9E%AC-%EB%B0%A9%ED%96%A5) $d$를 구하고, 두 사진 $z_1 = (3, 1)$, $z_2 = (-2, 4)$를 $\alpha = 0.5$로 "반쯤 밤으로" 바꾼 잠재 벡터를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $z_A = (2, 3)$ (낮), $z_B = (2, -1)$ (밤)
- $z_1 = (3, 1)$, $z_2 = (-2, 4)$ (바꿀 사진 둘)
- $\alpha = 0.5$ (반쯤)

**풀이**
1. 식을 그대로 쓴다: $d = z_B - z_A$, $z' = z + \alpha\,d$
2. 값을 대입한다: $d = (2, -1) - (2, 3)$
3. 성분끼리 뺀다: $2 - 2 = 0$, $-1 - 3 = -4$ 이므로 $d = (0, -4)$
4. $\alpha$를 곱한다: $0.5 \times 0 = 0$, $0.5 \times (-4) = -2$ 이므로 $\alpha d = (0, -2)$
5. 첫 사진에 더한다: $z_1' = (3, 1) + (0, -2) = (3 + 0,\ 1 + (-2)) = (3, -1)$
6. 둘째 사진에 더한다: $z_2' = (-2, 4) + (0, -2) = (-2 + 0,\ 4 + (-2)) = (-2, 2)$

**답**: $d = (0, -4)$, $z_1' = (3, -1)$, $z_2' = (-2, 2)$. 같은 방향 $d$를 서로 다른 사진에 더해도 둘째 성분만 똑같이 $-2$만큼 바뀐다 (이 예에서 둘째 축이 "밝기" 축이다).

</details>

### 문제 9

Lec19 3.2의 "[잠재 방향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#latent-direction-%EC%9E%A0%EC%9E%AC-%EB%B0%A9%ED%96%A5) 찾기"다. 3차원 [잠재 공간](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#latent-space-%EC%9E%A0%EC%9E%AC-%EA%B3%B5%EA%B0%84)에서 낮 사진이 $z_A = (1, 2, 0)$, 같은 장면 밤 사진이 $z_B = (0, -1, 1)$이다. 방향 $d$를 구하고, 새 사진 $z = (2, 3, 1)$에 $\alpha = 1$과 $\alpha = 0.5$로 적용하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $z_A = (1, 2, 0)$ (낮), $z_B = (0, -1, 1)$ (밤)
- $z = (2, 3, 1)$ (새 사진), $\alpha = 1$ 또는 $0.5$

**풀이**
1. 식을 그대로 쓴다: $d = z_B - z_A$, $z' = z + \alpha\,d$
2. 값을 대입한다: $d = (0, -1, 1) - (1, 2, 0)$
3. 성분끼리 뺀다: $0 - 1 = -1$, $-1 - 2 = -3$, $1 - 0 = 1$ 이므로 $d = (-1, -3, 1)$
4. $\alpha = 1$을 대입한다: $z' = (2, 3, 1) + 1 \times (-1, -3, 1)$
5. 성분끼리 더한다: $2 + (-1) = 1$, $3 + (-3) = 0$, $1 + 1 = 2$ 이므로 $z' = (1, 0, 2)$
6. $\alpha = 0.5$를 대입한다: $z' = (2, 3, 1) + 0.5 \times (-1, -3, 1)$
7. $\alpha$를 성분마다 곱한다: $0.5 \times (-1) = -0.5$, $0.5 \times (-3) = -1.5$, $0.5 \times 1 = 0.5$ 이므로 $z' = (2, 3, 1) + (-0.5, -1.5, 0.5)$
8. 성분끼리 더한다: $2 + (-0.5) = 1.5$, $3 + (-1.5) = 1.5$, $1 + 0.5 = 1.5$

**답**: $d = (-1, -3, 1)$, $\alpha = 1$에서 $z' = (1, 0, 2)$, $\alpha = 0.5$에서 $z' = (1.5, 1.5, 1.5)$. 이 $z'$를 [생성기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#generator-discriminator-%EC%83%9D%EC%84%B1%EA%B8%B0%EC%99%80-%ED%8C%90%EB%B3%84%EA%B8%B0) $G$에 넣으면 각각 "밤 사진"과 "반쯤 밤 사진"이 나온다.

</details>

### 문제 10

Lec19 3.3의 "어디서 보간하나"다. 픽셀이 4개인 사진 둘이 $x_0 = (0.2, 0.8, 0.4, 1.0)$, $x_1 = (1.0, 0.0, 0.6, 0.2)$이다. (a) 픽셀 공간에서 $t = 0.5$인 [보간](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#interpolation-%EB%B3%B4%EA%B0%84) 이미지를 구하라. (b) 두 사진의 잠재 벡터가 $z_0 = (1, 0)$, $z_1 = (0, 1)$일 때 [잠재 공간](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#latent-space-%EC%9E%A0%EC%9E%AC-%EA%B3%B5%EA%B0%84)에서 $t = 0.5$인 점을 구하라.

<details><summary>풀이와 답</summary>

두 경우 모두 같은 식 $z(t) = (1 - t)\,z_0 + t\,z_1$을 쓴다. 다른 것은 어느 공간의 벡터에 쓰느냐다.

**주어진 값**
- $x_0 = (0.2, 0.8, 0.4, 1.0)$, $x_1 = (1.0, 0.0, 0.6, 0.2)$ (픽셀 값)
- $z_0 = (1, 0)$, $z_1 = (0, 1)$ (잠재 벡터)
- $t = 0.5$

**풀이**
1. 식을 그대로 쓴다: $z(t) = (1 - t)\,z_0 + t\,z_1$ (픽셀 공간에서는 $z$ 자리에 $x$를 쓴다)
2. (a)를 대입한다: $x(0.5) = 0.5\,(0.2, 0.8, 0.4, 1.0) + 0.5\,(1.0, 0.0, 0.6, 0.2)$
3. 첫 벡터에 곱한다: $0.5 \times 0.2 = 0.1$, $0.5 \times 0.8 = 0.4$, $0.5 \times 0.4 = 0.2$, $0.5 \times 1.0 = 0.5$
4. 둘째 벡터에 곱한다: $0.5 \times 1.0 = 0.5$, $0.5 \times 0.0 = 0$, $0.5 \times 0.6 = 0.3$, $0.5 \times 0.2 = 0.1$
5. 칸끼리 더한다: $0.1 + 0.5 = 0.6$, $0.4 + 0 = 0.4$, $0.2 + 0.3 = 0.5$, $0.5 + 0.1 = 0.6$
6. (b)를 대입한다: $z(0.5) = 0.5\,(1, 0) + 0.5\,(0, 1)$
7. 곱하고 더한다: $(0.5, 0) + (0, 0.5) = (0.5, 0.5)$

**답**: (a) 픽셀 공간의 중간 이미지 $(0.6, 0.4, 0.5, 0.6)$는 두 사진을 반반으로 겹친 이미지다 (두 그림이 반투명하게 겹쳐 보이는 이상한 그림). (b) [잠재 공간](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#latent-space-%EC%9E%A0%EC%9E%AC-%EA%B3%B5%EA%B0%84)의 중간 점은 $(0.5, 0.5)$이고, 이것을 [생성기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#generator-discriminator-%EC%83%9D%EC%84%B1%EA%B8%B0%EC%99%80-%ED%8C%90%EB%B3%84%EA%B8%B0) $G$에 넣어야 이미지가 된다. $G$는 [잠재 공간](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#latent-space-%EC%9E%A0%EC%9E%AC-%EA%B3%B5%EA%B0%84)의 점을 자연 이미지 위로 보내도록 학습되어 있어, 같은 직선 [보간](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#interpolation-%EB%B3%B4%EA%B0%84)이 자연스러운 그림을 준다.
