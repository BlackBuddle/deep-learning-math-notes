## 기본 (직접 대입)

### 문제 1
두 식 $3x + 2y = 8$, $x + 4y = 6$을 $A\mathbf{x} = \mathbf{b}$ 모양으로 쓰고, $\mathbf{x} = (2, 1)$이 두 식의 해인지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**:
- $A = \begin{pmatrix}3&2\\1&4\end{pmatrix}$ (식의 계수. 첫 줄은 첫 식, 둘째 줄은 둘째 식)
- $\mathbf{x} = (2, 1)$ (확인할 후보. $x = 2$, $y = 1$)
- $\mathbf{b} = (8, 6)$ (두 식의 오른쪽 값)

**풀이**
1. 식을 그대로 쓴다: $A\mathbf{x} = \mathbf{b}$
2. 값을 대입한다: $\begin{pmatrix}3&2\\1&4\end{pmatrix}\begin{pmatrix}2\\1\end{pmatrix} \overset{?}{=} \begin{pmatrix}8\\6\end{pmatrix}$
3. 첫째 줄을 펼친다: $3 \times 2 + 2 \times 1$
4. 곱셈을 한다: 3 × 2 = 6, 2 × 1 = 2 이므로 $6 + 2 = 8$ (오른쪽 첫 칸 8과 같다)
5. 둘째 줄을 펼친다: $1 \times 2 + 4 \times 1$
6. 곱셈을 한다: 1 × 2 = 2, 4 × 1 = 4 이므로 $2 + 4 = 6$ (오른쪽 둘째 칸 6과 같다)

**답**: $A\mathbf{x} = (8, 6) = \mathbf{b}$이므로 $(2, 1)$은 해다

</details>

### 문제 2
$A = \begin{pmatrix}3&2\\1&4\end{pmatrix}$와 $B = \begin{pmatrix}2&6\\1&3\end{pmatrix}$의 행렬식을 구하고, 어느 쪽에 역행렬이 있는지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**:
- $A$: $a = 3,\ b = 2,\ c = 1,\ d = 4$
- $B$: $a = 2,\ b = 6,\ c = 1,\ d = 3$

**풀이**
1. 식을 그대로 쓴다: $\det = ad - bc$ (0이 아니면 역행렬이 있다)
2. $A$에 값을 대입한다: $\det A = 3 \times 4 - 2 \times 1$
3. 곱셈을 한다: 3 × 4 = 12, 2 × 1 = 2 이므로 $\det A = 12 - 2$
4. 뺄셈을 한다: 12 − 2 = 10 이므로 $\det A = 10 \neq 0$
5. $B$에 값을 대입한다: $\det B = 2 \times 3 - 6 \times 1$
6. 곱셈을 한다: 2 × 3 = 6, 6 × 1 = 6 이므로 $\det B = 6 - 6$
7. 뺄셈을 한다: 6 − 6 = 0 이므로 $\det B = 0$ (둘째 줄 (1, 3)의 2배가 첫째 줄 (2, 6)이라 줄이 겹친다)

**답**: $\det A = 10$이라 $A$는 역행렬이 있고, $\det B = 0$이라 $B$는 역행렬이 없다

</details>

### 문제 3
$A = \begin{pmatrix}3&2\\1&4\end{pmatrix}$의 역행렬을 2×2 공식으로 구하고, $A A^{-1} = I$인지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**:
- $a = 3,\ b = 2$ (첫 줄)
- $c = 1,\ d = 4$ (둘째 줄)

**풀이**
1. 식을 그대로 쓴다: $A^{-1} = \frac{1}{ad - bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}$
2. 값을 대입한다: $A^{-1} = \frac{1}{3 \times 4 - 2 \times 1}\begin{pmatrix}4&-2\\-1&3\end{pmatrix}$
3. 분모를 계산한다: 3 × 4 = 12, 2 × 1 = 2, 12 − 2 = 10 이므로 $A^{-1} = \frac{1}{10}\begin{pmatrix}4&-2\\-1&3\end{pmatrix}$
4. $\frac{1}{10} = 0.1$을 칸마다 곱한다: 0.1 × 4 = 0.4, 0.1 × (−2) = −0.2, 0.1 × (−1) = −0.1, 0.1 × 3 = 0.3 이므로 $A^{-1} = \begin{pmatrix}0.4&-0.2\\-0.1&0.3\end{pmatrix}$
5. 확인, 첫 줄·첫 열 칸: $3 \times 0.4 + 2 \times (-0.1) = 1.2 - 0.2 = 1$
6. 첫 줄·둘째 열 칸: $3 \times (-0.2) + 2 \times 0.3 = -0.6 + 0.6 = 0$
7. 둘째 줄·첫 열 칸: $1 \times 0.4 + 4 \times (-0.1) = 0.4 - 0.4 = 0$
8. 둘째 줄·둘째 열 칸: $1 \times (-0.2) + 4 \times 0.3 = -0.2 + 1.2 = 1$

**답**: $A^{-1} = \begin{pmatrix}0.4&-0.2\\-0.1&0.3\end{pmatrix}$, $A A^{-1} = \begin{pmatrix}1&0\\0&1\end{pmatrix} = I$

</details>

### 문제 4
문제 3의 역행렬로 $3x + 2y = 8$, $x + 4y = 6$의 해를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**:
- $A^{-1} = \begin{pmatrix}0.4&-0.2\\-0.1&0.3\end{pmatrix}$ (문제 3의 결과)
- $\mathbf{b} = (8, 6)$ (식 오른쪽 값)

**풀이**
1. 식을 그대로 쓴다: $\mathbf{x} = A^{-1}\mathbf{b}$
2. 값을 대입한다: $\mathbf{x} = \begin{pmatrix}0.4&-0.2\\-0.1&0.3\end{pmatrix}\begin{pmatrix}8\\6\end{pmatrix}$
3. 첫째 줄을 펼친다: $0.4 \times 8 + (-0.2) \times 6$
4. 곱셈을 한다: 0.4 × 8 = 3.2, (−0.2) × 6 = −1.2 이므로 $3.2 - 1.2 = 2$, $x = 2$
5. 둘째 줄을 펼친다: $(-0.1) \times 8 + 0.3 \times 6$
6. 곱셈을 한다: (−0.1) × 8 = −0.8, 0.3 × 6 = 1.8 이므로 $-0.8 + 1.8 = 1$, $y = 1$

**답**: $(x, y) = (2, 1)$ (문제 1에서 확인한 값과 같다)

</details>

### 문제 5
$S = \begin{pmatrix}1&2\\2&4\end{pmatrix}$일 때 $S\mathbf{x} = \mathbf{b}$의 해는 (가) $\mathbf{b} = (3, 6)$, (나) $\mathbf{b} = (3, 5)$에서 각각 몇 개인가?

<details><summary>풀이와 답</summary>

먼저 행렬식으로 역행렬이 있는지 본다. 없으면 $\mathbf{b}$마다 두 식을 직접 비교해야 한다.

**주어진 값**:
- $S = \begin{pmatrix}1&2\\2&4\end{pmatrix}$ (둘째 줄이 첫째 줄의 2배)
- (가) $\mathbf{b} = (3, 6)$, (나) $\mathbf{b} = (3, 5)$

**풀이**
1. 식을 그대로 쓴다: $\det S = ad - bc$
2. 값을 대입한다: $\det S = 1 \times 4 - 2 \times 2$
3. 곱셈과 뺄셈을 한다: 1 × 4 = 4, 2 × 2 = 4, 4 − 4 = 0 이므로 $\det S = 0$ (역행렬이 없어 $S^{-1}\mathbf{b}$로는 풀 수 없다)
4. (가)의 두 식을 쓴다: $x + 2y = 3$, $2x + 4y = 6$
5. 첫째 식에 2를 곱한다: $2(x + 2y) = 2 \times 3$, 즉 $2x + 4y = 6$. 둘째 식과 같다.
6. 같은 식이 두 번이므로 식이 사실상 하나다. $x + 2y = 3$을 만족하는 $(x, y)$는 모두 해다. 예: $(1, 1)$은 $1 + 2 = 3$, $2 + 4 = 6$으로 맞고, $(3, 0)$은 $3 + 0 = 3$, $6 + 0 = 6$으로 맞는다.
7. (나)의 두 식을 쓴다: $x + 2y = 3$, $2x + 4y = 5$
8. 첫째 식에 2를 곱한다: $2x + 4y = 6$. 그런데 둘째 식은 $2x + 4y = 5$다.
9. 같은 $2x + 4y$가 6이면서 5일 수는 없다. 모순이다.

**답**: (가) 해가 **무수히 많다**, (나) 해가 **없다** (둘 다 $\det S = 0$이라 역행렬은 없다)

</details>

### 문제 6
연필 2자루와 지우개 1개가 1500원, 연필 1자루와 지우개 2개가 1200원이다. 연필 한 자루와 지우개 한 개의 값을 역행렬로 구하라.

<details><summary>풀이와 답</summary>

값이 두 개($x$ = 연필, $y$ = 지우개)이고 식이 두 개라서 $A\mathbf{x} = \mathbf{b}$로 쓰고 $\mathbf{x} = A^{-1}\mathbf{b}$를 쓴다. 식은 $2x + y = 1500$, $x + 2y = 1200$이다.

**주어진 값**:
- $A = \begin{pmatrix}2&1\\1&2\end{pmatrix}$ (자루 수와 개수. 첫 줄은 첫째 영수증)
- $\mathbf{b} = (1500, 1200)$ (합계 금액)

**풀이**
1. 식을 그대로 쓴다: $A^{-1} = \frac{1}{ad - bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}$
2. 값을 대입한다: $A^{-1} = \frac{1}{2 \times 2 - 1 \times 1}\begin{pmatrix}2&-1\\-1&2\end{pmatrix}$
3. 분모를 계산한다: 2 × 2 = 4, 1 × 1 = 1, 4 − 1 = 3 이므로 $A^{-1} = \frac{1}{3}\begin{pmatrix}2&-1\\-1&2\end{pmatrix}$ (3이 0이 아니니 역행렬이 있다)
4. 해의 식을 쓴다: $\mathbf{x} = A^{-1}\mathbf{b} = \frac{1}{3}\begin{pmatrix}2&-1\\-1&2\end{pmatrix}\begin{pmatrix}1500\\1200\end{pmatrix}$
5. 첫째 줄을 펼친다: $2 \times 1500 + (-1) \times 1200 = 3000 - 1200 = 1800$
6. 둘째 줄을 펼친다: $(-1) \times 1500 + 2 \times 1200 = -1500 + 2400 = 900$ 이므로 $\mathbf{x} = \frac{1}{3}(1800, 900)$
7. 3으로 나눈다: 1800 ÷ 3 = 600, 900 ÷ 3 = 300
8. 확인한다: $2 \times 600 + 300 = 1500$, $600 + 2 \times 300 = 1200$ (두 영수증과 같다)

**답**: 연필 한 자루 **600원**, 지우개 한 개 **300원**

</details>

### 문제 7
$D = \begin{pmatrix}2&0\\0&4\end{pmatrix}$의 역행렬을 구하고, $D\mathbf{x} = (6, 2)$를 풀어라.

<details><summary>풀이와 답</summary>

**주어진 값**:
- $a = 2,\ b = 0$ (첫 줄)
- $c = 0,\ d = 4$ (둘째 줄)
- $\mathbf{b} = (6, 2)$ (오른쪽 값)

**풀이**
1. 식을 그대로 쓴다: $D^{-1} = \frac{1}{ad - bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}$
2. 값을 대입한다: $D^{-1} = \frac{1}{2 \times 4 - 0 \times 0}\begin{pmatrix}4&-0\\-0&2\end{pmatrix}$
3. 분모를 계산한다: 2 × 4 = 8, 0 × 0 = 0, 8 − 0 = 8 이고 −0 = 0 이므로 $D^{-1} = \frac{1}{8}\begin{pmatrix}4&0\\0&2\end{pmatrix}$
4. $\frac{1}{8} = 0.125$를 칸마다 곱한다: 0.125 × 4 = 0.5, 0.125 × 2 = 0.25 이므로 $D^{-1} = \begin{pmatrix}0.5&0\\0&0.25\end{pmatrix}$ (대각 행렬은 대각선 값을 하나씩 뒤집으면 된다. $\frac{1}{2} = 0.5$, $\frac{1}{4} = 0.25$)
5. 해의 식을 쓴다: $\mathbf{x} = D^{-1}\mathbf{b} = \begin{pmatrix}0.5&0\\0&0.25\end{pmatrix}\begin{pmatrix}6\\2\end{pmatrix}$
6. 첫째 줄: $0.5 \times 6 + 0 \times 2 = 3 + 0 = 3$
7. 둘째 줄: $0 \times 6 + 0.25 \times 2 = 0 + 0.5 = 0.5$

**답**: $D^{-1} = \begin{pmatrix}0.5&0\\0&0.25\end{pmatrix}$, $\mathbf{x} = (3, 0.5)$ (확인: $2 \times 3 = 6$, $4 \times 0.5 = 2$)

</details>

### 문제 8
점 (0, 2), (1, 3), (2, 7)에 직선 $y = w_0 + w_1 x$를 최소제곱으로 맞춰라. 정규방정식으로 $\mathbf{w}$를 구하고, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 제곱합 $E$도 구하라.

<details><summary>풀이와 답</summary>

점이 3개, 미지수가 2개라 모든 점을 지나는 직선은 없다. 그래서 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 제곱합을 가장 작게 하는 $\mathbf{w} = (X^\top X)^{-1}X^\top\mathbf{y}$를 쓴다.

**주어진 값**:
- $X = \begin{pmatrix}1&0\\1&1\\1&2\end{pmatrix}$ (첫 열은 [편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5), 둘째 열은 $x = 0, 1, 2$)
- $\mathbf{y} = (2, 3, 7)$ ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5))

**풀이**
1. 식을 그대로 쓴다: $\mathbf{w} = (X^\top X)^{-1}X^\top\mathbf{y}$
2. 값을 대입한다: $\mathbf{w} = \left(\begin{pmatrix}1&1&1\\0&1&2\end{pmatrix}\begin{pmatrix}1&0\\1&1\\1&2\end{pmatrix}\right)^{-1}\begin{pmatrix}1&1&1\\0&1&2\end{pmatrix}\begin{pmatrix}2\\3\\7\end{pmatrix}$
3. $X^\top X$의 첫 줄·첫 열: $1 \times 1 + 1 \times 1 + 1 \times 1 = 3$
4. 첫 줄·둘째 열: $1 \times 0 + 1 \times 1 + 1 \times 2 = 0 + 1 + 2 = 3$ (둘째 줄·첫 열도 3)
5. 둘째 줄·둘째 열: $0 \times 0 + 1 \times 1 + 2 \times 2 = 0 + 1 + 4 = 5$ 이므로 $X^\top X = \begin{pmatrix}3&3\\3&5\end{pmatrix}$
6. $X^\top\mathbf{y}$의 첫 칸: $1 \times 2 + 1 \times 3 + 1 \times 7 = 2 + 3 + 7 = 12$
7. 둘째 칸: $0 \times 2 + 1 \times 3 + 2 \times 7 = 0 + 3 + 14 = 17$ 이므로 $X^\top\mathbf{y} = (12, 17)$
8. 행렬식을 구한다: $3 \times 5 - 3 \times 3 = 15 - 9 = 6$ 이므로 $(X^\top X)^{-1} = \frac{1}{6}\begin{pmatrix}5&-3\\-3&3\end{pmatrix}$
9. 첫 칸: $\frac{1}{6}\big(5 \times 12 + (-3) \times 17\big) = \frac{1}{6}(60 - 51) = \frac{9}{6} = 1.5$
10. 둘째 칸: $\frac{1}{6}\big((-3) \times 12 + 3 \times 17\big) = \frac{1}{6}(-36 + 51) = \frac{15}{6} = 2.5$
11. [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)를 구한다. 예측 $X\mathbf{w}$: 1.5 + 0 × 2.5 = 1.5, 1.5 + 1 × 2.5 = 4, 1.5 + 2 × 2.5 = 6.5
12. 잔차(예측 − [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)): 1.5 − 2 = −0.5, 4 − 3 = 1, 6.5 − 7 = −0.5
13. 제곱해 더한다: $(-0.5)^2 + 1^2 + (-0.5)^2 = 0.25 + 1 + 0.25 = 1.5$

**답**: $\mathbf{w} = (1.5,\ 2.5)$, 직선 $y = 1.5 + 2.5x$, $E = 1.5$

</details>

### 문제 9
[Lec07 4](../../Lec07_%EC%B5%9C%EC%A0%81%ED%99%94%EC%9D%98_%EC%8A%A4%EC%BC%80%EC%9D%BC%EB%A7%81_%EA%B7%9C%EC%B9%99.md#4-%EB%89%B4%ED%84%B4-%EB%B0%A9%EB%B2%95)의 [뉴턴 방법](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#newtons-method-%EB%89%B4%ED%84%B4-%EB%B0%A9%EB%B2%95)은 한 걸음 $\Delta\mathbf{w} = -H^{-1}\mathbf{g}$를 움직인다. 이는 $H\mathbf{d} = \mathbf{g}$라는 연립방정식을 푸는 일이다. [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $L(w) = w_1^2 + 4w_2^2$의 지금 자리 $\mathbf{w} = (2, 1)$에서 뉴턴 한 걸음을 하면 어디에 도착하는가? ([MM26_테일러_전개와_뉴턴_방법](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/09_%EC%B5%9C%EC%A0%81%ED%99%94%EC%9D%98_%EA%B8%B0%ED%95%98/MM26_%ED%85%8C%EC%9D%BC%EB%9F%AC_%EC%A0%84%EA%B0%9C%EC%99%80_%EB%89%B4%ED%84%B4_%EB%B0%A9%EB%B2%95.md))

<details><summary>풀이와 답</summary>

$H$는 [헤세 행렬](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#hessian-%ED%97%A4%EC%84%B8-%ED%96%89%EB%A0%AC)(방향마다 얼마나 휘었는지), $\mathbf{g}$는 [그래디언트](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-vector-%EA%B7%B8%EB%9E%98%EB%94%94%EC%96%B8%ED%8A%B8-%EB%B2%A1%ED%84%B0)다. 역행렬 공식으로 $\mathbf{d} = H^{-1}\mathbf{g}$를 구한 뒤 $\mathbf{w}$에서 뺀다.

**주어진 값**:
- $\mathbf{w} = (2, 1)$ (지금 자리)
- $\mathbf{g} = (2w_1,\ 8w_2) = (2 \times 2,\ 8 \times 1) = (4, 8)$ (그래디언트: $w_1^2$의 [미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#derivative-%EB%AF%B8%EB%B6%84)은 $2w_1$, $4w_2^2$의 [미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#derivative-%EB%AF%B8%EB%B6%84)은 $8w_2$)
- $H = \begin{pmatrix}2&0\\0&8\end{pmatrix}$ ($w_1$ 방향의 휘어짐 2, $w_2$ 방향의 휘어짐 8, 섞인 칸 0)

**풀이**
1. 식을 그대로 쓴다: $\mathbf{d} = H^{-1}\mathbf{g}$, 새 자리 $\mathbf{w} - \mathbf{d}$
2. $H^{-1}$을 2×2 공식으로 구한다: $\frac{1}{2 \times 8 - 0 \times 0}\begin{pmatrix}8&0\\0&2\end{pmatrix} = \frac{1}{16}\begin{pmatrix}8&0\\0&2\end{pmatrix}$
3. $\frac{1}{16} = 0.0625$를 칸마다 곱한다: 0.0625 × 8 = 0.5, 0.0625 × 2 = 0.125 이므로 $H^{-1} = \begin{pmatrix}0.5&0\\0&0.125\end{pmatrix}$
4. 값을 대입한다: $\mathbf{d} = \begin{pmatrix}0.5&0\\0&0.125\end{pmatrix}\begin{pmatrix}4\\8\end{pmatrix}$
5. 첫째 줄: $0.5 \times 4 + 0 \times 8 = 2 + 0 = 2$
6. 둘째 줄: $0 \times 4 + 0.125 \times 8 = 0 + 1 = 1$ 이므로 $\mathbf{d} = (2, 1)$
7. 새 자리를 구한다: $\mathbf{w} - \mathbf{d} = (2 - 2,\ 1 - 1)$
8. 뺄셈을 한다: 2 − 2 = 0, 1 − 1 = 0

**답**: $(0, 0)$ (이 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)의 바닥. 이차식이라 한 걸음에 닿는다)

</details>

### 문제 10
[Lec06 5.4](../../Lec06_%EC%9D%BC%EB%B0%98%ED%99%94_%EC%9D%B4%EB%A1%A0.md#54-%EC%9D%B4%EC%A4%91-%ED%95%98%EA%B0%95)처럼 미지수가 식보다 많으면 해가 무수히 많다. 식 한 개 $w_1 + 2w_2 = 5$의 해 중 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)이 가장 작은 것을 $\mathbf{w}^\star = A^\top(AA^\top)^{-1}\mathbf{y}$로 구하라. ($A = \begin{pmatrix}1&2\end{pmatrix}$, $\mathbf{y} = (5)$, [MM23_최소_노름_해와_이중_하강](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/08_%EC%9D%BC%EB%B0%98%ED%99%94/MM23_%EC%B5%9C%EC%86%8C_%EB%85%B8%EB%A6%84_%ED%95%B4%EC%99%80_%EC%9D%B4%EC%A4%91_%ED%95%98%EA%B0%95.md))

<details><summary>풀이와 답</summary>

$A$는 1×2 행렬이라 $A A^\top$는 숫자 하나(1×1 행렬)이고, 그 역행렬은 역수 $\frac{1}{\text{그 숫자}}$다.

**주어진 값**:
- $A = \begin{pmatrix}1&2\end{pmatrix}$ (식 하나의 계수), $A^\top = \begin{pmatrix}1\\2\end{pmatrix}$ ([전치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#transpose-%EC%A0%84%EC%B9%98))
- $\mathbf{y} = (5)$ (식 오른쪽 값)

**풀이**
1. 식을 그대로 쓴다: $\mathbf{w}^\star = A^\top(AA^\top)^{-1}\mathbf{y}$
2. 값을 대입한다: $\mathbf{w}^\star = \begin{pmatrix}1\\2\end{pmatrix}\left(\begin{pmatrix}1&2\end{pmatrix}\begin{pmatrix}1\\2\end{pmatrix}\right)^{-1}(5)$
3. $AA^\top$를 계산한다: $1 \times 1 + 2 \times 2 = 1 + 4 = 5$
4. 숫자 하나의 역행렬은 역수다: $5^{-1} = \frac{1}{5} = 0.2$ 이므로 $\mathbf{w}^\star = \begin{pmatrix}1\\2\end{pmatrix} \times 0.2 \times 5$
5. 곱셈을 한다: 0.2 × 5 = 1 이므로 $\mathbf{w}^\star = \begin{pmatrix}1\\2\end{pmatrix} \times 1$
6. 칸마다 곱한다: 1 × 1 = 1, 2 × 1 = 2 이므로 $\mathbf{w}^\star = (1, 2)$
7. 식을 만족하는지 확인한다: $1 + 2 \times 2 = 5$
8. [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)을 다른 해와 비교한다. $\mathbf{w}^\star$: $\sqrt{1^2 + 2^2} = \sqrt{5} = 2.2361$, 해 $(3, 1)$: $\sqrt{9 + 1} = \sqrt{10} = 3.1623$, 해 $(5, 0)$: $\sqrt{25 + 0} = 5$

**답**: $\mathbf{w}^\star = (1, 2)$, [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84) $\sqrt{5} = 2.2361$ (다른 해 (3, 1), (5, 0)의 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84) 3.1623, 5보다 작다)

</details>
