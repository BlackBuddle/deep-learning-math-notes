# 예제: 립시츠 연속과 노름

개념 노트: [MM11_립시츠_연속과_노름](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/03_%EC%84%A0%ED%98%95%EB%8C%80%EC%88%98/MM11_%EB%A6%BD%EC%8B%9C%EC%B8%A0_%EC%97%B0%EC%86%8D%EA%B3%BC_%EB%85%B8%EB%A6%84.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 직접 풀어 보고, 펼쳐서 확인한다.

## 기본 (직접 대입)

### 문제 1
$g(x) = x^2$을 0~1에서 보면 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)의 상한이 $L = 2$다. $x = 0.5$에서 $\Delta x = 0.3$만큼 움직일 때 $|g(x + \Delta x) - g(x)| \le L\,|\Delta x|$가 성립하는지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $g(x) = x^2$ (재려는 함수)
- $L = 2$ (립시츠 상수)
- $x = 0.5$ (기준 입력)
- $\Delta x = 0.3$ (입력 변화량)

**풀이**
1. 식을 그대로 쓴다: $|g(x + \Delta x) - g(x)| \le L\,|\Delta x|$
2. 값을 대입한다: $|(0.5 + 0.3)^2 - 0.5^2| \le 2\,|0.3|$
3. 괄호 안 덧셈을 한다: 0.5 + 0.3 = 0.8 이므로 $|0.8^2 - 0.5^2| \le 2\,|0.3|$
4. 제곱을 한다: $0.8^2 = 0.64$, $0.5^2 = 0.25$ 이므로 $|0.64 - 0.25| \le 2\,|0.3|$
5. 왼쪽 뺄셈을 한다: 0.64 − 0.25 = 0.39
6. 오른쪽 곱셈을 한다: 2 × 0.3 = 0.6 이므로 $0.39 \le 0.6$
7. 두 수를 비교한다: 0.39는 0.6보다 작다

**답**: 성립한다 (0.39 ≤ 0.6)

</details>

### 문제 2
$g(x) = x^2$을 0~3 구간에서 볼 때 립시츠 상수 $L$을 구하고($g'(x) = 2x$), $x = 2$에서 $\Delta x = 0.5$일 때 두 점 사이의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 $L$ 이하인지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $g(x) = x^2$, 구간 0~3
- $g'(x) = 2x$ (도함수)
- $x = 2$, $\Delta x = 0.5$

**풀이**
1. 식을 그대로 쓴다: $L = \max |g'(x)|$, $g'(x) = 2x$
2. 가장 큰 곳을 찾는다: 구간 0~3에서 $2x$는 x가 클수록 커지므로 $x = 3$에서 최대
3. 값을 대입한다: $g'(3) = 2 \times 3 = 6$ 이므로 $L = 6$
4. 두 점 사이 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)의 식을 쓴다: $\frac{|g(x + \Delta x) - g(x)|}{|\Delta x|}$
5. 값을 대입한다: $\frac{|g(2.5) - g(2)|}{0.5} = \frac{|2.5^2 - 2^2|}{0.5}$
6. 제곱을 한다: $2.5^2 = 6.25$, $2^2 = 4$ 이므로 $\frac{|6.25 - 4|}{0.5}$
7. 뺄셈을 한다: 6.25 − 4 = 2.25 이므로 $\frac{2.25}{0.5}$
8. 나눗셈을 한다: 2.25 ÷ 0.5 = 4.5
9. 비교한다: 4.5는 6보다 작다

**답**: $L = 6$. 두 점 사이 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) 4.5는 $L$ 이하라 성립한다. (0~1 구간이었다면 $L = 2$였으니, 립시츠 상수는 구간에 따라 달라진다)

</details>

### 문제 3
원소가 4개인 벡터 $x = (3, 4, 0, 0)$의 유클리드 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)과 [RMS 노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#rms-norm-rms-%EB%85%B8%EB%A6%84)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x = (3, 4, 0, 0)$ (크기를 잴 벡터)
- $d = 4$ (원소 수)

**풀이**
1. 식을 그대로 쓴다: $\lVert x \rVert_2 = \sqrt{\sum_i x_i^2}, \quad \lVert x \rVert_{\mathrm{RMS}} = \frac{\lVert x \rVert_2}{\sqrt{d}}$ (√는 제곱하면 안의 수가 되는 양수)
2. 값을 대입한다 (Σ를 네 항으로 펼침): $\lVert x \rVert_2 = \sqrt{3^2 + 4^2 + 0^2 + 0^2}$
3. 제곱을 한다: 3² = 9, 4² = 16, 0² = 0, 0² = 0 이므로 $\sqrt{9 + 16 + 0 + 0}$
4. 더한다: 9 + 16 = 25 이므로 $\sqrt{25}$
5. 제곱근을 구한다: 5 × 5 = 25 이므로 $\lVert x \rVert_2 = 5$
6. RMS 식에 대입한다: $\lVert x \rVert_{\mathrm{RMS}} = \frac{5}{\sqrt{4}}$
7. 제곱근을 구한다: 2 × 2 = 4 이므로 $\sqrt{4} = 2$
8. 나눗셈을 한다: 5 ÷ 2 = 2.5

**답**: 유클리드 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84) 5, [RMS 노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#rms-norm-rms-%EB%85%B8%EB%A6%84) 2.5

</details>

### 문제 4
0~1에서 근사 함수 $f(x) = 0.5$ (늘 0.5)와 목표 함수 $g(x) = x$ 사이의 [최대 오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#l-error-l1-error-%EC%B5%9C%EB%8C%80-%EC%98%A4%EC%B0%A8%EC%99%80-%EC%A0%81%EB%B6%84-%EC%98%A4%EC%B0%A8)와 [적분 오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#l-error-l1-error-%EC%B5%9C%EB%8C%80-%EC%98%A4%EC%B0%A8%EC%99%80-%EC%A0%81%EB%B6%84-%EC%98%A4%EC%B0%A8)를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $f(x) = 0.5$ (근사 함수)
- $g(x) = x$ (목표 함수)
- $0 \le x \le 1$ (입력 구간)

**풀이**
1. 식을 그대로 쓴다: $\mathrm{error}_\infty = \max_x |f(x) - g(x)|, \quad \mathrm{error}_1 = \int |f(x) - g(x)|\,dx$
2. 값을 대입한다: $\mathrm{error}_\infty = \max_x |0.5 - x|, \quad \mathrm{error}_1 = \int_0^1 |0.5 - x|\,dx$
3. 차이가 가장 큰 곳을 찾는다: $x = 0$에서 $|0.5 - 0| = 0.5$, $x = 1$에서 $|0.5 - 1| = 0.5$, $x = 0.5$에서는 0. 가운데가 가장 작고 양 끝이 가장 크므로 $\mathrm{error}_\infty = 0.5$
4. 적분(∫)의 뜻: $|0.5 - x|$ 그래프 아래 넓이다. 이 그래프는 0~0.5와 0.5~1에서 각각 직각삼각형 모양이다.
5. 삼각형 하나의 넓이를 구한다: 밑변 0.5, 높이 0.5 이므로 0.5 × 0.5 ÷ 2 = 0.125
6. 두 삼각형을 더한다: 0.125 + 0.125 = 0.25

**답**: [최대 오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#l-error-l1-error-%EC%B5%9C%EB%8C%80-%EC%98%A4%EC%B0%A8%EC%99%80-%EC%A0%81%EB%B6%84-%EC%98%A4%EC%B0%A8) 0.5, [적분 오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#l-error-l1-error-%EC%B5%9C%EB%8C%80-%EC%98%A4%EC%B0%A8%EC%99%80-%EC%A0%81%EB%B6%84-%EC%98%A4%EC%B0%A8) 0.25

</details>

### 문제 5
$g(x) = |x|$는 $x = 0$에서 미분할 수 없지만 립시츠 상수 $L = 1$을 갖는다. $x = -1$에서 $\Delta x = 3$만큼 움직일 때 $|g(x + \Delta x) - g(x)| \le L\,|\Delta x|$가 성립하는지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $g(x) = |x|$ (절댓값 함수)
- $L = 1$
- $x = -1$, $\Delta x = 3$ (움직이는 길이 안에 꺾임점 0이 들어 있다)

**풀이**
1. 식을 그대로 쓴다: $|g(x + \Delta x) - g(x)| \le L\,|\Delta x|$
2. 값을 대입한다: $\big|\,|-1 + 3| - |-1|\,\big| \le 1 \times |3|$
3. 괄호 안 덧셈을 한다: −1 + 3 = 2 이므로 $\big|\,|2| - |-1|\,\big|$
4. 안쪽 절댓값을 푼다: |2| = 2, |−1| = 1 이므로 $|2 - 1|$
5. 왼쪽 뺄셈을 한다: 2 − 1 = 1
6. 오른쪽 곱셈을 한다: 1 × 3 = 3 이므로 $1 \le 3$
7. 두 수를 비교한다: 1은 3보다 작다

**답**: 성립한다 (1 ≤ 3). 꺾인 점이 있어도 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)의 크기가 어디서나 1 이하라 립시츠다.

</details>

### 문제 6
$g(x) = \sqrt{x}$가 립시츠가 아님을, $x = 0$에서 $\Delta x = 0.01$, $0.0001$로 줄여 가며 두 점 사이 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $\frac{|g(\Delta x) - g(0)|}{\Delta x}$로 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $g(x) = \sqrt{x}$ (제곱근 함수, $g(0) = 0$)
- $\Delta x = 0.01$, $0.0001$ (점점 줄이는 입력 변화량)

**풀이**
1. 식을 그대로 쓴다: [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $= \frac{|g(0 + \Delta x) - g(0)|}{\Delta x}$
2. $\Delta x = 0.01$을 대입한다: $\frac{|\sqrt{0.01} - 0|}{0.01}$
3. 제곱근을 구한다: 0.1 × 0.1 = 0.01 이므로 $\sqrt{0.01} = 0.1$
4. 나눗셈을 한다: $\frac{0.1}{0.01} = 10$
5. $\Delta x = 0.0001$을 대입한다: $\frac{|\sqrt{0.0001} - 0|}{0.0001}$
6. 제곱근을 구한다: 0.01 × 0.01 = 0.0001 이므로 $\sqrt{0.0001} = 0.01$
7. 나눗셈을 한다: $\frac{0.01}{0.0001} = 100$

**답**: [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 10에서 100으로 계속 커진다. $\Delta x$를 더 줄이면 끝없이 커져서 어떤 $L$로도 막을 수 없으므로 $\sqrt{x}$는 립시츠가 아니다.

</details>

### 문제 7
모든 원소가 3인 벡터가 4차원일 때와 16차원일 때 유클리드 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)과 [RMS 노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#rms-norm-rms-%EB%85%B8%EB%A6%84)을 각각 구하고, 왜 [RMS 노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#rms-norm-rms-%EB%85%B8%EB%A6%84)이 "차원 없는 크기"인지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x^{(4)} = (3, 3, 3, 3)$, $d = 4$
- $x^{(16)} = $ 3이 16개, $d = 16$

**풀이**
1. 식을 그대로 쓴다: $\lVert x \rVert_2 = \sqrt{\sum_i x_i^2}, \quad \lVert x \rVert_{\mathrm{RMS}} = \frac{\lVert x \rVert_2}{\sqrt{d}}$
2. 4차원 제곱의 합을 구한다: 3² = 9가 4개이므로 9 × 4 = 36
3. 4차원 유클리드 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84): $\sqrt{36} = 6$ (6 × 6 = 36)
4. 4차원 [RMS 노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#rms-norm-rms-%EB%85%B8%EB%A6%84): $\frac{6}{\sqrt{4}} = \frac{6}{2} = 3$
5. 16차원 제곱의 합을 구한다: 9가 16개이므로 9 × 16 = 144
6. 16차원 유클리드 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84): $\sqrt{144} = 12$ (12 × 12 = 144)
7. 16차원 [RMS 노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#rms-norm-rms-%EB%85%B8%EB%A6%84): $\frac{12}{\sqrt{16}} = \frac{12}{4} = 3$

**답**: 4차원은 유클리드 6, RMS 3. 16차원은 유클리드 12, RMS 3. 유클리드 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)은 차원이 커지면 같이 커지지만, [RMS 노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#rms-norm-rms-%EB%85%B8%EB%A6%84)은 $\sqrt{d}$로 나누어 "원소 하나의 평균적 크기" 3을 그대로 돌려준다.

</details>

### 문제 8
립시츠 상수가 $L = 2$인 함수를 폭 $w$인 칸 안에서 칸 가운데 값 하나로 근사하면, 칸 안 어디서든 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)가 $L \times \frac{w}{2}$ 이하다. 0~1 구간에서 [최대 오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#l-error-l1-error-%EC%B5%9C%EB%8C%80-%EC%98%A4%EC%B0%A8%EC%99%80-%EC%A0%81%EB%B6%84-%EC%98%A4%EC%B0%A8)를 $\varepsilon = 0.1$ 이하로 만들려면 칸의 폭 $w$와 칸 수는 얼마여야 하는가?

<details><summary>풀이와 답</summary>

칸 가운데에서 가장 먼 점까지의 거리는 $\frac{w}{2}$이고, 립시츠이므로 그 사이에서 함수는 $L \times \frac{w}{2}$보다 더 바뀌지 않는다.

**주어진 값**
- $L = 2$ (립시츠 상수)
- $\varepsilon = 0.1$ (허용 [최대 오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#l-error-l1-error-%EC%B5%9C%EB%8C%80-%EC%98%A4%EC%B0%A8%EC%99%80-%EC%A0%81%EB%B6%84-%EC%98%A4%EC%B0%A8))
- 구간 길이 1

**풀이**
1. 식을 그대로 쓴다: $L \times \frac{w}{2} \le \varepsilon$
2. 값을 대입한다: $2 \times \frac{w}{2} \le 0.1$
3. 정리한다: 2 × (w ÷ 2) = w 이므로 $w \le 0.1$
4. 칸 수 식을 쓴다: 칸 수 = 구간 길이 ÷ 칸 폭
5. 값을 대입한다: 1 ÷ 0.1
6. 나눗셈을 한다: 1 ÷ 0.1 = 10

**답**: 폭 $w \le 0.1$, 칸 수는 10개. 립시츠 상수가 클수록([기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 가파를수록) 칸이 더 잘아야 한다.

</details>

## 강의와 연결

### 문제 9
[Lec03 4절](../../Lec03_%EA%B7%BC%EC%82%AC_%EC%9D%B4%EB%A1%A0.md#4-%EA%B7%BC%EC%82%AC-%EB%AC%B8%EC%A0%9C%EB%A5%BC-%EC%8B%9D%EC%9C%BC%EB%A1%9C-%EC%93%B0%EA%B8%B0)의 두 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8). 0~1에서 목표 함수 $g(x) = 0$, 근사 함수 $f(x)$가 0.4~0.6 구간에만 솟은 삼각형 봉우리(0.4에서 0, 0.5에서 높이 1, 0.6에서 0)이고 나머지는 0이다. [최대 오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#l-error-l1-error-%EC%B5%9C%EB%8C%80-%EC%98%A4%EC%B0%A8%EC%99%80-%EC%A0%81%EB%B6%84-%EC%98%A4%EC%B0%A8)와 [적분 오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#l-error-l1-error-%EC%B5%9C%EB%8C%80-%EC%98%A4%EC%B0%A8%EC%99%80-%EC%A0%81%EB%B6%84-%EC%98%A4%EC%B0%A8)를 구하고, 둘이 왜 이렇게 다른지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $g(x) = 0$ (목표 함수)
- $f(x)$: 0.4에서 0, 0.5에서 1, 0.6에서 0인 삼각형 봉우리, 나머지는 0
- 구간 0~1

**풀이**
1. 식을 그대로 쓴다: $\mathrm{error}_\infty = \max_x |f(x) - g(x)|, \quad \mathrm{error}_1 = \int |f(x) - g(x)|\,dx$
2. 값을 대입한다: $g = 0$ 이므로 $|f(x) - g(x)| = |f(x)| = f(x)$ (봉우리는 0 이상)
3. [최대 오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#l-error-l1-error-%EC%B5%9C%EB%8C%80-%EC%98%A4%EC%B0%A8%EC%99%80-%EC%A0%81%EB%B6%84-%EC%98%A4%EC%B0%A8)를 구한다: $f$의 가장 큰 값은 꼭짓점의 1 이므로 $\mathrm{error}_\infty = 1$
4. 적분(∫)의 뜻: $f$ 그래프 아래 넓이다. 모양이 삼각형이다.
5. 밑변을 구한다: 0.6 − 0.4 = 0.2
6. 삼각형 넓이를 구한다: 밑변 × 높이 ÷ 2 = 0.2 × 1 ÷ 2 = 0.1

**답**: [최대 오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#l-error-l1-error-%EC%B5%9C%EB%8C%80-%EC%98%A4%EC%B0%A8%EC%99%80-%EC%A0%81%EB%B6%84-%EC%98%A4%EC%B0%A8) 1, [적분 오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#l-error-l1-error-%EC%B5%9C%EB%8C%80-%EC%98%A4%EC%B0%A8%EC%99%80-%EC%A0%81%EB%B6%84-%EC%98%A4%EC%B0%A8) 0.1. [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)가 큰 곳이 좁게 몰려 있으면 [최대 오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#l-error-l1-error-%EC%B5%9C%EB%8C%80-%EC%98%A4%EC%B0%A8%EC%99%80-%EC%A0%81%EB%B6%84-%EC%98%A4%EC%B0%A8)는 크지만 [적분 오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#l-error-l1-error-%EC%B5%9C%EB%8C%80-%EC%98%A4%EC%B0%A8%EC%99%80-%EC%A0%81%EB%B6%84-%EC%98%A4%EC%B0%A8)(차이의 넓이)는 작게 나온다.

</details>

### 문제 10
[Lec03 5절](../../Lec03_%EA%B7%BC%EC%82%AC_%EC%9D%B4%EB%A1%A0.md#5-%EB%A6%BD%EC%8B%9C%EC%B8%A0-%EC%97%B0%EC%86%8D)에서 입력이 벡터이면 $\Delta x$의 크기를 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)으로 잰다. $g(x) = 3x_1 + 4x_2$, $\Delta x = (0.6, 0.8)$일 때 출력 변화를 구하고, 유클리드 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84) 기준과 [RMS 노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#rms-norm-rms-%EB%85%B8%EB%A6%84) 기준으로 각각 (출력 변화) ÷ (입력 변화의 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84))을 구하라.

<details><summary>풀이와 답</summary>

같은 함수라도 입력 크기를 재는 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)이 다르면 립시츠 상수가 달라진다.

**주어진 값**
- $g(x) = 3x_1 + 4x_2$ (선형 함수)
- $\Delta x = (0.6, 0.8)$ (입력 변화), $d = 2$

**풀이**
1. 출력 변화 식을 쓴다: $g(x + \Delta x) - g(x) = 3\Delta x_1 + 4\Delta x_2$ (선형이라 x에 상관없다)
2. 값을 대입한다: $3 \times 0.6 + 4 \times 0.8$
3. 곱셈을 한다: 3 × 0.6 = 1.8, 4 × 0.8 = 3.2 이므로 $1.8 + 3.2$
4. 더한다: 1.8 + 3.2 = 5
5. 유클리드 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)을 구한다: $\lVert \Delta x \rVert_2 = \sqrt{0.6^2 + 0.8^2} = \sqrt{0.36 + 0.64}$
6. 더하고 제곱근을 구한다: 0.36 + 0.64 = 1 이므로 $\sqrt{1} = 1$
7. 유클리드 기준 비율: 5 ÷ 1 = 5
8. [RMS 노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#rms-norm-rms-%EB%85%B8%EB%A6%84)을 구한다: $\lVert \Delta x \rVert_{\mathrm{RMS}} = \frac{\lVert \Delta x \rVert_2}{\sqrt{d}} = \frac{1}{\sqrt{2}}$
9. 제곱근을 구한다: $\sqrt{2} \approx 1.4142$ 이므로 $\frac{1}{1.4142} \approx 0.7071$
10. RMS 기준 비율: 5 ÷ 0.7071 ≈ 7.0711

**답**: 출력 변화 5. 유클리드 기준 비율 5, RMS 기준 비율 약 7.07 ($= 5\sqrt{2}$). [RMS 노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#rms-norm-rms-%EB%85%B8%EB%A6%84)이 $\sqrt{d}$배 작아서 같은 함수의 립시츠 상수가 $\sqrt{d}$배 크게 나온다.

</details>
