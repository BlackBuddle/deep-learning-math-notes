# 예제: 마할라노비스 거리와 양의 준정부호 행렬

개념 노트: [MM43_마할라노비스_거리](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/03_%EC%84%A0%ED%98%95%EB%8C%80%EC%88%98/MM43_%EB%A7%88%ED%95%A0%EB%9D%BC%EB%85%B8%EB%B9%84%EC%8A%A4_%EA%B1%B0%EB%A6%AC.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 쓰는 규칙은 셋이다: 두 입력의 차이를 $\mathbf{d} = \mathbf{x}_i - \mathbf{x}_j$라 하면 [마할라노비스 거리](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#mahalanobis-distance-%EB%A7%88%ED%95%A0%EB%9D%BC%EB%85%B8%EB%B9%84%EC%8A%A4-%EA%B1%B0%EB%A6%AC) 제곱은 $d_A^2 = \mathbf{d}^\top A\,\mathbf{d}$이고 $A = W^\top W$다. 행렬에 벡터를 곱할 때는 행마다 칸끼리 곱해 더한다. $A$가 양의 준정부호(PSD)라는 것은 모든 $\mathbf{v}$에 대해 $\mathbf{v}^\top A\mathbf{v} \ge 0$이라는 뜻이다.

## 기본 (직접 대입)

### 문제 1

$A$가 단위행렬일 때 $d_A^2 = \mathbf{d}^\top\mathbf{d}$는 유클리드 거리 제곱이다. $\mathbf{d} = (3, 4)$일 때 값을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{d} = (3, 4)$ (두 입력의 차이)
- $A = \begin{pmatrix}1&0\\0&1\end{pmatrix}$ (단위행렬)

**풀이**
1. 식을 그대로 쓴다: $d_A^2 = \mathbf{d}^\top A\,\mathbf{d}$
2. 값을 대입한다: $d_A^2 = (3, 4)\begin{pmatrix}1&0\\0&1\end{pmatrix}\begin{pmatrix}3\\4\end{pmatrix}$
3. 행렬에 벡터를 곱한다 (행마다 펼친다): $A\mathbf{d} = (1\times3 + 0\times4,\ 0\times3 + 1\times4) = (3, 4)$
4. 차이 벡터와 내적한다 (칸끼리 곱해 더함): $3\times3 + 4\times4$
5. 곱하고 더한다: 9 + 16 = 25

**답**: $d_A^2 = 25$ (보통의 유클리드 거리 제곱)

</details>

### 문제 2

$A = \begin{pmatrix}4&0\\0&1\end{pmatrix}$, 차이 $\mathbf{d} = (1, 2)$일 때 $d_A^2$을 구하고 유클리드 거리 제곱과 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $A = \begin{pmatrix}4&0\\0&1\end{pmatrix}$ (첫째 방향을 4배 비싸게 치는 행렬)
- $\mathbf{d} = (1, 2)$ (두 입력의 차이)

**풀이**
1. 식을 그대로 쓴다: $d_A^2 = \mathbf{d}^\top A\,\mathbf{d}$
2. 값을 대입한다: $d_A^2 = (1, 2)\begin{pmatrix}4&0\\0&1\end{pmatrix}\begin{pmatrix}1\\2\end{pmatrix}$
3. 행렬에 벡터를 곱한다: $A\mathbf{d} = (4\times1 + 0\times2,\ 0\times1 + 1\times2) = (4, 2)$
4. 차이 벡터와 내적한다: $1\times4 + 2\times2$
5. 곱하고 더한다: 4 + 4 = 8
6. 유클리드 거리 제곱과 비교한다: $1^2 + 2^2 = 1 + 4 = 5$

**답**: $d_A^2 = 8$ (유클리드는 5). 첫째 방향의 차이가 4배로 반영되었다.

</details>

### 문제 3

선형 변환 $W = \begin{pmatrix}1&2\\0&1\end{pmatrix}$에 대해 $A = W^\top W$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $W = \begin{pmatrix}1&2\\0&1\end{pmatrix}$ (배우는 선형 변환)

**풀이**
1. 식을 그대로 쓴다: $A = W^\top W$
2. [전치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#transpose-%EC%A0%84%EC%B9%98)($\top$)를 구한다. 행과 열을 맞바꾼다: $W^\top = \begin{pmatrix}1&0\\2&1\end{pmatrix}$
3. 값을 대입한다: $A = \begin{pmatrix}1&0\\2&1\end{pmatrix}\begin{pmatrix}1&2\\0&1\end{pmatrix}$
4. 칸마다 (왼쪽 행) × (오른쪽 열)을 펼친다: $A = \begin{pmatrix}1\times1 + 0\times0 & 1\times2 + 0\times1\\ 2\times1 + 1\times0 & 2\times2 + 1\times1\end{pmatrix}$
5. 곱하고 더한다: 1 + 0 = 1, 2 + 0 = 2, 2 + 0 = 2, 4 + 1 = 5 이므로 $A = \begin{pmatrix}1&2\\2&5\end{pmatrix}$

**답**: $A = \begin{pmatrix}1&2\\2&5\end{pmatrix}$

</details>

### 문제 4

문제 3의 $W$와 $A$로 차이 $\mathbf{d} = (1, 1)$의 거리 제곱을 두 방법으로 구해 같은지 확인하라. (가) 변환 뒤 유클리드 거리 $\|W\mathbf{d}\|^2$, (나) $\mathbf{d}^\top A\mathbf{d}$.

<details><summary>풀이와 답</summary>

**주어진 값**
- $W = \begin{pmatrix}1&2\\0&1\end{pmatrix}$, $A = \begin{pmatrix}1&2\\2&5\end{pmatrix}$ (문제 3의 결과)
- $\mathbf{d} = (1, 1)$ (두 입력의 차이)

**풀이**
1. 식을 그대로 쓴다: (가) $\|W\mathbf{d}\|^2$, (나) $\mathbf{d}^\top A\,\mathbf{d}$
2. (가) 값을 대입한다: $W\mathbf{d} = \begin{pmatrix}1&2\\0&1\end{pmatrix}\begin{pmatrix}1\\1\end{pmatrix}$
3. (가) 행마다 펼친다: $(1\times1 + 2\times1,\ 0\times1 + 1\times1) = (3, 1)$
4. (가) 제곱해서 더한다: $\|(3, 1)\|^2 = 3^2 + 1^2 = 9 + 1 = 10$
5. (나) 값을 대입한다: $A\mathbf{d} = \begin{pmatrix}1&2\\2&5\end{pmatrix}\begin{pmatrix}1\\1\end{pmatrix}$
6. (나) 행마다 펼친다: $(1\times1 + 2\times1,\ 2\times1 + 5\times1) = (3, 7)$
7. (나) 차이 벡터와 내적한다: $1\times3 + 1\times7 = 3 + 7 = 10$
8. 비교한다: 10 = 10

**답**: (가) **10**, (나) **10**. 변환 뒤 유클리드 거리와 $A = W^\top W$로 잰 거리가 같다.

</details>

### 문제 5

$A = \begin{pmatrix}3&1\\1&3\end{pmatrix}$에서 $\mathbf{v} = (1, 1)$, $(1, -1)$, $(1, 0)$에 대해 $\mathbf{v}^\top A\mathbf{v}$를 구하라. 모두 0 이상이므로 PSD일 가능성이 높다. 반대로 $B = \begin{pmatrix}1&3\\3&1\end{pmatrix}$는 $\mathbf{v} = (1, -1)$에서 어떤 값이 나오는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $A = \begin{pmatrix}3&1\\1&3\end{pmatrix}$, $B = \begin{pmatrix}1&3\\3&1\end{pmatrix}$ (대칭 행렬)
- 시험 벡터 $(1, 1)$, $(1, -1)$, $(1, 0)$

**풀이**
1. 식을 그대로 쓴다: $\mathbf{v}^\top A\mathbf{v} = \sum_{k,l} v_k A_{kl} v_l$
2. $\mathbf{v} = (1, 1)$을 대입해 네 항으로 푼다: $1\times3\times1 + 1\times1\times1 + 1\times1\times1 + 1\times3\times1$
3. 항마다 곱하고 더한다: 3 + 1 + 1 + 3 = 8
4. $\mathbf{v} = (1, -1)$을 대입해 네 항으로 푼다: $1\times3\times1 + 1\times1\times(-1) + (-1)\times1\times1 + (-1)\times3\times(-1)$
5. 항마다 곱하고 더한다: 3 − 1 − 1 + 3 = 4
6. $\mathbf{v} = (1, 0)$을 대입한다: 0이 들어간 항은 0이라 $1\times3\times1 = 3$
7. $B$에 $\mathbf{v} = (1, -1)$을 대입해 네 항으로 푼다: $1\times1\times1 + 1\times3\times(-1) + (-1)\times3\times1 + (-1)\times1\times(-1)$
8. 항마다 곱하고 더한다: 1 − 3 − 3 + 1 = −4

**답**: $A$는 **8, 4, 3**으로 모두 0 이상이다 ([고윳값](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#eigenvector-eigenvalue-%EA%B3%A0%EC%9C%A0%EB%B2%A1%ED%84%B0%EC%99%80-%EA%B3%A0%EC%9C%B3%EA%B0%92) 4와 2라 PSD가 맞다). $B$는 $\mathbf{v} = (1, -1)$에서 **−4**로 음수라 PSD가 아니며 거리로 쓸 수 없다.

</details>

### 문제 6

$A = \begin{pmatrix}1&0\\0&0\end{pmatrix}$로 $\mathbf{x}_i = (2, 7)$과 $\mathbf{x}_j = (5, -3)$의 거리 제곱을 구하라. 어떤 정보가 지워지는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $A = \begin{pmatrix}1&0\\0&0\end{pmatrix}$ (둘째 방향의 눈금이 0인 행렬)
- $\mathbf{x}_i = (2, 7)$, $\mathbf{x}_j = (5, -3)$ (두 입력)

**풀이**
1. 식을 그대로 쓴다: $d_A^2 = (\mathbf{x}_i - \mathbf{x}_j)^\top A\,(\mathbf{x}_i - \mathbf{x}_j)$
2. 값을 대입한다: $d_A^2 = \big((2, 7) - (5, -3)\big)^\top \begin{pmatrix}1&0\\0&0\end{pmatrix} \big((2, 7) - (5, -3)\big)$
3. 두 입력을 칸별로 뺀다: $(2 - 5,\ 7 - (-3)) = (-3, 10)$
4. 행렬에 차이 벡터를 곱한다: $A(-3, 10) = (1\times(-3) + 0\times10,\ 0\times(-3) + 0\times10) = (-3, 0)$
5. 차이 벡터와 내적한다: $(-3)\times(-3) + 10\times0 = 9 + 0 = 9$

**답**: $d_A^2 = 9$. 둘째 칸의 차이(10)는 통째로 지워지고 첫째 칸의 차이(−3)만 반영된다.

</details>

### 문제 7

통계학의 [마할라노비스 거리](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#mahalanobis-distance-%EB%A7%88%ED%95%A0%EB%9D%BC%EB%85%B8%EB%B9%84%EC%8A%A4-%EA%B1%B0%EB%A6%AC)는 $A = \Sigma^{-1}$([공분산 행렬](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#covariance-matrix-%EA%B3%B5%EB%B6%84%EC%82%B0-%ED%96%89%EB%A0%AC)의 역행렬)을 쓴다. $\Sigma = \begin{pmatrix}4&0\\0&1\end{pmatrix}$일 때 $A$를 구하고, 평균 $(0, 0)$에서 점 $\mathbf{x} = (2, 1)$까지의 거리 제곱을 유클리드 거리 제곱과 비교하라. (대각 행렬의 역행렬은 대각 칸을 각각 $1/\text{값}$으로 바꾼 것이다.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $\Sigma = \begin{pmatrix}4&0\\0&1\end{pmatrix}$ ([공분산 행렬](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#covariance-matrix-%EA%B3%B5%EB%B6%84%EC%82%B0-%ED%96%89%EB%A0%AC), 첫째 방향이 더 퍼져 있음)
- $\mathbf{x} = (2, 1)$, 평균 $(0, 0)$ (점과 중심)

**풀이**
1. 식을 그대로 쓴다: $A = \Sigma^{-1}$, $d_A^2 = \mathbf{d}^\top A\,\mathbf{d}$
2. 역행렬을 구한다: $A = \begin{pmatrix}1/4&0\\0&1/1\end{pmatrix} = \begin{pmatrix}0.25&0\\0&1\end{pmatrix}$
3. 차이를 구한다: $\mathbf{d} = (2, 1) - (0, 0) = (2, 1)$
4. 값을 대입한다: $d_A^2 = (2, 1)\begin{pmatrix}0.25&0\\0&1\end{pmatrix}\begin{pmatrix}2\\1\end{pmatrix}$
5. 행렬에 벡터를 곱한다: $A\mathbf{d} = (0.25\times2 + 0\times1,\ 0\times2 + 1\times1) = (0.5, 1)$
6. 차이 벡터와 내적한다: $2\times0.5 + 1\times1 = 1 + 1 = 2$
7. 유클리드 거리 제곱과 비교한다: $2^2 + 1^2 = 4 + 1 = 5$

**답**: $A = \begin{pmatrix}0.25&0\\0&1\end{pmatrix}$, $d_A^2 = 2$ (유클리드는 5). 많이 퍼진 방향의 차이는 덜 멀게 친다.

</details>

### 문제 8

$A = \begin{pmatrix}2&0\\0&8\end{pmatrix}$, $\mathbf{x}_i = (3, 1)$, $\mathbf{x}_j = (1, 0)$일 때 [마할라노비스 거리](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#mahalanobis-distance-%EB%A7%88%ED%95%A0%EB%9D%BC%EB%85%B8%EB%B9%84%EC%8A%A4-%EA%B1%B0%EB%A6%AC) 제곱 $d_A^2$와 (제곱을 벗긴) 거리 $d_A$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $A = \begin{pmatrix}2&0\\0&8\end{pmatrix}$ (방향별 눈금 행렬)
- $\mathbf{x}_i = (3, 1)$, $\mathbf{x}_j = (1, 0)$ (두 입력)

**풀이**
1. 식을 그대로 쓴다: $d_A^2 = (\mathbf{x}_i - \mathbf{x}_j)^\top A\,(\mathbf{x}_i - \mathbf{x}_j)$, $d_A = \sqrt{d_A^2}$
2. 값을 대입한다: $d_A^2 = \big((3, 1) - (1, 0)\big)^\top \begin{pmatrix}2&0\\0&8\end{pmatrix} \big((3, 1) - (1, 0)\big)$
3. 두 입력을 칸별로 뺀다: $(3 - 1,\ 1 - 0) = (2, 1)$
4. 행렬에 차이 벡터를 곱한다: $A(2, 1) = (2\times2 + 0\times1,\ 0\times2 + 8\times1) = (4, 8)$
5. 차이 벡터와 내적한다: $2\times4 + 1\times8 = 8 + 8 = 16$
6. 제곱근을 씌운다. $\sqrt{16}$은 제곱해서 16이 되는 양수다: $d_A = \sqrt{16} = 4$

**답**: $d_A^2 = 16$, $d_A = 4$

</details>

### 문제 9

Lec12 4.1의 선형 [거리 척도 학습](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#metric-learning-%EA%B1%B0%EB%A6%AC-%EC%B2%99%EB%8F%84-%ED%95%99%EC%8A%B5)에서 입력을 $z = W\mathbf{x}$로 옮긴다. $W = (1,\ 0)$ (1×2, 첫째 좌표만 남김)이다. 같은 부류 쌍 $(1, 5)$, $(2, -3)$과 다른 부류 쌍 $(1, 5)$, $(6, 5)$의 거리 제곱을 변환 뒤에 구하고, $A = W^\top W$로 잰 값과 같은지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $W = (1, 0)$ (인코더, 2차원을 1차원으로)
- 같은 부류 쌍 $(1, 5)$, $(2, -3)$ / 다른 부류 쌍 $(1, 5)$, $(6, 5)$

**풀이**
1. 식을 그대로 쓴다: $\|W\mathbf{d}\|^2$ (변환 뒤 거리), $A = W^\top W$, $d_A^2 = \mathbf{d}^\top A\,\mathbf{d}$
2. $A$를 구한다: $W^\top = \begin{pmatrix}1\\0\end{pmatrix}$ 이므로 $A = \begin{pmatrix}1\\0\end{pmatrix}(1, 0) = \begin{pmatrix}1\times1&1\times0\\0\times1&0\times0\end{pmatrix} = \begin{pmatrix}1&0\\0&0\end{pmatrix}$
3. 같은 부류 쌍의 차이: $(1 - 2,\ 5 - (-3)) = (-1, 8)$
4. 변환 뒤 거리: $W\mathbf{d} = 1\times(-1) + 0\times8 = -1$ 이므로 $\|W\mathbf{d}\|^2 = (-1)^2 = 1$
5. $A$로 잰 거리: $A\mathbf{d} = (1\times(-1) + 0\times8,\ 0\times(-1) + 0\times8) = (-1, 0)$ 이므로 $\mathbf{d}^\top A\mathbf{d} = (-1)\times(-1) + 8\times0 = 1$
6. 다른 부류 쌍의 차이: $(1 - 6,\ 5 - 5) = (-5, 0)$
7. 변환 뒤 거리: $W\mathbf{d} = 1\times(-5) + 0\times0 = -5$ 이므로 $\|W\mathbf{d}\|^2 = (-5)^2 = 25$
8. $A$로 잰 거리: $A\mathbf{d} = (-5, 0)$ 이므로 $\mathbf{d}^\top A\mathbf{d} = (-5)\times(-5) + 0\times0 = 25$

**답**: 같은 부류 쌍 **1**, 다른 부류 쌍 **25**이고 두 방법의 값이 같다. 이 $W$는 둘째 좌표를 버려, 같은 쪽은 가깝게 다른 쪽은 멀게 한다.

</details>

### 문제 10

Lec12 4.2의 최적화는 $A \succeq 0$이라는 조건에서 푼다. $A = \begin{pmatrix}1&1\\1&1\end{pmatrix}$이 PSD인지 확인하려고 $\mathbf{v} = (1, -1)$과 $(1, 1)$에서 $\mathbf{v}^\top A\mathbf{v}$를 구하고, 두 점 $\mathbf{x}_i = (1, 0)$, $\mathbf{x}_j = (0, 1)$의 거리 제곱을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $A = \begin{pmatrix}1&1\\1&1\end{pmatrix}$ (확인할 대칭 행렬)
- $\mathbf{v} = (1, -1)$, $(1, 1)$ (시험 벡터)
- $\mathbf{x}_i = (1, 0)$, $\mathbf{x}_j = (0, 1)$ (두 점)

**풀이**
1. 식을 그대로 쓴다: $\mathbf{v}^\top A\mathbf{v}$, $d_A^2 = \mathbf{d}^\top A\mathbf{d}$
2. $\mathbf{v} = (1, -1)$에 행렬을 곱한다: $A\mathbf{v} = (1\times1 + 1\times(-1),\ 1\times1 + 1\times(-1)) = (0, 0)$
3. 내적한다: $1\times0 + (-1)\times0 = 0$ (음수는 아니다)
4. $\mathbf{v} = (1, 1)$에 행렬을 곱한다: $A\mathbf{v} = (1\times1 + 1\times1,\ 1\times1 + 1\times1) = (2, 2)$
5. 내적한다: $1\times2 + 1\times2 = 4$
6. 두 점의 차이를 구한다: $\mathbf{d} = (1 - 0,\ 0 - 1) = (1, -1)$
7. 거리 제곱에 대입한다: $d_A^2 = \mathbf{d}^\top A\mathbf{d}$ 이고 2~3단계와 같은 벡터이므로 $0$

**답**: 값이 **0**과 **4**로 음수가 없어 PSD([고윳값](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#eigenvector-eigenvalue-%EA%B3%A0%EC%9C%A0%EB%B2%A1%ED%84%B0%EC%99%80-%EA%B3%A0%EC%9C%B3%EA%B0%92) 2와 0)다. 서로 다른 두 점 $(1, 0)$, $(0, 1)$의 거리 제곱이 **0**이 된다. [고윳값](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#eigenvector-eigenvalue-%EA%B3%A0%EC%9C%A0%EB%B2%A1%ED%84%B0%EC%99%80-%EA%B3%A0%EC%9C%B3%EA%B0%92) 0인 방향 $(1, -1)$의 차이를 지우기 때문이다.
