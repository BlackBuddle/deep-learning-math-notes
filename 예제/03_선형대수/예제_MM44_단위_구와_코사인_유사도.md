# 예제: 단위 구와 코사인 유사도

개념 노트: [MM44_단위_구와_코사인_유사도](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/03_%EC%84%A0%ED%98%95%EB%8C%80%EC%88%98/MM44_%EB%8B%A8%EC%9C%84_%EA%B5%AC%EC%99%80_%EC%BD%94%EC%82%AC%EC%9D%B8_%EC%9C%A0%EC%82%AC%EB%8F%84.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 쓰는 규칙은 셋이다: [정규화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#normalization-%EC%A0%95%EA%B7%9C%ED%99%94)는 $\hat{\mathbf{u}} = \mathbf{u}/\|\mathbf{u}\|$이고, [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)(길이)은 칸 제곱의 합에 $\sqrt{\ }$를 씌운 것이다. [코사인 유사도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cosine-similarity-%EC%BD%94%EC%82%AC%EC%9D%B8-%EC%9C%A0%EC%82%AC%EB%8F%84)는 $\cos\theta = \dfrac{\mathbf{u}^\top\mathbf{v}}{\|\mathbf{u}\|\|\mathbf{v}\|}$이다. 길이 1인 두 벡터라면 $\|\mathbf{u}-\mathbf{v}\|^2 = 2 - 2\cos\theta$다. $\sqrt{a}$는 제곱해서 $a$가 되는 양수다.

## 기본 (직접 대입)

### 문제 1

$\mathbf{u} = (6, 8)$을 길이 1로 정규화하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{u} = (6, 8)$ (정규화할 벡터)

**풀이**
1. 식을 그대로 쓴다: $\hat{\mathbf{u}} = \mathbf{u} / \|\mathbf{u}\|$, $\|\mathbf{u}\| = \sqrt{u_1^2 + u_2^2}$
2. 값을 대입한다: $\|\mathbf{u}\| = \sqrt{6^2 + 8^2}$
3. 제곱하고 더한다: 36 + 64 = 100 이므로 $\|\mathbf{u}\| = \sqrt{100}$
4. 제곱근을 구한다: $\sqrt{100} = 10$ (10 × 10 = 100)
5. 길이로 칸마다 나눈다: $\hat{\mathbf{u}} = (6/10,\ 8/10)$
6. 나눈다: 6/10 = 0.6, 8/10 = 0.8 이므로 $\hat{\mathbf{u}} = (0.6, 0.8)$

**답**: $\hat{\mathbf{u}} = (0.6, 0.8)$. 확인: $0.6^2 + 0.8^2 = 0.36 + 0.64 = 1$.

</details>

### 문제 2

$\mathbf{a} = (1, 2)$와 $\mathbf{b} = (2, 1)$의 [코사인 유사도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cosine-similarity-%EC%BD%94%EC%82%AC%EC%9D%B8-%EC%9C%A0%EC%82%AC%EB%8F%84)를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{a} = (1, 2)$, $\mathbf{b} = (2, 1)$ (두 벡터)

**풀이**
1. 식을 그대로 쓴다: $\cos\theta = \dfrac{\mathbf{a}^\top\mathbf{b}}{\|\mathbf{a}\|\,\|\mathbf{b}\|}$
2. 값을 대입한다: $\cos\theta = \dfrac{(1, 2)^\top(2, 1)}{\|(1, 2)\|\,\|(2, 1)\|}$
3. [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)을 칸별로 곱해 더한다: $1\times2 + 2\times1 = 2 + 2 = 4$
4. 길이를 구한다: $\|\mathbf{a}\| = \sqrt{1^2 + 2^2} = \sqrt{5} = 2.2361$, $\|\mathbf{b}\| = \sqrt{2^2 + 1^2} = \sqrt{5} = 2.2361$
5. 두 길이를 곱한다: $\sqrt{5} \times \sqrt{5} = 5$ (같은 제곱근끼리 곱하면 안의 수가 나온다)
6. 나눈다: $\cos\theta = 4 / 5 = 0.8$

**답**: $\cos\theta = 0.8$

</details>

### 문제 3

단위 벡터 $\mathbf{u} = (0.6, 0.8)$, $\mathbf{v} = (0.8, 0.6)$의 거리 제곱을 (가) 직접 빼서, (나) $2 - 2\cos\theta$로 구해 같은지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{u} = (0.6, 0.8)$, $\mathbf{v} = (0.8, 0.6)$ (길이가 모두 1인 벡터)

**풀이**
1. 식을 그대로 쓴다: (가) $\|\mathbf{u} - \mathbf{v}\|^2$, (나) $2 - 2\,\mathbf{u}^\top\mathbf{v}$
2. (가) 값을 대입한다: $\|(0.6, 0.8) - (0.8, 0.6)\|^2$
3. (가) 칸별로 뺀다: 0.6 − 0.8 = −0.2, 0.8 − 0.6 = 0.2 이므로 $\|(-0.2, 0.2)\|^2$
4. (가) 제곱하고 더한다: $(-0.2)^2 + 0.2^2 = 0.04 + 0.04 = 0.08$
5. (나) [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)을 구한다: $0.6\times0.8 + 0.8\times0.6 = 0.48 + 0.48 = 0.96$
6. (나) 값을 대입한다: $2 - 2 \times 0.96$
7. (나) 곱하고 뺀다: 2 × 0.96 = 1.92 이므로 $2 - 1.92 = 0.08$
8. 비교한다: 0.08 = 0.08

**답**: (가) **0.08**, (나) **0.08**. 단위 벡터끼리는 거리와 [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)이 이어진다.

</details>

### 문제 4

$\mathbf{a} = (1, 1)$, $\mathbf{b} = (1, 0)$이다. $\mathbf{a}$의 길이를 10배로 늘린 $10\mathbf{a} = (10, 10)$과 $\mathbf{b}$의 [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)과 [코사인 유사도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cosine-similarity-%EC%BD%94%EC%82%AC%EC%9D%B8-%EC%9C%A0%EC%82%AC%EB%8F%84)를, 원래 $\mathbf{a}$와 $\mathbf{b}$의 값과 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{a} = (1, 1)$, $10\mathbf{a} = (10, 10)$, $\mathbf{b} = (1, 0)$

**풀이**
1. 식을 그대로 쓴다: [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81) $\mathbf{x}^\top\mathbf{b}$, 코사인 $\dfrac{\mathbf{x}^\top\mathbf{b}}{\|\mathbf{x}\|\|\mathbf{b}\|}$
2. $\mathbf{a}$의 [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81): $1\times1 + 1\times0 = 1$
3. $10\mathbf{a}$의 [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81): $10\times1 + 10\times0 = 10$
4. 길이를 구한다: $\|\mathbf{a}\| = \sqrt{1 + 1} = 1.4142$, $\|10\mathbf{a}\| = \sqrt{100 + 100} = \sqrt{200} = 14.1421$, $\|\mathbf{b}\| = \sqrt{1 + 0} = 1$
5. $\mathbf{a}$의 코사인: $1 / (1.4142 \times 1) = 0.7071$
6. $10\mathbf{a}$의 코사인: $10 / (14.1421 \times 1) = 0.7071$

**답**: [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)은 **1 → 10**으로 10배가 되지만 [코사인 유사도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cosine-similarity-%EC%BD%94%EC%82%AC%EC%9D%B8-%EC%9C%A0%EC%82%AC%EB%8F%84)는 둘 다 **0.7071**로 그대로다. 코사인은 크기에 휘둘리지 않는다.

</details>

### 문제 5

3차원 벡터 $\mathbf{a} = (1, 2, 2)$, $\mathbf{b} = (2, 2, 1)$의 [코사인 유사도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cosine-similarity-%EC%BD%94%EC%82%AC%EC%9D%B8-%EC%9C%A0%EC%82%AC%EB%8F%84)와 사이각을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{a} = (1, 2, 2)$, $\mathbf{b} = (2, 2, 1)$ (3차원 벡터)

**풀이**
1. 식을 그대로 쓴다: $\cos\theta = \dfrac{\mathbf{a}^\top\mathbf{b}}{\|\mathbf{a}\|\,\|\mathbf{b}\|}$
2. 값을 대입한다: $\cos\theta = \dfrac{(1,2,2)^\top(2,2,1)}{\|(1,2,2)\|\,\|(2,2,1)\|}$
3. [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)을 칸별로 곱해 더한다: $1\times2 + 2\times2 + 2\times1 = 2 + 4 + 2 = 8$
4. 길이를 구한다: $\|\mathbf{a}\| = \sqrt{1 + 4 + 4} = \sqrt{9} = 3$, $\|\mathbf{b}\| = \sqrt{4 + 4 + 1} = \sqrt{9} = 3$
5. 두 길이를 곱한다: $3 \times 3 = 9$
6. 나눈다: $\cos\theta = 8 / 9 = 0.8889$
7. 각도로 바꾼다. arccos는 코사인 값이 주어진 수가 되는 각을 찾는 계산이다: $\arccos 0.8889 = 27.27°$

**답**: $\cos\theta = 0.8889$, 사이각 약 **27.27°**

</details>

### 문제 6

두 단위 벡터의 거리 제곱이 $\|\mathbf{u} - \mathbf{v}\|^2 = 1.2$일 때 [코사인 유사도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cosine-similarity-%EC%BD%94%EC%82%AC%EC%9D%B8-%EC%9C%A0%EC%82%AC%EB%8F%84)와 사이각을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\|\mathbf{u} - \mathbf{v}\|^2 = 1.2$ (단위 벡터 사이 거리 제곱)

**풀이**
1. 식을 그대로 쓴다: $\cos\theta = 1 - \dfrac{\|\mathbf{u} - \mathbf{v}\|^2}{2}$ ($2 - 2\cos\theta = \|\mathbf{u}-\mathbf{v}\|^2$을 $\cos\theta$에 대해 푼 것)
2. 값을 대입한다: $\cos\theta = 1 - \dfrac{1.2}{2}$
3. 나눈다: 1.2 / 2 = 0.6
4. 뺀다: $1 - 0.6 = 0.4$
5. 각도로 바꾼다: $\arccos 0.4 = 66.42°$

**답**: $\cos\theta = 0.4$, 사이각 약 **66.42°**

</details>

### 문제 7

단위 벡터 $\mathbf{u} = (1, 0)$에 대해 (가) 반대 방향 $\mathbf{v} = (-1, 0)$, (나) 직각 방향 $\mathbf{w} = (0, 1)$의 [코사인 유사도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cosine-similarity-%EC%BD%94%EC%82%AC%EC%9D%B8-%EC%9C%A0%EC%82%AC%EB%8F%84)와 거리 제곱을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{u} = (1, 0)$, $\mathbf{v} = (-1, 0)$, $\mathbf{w} = (0, 1)$ (모두 길이 1)

**풀이**
1. 식을 그대로 쓴다: $\cos\theta = \mathbf{u}^\top\mathbf{x}$ (단위 벡터라 [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)이 곧 코사인), 거리 제곱 $= 2 - 2\cos\theta$
2. (가) [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)을 구한다: $1\times(-1) + 0\times0 = -1$ 이므로 $\cos\theta = -1$
3. (가) 거리 제곱에 대입한다: $2 - 2\times(-1) = 2 + 2 = 4$
4. (가) 직접 확인한다: $\|(1,0) - (-1,0)\|^2 = 2^2 + 0^2 = 4$
5. (나) [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)을 구한다: $1\times0 + 0\times1 = 0$ 이므로 $\cos\theta = 0$
6. (나) 거리 제곱에 대입한다: $2 - 2\times0 = 2$
7. (나) 직접 확인한다: $\|(1,0) - (0,1)\|^2 = 1^2 + (-1)^2 = 2$

**답**: (가) 코사인 **−1**, 거리 제곱 **4** (가장 멀다). (나) 코사인 **0**, 거리 제곱 **2** (중간).

</details>

### 문제 8

$\mathbf{u} = (3, 4)$, $\mathbf{v} = (2, 0)$은 길이가 1이 아니다. 거리 제곱 $\|\mathbf{u} - \mathbf{v}\|^2$를 직접 구하고, $2 - 2\cos\theta$와 같은지 확인하라. ($\cos\theta = 0.6$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{u} = (3, 4)$, $\mathbf{v} = (2, 0)$ (정규화하지 않은 벡터)
- $\cos\theta = 0.6$ (두 벡터의 [코사인 유사도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cosine-similarity-%EC%BD%94%EC%82%AC%EC%9D%B8-%EC%9C%A0%EC%82%AC%EB%8F%84))

**풀이**
1. 식을 그대로 쓴다: $\|\mathbf{u} - \mathbf{v}\|^2$ 와 $2 - 2\cos\theta$ 를 따로 구해 견준다
2. 직접 값을 대입한다: $\|(3, 4) - (2, 0)\|^2$
3. 칸별로 뺀다: $(1, 4)$
4. 제곱하고 더한다: $1^2 + 4^2 = 1 + 16 = 17$
5. 식에 대입한다: $2 - 2\times0.6$
6. 곱하고 뺀다: 2 × 0.6 = 1.2 이므로 $2 - 1.2 = 0.8$
7. 비교한다: $17 \ne 0.8$

**답**: 직접 구한 값은 **17**이고 식의 값은 **0.8**이라 다르다. $2 - 2\cos\theta$는 **둘 다 길이 1일 때만** 성립한다 (정규화한 $(0.6, 0.8)$과 $(1, 0)$이라면 0.8이다).

</details>

### 문제 9

Lec12 4.3은 표현을 정규화하면 크기에 휘둘리지 않는다고 한다. 질문 $\mathbf{q} = (1, 1)$에 대해 후보 $\mathbf{c}_1 = (10, 0)$, $\mathbf{c}_2 = (1, 3)$, $\mathbf{c}_3 = (-1, -1)$을 (가) [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81), (나) [코사인 유사도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cosine-similarity-%EC%BD%94%EC%82%AC%EC%9D%B8-%EC%9C%A0%EC%82%AC%EB%8F%84)로 순위를 매기라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{q} = (1, 1)$ (질문)
- $\mathbf{c}_1 = (10, 0)$, $\mathbf{c}_2 = (1, 3)$, $\mathbf{c}_3 = (-1, -1)$ (후보)

**풀이**
1. 식을 그대로 쓴다: [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81) $\mathbf{q}^\top\mathbf{c}$, 코사인 $\dfrac{\mathbf{q}^\top\mathbf{c}}{\|\mathbf{q}\|\|\mathbf{c}\|}$
2. (가) [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)을 구한다: $\mathbf{c}_1$은 $1\times10 + 1\times0 = 10$, $\mathbf{c}_2$는 $1\times1 + 1\times3 = 4$, $\mathbf{c}_3$은 $1\times(-1) + 1\times(-1) = -2$
3. (가) 순위를 매긴다: $10 > 4 > -2$ 이므로 $\mathbf{c}_1$, $\mathbf{c}_2$, $\mathbf{c}_3$ 순서
4. (나) 길이를 구한다: $\|\mathbf{q}\| = \sqrt{2} = 1.4142$, $\|\mathbf{c}_1\| = \sqrt{100} = 10$, $\|\mathbf{c}_2\| = \sqrt{1 + 9} = \sqrt{10} = 3.1623$, $\|\mathbf{c}_3\| = \sqrt{1 + 1} = 1.4142$
5. (나) $\mathbf{c}_1$의 코사인: $10 / (1.4142 \times 10) = 0.7071$
6. (나) $\mathbf{c}_2$의 코사인: $4 / (1.4142 \times 3.1623) = 4 / 4.4721 = 0.8944$
7. (나) $\mathbf{c}_3$의 코사인: $-2 / (1.4142 \times 1.4142) = -2 / 2 = -1$
8. (나) 순위를 매긴다: $0.8944 > 0.7071 > -1$ 이므로 $\mathbf{c}_2$, $\mathbf{c}_1$, $\mathbf{c}_3$ 순서

**답**: (가) [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81) 순위는 **$\mathbf{c}_1$ > $\mathbf{c}_2$ > $\mathbf{c}_3$**, (나) 코사인 순위는 **$\mathbf{c}_2$ > $\mathbf{c}_1$ > $\mathbf{c}_3$**. ### 문제 10

Lec12 6.1의 [InfoNCE](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#infonce-infonce-%EC%86%90%EC%8B%A4)는 거리 대신 [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81) $f(\mathbf{x})^\top f(\cdot)$을 쓴다. 단위 벡터 앵커 $\mathbf{a} = (1, 0)$, 양성 $\mathbf{p} = (0.6, 0.8)$, 음성 $\mathbf{n} = (-0.6, 0.8)$에 대해 [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81) $s^+$, $s^-$와 거리 제곱 $\|\mathbf{a} - \mathbf{p}\|^2$, $\|\mathbf{a} - \mathbf{n}\|^2$를 구하고, [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)이 클수록 거리가 작은지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{a} = (1, 0)$ (앵커), $\mathbf{p} = (0.6, 0.8)$ (양성), $\mathbf{n} = (-0.6, 0.8)$ (음성). 모두 길이 1

**풀이**
1. 식을 그대로 쓴다: $s = \mathbf{a}^\top\mathbf{x}$, $\|\mathbf{a} - \mathbf{x}\|^2 = 2 - 2s$
2. 양성 [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81): $s^+ = 1\times0.6 + 0\times0.8 = 0.6$
3. 음성 [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81): $s^- = 1\times(-0.6) + 0\times0.8 = -0.6$
4. 양성 거리 제곱을 직접 구한다: $\|(1,0) - (0.6,0.8)\|^2 = \|(0.4, -0.8)\|^2 = 0.16 + 0.64 = 0.8$
5. 식으로 확인한다: $2 - 2\times0.6 = 2 - 1.2 = 0.8$
6. 음성 거리 제곱을 직접 구한다: $\|(1,0) - (-0.6,0.8)\|^2 = \|(1.6, -0.8)\|^2 = 2.56 + 0.64 = 3.2$
7. 식으로 확인한다: $2 - 2\times(-0.6) = 2 + 1.2 = 3.2$
8. 비교한다: [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)은 $0.6 > -0.6$ 이고 거리 제곱은 $0.8 < 3.2$

**답**: $s^+ = 0.6$, $s^- = -0.6$, 거리 제곱은 **0.8**과 **3.2**. [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)이 큰 양성이 거리도 더 가깝다. 단위 구 위에서는 "[내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)을 키운다"와 "거리를 줄인다"가 같은 일이다.

</details>
