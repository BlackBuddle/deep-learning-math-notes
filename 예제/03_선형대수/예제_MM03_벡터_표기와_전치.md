# 예제: 벡터 표기와 전치

개념 노트: [MM03_벡터_표기와_전치](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/03_%EC%84%A0%ED%98%95%EB%8C%80%EC%88%98/MM03_%EB%B2%A1%ED%84%B0_%ED%91%9C%EA%B8%B0%EC%99%80_%EC%A0%84%EC%B9%98.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 벡터는 기본이 세로(열벡터)이고, $\mathbf{x}^\top\mathbf{w}$는 "눕힌 $\mathbf{x}$ × 세운 $\mathbf{w}$", 곧 칸끼리 곱해 더한 값([내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81))이다.

## 기본 (직접 대입)

### 문제 1

$\mathbf{x} = (1, 3)$, $\mathbf{w} = (2, -1)$일 때 $\mathbf{x}^\top\mathbf{w}$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{x} = (1, 3)$ (입력 벡터)
- $\mathbf{w} = (2, -1)$ ([가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) 벡터)

**풀이**
1. 식을 그대로 쓴다: $\mathbf{x}^\top \mathbf{w}$
2. 값을 대입한다 ($\mathbf{x}$는 전치해 가로로 눕힌다): $\mathbf{x}^\top \mathbf{w} = \begin{pmatrix} 1 & 3 \end{pmatrix} \begin{pmatrix} 2 \\ -1 \end{pmatrix}$
3. 칸끼리 곱해 더하는 꼴로 펼친다: $\mathbf{x}^\top \mathbf{w} = 1 \times 2 + 3 \times (-1)$
4. 첫째 곱셈을 한다: 1 × 2 = 2 이므로 $\mathbf{x}^\top \mathbf{w} = 2 + 3 \times (-1)$
5. 둘째 곱셈을 한다: 3 × (−1) = −3 이므로 $\mathbf{x}^\top \mathbf{w} = 2 + (-3)$
6. 더한다: 2 + (−3) = −1

**답**: $\mathbf{x}^\top \mathbf{w} = -1$

</details>

### 문제 2

$\mathbf{x} = (4, -2, 1)$을 전치해 가로 벡터로 쓰고, $\mathbf{w} = (1, 2, 3)$과의 [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81) $\mathbf{x}^\top\mathbf{w}$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{x} = (4, -2, 1)$ (세로로 서 있는 벡터)
- $\mathbf{w} = (1, 2, 3)$ (세로로 서 있는 벡터)

**풀이**
1. 전치한다 (세로를 가로로 눕힌다): $\mathbf{x}^\top = \begin{pmatrix} 4 & -2 & 1 \end{pmatrix}$ (1행 3열)
2. 식을 그대로 쓴다: $\mathbf{x}^\top \mathbf{w}$
3. 값을 대입한다: $\mathbf{x}^\top \mathbf{w} = \begin{pmatrix} 4 & -2 & 1 \end{pmatrix} \begin{pmatrix} 1 \\ 2 \\ 3 \end{pmatrix}$
4. 칸끼리 곱해 더하는 꼴로 펼친다: $\mathbf{x}^\top \mathbf{w} = 4 \times 1 + (-2) \times 2 + 1 \times 3$
5. 곱셈을 한다: 4 × 1 = 4, (−2) × 2 = −4, 1 × 3 = 3 이므로 $\mathbf{x}^\top \mathbf{w} = 4 + (-4) + 3$
6. 왼쪽부터 더한다: 4 + (−4) = 0 이므로 $\mathbf{x}^\top \mathbf{w} = 0 + 3$
7. 더한다: 0 + 3 = 3

**답**: $\mathbf{x}^\top = (4\ \ -2\ \ 1)$, $\mathbf{x}^\top\mathbf{w} = 3$

</details>

### 문제 3

$\mathbf{x} = (3, 2)$, $\mathbf{w} = (0.5, -1)$, $b = 0.25$일 때 [선형층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#linear-layer-%EC%84%A0%ED%98%95%EC%B8%B5) 출력 한 칸 $z = \mathbf{x}^\top\mathbf{w} + b$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{x} = (3, 2)$ (입력 벡터)
- $\mathbf{w} = (0.5, -1)$ ([가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) 벡터)
- $b = 0.25$ ([편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5))

**풀이**
1. 식을 그대로 쓴다: $z = \mathbf{x}^\top \mathbf{w} + b$
2. 값을 대입한다 ([내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)을 칸끼리 곱해 더하는 꼴로 펼친다): $z = 3 \times 0.5 + 2 \times (-1) + 0.25$
3. 첫째 곱셈을 한다: 3 × 0.5 = 1.5 이므로 $z = 1.5 + 2 \times (-1) + 0.25$
4. 둘째 곱셈을 한다: 2 × (−1) = −2 이므로 $z = 1.5 + (-2) + 0.25$
5. 왼쪽부터 더한다: 1.5 + (−2) = −0.5 (이 값이 $\mathbf{x}^\top\mathbf{w}$) 이므로 $z = -0.5 + 0.25$
6. [편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5)을 더한다: −0.5 + 0.25 = −0.25

**답**: $z = -0.25$

</details>

### 문제 4

Σ 표기 $z_j = \sum_{i=1}^{3} w_{ij}\, x_i + b_j$로 계산하라. 입력 $\mathbf{x} = (1, 0, 2)$, 출력 칸 $j$의 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) $(w_{1j}, w_{2j}, w_{3j}) = (2, 3, -1)$, [편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5) $b_j = 1$이다.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x_1 = 1$, $x_2 = 0$, $x_3 = 2$ (입력)
- $w_{1j} = 2$, $w_{2j} = 3$, $w_{3j} = -1$ (출력 칸 $j$의 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98))
- $b_j = 1$ ([편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5))

**풀이**
1. 식을 그대로 쓴다: $z_j = \sum_{i=1}^{3} w_{ij}\, x_i + b_j$
2. 값을 대입한다 (Σ를 i = 1, 2, 3 세 항으로 펼친다): $z_j = 2 \times 1 + 3 \times 0 + (-1) \times 2 + 1$
3. 첫째 곱셈을 한다: 2 × 1 = 2 이므로 $z_j = 2 + 3 \times 0 + (-1) \times 2 + 1$
4. 둘째 곱셈을 한다: 3 × 0 = 0 이므로 $z_j = 2 + 0 + (-1) \times 2 + 1$
5. 셋째 곱셈을 한다: (−1) × 2 = −2 이므로 $z_j = 2 + 0 + (-2) + 1$
6. 왼쪽부터 더한다: 2 + 0 = 2, 2 + (−2) = 0 이므로 $z_j = 0 + 1$
7. [편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5)을 더한다: 0 + 1 = 1

**답**: $z_j = 1$

</details>

### 문제 5

출력 2칸짜리 [선형층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#linear-layer-%EC%84%A0%ED%98%95%EC%B8%B5)의 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) 행렬 $\mathbf{W}$의 행이 $(2, 1)$, $(0, 3)$이고 [편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5)이 $\mathbf{b} = (1, -1)$이다. 입력 $\mathbf{x} = (1, 2)$의 출력 $\mathbf{W}\mathbf{x} + \mathbf{b}$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{W}$의 두 행 $(2, 1)$, $(0, 3)$ (출력 칸마다 한 행)
- $\mathbf{x} = (1, 2)$ (입력 벡터)
- $\mathbf{b} = (1, -1)$ (출력 칸마다의 [편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5))

**풀이**
1. 식을 그대로 쓴다: $\mathbf{W}\mathbf{x} + \mathbf{b}$
2. 값을 대입한다: $\begin{pmatrix} 2 & 1 \\ 0 & 3 \end{pmatrix} \begin{pmatrix} 1 \\ 2 \end{pmatrix} + \begin{pmatrix} 1 \\ -1 \end{pmatrix}$
3. [행렬 곱](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#matrix-multiplication-%ED%96%89%EB%A0%AC-%EA%B3%B1)을 행마다 칸끼리 곱해 더하는 꼴로 펼친다: $\begin{pmatrix} 2 \times 1 + 1 \times 2 \\ 0 \times 1 + 3 \times 2 \end{pmatrix} + \begin{pmatrix} 1 \\ -1 \end{pmatrix}$
4. 첫째 행 곱셈을 한다: 2 × 1 = 2, 1 × 2 = 2 이므로 첫째 칸은 2 + 2
5. 첫째 행을 더한다: 2 + 2 = 4
6. 둘째 행 곱셈을 한다: 0 × 1 = 0, 3 × 2 = 6 이므로 둘째 칸은 0 + 6
7. 둘째 행을 더한다: 0 + 6 = 6 이므로 $\begin{pmatrix} 4 \\ 6 \end{pmatrix} + \begin{pmatrix} 1 \\ -1 \end{pmatrix}$
8. [편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5)을 칸끼리 더한다: 4 + 1 = 5, 6 + (−1) = 5

**답**: $\mathbf{W}\mathbf{x} + \mathbf{b} = (5, 5)$

</details>

### 문제 6

입력이 5칸, 출력이 4칸인 [선형층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#linear-layer-%EC%84%A0%ED%98%95%EC%B8%B5)의 $\mathbf{W}$, $\mathbf{b}$의 모양과 [파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0) 수를 구하라. 배치 크기가 10이면 $\mathbf{X}$와 출력 $\mathbf{Z} = \mathbf{X}\mathbf{W}^\top + \mathbf{b}$의 모양은?

<details><summary>풀이와 답</summary>

**주어진 값**
- 입력 5칸 (입력 벡터의 길이)
- 출력 4칸 (출력 벡터의 길이)
- 배치 크기 10 (한 번에 계산하는 입력 개수)

**풀이**
1. $\mathbf{W}$의 모양 식을 쓴다: (출력 수) × (입력 수)
2. 값을 대입한다: 4 × 5 이므로 $\mathbf{W}$는 4×5
3. $\mathbf{b}$의 칸 수 식을 쓴다: (출력 수), 값을 대입하면 4
4. [파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0) 수 식을 쓴다: ([파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0) 수) = ($\mathbf{W}$의 칸 수) + ($\mathbf{b}$의 칸 수)
5. 값을 대입한다: ([파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0) 수) = 4 × 5 + 4
6. 곱셈을 한다: 4 × 5 = 20 이므로 ([파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0) 수) = 20 + 4
7. 더한다: 20 + 4 = 24
8. $\mathbf{X}$의 모양 식을 쓴다: (배치 크기) × (입력 수) = 10 × 5
9. 출력 모양을 구한다: (10×5) 곱하기 $\mathbf{W}^\top$(5×4)에서 앞의 열 수 5와 뒤의 행 수 5가 같아 곱할 수 있고, 결과는 (앞의 행 수) × (뒤의 열 수) = 10×4

**답**: $\mathbf{W}$ 4×5, $\mathbf{b}$ 4, [파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0) 24개, $\mathbf{X}$ 10×5, 출력 10×4

</details>

### 문제 7

입력 두 개를 행으로 쌓은 $\mathbf{X} = \begin{pmatrix} 1 & 0 \\ 2 & 1 \end{pmatrix}$, [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) 행렬 $\mathbf{W} = \begin{pmatrix} 1 & 2 \\ -1 & 1 \end{pmatrix}$ (행이 출력 칸), [편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5) $\mathbf{b} = (0, 1)$일 때 $\mathbf{Z} = \mathbf{X}\mathbf{W}^\top + \mathbf{b}$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{X}$의 두 행 $(1, 0)$, $(2, 1)$ (입력 두 개)
- $\mathbf{W}$의 두 행 $(1, 2)$, $(-1, 1)$ (출력 칸마다 한 행)
- $\mathbf{b} = (0, 1)$ ([편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5))

**풀이**
1. 식을 그대로 쓴다: $\mathbf{Z} = \mathbf{X}\mathbf{W}^\top + \mathbf{b}$
2. $\mathbf{W}$를 전치한다 (행과 열을 맞바꾼다): $\mathbf{W}^\top = \begin{pmatrix} 1 & -1 \\ 2 & 1 \end{pmatrix}$
3. 값을 대입한다: $\mathbf{Z} = \begin{pmatrix} 1 & 0 \\ 2 & 1 \end{pmatrix} \begin{pmatrix} 1 & -1 \\ 2 & 1 \end{pmatrix} + \begin{pmatrix} 0 & 1 \\ 0 & 1 \end{pmatrix}$ ([편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5)은 입력마다 같은 행으로 더한다)
4. 첫째 입력 (1, 0)의 첫째 출력: 1 × 1 + 0 × 2 = 1 + 0 = 1
5. 첫째 입력 (1, 0)의 둘째 출력: 1 × (−1) + 0 × 1 = −1 + 0 = −1
6. 둘째 입력 (2, 1)의 첫째 출력: 2 × 1 + 1 × 2 = 2 + 2 = 4
7. 둘째 입력 (2, 1)의 둘째 출력: 2 × (−1) + 1 × 1 = −2 + 1 = −1 이므로 $\mathbf{X}\mathbf{W}^\top = \begin{pmatrix} 1 & -1 \\ 4 & -1 \end{pmatrix}$
8. [편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5)을 칸끼리 더한다: 1 + 0 = 1, −1 + 1 = 0, 4 + 0 = 4, −1 + 1 = 0

**답**: $\mathbf{Z} = \begin{pmatrix} 1 & 0 \\ 4 & 0 \end{pmatrix}$ (첫째 행이 첫째 입력의 출력, 둘째 행이 둘째 입력의 출력)

</details>

### 문제 8

입력 행렬 $\mathbf{X}$가 32×10이고 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) $\mathbf{W}$가 (출력 6 × 입력 10)이다. $\mathbf{X}\mathbf{W}$와 $\mathbf{X}\mathbf{W}^\top$ 중 곱할 수 있는 것은 어느 쪽이고, 결과의 모양은 무엇인가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{X}$의 모양 = 32×10
- $\mathbf{W}$의 모양 = 6×10
- $\mathbf{W}^\top$의 모양 = 10×6 (전치하면 행과 열이 바뀐다)

**풀이**
1. 규칙을 쓴다: (a×b) 곱하기 (c×d)는 b = c일 때만 가능하고, 결과는 a×d이다.
2. $\mathbf{X}\mathbf{W}$에 대입한다: (32×10) 곱하기 (6×10)
3. 확인한다: 앞의 열 수 10과 뒤의 행 수 6이 다르므로 곱할 수 없다.
4. $\mathbf{X}\mathbf{W}^\top$에 대입한다: (32×10) 곱하기 (10×6)
5. 확인한다: 앞의 열 수 10과 뒤의 행 수 10이 같으므로 곱할 수 있다.
6. 결과 모양을 구한다: (앞의 행 수) × (뒤의 열 수) = 32×6

**답**: $\mathbf{X}\mathbf{W}^\top$만 가능하고 결과는 32×6 (입력마다 출력 6칸)

</details>

### 문제 9

[Lec01 5.5](../../Lec01_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%86%8C%EA%B0%9C.md#55-%EC%B8%B5-%EC%8C%93%EA%B8%B0)의 2층 망 $\mathbf{h} = g(\mathbf{W}_1\mathbf{x} + \mathbf{b}_1)$, $y = g(\mathbf{W}_2\mathbf{h} + b_2)$에서 $g$ = [ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8)(음수는 0, 0 이상은 그대로)이고 $\mathbf{x} = (1, 2, 0)$, $\mathbf{W}_1 = \begin{pmatrix} 1 & 0 & -1 \\ 2 & 1 & 0 \end{pmatrix}$, $\mathbf{b}_1 = (0, -3)$, $\mathbf{W}_2 = (2, -1)$, $b_2 = 0.5$이다. $\mathbf{h}$, $y$, [파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0) 수를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{x} = (1, 2, 0)$ (입력)
- $\mathbf{W}_1$의 두 행 $(1, 0, -1)$, $(2, 1, 0)$, $\mathbf{b}_1 = (0, -3)$ (첫째 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5))
- $\mathbf{W}_2 = (2, -1)$ (1행 2열), $b_2 = 0.5$ (둘째 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5))
- $g(z) = \max(0, z)$ ([ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8))

**풀이**
1. 식을 그대로 쓴다: $\mathbf{h} = g(\mathbf{W}_1\mathbf{x} + \mathbf{b}_1)$
2. 값을 대입한다: $\mathbf{h} = g\left(\begin{pmatrix} 1 & 0 & -1 \\ 2 & 1 & 0 \end{pmatrix} \begin{pmatrix} 1 \\ 2 \\ 0 \end{pmatrix} + \begin{pmatrix} 0 \\ -3 \end{pmatrix}\right)$
3. 첫째 행을 칸끼리 곱한다: 1 × 1 = 1, 0 × 2 = 0, (−1) × 0 = 0
4. 첫째 행을 더한다: 1 + 0 + 0 = 1
5. 둘째 행을 칸끼리 곱한다: 2 × 1 = 2, 1 × 2 = 2, 0 × 0 = 0
6. 둘째 행을 더한다: 2 + 2 + 0 = 4 이므로 $\mathbf{W}_1\mathbf{x} = (1, 4)$
7. [편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5)을 칸끼리 더한다: 1 + 0 = 1, 4 + (−3) = 1 이므로 $\mathbf{h} = g\big((1, 1)\big)$
8. [ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8)를 적용한다: max(0, 1) = 1 (두 칸 모두) 이므로 $\mathbf{h} = (1, 1)$
9. 둘째 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5) 식을 쓰고 대입한다: $y = g(\mathbf{W}_2\mathbf{h} + b_2) = g(2 \times 1 + (-1) \times 1 + 0.5)$
10. 곱셈을 한다: 2 × 1 = 2, (−1) × 1 = −1 이므로 $y = g(2 + (-1) + 0.5)$
11. 더한다: 2 + (−1) = 1, 1 + 0.5 = 1.5 이므로 $y = g(1.5)$
12. [ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8)를 적용한다: max(0, 1.5) = 1.5 이므로 $y = 1.5$
13. [파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0) 수를 센다: $\mathbf{W}_1$ 6개 + $\mathbf{b}_1$ 2개 + $\mathbf{W}_2$ 2개 + $b_2$ 1개 = 11

**답**: $\mathbf{h} = (1, 1)$, $y = 1.5$, [파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0) 11개

</details>

### 문제 10

[Lec08 4.1](../../Lec08_%ED%8A%B8%EB%9E%9C%EC%8A%A4%ED%8F%AC%EB%A8%B8.md#41-%ED%91%9C%EA%B8%B0-%ED%86%A0%ED%81%B0-%ED%96%89%EB%A0%AC-t)은 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 벡터를 전치해 행으로 쌓은 행렬 $T$를 쓰고, 4.2절은 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)의 선형 결합을 $T_{\text{out}} = W\, T_{\text{in}}$으로 쓴다. [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) $\mathbf{t}_1 = (1, 2)$, $\mathbf{t}_2 = (0, 1)$, $\mathbf{t}_3 = (2, -1)$로 만든 $T$의 모양을 말하고, $W = \begin{pmatrix} 1 & 1 & 0 \\ 0 & 1 & 1 \end{pmatrix}$일 때 $T_{\text{out}}$을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{t}_1 = (1, 2)$, $\mathbf{t}_2 = (0, 1)$, $\mathbf{t}_3 = (2, -1)$ ([토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 벡터, 칸 2개짜리 3개)
- $W$의 두 행 $(1, 1, 0)$, $(0, 1, 1)$ (새 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)마다 어떤 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)을 얼마씩 섞을지)

**풀이**
1. $T$를 만든다 (각 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)을 전치해 가로로 눕히고 위아래로 쌓는다): $T = \begin{pmatrix} 1 & 2 \\ 0 & 1 \\ 2 & -1 \end{pmatrix}$
2. 모양을 읽는다: 행 3개([토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 수 $N = 3$), 열 2개([토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 차원 $d = 2$) 이므로 3×2
3. 식을 그대로 쓴다: $T_{\text{out}} = W\, T_{\text{in}}$
4. 값을 대입한다: $T_{\text{out}} = \begin{pmatrix} 1 & 1 & 0 \\ 0 & 1 & 1 \end{pmatrix} \begin{pmatrix} 1 & 2 \\ 0 & 1 \\ 2 & -1 \end{pmatrix}$
5. 모양을 확인한다: (2×3) 곱하기 (3×2)에서 앞의 열 수 3과 뒤의 행 수 3이 같고 결과는 2×2
6. 행마다 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)을 섞는 꼴로 펼친다: 첫째 행 = 1 × (1, 2) + 1 × (0, 1) + 0 × (2, −1), 둘째 행 = 0 × (1, 2) + 1 × (0, 1) + 1 × (2, −1)
7. 첫째 행을 계산한다: (1, 2) + (0, 1) + (0, 0) = (1 + 0 + 0, 2 + 1 + 0) = (1, 3)
8. 둘째 행을 계산한다: (0, 0) + (0, 1) + (2, −1) = (0 + 0 + 2, 0 + 1 + (−1)) = (2, 0)

**답**: $T$는 3×2, $T_{\text{out}} = \begin{pmatrix} 1 & 3 \\ 2 & 0 \end{pmatrix}$ (첫째 새 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)은 $\mathbf{t}_1 + \mathbf{t}_2$, 둘째는 $\mathbf{t}_2 + \mathbf{t}_3$)

</details>
