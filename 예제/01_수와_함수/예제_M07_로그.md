### 문제 1
$\log_2 32$는? (2를 몇 번 곱해야 32가 되는지 센다)

<details><summary>풀이와 답</summary>

**주어진 값**
- 밑 $2$ (거듭 곱하는 수)
- $32$ (곱해서 나와야 하는 결과)
- $n$ (구할 값: 곱하는 횟수)

**풀이**
1. 식을 그대로 쓴다: $2^n = 32 \quad\Longleftrightarrow\quad \log_2 32 = n$
2. 2를 1번 곱한다: $2^1 = 2$
3. 한 번 더 곱한다: $2^2 = 2 \times 2 = 4$
4. 한 번 더 곱한다: $2^3 = 4 \times 2 = 8$
5. 한 번 더 곱한다: $2^4 = 8 \times 2 = 16$
6. 한 번 더 곱한다: $2^5 = 16 \times 2 = 32$ ← 32가 되었다
7. 곱한 횟수를 센다: 5번이므로 $n = 5$

**답**: $\log_2 32 = 5$ ($2^5 = 32$이기 때문)

</details>

### 문제 2
$\log_{10} 1000$과 $\log_{10} 0.01$을 구하라. 둘의 부호는 왜 다른가?

<details><summary>풀이와 답</summary>

**주어진 값**
- 밑 $10$
- $1000$, $0.01$ (결과 두 개)

**풀이**
1. 식을 그대로 쓴다: $10^n = x \quad\Longleftrightarrow\quad \log_{10} x = n$
2. 첫째. 값을 대입한다: $10^n = 1000$ 을 만족하는 $n$을 찾는다.
3. 10을 곱해 간다: $10^1 = 10$, $10^2 = 100$, $10^3 = 1000$ ← 3번 곱했으므로 $\log_{10} 1000 = 3$
4. 둘째. 값을 대입한다: $10^n = 0.01$ 을 만족하는 $n$을 찾는다.
5. 0.01은 1보다 작으므로 곱하는 횟수는 음수이다(음수 번 곱하기 = 나누기). $a^{-n} = \frac{1}{a^n}$ 을 쓴다: $10^{-2} = \frac{1}{10^2}$
6. 분모를 계산한다: $10^2 = 100$ 이므로 $10^{-2} = \frac{1}{100} = 0.01$
7. 그러므로 $\log_{10} 0.01 = -2$

**답**: $\log_{10} 1000 = 3$, $\log_{10} 0.01 = -2$. 1보다 큰 수의 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)는 양수, 1보다 작은 수의 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)는 음수이다.

</details>

### 문제 3
$\ln e$와 $\ln e^2$를 구하라. ($\ln$은 밑이 $e \approx 2.718$인 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8))

<details><summary>풀이와 답</summary>

**주어진 값**
- 밑 $e$ ($\ln$의 밑)
- 결과 $e$ (첫째), 결과 $e^2$ (둘째)

**풀이**
1. 식을 그대로 쓴다: $e^n = x \quad\Longleftrightarrow\quad \ln x = n$
2. 첫째. 값을 대입한다: $e^n = e$ 를 만족하는 $n$을 찾는다.
3. $e$를 1번 곱한 것이 $e$ 자신이다: $e^1 = e$ 이므로 $\ln e = 1$
4. 둘째. 값을 대입한다: $e^n = e^2$ 를 만족하는 $n$을 찾는다.
5. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 그대로 읽는다: $n = 2$ 일 때 $e^2 = e^2$ 이므로 $\ln e^2 = 2$

**답**: $\ln e = 1$, $\ln e^2 = 2$

</details>

### 문제 4
[정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)에 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) $p = 0.8$을 준 모델의 벌점 $-\ln p$를 구하라. ($\ln 0.8 = -0.2231$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $p = 0.8$ ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)에 모델이 준 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $\ln 0.8 = -0.2231$ (계산기나 `np.log(0.8)`로 구한 값. 0.8은 1보다 작아 음수이다)

**풀이**
1. 식을 그대로 쓴다: $\text{벌점} = -\ln p$
2. 값을 대입한다: $\text{벌점} = -\ln 0.8$
3. $\ln 0.8$의 값을 넣는다: $\text{벌점} = -(-0.2231)$
4. 마이너스 두 개는 플러스이다: $-(-0.2231) = 0.2231$

**답**: 벌점 = 0.2231 ([확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 높게 줄수록 벌점이 작다)

</details>

### 문제 5
[로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8) 규칙 $\log(a \times b) = \log a + \log b$를 밑 2, $a = 4$, $b = 16$으로 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $a = 4$, $b = 16$ (두 양수)
- 밑 $2$

**풀이**
1. 식을 그대로 쓴다: $\log(a \times b) = \log a + \log b$
2. 값을 대입한다: $\log_2(4 \times 16) = \log_2 4 + \log_2 16$
3. 왼쪽 괄호 안을 곱한다: $4 \times 16 = 64$ 이므로 $\log_2 64$
4. 왼쪽 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 구한다. 2를 계속 곱한다: $2, 4, 8, 16, 32, 64$ ← 6번 곱했으므로 $\log_2 64 = 6$
5. 오른쪽 첫 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 구한다: $2 \times 2 = 4$ 이므로 2번 곱했고 $\log_2 4 = 2$
6. 오른쪽 둘째 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 구한다: $2, 4, 8, 16$ ← 4번 곱했으므로 $\log_2 16 = 4$
7. 오른쪽 두 값을 더한다: $2 + 4 = 6$
8. 양쪽을 비교한다: 왼쪽 6, 오른쪽 6으로 같다.

**답**: $\log_2(4 \times 16) = \log_2 4 + \log_2 16 = 6$

</details>

### 문제 6
[확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 0.1인 일이 연달아 두 번 일어날 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은 $0.1 \times 0.1 = 0.01$이다. 곱의 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8) 규칙으로 $\ln 0.01$을 구하라. ($\ln 0.1 = -2.3026$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $a = 0.1$, $b = 0.1$ (두 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $\ln 0.1 = -2.3026$ (계산기나 `np.log(0.1)`로 구한 값)

**풀이**
1. 식을 그대로 쓴다: $\ln(a \times b) = \ln a + \ln b$
2. 값을 대입한다: $\ln(0.1 \times 0.1) = \ln 0.1 + \ln 0.1$
3. 왼쪽 괄호 안을 곱한다: $0.1 \times 0.1 = 0.01$ 이므로 $\ln 0.01$
4. 오른쪽에 $\ln 0.1$의 값을 넣는다: $\ln 0.1 + \ln 0.1 = -2.3026 + (-2.3026)$
5. 덧셈을 한다: $-2.3026 + (-2.3026) = -4.6052$

**답**: $\ln 0.01 = -4.6052$ (곱하기가 더하기로 바뀌어, 작은 수를 여러 번 곱해도 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)는 다루기 쉬운 크기로 남는다)

</details>

### 문제 7
모델이 샘플 3개의 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)에 준 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 $p = 0.9,\ 0.5,\ 0.1$이다. 샘플별 벌점 $-\ln p$를 구하고 평균([교차 엔트로피](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cross-entropy-%EA%B5%90%EC%B0%A8-%EC%97%94%ED%8A%B8%EB%A1%9C%ED%94%BC))을 구하라. ($\ln 0.9 = -0.105$, $\ln 0.5 = -0.693$, $\ln 0.1 = -2.303$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $p_1 = 0.9$, $p_2 = 0.5$, $p_3 = 0.1$ ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)에 준 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $\ln 0.9 = -0.105$, $\ln 0.5 = -0.693$, $\ln 0.1 = -2.303$ (1보다 작은 수의 ln은 음수)
- $m = 3$ (샘플 개수)

**풀이**
1. 벌점 식을 그대로 쓴다: $\text{벌점}_i = -\ln p_i$
2. 값을 대입한다: $-\ln 0.9,\ -\ln 0.5,\ -\ln 0.1$
3. $\ln$ 값을 넣는다: $-(-0.105),\ -(-0.693),\ -(-2.303)$
4. 마이너스 두 개는 플러스이다: 벌점은 $0.105,\ 0.693,\ 2.303$
5. 평균 식을 그대로 쓴다: $\text{평균} = \frac{1}{m}\sum_{i=1}^{m} \text{벌점}_i$
6. 값을 대입한다(Σ는 i = 1, 2, 3 항을 펼친다): $\text{평균} = \frac{1}{3}(0.105 + 0.693 + 2.303)$
7. 괄호 안을 더한다: $0.105 + 0.693 = 0.798$, $0.798 + 2.303 = 3.101$ 이므로 $\frac{1}{3} \times 3.101$
8. 3으로 나눈다: $3.101 \div 3 = 1.034$

**답**: 벌점은 0.105, 0.693, 2.303이고 평균은 약 1.034. [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 낮게 준 세 번째 샘플이 평균을 크게 끌어올린다.

</details>

### 문제 8
데이터 1024개가 정렬되어 있을 때 이진 탐색은 "범위를 반으로 줄이기"를 되풀이해 한 개만 남긴다. 몇 번 반으로 줄이면 되는가? 데이터가 2048개로 2배 늘면 몇 번이 되는가? ($\log_2 x$는 x를 1이 될 때까지 반으로 나누는 횟수)

<details><summary>풀이와 답</summary>

**주어진 값**
- $x = 1024$ (데이터 개수), 늘린 뒤 $x = 2048$
- 밑 $2$ (반으로 나누므로)

**풀이**
1. 식을 그대로 쓴다: $2^n = x \quad\Longleftrightarrow\quad \log_2 x = n$
2. 값을 대입한다: $2^n = 1024$ 를 만족하는 $n$을 찾는다.
3. 2의 거듭제곱을 차례로 적는다: $2^1 = 2$, $2^2 = 4$, $2^3 = 8$, $2^4 = 16$, $2^5 = 32$
4. 이어서 적는다: $2^6 = 64$, $2^7 = 128$, $2^8 = 256$, $2^9 = 512$, $2^{10} = 1024$ ← 10번 곱했으므로 $\log_2 1024 = 10$
5. 2048개일 때 값을 대입한다: $2^n = 2048$
6. 앞의 값에서 한 번 더 곱한다: $2^{11} = 2^{10} \times 2 = 1024 \times 2 = 2048$ 이므로 $\log_2 2048 = 11$

**답**: 1024개이면 10번, 2048개이면 11번. 데이터가 2배가 되어도 횟수는 1번만 는다.

</details>

### 문제 9
[Lec09 14.2](../../Lec09_%ED%95%B4%EC%BB%A4%EC%9D%98_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EA%B0%80%EC%9D%B4%EB%93%9C.md#142-%EB%A1%9C%EA%B7%B8-%EC%86%90%EC%8B%A4-%EC%88%AB%EC%9E%90-%EC%99%B8%EC%9A%B0%EA%B8%B0)에서 K개 클래스를 찍어서 맞힐 때의 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은 $-\ln \frac{1}{K} = \ln K$이다. $K = 10$일 때 찍기 수준 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 구하고, 훈련 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 2.30 근처에서 내려가지 않는 10개 클래스 모델에 대해 판단하라. ($\ln 10 = 2.3026$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $K = 10$ (클래스 수)
- $\ln 10 = 2.3026$ (계산기나 `np.log(10)`으로 구한 값)
- 모델의 훈련 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $\approx 2.30$

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_{\text{chance}} = -\ln \frac{1}{K}$
2. 값을 대입한다: $\mathcal{L}_{\text{chance}} = -\ln \frac{1}{10}$
3. 분수를 소수로 바꾼다: $\frac{1}{10} = 0.1$ 이므로 $-\ln 0.1$
4. $\ln 0.1$의 값을 넣는다: $\ln 0.1 = -2.3026$ 이므로 $-(-2.3026)$
5. 마이너스 두 개는 플러스이다: $-(-2.3026) = 2.3026$
6. 모델의 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)과 비교한다: 2.30은 2.3026과 거의 같다.

**답**: 찍기 수준 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은 2.3026. [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 2.30에서 내려가지 않는 모델은 아무것도 배우지 못한 것이다 (10개 중 하나를 무작위로 찍는 수준)

</details>

### 문제 10
[Lec10 8.2](../../Lec10_%EA%B8%B0%EC%96%B5%EA%B3%BC_%EC%8B%9C%ED%80%80%EC%8A%A4.md#82-%EB%B9%94-%EC%84%9C%EC%B9%98)의 [빔 서치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#beam-search-%EB%B9%94-%EC%84%9C%EC%B9%98)는 문장 점수를 $\text{score} = \sum_{t=1}^{T} \ln p(y_t \mid y_{<t})$로 매긴다. 문장 A는 단어 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 $(0.5,\ 0.4)$, 문장 B는 $(0.3,\ 0.8)$이다. 두 점수를 구해 어느 쪽이 높은지 비교하라. ($\ln 0.5 = -0.6931$, $\ln 0.4 = -0.9163$, $\ln 0.3 = -1.2040$, $\ln 0.8 = -0.2231$)

<details><summary>풀이와 답</summary>

**주어진 값**
- 문장 A: $p(y_1) = 0.5$, $p(y_2) = 0.4$
- 문장 B: $p(y_1) = 0.3$, $p(y_2) = 0.8$
- $T = 2$ (단어 수)
- 위에 적은 $\ln$ 값들

**풀이**
1. 식을 그대로 쓴다: $\text{score} = \sum_{t=1}^{T} \ln p(y_t \mid y_{<t})$
2. 문장 A의 값을 대입한다(Σ는 t = 1, 2 항을 펼친다): $\text{score}_A = \ln 0.5 + \ln 0.4$
3. $\ln$ 값을 넣는다: $\text{score}_A = -0.6931 + (-0.9163)$
4. 덧셈을 한다: $-0.6931 + (-0.9163) = -1.6094$
5. 문장 B의 값을 대입한다: $\text{score}_B = \ln 0.3 + \ln 0.8$
6. $\ln$ 값을 넣는다: $\text{score}_B = -1.2040 + (-0.2231)$
7. 덧셈을 한다: $-1.2040 + (-0.2231) = -1.4271$
8. 비교한다: $-1.4271$은 $-1.6094$보다 크다(0에 더 가깝다).
9. 확인한다. 곱의 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8) 규칙에 따라 점수는 문장 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)의 ln과 같다: A는 $0.5 \times 0.4 = 0.2$, B는 $0.3 \times 0.8 = 0.24$ 이고 0.24가 더 크다.

**답**: $\text{score}_A = -1.6094$, $\text{score}_B = -1.4271$. 문장 B가 더 높다. 첫 단어만 보면 A(0.5)가 앞서지만 전체 점수는 B가 높다. 그래서 [빔 서치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#beam-search-%EB%B9%94-%EC%84%9C%EC%B9%98)는 경로 전체의 점수를 본다.

</details>
