# 예제: 분산과 표준편차와 공분산

개념 노트: [MM85_분산과_표준편차와_공분산](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/01_%EC%88%98%EC%99%80_%ED%95%A8%EC%88%98/MM85_%EB%B6%84%EC%82%B0%EA%B3%BC_%ED%91%9C%EC%A4%80%ED%8E%B8%EC%B0%A8%EC%99%80_%EA%B3%B5%EB%B6%84%EC%82%B0.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 문제 번호 순서는 쉬운 것에서 어려운 것, 마지막 둘은 강의 내용과 잇는 문제다. 따로 말이 없으면 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)은 개수 $N$으로 나눈다.

## 기본 (직접 대입)

### 문제 1
네 값 $x = (1, 3, 5, 7)$의 평균, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0), 표준편차를 구하라. ($\sqrt{5} = 2.2361$)

<details><summary>풀이와 답</summary>

**주어진 값**:
- $x_1 = 1,\ x_2 = 3,\ x_3 = 5,\ x_4 = 7$ (값 네 개)
- $N = 4$ (값의 개수)

**풀이**
1. 식을 그대로 쓴다: $\mu = \frac{1}{N}\sum x_i$, $\sigma^2 = \frac{1}{N}\sum (x_i - \mu)^2$, $\sigma = \sqrt{\sigma^2}$
2. 값을 대입한다: $\mu = \frac{1}{4}(1 + 3 + 5 + 7)$
3. 더한다: 1 + 3 + 5 + 7 = 16 이므로 $\mu = \frac{1}{4} \times 16$
4. 나눈다: 16 ÷ 4 = 4 이므로 $\mu = 4$
5. [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) 식에 평균을 넣는다: $\sigma^2 = \frac{1}{4}\big((1-4)^2 + (3-4)^2 + (5-4)^2 + (7-4)^2\big)$
6. 편차를 계산한다: 1 − 4 = −3, 3 − 4 = −1, 5 − 4 = 1, 7 − 4 = 3 이므로 $\sigma^2 = \frac{1}{4}\big((-3)^2 + (-1)^2 + 1^2 + 3^2\big)$
7. 제곱한다: 9, 1, 1, 9 이므로 $\sigma^2 = \frac{1}{4}(9 + 1 + 1 + 9)$
8. 더한다: 9 + 1 + 1 + 9 = 20 이므로 $\sigma^2 = \frac{1}{4} \times 20$
9. 나눈다: 20 ÷ 4 = 5 이므로 $\sigma^2 = 5$
10. 제곱근을 구한다: $\sigma = \sqrt{5} = 2.2361$

**답**: 평균 4, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) 5, 표준편차 2.2361

</details>

### 문제 2
$x = (2, 4, 6, 8)$의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 N으로 나눌 때와 N−1로 나눌 때 각각 구하라. (평균 5, 편차 제곱의 합 20은 이미 구했다.)

<details><summary>풀이와 답</summary>

**주어진 값**:
- $N = 4$ (값의 개수)
- $\sum (x_i - \mu)^2 = 20$ (편차 제곱의 합: 9 + 1 + 1 + 9)

**풀이**
1. 식을 그대로 쓴다: $\sigma^2_{N} = \frac{1}{N}\sum (x_i - \mu)^2$, $\sigma^2_{N-1} = \frac{1}{N-1}\sum (x_i - \mu)^2$
2. 값을 대입한다: $\sigma^2_{N} = \frac{20}{4}$, $\sigma^2_{N-1} = \frac{20}{4 - 1}$
3. N으로 나눈다: 20 ÷ 4 = 5
4. 분모를 계산한다: 4 − 1 = 3 이므로 $\sigma^2_{N-1} = \frac{20}{3}$
5. N−1로 나눈다: 20 ÷ 3 = 6.6667

**답**: N으로 나누면 5, N−1로 나누면 6.6667 (`np.var`는 5, `torch.var`는 기본이 6.6667)

</details>

### 문제 3
세 점 $(x, y) = (1, 2),\ (2, 4),\ (3, 6)$의 공분산 $\mathrm{Cov}[x, y]$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**:
- $(x_i, y_i) = (1, 2),\ (2, 4),\ (3, 6)$ (점 세 개)
- $N = 3$ (점의 개수)

**풀이**
1. 식을 그대로 쓴다: $\mathrm{Cov}[x, y] = \frac{1}{N}\sum (x_i - \mu_x)(y_i - \mu_y)$
2. 평균을 구한다: $\mu_x = (1 + 2 + 3) / 3 = 6 / 3 = 2$, $\mu_y = (2 + 4 + 6) / 3 = 12 / 3 = 4$
3. 값을 대입한다: $\mathrm{Cov} = \frac{1}{3}\big((1-2)(2-4) + (2-2)(4-4) + (3-2)(6-4)\big)$
4. 편차를 계산한다: $\mathrm{Cov} = \frac{1}{3}\big((-1)(-2) + 0 \times 0 + 1 \times 2\big)$
5. 곱한다: (−1)(−2) = 2, 0 × 0 = 0, 1 × 2 = 2 이므로 $\mathrm{Cov} = \frac{1}{3}(2 + 0 + 2)$
6. 더한다: 2 + 0 + 2 = 4 이므로 $\mathrm{Cov} = \frac{4}{3}$
7. 나눈다: 4 ÷ 3 = 1.3333

**답**: $\mathrm{Cov}[x, y] = 1.3333$ (양수: $x$가 커지면 $y$도 커진다)

</details>

### 문제 4
문제 3의 세 점에서 상관계수 $\rho$를 구하라. (공분산은 4/3 = 1.3333)

<details><summary>풀이와 답</summary>

**주어진 값**:
- $\mathrm{Cov}[x, y] = 1.3333$ (문제 3의 결과)
- $x$의 편차 $(-1, 0, 1)$, $y$의 편차 $(-2, 0, 2)$ (문제 3의 평균 2, 4에서 나온 값)

**풀이**
1. 식을 그대로 쓴다: $\rho = \frac{\mathrm{Cov}[x, y]}{\sigma_x\,\sigma_y}$, $\sigma^2 = \frac{1}{N}\sum (x_i - \mu)^2$
2. $x$의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 대입한다: $\sigma_x^2 = \frac{1}{3}\big((-1)^2 + 0^2 + 1^2\big)$
3. 계산한다: 1 + 0 + 1 = 2 이므로 $\sigma_x^2 = \frac{2}{3} = 0.6667$
4. $y$의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 대입한다: $\sigma_y^2 = \frac{1}{3}\big((-2)^2 + 0^2 + 2^2\big)$
5. 계산한다: 4 + 0 + 4 = 8 이므로 $\sigma_y^2 = \frac{8}{3} = 2.6667$
6. 제곱근을 구한다: $\sigma_x = \sqrt{0.6667} = 0.8165$, $\sigma_y = \sqrt{2.6667} = 1.6330$
7. 값을 대입한다: $\rho = \frac{1.3333}{0.8165 \times 1.6330}$
8. 분모를 곱한다: 0.8165 × 1.6330 = 1.3333 이므로 $\rho = \frac{1.3333}{1.3333}$
9. 나눈다: 1.3333 ÷ 1.3333 = 1

**답**: $\rho = 1$ (세 점이 올라가는 직선 $y = 2x$ 위에 있다. 공분산은 단위에 따라 커졌다 작아지지만 상관계수는 늘 −1 ~ 1이다)

</details>

### 문제 5
점수 $(2, 4, 4, 4, 5, 5, 7, 9)$의 평균은 5, 표준편차는 2이다. 점수 9와 점수 2의 [표준화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#standardization-%ED%91%9C%EC%A4%80%ED%99%94) 값 $z$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**:
- $\mu = 5$ (평균)
- $\sigma = 2$ (표준편차)
- $x = 9$, $x = 2$ (표준화할 점수)

**풀이**
1. 식을 그대로 쓴다: $z = \frac{x - \mu}{\sigma}$
2. 값을 대입한다: $z_{9} = \frac{9 - 5}{2}$, $z_{2} = \frac{2 - 5}{2}$
3. 분자를 계산한다: 9 − 5 = 4, 2 − 5 = −3 이므로 $z_{9} = \frac{4}{2}$, $z_{2} = \frac{-3}{2}$
4. 나눈다: 4 ÷ 2 = 2, −3 ÷ 2 = −1.5

**답**: 9는 $z = 2$ (평균보다 표준편차 2개 위), 2는 $z = -1.5$ (표준편차 1.5개 아래)

</details>

### 문제 6
$x = (1, 2, 3, 4)$에서 $\mathrm{Var}[x] = E[x^2] - \mu^2$로 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**:
- $x = (1, 2, 3, 4)$ (값 네 개)
- $N = 4$, $\mu = (1 + 2 + 3 + 4) / 4 = 10 / 4 = 2.5$ (개수와 평균)

**풀이**
1. 식을 그대로 쓴다: $\mathrm{Var}[x] = E[x^2] - \mu^2$
2. 값을 대입한다: $\mathrm{Var}[x] = \frac{1^2 + 2^2 + 3^2 + 4^2}{4} - 2.5^2$
3. 제곱한다: 1² = 1, 2² = 4, 3² = 9, 4² = 16, 2.5² = 6.25 이므로 $\mathrm{Var}[x] = \frac{1 + 4 + 9 + 16}{4} - 6.25$
4. 더한다: 1 + 4 + 9 + 16 = 30 이므로 $\mathrm{Var}[x] = \frac{30}{4} - 6.25$
5. 나눈다: 30 ÷ 4 = 7.5 이므로 $\mathrm{Var}[x] = 7.5 - 6.25$
6. 뺀다: 7.5 − 6.25 = 1.25
7. 정의 식으로 확인한다: $\frac{(-1.5)^2 + (-0.5)^2 + 0.5^2 + 1.5^2}{4} = \frac{2.25 + 0.25 + 0.25 + 2.25}{4} = \frac{5}{4} = 1.25$

**답**: $\mathrm{Var}[x] = 1.25$ (두 방법이 같다)

</details>

### 문제 7
키 $(150, 160, 170, 180)$ cm의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)은 125, 표준편차는 11.1803이다. 같은 키를 m로 재면 $(1.5, 1.6, 1.7, 1.8)$이다. m 단위의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)과 표준편차를 구하고 cm의 값과 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**:
- $x = (1.5, 1.6, 1.7, 1.8)$ m (값 네 개)
- $N = 4$ (개수)
- cm의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) 125, 표준편차 11.1803 (비교할 값)

**풀이**
1. 식을 그대로 쓴다: $\mu = \frac{1}{N}\sum x_i$, $\sigma^2 = \frac{1}{N}\sum (x_i - \mu)^2$
2. 평균을 구한다: $\mu = \frac{1.5 + 1.6 + 1.7 + 1.8}{4} = \frac{6.6}{4} = 1.65$
3. [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) 식에 대입한다: $\sigma^2 = \frac{1}{4}\big((1.5 - 1.65)^2 + (1.6 - 1.65)^2 + (1.7 - 1.65)^2 + (1.8 - 1.65)^2\big)$
4. 편차를 계산한다: −0.15, −0.05, 0.05, 0.15 이므로 $\sigma^2 = \frac{1}{4}\big((-0.15)^2 + (-0.05)^2 + 0.05^2 + 0.15^2\big)$
5. 제곱한다: 0.0225, 0.0025, 0.0025, 0.0225 이므로 $\sigma^2 = \frac{1}{4}(0.0225 + 0.0025 + 0.0025 + 0.0225)$
6. 더한다: 0.0225 + 0.0025 + 0.0025 + 0.0225 = 0.05 이므로 $\sigma^2 = \frac{0.05}{4}$
7. 나눈다: 0.05 ÷ 4 = 0.0125
8. 표준편차를 구한다: $\sigma = \sqrt{0.0125} = 0.1118$
9. cm와 비교한다: 125 ÷ 0.0125 = 10000, 11.1803 ÷ 0.1118 = 100

**답**: [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) 0.0125, 표준편차 0.1118. 단위를 cm에서 m로 바꾸면(값이 1/100배) 표준편차는 1/100배, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)은 1/10000배다. [표준화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#standardization-%ED%91%9C%EC%A4%80%ED%99%94) $z$는 단위에 상관없이 같다

</details>

### 문제 8
점 $(3, 0),\ (-3, 0),\ (0, 1),\ (0, -1)$의 [공분산 행렬](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#covariance-matrix-%EA%B3%B5%EB%B6%84%EC%82%B0-%ED%96%89%EB%A0%AC) $\Sigma$를 구하라. (두 축의 평균은 모두 0이다.)

<details><summary>풀이와 답</summary>

**주어진 값**:
- $(x_i, y_i) = (3, 0),\ (-3, 0),\ (0, 1),\ (0, -1)$ (점 네 개)
- $N = 4$, $\mu_x = \mu_y = 0$ (개수와 평균)

**풀이**
1. 식을 그대로 쓴다: $\Sigma = \begin{pmatrix} \mathrm{Var}[x] & \mathrm{Cov}[x, y] \\ \mathrm{Cov}[y, x] & \mathrm{Var}[y] \end{pmatrix}$
2. $x$의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 대입한다 (평균이 0이라 값 그대로): $\mathrm{Var}[x] = \frac{3^2 + (-3)^2 + 0^2 + 0^2}{4}$
3. 계산한다: 9 + 9 + 0 + 0 = 18 이므로 $\mathrm{Var}[x] = \frac{18}{4} = 4.5$
4. $y$의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 대입한다: $\mathrm{Var}[y] = \frac{0^2 + 0^2 + 1^2 + (-1)^2}{4}$
5. 계산한다: 0 + 0 + 1 + 1 = 2 이므로 $\mathrm{Var}[y] = \frac{2}{4} = 0.5$
6. 공분산을 대입한다: $\mathrm{Cov}[x, y] = \frac{3 \times 0 + (-3) \times 0 + 0 \times 1 + 0 \times (-1)}{4}$
7. 계산한다: 0 + 0 + 0 + 0 = 0 이므로 $\mathrm{Cov}[x, y] = 0$
8. 행렬에 넣는다: $\Sigma = \begin{pmatrix} 4.5 & 0 \\ 0 & 0.5 \end{pmatrix}$

**답**: $\Sigma = \begin{pmatrix} 4.5 & 0 \\ 0 & 0.5 \end{pmatrix}$ (가로로 길게 퍼지고(4.5) 세로로 좁다(0.5). 공분산 0은 한 쪽이 커져도 다른 쪽이 기울지 않는다는 뜻)

</details>

### 문제 9
[MM43_마할라노비스_거리](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/03_%EC%84%A0%ED%98%95%EB%8C%80%EC%88%98/MM43_%EB%A7%88%ED%95%A0%EB%9D%BC%EB%85%B8%EB%B9%84%EC%8A%A4_%EA%B1%B0%EB%A6%AC.md)에서는 거리를 $d^2 = \mathbf{x}^\top\Sigma^{-1}\mathbf{x}$로 잰다. $\Sigma$가 대각선 행렬이면 $\Sigma^{-1}$은 대각선 칸을 역수($1/\text{분산}$)로 바꾼 것이라 $d^2 = \frac{x^2}{\sigma_x^2} + \frac{y^2}{\sigma_y^2}$이다. 문제 8의 $\Sigma$에서 점 $(3, 0)$과 $(0, 1)$의 보통 거리(원점에서)와 [마할라노비스 거리](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#mahalanobis-distance-%EB%A7%88%ED%95%A0%EB%9D%BC%EB%85%B8%EB%B9%84%EC%8A%A4-%EA%B1%B0%EB%A6%AC)를 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**:
- $\sigma_x^2 = 4.5,\ \sigma_y^2 = 0.5$ (문제 8의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0))
- 점 A $= (3, 0)$, 점 B $= (0, 1)$ (원점에서 잴 점)
- $\sqrt{2} = 1.4142$ (제곱근 값)

**풀이**
1. 식을 그대로 쓴다: $d^2 = \frac{x^2}{\sigma_x^2} + \frac{y^2}{\sigma_y^2}$
2. A의 보통 거리를 구한다: 원점에서 (3, 0)까지는 3
3. B의 보통 거리를 구한다: 원점에서 (0, 1)까지는 1
4. A를 대입한다: $d_A^2 = \frac{3^2}{4.5} + \frac{0^2}{0.5}$
5. 제곱한다: 3² = 9, 0² = 0 이므로 $d_A^2 = \frac{9}{4.5} + \frac{0}{0.5}$
6. 나눈다: 9 ÷ 4.5 = 2, 0 ÷ 0.5 = 0 이므로 $d_A^2 = 2 + 0 = 2$
7. B를 대입한다: $d_B^2 = \frac{0^2}{4.5} + \frac{1^2}{0.5}$
8. 나눈다: 0 ÷ 4.5 = 0, 1 ÷ 0.5 = 2 이므로 $d_B^2 = 0 + 2 = 2$
9. 제곱근을 구한다: $d_A = d_B = \sqrt{2} = 1.4142$

**답**: 보통 거리는 A 3, B 1로 3배 차이지만 [마할라노비스 거리](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#mahalanobis-distance-%EB%A7%88%ED%95%A0%EB%9D%BC%EB%85%B8%EB%B9%84%EC%8A%A4-%EA%B1%B0%EB%A6%AC)는 둘 다 1.4142로 같다. 많이 퍼진 축([분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) 4.5)에서의 3칸은 덜 먼 것으로 치기 때문이다

</details>

### 문제 10
[MM40_PCA와_선형_오토인코더](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/10_%ED%91%9C%ED%98%84_%ED%95%99%EC%8A%B5/MM40_PCA%EC%99%80_%EC%84%A0%ED%98%95_%EC%98%A4%ED%86%A0%EC%9D%B8%EC%BD%94%EB%8D%94.md)에서는 점을 방향 $\mathbf{w}$로 투영한 값의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)이 가장 큰 방향을 찾는다. 점 $(2, 2),\ (-2, -2),\ (1, -1),\ (-1, 1)$을 $\mathbf{w}_1 = (1, 1)/\sqrt{2}$와 $\mathbf{w}_2 = (1, -1)/\sqrt{2}$에 투영한 값의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 각각 구하라. (투영값 $= \mathbf{w}\cdot\mathbf{x}$, $\sqrt{2} = 1.4142$)

<details><summary>풀이와 답</summary>

**주어진 값**:
- 점 네 개: $(2, 2),\ (-2, -2),\ (1, -1),\ (-1, 1)$
- $\mathbf{w}_1 = (1, 1)/1.4142$, $\mathbf{w}_2 = (1, -1)/1.4142$ ([투영](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#projection-%ED%88%AC%EC%98%81) 방향)
- 투영값의 평균은 모두 0 (점들이 원점 대칭이라)

**풀이**
1. 식을 그대로 쓴다: 투영값 $= \frac{x + y}{\sqrt{2}}$ ($\mathbf{w}_1$), $\frac{x - y}{\sqrt{2}}$ ($\mathbf{w}_2$), [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $= \frac{1}{N}\sum (\text{투영값})^2$
2. $\mathbf{w}_1$로 투영한다: $\frac{2 + 2}{1.4142},\ \frac{-2 - 2}{1.4142},\ \frac{1 - 1}{1.4142},\ \frac{-1 + 1}{1.4142}$
3. 계산한다: 4 ÷ 1.4142 = 2.8284 이므로 투영값은 2.8284, −2.8284, 0, 0
4. [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 구한다: $\frac{2.8284^2 + (-2.8284)^2 + 0^2 + 0^2}{4}$
5. 제곱한다: 2.8284² = 8 이므로 $\frac{8 + 8 + 0 + 0}{4}$
6. 더하고 나눈다: 16 ÷ 4 = 4
7. $\mathbf{w}_2$로 투영한다: $\frac{2 - 2}{1.4142},\ \frac{-2 + 2}{1.4142},\ \frac{1 + 1}{1.4142},\ \frac{-1 - 1}{1.4142}$
8. 계산한다: 2 ÷ 1.4142 = 1.4142 이므로 투영값은 0, 0, 1.4142, −1.4142
9. [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 구한다: $\frac{0 + 0 + 1.4142^2 + (-1.4142)^2}{4} = \frac{2 + 2}{4}$
10. 나눈다: 4 ÷ 4 = 1

**답**: $\mathbf{w}_1$ 방향 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) 4, $\mathbf{w}_2$ 방향 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) 1. 합은 5로 두 축의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) 합 2.5 + 2.5와 같고, 4가 [공분산 행렬](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#covariance-matrix-%EA%B3%B5%EB%B6%84%EC%82%B0-%ED%96%89%EB%A0%AC) $\begin{pmatrix}2.5&1.5\\1.5&2.5\end{pmatrix}$의 큰 [고윳값](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#eigenvector-eigenvalue-%EA%B3%A0%EC%9C%A0%EB%B2%A1%ED%84%B0%EC%99%80-%EA%B3%A0%EC%9C%B3%EA%B0%92)이다. 가장 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)이 큰 방향 (1, 1)이 주성분이다
