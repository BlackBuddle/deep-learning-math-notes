## 기본 (직접 대입)

### 문제 1
일차함수 $y = wx + b$에서 $w = 4$, $b = 3$일 때 $x = 2$를 넣으면 y는?

<details><summary>풀이와 답</summary>

**주어진 값**
- $w = 4$ ([기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0), x에 곱하는 수)
- $b = 3$ (y절편, 더하는 수)
- $x = 2$ (넣는 값)

**풀이**
1. 식을 그대로 쓴다: $y = wx + b$
2. 값을 대입한다: $y = 4 \times 2 + 3$
3. 곱셈을 먼저 한다: $4 \times 2 = 8$ 이므로 $y = 8 + 3$
4. 덧셈을 한다: $8 + 3 = 11$ 이므로 $y = 11$

**답**: $y = 11$

</details>

### 문제 2
함수 $f(x) = -x + 5$에서 $f(3)$의 값은? ($f(3)$은 "f에 3을 넣으면 나오는 값"이다)

<details><summary>풀이와 답</summary>

**주어진 값**
- $f(x) = -x + 5$ (규칙: x에 −1을 곱하고 5를 더한다. 곧 $w = -1$, $b = 5$)
- $x = 3$ (넣는 값)

**풀이**
1. 식을 그대로 쓴다: $f(x) = -x + 5$
2. 값을 대입한다(x 자리에 3을 넣는다): $f(3) = -3 + 5$
3. 덧셈을 한다: $-3 + 5 = 2$ 이므로 $f(3) = 2$

**답**: $f(3) = 2$

</details>

### 문제 3
$y = 0.5x + 1$에 $x = 6$을 넣으면 y는?

<details><summary>풀이와 답</summary>

**주어진 값**
- $w = 0.5$ ([기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0))
- $b = 1$ (y절편)
- $x = 6$ (넣는 값)

**풀이**
1. 식을 그대로 쓴다: $y = wx + b$
2. 값을 대입한다: $y = 0.5 \times 6 + 1$
3. 곱셈을 먼저 한다: $0.5 \times 6 = 3$ 이므로 $y = 3 + 1$
4. 덧셈을 한다: $3 + 1 = 4$ 이므로 $y = 4$

**답**: $y = 4$

</details>

### 문제 4
직선 $y = -3x + 6$의 $w$와 $b$를 읽고, $x = 2$를 넣었을 때 y를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $y = -3x + 6$ (읽어야 할 식)
- $x = 2$ (넣는 값)

**풀이**
1. 식을 그대로 쓴다: $y = wx + b$
2. 문제의 식과 나란히 놓고 읽는다: $y = -3x + 6$ 이므로 $x$ 앞의 수가 $w = -3$, 뒤에 더한 수가 $b = 6$
3. 값을 대입한다: $y = (-3) \times 2 + 6$
4. 곱셈을 먼저 한다: $(-3) \times 2 = -6$ 이므로 $y = -6 + 6$
5. 덧셈을 한다: $-6 + 6 = 0$ 이므로 $y = 0$

**답**: $w = -3$, $b = 6$, $y = 0$

</details>

## 응용

### 문제 5
직선이 점 $(0, 1)$과 점 $(2, 5)$를 지난다. 이 직선 $y = wx + b$의 $w$와 $b$를 구하고, $x = 4$일 때 y를 예측하라.
(점 $(2, 5)$는 "2를 넣으면 5가 나온다"는 뜻이다)

<details><summary>풀이와 답</summary>

**주어진 값**
- 점 $(0, 1)$: $x = 0$일 때 $y = 1$
- 점 $(2, 5)$: $x = 2$일 때 $y = 5$
- 예측할 입력 $x = 4$

**풀이**
1. $b$부터 구한다. 식을 그대로 쓴다: $y = wx + b$
2. 첫째 점의 값을 대입한다: $1 = w \times 0 + b$
3. 곱셈을 한다: $w \times 0 = 0$ 이므로 $1 = 0 + b$, 곧 $b = 1$ ($x = 0$일 때의 y가 y절편이다)
4. $w$를 구한다. 둘째 점과 구한 $b$를 대입한다: $5 = w \times 2 + 1$
5. 양쪽에서 1을 뺀다: $5 - 1 = 4$ 이므로 $4 = 2w$
6. 양쪽을 2로 나눈다: $4 \div 2 = 2$ 이므로 $w = 2$
7. 구한 식으로 예측한다. 값을 대입한다: $y = 2 \times 4 + 1$
8. 곱셈을 먼저 한다: $2 \times 4 = 8$ 이므로 $y = 8 + 1$
9. 덧셈을 한다: $8 + 1 = 9$

**답**: $w = 2$, $b = 1$ (곧 $y = 2x + 1$), $x = 4$일 때 $y = 9$

</details>

### 문제 6
$y = 3x + 2$에서 x가 1일 때와 4일 때의 y를 구하고, x가 3 늘면 y가 얼마나 느는지 $w$와 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $w = 3$ ([기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0))
- $b = 2$ (y절편)
- $x = 1$과 $x = 4$ (넣는 값 두 개)

**풀이**
1. 식을 그대로 쓴다: $y = wx + b$
2. $x = 1$을 대입한다: $y = 3 \times 1 + 2$
3. 곱셈을 한 뒤 더한다: $3 \times 1 = 3$ 이므로 $y = 3 + 2 = 5$
4. $x = 4$를 대입한다: $y = 3 \times 4 + 2$
5. 곱셈을 한 뒤 더한다: $3 \times 4 = 12$ 이므로 $y = 12 + 2 = 14$
6. y가 늘어난 양을 구한다: $14 - 5 = 9$
7. x가 늘어난 양을 구한다: $4 - 1 = 3$
8. 늘어난 y를 늘어난 x로 나눈다: $9 \div 3 = 3$, 이것이 $w$와 같다

**답**: $x = 1$일 때 5, $x = 4$일 때 14. x가 3 늘면 y는 9 늘고, 9 ÷ 3 = 3 = $w$ (x가 1 늘 때마다 y는 $w$씩 는다)

</details>

### 문제 7
$y = 2x + 1$에서 y절편 $b$만 1에서 5로 바꾸면, $x = 3$에서의 y는 얼마에서 얼마로 바뀌는가? 직선 전체는 어떻게 움직이는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $w = 2$ ([기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0), 그대로)
- $b$: 1 → 5 (y절편이 바뀐다)
- $x = 3$ (넣는 값)

**풀이**
1. 식을 그대로 쓴다: $y = wx + b$
2. 바꾸기 전($b = 1$)을 대입한다: $y = 2 \times 3 + 1$
3. 곱셈을 한 뒤 더한다: $2 \times 3 = 6$ 이므로 $y = 6 + 1 = 7$
4. 바꾼 뒤($b = 5$)를 대입한다: $y = 2 \times 3 + 5$
5. 곱셈을 한 뒤 더한다: $2 \times 3 = 6$ 이므로 $y = 6 + 5 = 11$
6. 바뀐 양을 구한다: $11 - 7 = 4$, 이것은 $b$가 늘어난 양 $5 - 1 = 4$와 같다

**답**: y는 7에서 11로 바뀐다. 모든 x에서 y가 4씩 커지므로 직선 전체가 위로 4만큼 평행 이동한다.

</details>

### 문제 8
EX\_01의 계단 함수 `y = np.float32(s > 10)`에 $s = 7$과 $s = 10.5$를 넣으면 각각 y는? (참은 1.0, 거짓은 0.0이다)

<details><summary>풀이와 답</summary>

**주어진 값**
- 코드 `y = np.float32(s > 10)` (s가 10보다 크면 1.0, 아니면 0.0)
- $s = 7$, $s = 10.5$ (넣는 값 두 개)

**풀이**
1. 코드를 그대로 쓴다: `y = np.float32(s > 10)`
2. $s = 7$을 대입한다: `y = np.float32(7 > 10)`
3. 비교한다: 7은 10보다 크지 않다 → 거짓(False)이므로 `y = np.float32(False)`
4. 바꾼다: 거짓은 0이므로 $y = 0.0$
5. $s = 10.5$를 대입한다: `y = np.float32(10.5 > 10)`
6. 비교한다: 10.5는 10보다 0.5 크다 → 참(True)이므로 `y = np.float32(True)`
7. 바꾼다: 참은 1이므로 $y = 1.0$

**답**: $s = 7$일 때 $y = 0.0$, $s = 10.5$일 때 $y = 1.0$

</details>

### 문제 9
[Lec01 5.4](../../Lec01_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%86%8C%EA%B0%9C.md#54-%ED%8D%BC%EC%85%89%ED%8A%B8%EB%A1%A0%EA%B3%BC-%EC%84%A0%ED%98%95-%EB%B6%84%EB%A5%98)의 [퍼셉트론](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#perceptron-%ED%8D%BC%EC%85%89%ED%8A%B8%EB%A1%A0)은 일차식 z를 만든 뒤 계단 함수 g를 붙인다(z가 0보다 크면 1, 아니면 0). 입력이 숫자 하나인 [퍼셉트론](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#perceptron-%ED%8D%BC%EC%85%89%ED%8A%B8%EB%A1%A0)에서 $w = 2$, $b = -6$일 때, $x = 2$와 $x = 4$의 출력 $y = g(z)$를 구하라. 어느 x부터 출력이 1이 되는가?
(여기서 z는 일차함수 $z = wx + b$이다. 강의 식의 $\mathbf{x}^\top \mathbf{w}$가 입력 하나일 때는 $wx$가 된다)

<details><summary>풀이와 답</summary>

**주어진 값**
- $w = 2$ ([가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98))
- $b = -6$ ([편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5))
- $x = 2$, $x = 4$ (입력 두 개)
- $g$: z > 0이면 1, 아니면 0 (계단 함수)

**풀이**
1. 식을 그대로 쓴다: $z = wx + b, \qquad y = g(z)$
2. $x = 2$를 대입한다: $z = 2 \times 2 + (-6)$
3. 곱셈을 한 뒤 더한다: $2 \times 2 = 4$ 이므로 $z = 4 + (-6) = -2$
4. 계단 함수를 적용한다: $-2$는 0보다 크지 않으므로 $y = g(-2) = 0$
5. $x = 4$를 대입한다: $z = 2 \times 4 + (-6)$
6. 곱셈을 한 뒤 더한다: $2 \times 4 = 8$ 이므로 $z = 8 + (-6) = 2$
7. 계단 함수를 적용한다: $2$는 0보다 크므로 $y = g(2) = 1$
8. 경계를 찾는다. $z = 0$이 되는 x를 구한다: $2x - 6 = 0$ 이므로 $2x = 6$, $x = 6 \div 2 = 3$
9. $x = 3$에서는 $z = 0$이고 "0보다 크다"가 아니므로 출력은 0이다. 그래서 3을 넘으면 1이 된다.

**답**: $x = 2$이면 $y = 0$, $x = 4$이면 $y = 1$. 경계는 $x = 3$이고 3보다 큰 x부터 출력이 1이다 (일차함수 $z = 2x - 6$이 0을 지나는 자리)

</details>

### 문제 10
[Lec11 1절](../../Lec11_%ED%91%9C%ED%98%84_%ED%95%99%EC%8A%B5_%EC%9E%AC%EA%B5%AC%EC%84%B1.md#1-%ED%91%9C%ED%98%84-%ED%95%99%EC%8A%B5%EC%9D%B4%EB%9E%80)에서 말하듯 모델은 입력을 다른 값으로 옮기는 함수들을 이어 붙인 것이다. 첫째 함수 $f(x) = 2x + 1$ 다음에 둘째 함수 $g(u) = 3u - 2$를 이어 붙였을 때, 입력 $x = 1$의 최종 출력 $g(f(1))$은? 같은 입력으로 순서를 바꾼 $f(g(1))$도 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $f(x) = 2x + 1$ (첫째 함수)
- $g(u) = 3u - 2$ (둘째 함수. 입력 이름이 u이지만 규칙은 같다)
- $x = 1$ (넣는 값)

**풀이**
1. $g(f(1))$은 안쪽부터 계산한다. 식을 그대로 쓴다: $f(x) = 2x + 1$
2. 값을 대입한다: $f(1) = 2 \times 1 + 1$
3. 곱셈을 한 뒤 더한다: $2 \times 1 = 2$ 이므로 $f(1) = 2 + 1 = 3$
4. $f(1) = 3$을 $g$의 입력으로 넣는다. 식을 그대로 쓴다: $g(u) = 3u - 2$
5. 값을 대입한다: $g(3) = 3 \times 3 - 2$
6. 곱셈을 한 뒤 뺀다: $3 \times 3 = 9$ 이므로 $g(3) = 9 - 2 = 7$
7. 순서를 바꾼 $f(g(1))$을 계산한다. 먼저 $g(1) = 3 \times 1 - 2$
8. 곱셈을 한 뒤 뺀다: $3 \times 1 = 3$ 이므로 $g(1) = 3 - 2 = 1$
9. $g(1) = 1$을 $f$에 넣는다: $f(1) = 2 \times 1 + 1 = 3$

**답**: $g(f(1)) = 7$, $f(g(1)) = 3$. 함수를 이어 붙이는 순서가 다르면 결과도 달라진다.

</details>
