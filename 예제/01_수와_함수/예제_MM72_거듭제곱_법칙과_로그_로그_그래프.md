# 예제: 거듭제곱 법칙과 로그-로그 그래프

개념 노트: [MM72_거듭제곱_법칙과_로그_로그_그래프](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/01_%EC%88%98%EC%99%80_%ED%95%A8%EC%88%98/MM72_%EA%B1%B0%EB%93%AD%EC%A0%9C%EA%B3%B1_%EB%B2%95%EC%B9%99%EA%B3%BC_%EB%A1%9C%EA%B7%B8_%EB%A1%9C%EA%B7%B8_%EA%B7%B8%EB%9E%98%ED%94%84.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 문제 번호 순서는 쉬운 것에서 어려운 것, 마지막 둘은 강의 내용과 잇는 문제다. 따로 말이 없으면 법칙은 $L(X) = (X_c / X)^{\alpha}$이고, $\log$는 밑이 10인 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)다.

## 기본 (직접 대입)

### 문제 1
$X_c = 100$, $\alpha = 0.5$인 [거듭제곱 법칙](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#power-law-%EA%B1%B0%EB%93%AD%EC%A0%9C%EA%B3%B1-%EB%B2%95%EC%B9%99)에서 자원이 $X = 25$일 때 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $L$은?

<details><summary>풀이와 답</summary>

**주어진 값**
- $X_c = 100$ (맞춤 상수)
- $\alpha = 0.5$ ([지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98), 0.5제곱은 제곱근과 같다)
- $X = 25$ (자원)

**풀이**
1. 식을 그대로 쓴다: $L(X) = \left(\dfrac{X_c}{X}\right)^{\alpha}$
2. 값을 대입한다: $L = \left(\dfrac{100}{25}\right)^{0.5}$
3. 나눈다: $100 / 25 = 4$ 이므로 $L = 4^{0.5}$
4. 0.5제곱은 제곱근이다 ($\sqrt{x}$는 제곱해서 $x$가 되는 양수): $\sqrt{4} = 2$

**답**: $L = $ **2**

</details>

### 문제 2
$\alpha = 0.5$일 때 자원을 4배로 늘리면 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은 몇 배가 되는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $\alpha = 0.5$ ([지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98))
- $k = 4$ (자원을 늘리는 배수)

**풀이**
1. 식을 그대로 쓴다: $L \to k^{-\alpha} L$ (자원을 $k$배 하면 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은 $k^{-\alpha}$배)
2. 값을 대입한다: $k^{-\alpha} = 4^{-0.5}$
3. 음수 [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)는 역수다 ($X^{-a} = 1 / X^{a}$): $4^{-0.5} = \dfrac{1}{4^{0.5}}$
4. 0.5제곱은 제곱근이다: $4^{0.5} = \sqrt{4} = 2$ 이므로 $\dfrac{1}{2}$
5. 나눈다: $1 / 2 = 0.5$

**답**: **0.5배**. 자원을 4배로 하면 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 절반이 된다.

</details>

### 문제 3
$X_c = 10^4$, $\alpha = 0.5$, $X = 10^2$일 때 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)-로그 직선의 식 $\log L = \alpha \log X_c - \alpha \log X$로 $\log L$을 구하고, $L$로 되돌려라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $X_c = 10^4$ (맞춤 상수), $\alpha = 0.5$ ([지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)), $X = 10^2$ (자원)
- $\log_{10} 10^{m} = m$ ($\log_{10}$은 "10을 몇 번 곱해야 그 수가 되나")

**풀이**
1. 식을 그대로 쓴다: $\log_{10} L = \alpha \log_{10} X_c - \alpha \log_{10} X$
2. 값을 대입한다: $\log_{10} L = 0.5 \times \log_{10} 10^4 - 0.5 \times \log_{10} 10^2$
3. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 구한다: $\log_{10} 10^4 = 4$, $\log_{10} 10^2 = 2$ 이므로 $\log_{10} L = 0.5 \times 4 - 0.5 \times 2$
4. 곱한다: $0.5 \times 4 = 2$, $0.5 \times 2 = 1$ 이므로 $\log_{10} L = 2 - 1$
5. 뺀다: $2 - 1 = 1$
6. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 되돌린다 (10의 거듭제곱): $L = 10^{1} = 10$
7. 검산한다: $\left(\dfrac{10^4}{10^2}\right)^{0.5} = 100^{0.5} = 10$

**답**: $\log_{10} L = $ **1**, $L = $ **10**

</details>

### 문제 4
두 실험에서 자원 $X_1 = 10$일 때 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $L_1 = 100$, 자원 $X_2 = 1000$일 때 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $L_2 = 10$이었다. [거듭제곱 법칙](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#power-law-%EA%B1%B0%EB%93%AD%EC%A0%9C%EA%B3%B1-%EB%B2%95%EC%B9%99)의 [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98) $\alpha$는?

<details><summary>풀이와 답</summary>

**주어진 값**
- $X_1 = 10$, $L_1 = 100$ (작은 실험)
- $X_2 = 1000$, $L_2 = 10$ (큰 실험)

**풀이**
1. 식을 그대로 쓴다: $\alpha = -\dfrac{\log_{10} L_2 - \log_{10} L_1}{\log_{10} X_2 - \log_{10} X_1}$
2. 값을 대입한다: $\alpha = -\dfrac{\log_{10} 10 - \log_{10} 100}{\log_{10} 1000 - \log_{10} 10}$
3. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 구한다: $\log_{10} 10 = 1$, $\log_{10} 100 = 2$, $\log_{10} 1000 = 3$ 이므로 $\alpha = -\dfrac{1 - 2}{3 - 1}$
4. 분자를 뺀다: $1 - 2 = -1$
5. 분모를 뺀다: $3 - 1 = 2$ 이므로 $\alpha = -\dfrac{-1}{2}$
6. 나눈다: $-1 / 2 = -0.5$
7. 마이너스를 붙인다: $-(-0.5) = 0.5$

**답**: $\alpha = $ **0.5**

</details>

### 문제 5
자원 $X = 10, 100, 1000$에서 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 $8, 4, 2$였다. [로그-로그 그래프](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-log-plot-%EB%A1%9C%EA%B7%B8-%EB%A1%9C%EA%B7%B8-%EA%B7%B8%EB%9E%98%ED%94%84)에서 이 점들은 직선인가? 직선이라면 [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98) $\alpha$는? ($\log_{10} 8 = 0.9031$, $\log_{10} 4 = 0.6021$, $\log_{10} 2 = 0.3010$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $(X, L) = (10, 8), (100, 4), (1000, 2)$
- $\log_{10} L = 0.9031,\ 0.6021,\ 0.3010$ ([손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)의 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8))
- $\log_{10} X = 1,\ 2,\ 3$ (자원의 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8))

**풀이**
1. 식을 그대로 쓴다: [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $= \dfrac{\log_{10} L_2 - \log_{10} L_1}{\log_{10} X_2 - \log_{10} X_1}$ (직선이면 어느 두 점을 잡아도 같다)
2. 첫 구간을 대입한다: $\dfrac{0.6021 - 0.9031}{2 - 1}$
3. 계산한다: $0.6021 - 0.9031 = -0.3010$, $2 - 1 = 1$ 이므로 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $= -0.3010$
4. 둘째 구간을 대입한다: $\dfrac{0.3010 - 0.6021}{3 - 2}$
5. 계산한다: $0.3010 - 0.6021 = -0.3011$ 이므로 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $= -0.3011 \approx -0.3010$
6. 비교한다: 두 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 같으므로 직선이다.
7. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 구한다 ($\alpha$는 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)에 마이너스를 붙인 값): $\alpha = -(-0.3010) = 0.3010$

**답**: **직선**이고 $\alpha = $ **0.301**. 자원이 10배가 될 때마다 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 정확히 절반으로 줄기 때문이다 ($10^{-0.301} = 0.5$).

</details>

### 문제 6
문제 5의 법칙을 그대로 연장하면 자원 $X = 10^4$일 때 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은 얼마로 예측되는가? ($10^{0.3010} = 2$, 곧 $10^{-0.3010} = 0.5$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $\alpha = 0.3010$ (문제 5에서 구한 [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98))
- $X = 1000$에서 $L = 2$ (마지막 측정점)
- 목표 $X = 10^4$ (자원을 $k = 10$배)

**풀이**
1. 식을 그대로 쓴다: $L \to k^{-\alpha} L$
2. 값을 대입한다: $L(10^4) = 10^{-0.3010} \times L(1000) = 10^{-0.3010} \times 2$
3. 배수를 구한다: $10^{-0.3010} = 0.5$ 이므로 $L(10^4) = 0.5 \times 2$
4. 곱한다: $0.5 \times 2 = 1$

**답**: **1**. 측정하지 않은 범위로 직선을 연장한 [외삽](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#extrapolation-%EC%99%B8%EC%82%BD)이다. 그 범위에서 직선이 유지된다는 보장은 없다 (노트의 ⚠ 주의).

</details>

### 문제 7
[손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 절반으로 줄이려면 자원을 몇 배로 늘려야 하는가? [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)가 $\alpha = 0.5$인 경우와 $\alpha = 0.25$인 경우를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 목표: $k^{-\alpha} = \frac{1}{2}$ ([손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 절반)
- $\alpha = 0.5$ 또는 $\alpha = 0.25$

**풀이**
1. 식을 그대로 쓴다: $k^{-\alpha} = \dfrac{1}{2} \;\Longleftrightarrow\; k = 2^{1/\alpha}$
2. $\alpha = 0.5$를 대입한다: $k = 2^{1/0.5}$
3. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $1 / 0.5 = 2$ 이므로 $k = 2^2$
4. 제곱한다: $2 \times 2 = 4$
5. $\alpha = 0.25$를 대입한다: $k = 2^{1/0.25}$
6. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $1 / 0.25 = 4$ 이므로 $k = 2^4$
7. 거듭제곱한다: $2 \times 2 \times 2 \times 2 = 16$

**답**: $\alpha = 0.5$면 **4배**, $\alpha = 0.25$면 **16배**. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)가 절반이 되면 필요한 자원이 제곱으로 늘어난다.

</details>

### 문제 8
데이터 법칙의 [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)가 $\alpha = 0.095$일 때, [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 20% 줄이려면(0.8배로) 데이터를 몇 배로 늘려야 하는가? ($\ln 0.8 = -0.2231$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $\alpha = 0.095$ ([지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98))
- 목표: $k^{-\alpha} = 0.8$
- $\ln 0.8 = -0.2231$ ($\ln a$는 "$e$를 몇 제곱해야 $a$가 되나", $e$는 약 2.718)

**풀이**
1. 식을 그대로 쓴다: $k^{-\alpha} = 0.8 \;\Longleftrightarrow\; k = 0.8^{-1/\alpha} = e^{-\ln(0.8)/\alpha}$
2. 값을 대입한다: $k = e^{-(-0.2231)/0.095}$
3. 부호를 정리한다: $-(-0.2231) = 0.2231$ 이므로 $k = e^{0.2231 / 0.095}$
4. 나눈다: $0.2231 / 0.095 = 2.3489$ 이므로 $k = e^{2.3489}$
5. $e$의 거듭제곱을 계산한다 (계산기의 exp): $e^{2.3489} = 10.47$

**답**: 약 **10.5배**. 노트에서 10배일 때 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 0.8035배였던 것과 맞는다. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)가 작아서 20%를 줄이는 데도 자릿수 하나만큼의 데이터가 든다.

</details>

## 강의와 연결

### 문제 9
[Lec20 4](../../Lec20_%EC%8A%A4%EC%BC%80%EC%9D%BC%EB%A7%81_%EB%B2%95%EC%B9%99.md#4-%EB%B0%9C%EA%B2%AC-1-%EA%B1%B0%EB%93%AD%EC%A0%9C%EA%B3%B1-%EB%B2%95%EC%B9%99)의 데이터 법칙 $L(D) = (D_c / D)^{0.095}$, $D_c = 5.4 \times 10^{13}$에서 $D = 10^8$ 토큰일 때 시험 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은? ($\ln(5.4 \times 10^5) = 13.1993$이고, $a^b = e^{b \ln a}$로 계산한다.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $D_c = 5.4 \times 10^{13}$ (맞춤 상수)
- $\alpha = 0.095$ ([지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98))
- $D = 10^8$ ([학습](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5) [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 수)

**풀이**
1. 식을 그대로 쓴다: $L(D) = \left(\dfrac{D_c}{D}\right)^{\alpha}$
2. 값을 대입한다: $L = \left(\dfrac{5.4 \times 10^{13}}{10^8}\right)^{0.095}$
3. 나눈다: $10^{13} / 10^8 = 10^5$ 이므로 $L = (5.4 \times 10^5)^{0.095}$
4. 소수 [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)는 $a^b = e^{b \ln a}$로 바꾼다: $L = e^{0.095 \times \ln(5.4 \times 10^5)}$
5. 자연로그를 쓴다: $\ln(5.4 \times 10^5) = 13.1993$ 이므로 $L = e^{0.095 \times 13.1993}$
6. 곱한다: $0.095 \times 13.1993 = 1.2539$ 이므로 $L = e^{1.2539}$
7. $e$의 거듭제곱을 계산한다: $e^{1.2539} = 3.5041$

**답**: $L(10^8) = $ **3.5041**. 노트 3절 표의 첫 값과 같다.

</details>

### 문제 10
[Lec20 4](../../Lec20_%EC%8A%A4%EC%BC%80%EC%9D%BC%EB%A7%81_%EB%B2%95%EC%B9%99.md#4-%EB%B0%9C%EA%B2%AC-1-%EA%B1%B0%EB%93%AD%EC%A0%9C%EA%B3%B1-%EB%B2%95%EC%B9%99)처럼 [로그-로그 그래프](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-log-plot-%EB%A1%9C%EA%B7%B8-%EB%A1%9C%EA%B7%B8-%EA%B7%B8%EB%9E%98%ED%94%84)에서 직선이 되는 것은 거듭제곱 법칙뿐이다. 거듭제곱 $L = 10 X^{-0.5}$와 [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98) 감소 $L = 10 \times 0.5^{X/100}$을 비교한다. 두 곡선의 값은 다음과 같다. $X = 10, 100, 1000$에서 거듭제곱은 $3.1623,\ 1,\ 0.3162$, [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98) 감소는 $9.3303,\ 5,\ 0.009766$이다. 구간 $10 \to 100$과 $100 \to 1000$의 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)-로그 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)를 각각 구하라. ($\log_{10} 3.1623 = 0.5$, $\log_{10} 0.3162 = -0.5$, $\log_{10} 9.3303 = 0.9699$, $\log_{10} 5 = 0.6990$, $\log_{10} 0.009766 = -2.0103$)

<details><summary>풀이와 답</summary>

**주어진 값**
- 거듭제곱의 $\log_{10} L$: $0.5,\ 0,\ -0.5$ ($X = 10, 100, 1000$)
- [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98) 감소의 $\log_{10} L$: $0.9699,\ 0.6990,\ -2.0103$
- $\log_{10} X = 1,\ 2,\ 3$ (가로 좌표)

**풀이**
1. 식을 그대로 쓴다: [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $= \dfrac{\Delta \log_{10} L}{\Delta \log_{10} X}$ (세로 변화 ÷ 가로 변화)
2. 거듭제곱, 첫 구간: $\dfrac{0 - 0.5}{2 - 1} = \dfrac{-0.5}{1} = -0.5$
3. 거듭제곱, 둘째 구간: $\dfrac{-0.5 - 0}{3 - 2} = \dfrac{-0.5}{1} = -0.5$
4. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98) 감소, 첫 구간: $\dfrac{0.6990 - 0.9699}{2 - 1} = \dfrac{-0.2709}{1} = -0.2709$
5. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98) 감소, 둘째 구간: $\dfrac{-2.0103 - 0.6990}{3 - 2} = \dfrac{-2.7093}{1} = -2.7093$
6. 비교한다: 거듭제곱은 두 구간 모두 $-0.5$로 같고, [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98) 감소는 $-0.27$에서 $-2.71$로 점점 가팔라진다.

**답**: 거듭제곱은 **-0.5, -0.5** (직선, [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98) $-\alpha$). [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98) 감소는 **-0.2709, -2.7093** (아래로 꺾이는 곡선). [로그-로그 그래프](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-log-plot-%EB%A1%9C%EA%B7%B8-%EB%A1%9C%EA%B7%B8-%EA%B7%B8%EB%9E%98%ED%94%84)에서 점들이 일직선이면 [거듭제곱 법칙](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#power-law-%EA%B1%B0%EB%93%AD%EC%A0%9C%EA%B3%B1-%EB%B2%95%EC%B9%99)이라고 보는 이유다.

</details>
