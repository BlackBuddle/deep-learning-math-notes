### 문제 1
$\sum_{i=1}^{5} i$의 값은? ($i$를 1부터 5까지 바꿔 가며 $i$ 자체를 전부 더한다)

<details><summary>풀이와 답</summary>

**주어진 값**
- 아래쪽 숫자 $1$ ($i$가 1부터 시작한다)
- 위쪽 숫자 $5$ ($i$가 5까지 간다)
- Σ 안의 $i$ (더하는 것은 번호 그 자체)

**풀이**
1. 식을 그대로 쓴다: $\sum_{i=1}^{5} i$
2. Σ를 항 하나씩 펼친다(i에 1, 2, 3, 4, 5를 차례로 넣는다): $1 + 2 + 3 + 4 + 5$
3. 앞의 두 수를 더한다: $1 + 2 = 3$ 이므로 $3 + 3 + 4 + 5$
4. 다음 수를 더한다: $3 + 3 = 6$ 이므로 $6 + 4 + 5$
5. 다음 수를 더한다: $6 + 4 = 10$ 이므로 $10 + 5$
6. 마지막 수를 더한다: $10 + 5 = 15$

**답**: 15

</details>

### 문제 2
$\sum_{i=1}^{3} i^2$의 값은? ($i^2$은 $i \times i$, 곧 번호를 제곱한 값이다)

<details><summary>풀이와 답</summary>

**주어진 값**
- 아래쪽 숫자 $1$, 위쪽 숫자 $3$ ($i$가 1, 2, 3으로 바뀐다)
- Σ 안의 $i^2$ (번호를 제곱한 값을 더한다)

**풀이**
1. 식을 그대로 쓴다: $\sum_{i=1}^{3} i^2$
2. Σ를 항 하나씩 펼친다: $1^2 + 2^2 + 3^2$
3. 첫째 제곱을 한다: $1^2 = 1 \times 1 = 1$ 이므로 $1 + 2^2 + 3^2$
4. 둘째 제곱을 한다: $2^2 = 2 \times 2 = 4$ 이므로 $1 + 4 + 3^2$
5. 셋째 제곱을 한다: $3^2 = 3 \times 3 = 9$ 이므로 $1 + 4 + 9$
6. 앞의 두 수를 더한다: $1 + 4 = 5$ 이므로 $5 + 9$
7. 마지막 수를 더한다: $5 + 9 = 14$

**답**: 14

</details>

### 문제 3
값 4개 $y_1 = 2$, $y_2 = 6$, $y_3 = 7$, $y_4 = 5$의 평균은? 평균 식은 $\frac{1}{m}\sum_{i=1}^{m} y_i$이다.

<details><summary>풀이와 답</summary>

**주어진 값**
- $m = 4$ (데이터 개수)
- $y_1 = 2$, $y_2 = 6$, $y_3 = 7$, $y_4 = 5$ (i번째 값)

**풀이**
1. 식을 그대로 쓴다: $\text{평균} = \frac{1}{m}\sum_{i=1}^{m} y_i$
2. 값을 대입한다(Σ는 i = 1, 2, 3, 4 항을 하나씩 펼친다): $\text{평균} = \frac{1}{4}(2 + 6 + 7 + 5)$
3. 괄호 안 앞의 두 수를 더한다: $2 + 6 = 8$ 이므로 $\frac{1}{4}(8 + 7 + 5)$
4. 다음 수를 더한다: $8 + 7 = 15$ 이므로 $\frac{1}{4}(15 + 5)$
5. 마지막 수를 더한다: $15 + 5 = 20$ 이므로 $\frac{1}{4} \times 20$
6. $\frac{1}{4}$을 곱하는 것은 4로 나누는 것이다: $20 \div 4 = 5$

**답**: 평균 = 5

</details>

### 문제 4
[가중합](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weighted-sum-%EA%B0%80%EC%A4%91%ED%95%A9) $s = \sum_{i=1}^{3} w_i x_i + b$에서 $x = [1, 2, 3]$, $w = [2, 0, 1]$, $b = -1$일 때 s는?

<details><summary>풀이와 답</summary>

**주어진 값**
- $x_1 = 1$, $x_2 = 2$, $x_3 = 3$ (입력)
- $w_1 = 2$, $w_2 = 0$, $w_3 = 1$ ([가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98))
- $b = -1$ ([편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5))

**풀이**
1. 식을 그대로 쓴다: $s = \sum_{i=1}^{3} w_i x_i + b$
2. 값을 대입한다(Σ는 i = 1, 2, 3 항을 하나씩 펼친다): $s = 2 \times 1 + 0 \times 2 + 1 \times 3 + (-1)$
3. 첫째 곱셈을 한다: $2 \times 1 = 2$ 이므로 $s = 2 + 0 \times 2 + 1 \times 3 + (-1)$
4. 둘째 곱셈을 한다: $0 \times 2 = 0$ 이므로 $s = 2 + 0 + 1 \times 3 + (-1)$
5. 셋째 곱셈을 한다: $1 \times 3 = 3$ 이므로 $s = 2 + 0 + 3 + (-1)$
6. 앞에서부터 더한다: $2 + 0 = 2$ 이므로 $s = 2 + 3 + (-1)$
7. 다음 수를 더한다: $2 + 3 = 5$ 이므로 $s = 5 + (-1)$
8. [편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5)을 더한다: $5 + (-1) = 4$

**답**: $s = 4$

</details>

### 문제 5
$\sum_{i=1}^{4} (2i + 1)$의 값은? (괄호 안의 식에 i를 넣어 나온 값을 전부 더한다)

<details><summary>풀이와 답</summary>

**주어진 값**
- 아래쪽 숫자 $1$, 위쪽 숫자 $4$ ($i$가 1, 2, 3, 4로 바뀐다)
- Σ 안의 $2i + 1$ (번호마다 더할 값)

**풀이**
1. 식을 그대로 쓴다: $\sum_{i=1}^{4} (2i + 1)$
2. Σ를 항 하나씩 펼친다: $(2 \times 1 + 1) + (2 \times 2 + 1) + (2 \times 3 + 1) + (2 \times 4 + 1)$
3. 첫째 괄호를 계산한다: $2 \times 1 + 1 = 3$ 이므로 $3 + (2 \times 2 + 1) + (2 \times 3 + 1) + (2 \times 4 + 1)$
4. 둘째 괄호를 계산한다: $2 \times 2 + 1 = 5$ 이므로 $3 + 5 + (2 \times 3 + 1) + (2 \times 4 + 1)$
5. 셋째 괄호를 계산한다: $2 \times 3 + 1 = 7$ 이므로 $3 + 5 + 7 + (2 \times 4 + 1)$
6. 넷째 괄호를 계산한다: $2 \times 4 + 1 = 9$ 이므로 $3 + 5 + 7 + 9$
7. 앞에서부터 더한다: $3 + 5 = 8$ 이므로 $8 + 7 + 9$
8. 다음 수를 더한다: $8 + 7 = 15$ 이므로 $15 + 9$
9. 마지막 수를 더한다: $15 + 9 = 24$

**답**: 24

</details>

### 문제 6
시험을 5번 봤더니 평균이 80점이었다. 점수를 전부 더한 합은 얼마인가? (평균 식 $\text{평균} = \frac{1}{m}\sum y_i$에서 합 $\sum y_i$를 거꾸로 구한다)

<details><summary>풀이와 답</summary>

**주어진 값**
- $m = 5$ (시험 횟수, 데이터 개수)
- 평균 $= 80$
- 구할 것: 합 $\sum_{i=1}^{5} y_i$

**풀이**
1. 식을 그대로 쓴다: $\text{평균} = \frac{1}{m}\sum_{i=1}^{m} y_i$
2. 값을 대입한다(합을 S라 쓴다): $80 = \frac{1}{5} \times S$
3. $\frac{1}{5}$을 곱하는 것은 5로 나누는 것이다: $80 = S \div 5$
4. 양쪽에 5를 곱해 나눗셈을 없앤다: $80 \times 5 = S$
5. 곱셈을 한다: $80 \times 5 = 400$ 이므로 $S = 400$

**답**: 합 = 400 (합 = 평균 × 개수)

</details>

### 문제 7
[MSE](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#mse-mean-squared-error-%ED%8F%89%EA%B7%A0-%EC%A0%9C%EA%B3%B1-%EC%98%A4%EC%B0%A8) $\text{cost} = \frac{1}{m}\sum_{i=1}^{m}\left(h(x_i) - y_i\right)^2$을 데이터 3개에서 구하라. 예측은 $h(x_1) = 2$, $h(x_2) = 4$, $h(x_3) = 6$, [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)은 $y_1 = 1$, $y_2 = 5$, $y_3 = 8$이다.

<details><summary>풀이와 답</summary>

**주어진 값**
- $m = 3$ (데이터 개수)
- $h(x_1) = 2$, $h(x_2) = 4$, $h(x_3) = 6$ (모델의 예측)
- $y_1 = 1$, $y_2 = 5$, $y_3 = 8$ ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5))

**풀이**
1. 식을 그대로 쓴다: $\text{cost} = \frac{1}{m}\sum_{i=1}^{m}\left(h(x_i) - y_i\right)^2$
2. 값을 대입한다(Σ는 i = 1, 2, 3 항을 하나씩 펼친다): $\text{cost} = \frac{1}{3}\left((2 - 1)^2 + (4 - 5)^2 + (6 - 8)^2\right)$
3. 첫째 괄호의 뺄셈을 한다: $2 - 1 = 1$ 이므로 $\frac{1}{3}\left(1^2 + (4 - 5)^2 + (6 - 8)^2\right)$
4. 둘째 괄호의 뺄셈을 한다: $4 - 5 = -1$ 이므로 $\frac{1}{3}\left(1^2 + (-1)^2 + (6 - 8)^2\right)$
5. 셋째 괄호의 뺄셈을 한다: $6 - 8 = -2$ 이므로 $\frac{1}{3}\left(1^2 + (-1)^2 + (-2)^2\right)$
6. 제곱을 한다(음수끼리 곱하면 양수): $1^2 = 1$, $(-1)^2 = 1$, $(-2)^2 = (-2) \times (-2) = 4$ 이므로 $\frac{1}{3}(1 + 1 + 4)$
7. 괄호 안을 더한다: $1 + 1 = 2$, $2 + 4 = 6$ 이므로 $\frac{1}{3} \times 6$
8. $\frac{1}{3}$을 곱하는 것은 3으로 나누는 것이다: $6 \div 3 = 2$

**답**: cost = 2

</details>

### 문제 8
[오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)가 $e_1 = 3$, $e_2 = -3$이다. (a) [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)를 그냥 평균 내면 얼마인가? (b) 제곱해서 평균 낸 [MSE](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#mse-mean-squared-error-%ED%8F%89%EA%B7%A0-%EC%A0%9C%EA%B3%B1-%EC%98%A4%EC%B0%A8)는 얼마인가? 둘을 비교해 왜 제곱하는지 설명하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $e_1 = 3$, $e_2 = -3$ ([오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 두 개)
- $m = 2$ (데이터 개수)

**풀이**
1. (a) 평균 식을 그대로 쓴다: $\frac{1}{m}\sum_{i=1}^{m} e_i$
2. 값을 대입한다(Σ는 i = 1, 2 항을 펼친다): $\frac{1}{2}(3 + (-3))$
3. 괄호 안을 더한다: $3 + (-3) = 0$ 이므로 $\frac{1}{2} \times 0$
4. 곱셈을 한다: $\frac{1}{2} \times 0 = 0$
5. (b) [MSE](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#mse-mean-squared-error-%ED%8F%89%EA%B7%A0-%EC%A0%9C%EA%B3%B1-%EC%98%A4%EC%B0%A8) 식을 그대로 쓴다: $\text{MSE} = \frac{1}{m}\sum_{i=1}^{m} e_i^2$
6. 값을 대입한다: $\text{MSE} = \frac{1}{2}\left(3^2 + (-3)^2\right)$
7. 제곱을 한다: $3^2 = 9$, $(-3)^2 = (-3) \times (-3) = 9$ 이므로 $\frac{1}{2}(9 + 9)$
8. 괄호 안을 더한다: $9 + 9 = 18$ 이므로 $\frac{1}{2} \times 18$
9. 2로 나눈다: $18 \div 2 = 9$

**답**: (a) 0, (b) 9. +3과 −3이 그냥 더하면 서로 지워져 "하나도 안 틀렸다"처럼 보이지만, 제곱하면 둘 다 9가 되어 틀린 만큼 쌓인다. 그래서 [MSE](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#mse-mean-squared-error-%ED%8F%89%EA%B7%A0-%EC%A0%9C%EA%B3%B1-%EC%98%A4%EC%B0%A8)는 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)를 제곱해서 평균 낸다.

</details>

### 문제 9
[Lec04 3.1](../../Lec04_%EA%B2%A9%EC%9E%90_%EC%95%84%ED%82%A4%ED%85%8D%EC%B2%98.md#31-%ED%95%84%ED%84%B0%EC%99%80-%ED%95%A9%EC%84%B1%EA%B3%B1-%EC%8B%9D)의 [합성곱](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#convolution-%ED%95%A9%EC%84%B1%EA%B3%B1) 식은 패치 안 값에 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)를 곱해 더하는 Σ다. 이것을 1차원으로 줄인 $x_{\text{out}}[n] = b + \sum_{k=-1}^{1} w[k]\, x_{\text{in}}[n+k]$를 계산하라. $w[-1] = 1$, $w[0] = 0$, $w[1] = -1$, $b = 0.5$이고 입력은 $x_{\text{in}}[n-1] = 4$, $x_{\text{in}}[n] = 2$, $x_{\text{in}}[n+1] = 3$이다.
(번호 $k$가 −1, 0, 1로 바뀌므로 항이 3개다)

<details><summary>풀이와 답</summary>

**주어진 값**
- $w[-1] = 1$, $w[0] = 0$, $w[1] = -1$ ([필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0) [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) 3칸)
- $x_{\text{in}}[n-1] = 4$, $x_{\text{in}}[n] = 2$, $x_{\text{in}}[n+1] = 3$ (n 둘레의 입력 3칸)
- $b = 0.5$ ([편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5))

**풀이**
1. 식을 그대로 쓴다: $x_{\text{out}}[n] = b + \sum_{k=-1}^{1} w[k]\, x_{\text{in}}[n+k]$
2. 값을 대입한다(Σ는 $k = -1, 0, 1$ 항을 하나씩 펼친다): $x_{\text{out}}[n] = 0.5 + 1 \times 4 + 0 \times 2 + (-1) \times 3$
3. 첫째 곱셈을 한다: $1 \times 4 = 4$ 이므로 $0.5 + 4 + 0 \times 2 + (-1) \times 3$
4. 둘째 곱셈을 한다: $0 \times 2 = 0$ 이므로 $0.5 + 4 + 0 + (-1) \times 3$
5. 셋째 곱셈을 한다: $(-1) \times 3 = -3$ 이므로 $0.5 + 4 + 0 + (-3)$
6. 앞에서부터 더한다: $0.5 + 4 = 4.5$, $4.5 + 0 = 4.5$ 이므로 $4.5 + (-3)$
7. 마지막 수를 더한다: $4.5 + (-3) = 1.5$

**답**: $x_{\text{out}}[n] = 1.5$

</details>

### 문제 10
[Lec02 2.2](../../Lec02_%EC%8B%A0%EA%B2%BD%EB%A7%9D_%ED%95%99%EC%8A%B5.md#22-%ED%99%95%EB%A5%A0%EC%A0%81-%EA%B2%BD%EC%82%AC%ED%95%98%EA%B0%95%EB%B2%95)의 [SGD](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#stochastic-gradient-descent-%ED%99%95%EB%A5%A0%EC%A0%81-%EA%B2%BD%EC%82%AC%ED%95%98%EA%B0%95%EB%B2%95)는 전체 데이터 대신 배치의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)를 평균 내어 쓴다. 배치 크기가 $B = 4$이고 데이터별 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 $g_1 = 2$, $g_2 = -1$, $g_3 = 3$, $g_4 = 0$일 때 배치 평균 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $\frac{1}{B}\sum_{i=1}^{B} g_i$를 구하라. 이 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)로 [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0) $\eta = 0.1$, 현재 $\theta = 5$일 때 한 번 갱신한 $\theta \leftarrow \theta - \eta \bar{g}$는? ($\bar{g}$는 평균 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0))

<details><summary>풀이와 답</summary>

**주어진 값**
- $B = 4$ (배치 크기, 데이터 개수)
- $g_1 = 2$, $g_2 = -1$, $g_3 = 3$, $g_4 = 0$ (데이터별 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0))
- $\eta = 0.1$ ([학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0))
- $\theta = 5$ (현재 [파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0))

**풀이**
1. 평균 식을 그대로 쓴다: $\bar{g} = \frac{1}{B}\sum_{i=1}^{B} g_i$
2. 값을 대입한다(Σ는 i = 1, 2, 3, 4 항을 하나씩 펼친다): $\bar{g} = \frac{1}{4}(2 + (-1) + 3 + 0)$
3. 괄호 안 앞의 두 수를 더한다: $2 + (-1) = 1$ 이므로 $\frac{1}{4}(1 + 3 + 0)$
4. 다음 수를 더한다: $1 + 3 = 4$ 이므로 $\frac{1}{4}(4 + 0)$
5. 마지막 수를 더한다: $4 + 0 = 4$ 이므로 $\frac{1}{4} \times 4$
6. 4로 나눈다: $4 \div 4 = 1$ 이므로 $\bar{g} = 1$
7. 갱신식을 그대로 쓴다: $\theta \leftarrow \theta - \eta \bar{g}$
8. 값을 대입한다: $\theta \leftarrow 5 - 0.1 \times 1$
9. 곱셈을 먼저 한다: $0.1 \times 1 = 0.1$ 이므로 $\theta \leftarrow 5 - 0.1$
10. 뺄셈을 한다: $5 - 0.1 = 4.9$

**답**: $\bar{g} = 1$, 갱신 뒤 $\theta = 4.9$

</details>
