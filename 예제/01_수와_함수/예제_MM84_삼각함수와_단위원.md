# 예제: 삼각함수와 단위원

개념 노트: [MM84_삼각함수와_단위원](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/01_%EC%88%98%EC%99%80_%ED%95%A8%EC%88%98/MM84_%EC%82%BC%EA%B0%81%ED%95%A8%EC%88%98%EC%99%80_%EB%8B%A8%EC%9C%84%EC%9B%90.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 문제 번호 순서는 쉬운 것에서 어려운 것, 마지막 둘은 강의 내용과 잇는 문제다. 필요하면 $\pi = 3.1416$을 쓴다.

## 기본 (직접 대입)

### 문제 1
60°를 라디안으로 바꿔라.

<details><summary>풀이와 답</summary>

**주어진 값**:
- 도 $= 60$ (바꿀 각도)
- $\pi = 3.1416$ (원주율)

**풀이**
1. 식을 그대로 쓴다: $\text{라디안} = \text{도} \times \frac{\pi}{180}$
2. 값을 대입한다: $\text{라디안} = 60 \times \frac{3.1416}{180}$
3. 60과 180을 먼저 나눈다: 60 ÷ 180 = 1/3 이므로 $\text{라디안} = \frac{1}{3} \times 3.1416$
4. 곱한다: 3.1416 ÷ 3 = 1.0472

**답**: 1.0472 라디안 (= π/3)

</details>

### 문제 2
$\frac{3\pi}{4}$ 라디안은 몇 도인가? (라디안 식을 뒤집으면 $\text{도} = \text{라디안} \times \frac{180}{\pi}$이다.)

<details><summary>풀이와 답</summary>

**주어진 값**:
- 라디안 $= \frac{3\pi}{4}$ (바꿀 각도)

**풀이**
1. 식을 그대로 쓴다: $\text{도} = \text{라디안} \times \frac{180}{\pi}$
2. 값을 대입한다: $\text{도} = \frac{3\pi}{4} \times \frac{180}{\pi}$
3. π를 위아래에서 지운다 (π ÷ π = 1): $\text{도} = \frac{3}{4} \times 180$
4. 3과 180을 곱한다: 3 × 180 = 540 이므로 $\text{도} = \frac{540}{4}$
5. 나눈다: 540 ÷ 4 = 135

**답**: 135°

</details>

### 문제 3
단위원에서 45° 돌아간 점의 좌표와 $\tan 45°$를 구하라. ($\cos 45° = \sin 45° = \frac{\sqrt{2}}{2}$, √2는 제곱하면 2가 되는 수로 1.4142이다.)

<details><summary>풀이와 답</summary>

**주어진 값**:
- $\theta = 45°$ (돈 각도)
- $\cos 45° = \sin 45° = \frac{\sqrt{2}}{2}$ (점의 가로, 세로 좌표)
- $\sqrt{2} = 1.4142$ (제곱근 값)

**풀이**
1. 식을 그대로 쓴다: $P(\theta) = (\cos\theta,\ \sin\theta)$, $\tan\theta = \frac{\sin\theta}{\cos\theta}$
2. 값을 대입한다: $P(45°) = \left(\frac{\sqrt{2}}{2},\ \frac{\sqrt{2}}{2}\right)$, $\tan 45° = \frac{\sqrt{2}/2}{\sqrt{2}/2}$
3. √2를 숫자로 바꾼다: $P(45°) = \left(\frac{1.4142}{2},\ \frac{1.4142}{2}\right)$
4. 나눈다: 1.4142 ÷ 2 = 0.7071 이므로 $P(45°) = (0.7071,\ 0.7071)$
5. tan을 계산한다: 같은 수를 같은 수로 나누므로 $\tan 45° = \frac{0.7071}{0.7071} = 1$

**답**: $P(45°) = (0.7071,\ 0.7071)$, $\tan 45° = 1$ (45° 직선의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)는 1)

</details>

### 문제 4
1사분면(오른쪽 위)의 각 $\theta$에서 $\cos\theta = 0.6$이다. $\sin\theta$와 $\tan\theta$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**:
- $\cos\theta = 0.6$ (점의 가로 좌표)
- 1사분면이라 $\sin\theta > 0$ (세로 좌표는 양수)

**풀이**
1. 식을 그대로 쓴다: $\sin^2\theta + \cos^2\theta = 1$
2. 값을 대입한다: $\sin^2\theta + 0.6^2 = 1$
3. 제곱한다: 0.6 × 0.6 = 0.36 이므로 $\sin^2\theta + 0.36 = 1$
4. 0.36을 넘긴다: 1 − 0.36 = 0.64 이므로 $\sin^2\theta = 0.64$
5. 제곱근을 구한다 (0.8 × 0.8 = 0.64): $\sin\theta = 0.8$
6. tan 식을 쓰고 대입한다: $\tan\theta = \frac{\sin\theta}{\cos\theta} = \frac{0.8}{0.6}$
7. 나눈다: 0.8 ÷ 0.6 = 1.3333

**답**: $\sin\theta = 0.8$, $\tan\theta = 1.3333$

</details>

## 응용

### 문제 5
$\sin 750°$의 값은? ($\sin 30° = 0.5$이고, 한 바퀴 360°마다 같은 값이 되풀이된다.)

<details><summary>풀이와 답</summary>

**주어진 값**:
- $\theta = 750°$ (돈 각도)
- $\sin 30° = 0.5$ (기준 값)
- 주기 $360°$ (한 바퀴)

**풀이**
1. 식을 그대로 쓴다: $\sin(\theta + 360°) = \sin\theta$ (한 바퀴를 더 돌아도 같은 점)
2. 값을 대입한다: $\sin 750° = \sin(750° - 360° - 360°)$
3. 한 바퀴를 뺀다: 750 − 360 = 390 이므로 $\sin 750° = \sin(390° - 360°)$
4. 한 바퀴를 한 번 더 뺀다: 390 − 360 = 30 이므로 $\sin 750° = \sin 30°$
5. 값을 읽는다: $\sin 30° = 0.5$

**답**: 0.5

</details>

### 문제 6
210° 돌아간 점의 $(\cos, \sin)$을 구하고 $\sin^2 + \cos^2 = 1$을 확인하라. (210° = 180° + 30°이라 30°의 점 (0.8660, 0.5)를 원점 기준 정반대 자리로 옮긴 점이다.)

<details><summary>풀이와 답</summary>

**주어진 값**:
- $\theta = 210°$ (돈 각도)
- 30°의 점 $(\cos 30°,\ \sin 30°) = (0.8660,\ 0.5)$ (기준 점)

**풀이**
1. 식을 그대로 쓴다: 정반대 자리는 두 좌표의 부호가 모두 바뀐다. $P(210°) = (-\cos 30°,\ -\sin 30°)$
2. 값을 대입한다: $P(210°) = (-0.8660,\ -0.5)$
3. 확인 식을 쓴다: $\sin^2\theta + \cos^2\theta = 1$
4. 값을 대입한다: $(-0.5)^2 + (-0.8660)^2$
5. 제곱한다: (−0.5) × (−0.5) = 0.25, (−0.8660) × (−0.8660) = 0.75 이므로 $0.25 + 0.75$
6. 더한다: 0.25 + 0.75 = 1

**답**: $P(210°) = (-0.8660,\ -0.5)$, $\sin^2 + \cos^2 = 1$ (3사분면은 두 좌표 모두 음수)

</details>

### 문제 7
$\sin(\omega p)$의 주기 $T = \frac{2\pi}{\omega}$를 $\omega = 0.5$와 $\omega = 2$에 대해 구하고, 더 빨리 되풀이하는 쪽을 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**:
- $\omega_1 = 0.5$, $\omega_2 = 2$ (위치가 한 칸 늘 때 도는 각, 라디안)
- $2\pi = 6.2832$ (한 바퀴)

**풀이**
1. 식을 그대로 쓴다: $T = \frac{2\pi}{\omega}$
2. 값을 대입한다: $T_1 = \frac{6.2832}{0.5}$, $T_2 = \frac{6.2832}{2}$
3. 첫째를 나눈다: 6.2832 ÷ 0.5 = 12.5664 이므로 $T_1 = 12.5664$
4. 둘째를 나눈다: 6.2832 ÷ 2 = 3.1416 이므로 $T_2 = 3.1416$
5. 비교한다: 3.1416 < 12.5664 이므로 $\omega_2$ 쪽이 위치 3.14 만에 한 바퀴를 돈다

**답**: $T_1 = 12.5664$, $T_2 = 3.1416$. $\omega$가 클수록 주기가 짧아 더 빨리 되풀이한다 (사인파 [위치 인코딩](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#positional-encoding-%EC%9C%84%EC%B9%98-%EC%9D%B8%EC%BD%94%EB%94%A9)이 $\omega$를 여러 값으로 두는 이유)

</details>

### 문제 8
각도 더하기 공식으로 $\cos 75°$를 구하라. (75° = 30° + 45°, $\cos 30° = 0.86603$, $\sin 30° = 0.5$, $\cos 45° = \sin 45° = 0.70711$)

<details><summary>풀이와 답</summary>

**주어진 값**:
- $a = 30°,\ b = 45°$ (쪼갠 각)
- $\cos 30° = 0.86603,\ \sin 30° = 0.5$ (a의 값)
- $\cos 45° = \sin 45° = 0.70711$ (b의 값)

**풀이**
1. 식을 그대로 쓴다: $\cos(a+b) = \cos a\cos b - \sin a\sin b$
2. 값을 대입한다: $\cos 75° = 0.86603 \times 0.70711 - 0.5 \times 0.70711$
3. 첫 항을 곱한다: 0.86603 × 0.70711 = 0.61238 이므로 $\cos 75° = 0.61238 - 0.5 \times 0.70711$
4. 둘째 항을 곱한다: 0.5 × 0.70711 = 0.35356 이므로 $\cos 75° = 0.61238 - 0.35356$
5. 뺀다: 0.61238 − 0.35356 = 0.25882

**답**: $\cos 75° \approx 0.2588$ (75°는 거의 12시 방향이라 가로 좌표가 작다)

</details>

### 문제 9
[Lec08 7](../../Lec08_%ED%8A%B8%EB%9E%9C%EC%8A%A4%ED%8F%AC%EB%A8%B8.md#7-%EC%9C%84%EC%B9%98-%EC%9D%B8%EC%BD%94%EB%94%A9)의 [RoPE](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#rope-rotary-position-embedding-%ED%9A%8C%EC%A0%84-%EC%9C%84%EC%B9%98-%EC%9E%84%EB%B2%A0%EB%94%A9)처럼 위치가 하나 늘 때마다 (1, 0)을 30°씩 돌린 단위 벡터를 쓴다. 위치 (4, 2)의 벡터 둘의 [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)과 위치 (7, 5)의 벡터 둘의 [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)을 구하고 같은지 비교하라.
(위치 4: (−0.5, 0.8660), 위치 2: (0.5, 0.8660), 위치 7: (−0.8660, −0.5), 위치 5: (−0.8660, 0.5))

<details><summary>풀이와 답</summary>

**주어진 값**:
- 위치 4 = $(-0.5,\ 0.8660)$ (120°), 위치 2 = $(0.5,\ 0.8660)$ (60°)
- 위치 7 = $(-0.8660,\ -0.5)$ (210°), 위치 5 = $(-0.8660,\ 0.5)$ (150°)

**풀이**
1. 식을 그대로 쓴다: $(\cos a,\ \sin a) \cdot (\cos b,\ \sin b) = \cos a\cos b + \sin a\sin b$
2. (4, 2)에 값을 대입한다: $(-0.5) \times 0.5 + 0.8660 \times 0.8660$
3. 곱한다: (−0.5) × 0.5 = −0.25, 0.8660 × 0.8660 = 0.75 이므로 $-0.25 + 0.75$
4. 더한다: −0.25 + 0.75 = 0.5
5. (7, 5)에 값을 대입한다: $(-0.8660) \times (-0.8660) + (-0.5) \times 0.5$
6. 곱한다: (−0.8660) × (−0.8660) = 0.75, (−0.5) × 0.5 = −0.25 이므로 $0.75 - 0.25$
7. 뺀다: 0.75 − 0.25 = 0.5
8. 비교한다: 두 위치 쌍의 차이는 모두 2칸 = 60°이고 $\cos 60° = 0.5$이다

**답**: 둘 다 0.5로 같다. 위치 번호가 달라도 **차이**가 같으면 [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)이 같아서 상대 위치만 남는다

</details>

### 문제 10
[MM17_사인파_위치_인코딩](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/07_%EA%B5%AC%EC%A1%B0_%EC%95%84%ED%82%A4%ED%85%8D%EC%B2%98/MM17_%EC%82%AC%EC%9D%B8%ED%8C%8C_%EC%9C%84%EC%B9%98_%EC%9D%B8%EC%BD%94%EB%94%A9.md)처럼 위치 $p$를 $(\sin(\omega p),\ \cos(\omega p))$로 바꾼다. $\omega = \pi/6$(한 칸에 30°)일 때 주기 $T$, 위치 $p = 2$와 $p = 14$의 값, 그 묶음의 $\sin^2 + \cos^2$을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**:
- $\omega = \pi/6$ (한 칸에 도는 각, 30°)
- $p = 2$, $p = 14$ (비교할 위치)
- $\sin 60° = 0.8660$, $\cos 60° = 0.5$ (60°의 점)

**풀이**
1. 식을 그대로 쓴다: $T = \frac{2\pi}{\omega}$
2. 값을 대입한다: $T = \frac{2\pi}{\pi/6}$
3. 뒤집어 곱한다: $2\pi \times \frac{6}{\pi} = 12$ 이므로 $T = 12$
4. $p = 2$의 각을 구한다: 30° × 2 = 60° 이므로 $(\sin, \cos) = (0.8660,\ 0.5)$
5. $p = 14$의 각을 구한다: 30° × 14 = 420°
6. 한 바퀴를 뺀다: 420 − 360 = 60° 이므로 $p = 2$와 같은 자리이고 $(\sin, \cos) = (0.8660,\ 0.5)$
7. 확인 식을 쓰고 대입한다: $\sin^2 + \cos^2 = 0.8660^2 + 0.5^2$
8. 제곱한다: 0.8660 × 0.8660 = 0.75, 0.5 × 0.5 = 0.25 이므로 $0.75 + 0.25$
9. 더한다: 0.75 + 0.25 = 1

**답**: $T = 12$, $p = 2$와 $p = 14$는 둘 다 $(0.8660,\ 0.5)$ (12칸 떨어지면 같은 값), $\sin^2 + \cos^2 = 1$ (모든 위치의 묶음이 단위원 위에 있다)

</details>
