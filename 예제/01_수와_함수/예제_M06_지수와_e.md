# 예제: 지수와 e

개념 노트: [M06_지수와_e](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/01_%EC%88%98%EC%99%80_%ED%95%A8%EC%88%98/M06_%EC%A7%80%EC%88%98%EC%99%80_e.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 문제 10개, 쉬운 것부터 어려운 것 순서다. $e$의 거듭제곱 값은 계산기나 파이썬 `math.exp`로 구한 것을 소수 넷째 자리까지 쓴다.

## 기본 (직접 대입)

### 문제 1
$2^4$, $5^0$, $2^{-3}$의 값을 각각 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 밑 $a = 2$, [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98) $n = 4$ (첫째)
- 밑 $a = 5$, [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98) $n = 0$ (둘째)
- 밑 $a = 2$, [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98) $n = -3$ (셋째)

**풀이**
1. 첫째. 식을 그대로 쓴다: $a^n = a \times a \times \cdots \times a$ ($a$를 $n$번 곱한다)
2. 값을 대입한다: $2^4 = 2 \times 2 \times 2 \times 2$
3. 앞에서부터 곱한다: $2 \times 2 = 4$, $4 \times 2 = 8$, $8 \times 2 = 16$ 이므로 $2^4 = 16$
4. 둘째. 어떤 수든 0번 곱하면 1이 남는다: $5^0 = 1$
5. 셋째. 식을 그대로 쓴다: $a^{-n} = \frac{1}{a^n}$
6. 값을 대입한다: $2^{-3} = \frac{1}{2^3}$
7. 분모의 거듭제곱을 한다: $2^3 = 2 \times 2 \times 2 = 8$ 이므로 $2^{-3} = \frac{1}{8}$
8. 나눗셈을 한다: $1 \div 8 = 0.125$

**답**: $2^4 = 16$, $5^0 = 1$, $2^{-3} = 0.125$

</details>

### 문제 2
[지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98) 규칙 "같은 밑끼리 곱하면 지수끼리 더한다"를 $2^2 \times 2^3$으로 확인하라. 곱을 직접 계산한 값과 $2^5$를 비교한다.

<details><summary>풀이와 답</summary>

**주어진 값**
- $2^2$ (밑 2, [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98) 2)
- $2^3$ (밑 2, [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98) 3)

**풀이**
1. 규칙을 그대로 쓴다: $a^m \times a^n = a^{m+n}$
2. 값을 대입한다: $2^2 \times 2^3 = 2^{2+3}$
3. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 더한다: $2 + 3 = 5$ 이므로 $2^2 \times 2^3 = 2^5$
4. 오른쪽을 계산한다: $2^5 = 2 \times 2 \times 2 \times 2 \times 2 = 32$
5. 왼쪽을 직접 계산한다. 각 거듭제곱을 먼저 구한다: $2^2 = 4$, $2^3 = 8$ 이므로 $4 \times 8$
6. 곱셈을 한다: $4 \times 8 = 32$
7. 두 값을 비교한다: 32 = 32 로 같다.

**답**: $2^2 \times 2^3 = 32 = 2^5$ (지수끼리 더한 것과 같다)

</details>

### 문제 3
$e \approx 2.7183$일 때 $e^{-1}$의 값을 구하라. (소수 넷째 자리까지)

<details><summary>풀이와 답</summary>

**주어진 값**
- $e \approx 2.7183$ (자연상수, 밑)
- $x = 1$ ([지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98). 구할 것은 $e^{-1}$이다)

**풀이**
1. 식을 그대로 쓴다: $e^{-x} = \frac{1}{e^x}$
2. 값을 대입한다: $e^{-1} = \frac{1}{e^1}$
3. $e^1$은 e 자신이다: $e^1 = 2.7183$ 이므로 $e^{-1} = \frac{1}{2.7183}$
4. 나눗셈을 한다: $1 \div 2.7183 = 0.3679$

**답**: $e^{-1} = 0.3679$ (양수이고 1보다 작다)

</details>

### 문제 4
[시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C) $\sigma(z) = \frac{1}{1 + e^{-z}}$에 $z = -2$를 넣은 값은? ($e^2 \approx 7.3891$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $z = -2$ (입력 점수)
- $e^2 \approx 7.3891$ ($e$를 2번 곱한 값)

**풀이**
1. 식을 그대로 쓴다: $\sigma(z) = \frac{1}{1 + e^{-z}}$
2. 값을 대입한다: $\sigma(-2) = \frac{1}{1 + e^{-(-2)}}$
3. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)의 부호를 정리한다: $-(-2) = 2$ 이므로 $\frac{1}{1 + e^{2}}$
4. $e^2$의 값을 넣는다: $\frac{1}{1 + 7.3891}$
5. 분모의 덧셈을 한다: $1 + 7.3891 = 8.3891$ 이므로 $\frac{1}{8.3891}$
6. 나눗셈을 한다: $1 \div 8.3891 = 0.1192$

**답**: $\sigma(-2) = 0.1192$ (음수 점수는 0.5보다 작은 값이 된다)

</details>

### 문제 5
은행에 1원을 이자율 100%로 1년 맡긴다. 이자를 1년에 $k$번 나눠 붙이면 1년 뒤 금액은 $\left(1 + \frac{1}{k}\right)^k$이다. $k = 2$와 $k = 4$일 때 1년 뒤 금액을 구하고, $e \approx 2.718$과 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 식 $\left(1 + \frac{1}{k}\right)^k$ (나눠 붙이는 횟수 $k$)
- $k = 2$ (반년마다), $k = 4$ (석 달마다)

**풀이**
1. 식을 그대로 쓴다: $\left(1 + \frac{1}{k}\right)^k$
2. $k = 2$를 대입한다: $\left(1 + \frac{1}{2}\right)^2$
3. 괄호 안을 계산한다: $1 + \frac{1}{2} = 1.5$ 이므로 $1.5^2$
4. 제곱을 한다: $1.5 \times 1.5 = 2.25$
5. $k = 4$를 대입한다: $\left(1 + \frac{1}{4}\right)^4$
6. 괄호 안을 계산한다: $1 + \frac{1}{4} = 1.25$ 이므로 $1.25^4$
7. 4번 곱한다. 앞에서부터 곱한다: $1.25 \times 1.25 = 1.5625$
8. 다음 곱셈을 한다: $1.5625 \times 1.25 = 1.953125$
9. 마지막 곱셈을 한다: $1.953125 \times 1.25 = 2.44140625$, 소수 넷째 자리까지 쓰면 2.4414
10. $e \approx 2.718$과 비교한다: 2.25 → 2.4414 로 횟수가 늘수록 커지지만 2.718을 넘지 않는다.

**답**: $k = 2$이면 2.25원, $k = 4$이면 약 2.4414원. 횟수를 늘릴수록 $e \approx 2.718$에 다가간다.

</details>

### 문제 6
[시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C)에 $z = 2$와 $z = -2$를 넣은 값을 각각 구해 더하면 얼마인가? ($e^{-2} \approx 0.1353$, $e^{2} \approx 7.3891$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $z = 2$, $z = -2$ (입력 점수)
- $e^{-2} \approx 0.1353$, $e^{2} \approx 7.3891$

**풀이**
1. 식을 그대로 쓴다: $\sigma(z) = \frac{1}{1 + e^{-z}}$
2. $z = 2$를 대입한다: $\sigma(2) = \frac{1}{1 + e^{-2}} = \frac{1}{1 + 0.1353}$
3. 분모의 덧셈을 한다: $1 + 0.1353 = 1.1353$ 이므로 $\frac{1}{1.1353}$
4. 나눗셈을 한다: $1 \div 1.1353 = 0.8808$ 이므로 $\sigma(2) = 0.8808$
5. $z = -2$를 대입한다: $\sigma(-2) = \frac{1}{1 + e^{2}} = \frac{1}{1 + 7.3891}$
6. 분모의 덧셈을 한다: $1 + 7.3891 = 8.3891$ 이므로 $\frac{1}{8.3891}$
7. 나눗셈을 한다: $1 \div 8.3891 = 0.1192$ 이므로 $\sigma(-2) = 0.1192$
8. 두 값을 더한다: $0.8808 + 0.1192 = 1.0000$

**답**: $\sigma(2) = 0.8808$, $\sigma(-2) = 0.1192$, 합은 1. 부호만 반대인 두 점수의 [시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C)는 합이 1이다.

</details>

### 문제 7
$e^2 \approx 7.3891$, $e^3 \approx 20.0855$이다. x가 2에서 3으로 1 늘면 $e^x$는 몇 배가 되는가? 이 값은 무엇과 같은가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $e^2 = 7.3891$ (x = 2일 때)
- $e^3 = 20.0855$ (x = 3일 때)

**풀이**
1. 몇 배인지는 나눗셈으로 구한다. 식을 쓴다: $\text{배수} = \frac{e^3}{e^2}$
2. 값을 대입한다: $\text{배수} = \frac{20.0855}{7.3891}$
3. 나눗셈을 한다: $20.0855 \div 7.3891 = 2.7183$
4. 규칙으로 확인한다. 같은 밑의 나눗셈은 [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 뺀다: $\frac{e^3}{e^2} = e^{3-2} = e^1 = e \approx 2.7183$

**답**: 약 2.7183배. 이것은 $e$ 자신이다 (x가 1 늘 때마다 $e^x$는 $e$배가 된다)

</details>

### 문제 8
점수 $[1002, 1000]$을 [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)에 넣으려 한다. $e^{1002}$는 컴퓨터가 담을 수 없을 만큼 커서 넘친다(오버플로). 점수에서 가장 큰 값 1002를 먼저 빼서 계산하면 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은? ($e^2 \approx 7.3891$)

<details><summary>풀이와 답</summary>

**주어진 값**
- 점수 $z_1 = 1002$, $z_2 = 1000$
- 가장 큰 값 $1002$ (모든 점수에서 뺄 값)
- $e^2 \approx 7.3891$, $e^0 = 1$

**풀이**
1. 가장 큰 값을 뺀다: $1002 - 1002 = 0$, $1000 - 1002 = -2$ 이므로 새 점수는 $[0, -2]$
2. 식을 그대로 쓴다: $p_k = \frac{e^{z_k}}{\sum_j e^{z_j}}$ ([소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4))
3. 값을 대입한다(Σ는 j = 1, 2 두 항): $p_1 = \frac{e^{0}}{e^{0} + e^{-2}}$
4. 분자와 분모를 $e^2$배 해서 음수 [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 없앤다: $p_1 = \frac{e^{0} \times e^{2}}{(e^{0} + e^{-2}) \times e^{2}} = \frac{e^{2}}{e^{2} + e^{0}}$
5. 값을 넣는다: $p_1 = \frac{7.3891}{7.3891 + 1}$
6. 분모의 덧셈을 한다: $7.3891 + 1 = 8.3891$ 이므로 $\frac{7.3891}{8.3891}$
7. 나눗셈을 한다: $7.3891 \div 8.3891 = 0.8808$ 이므로 $p_1 = 0.8808$
8. 합이 1이므로 $p_2 = 1 - 0.8808 = 0.1192$

**답**: $p = (0.8808,\ 0.1192)$. 최댓값을 빼도 비율이 같아서 결과가 같고, 넘침을 피한다.

</details>

### 문제 9
[Lec01 5.6](../../Lec01_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%86%8C%EA%B0%9C.md#56-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4%EC%99%80-%EA%B5%90%EC%B0%A8-%EC%97%94%ED%8A%B8%EB%A1%9C%ED%94%BC-%EC%86%90%EC%8B%A4)의 [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4) $p_k = \frac{e^{z_k}}{\sum_j e^{z_j}}$에서 범주 3개의 점수가 $z = (3, 1, 0)$일 때 $p_1, p_2, p_3$을 구하라. ($e^3 \approx 20.0855$, $e^1 \approx 2.7183$, $e^0 = 1$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $z_1 = 3$, $z_2 = 1$, $z_3 = 0$ (범주별 점수)
- $e^3 = 20.0855$, $e^1 = 2.7183$, $e^0 = 1$ ($e$를 $z$번 곱한 값)

**풀이**
1. 식을 그대로 쓴다: $p_k = \frac{e^{z_k}}{\sum_j e^{z_j}}$
2. 값을 대입한다(Σ는 j = 1, 2, 3 세 항으로 펼친다): $p_1 = \frac{e^{3}}{e^{3} + e^{1} + e^{0}}$
3. $e$의 값을 넣는다: $p_1 = \frac{20.0855}{20.0855 + 2.7183 + 1}$
4. 분모를 더한다: $20.0855 + 2.7183 = 22.8038$, $22.8038 + 1 = 23.8038$ 이므로 $p_1 = \frac{20.0855}{23.8038}$
5. 나눗셈을 한다: $20.0855 \div 23.8038 = 0.8438$
6. $p_2$도 같은 분모를 쓴다: $p_2 = \frac{e^{1}}{23.8038} = \frac{2.7183}{23.8038}$, 나눗셈을 하면 $0.1142$
7. $p_3$도 같다: $p_3 = \frac{e^{0}}{23.8038} = \frac{1}{23.8038}$, 나눗셈을 하면 $0.0420$
8. 합을 확인한다: $0.8438 + 0.1142 + 0.0420 = 1.0000$

**답**: $p = (0.8438,\ 0.1142,\ 0.0420)$. 점수가 가장 큰 범주가 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)도 가장 크고 합은 1이다.

</details>

### 문제 10
[Lec14 6.1](../../Lec14_%EC%83%9D%EC%84%B1_%EB%AA%A8%EB%8D%B8_%EA%B8%B0%EC%B4%88.md#61-%EB%B3%BC%EC%B8%A0%EB%A7%8C-%EB%B6%84%ED%8F%AC%EC%99%80-%EC%97%90%EB%84%88%EC%A7%80-%EB%B9%84%EC%9C%A8)의 [볼츠만 분포](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#boltzmann-distribution-%EB%B3%BC%EC%B8%A0%EB%A7%8C-%EB%B6%84%ED%8F%AC) $p(x) = \frac{e^{-E(x)}}{Z}$, $Z = \sum_x e^{-E(x)}$에서 상태가 둘뿐이고 에너지가 $E(x_1) = 1$, $E(x_2) = 3$이다. 두 상태의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)과, $Z$를 몰라도 구할 수 있는 비율 $p(x_1) / p(x_2)$를 구하라. ($e^{-1} \approx 0.3679$, $e^{-3} \approx 0.0498$, $e^{2} \approx 7.3891$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $E(x_1) = 1$, $E(x_2) = 3$ (에너지)
- $e^{-1} = 0.3679$, $e^{-3} = 0.0498$, $e^{2} = 7.3891$

**풀이**
1. 식을 그대로 쓴다: $p(x) = \frac{e^{-E(x)}}{Z}$, $Z = \sum_x e^{-E(x)}$
2. $Z$를 먼저 구한다. 값을 대입한다(Σ는 두 상태의 항): $Z = e^{-1} + e^{-3}$
3. $e$의 값을 넣는다: $Z = 0.3679 + 0.0498$
4. 덧셈을 한다: $0.3679 + 0.0498 = 0.4177$
5. 첫째 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구한다: $p(x_1) = \frac{e^{-1}}{Z} = \frac{0.3679}{0.4177}$
6. 나눗셈을 한다: $0.3679 \div 0.4177 = 0.8808$
7. 둘째 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구한다: $p(x_2) = \frac{e^{-3}}{Z} = \frac{0.0498}{0.4177}$, 나눗셈을 하면 $0.1192$
8. 비율을 구한다. 식을 쓴다: $\frac{p(x_1)}{p(x_2)} = \frac{e^{-1}/Z}{e^{-3}/Z} = \frac{e^{-1}}{e^{-3}}$ ($Z$가 약분되어 사라진다)
9. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 뺀다: $\frac{e^{-1}}{e^{-3}} = e^{-1-(-3)} = e^{2}$
10. 값을 넣는다: $e^{2} = 7.3891$

**답**: $p(x_1) = 0.8808$, $p(x_2) = 0.1192$, 비율 $p(x_1) / p(x_2) = e^{2} \approx 7.3891$ (에너지 차이 2만으로 정해지고 $Z$는 필요 없다)
