# 예제: 활성화 함수의 미분

개념 노트: [MM05_활성화_함수의_미분](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/05_%EC%8B%A0%EA%B2%BD%EB%A7%9D%EC%9D%98_%EA%B3%84%EC%82%B0/MM05_%ED%99%9C%EC%84%B1%ED%99%94_%ED%95%A8%EC%88%98%EC%9D%98_%EB%AF%B8%EB%B6%84.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 쓰는 식은 세 가지다: [시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C) $\sigma(z) = \frac{1}{1 + e^{-z}}$ 의 도함수 $\sigma'(z) = \sigma(z)(1 - \sigma(z))$, [tanh](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#tanh-%EC%8C%8D%EA%B3%A1%ED%83%84%EC%A0%A0%ED%8A%B8)의 도함수 $\tanh' z = 1 - \tanh^2 z$, [ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8) $\max(0, z)$의 도함수(z > 0이면 1, z < 0이면 0). e는 약 2.718이고, $e^{z}$ 값은 계산기나 `np.exp`로 구한다.

## 기본 (직접 대입)

### 문제 1

$z = 0$에서 [시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C)의 값 $\sigma(0)$과 도함수 $\sigma'(0)$을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $z = 0$ (입력)

**풀이**
1. 식을 그대로 쓴다: $\sigma(z) = \frac{1}{1 + e^{-z}}$
2. 값을 대입한다: $\sigma(0) = \frac{1}{1 + e^{-0}}$
3. e의 거듭제곱을 구한다 (e를 0번 곱한 값은 1): $e^{0} = 1$ 이므로 $\sigma(0) = \frac{1}{1 + 1}$
4. 분모를 더한다: 1 + 1 = 2 이므로 $\sigma(0) = \frac{1}{2}$
5. 나눗셈을 한다: 1 ÷ 2 = 0.5 이므로 $\sigma(0) = 0.5$
6. 도함수 식을 쓴다: $\sigma'(z) = \sigma(z)(1 - \sigma(z))$
7. 값을 대입한다: $\sigma'(0) = 0.5 \times (1 - 0.5)$
8. 괄호를 계산한다: 1 − 0.5 = 0.5 이므로 $\sigma'(0) = 0.5 \times 0.5$
9. 곱셈을 한다: 0.5 × 0.5 = 0.25 이므로 $\sigma'(0) = 0.25$

**답**: $\sigma(0) = 0.5$, $\sigma'(0) = 0.25$ ([시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C) 도함수의 최댓값)

</details>

### 문제 2

[tanh](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#tanh-%EC%8C%8D%EA%B3%A1%ED%83%84%EC%A0%A0%ED%8A%B8)의 도함수 $\tanh' z = 1 - \tanh^2 z$를 $z = 0$과 $z = 1$에서 구하라. ($\tanh 0 = 0$, $\tanh 1 = 0.7616$이다.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $\tanh 0 = 0$ ($z = 0$일 때 [tanh](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#tanh-%EC%8C%8D%EA%B3%A1%ED%83%84%EC%A0%A0%ED%8A%B8) 값)
- $\tanh 1 = 0.7616$ ($z = 1$일 때 [tanh](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#tanh-%EC%8C%8D%EA%B3%A1%ED%83%84%EC%A0%A0%ED%8A%B8) 값, 계산기로 구한 값)

**풀이**
1. 식을 그대로 쓴다: $\tanh' z = 1 - \tanh^2 z$
2. $z = 0$을 대입한다: $\tanh' 0 = 1 - 0^2$
3. 제곱한다: 0² = 0 이므로 $\tanh' 0 = 1 - 0$
4. 뺄셈을 한다: 1 − 0 = 1 이므로 $\tanh' 0 = 1$
5. $z = 1$을 대입한다: $\tanh' 1 = 1 - 0.7616^2$
6. 제곱한다: 0.7616 × 0.7616 = 0.5800 이므로 $\tanh' 1 = 1 - 0.5800$
7. 뺄셈을 한다: 1 − 0.5800 = 0.4200 이므로 $\tanh' 1 = 0.4200$

**답**: $\tanh' 0 = 1$, $\tanh' 1 = 0.4200$

</details>

### 문제 3

[ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8) $g(z) = \max(0, z)$의 값과 도함수 $g'(z)$를 $z = -2$, $0.5$, $3$에서 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $z = -2$, $0.5$, $3$ (입력 세 개)
- $g'(z) = 1$ ($z > 0$), $g'(z) = 0$ ($z < 0$)

**풀이**
1. 식을 그대로 쓴다: $g(z) = \max(0, z)$ (0과 z 중 큰 값)
2. $z = -2$를 대입한다: $g(-2) = \max(0, -2)$ = 0 (0이 더 크다), 음수이므로 $g'(-2) = 0$
3. $z = 0.5$를 대입한다: $g(0.5) = \max(0, 0.5)$ = 0.5 (0.5가 더 크다), 양수이므로 $g'(0.5) = 1$
4. $z = 3$을 대입한다: $g(3) = \max(0, 3)$ = 3 (3이 더 크다), 양수이므로 $g'(3) = 1$

**답**: $z = -2$: 값 0, 도함수 0 / $z = 0.5$: 값 0.5, 도함수 1 / $z = 3$: 값 3, 도함수 1

</details>

### 문제 4

[시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C)의 도함수 $\sigma'(2)$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $z = 2$ (입력)

**풀이**
1. $\sigma(2)$의 식을 쓴다: $\sigma(z) = \frac{1}{1 + e^{-z}}$
2. 값을 대입한다: $\sigma(2) = \frac{1}{1 + e^{-2}}$
3. e의 음수 거듭제곱을 구한다 (1을 $e^2 = 7.3891$로 나눈다): $e^{-2} = 0.1353$ 이므로 $\sigma(2) = \frac{1}{1 + 0.1353}$
4. 분모를 더한다: 1 + 0.1353 = 1.1353 이므로 $\sigma(2) = \frac{1}{1.1353}$
5. 나눗셈을 한다: 1 ÷ 1.1353 = 0.8808 이므로 $\sigma(2) = 0.8808$
6. 도함수 식을 쓴다: $\sigma'(z) = \sigma(z)(1 - \sigma(z))$
7. 값을 대입한다: $\sigma'(2) = 0.8808 \times (1 - 0.8808)$
8. 괄호를 계산한다: 1 − 0.8808 = 0.1192 이므로 $\sigma'(2) = 0.8808 \times 0.1192$
9. 곱셈을 한다: 0.8808 × 0.1192 = 0.1050 이므로 $\sigma'(2) = 0.1050$

**답**: $\sigma'(2) = 0.1050$ (최댓값 0.25의 절반이 안 된다)

</details>

[시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C)의 도함수 $\sigma'(-4)$를 구하라. 입력이 아주 작은 쪽(음수)에서 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 어떻게 되는지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $z = -4$ (입력)

**풀이**
1. $\sigma(-4)$의 식을 쓴다: $\sigma(z) = \frac{1}{1 + e^{-z}}$
2. 값을 대입한다: $\sigma(-4) = \frac{1}{1 + e^{-(-4)}}$
3. 부호를 정리한다: −(−4) = 4 이므로 $\sigma(-4) = \frac{1}{1 + e^{4}}$
4. e의 거듭제곱을 구한다 (e를 네 번 곱한 값): $e^{4} = 54.5982$ 이므로 $\sigma(-4) = \frac{1}{1 + 54.5982}$
5. 분모를 더한다: 1 + 54.5982 = 55.5982 이므로 $\sigma(-4) = \frac{1}{55.5982}$
6. 나눗셈을 한다: 1 ÷ 55.5982 = 0.0180 이므로 $\sigma(-4) = 0.0180$
7. 도함수 식을 쓴다: $\sigma'(z) = \sigma(z)(1 - \sigma(z))$
8. 값을 대입한다: $\sigma'(-4) = 0.0180 \times (1 - 0.0180)$
9. 괄호를 계산한다: 1 − 0.0180 = 0.9820 이므로 $\sigma'(-4) = 0.0180 \times 0.9820$
10. 곱셈을 한다: 0.0180 × 0.9820 = 0.0177 이므로 $\sigma'(-4) = 0.0177$

**답**: $\sigma'(-4) = 0.0177$ (최댓값 0.25의 약 14분의 1. 포화되어 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 거의 사라진다)

<details><summary>풀이와 답</summary>

**주어진 값**
- [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5) 5개 (도함수가 5번 곱해진다)
- [시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C)의 도함수 최댓값 = 0.25
- [ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8)의 도함수 = 1 (양수 쪽)

**풀이**
1. 식을 그대로 쓴다: $\text{전달 배율} = g'(z_1) \times g'(z_2) \times g'(z_3) \times g'(z_4) \times g'(z_5)$
2. [시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C)에 값을 대입한다: $\text{전달 배율} = 0.25 \times 0.25 \times 0.25 \times 0.25 \times 0.25$
3. 앞의 둘을 곱한다: 0.25 × 0.25 = 0.0625 이므로 $0.0625 \times 0.25 \times 0.25 \times 0.25$
4. 이어서 곱한다: 0.0625 × 0.25 = 0.015625 이므로 $0.015625 \times 0.25 \times 0.25$
5. 이어서 곱한다: 0.015625 × 0.25 = 0.00390625 이므로 $0.00390625 \times 0.25$
6. 마지막으로 곱한다: 0.00390625 × 0.25 = 0.0009765625 이므로 [시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C)의 배율은 약 0.00098
7. [ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8)에 값을 대입한다: $\text{전달 배율} = 1 \times 1 \times 1 \times 1 \times 1$
8. 곱셈을 한다: 1을 몇 번 곱해도 1

**답**: [시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C) 약 0.00098 (약 1000분의 1), [ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8) 1 (줄지 않는다)

### 문제 7

$\tanh z = 2\sigma(2z) - 1$을 이용해 $z = 0.5$에서 $\tanh 0.5$를 구하고, 도함수 $\tanh' 0.5 = 1 - \tanh^2 0.5$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $z = 0.5$ (입력)
- $\tanh z = 2\sigma(2z) - 1$ ([tanh](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#tanh-%EC%8C%8D%EA%B3%A1%ED%83%84%EC%A0%A0%ED%8A%B8)와 [시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C)의 관계)

**풀이**
1. 식을 그대로 쓴다: $\tanh z = 2\sigma(2z) - 1$
2. 값을 대입한다: $\tanh 0.5 = 2\sigma(2 \times 0.5) - 1$
3. 괄호 속 곱셈을 한다: 2 × 0.5 = 1 이므로 $\tanh 0.5 = 2\sigma(1) - 1$
4. $\sigma(1)$을 구한다: $\sigma(1) = \frac{1}{1 + e^{-1}}$, $e^{-1} = 0.3679$ 이므로 $\frac{1}{1 + 0.3679} = \frac{1}{1.3679} = 0.7311$
5. 대입한다: $\tanh 0.5 = 2 \times 0.7311 - 1$
6. 곱셈을 한다: 2 × 0.7311 = 1.4622 이므로 $\tanh 0.5 = 1.4622 - 1$
7. 뺄셈을 한다: 1.4622 − 1 = 0.4622 이므로 $\tanh 0.5 = 0.4622$
8. 도함수 식을 쓰고 대입한다: $\tanh' 0.5 = 1 - 0.4622^2$
9. 제곱한다: 0.4622 × 0.4622 = 0.2136 이므로 $\tanh' 0.5 = 1 - 0.2136$
10. 뺄셈을 한다: 1 − 0.2136 = 0.7864 이므로 $\tanh' 0.5 = 0.7864$

**답**: $\tanh 0.5 = 0.4622$, $\tanh' 0.5 = 0.7864$

</details>

### 문제 8

$z = 1$에서 [시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C) 도함수 $\sigma'(1)$과 [tanh](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#tanh-%EC%8C%8D%EA%B3%A1%ED%83%84%EC%A0%A0%ED%8A%B8) 도함수 $\tanh' 1$ 중 어느 쪽이 큰가? 몇 배인가? ($\sigma(1) = 0.7311$, $\tanh' 1 = 0.4200$은 앞의 문제들에서 구했다.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $\sigma(1) = 0.7311$ ([시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C) 값)
- $\tanh' 1 = 0.4200$ ([tanh](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#tanh-%EC%8C%8D%EA%B3%A1%ED%83%84%EC%A0%A0%ED%8A%B8) 도함수, 문제 2)

**풀이**
1. [시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C) 도함수 식을 쓴다: $\sigma'(z) = \sigma(z)(1 - \sigma(z))$
2. 값을 대입한다: $\sigma'(1) = 0.7311 \times (1 - 0.7311)$
3. 괄호를 계산한다: 1 − 0.7311 = 0.2689 이므로 $\sigma'(1) = 0.7311 \times 0.2689$
4. 곱셈을 한다: 0.7311 × 0.2689 = 0.1966 이므로 $\sigma'(1) = 0.1966$
5. 비교한다: 0.4200 > 0.1966 이므로 [tanh](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#tanh-%EC%8C%8D%EA%B3%A1%ED%83%84%EC%A0%A0%ED%8A%B8) 쪽이 크다.
6. 배수를 구한다: 0.4200 ÷ 0.1966 = 2.14

**답**: $\sigma'(1) = 0.1966$, $\tanh' 1 = 0.4200$ 이므로 [tanh](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#tanh-%EC%8C%8D%EA%B3%A1%ED%83%84%EC%A0%A0%ED%8A%B8)의 도함수가 약 2.1배 크다 ([tanh](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#tanh-%EC%8C%8D%EA%B3%A1%ED%83%84%EC%A0%A0%ED%8A%B8)가 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)를 더 잘 전달한다)

[시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C) 두 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)을 지나는데 뒤에서 온 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)가 2이고, 첫째 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)의 $z_1 = 0$ ($\sigma'(0) = 0.25$), 둘째 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)의 $z_2 = 1$ ($\sigma'(1) = 0.1966$)이다. 전달 배율과 앞쪽에 도착하는 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**

- $\sigma'(z_1) = 0.25$ (첫째 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)의 도함수)

**풀이**
1. 식을 그대로 쓴다: $\text{도착 오차} = \text{오차} \times \sigma'(z_2) \times \sigma'(z_1)$

4. [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)를 곱한다: 2 × 0.04915 = 0.0983 이므로 $\text{도착 오차} = 0.0983$

**답**: 전달 배율 0.04915, 도착 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 0.0983 (2였던 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)가 약 20분의 1로 줄었다)

### 문제 10

[Lec10 3.2](../../Lec10_%EA%B8%B0%EC%96%B5%EA%B3%BC_%EC%8B%9C%ED%80%80%EC%8A%A4.md#32-%EA%B0%80%EC%9E%A5-%EB%8B%A8%EC%88%9C%ED%95%9C-rnn)의 단순한 [RNN](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#rnn-recurrent-neural-network-%EC%88%9C%ED%99%98-%EC%8B%A0%EA%B2%BD%EB%A7%9D)은 같은 [활성화 함수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#activation-function-%ED%99%9C%EC%84%B1%ED%99%94-%ED%95%A8%EC%88%98)를 시간 단계마다 되풀이해 통과시킨다. 매 단계의 [tanh](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#tanh-%EC%8C%8D%EA%B3%A1%ED%83%84%EC%A0%A0%ED%8A%B8) 도함수가 0.42 ($\tanh' 1$ 근처의 값)라면 5단계를 거친 전달 배율은 얼마인가?

<details><summary>풀이와 답</summary>

**주어진 값**
- 단계 수 = 5 (도함수가 5번 곱해진다)
- 매 단계의 도함수 = 0.42

**풀이**
1. 식을 그대로 쓴다: $\text{전달 배율} = g' \times g' \times g' \times g' \times g'$ (같은 값이 5번 곱해진다)
2. 값을 대입한다: $\text{전달 배율} = 0.42 \times 0.42 \times 0.42 \times 0.42 \times 0.42$
3. 앞의 둘을 곱한다: 0.42 × 0.42 = 0.1764 이므로 $0.1764 \times 0.42 \times 0.42 \times 0.42$
4. 이어서 곱한다: 0.1764 × 0.42 = 0.0741 이므로 $0.0741 \times 0.42 \times 0.42$
5. 이어서 곱한다: 0.0741 × 0.42 = 0.0311 이므로 $0.0311 \times 0.42$
6. 마지막으로 곱한다: 0.0311 × 0.42 = 0.0131 이므로 $\text{전달 배율} = 0.0131$

**답**: 약 0.0131 (5단계 만에 약 76분의 1로 줄어든다. 단계가 길수록 [기울기 소실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#vanishing-gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0-%EC%86%8C%EC%8B%A4)이 심해진다)

</details>
