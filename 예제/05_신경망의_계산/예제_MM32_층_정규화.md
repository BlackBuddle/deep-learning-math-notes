## 기본 (직접 대입)

### 문제 1

[토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) $\mathbf{x} = (1, 3, 5, 7)$의 평균 $\mu$와 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $\sigma^2$을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{x} = (1, 3, 5, 7)$ ([토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 벡터)
- $d = 4$ (칸 수)

**풀이**
1. 식을 그대로 쓴다: $\mu = \dfrac{1}{d}\sum_{k=1}^{d} x_k$, $\sigma^2 = \dfrac{1}{d}\sum_{k=1}^{d}(x_k - \mu)^2$
2. 평균에 대입한다: $\mu = \dfrac{1}{4}(1 + 3 + 5 + 7)$
3. 덧셈을 한다 ($\sum$은 모든 칸을 차례로 더한다는 뜻): $1 + 3 + 5 + 7 = 16$ 이므로 $\mu = \dfrac{1}{4} \times 16$
4. 나눗셈을 한다: $\mu = 16 \div 4 = 4$
5. [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)에 대입한다: $\sigma^2 = \dfrac{1}{4}\big((1 - 4)^2 + (3 - 4)^2 + (5 - 4)^2 + (7 - 4)^2\big)$
6. 괄호 안 뺄셈을 한다: $1 - 4 = -3$, $3 - 4 = -1$, $5 - 4 = 1$, $7 - 4 = 3$ 이므로 $\dfrac{1}{4}\big((-3)^2 + (-1)^2 + 1^2 + 3^2\big)$
7. 제곱을 한다: $(-3)^2 = 9$, $(-1)^2 = 1$, $1^2 = 1$, $3^2 = 9$ 이므로 $\dfrac{1}{4}(9 + 1 + 1 + 9)$
8. 덧셈을 한다: $9 + 1 + 1 + 9 = 20$ 이므로 $\dfrac{1}{4} \times 20$
9. 나눗셈을 한다: $\sigma^2 = 20 \div 4 = 5$

**답**: $\mu = 4$, $\sigma^2 = 5$

</details>

### 문제 2

[토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) $\mathbf{x} = (4, 8)$를 $\gamma = 1$, $\beta = 0$, $\epsilon = 0.00001$로 층 정규화하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{x} = (4, 8)$ (정규화할 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0), 칸 2개)
- $\gamma = 1$, $\beta = 0$ (배율과 이동, 그대로 두는 값)
- $\epsilon = 0.00001$ (0으로 나누기를 막는 작은 수)

**풀이**
1. 식을 그대로 쓴다: $\text{LN}(\mathbf{x})_k = \gamma\,\dfrac{x_k - \mu}{\sqrt{\sigma^2 + \epsilon}} + \beta$
2. 평균을 구한다: $\mu = \dfrac{1}{2}(4 + 8) = \dfrac{12}{2} = 6$
3. 칸마다 평균을 뺀다: $(4 - 6,\ 8 - 6) = (-2, 2)$
4. [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 구한다 (제곱의 평균): $\sigma^2 = \dfrac{1}{2}\big((-2)^2 + 2^2\big) = \dfrac{1}{2}(4 + 4) = 4$
5. 값을 대입한다: $\text{LN}(\mathbf{x})_k = 1 \times \dfrac{x_k - 6}{\sqrt{4 + 0.00001}} + 0$
6. $\epsilon$을 더한다: $4 + 0.00001 = 4.00001$
7. $\sqrt{\ }$의 뜻: 제곱하면 그 수가 되는 양수다 (코드 `np.sqrt`). $\sqrt{4.00001} = 2.0000$ (소수 넷째 자리까지)
8. 칸마다 나눗셈을 한다: $-2 \div 2.0000 = -1$, $2 \div 2.0000 = 1$
9. 배율 1을 곱하고 이동 0을 더한다: $1 \times (-1) + 0 = -1$, $1 \times 1 + 0 = 1$

**답**: $\text{LN}(\mathbf{x}) = (-1, 1)$

</details>

### 문제 3

정규화한 값이 $\hat{\mathbf{x}} = (-1, 1)$이고 학습된 배율 $\gamma = 3$, 이동 $\beta = 2$일 때 [층 정규화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-normalization-%EC%B8%B5-%EC%A0%95%EA%B7%9C%ED%99%94)의 최종 출력을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\hat{\mathbf{x}} = (-1, 1)$ (평균을 빼고 표준편차로 나눈 값)
- $\gamma = 3$ (배율), $\beta = 2$ (이동)

**풀이**
1. 식을 그대로 쓴다: $\text{LN}(\mathbf{x})_k = \gamma\,\hat{x}_k + \beta$
2. 값을 대입한다: $\text{LN}(\mathbf{x}) = \big(3 \times (-1) + 2,\ 3 \times 1 + 2\big)$
3. 곱셈을 먼저 한다: $3 \times (-1) = -3$, $3 \times 1 = 3$ 이므로 $(-3 + 2,\ 3 + 2)$
4. 덧셈을 한다: $-3 + 2 = -1$, $3 + 2 = 5$

**답**: $\text{LN}(\mathbf{x}) = (-1, 5)$. 출력의 평균은 $\beta = 2$, 칸 사이의 폭은 $\gamma = 3$배가 된다

</details>

### 문제 4

[토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) $\mathbf{x} = (1, 7)$을 $\gamma = 1$, $\epsilon = 0.00001$로 [RMSNorm](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#rmsnorm-rms-%EC%A0%95%EA%B7%9C%ED%99%94) 하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{x} = (1, 7)$ ([토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0), 칸 2개)
- $d = 2$ (칸 수)
- $\gamma = 1$ (배율), $\epsilon = 0.00001$

**풀이**
1. 식을 그대로 쓴다: $\text{RMSNorm}(\mathbf{x})_k = \gamma\,\dfrac{x_k}{\sqrt{\frac{1}{d}\sum_{j=1}^{d} x_j^2 + \epsilon}}$
2. 값을 대입한다: $\text{RMSNorm}(\mathbf{x})_k = 1 \times \dfrac{x_k}{\sqrt{\frac{1}{2}(1^2 + 7^2) + 0.00001}}$
3. 제곱을 한다: $1^2 = 1$, $7^2 = 49$ 이므로 $\sqrt{\frac{1}{2}(1 + 49) + 0.00001}$
4. 덧셈과 나눗셈을 한다: $1 + 49 = 50$, $50 \div 2 = 25$ 이므로 $\sqrt{25 + 0.00001}$
5. $\epsilon$을 더하고 제곱근을 구한다: $25 + 0.00001 = 25.00001$, $\sqrt{25.00001} = 5.0000$
6. 칸마다 나눗셈을 한다: $1 \div 5 = 0.2$, $7 \div 5 = 1.4$
7. 배율 1을 곱한다: 값이 그대로다

**답**: $\text{RMSNorm}(\mathbf{x}) = (0.2, 1.4)$. 평균을 빼지 않았으므로 두 값이 모두 양수로 남는다

</details>

### 문제 5

[토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) $(1, 3, 5, 7)$과 그 10배인 $(10, 30, 50, 70)$을 각각 [층 정규화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-normalization-%EC%B8%B5-%EC%A0%95%EA%B7%9C%ED%99%94)($\gamma = 1$, $\beta = 0$, $\epsilon = 0.00001$)하여 결과가 같은지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{a} = (1, 3, 5, 7)$ (원래 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)), $\mathbf{b} = (10, 30, 50, 70)$ (10배 한 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0))
- $d = 4$, $\epsilon = 0.00001$

**풀이**
1. 식을 그대로 쓴다: $\text{LN}(\mathbf{x})_k = \dfrac{x_k - \mu}{\sqrt{\sigma^2 + \epsilon}}$ ($\gamma = 1$, $\beta = 0$)
2. $\mathbf{a}$의 평균과 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 구한다: $\mu_a = (1 + 3 + 5 + 7) \div 4 = 4$, $\sigma_a^2 = \dfrac{(-3)^2 + (-1)^2 + 1^2 + 3^2}{4} = \dfrac{20}{4} = 5$
3. $\mathbf{a}$의 분모를 구한다: $\sqrt{5 + 0.00001} = \sqrt{5.00001} = 2.2361$
4. $\mathbf{a}$의 칸마다 나눗셈을 한다: $-3 \div 2.2361 = -1.3416$, $-1 \div 2.2361 = -0.4472$, $1 \div 2.2361 = 0.4472$, $3 \div 2.2361 = 1.3416$
5. $\mathbf{b}$의 평균과 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 구한다: $\mu_b = (10 + 30 + 50 + 70) \div 4 = 40$, 차이 $(-30, -10, 10, 30)$, $\sigma_b^2 = \dfrac{900 + 100 + 100 + 900}{4} = \dfrac{2000}{4} = 500$
6. $\mathbf{b}$의 분모를 구한다: $\sqrt{500 + 0.00001} = 22.3607$
7. $\mathbf{b}$의 칸마다 나눗셈을 한다: $-30 \div 22.3607 = -1.3416$, $-10 \div 22.3607 = -0.4472$, $10 \div 22.3607 = 0.4472$, $30 \div 22.3607 = 1.3416$

**답**: 두 결과가 $(-1.3416, -0.4472, 0.4472, 1.3416)$으로 같다. 10배 하면 분자(차이)와 분모(표준편차)가 함께 10배가 되어 약분된다

</details>

### 문제 6

[토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)의 모든 칸이 같은 $\mathbf{x} = (5, 5, 5)$를 [층 정규화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-normalization-%EC%B8%B5-%EC%A0%95%EA%B7%9C%ED%99%94)($\epsilon = 0.00001$)하면 어떻게 되는지, 그리고 $\epsilon$이 없으면 무슨 일이 생기는지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{x} = (5, 5, 5)$ (칸이 모두 같은 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0))
- $d = 3$, $\gamma = 1$, $\beta = 0$, $\epsilon = 0.00001$

**풀이**
1. 식을 그대로 쓴다: $\text{LN}(\mathbf{x})_k = \dfrac{x_k - \mu}{\sqrt{\sigma^2 + \epsilon}}$
2. 평균을 구한다: $\mu = (5 + 5 + 5) \div 3 = 15 \div 3 = 5$
3. 칸마다 평균을 뺀다: $(5 - 5,\ 5 - 5,\ 5 - 5) = (0, 0, 0)$
4. [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 구한다: $\sigma^2 = \dfrac{0^2 + 0^2 + 0^2}{3} = 0$
5. 값을 대입한다: $\text{LN}(\mathbf{x})_k = \dfrac{0}{\sqrt{0 + 0.00001}}$
6. 분모를 구한다: $\sqrt{0.00001} = 0.0032$ (제곱하면 0.00001이 되는 양수)
7. 나눗셈을 한다: $0 \div 0.0032 = 0$ (세 칸 모두)
8. $\epsilon$이 없다면 분모가 $\sqrt{0} = 0$이라서 $0 \div 0$이 되어 계산이 깨진다

**답**: $\text{LN}(\mathbf{x}) = (0, 0, 0)$. $\epsilon$은 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)이 0일 때 0으로 나누는 것을 막는다

</details>

### 문제 7

[토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) $\mathbf{x} = (2, 4, 6, 8)$을 [층 정규화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-normalization-%EC%B8%B5-%EC%A0%95%EA%B7%9C%ED%99%94)($\gamma = 1$, $\beta = 0$, $\epsilon$은 영향이 없어 생략)하고, 결과의 평균이 0, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)이 1인지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{x} = (2, 4, 6, 8)$ ([토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0), 칸 4개)
- $d = 4$

**풀이**
1. 식을 그대로 쓴다: $\text{LN}(\mathbf{x})_k = \dfrac{x_k - \mu}{\sigma}$, $\sigma = \sqrt{\sigma^2}$
2. 평균을 구한다: $\mu = (2 + 4 + 6 + 8) \div 4 = 20 \div 4 = 5$
3. 칸마다 평균을 뺀다: $(2 - 5,\ 4 - 5,\ 6 - 5,\ 8 - 5) = (-3, -1, 1, 3)$
4. [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 구한다: $\sigma^2 = \dfrac{(-3)^2 + (-1)^2 + 1^2 + 3^2}{4} = \dfrac{9 + 1 + 1 + 9}{4} = \dfrac{20}{4} = 5$
5. 표준편차를 구한다: $\sigma = \sqrt{5} = 2.2361$ (제곱하면 5가 되는 양수)
6. 칸마다 나눗셈을 한다: $-3 \div 2.2361 = -1.3416$, $-1 \div 2.2361 = -0.4472$, $1 \div 2.2361 = 0.4472$, $3 \div 2.2361 = 1.3416$
7. 평균을 확인한다: $(-1.3416 - 0.4472 + 0.4472 + 1.3416) \div 4 = 0 \div 4 = 0$
8. [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 확인한다 (평균이 0이므로 제곱의 평균): $\dfrac{1.3416^2 + 0.4472^2 + 0.4472^2 + 1.3416^2}{4} = \dfrac{1.8 + 0.2 + 0.2 + 1.8}{4} = \dfrac{4}{4} = 1$

**답**: $\text{LN}(\mathbf{x}) = (-1.3416, -0.4472, 0.4472, 1.3416)$, 평균 0, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) 1

</details>

### 문제 8

[토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) $\mathbf{x} = (10, 12, 14)$를 (a) [층 정규화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-normalization-%EC%B8%B5-%EC%A0%95%EA%B7%9C%ED%99%94), (b) [RMSNorm](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#rmsnorm-rms-%EC%A0%95%EA%B7%9C%ED%99%94) 하라 ($\gamma = 1$, $\beta = 0$, $\epsilon$은 영향이 없어 생략). 어느 쪽 결과가 0을 중심으로 대칭인가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{x} = (10, 12, 14)$ ([토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0), 칸 3개)
- $d = 3$

**풀이**
1. (a) 평균을 구한다: $\mu = (10 + 12 + 14) \div 3 = 36 \div 3 = 12$
2. (a) 칸마다 평균을 뺀다: $(-2, 0, 2)$
3. (a) [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 구한다: $\sigma^2 = \dfrac{4 + 0 + 4}{3} = \dfrac{8}{3} = 2.6667$, 표준편차 $\sigma = \sqrt{2.6667} = 1.633$
4. (a) 나눗셈을 한다: $-2 \div 1.633 = -1.2247$, $0 \div 1.633 = 0$, $2 \div 1.633 = 1.2247$
5. (b) 식을 쓴다: $\text{RMSNorm}(\mathbf{x})_k = \dfrac{x_k}{\sqrt{\frac{1}{d}\sum_j x_j^2}}$
6. (b) 제곱의 평균을 구한다: $\dfrac{10^2 + 12^2 + 14^2}{3} = \dfrac{100 + 144 + 196}{3} = \dfrac{440}{3} = 146.6667$
7. (b) 제곱근을 구한다 (제곱하면 그 수가 되는 양수): $\sqrt{146.6667} = 12.1106$
8. (b) 나눗셈을 한다: $10 \div 12.1106 = 0.8257$, $12 \div 12.1106 = 0.9909$, $14 \div 12.1106 = 1.1560$

**답**: (a) [층 정규화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-normalization-%EC%B8%B5-%EC%A0%95%EA%B7%9C%ED%99%94)는 $(-1.2247, 0, 1.2247)$로 0을 중심으로 대칭이다. (b) [RMSNorm](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#rmsnorm-rms-%EC%A0%95%EA%B7%9C%ED%99%94)은 $(0.8257, 0.9909, 1.1560)$으로 평균을 빼지 않아 모두 양수로 남는다

</details>

### 문제 9

[Lec08 6.2](../../Lec08_%ED%8A%B8%EB%9E%9C%EC%8A%A4%ED%8F%AC%EB%A8%B8.md#62-vit-%EB%B8%94%EB%A1%9D-%EC%9E%94%EC%B0%A8-%EC%97%B0%EA%B2%B0%EA%B3%BC-%EC%B8%B5-%EC%A0%95%EA%B7%9C%ED%99%94)의 ViT 블록은 [어텐션](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#attention-%EC%96%B4%ED%85%90%EC%85%98)(또는 MLP) 앞에서 정규화한 뒤 그 결과를 잔차로 더한다. $y = \mathbf{x} + F\big(\text{LN}(\mathbf{x})\big)$에서 $\mathbf{x} = (2, 4, 6)$, 설명용 블록 $F(\mathbf{z}) = 2\mathbf{z}$, $\epsilon = 0.00001$일 때 $y$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{x} = (2, 4, 6)$ (블록 입력 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0))
- $F(\mathbf{z}) = 2\mathbf{z}$ (설명용으로 단순화한 블록, 칸마다 2배)
- $\gamma = 1$, $\beta = 0$, $\epsilon = 0.00001$

**풀이**
1. 식을 그대로 쓴다: $y = \mathbf{x} + F\big(\text{LN}(\mathbf{x})\big)$, $\text{LN}(\mathbf{x})_k = \dfrac{x_k - \mu}{\sqrt{\sigma^2 + \epsilon}}$
2. 평균을 구한다: $\mu = (2 + 4 + 6) \div 3 = 12 \div 3 = 4$
3. 칸마다 평균을 뺀다: $(2 - 4,\ 4 - 4,\ 6 - 4) = (-2, 0, 2)$
4. [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 구한다: $\sigma^2 = \dfrac{4 + 0 + 4}{3} = 2.6667$
5. 분모를 구한다: $\epsilon$을 더하면 $2.6667 + 0.00001 = 2.66671$, 제곱근은 $\sqrt{2.66671} = 1.633$
6. 나눗셈을 한다: $\text{LN}(\mathbf{x}) = (-2 \div 1.633,\ 0 \div 1.633,\ 2 \div 1.633) = (-1.2247, 0, 1.2247)$
7. 블록 $F$를 적용한다: $F(\text{LN}(\mathbf{x})) = (2 \times (-1.2247),\ 2 \times 0,\ 2 \times 1.2247) = (-2.4495, 0, 2.4495)$ (반올림 전 값으로 곱한다)
8. 잔차를 더한다: $y = (2 + (-2.4495),\ 4 + 0,\ 6 + 2.4495)$
9. 덧셈을 한다: $2 - 2.4495 = -0.4495$, $4 + 0 = 4$, $6 + 2.4495 = 8.4495$

**답**: $y = (-0.4495,\ 4,\ 8.4495)$. 블록은 정규화된 입력(크기가 일정)을 받고, 원래 $\mathbf{x}$는 잔차로 그대로 이어진다

</details>

### 문제 10

[Lec09 5.1](../../Lec09_%ED%95%B4%EC%BB%A4%EC%9D%98_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EA%B0%80%EC%9D%B4%EB%93%9C.md#51-rms-%EC%A0%95%EA%B7%9C%ED%99%94%EC%99%80-%EC%B8%B5-%EC%A0%95%EA%B7%9C%ED%99%94)은 "저차원이 오히려 이상하다"고 말한다. 칸이 2개($K = 2$)인 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) $(3, 4)$, $(1, 10)$, $(5, 2)$를 강의 식(평균을 빼고 RMS로 나누기)으로 정규화하면 어떤 결과가 나오는지 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{x}_A = (3, 4)$, $\mathbf{x}_B = (1, 10)$, $\mathbf{x}_C = (5, 2)$ (칸이 2개인 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 세 개)
- $K = 2$ ($\epsilon$은 영향이 없어 생략)

**풀이**
1. 식을 그대로 쓴다: 평균 빼기 $x[k] = x_{\text{in}}[k] - \frac{1}{K}\sum x_{\text{in}}$, 그다음 $x_{\text{out}} = x \Big/ \sqrt{\frac{1}{K}\sum x[k]^2}$
2. $\mathbf{x}_A$: 평균 $(3 + 4) \div 2 = 3.5$, 평균을 뺀다: $(3 - 3.5,\ 4 - 3.5) = (-0.5, 0.5)$
3. $\mathbf{x}_A$: 제곱의 평균은 $\dfrac{0.25 + 0.25}{2} = 0.25$, 제곱근은 $\sqrt{0.25} = 0.5$, 나눗셈은 $(-0.5 \div 0.5,\ 0.5 \div 0.5) = (-1, 1)$
4. $\mathbf{x}_B$: 평균 $(1 + 10) \div 2 = 5.5$, 평균을 뺀다: $(1 - 5.5,\ 10 - 5.5) = (-4.5, 4.5)$
5. $\mathbf{x}_B$: 제곱의 평균은 $\dfrac{20.25 + 20.25}{2} = 20.25$, 제곱근은 $\sqrt{20.25} = 4.5$, 나눗셈은 $(-4.5 \div 4.5,\ 4.5 \div 4.5) = (-1, 1)$
6. $\mathbf{x}_C$: 평균 $(5 + 2) \div 2 = 3.5$, 평균을 뺀다: $(5 - 3.5,\ 2 - 3.5) = (1.5, -1.5)$
7. $\mathbf{x}_C$: 제곱의 평균은 $\dfrac{2.25 + 2.25}{2} = 2.25$, 제곱근은 $\sqrt{2.25} = 1.5$, 나눗셈은 $(1.5 \div 1.5,\ -1.5 \div 1.5) = (1, -1)$

**답**: 세 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)의 결과는 $(-1, 1)$, $(-1, 1)$, $(1, -1)$이다. 칸이 2개면 평균을 뺀 값이 늘 $(-a, a)$ 꼴이라 [정규화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#normalization-%EC%A0%95%EA%B7%9C%ED%99%94) 결과가 $(-1, 1)$과 $(1, -1)$ 두 가지뿐이고, [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) $(3, 4)$와 $(1, 10)$의 차이가 완전히 사라진다. 차원이 높으면 이런 정보 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 생기지 않는다

</details>
