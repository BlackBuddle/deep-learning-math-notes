## 기본 (직접 대입)

### 문제 1

데이터 $(4, 8, 12, 16)$의 평균, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0), 표준편차를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x = (4, 8, 12, 16)$ (한 특징의 값 네 개)
- $N = 4$ (값의 개수)

**풀이**
1. 식을 그대로 쓴다: $\mu = \dfrac{1}{N}\sum x_i$, $\mathrm{Var} = \dfrac{1}{N}\sum (x_i - \mu)^2$, $\sigma = \sqrt{\mathrm{Var}}$
2. 평균에 대입한다: $\mu = \dfrac{1}{4}(4 + 8 + 12 + 16)$
3. 덧셈을 한다: $4 + 8 + 12 + 16 = 40$ 이므로 $\mu = \dfrac{1}{4} \times 40$
4. 나눗셈을 한다: $\mu = 40 \div 4 = 10$
5. [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)에 대입한다: $\mathrm{Var} = \dfrac{1}{4}\big((4 - 10)^2 + (8 - 10)^2 + (12 - 10)^2 + (16 - 10)^2\big)$
6. 괄호 안 뺄셈을 한다: $4 - 10 = -6$, $8 - 10 = -2$, $12 - 10 = 2$, $16 - 10 = 6$ 이므로 $\dfrac{1}{4}\big((-6)^2 + (-2)^2 + 2^2 + 6^2\big)$
7. 제곱을 한다: $36$, $4$, $4$, $36$ 이므로 $\dfrac{1}{4}(36 + 4 + 4 + 36)$
8. 덧셈과 나눗셈을 한다: $36 + 4 + 4 + 36 = 80$, $80 \div 4 = 20$ 이므로 $\mathrm{Var} = 20$
9. $\sqrt{\ }$의 뜻: 제곱하면 그 수가 되는 양수다 (코드 `np.sqrt`). $\sigma = \sqrt{20} = 4.4721$

**답**: $\mu = 10$, $\mathrm{Var} = 20$, $\sigma = 4.4721$

</details>

### 문제 2

평균 $10$, 표준편차 $4.4721$인 데이터 $(4, 8, 12, 16)$을 표준화하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x = (4, 8, 12, 16)$ (표준화할 값)
- $\mathbb{E}[x] = 10$ (평균), $\sqrt{\mathrm{Var}[x]} = 4.4721$ (표준편차)

**풀이**
1. 식을 그대로 쓴다: $x \leftarrow \dfrac{x - \mathbb{E}[x]}{\sqrt{\mathrm{Var}[x]}}$
2. 값을 대입한다: $\Big(\dfrac{4 - 10}{4.4721},\ \dfrac{8 - 10}{4.4721},\ \dfrac{12 - 10}{4.4721},\ \dfrac{16 - 10}{4.4721}\Big)$
3. 분자의 뺄셈을 한다: $4 - 10 = -6$, $8 - 10 = -2$, $12 - 10 = 2$, $16 - 10 = 6$ 이므로 $\Big(\dfrac{-6}{4.4721},\ \dfrac{-2}{4.4721},\ \dfrac{2}{4.4721},\ \dfrac{6}{4.4721}\Big)$
4. 나눗셈을 한다: $-6 \div 4.4721 = -1.3416$, $-2 \div 4.4721 = -0.4472$, $2 \div 4.4721 = 0.4472$, $6 \div 4.4721 = 1.3416$

**답**: $(-1.3416, -0.4472, 0.4472, 1.3416)$. 평균이 0이 되고 음수가 생겼다

</details>

### 문제 3

같은 데이터 $(4, 8, 12, 16)$을 최소-최대 정규화하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x = (4, 8, 12, 16)$ (바꿀 값)
- $\min x = 4$ (가장 작은 값), $\max x = 16$ (가장 큰 값)

**풀이**
1. 식을 그대로 쓴다: $x \leftarrow \dfrac{x - \min x}{\max x - \min x}$
2. 값을 대입한다: $\Big(\dfrac{4 - 4}{16 - 4},\ \dfrac{8 - 4}{16 - 4},\ \dfrac{12 - 4}{16 - 4},\ \dfrac{16 - 4}{16 - 4}\Big)$
3. 분모의 뺄셈을 먼저 한다: $16 - 4 = 12$ 이므로 $\Big(\dfrac{4 - 4}{12},\ \dfrac{8 - 4}{12},\ \dfrac{12 - 4}{12},\ \dfrac{16 - 4}{12}\Big)$
4. 분자의 뺄셈을 한다: $4 - 4 = 0$, $8 - 4 = 4$, $12 - 4 = 8$, $16 - 4 = 12$ 이므로 $\Big(\dfrac{0}{12},\ \dfrac{4}{12},\ \dfrac{8}{12},\ \dfrac{12}{12}\Big)$
5. 나눗셈을 한다: $0 \div 12 = 0$, $4 \div 12 = 0.3333$, $8 \div 12 = 0.6667$, $12 \div 12 = 1$

**답**: $(0, 0.3333, 0.6667, 1)$. 가장 작은 값이 0, 가장 큰 값이 1이 된다

</details>

### 문제 4

A 시험은 평균 70점, 표준편차 10점이고 철수가 85점을 받았다. B 시험은 평균 60점, 표준편차 5점이고 영희가 70점을 받았다. 표준화한 점수로 누가 자기 시험에서 더 높은 위치인지 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 철수: $x = 85$, $\mathbb{E}[x] = 70$ (평균), $\sqrt{\mathrm{Var}[x]} = 10$ (표준편차)
- 영희: $x = 70$, $\mathbb{E}[x] = 60$ (평균), $\sqrt{\mathrm{Var}[x]} = 5$ (표준편차)

**풀이**
1. 식을 그대로 쓴다: $z = \dfrac{x - \mathbb{E}[x]}{\sqrt{\mathrm{Var}[x]}}$ (평균에서 표준편차 몇 개만큼 떨어졌는가)
2. 철수에 대입한다: $z = \dfrac{85 - 70}{10}$
3. 뺄셈을 한다: $85 - 70 = 15$ 이므로 $z = \dfrac{15}{10}$
4. 나눗셈을 한다: $15 \div 10 = 1.5$
5. 영희에 대입한다: $z = \dfrac{70 - 60}{5}$
6. 뺄셈을 한다: $70 - 60 = 10$ 이므로 $z = \dfrac{10}{5}$
7. 나눗셈을 한다: $10 \div 5 = 2$

**답**: 철수 $z = 1.5$, 영희 $z = 2$. 점수는 철수가 높지만 자기 시험 안에서의 위치는 영희가 더 높다

</details>

### 문제 5

키 $(150, 170, 190)$ cm를 표준화한 결과와, 같은 키를 미터로 바꾼 $(1.5, 1.7, 1.9)$ m를 표준화한 결과를 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x_{\text{cm}} = (150, 170, 190)$, $x_{\text{m}} = (1.5, 1.7, 1.9)$ (같은 키, 단위만 다름)
- $N = 3$

**풀이**
1. 식을 그대로 쓴다: $z = \dfrac{x - \mu}{\sigma}$, $\mu = \dfrac{1}{N}\sum x$, $\sigma = \sqrt{\dfrac{1}{N}\sum (x - \mu)^2}$
2. cm의 평균을 구한다: $\mu = (150 + 170 + 190) \div 3 = 510 \div 3 = 170$
3. cm의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 구한다: $\dfrac{(-20)^2 + 0^2 + 20^2}{3} = \dfrac{400 + 0 + 400}{3} = \dfrac{800}{3} = 266.6667$
4. cm의 표준편차를 구한다: $\sqrt{266.6667} = 16.3299$
5. cm를 표준화한다: $(-20 \div 16.3299,\ 0 \div 16.3299,\ 20 \div 16.3299) = (-1.2247, 0, 1.2247)$
6. m의 평균을 구한다: $\mu = (1.5 + 1.7 + 1.9) \div 3 = 5.1 \div 3 = 1.7$
7. m의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 구한다: $\dfrac{(-0.2)^2 + 0^2 + 0.2^2}{3} = \dfrac{0.04 + 0 + 0.04}{3} = 0.0267$, 표준편차 $\sqrt{0.0267} = 0.1633$
8. m를 표준화한다: $(-0.2 \div 0.1633,\ 0 \div 0.1633,\ 0.2 \div 0.1633) = (-1.2247, 0, 1.2247)$

**답**: 두 결과가 모두 $(-1.2247, 0, 1.2247)$로 같다. 평균과 표준편차가 단위와 함께 100배씩 바뀌어 약분되므로 [표준화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#standardization-%ED%91%9C%EC%A4%80%ED%99%94)는 단위를 지운다

</details>

### 문제 6

모델 $\hat y = w_1 x_1 + w_2 x_2$, [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $L = (\hat y - t)^2 / 2$, 입력 $(x_1, x_2) = (500, 2)$, [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) $t = 2$, 시작 $w = (0, 0)$에서 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $\left(\dfrac{\partial L}{\partial w_1}, \dfrac{\partial L}{\partial w_2}\right)$를 구하라. 두 입력을 표준화해 $(1, 1)$ 크기로 만들면 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)는 어떻게 되는가? ($\dfrac{\partial L}{\partial w_i} = (\hat y - t)\,x_i$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $x = (500, 2)$ (크기가 250배 다른 입력)
- $t = 2$ ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)), $w = (0, 0)$ (시작 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98))
- $\dfrac{\partial L}{\partial w_i} = (\hat y - t)\,x_i$ ([기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) 식)

**풀이**
1. 예측을 구한다: $\hat y = w_1 x_1 + w_2 x_2 = 0 \times 500 + 0 \times 2 = 0 + 0 = 0$
2. [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)를 구한다: $\hat y - t = 0 - 2 = -2$
3. 식을 그대로 쓴다: $\dfrac{\partial L}{\partial w_i} = (\hat y - t)\,x_i$
4. 값을 대입한다: $\Big(\dfrac{\partial L}{\partial w_1},\ \dfrac{\partial L}{\partial w_2}\Big) = \big((-2) \times 500,\ (-2) \times 2\big)$
5. 곱셈을 한다: $(-2) \times 500 = -1000$, $(-2) \times 2 = -4$
6. 크기를 비교한다: $1000 \div 4 = 250$ 이므로 $w_1$ 쪽 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 250배 크다
7. 입력을 $(1, 1)$로 바꿔 대입한다: $\big((-2) \times 1,\ (-2) \times 1\big) = (-2, -2)$

**답**: [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)는 $(-1000, -4)$로 250배 차이가 난다. [표준화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#standardization-%ED%91%9C%EC%A4%80%ED%99%94)로 입력 크기를 맞추면 $(-2, -2)$로 같아져 한 [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0)로 두 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)를 함께 다룰 수 있다

</details>

### 문제 7

데이터 $(10, 12, 14, 1000)$과 이상치가 없는 $(10, 12, 14, 16)$을 각각 최소-최대 정규화하여, 이상치가 결과를 어떻게 바꾸는지 보라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x_A = (10, 12, 14, 1000)$ (이상치 1000이 섞임), $x_B = (10, 12, 14, 16)$ (이상치 없음)
- $x_A$: $\min = 10$, $\max = 1000$ / $x_B$: $\min = 10$, $\max = 16$

**풀이**
1. 식을 그대로 쓴다: $x \leftarrow \dfrac{x - \min x}{\max x - \min x}$
2. $x_A$의 분모를 구한다: $1000 - 10 = 990$
3. $x_A$의 분자를 구한다: $10 - 10 = 0$, $12 - 10 = 2$, $14 - 10 = 4$, $1000 - 10 = 990$
4. $x_A$를 나눈다: $0 \div 990 = 0$, $2 \div 990 = 0.0020$, $4 \div 990 = 0.0040$, $990 \div 990 = 1$
5. $x_B$의 분모를 구한다: $16 - 10 = 6$
6. $x_B$의 분자를 구한다: $0$, $2$, $4$, $6$
7. $x_B$를 나눈다: $0 \div 6 = 0$, $2 \div 6 = 0.3333$, $4 \div 6 = 0.6667$, $6 \div 6 = 1$

**답**: 이상치가 있으면 $(0, 0.0020, 0.0040, 1)$로 나머지 세 값이 모두 0 근처로 몰리고, 없으면 $(0, 0.3333, 0.6667, 1)$로 고르게 퍼진다

</details>

### 문제 8

[학습 데이터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-data-test-data-%ED%95%99%EC%8A%B5-%EB%8D%B0%EC%9D%B4%ED%84%B0%EC%99%80-%EC%8B%9C%ED%97%98-%EB%8D%B0%EC%9D%B4%ED%84%B0)에서 구한 평균이 $100$, 표준편차가 $20$이다. [시험 데이터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-data-test-data-%ED%95%99%EC%8A%B5-%EB%8D%B0%EC%9D%B4%ED%84%B0%EC%99%80-%EC%8B%9C%ED%97%98-%EB%8D%B0%EC%9D%B4%ED%84%B0) $(110, 130, 150)$을 (a) [학습 데이터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-data-test-data-%ED%95%99%EC%8A%B5-%EB%8D%B0%EC%9D%B4%ED%84%B0%EC%99%80-%EC%8B%9C%ED%97%98-%EB%8D%B0%EC%9D%B4%ED%84%B0)의 평균·표준편차로, (b) [시험 데이터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-data-test-data-%ED%95%99%EC%8A%B5-%EB%8D%B0%EC%9D%B4%ED%84%B0%EC%99%80-%EC%8B%9C%ED%97%98-%EB%8D%B0%EC%9D%B4%ED%84%B0) 자신의 평균·표준편차로 표준화하라. 어느 쪽이 올바른가?

<details><summary>풀이와 답</summary>

**주어진 값**
- [학습](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5) 통계: $\mu_{\text{train}} = 100$, $\sigma_{\text{train}} = 20$
- [시험 데이터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-data-test-data-%ED%95%99%EC%8A%B5-%EB%8D%B0%EC%9D%B4%ED%84%B0%EC%99%80-%EC%8B%9C%ED%97%98-%EB%8D%B0%EC%9D%B4%ED%84%B0): $x = (110, 130, 150)$

**풀이**
1. 식을 그대로 쓴다: $z = \dfrac{x - \mu}{\sigma}$
2. (a) [학습](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5) 통계를 대입한다: $z = \Big(\dfrac{110 - 100}{20},\ \dfrac{130 - 100}{20},\ \dfrac{150 - 100}{20}\Big)$
3. (a) 뺄셈을 한다: $110 - 100 = 10$, $130 - 100 = 30$, $150 - 100 = 50$
4. (a) 나눗셈을 한다: $10 \div 20 = 0.5$, $30 \div 20 = 1.5$, $50 \div 20 = 2.5$
5. (b) [시험 데이터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-data-test-data-%ED%95%99%EC%8A%B5-%EB%8D%B0%EC%9D%B4%ED%84%B0%EC%99%80-%EC%8B%9C%ED%97%98-%EB%8D%B0%EC%9D%B4%ED%84%B0)의 평균을 구한다: $\mu = (110 + 130 + 150) \div 3 = 390 \div 3 = 130$
6. (b) [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 구한다: $\dfrac{(-20)^2 + 0^2 + 20^2}{3} = \dfrac{800}{3} = 266.6667$, 표준편차 $\sqrt{266.6667} = 16.3299$
7. (b) 대입해 나눈다: $(-20 \div 16.3299,\ 0 \div 16.3299,\ 20 \div 16.3299) = (-1.2247, 0, 1.2247)$

**답**: (a)는 $(0.5, 1.5, 2.5)$, (b)는 $(-1.2247, 0, 1.2247)$이다. 올바른 쪽은 (a)다. (b)는 [시험 데이터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-data-test-data-%ED%95%99%EC%8A%B5-%EB%8D%B0%EC%9D%B4%ED%84%B0%EC%99%80-%EC%8B%9C%ED%97%98-%EB%8D%B0%EC%9D%B4%ED%84%B0)가 [학습 데이터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-data-test-data-%ED%95%99%EC%8A%B5-%EB%8D%B0%EC%9D%B4%ED%84%B0%EC%99%80-%EC%8B%9C%ED%97%98-%EB%8D%B0%EC%9D%B4%ED%84%B0)보다 모두 크다는 사실을 지워 버려 [학습](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5) 때와 다른 변환이 된다

### 문제 9

[Lec09 6.2](../../Lec09_%ED%95%B4%EC%BB%A4%EC%9D%98_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EA%B0%80%EC%9D%B4%EB%93%9C.md#62-%EC%9E%90%EB%A3%8C%ED%98%95-%EB%B0%94%EA%BE%B8%EA%B8%B0%EC%9D%98-%ED%95%A8%EC%A0%95)의 "표준화하면 음수가 생기는데 uint8로 바꾸면 사라진다" 버그를 확인한다. 표준화한 값이 (설명을 위해 정수로 둔) $(-2, 0, 3)$일 때 uint8(0~255만 담는 [자료형](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dtype-data-type-%EC%9E%90%EB%A3%8C%ED%98%95))로 바꾸면 어떤 값이 되는가? uint8은 음수 $v$를 $v + 256$으로 돌려 담는다.

<details><summary>풀이와 답</summary>

**주어진 값**
- $v = (-2, 0, 3)$ (표준화한 값, 음수가 섞임)
- uint8의 범위는 $0 \sim 255$ (256가지), 범위를 벗어난 음수 $v$는 $v + 256$으로 감긴다

**풀이**
1. 식을 그대로 쓴다: $v_{\text{uint8}} = v + 256$ ($v < 0$일 때), $v_{\text{uint8}} = v$ ($0 \le v \le 255$일 때)
2. $v = -2$를 대입한다 (음수): $-2 + 256$
3. 덧셈을 한다: $-2 + 256 = 254$
4. $v = 0$은 범위 안이므로 그대로 $0$
5. $v = 3$도 범위 안이므로 그대로 $3$
6. 영향을 본다: 원래 가장 작은 값 $-2$가 가장 큰 값 근처인 $254$가 되어, 이 값을 $255$로 나누면 $254 \div 255 = 0.9961$이 된다

**답**: $(254, 0, 3)$. 가장 작던 $-2$가 가장 큰 값 $254$로 둔갑한다 (정규화한 데이터는 float로 두어야 한다)

</details>

### 문제 10

[Lec09 4](../../Lec09_%ED%95%B4%EC%BB%A4%EC%9D%98_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EA%B0%80%EC%9D%B4%EB%93%9C.md#4-%ED%91%9C%EC%A4%80%ED%99%94)처럼 사람 세 명의 키(cm) $(160, 170, 180)$과 몸무게(kg) $(40, 60, 80)$을 두 특징으로 쓴다. 1번 사람과 3번 사람 사이의 거리를 (a) [표준화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#standardization-%ED%91%9C%EC%A4%80%ED%99%94) 전, (b) 각 특징을 따로 표준화한 뒤에 구하고, 거리의 몇 %가 몸무게 차이에서 오는지 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 키: $(160, 170, 180)$, 몸무게: $(40, 60, 80)$ (사람 1, 2, 3의 값)
- 거리 $= \sqrt{(\text{키 차이})^2 + (\text{몸무게 차이})^2}$, [표준화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#standardization-%ED%91%9C%EC%A4%80%ED%99%94)는 특징마다 $z = (x - \mu)/\sigma$

**풀이**
1. (a) [표준화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#standardization-%ED%91%9C%EC%A4%80%ED%99%94) 전 차이를 구한다: 키 $180 - 160 = 20$, 몸무게 $80 - 40 = 40$
2. (a) 거리를 구한다: $\sqrt{20^2 + 40^2} = \sqrt{400 + 1600} = \sqrt{2000} = 44.7214$ (제곱하면 2000이 되는 양수)
3. (a) 몸무게 몫을 구한다: 제곱 기준으로 $1600 \div 2000 = 0.8$, 곧 80%
4. (b) 키를 표준화한다: $\mu = 170$, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $\dfrac{100 + 0 + 100}{3} = 66.6667$, 표준편차 $\sqrt{66.6667} = 8.165$, 값은 $(-10 \div 8.165,\ 0,\ 10 \div 8.165) = (-1.2247, 0, 1.2247)$
5. (b) 몸무게를 표준화한다: $\mu = 60$, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $\dfrac{400 + 0 + 400}{3} = 266.6667$, 표준편차 $\sqrt{266.6667} = 16.3299$, 값은 $(-20 \div 16.3299,\ 0,\ 20 \div 16.3299) = (-1.2247, 0, 1.2247)$
6. (b) [표준화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#standardization-%ED%91%9C%EC%A4%80%ED%99%94) 뒤 차이를 구한다: 키 $1.2247 - (-1.2247) = 2.4495$, 몸무게도 $2.4495$
7. (b) 거리를 구한다: $\sqrt{2.4495^2 + 2.4495^2} = \sqrt{6 + 6} = \sqrt{12} = 3.4641$
8. (b) 몸무게 몫을 구한다: $6 \div 12 = 0.5$, 곧 50%

**답**: [표준화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#standardization-%ED%91%9C%EC%A4%80%ED%99%94) 전 거리는 $44.7214$이고 80%가 몸무게 차이다 (단위가 큰 쪽이 좌우한다). [표준화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#standardization-%ED%91%9C%EC%A4%80%ED%99%94) 후 거리는 $3.4641$이고 두 특징이 50%씩 기여한다. [표준화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#standardization-%ED%91%9C%EC%A4%80%ED%99%94)는 "어느 차원도 미리 더 중요하지 않다"는 가정을 넣는다

</details>
