## 기본 (직접 대입)

### 문제 1

감쇠 계수 $\beta = 0.9$이고 지금까지의 EMA가 $10$인데 새 값 $20$이 들어왔다. 갱신된 EMA를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\beta = 0.9$ (감쇠 계수)
- $\theta^{t-1}_{\text{EMA}} = 10$ (바로 전 EMA)
- $\theta^{t} = 20$ (새 값)

**풀이**
1. 식을 그대로 쓴다: $\theta^{t}_{\text{EMA}} = \beta\, \theta^{t-1}_{\text{EMA}} + (1-\beta)\, \theta^{t}$
2. 값을 대입한다: $\theta^{t}_{\text{EMA}} = 0.9 \times 10 + (1 - 0.9) \times 20$
3. 괄호를 먼저 계산한다: $1 - 0.9 = 0.1$ 이므로 $0.9 \times 10 + 0.1 \times 20$
4. 곱셈을 한다: $0.9 \times 10 = 9$, $0.1 \times 20 = 2$ 이므로 $9 + 2$
5. 덧셈을 한다: $9 + 2 = 11$

**답**: $\theta^{t}_{\text{EMA}} = 11$. 새 값이 20으로 훨씬 컸지만 EMA는 10에서 11로 조금만 움직인다

</details>

### 문제 2

$\beta = 0.5$, 시작 EMA $= 0$이고 값 $8, 4, 12$가 차례로 들어올 때 세 스텝의 EMA를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\beta = 0.5$ (감쇠 계수), $1 - \beta = 0.5$
- $\theta^{0}_{\text{EMA}} = 0$ (시작 값)
- $\theta^1 = 8$, $\theta^2 = 4$, $\theta^3 = 12$ (들어온 값)

**풀이**
1. 식을 그대로 쓴다: $\theta^{t}_{\text{EMA}} = \beta\, \theta^{t-1}_{\text{EMA}} + (1-\beta)\, \theta^{t}$
2. $t = 1$을 대입한다: $\theta^{1}_{\text{EMA}} = 0.5 \times 0 + 0.5 \times 8$
3. 곱셈과 덧셈을 한다: $0.5 \times 0 = 0$, $0.5 \times 8 = 4$ 이므로 $0 + 4 = 4$
4. $t = 2$를 대입한다 (방금 구한 4를 쓴다): $\theta^{2}_{\text{EMA}} = 0.5 \times 4 + 0.5 \times 4$
5. 곱셈과 덧셈을 한다: $0.5 \times 4 = 2$ (두 항 모두) 이므로 $2 + 2 = 4$
6. $t = 3$을 대입한다: $\theta^{3}_{\text{EMA}} = 0.5 \times 4 + 0.5 \times 12$
7. 곱셈과 덧셈을 한다: $0.5 \times 4 = 2$, $0.5 \times 12 = 6$ 이므로 $2 + 6 = 8$

**답**: 세 스텝의 EMA는 $4, 4, 8$이다

</details>

### 문제 3

$\beta = 0.8$일 때 $k = 0, 1, 2, 3$ 스텝 전 값의 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) $(1-\beta)\beta^k$를 구하고, 네 개의 합을 $1 - \beta^4$와 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\beta = 0.8$, $1 - \beta = 0.2$
- $k = 0, 1, 2, 3$ (몇 스텝 전의 값인가, 0은 지금)

**풀이**
1. 식을 그대로 쓴다: [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) $w_k = (1-\beta)\,\beta^{k}$
2. $k = 0$을 대입한다 (0제곱은 1): $0.2 \times 0.8^{0} = 0.2 \times 1 = 0.2$
3. $k = 1$을 대입한다: $0.2 \times 0.8^{1} = 0.2 \times 0.8 = 0.16$
4. $k = 2$를 대입한다 ($0.8^2 = 0.8 \times 0.8 = 0.64$): $0.2 \times 0.64 = 0.128$
5. $k = 3$을 대입한다 ($0.8^3 = 0.64 \times 0.8 = 0.512$): $0.2 \times 0.512 = 0.1024$
6. 네 개를 더한다: $0.2 + 0.16 + 0.128 + 0.1024 = 0.5904$
7. 오른쪽 식을 구한다: $0.8^4 = 0.512 \times 0.8 = 0.4096$ 이므로 $1 - 0.4096 = 0.5904$

**답**: [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)는 $0.2, 0.16, 0.128, 0.1024$이고 합은 $0.5904 = 1 - 0.8^4$로 같다. 오래된 값일수록 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)가 작다

</details>

### 문제 4

EMA가 대략 몇 개의 값을 평균하는지 나타내는 창 크기 $1/(1-\beta)$를 $\beta = 0.95$, $0.98$, $0.999$에 대해 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\beta = 0.95,\ 0.98,\ 0.999$ (감쇠 계수)

**풀이**
1. 식을 그대로 쓴다: 창 크기 $= \dfrac{1}{1-\beta}$
2. $\beta = 0.95$를 대입한다: $\dfrac{1}{1 - 0.95} = \dfrac{1}{0.05}$, 나눗셈은 $1 \div 0.05 = 20$
3. $\beta = 0.98$을 대입한다: $\dfrac{1}{1 - 0.98} = \dfrac{1}{0.02}$, 나눗셈은 $1 \div 0.02 = 50$
4. $\beta = 0.999$를 대입한다: $\dfrac{1}{1 - 0.999} = \dfrac{1}{0.001}$, 나눗셈은 $1 \div 0.001 = 1000$

**답**: 창 크기는 각각 약 $20$, $50$, $1000$이다. $\beta$가 1에 가까울수록 과거를 더 오래 기억한다

</details>

### 문제 5

$\beta = 0.5$, 시작 EMA $= 0$이고 값이 계속 $6$일 때 두 스텝의 EMA와 [편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5) 보정 값 $\hat\theta^t = \theta^t_{\text{EMA}} / (1 - \beta^t)$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\beta = 0.5$ (감쇠 계수)
- $\theta^0_{\text{EMA}} = 0$ (시작 값)
- $\theta^1 = 6$, $\theta^2 = 6$ (들어온 값)

**풀이**
1. 식을 그대로 쓴다: $\theta^{t}_{\text{EMA}} = \beta\, \theta^{t-1}_{\text{EMA}} + (1-\beta)\, \theta^{t}$, $\hat\theta^{t} = \dfrac{\theta^{t}_{\text{EMA}}}{1-\beta^t}$
2. $t = 1$을 대입한다: $\theta^{1}_{\text{EMA}} = 0.5 \times 0 + 0.5 \times 6 = 0 + 3 = 3$
3. $t = 2$를 대입한다: $\theta^{2}_{\text{EMA}} = 0.5 \times 3 + 0.5 \times 6 = 1.5 + 3 = 4.5$
4. $t = 1$ 보정에 대입한다: $\hat\theta^{1} = \dfrac{3}{1 - 0.5^1}$
5. 분모를 계산한다: $0.5^1 = 0.5$, $1 - 0.5 = 0.5$ 이므로 $\dfrac{3}{0.5}$, 나눗셈은 $3 \div 0.5 = 6$
6. $t = 2$ 보정에 대입한다: $\hat\theta^{2} = \dfrac{4.5}{1 - 0.5^2}$
7. 분모를 계산한다: $0.5^2 = 0.5 \times 0.5 = 0.25$, $1 - 0.25 = 0.75$ 이므로 $\dfrac{4.5}{0.75}$, 나눗셈은 $4.5 \div 0.75 = 6$

**답**: EMA는 $3, 4.5$로 실제 값 6보다 작지만, 보정하면 $6, 6$으로 돌아온다. 0에서 시작해서 생긴 치우침을 $1 - \beta^t$로 나눠 바로잡는다

</details>

### 문제 6

$\beta = 0.5$, 시작 EMA $= 0$이고 값 $2, 6, 4$가 들어왔다. 펼친 식 $\theta^{3}_{\text{EMA}} = (1-\beta)\sum_{k=0}^{2} \beta^{k}\,\theta^{3-k}$으로 세 번째 EMA를 구하고, 되풀이 계산과 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\beta = 0.5$ (감쇠 계수)
- $\theta^1 = 2$, $\theta^2 = 6$, $\theta^3 = 4$ (들어온 값, $\theta^3$이 지금)

**풀이**
1. 식을 그대로 쓴다: $\theta^{3}_{\text{EMA}} = (1-\beta)\sum_{k=0}^{2} \beta^{k}\,\theta^{3-k}$
2. $\sum$을 세 항으로 펼친다 ($k = 0, 1, 2$): $(1-\beta)\big(\beta^{0}\theta^{3} + \beta^{1}\theta^{2} + \beta^{2}\theta^{1}\big)$
3. 값을 대입한다: $(1 - 0.5)\big(0.5^{0} \times 4 + 0.5^{1} \times 6 + 0.5^{2} \times 2\big)$
4. 거듭제곱을 계산한다 ($0.5^0 = 1$, $0.5^1 = 0.5$, $0.5^2 = 0.25$): $(1 - 0.5)\big(1 \times 4 + 0.5 \times 6 + 0.25 \times 2\big)$
5. 괄호 안 곱셈을 한다: $1 \times 4 = 4$, $0.5 \times 6 = 3$, $0.25 \times 2 = 0.5$ 이므로 $(1 - 0.5)(4 + 3 + 0.5)$
6. 괄호 안 덧셈을 한다: $4 + 3 + 0.5 = 7.5$ 이므로 $(1 - 0.5) \times 7.5$
7. 앞 괄호를 계산하고 곱한다: $1 - 0.5 = 0.5$, $0.5 \times 7.5 = 3.75$
8. 되풀이 계산으로 확인한다: $\theta^1_{\text{EMA}} = 0.5 \times 0 + 0.5 \times 2 = 1$, $\theta^2_{\text{EMA}} = 0.5 \times 1 + 0.5 \times 6 = 3.5$, $\theta^3_{\text{EMA}} = 0.5 \times 3.5 + 0.5 \times 4 = 1.75 + 2 = 3.75$

**답**: $\theta^{3}_{\text{EMA}} = 3.75$. 펼친 식과 되풀이 계산이 같다. [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)는 지금 값 $0.5$, 한 스텝 전 $0.25$, 두 스텝 전 $0.125$다

</details>

### 문제 7

$\beta = 0.9$, 시작 EMA $= 0$인 상태에서 값이 갑자기 $10$으로 바뀌어 계속 $10$이다. 5스텝 동안의 EMA를 구하고, 5스텝과 10스텝 뒤에 목표값 10의 몇 %까지 따라왔는지 $1 - \beta^t$로 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\beta = 0.9$ (감쇠 계수), $1 - \beta = 0.1$
- $\theta^{0}_{\text{EMA}} = 0$ (시작 값), $\theta^t = 10$ (계속 들어오는 값)

**풀이**
1. 식을 그대로 쓴다: $\theta^{t}_{\text{EMA}} = 0.9\, \theta^{t-1}_{\text{EMA}} + 0.1 \times 10$
2. $t = 1$: $0.9 \times 0 + 1 = 1$
3. $t = 2$: $0.9 \times 1 + 1 = 0.9 + 1 = 1.9$
4. $t = 3$: $0.9 \times 1.9 + 1 = 1.71 + 1 = 2.71$
5. $t = 4$: $0.9 \times 2.71 + 1 = 2.439 + 1 = 3.439$
6. $t = 5$: $0.9 \times 3.439 + 1 = 3.0951 + 1 = 4.0951$
7. 5스텝의 비율을 구한다: $1 - 0.9^5$, 거듭제곱은 $0.9^5 = 0.59049$ 이므로 $1 - 0.59049 = 0.4095$
8. 10스텝의 비율을 구한다: $0.9^{10} = 0.3487$ 이므로 $1 - 0.3487 = 0.6513$

**답**: EMA는 $1, 1.9, 2.71, 3.439, 4.0951$이다. 5스텝 뒤 약 $41\%$, 10스텝 뒤 약 $65\%$까지만 따라온다. EMA는 값이 갑자기 바뀌면 약 $1/(1-\beta) = 10$ 스텝이 지나야 따라간다 (느리다)

</details>

### 문제 8

잡음이 낀 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $(4, 2, 5, 3)$을 $\beta = 0.5$ EMA로 매끄럽게 한다. 0 대신 첫 값 $4$로 시작할 때 네 스텝의 EMA를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\beta = 0.5$ (감쇠 계수)
- $\theta^{0}_{\text{EMA}} = 4$ (첫 값으로 시작)
- $\theta^1 = 4$, $\theta^2 = 2$, $\theta^3 = 5$, $\theta^4 = 3$ ([손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) 값)

**풀이**
1. 식을 그대로 쓴다: $\theta^{t}_{\text{EMA}} = \beta\, \theta^{t-1}_{\text{EMA}} + (1-\beta)\, \theta^{t}$
2. $t = 1$을 대입한다: $0.5 \times 4 + 0.5 \times 4 = 2 + 2 = 4$
3. $t = 2$를 대입한다: $0.5 \times 4 + 0.5 \times 2 = 2 + 1 = 3$
4. $t = 3$을 대입한다: $0.5 \times 3 + 0.5 \times 5 = 1.5 + 2.5 = 4$
5. $t = 4$를 대입한다: $0.5 \times 4 + 0.5 \times 3 = 2 + 1.5 = 3.5$

**답**: EMA는 $4, 3, 4, 3.5$다. 원래 값 $(4, 2, 5, 3)$보다 들쭉날쭉한 폭이 줄었고, 첫 값으로 시작했으므로 초반 치우침도 없다

</details>

### 문제 9

[Lec09 14.3](../../Lec09_%ED%95%B4%EC%BB%A4%EC%9D%98_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EA%B0%80%EC%9D%B4%EB%93%9C.md#143-%EC%A7%80%EC%88%98-%EC%9D%B4%EB%8F%99-%ED%8F%89%EA%B7%A0)의 [모멘텀](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#momentum-%EB%AA%A8%EB%A9%98%ED%85%80)은 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)의 EMA다. $\beta = 0.9$, 시작 $v = 0$이고 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 $1, 1, 1, -1$로 들어올 때 네 스텝의 $v$를 구하라. 마지막에 부호가 바뀐 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 $v$를 얼마나 움직이는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $\beta = 0.9$ (감쇠 계수), $1 - \beta = 0.1$
- $v^0 = 0$ (시작 값)
- $g^1 = 1$, $g^2 = 1$, $g^3 = 1$, $g^4 = -1$ ([기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0))

**풀이**
1. 식을 그대로 쓴다: $v^{t} = \beta\, v^{t-1} + (1-\beta)\, g^{t}$
2. $t = 1$을 대입한다: $0.9 \times 0 + 0.1 \times 1 = 0 + 0.1 = 0.1$
3. $t = 2$를 대입한다: $0.9 \times 0.1 + 0.1 \times 1 = 0.09 + 0.1 = 0.19$
4. $t = 3$을 대입한다: $0.9 \times 0.19 + 0.1 \times 1 = 0.171 + 0.1 = 0.271$
5. $t = 4$를 대입한다: $0.9 \times 0.271 + 0.1 \times (-1)$
6. 곱셈을 한다: $0.9 \times 0.271 = 0.2439$, $0.1 \times (-1) = -0.1$ 이므로 $0.2439 + (-0.1)$
7. 덧셈을 한다: $0.2439 - 0.1 = 0.1439$
8. 변화량을 본다: $0.1439 - 0.271 = -0.1271$

**답**: $v$는 $0.1, 0.19, 0.271, 0.1439$다. 마지막 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 $-1$로 뒤집혀도 $v$는 $0.271$에서 $0.1439$로 줄 뿐 부호가 바뀌지 않는다. [모멘텀](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#momentum-%EB%AA%A8%EB%A9%98%ED%85%80)은 과거 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) 방향을 기억해 갑작스러운 흔들림을 눌러 준다

</details>

### 문제 10

[Lec18 4.2](../../Lec18_%EC%A0%84%EC%9D%B4_%ED%95%99%EC%8A%B5_%EB%AA%A8%EB%8D%B8.md#42-%EB%B9%84%EC%A7%80%EB%8F%84-%EB%8F%84%EB%A9%94%EC%9D%B8-%EC%A0%81%EC%9D%91)의 EMA 교사는 $\tau \leftarrow 0.99\,\tau + 0.01\,\theta$로 학생 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) $\theta$를 천천히 따라간다. 교사의 시작 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)가 $\tau = 0$이고 학생 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)가 계속 $\theta = 1$일 때 세 스텝 뒤의 $\tau$를 구하고, 100스텝 뒤의 $\tau = 1 - 0.99^{100}$도 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\beta = 0.99$ (감쇠 계수), $1 - \beta = 0.01$
- $\tau^0 = 0$ (교사의 시작 값), $\theta = 1$ (학생 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98))
- $0.99^{100} = 0.3660$ (계산기의 $x^y$ 키)

**풀이**
1. 식을 그대로 쓴다: $\tau^{t} = 0.99\,\tau^{t-1} + 0.01 \times \theta$
2. $t = 1$을 대입한다: $0.99 \times 0 + 0.01 \times 1 = 0 + 0.01 = 0.01$
3. $t = 2$를 대입한다: $0.99 \times 0.01 + 0.01 \times 1 = 0.0099 + 0.01 = 0.0199$
4. $t = 3$을 대입한다: $0.99 \times 0.0199 + 0.01 \times 1 = 0.019701 + 0.01 = 0.029701$
5. 100스텝의 식을 쓴다: [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) 합은 $1 - \beta^{100}$ 이고 값이 계속 1이므로 $\tau^{100} = 1 - 0.99^{100}$
6. 값을 대입한다: $1 - 0.3660 = 0.6340$

**답**: 세 스텝 뒤 $\tau = 0.0297$, 100스텝 뒤 $\tau = 0.6340$이다. 학생이 갑자기 1로 바뀌어도 교사는 100스텝에 걸쳐 약 63%만 따라가므로 천천히 변하는 안정된 목표가 된다

</details>
