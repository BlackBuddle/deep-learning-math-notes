# 예제: 정답 거르기와 반복 자기 개선

개념 노트: [MM82_정답_거르기와_반복_자기_개선](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/13_%EC%96%B8%EC%96%B4_%EB%AA%A8%EB%8D%B8%EA%B3%BC_%EC%B6%94%EB%A1%A0/MM82_%EC%A0%95%EB%8B%B5_%EA%B1%B0%EB%A5%B4%EA%B8%B0%EC%99%80_%EB%B0%98%EB%B3%B5_%EC%9E%90%EA%B8%B0_%EA%B0%9C%EC%84%A0.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 쓰는 식은 정답률 $P = \sum_s p(s) q(s)$, 한 번 거른 분포 $p_{\text{new}}(s) = p(s) q(s) / \sum_{s'} p(s') q(s')$, $t$번 거른 분포 $p_t(s) = p_0(s) q(s)^t / \sum_{s'} p_0(s') q(s')^t$이다. $p(s)$는 풀이 방식 $s$를 고를 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0), $q(s)$는 그 방식의 정답률이다.

## 기본 (직접 대입)

### 문제 1

모델이 방식 A, B를 각각 $0.5$, $0.5$의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)로 쓰고, 정답률은 $q(A) = 0.4$, $q(B) = 0.8$이다. 전체 정답률은?

<details><summary>풀이와 답</summary>

**주어진 값**
- $p(A) = 0.5$, $p(B) = 0.5$ (방식을 고를 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $q(A) = 0.4$, $q(B) = 0.8$ (방식별 정답률)

**풀이**
1. 식을 그대로 쓴다: $P = \sum_s p(s)\, q(s)$
2. 값을 대입한다 (Σ를 두 항으로 펼친다): $P = 0.5 \times 0.4 + 0.5 \times 0.8$
3. 첫 곱셈을 한다: $0.5 \times 0.4 = 0.2$ 이므로 $P = 0.2 + 0.5 \times 0.8$
4. 둘째 곱셈을 한다: $0.5 \times 0.8 = 0.4$ 이므로 $P = 0.2 + 0.4$
5. 더한다: $0.2 + 0.4 = 0.6$

**답**: $0.6$

</details>

### 문제 2

방식이 세 개이고 $p = (0.2, 0.3, 0.5)$, $q = (0.5, 0.4, 0.6)$이다. 전체 정답률은?

<details><summary>풀이와 답</summary>

**주어진 값**
- $p(A) = 0.2$, $p(B) = 0.3$, $p(C) = 0.5$ (방식을 고를 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $q(A) = 0.5$, $q(B) = 0.4$, $q(C) = 0.6$ (방식별 정답률)

**풀이**
1. 식을 그대로 쓴다: $P = \sum_s p(s)\, q(s)$
2. 값을 대입한다 (Σ를 세 항으로 펼친다): $P = 0.2 \times 0.5 + 0.3 \times 0.4 + 0.5 \times 0.6$
3. 곱셈을 한다: $0.2 \times 0.5 = 0.1$, $0.3 \times 0.4 = 0.12$, $0.5 \times 0.6 = 0.3$ 이므로 $P = 0.1 + 0.12 + 0.3$
4. 더한다: $0.1 + 0.12 = 0.22$, $0.22 + 0.3 = 0.52$

**답**: $0.52$

</details>

### 문제 3

방식 A, B를 $0.5$, $0.5$로 쓰고 정답률이 $0.2$, $0.6$이다. 맞은 풀이만 걸러 다시 배우면 새로 A, B를 쓸 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은?

<details><summary>풀이와 답</summary>

**주어진 값**
- $p(A) = 0.5$, $p(B) = 0.5$ (거르기 전 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $q(A) = 0.2$, $q(B) = 0.6$ (정답률)

**풀이**
1. 식을 그대로 쓴다: $p_{\text{new}}(s) = \dfrac{p(s)\, q(s)}{p(A)\, q(A) + p(B)\, q(B)}$
2. 남는 몫을 구한다 (거르고 남는 비율): $p(A)\,q(A) = 0.5 \times 0.2 = 0.1$, $p(B)\,q(B) = 0.5 \times 0.6 = 0.3$
3. 분모를 더한다: $0.1 + 0.3 = 0.4$
4. A에 대입한다: $p_{\text{new}}(A) = \dfrac{0.1}{0.4}$
5. 나눈다: $0.1 \div 0.4 = 0.25$
6. B에 대입해 나눈다: $p_{\text{new}}(B) = \dfrac{0.3}{0.4} = 0.75$

**답**: A $0.25$, B $0.75$ (합은 1). 정답률이 높은 B가 더 자주 쓰이게 된다.

</details>

### 문제 4

문제 3의 새 모델의 정답률은? 한 번 거르기 전의 정답률과 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p_{\text{new}}(A) = 0.25$, $p_{\text{new}}(B) = 0.75$ (문제 3의 결과)
- $q(A) = 0.2$, $q(B) = 0.6$ (정답률)
- 거르기 전 정답률 $= 0.5 \times 0.2 + 0.5 \times 0.6 = 0.1 + 0.3 = 0.4$ (문제 3의 분모)

**풀이**
1. 식을 그대로 쓴다: $P_{\text{new}} = \sum_s p_{\text{new}}(s)\, q(s)$
2. 값을 대입한다 (Σ를 두 항으로 펼친다): $P_{\text{new}} = 0.25 \times 0.2 + 0.75 \times 0.6$
3. 곱셈을 한다: $0.25 \times 0.2 = 0.05$, $0.75 \times 0.6 = 0.45$ 이므로 $P_{\text{new}} = 0.05 + 0.45$
4. 더한다: $0.05 + 0.45 = 0.5$
5. 비교한다: $0.5 > 0.4$

**답**: 새 정답률 $0.5$ (거르기 전 $0.4$에서 올랐다)

</details>

### 문제 5

문제 3의 모델($p_0 = (0.5, 0.5)$, $q = (0.2, 0.6)$)에서 거르고 배우기를 $t = 2$번 하면 A, B를 쓸 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)과 정답률은?

<details><summary>풀이와 답</summary>

**주어진 값**
- $p_0(A) = 0.5$, $p_0(B) = 0.5$ (처음 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $q(A) = 0.2$, $q(B) = 0.6$ (정답률)
- $t = 2$ (반복 횟수)

**풀이**
1. 식을 그대로 쓴다: $p_t(s) = \dfrac{p_0(s)\, q(s)^t}{p_0(A)\, q(A)^t + p_0(B)\, q(B)^t}$
2. 값을 대입한다: 분자 A $= 0.5 \times 0.2^2$, 분자 B $= 0.5 \times 0.6^2$
3. 거듭제곱을 한다: $0.2^2 = 0.04$, $0.6^2 = 0.36$ 이므로 $0.5 \times 0.04$, $0.5 \times 0.36$
4. 곱셈을 한다: $0.5 \times 0.04 = 0.02$, $0.5 \times 0.36 = 0.18$
5. 분모를 더한다: $0.02 + 0.18 = 0.2$
6. 나눈다: $p_2(A) = 0.02 \div 0.2 = 0.1$, $p_2(B) = 0.18 \div 0.2 = 0.9$
7. 정답률을 구한다: $P = 0.1 \times 0.2 + 0.9 \times 0.6 = 0.02 + 0.54 = 0.56$

**답**: A $0.1$, B $0.9$, 정답률 $0.56$. 한 번 거르면 $0.5$, 두 번 거르면 $0.56$으로 오른다.

</details>

### 문제 6

방식이 셋이고 $p = (0.6, 0.3, 0.1)$, $q = (0.1, 0.5, 0.8)$이다. 한 번 거른 뒤 방식 C를 쓸 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)과 새 정답률은?

<details><summary>풀이와 답</summary>

**주어진 값**
- $p(A) = 0.6$, $p(B) = 0.3$, $p(C) = 0.1$ (거르기 전 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $q(A) = 0.1$, $q(B) = 0.5$, $q(C) = 0.8$ (정답률)

**풀이**
1. 식을 그대로 쓴다: $p_{\text{new}}(C) = \dfrac{p(C)\, q(C)}{\sum_s p(s)\, q(s)}$, $P_{\text{new}} = \dfrac{\sum_s p(s)\, q(s)\, q(s)}{\sum_s p(s)\, q(s)}$
2. 남는 몫을 곱한다: $0.6 \times 0.1 = 0.06$, $0.3 \times 0.5 = 0.15$, $0.1 \times 0.8 = 0.08$
3. 분모를 더한다: $0.06 + 0.15 + 0.08 = 0.29$
4. C에 대입해 나눈다: $p_{\text{new}}(C) = 0.08 \div 0.29 = 0.2759$
5. 정답률의 분자에서 남는 몫에 정답률을 한 번 더 곱한다: $0.06 \times 0.1 = 0.006$, $0.15 \times 0.5 = 0.075$, $0.08 \times 0.8 = 0.064$
6. 분자를 더한다: $0.006 + 0.075 + 0.064 = 0.145$
7. 나눈다: $P_{\text{new}} = 0.145 \div 0.29 = 0.5$

**답**: C를 쓸 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) $0.2759$ (처음 $0.1$에서 올랐다), 새 정답률 $0.5$ (처음 $0.29$에서 올랐다)

</details>

### 문제 7

방식 A의 정답률이 $q(A) = 0$, 방식 B의 정답률이 $q(B) = 0.5$이고 $p(A) = 0.7$, $p(B) = 0.3$이다. 한 번 거르면 A, B를 쓸 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은? 두 번, 세 번 걸러도 달라지는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $p(A) = 0.7$, $p(B) = 0.3$ (거르기 전 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $q(A) = 0$, $q(B) = 0.5$ (정답률)

**풀이**
1. 식을 그대로 쓴다: $p_t(s) = \dfrac{p_0(s)\, q(s)^t}{p_0(A)\, q(A)^t + p_0(B)\, q(B)^t}$
2. $t = 1$의 남는 몫을 구한다: $0.7 \times 0 = 0$, $0.3 \times 0.5 = 0.15$
3. 분모를 더한다: $0 + 0.15 = 0.15$
4. 나눈다: $p_1(A) = 0 \div 0.15 = 0$, $p_1(B) = 0.15 \div 0.15 = 1$
5. $t$가 더 커져도 A의 분자는 $0.7 \times 0^t = 0$ 이므로 계속 $0$

**답**: 한 번 거르면 A $0$, B $1$이고, 몇 번을 걸러도 A는 $0$이다. 정답률이 0인 방식은 첫 번에 완전히 사라지고 아무리 반복해도 되살아나지 않는다. (처음부터 쓰지 않는 방식, $p_0 = 0$도 마찬가지다.)

</details>

### 문제 8

방식 A, B를 $0.5$, $0.5$로 쓰고 정답률이 $0.3$, $0.9$이다. 한 번, 두 번 거른 뒤 정답률은 얼마이고, 반복을 끝없이 해도 넘을 수 없는 값은 얼마인가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $p_0(A) = 0.5$, $p_0(B) = 0.5$ (처음 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $q(A) = 0.3$, $q(B) = 0.9$ (정답률)

**풀이**
1. 식을 그대로 쓴다: $p_t(s) = \dfrac{p_0(s)\, q(s)^t}{\sum_{s'} p_0(s')\, q(s')^t}$, $P_t = \sum_s p_t(s)\, q(s)$
2. $t = 1$의 남는 몫을 구한다: $0.5 \times 0.3 = 0.15$, $0.5 \times 0.9 = 0.45$
3. 분모를 더하고 나눈다: $0.15 + 0.45 = 0.6$ 이므로 $p_1 = (0.15 \div 0.6,\ 0.45 \div 0.6) = (0.25,\ 0.75)$
4. 정답률을 구한다: $P_1 = 0.25 \times 0.3 + 0.75 \times 0.9 = 0.075 + 0.675 = 0.75$
5. $t = 2$의 남는 몫을 구한다: $0.3^2 = 0.09$, $0.9^2 = 0.81$ 이므로 $0.5 \times 0.09 = 0.045$, $0.5 \times 0.81 = 0.405$
6. 분모를 더하고 나눈다: $0.045 + 0.405 = 0.45$ 이므로 $p_2 = (0.045 \div 0.45,\ 0.405 \div 0.45) = (0.1,\ 0.9)$
7. 정답률을 구한다: $P_2 = 0.1 \times 0.3 + 0.9 \times 0.9 = 0.03 + 0.81 = 0.84$
8. 상한을 본다: 정답률은 방식별 정답률의 가중 평균이라 가장 큰 $q$보다 클 수 없다: $\max(0.3, 0.9) = 0.9$

**답**: $P_1 = 0.75$, $P_2 = 0.84$, 상한은 $0.9$. 처음 $0.6$에서 출발한 정답률이 $0.9$에 점점 가까워지지만 넘지는 못한다. 모델이 이미 할 줄 아는 방식 안에서 고르는 것뿐이기 때문이다.

</details>

### 문제 9

[Lec24 11.3](../../Lec24_%EC%B6%94%EB%A1%A0_%EB%B0%A9%EB%B2%95.md#113-star%EC%99%80-o1-%EC%B6%94%EC%B8%A1): [검증기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#verifier-%EA%B2%80%EC%A6%9D%EA%B8%B0)가 완벽하지 않으면 거르기에서 살아남을 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 정답률 $q$가 아니라 통과율 $r$이 된다. 방식 A는 [검증기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#verifier-%EA%B2%80%EC%A6%9D%EA%B8%B0)를 잘 속여 통과율 $r(A) = 0.9$지만 실제 정답률은 $q(A) = 0.2$이고, 방식 B는 통과율 $r(B) = 0.5$, 정답률 $q(B) = 0.6$이다. 처음에 $p = (0.5, 0.5)$일 때, 통과한 풀이만 모아 다시 배운 새 모델의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) $p_{\text{new}}$와 실제 정답률은? 처음 실제 정답률과 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p(A) = 0.5$, $p(B) = 0.5$ (거르기 전 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $r(A) = 0.9$, $r(B) = 0.5$ ([검증기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#verifier-%EA%B2%80%EC%A6%9D%EA%B8%B0) 통과율)
- $q(A) = 0.2$, $q(B) = 0.6$ (실제 정답률)

**풀이**
1. 식을 그대로 쓴다 (정답률 $q$ 자리에 통과율 $r$을 넣는다): $p_{\text{new}}(s) = \dfrac{p(s)\, r(s)}{\sum_{s'} p(s')\, r(s')}$
2. 남는 몫을 구한다: $0.5 \times 0.9 = 0.45$, $0.5 \times 0.5 = 0.25$
3. 분모를 더한다: $0.45 + 0.25 = 0.7$
4. 나눈다: $p_{\text{new}}(A) = 0.45 \div 0.7 = 0.6429$, $p_{\text{new}}(B) = 0.25 \div 0.7 = 0.3571$
5. 새 실제 정답률은 진짜 $q$로 구한다: $0.6429 \times 0.2 + 0.3571 \times 0.6$
6. 곱셈을 한다: $0.6429 \times 0.2 = 0.1286$, $0.3571 \times 0.6 = 0.2143$
7. 더한다: $0.1286 + 0.2143 = 0.3429$
8. 처음 정답률을 구한다: $0.5 \times 0.2 + 0.5 \times 0.6 = 0.1 + 0.3 = 0.4$
9. 비교한다: $0.3429 < 0.4$

**답**: $p_{\text{new}} = (0.6429,\ 0.3571)$, 실제 정답률 $0.3429$로 처음 $0.4$보다 떨어진다. [검증기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#verifier-%EA%B2%80%EC%A6%9D%EA%B8%B0)를 속이는 방식이 커지면 반복할수록 오히려 나빠진다(보상 해킹).

</details>

### 문제 10

[Lec24 11.1](../../Lec24_%EC%B6%94%EB%A1%A0_%EB%B0%A9%EB%B2%95.md#111-%EC%9E%90%EA%B8%B0-%EA%B0%9C%EC%84%A0)의 "탐색하고, [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)을 다시 학습하고, 되풀이한다"는 고리를 숫자로 따라가 본다. 방식 A, B, C의 $p_0 = (0.5, 0.3, 0.2)$, $q = (0.2, 0.5, 0.9)$일 때 $t = 3$번 거른 뒤 C를 쓸 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은?

<details><summary>풀이와 답</summary>

**주어진 값**
- $p_0(A) = 0.5$, $p_0(B) = 0.3$, $p_0(C) = 0.2$ (처음 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $q(A) = 0.2$, $q(B) = 0.5$, $q(C) = 0.9$ (정답률)
- $t = 3$ (반복 횟수)

**풀이**
1. 식을 그대로 쓴다: $p_t(C) = \dfrac{p_0(C)\, q(C)^t}{p_0(A)\, q(A)^t + p_0(B)\, q(B)^t + p_0(C)\, q(C)^t}$
2. 값을 대입한다: $p_3(C) = \dfrac{0.2 \times 0.9^3}{0.5 \times 0.2^3 + 0.3 \times 0.5^3 + 0.2 \times 0.9^3}$
3. 세제곱을 한다: $0.2^3 = 0.008$, $0.5^3 = 0.125$, $0.9^3 = 0.729$
4. 곱셈을 한다: $0.5 \times 0.008 = 0.004$, $0.3 \times 0.125 = 0.0375$, $0.2 \times 0.729 = 0.1458$ 이므로 $p_3(C) = \dfrac{0.1458}{0.004 + 0.0375 + 0.1458}$
5. 분모를 더한다: $0.004 + 0.0375 + 0.1458 = 0.1873$
6. 나눈다: $0.1458 \div 0.1873 = 0.7784$

**답**: $0.7784$. C의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 처음 $0.2$에서 세 번 만에 약 $0.78$이 된다. 정답률이 가장 높은 방식으로 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 몰린다.

</details>
