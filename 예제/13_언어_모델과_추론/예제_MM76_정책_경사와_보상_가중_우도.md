# 예제: 정책 경사와 보상 가중 우도

개념 노트: [MM76_정책_경사와_보상_가중_우도](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/13_%EC%96%B8%EC%96%B4_%EB%AA%A8%EB%8D%B8%EA%B3%BC_%EC%B6%94%EB%A1%A0/MM76_%EC%A0%95%EC%B1%85_%EA%B2%BD%EC%82%AC%EC%99%80_%EB%B3%B4%EC%83%81_%EA%B0%80%EC%A4%91_%EC%9A%B0%EB%8F%84.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 문제 번호 순서는 쉬운 것에서 어려운 것, 마지막 둘은 강의 내용과 잇는 문제다. 모델은 [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93)에 [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)를 씌운 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) $p_k$로 답 $k$를 뽑고, 답마다 보상 $r_k$가 있다.

## 기본 (직접 대입)

### 문제 1
모델이 세 답을 $p = (0.5, 0.25, 0.25)$의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)로 뽑고, 보상은 $r = (2, 0, -2)$다. 기대 보상 $J$는?

<details><summary>풀이와 답</summary>

**주어진 값**
- $p = (0.5,\ 0.25,\ 0.25)$ (세 답을 뽑을 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $r = (2,\ 0,\ -2)$ (세 답의 보상)

**풀이**
1. 식을 그대로 쓴다: $J(\theta) = \sum_{y} p_\theta(y)\, r(y)$
2. 값을 대입한다 (Σ를 세 항으로 펼침): $J = 0.5 \times 2 + 0.25 \times 0 + 0.25 \times (-2)$
3. 첫 항을 곱한다: $0.5 \times 2 = 1$
4. 둘째 항을 곱한다: $0.25 \times 0 = 0$
5. 셋째 항을 곱한다: $0.25 \times (-2) = -0.5$
6. 더한다: $1 + 0 + (-0.5) = 0.5$

**답**: $J = $ **0.5**

</details>

### 문제 2
답이 네 개이고 모델이 모두 같은 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)로 뽑는다. 보상이 $r = (4, 2, 0, -2)$이면 기대 보상은?

<details><summary>풀이와 답</summary>

**주어진 값**
- $p = (0.25,\ 0.25,\ 0.25,\ 0.25)$ (네 답을 뽑을 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0), $1/4$씩)
- $r = (4,\ 2,\ 0,\ -2)$ (네 답의 보상)

**풀이**
1. 식을 그대로 쓴다: $J = \sum_{y} p_\theta(y)\, r(y)$
2. 값을 대입한다 (Σ를 네 항으로 펼침): $J = 0.25 \times 4 + 0.25 \times 2 + 0.25 \times 0 + 0.25 \times (-2)$
3. 각 항을 곱한다: $1,\ 0.5,\ 0,\ -0.5$ 이므로 $J = 1 + 0.5 + 0 + (-0.5)$
4. 더한다: $1 + 0.5 + 0 - 0.5 = 1$

**답**: $J = $ **1**. [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 같으면 기대 보상은 보상의 평균과 같다 ($(4 + 2 + 0 - 2)/4 = 1$).

</details>

### 문제 3
문제 1의 모델에서 [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93) [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $\dfrac{\partial J}{\partial \theta_k} = p_k (r_k - J)$를 세 칸 모두 구하고, 세 값의 합을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p = (0.5,\ 0.25,\ 0.25)$, $r = (2,\ 0,\ -2)$ (문제 1)
- $J = 0.5$ (문제 1에서 구한 기대 보상)

**풀이**
1. 식을 그대로 쓴다: $\dfrac{\partial J}{\partial \theta_k} = p_k\,(r_k - J)$
2. 값을 대입한다: $\dfrac{\partial J}{\partial \theta_1} = 0.5\,(2 - 0.5)$, $\dfrac{\partial J}{\partial \theta_2} = 0.25\,(0 - 0.5)$, $\dfrac{\partial J}{\partial \theta_3} = 0.25\,(-2 - 0.5)$
3. 괄호 안을 뺀다: $2 - 0.5 = 1.5$, $0 - 0.5 = -0.5$, $-2 - 0.5 = -2.5$
4. 곱한다: $0.5 \times 1.5 = 0.75$, $0.25 \times (-0.5) = -0.125$, $0.25 \times (-2.5) = -0.625$
5. 세 값을 더한다: $0.75 + (-0.125) + (-0.625) = 0$

**답**: [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)는 **(0.75, -0.125, -0.625)**이고 합은 **0**. 평균(0.5)보다 나은 답 1은 오르고 못한 답 2, 3은 내린다. [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)에서는 전체를 한꺼번에 올리는 일이 없어 합이 0이다.

</details>

### 문제 4
두 답의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 $p = (0.7, 0.3)$이다. [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4) [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93)에서 2번 답을 더 자주 뽑게 하는 방향 $\nabla_\theta \ln p_\theta(y) = \mathbf{e}_y - \mathbf{p}$를 $y = 2$일 때 구하라. ($\mathbf{e}_2$는 2번 칸만 1인 벡터 $(0, 1)$이다.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{p} = (0.7,\ 0.3)$ (현재 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $y = 2$ ($\mathbf{e}_2 = (0, 1)$)

**풀이**
1. 식을 그대로 쓴다: $\nabla_\theta \ln p_\theta(y) = \mathbf{e}_y - \mathbf{p}$
2. 값을 대입한다: $\mathbf{e}_2 - \mathbf{p} = (0, 1) - (0.7, 0.3)$
3. 칸별로 뺀다: 첫 칸 $0 - 0.7 = -0.7$, 둘째 칸 $1 - 0.3 = 0.7$

**답**: **(-0.7, 0.7)**. [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93) 2를 올리고 [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93) 1을 내리는 방향이다. 이미 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 높은 답(1번)을 뽑았을 때보다 낮은 답(2번)을 뽑았을 때 더 크게 움직인다.

</details>

### 문제 5
답이 두 개이고 모델은 $p = (0.5, 0.5)$로 뽑는다. 보상은 $r = (1, 0)$이다. 표본 4개를 뽑았더니 1번, 2번, 2번, 2번이 나왔다. 표본으로 어림한 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $\frac{1}{N}\sum_i r(y_i)\, \nabla_\theta \ln p_\theta(y_i)$를 구하라. (정확한 값은 $(0.25, -0.25)$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{p} = (0.5,\ 0.5)$, $r(1) = 1$, $r(2) = 0$
- $y_1 = 1,\ y_2 = 2,\ y_3 = 2,\ y_4 = 2$ (뽑은 표본), $N = 4$

**풀이**
1. 식을 그대로 쓴다: $\nabla_\theta J \approx \dfrac{1}{N}\sum_{i=1}^{N} r(y_i)\, (\mathbf{e}_{y_i} - \mathbf{p})$
2. 값을 대입한다 (Σ를 네 항으로 펼침): $\dfrac{1}{4}\big[1 \times (\mathbf{e}_1 - \mathbf{p}) + 0 \times (\mathbf{e}_2 - \mathbf{p}) + 0 \times (\mathbf{e}_2 - \mathbf{p}) + 0 \times (\mathbf{e}_2 - \mathbf{p})\big]$
3. 1번 답의 방향을 뺀다: $\mathbf{e}_1 - \mathbf{p} = (1, 0) - (0.5, 0.5) = (0.5, -0.5)$
4. 보상을 곱한다: 첫 항은 $1 \times (0.5, -0.5) = (0.5, -0.5)$, 나머지 세 항은 보상이 0이라 $(0, 0)$
5. 칸별로 더한다: $(0.5 + 0 + 0 + 0,\ -0.5 + 0 + 0 + 0) = (0.5, -0.5)$
6. $N$으로 나눈다: $(0.5 / 4,\ -0.5 / 4) = (0.125, -0.125)$

**답**: **(0.125, -0.125)**. 방향은 맞지만 정확한 (0.25, -0.25)의 절반이다. 보상 1인 답이 4개 중 1번만 뽑혀서 어림이 약하게 나왔다.

</details>

### 문제 6
문제 5의 표본에 기준선 $b = $ 표본 평균 보상을 빼서 어림하라: $\frac{1}{N}\sum_i \big(r(y_i) - b\big)\, \nabla_\theta \ln p_\theta(y_i)$. 정확한 값 $(0.25, -0.25)$와 문제 5의 어림 중 어느 쪽이 가까운가?

<details><summary>풀이와 답</summary>

**주어진 값**
- 표본 $y = (1, 2, 2, 2)$, 표본의 보상 $r = (1, 0, 0, 0)$
- $\mathbf{e}_1 - \mathbf{p} = (0.5, -0.5)$, $\mathbf{e}_2 - \mathbf{p} = (-0.5, 0.5)$ (답마다의 방향)
- $N = 4$

**풀이**
1. 기준선을 구한다: $b = (1 + 0 + 0 + 0)/4 = 0.25$
2. 식을 그대로 쓴다: $\nabla_\theta J \approx \dfrac{1}{N}\sum_{i=1}^{N} \big(r(y_i) - b\big)\, (\mathbf{e}_{y_i} - \mathbf{p})$
3. 값을 대입한다 (Σ를 네 항으로 펼침): $\dfrac{1}{4}\big[(1 - 0.25)(0.5, -0.5) + 3 \times (0 - 0.25)(-0.5, 0.5)\big]$
4. 괄호 안 뺄셈: $1 - 0.25 = 0.75$, $0 - 0.25 = -0.25$
5. 첫 항을 곱한다: $0.75 \times (0.5, -0.5) = (0.375, -0.375)$
6. 나머지 세 항을 곱한다: $-0.25 \times (-0.5, 0.5) = (0.125, -0.125)$, 세 번이므로 $(0.375, -0.375)$
7. 칸별로 더한다: $(0.375 + 0.375,\ -0.375 - 0.375) = (0.75, -0.75)$
8. $N$으로 나눈다: $(0.75 / 4,\ -0.75 / 4) = (0.1875, -0.1875)$
9. 정확한 값 0.25와의 차이를 비교한다: 문제 5는 $0.25 - 0.125 = 0.125$, 기준선을 쓴 이번은 $0.25 - 0.1875 = 0.0625$

**답**: **(0.1875, -0.1875)**. 기준선을 뺀 쪽이 정확한 값에 더 가깝다. 보상 0인 답이 "평균보다 못하다"는 신호를 주기 때문이다.

</details>

### 문제 7
세 답의 [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93)이 $\theta = (0, 0, 0)$이고 보상은 $r = (3, 0, -3)$이다. [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0) 1로 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) 오르기를 한 번 하면($\theta \leftarrow \theta + \nabla_\theta J$) [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)과 기대 보상은 어떻게 되는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $\theta = (0, 0, 0)$ (처음 [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93)), 그래서 $p = (1/3, 1/3, 1/3)$
- $r = (3, 0, -3)$ (보상), [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0) 1

**풀이**
1. 처음 기대 보상을 구한다: $J = \frac{1}{3}\times 3 + \frac{1}{3}\times 0 + \frac{1}{3}\times(-3) = 1 + 0 + (-1) = 0$
2. [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) 식을 쓴다: $\dfrac{\partial J}{\partial \theta_k} = p_k\,(r_k - J)$
3. 값을 대입한다: $\frac{1}{3}(3 - 0)$, $\frac{1}{3}(0 - 0)$, $\frac{1}{3}(-3 - 0)$
4. 계산한다: $1,\ 0,\ -1$ 이므로 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)는 $(1, 0, -1)$
5. [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93)을 갱신한다: $\theta = (0 + 1,\ 0 + 0,\ 0 - 1) = (1, 0, -1)$
6. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 구한다 ($e$는 약 2.718, 계산기의 exp): $e^{1} = 2.7183$, $e^{0} = 1$, $e^{-1} = 0.3679$
7. 합을 구한다: $2.7183 + 1 + 0.3679 = 4.0862$
8. [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)로 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구한다: $2.7183 / 4.0862 = 0.6652$, $1 / 4.0862 = 0.2447$, $0.3679 / 4.0862 = 0.0900$
9. 새 기대 보상을 구한다: $0.6652 \times 3 + 0.2447 \times 0 + 0.0900 \times (-3) = 1.9956 + 0 - 0.27 = 1.7256$

**답**: [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) **(0.6652, 0.2447, 0.0900)**, 기대 보상이 **0에서 1.7256**으로 오른다. 보상 3인 답의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 크게 올랐다.

</details>

### 문제 8
세 답의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 $p = (0.2, 0.3, 0.5)$이고 보상이 모두 양수 $r = (4, 1, 2)$다. [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93) [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) 세 값을 구하고, 보상이 모두 양수인데도 어떤 답은 내려가는지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $p = (0.2,\ 0.3,\ 0.5)$ ([확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $r = (4,\ 1,\ 2)$ (보상)

**풀이**
1. 기대 보상의 식을 쓰고 대입한다: $J = \sum_y p_y r_y = 0.2 \times 4 + 0.3 \times 1 + 0.5 \times 2$
2. 곱한다: $0.8,\ 0.3,\ 1.0$ 이므로 $J = 0.8 + 0.3 + 1.0 = 2.1$
3. [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) 식을 쓴다: $\dfrac{\partial J}{\partial \theta_k} = p_k\,(r_k - J)$
4. 값을 대입한다: $0.2\,(4 - 2.1)$, $0.3\,(1 - 2.1)$, $0.5\,(2 - 2.1)$
5. 괄호 안을 뺀다: $1.9,\ -1.1,\ -0.1$
6. 곱한다: $0.2 \times 1.9 = 0.38$, $0.3 \times (-1.1) = -0.33$, $0.5 \times (-0.1) = -0.05$
7. 합을 구한다: $0.38 + (-0.33) + (-0.05) = 0$

**답**: [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) **(0.38, -0.33, -0.05)**. 보상이 모두 양수여도 평균 보상 $J = 2.1$보다 낮은 답 2, 3은 내려간다. 올라가는 것은 평균보다 나은 답 1뿐이고, [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)의 합은 0이다.

</details>

### 문제 9
[Lec21 10.3](../../Lec21_%EC%96%B8%EC%96%B4_%EB%AA%A8%EB%8D%B8.md#103-%EC%A0%95%EC%B1%85-%EA%B2%BD%EC%82%AC)의 [RLHF](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#rlhf-reinforcement-learning-from-human-feedback-%EC%82%AC%EB%9E%8C-%ED%94%BC%EB%93%9C%EB%B0%B1-%EA%B0%95%ED%99%94-%ED%95%99%EC%8A%B5) 둘째 단계는 [보상 모델](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#reward-model-%EB%B3%B4%EC%83%81-%EB%AA%A8%EB%8D%B8) 점수의 [기댓값](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#expectation-%EA%B8%B0%EB%8C%93%EA%B0%92)을 키우는 일이다. 요약 후보 3개를 모델이 $p = (0.6, 0.3, 0.1)$로 뽑고 [보상 모델](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#reward-model-%EB%B3%B4%EC%83%81-%EB%AA%A8%EB%8D%B8) 점수가 $r = (0.8, 0.5, -1)$이다. 기대 점수 $J$와, 가장 나쁜 요약(3번)의 [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93) [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)는?

<details><summary>풀이와 답</summary>

**주어진 값**
- $p = (0.6,\ 0.3,\ 0.1)$ (세 요약을 뽑을 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $r = (0.8,\ 0.5,\ -1)$ ([보상 모델](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#reward-model-%EB%B3%B4%EC%83%81-%EB%AA%A8%EB%8D%B8) 점수)

**풀이**
1. 식을 그대로 쓴다: $J = \sum_y p_\theta(y)\, r(y)$, $\dfrac{\partial J}{\partial \theta_3} = p_3\,(r_3 - J)$
2. 값을 대입한다 (Σ를 세 항으로 펼침): $J = 0.6 \times 0.8 + 0.3 \times 0.5 + 0.1 \times (-1)$
3. 각 항을 곱한다: $0.48,\ 0.15,\ -0.1$
4. 더한다: $0.48 + 0.15 + (-0.1) = 0.53$
5. [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)에 대입한다: $\dfrac{\partial J}{\partial \theta_3} = 0.1 \times (-1 - 0.53)$
6. 괄호 안을 뺀다: $-1 - 0.53 = -1.53$
7. 곱한다: $0.1 \times (-1.53) = -0.153$

**답**: $J = $ **0.53**, 3번 요약의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) **-0.153**. 음수이므로 경사 오르기에서 3번 요약의 [로짓](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logit-%EB%A1%9C%EC%A7%93)이 내려간다.

</details>

### 문제 10
[Lec21 10.3](../../Lec21_%EC%96%B8%EC%96%B4_%EB%AA%A8%EB%8D%B8.md#103-%EC%A0%95%EC%B1%85-%EA%B2%BD%EC%82%AC)에서 보상 점수만 최대화하면 [보상 모델](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#reward-model-%EB%B3%B4%EC%83%81-%EB%AA%A8%EB%8D%B8)의 빈틈을 파고든다는 이야기를 한다. [RLHF](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#rlhf-reinforcement-learning-from-human-feedback-%EC%82%AC%EB%9E%8C-%ED%94%BC%EB%93%9C%EB%B0%B1-%EA%B0%95%ED%99%94-%ED%95%99%EC%8A%B5)는 목표에 $-\beta\, D_{KL}(p_\theta \,\|\, p_{\text{ref}})$를 더한다. 두 답에서 현재 모델 $p_\theta = (0.8, 0.2)$, 기준 모델 $p_{\text{ref}} = (0.5, 0.5)$, 보상 $r = (1, 0)$, $\beta = 0.1$일 때 벌점을 뺀 목표값 $J - \beta D_{KL}$을 구하라. ($D_{KL}(p \,\|\, q) = \sum_k p_k \ln \dfrac{p_k}{q_k}$, $\ln 1.6 = 0.4700$, $\ln 0.4 = -0.9163$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $p_\theta = (0.8,\ 0.2)$, $p_{\text{ref}} = (0.5,\ 0.5)$ (현재 모델, 기준 모델)
- $r = (1,\ 0)$ (보상), $\beta = 0.1$ (벌점의 세기)
- $\ln 1.6 = 0.4700$, $\ln 0.4 = -0.9163$ ($\ln a$는 "$e$를 몇 제곱해야 $a$가 되나")

**풀이**
1. 기대 보상의 식을 쓰고 대입한다: $J = 0.8 \times 1 + 0.2 \times 0$
2. 곱하고 더한다: $0.8 + 0 = 0.8$
3. KL의 식을 쓰고 대입한다: $D_{KL} = 0.8 \ln \dfrac{0.8}{0.5} + 0.2 \ln \dfrac{0.2}{0.5}$
4. 나눈다: $0.8 / 0.5 = 1.6$, $0.2 / 0.5 = 0.4$ 이므로 $D_{KL} = 0.8 \ln 1.6 + 0.2 \ln 0.4$
5. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 대입한다: $D_{KL} = 0.8 \times 0.4700 + 0.2 \times (-0.9163)$
6. 곱한다: $0.8 \times 0.4700 = 0.3760$, $0.2 \times (-0.9163) = -0.1833$
7. 더한다: $0.3760 + (-0.1833) = 0.1927$
8. 벌점을 곱한다: $\beta D_{KL} = 0.1 \times 0.1927 = 0.01927$
9. 뺀다: $J - \beta D_{KL} = 0.8 - 0.01927 = 0.7807$

**답**: **0.7807**. 기대 보상 0.8에서 기준 모델과 멀어진 만큼의 벌점 0.0193을 뺀 값이다. 모델이 기준 모델에서 더 멀어질수록 벌점이 커져 보상 해킹을 막는다.

</details>
