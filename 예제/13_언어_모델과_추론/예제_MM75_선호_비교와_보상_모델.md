# 예제: 선호 비교와 보상 모델

개념 노트: [MM75_선호_비교와_보상_모델](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/13_%EC%96%B8%EC%96%B4_%EB%AA%A8%EB%8D%B8%EA%B3%BC_%EC%B6%94%EB%A1%A0/MM75_%EC%84%A0%ED%98%B8_%EB%B9%84%EA%B5%90%EC%99%80_%EB%B3%B4%EC%83%81_%EB%AA%A8%EB%8D%B8.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 문제 번호 순서는 쉬운 것에서 어려운 것, 마지막 둘은 강의 내용과 잇는 문제다. [시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C)는 $\sigma(z) = \dfrac{1}{1 + e^{-z}}$이고, $e$는 약 2.718인 수, $\ln a$는 "$e$를 몇 제곱해야 $a$가 되나"다 (계산기의 exp, ln 키로 구한다).

## 기본 (직접 대입)

### 문제 1
[보상 모델](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#reward-model-%EB%B3%B4%EC%83%81-%EB%AA%A8%EB%8D%B8)이 사람이 고른 답 $y_w$에 3점, 고르지 않은 답 $y_l$에 1점을 주었다. $y_w$가 이길 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)과 이 쌍의 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은?

<details><summary>풀이와 답</summary>

**주어진 값**
- $r_\phi(x, y_w) = 3$ (사람이 고른 답의 점수)
- $r_\phi(x, y_l) = 1$ (고르지 않은 답의 점수)

**풀이**
1. 식을 그대로 쓴다: $P = \sigma(r_w - r_l) = \dfrac{1}{1 + e^{-(r_w - r_l)}}$, $\mathcal{L}_{\text{RM}} = -\ln P$
2. 값을 대입한다: $P = \dfrac{1}{1 + e^{-(3 - 1)}}$
3. 점수 차를 뺀다: $3 - 1 = 2$ 이므로 $P = \dfrac{1}{1 + e^{-2}}$
4. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^{-2} = 0.1353$ 이므로 $P = \dfrac{1}{1 + 0.1353}$
5. 분모를 더한다: $1 + 0.1353 = 1.1353$
6. 나눈다: $1 / 1.1353 = 0.8808$
7. [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 구한다: $\ln 0.8808 = -0.1269$ 이므로 $\mathcal{L}_{\text{RM}} = 0.1269$

**답**: 이길 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) **0.8808**, [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) **0.1269**. 점수 차가 커서 모델이 꽤 확신하고, 그 확신이 맞아 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 작다.

</details>

### 문제 2
[보상 모델](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#reward-model-%EB%B3%B4%EC%83%81-%EB%AA%A8%EB%8D%B8)이 반대로 믿는 경우다. 사람이 고른 답 $y_w$에 1점, 고르지 않은 답 $y_l$에 2점을 주었다. 이길 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)과 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은?

<details><summary>풀이와 답</summary>

**주어진 값**
- $r_\phi(x, y_w) = 1$ (사람이 고른 답의 점수)
- $r_\phi(x, y_l) = 2$ (고르지 않은 답의 점수)

**풀이**
1. 식을 그대로 쓴다: $P = \dfrac{1}{1 + e^{-(r_w - r_l)}}$, $\mathcal{L}_{\text{RM}} = -\ln P$
2. 값을 대입한다: $P = \dfrac{1}{1 + e^{-(1 - 2)}}$
3. 점수 차를 뺀다: $1 - 2 = -1$ 이므로 $P = \dfrac{1}{1 + e^{-(-1)}} = \dfrac{1}{1 + e^{1}}$
4. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^{1} = 2.7183$ 이므로 $P = \dfrac{1}{1 + 2.7183}$
5. 분모를 더한다: $1 + 2.7183 = 3.7183$
6. 나눈다: $1 / 3.7183 = 0.2689$
7. [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 구한다: $\ln 0.2689 = -1.3133$ 이므로 $\mathcal{L}_{\text{RM}} = 1.3133$

**답**: 이길 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) **0.2689**, [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) **1.3133**. 틀리게 믿으면 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 크다.

</details>

### 문제 3
점수 차 $\Delta = r_w - r_l = 1$일 때 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $-\ln \sigma(\Delta)$의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $\sigma(\Delta) - 1$을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\Delta = 1$ (점수 차)

**풀이**
1. 식을 그대로 쓴다: $\dfrac{\partial \mathcal{L}}{\partial r_w} = \sigma(\Delta) - 1$, $\sigma(\Delta) = \dfrac{1}{1 + e^{-\Delta}}$
2. 값을 대입한다: $\sigma(1) - 1 = \dfrac{1}{1 + e^{-1}} - 1$
3. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^{-1} = 0.3679$ 이므로 $\dfrac{1}{1 + 0.3679} - 1$
4. 분모를 더한다: $1 + 0.3679 = 1.3679$
5. 나눈다: $1 / 1.3679 = 0.7311$
6. 뺀다: $0.7311 - 1 = -0.2689$

**답**: [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) **-0.2689**. 음수이므로 $r_w$를 올리면 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 줄고, $r_l$의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)는 부호가 반대(+0.2689)라 $r_l$은 내린다.

</details>

### 문제 4
어떤 질문에서 [보상 모델](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#reward-model-%EB%B3%B4%EC%83%81-%EB%AA%A8%EB%8D%B8)이 두 답에 103.5점과 102.5점을 주었다. 사람은 103.5점짜리를 골랐다. 103.5점이 이길 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은? 그리고 이 값이 점수 4.5와 3.5(같은 차이 1)일 때와 같은지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $r_\phi(x, y_w) = 103.5$, $r_\phi(x, y_l) = 102.5$ (두 점수)

**풀이**
1. 식을 그대로 쓴다: $P = \dfrac{1}{1 + e^{-(r_w - r_l)}}$
2. 값을 대입한다: $P = \dfrac{1}{1 + e^{-(103.5 - 102.5)}}$
3. 점수 차를 뺀다: $103.5 - 102.5 = 1$ 이므로 $P = \dfrac{1}{1 + e^{-1}}$
4. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^{-1} = 0.3679$ 이므로 $P = \dfrac{1}{1.3679}$
5. 나눈다: $1 / 1.3679 = 0.7311$
6. 4.5와 3.5로 비교한다: $4.5 - 3.5 = 1$ 이므로 같은 식 $\dfrac{1}{1 + e^{-1}} = 0.7311$

**답**: **0.7311**이고 4.5, 3.5일 때와 **같다**. [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은 점수의 차이만 쓰므로 점수 자체의 크기에는 뜻이 없다.

</details>

### 문제 5
처음 점수가 $r_w = 1$, $r_l = 0$이다. [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0) $\eta = 0.5$로 점수를 한 번 갱신하면 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은 얼마에서 얼마로 줄어드는가? (점수 자체를 [파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0)로 보는 단순화)

<details><summary>풀이와 답</summary>

**주어진 값**
- $r_w = 1$, $r_l = 0$ (처음 점수)
- $\eta = 0.5$ ([학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0))

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L} = -\ln \sigma(r_w - r_l)$, $\dfrac{\partial \mathcal{L}}{\partial r_w} = \sigma(r_w - r_l) - 1$
2. 점수 차를 뺀다: $1 - 0 = 1$
3. 처음 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 구한다: $\sigma(1) = 0.7311$, $-\ln 0.7311 = 0.3133$
4. [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)를 구한다: $0.7311 - 1 = -0.2689$
5. $r_w$를 갱신한다. 경사 하강은 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)의 반대로 간다: $r_w = 1 - 0.5 \times (-0.2689) = 1 + 0.1345 = 1.1345$
6. $r_l$을 갱신한다. $r_l$의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)는 부호가 반대(+0.2689)다: $r_l = 0 - 0.5 \times 0.2689 = -0.1345$
7. 새 점수 차를 뺀다: $1.1345 - (-0.1345) = 1.2689$
8. 새 [시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C)를 구한다: $e^{-1.2689} = 0.2811$, $1 + 0.2811 = 1.2811$, $1 / 1.2811 = 0.7806$
9. 새 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 구한다: $-\ln 0.7806 = 0.2477$

**답**: [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 **0.3133에서 0.2477**로 줄어든다. 고른 쪽 점수는 오르고 안 고른 쪽 점수는 같은 만큼 내린다.

</details>

### 문제 6
선호 쌍 세 개의 점수 차가 $\Delta = 2,\ 0,\ -1$이다. 평균 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $\frac{1}{3}\sum_i -\ln \sigma(\Delta_i)$을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\Delta_1 = 2$, $\Delta_2 = 0$, $\Delta_3 = -1$ (점수 차)
- 쌍의 수 $= 3$

**풀이**
1. 식을 그대로 쓴다: $\bar{\mathcal{L}} = \dfrac{1}{3}\sum_{i=1}^{3} -\ln \sigma(\Delta_i)$
2. 값을 대입한다 (Σ를 세 항으로 펼침): $\bar{\mathcal{L}} = \dfrac{1}{3}\big(-\ln \sigma(2) - \ln \sigma(0) - \ln \sigma(-1)\big)$
3. [시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C)를 구한다: $\sigma(2) = 0.8808$, $\sigma(0) = 1/(1 + e^{0}) = 1/2 = 0.5$, $\sigma(-1) = 0.2689$
4. [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 구한다: $-\ln 0.8808 = 0.1269$, $-\ln 0.5 = 0.6931$, $-\ln 0.2689 = 1.3133$
5. 세 항을 더한다: $0.1269 + 0.6931 + 1.3133 = 2.1333$
6. 3으로 나눈다: $2.1333 / 3 = 0.7111$

**답**: 평균 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) **0.7111**. 틀리게 믿는 쌍(-1) 하나가 평균을 많이 끌어올린다.

</details>

### 문제 7
세 답 A, B, C의 점수가 2, 1, 0이다. 사람이 A를 B보다, B를 C보다 낫다고 골랐다. [보상 모델](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#reward-model-%EB%B3%B4%EC%83%81-%EB%AA%A8%EB%8D%B8)이 두 선택을 모두 맞힐 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은? (두 선택이 서로 [독립](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#independence-%EB%8F%85%EB%A6%BD)이라 곱한다.) 또 두 쌍의 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 더하면?

<details><summary>풀이와 답</summary>

**주어진 값**
- $r_A = 2$, $r_B = 1$, $r_C = 0$ (세 점수)
- 선택: $A \succ B$, $B \succ C$

**풀이**
1. 식을 그대로 쓴다: $P(A \succ B) = \sigma(r_A - r_B)$, $P(B \succ C) = \sigma(r_B - r_C)$
2. 값을 대입한다: $P(A \succ B) = \sigma(2 - 1)$, $P(B \succ C) = \sigma(1 - 0)$
3. 점수 차를 뺀다: 두 차이 모두 $1$ 이므로 두 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 모두 $\sigma(1)$
4. [시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C)를 구한다: $\sigma(1) = \dfrac{1}{1 + 0.3679} = 0.7311$
5. 곱한다: $0.7311 \times 0.7311 = 0.5345$
6. 쌍마다 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 구한다: $-\ln 0.7311 = 0.3133$
7. 두 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 더한다: $0.3133 + 0.3133 = 0.6265$

**답**: 두 선택을 모두 맞힐 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) **0.5345**, [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)의 합 **0.6265**. [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 곱한 것의 $-\ln$은 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 더한 것과 같다 ($-\ln 0.5345 = 0.6265$).

</details>

### 문제 8
[DPO](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dpo-direct-preference-optimization-%EC%A7%81%EC%A0%91-%EC%84%A0%ED%98%B8-%EC%B5%9C%EC%A0%81%ED%99%94) [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 구하라. 고른 답 $y_w$에 지금 모델은 0.4, 기준 모델은 0.2를 주고, 안 고른 답 $y_l$에는 지금 모델이 0.1, 기준 모델이 0.2를 준다. $\beta = 0.5$다.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\pi_\theta(y_w \mid x) = 0.4$, $\pi_{\text{ref}}(y_w \mid x) = 0.2$ (고른 답의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $\pi_\theta(y_l \mid x) = 0.1$, $\pi_{\text{ref}}(y_l \mid x) = 0.2$ (안 고른 답의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $\beta = 0.5$ (세기)

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_{\text{DPO}} = -\ln \sigma\Big(\beta \ln \dfrac{\pi_\theta(y_w \mid x)}{\pi_{\text{ref}}(y_w \mid x)} - \beta \ln \dfrac{\pi_\theta(y_l \mid x)}{\pi_{\text{ref}}(y_l \mid x)}\Big)$
2. 값을 대입한다: $\mathcal{L}_{\text{DPO}} = -\ln \sigma\Big(0.5 \ln \dfrac{0.4}{0.2} - 0.5 \ln \dfrac{0.1}{0.2}\Big)$
3. 나눗셈을 먼저 한다: $0.4 / 0.2 = 2$, $0.1 / 0.2 = 0.5$ 이므로 $-\ln \sigma(0.5 \ln 2 - 0.5 \ln 0.5)$
4. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 계산한다: $\ln 2 = 0.6931$, $\ln 0.5 = -0.6931$ 이므로 $-\ln \sigma(0.5 \times 0.6931 - 0.5 \times (-0.6931))$
5. 곱한다: $0.5 \times 0.6931 = 0.3466$, $0.5 \times (-0.6931) = -0.3466$
6. 뺀다: $0.3466 - (-0.3466) = 0.6931$ 이므로 $-\ln \sigma(0.6931)$
7. [시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C)를 계산한다: $e^{-0.6931} = 0.5$, $1 + 0.5 = 1.5$, $1 / 1.5 = 0.6667$
8. 음의 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 씌운다: $-\ln 0.6667 = 0.4055$

**답**: **0.4055**. 반반(점수 차 0)일 때의 $\ln 2 = 0.6931$보다 작다.

</details>

### 문제 9
[Lec21 10.2](../../Lec21_%EC%96%B8%EC%96%B4_%EB%AA%A8%EB%8D%B8.md#102-%EB%B3%B4%EC%83%81-%EB%AA%A8%EB%8D%B8)의 슬라이드 요약 두 개의 점수는 $s_1 = 4.8$, $s_2 = 4.3$이다. 이번에는 사람이 $s_2$를 골랐다고 하자. [보상 모델](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#reward-model-%EB%B3%B4%EC%83%81-%EB%AA%A8%EB%8D%B8)이 본 "사람이 고른 쪽이 이길 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)"과 이 쌍의 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은?

<details><summary>풀이와 답</summary>

**주어진 값**
- $r_\phi(x, y_w) = 4.3$ (사람이 고른 $s_2$의 점수)
- $r_\phi(x, y_l) = 4.8$ (고르지 않은 $s_1$의 점수)

**풀이**
1. 식을 그대로 쓴다: $P = \sigma(r_w - r_l) = \dfrac{1}{1 + e^{-(r_w - r_l)}}$, $\mathcal{L}_{\text{RM}} = -\ln P$
2. 값을 대입한다: $P = \dfrac{1}{1 + e^{-(4.3 - 4.8)}}$
3. 점수 차를 뺀다: $4.3 - 4.8 = -0.5$ 이므로 $P = \dfrac{1}{1 + e^{0.5}}$
4. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^{0.5} = 1.6487$ 이므로 $P = \dfrac{1}{1 + 1.6487}$
5. 분모를 더한다: $1 + 1.6487 = 2.6487$
6. 나눈다: $1 / 2.6487 = 0.3775$
7. [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 구한다: $\ln 0.3775 = -0.9741$ 이므로 $\mathcal{L}_{\text{RM}} = 0.9741$

**답**: [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) **0.3775**, [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) **0.9741**. 사람이 $s_1$을 골랐을 때의 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) 0.4741보다 크다. 모델이 믿는 쪽과 사람의 선택이 어긋나면 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 커지고, [학습](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5)이 그 어긋남을 줄인다.

</details>

### 문제 10
[Lec21 10.4](../../Lec21_%EC%96%B8%EC%96%B4_%EB%AA%A8%EB%8D%B8.md#104-%EB%B3%B4%EC%83%81-%EB%AA%A8%EB%8D%B8-%EC%97%86%EC%9D%B4-dpo)의 [DPO](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dpo-direct-preference-optimization-%EC%A7%81%EC%A0%91-%EC%84%A0%ED%98%B8-%EC%B5%9C%EC%A0%81%ED%99%94)를 숫자로 본다. $\beta = 1$이다. (a) 출발점에서는 지금 모델이 기준 모델과 같다($\pi_\theta = \pi_{\text{ref}}$). [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은? (b) [학습](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5) 뒤 고른 답의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 $\pi_\theta(y_w) = 0.25$($\pi_{\text{ref}}(y_w) = 0.2$), 안 고른 답이 $\pi_\theta(y_l) = 0.16$($\pi_{\text{ref}}(y_l) = 0.2$)이 되었다. [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은?

<details><summary>풀이와 답</summary>

**주어진 값**
- $\beta = 1$ (세기)
- (a) $\pi_\theta(y_w) = \pi_{\text{ref}}(y_w) = 0.2$, $\pi_\theta(y_l) = \pi_{\text{ref}}(y_l) = 0.2$
- (b) $\pi_\theta(y_w) = 0.25$, $\pi_{\text{ref}}(y_w) = 0.2$, $\pi_\theta(y_l) = 0.16$, $\pi_{\text{ref}}(y_l) = 0.2$

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_{\text{DPO}} = -\ln \sigma\Big(\beta \ln \dfrac{\pi_\theta(y_w)}{\pi_{\text{ref}}(y_w)} - \beta \ln \dfrac{\pi_\theta(y_l)}{\pi_{\text{ref}}(y_l)}\Big)$
2. (a) 값을 대입한다: $-\ln \sigma\Big(1 \times \ln \dfrac{0.2}{0.2} - 1 \times \ln \dfrac{0.2}{0.2}\Big)$
3. 나눈다: $0.2 / 0.2 = 1$, $\ln 1 = 0$ 이므로 $-\ln \sigma(0 - 0) = -\ln \sigma(0)$
4. [시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C)를 구한다: $\sigma(0) = 1/(1 + e^{0}) = 1/2 = 0.5$
5. 음의 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 씌운다: $-\ln 0.5 = 0.6931$
6. (b) 값을 대입한다: $-\ln \sigma\Big(\ln \dfrac{0.25}{0.2} - \ln \dfrac{0.16}{0.2}\Big)$
7. 나눈다: $0.25 / 0.2 = 1.25$, $0.16 / 0.2 = 0.8$ 이므로 $-\ln \sigma(\ln 1.25 - \ln 0.8)$
8. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 계산한다: $\ln 1.25 = 0.2231$, $\ln 0.8 = -0.2231$
9. 뺀다: $0.2231 - (-0.2231) = 0.4463$ 이므로 $-\ln \sigma(0.4463)$
10. [시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C)를 계산한다: $e^{-0.4463} = 0.6400$, $1 + 0.6400 = 1.6400$, $1 / 1.6400 = 0.6098$
11. 음의 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 씌운다: $-\ln 0.6098 = 0.4947$

**답**: (a) **0.6931**, (b) **0.4947**. 고른 답의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 기준보다 올리고 안 고른 답을 내리면 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 줄어든다. [학습](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5)은 이 방향으로 모델을 움직인다.

</details>
