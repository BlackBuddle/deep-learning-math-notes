## 기본 (직접 대입)

### 문제 1
직선 $f(x) = x$ 아래의 넓이를 구간 0~2에서 막대 4개(높이는 각 칸의 왼쪽 끝 값)로 어림하라. 정확한 넓이는 2다.

<details><summary>풀이와 답</summary>

**주어진 값**
- $f(x) = x$ (막대 높이를 정하는 함수)
- $a = 0,\ b = 2$ (구간)
- $n = 4$ (막대 수)
- 정확한 넓이 2 (밑변 2, 높이 2인 삼각형: 2 × 2 ÷ 2)

**풀이**
1. 식을 그대로 쓴다: $\sum_{i=0}^{n-1} f(x_i)\,\Delta x$, 여기서 $\Delta x = \frac{b-a}{n}$
2. 값을 대입한다: $\sum_{i=0}^{3} f(x_i) \times \frac{2 - 0}{4}$
3. 막대 너비를 구한다: (2 − 0) ÷ 4 = 0.5 이므로 $\sum_{i=0}^{3} f(x_i) \times 0.5$
4. 왼쪽 끝을 구한다 (0.5씩 더함): $x_0 = 0,\ x_1 = 0.5,\ x_2 = 1,\ x_3 = 1.5$
5. Σ를 네 항으로 펼친다: $f(0) \times 0.5 + f(0.5) \times 0.5 + f(1) \times 0.5 + f(1.5) \times 0.5$
6. f(x) = x라서 높이는 x 그대로다: $0 \times 0.5 + 0.5 \times 0.5 + 1 \times 0.5 + 1.5 \times 0.5$
7. 곱셈을 한다: 0 + 0.25 + 0.5 + 0.75
8. 더한다: 0 + 0.25 + 0.5 + 0.75 = 1.5

**답**: 1.5 (정확한 값 2보다 0.5 작다. 왼쪽 끝 높이라 막대가 직선 아래에 놓인다)

</details>

### 문제 2
$f(x) = x^2$ 아래의 넓이를 구간 0~2에서 막대 4개(왼쪽 끝 높이)로 어림하라. 정확한 넓이는 $\frac{8}{3} \approx 2.667$이다.

<details><summary>풀이와 답</summary>

**주어진 값**
- $f(x) = x^2$ (막대 높이를 정하는 함수)
- $a = 0,\ b = 2$, $n = 4$

**풀이**
1. 식을 그대로 쓴다: $\sum_{i=0}^{n-1} f(x_i)\,\Delta x$, $\Delta x = \frac{b-a}{n}$
2. 값을 대입한다: $\sum_{i=0}^{3} f(x_i) \times \frac{2 - 0}{4}$
3. 막대 너비를 구한다: (2 − 0) ÷ 4 = 0.5 이므로 $\sum_{i=0}^{3} f(x_i) \times 0.5$
4. 왼쪽 끝을 구한다: $x_0 = 0,\ x_1 = 0.5,\ x_2 = 1,\ x_3 = 1.5$
5. Σ를 네 항으로 펼친다: $f(0) \times 0.5 + f(0.5) \times 0.5 + f(1) \times 0.5 + f(1.5) \times 0.5$
6. 높이를 제곱으로 구한다: $0^2 = 0$, $0.5^2 = 0.25$, $1^2 = 1$, $1.5^2 = 2.25$ 이므로 $0 \times 0.5 + 0.25 \times 0.5 + 1 \times 0.5 + 2.25 \times 0.5$
7. 곱셈을 한다: 0 + 0.125 + 0.5 + 1.125
8. 더한다: 0 + 0.125 + 0.5 + 1.125 = 1.75

**답**: 1.75 (정확한 값 2.667보다 작다. 곡선이 올라가는 모양이라 왼쪽 끝 막대는 늘 모자란다)

</details>

### 문제 3
$f(x) = x^2$ 아래의 넓이를 구간 0~1에서 막대 4개로 어림하되, 이번에는 높이를 각 칸의 **오른쪽 끝** 값으로 정하라. 정확한 넓이는 $\frac{1}{3}$이다.

<details><summary>풀이와 답</summary>

**주어진 값**
- $f(x) = x^2$
- $a = 0,\ b = 1$, $n = 4$
- 높이는 오른쪽 끝 $x_i + \Delta x$에서 잰다

**풀이**
1. 식을 그대로 쓴다: $\sum f(\text{오른쪽 끝}) \times \Delta x$, $\Delta x = \frac{b-a}{n}$
2. 막대 너비를 구한다: (1 − 0) ÷ 4 = 0.25 이므로 $\Delta x = 0.25$
3. 오른쪽 끝을 구한다: $0.25,\ 0.5,\ 0.75,\ 1$
4. 값을 대입한다 (Σ를 네 항으로 펼침): $f(0.25) \times 0.25 + f(0.5) \times 0.25 + f(0.75) \times 0.25 + f(1) \times 0.25$
5. 높이를 제곱으로 구한다: $0.25^2 = 0.0625$, $0.5^2 = 0.25$, $0.75^2 = 0.5625$, $1^2 = 1$
6. 높이를 더해 한꺼번에 곱한다: $(0.0625 + 0.25 + 0.5625 + 1) \times 0.25$
7. 괄호 안을 더한다: 0.0625 + 0.25 = 0.3125, 0.3125 + 0.5625 = 0.875, 0.875 + 1 = 1.875
8. 곱셈을 한다: 1.875 × 0.25 = 0.46875

**답**: 0.46875 (정확한 값 0.3333보다 크다. 올라가는 곡선에서는 오른쪽 끝 막대가 넘치고, 왼쪽 끝 막대(0.21875)는 모자란다)

</details>

### 문제 4
$\mathrm{bump}(x) = \mathrm{ReLU}(x) - 2\,\mathrm{ReLU}(x-1) + \mathrm{ReLU}(x-2)$에서 $x = 0.75$와 $x = 2.5$의 값을 구하라. ($\mathrm{ReLU}(z)$는 z가 0보다 작으면 0, 아니면 z)

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathrm{bump}(x) = \mathrm{ReLU}(x) - 2\,\mathrm{ReLU}(x-1) + \mathrm{ReLU}(x-2)$
- $x = 0.75$, $x = 2.5$

**풀이**
1. 식을 그대로 쓴다: $\mathrm{bump}(x) = \mathrm{ReLU}(x) - 2\,\mathrm{ReLU}(x-1) + \mathrm{ReLU}(x-2)$
2. $x = 0.75$를 대입한다: $\mathrm{ReLU}(0.75) - 2\,\mathrm{ReLU}(0.75 - 1) + \mathrm{ReLU}(0.75 - 2)$
3. 괄호 안을 계산한다: 0.75 − 1 = −0.25, 0.75 − 2 = −1.25 이므로 $\mathrm{ReLU}(0.75) - 2\,\mathrm{ReLU}(-0.25) + \mathrm{ReLU}(-1.25)$
4. [ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8)를 적용한다 (음수는 0): $0.75 - 2 \times 0 + 0$
5. 계산한다: 0.75 − 0 + 0 = 0.75
6. $x = 2.5$를 대입한다: $\mathrm{ReLU}(2.5) - 2\,\mathrm{ReLU}(2.5 - 1) + \mathrm{ReLU}(2.5 - 2)$
7. 괄호 안을 계산한다: 2.5 − 1 = 1.5, 2.5 − 2 = 0.5 이므로 $\mathrm{ReLU}(2.5) - 2\,\mathrm{ReLU}(1.5) + \mathrm{ReLU}(0.5)$
8. [ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8)를 적용한다 (모두 0 이상이라 그대로): $2.5 - 2 \times 1.5 + 0.5$
9. 곱셈을 한다: 2 × 1.5 = 3 이므로 $2.5 - 3 + 0.5$
10. 계산한다: 2.5 − 3 = −0.5, −0.5 + 0.5 = 0

**답**: $\mathrm{bump}(0.75) = 0.75$, $\mathrm{bump}(2.5) = 0$ (봉우리 바깥에서는 0)

</details>

### 문제 5
높이가 2인 봉우리 $2\,\mathrm{ReLU}(x) - 4\,\mathrm{ReLU}(x-1) + 2\,\mathrm{ReLU}(x-2)$의 $x = 0.5$, $1$, $1.5$ 값을 구하라. 본문의 높이 1 봉우리와 어떤 관계인가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $h(x) = 2\,\mathrm{ReLU}(x) - 4\,\mathrm{ReLU}(x-1) + 2\,\mathrm{ReLU}(x-2)$
- $x = 0.5,\ 1,\ 1.5$

**풀이**
1. 식을 그대로 쓴다: $h(x) = 2\,\mathrm{ReLU}(x) - 4\,\mathrm{ReLU}(x-1) + 2\,\mathrm{ReLU}(x-2)$
2. $x = 0.5$를 대입한다: $2\,\mathrm{ReLU}(0.5) - 4\,\mathrm{ReLU}(-0.5) + 2\,\mathrm{ReLU}(-1.5)$
3. [ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8)를 적용한다 (음수는 0): $2 \times 0.5 - 4 \times 0 + 2 \times 0$
4. 계산한다: 1 − 0 + 0 = 1
5. $x = 1$을 대입한다: $2\,\mathrm{ReLU}(1) - 4\,\mathrm{ReLU}(0) + 2\,\mathrm{ReLU}(-1)$
6. [ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8)를 적용한다: $2 \times 1 - 4 \times 0 + 2 \times 0$
7. 계산한다: 2 − 0 + 0 = 2
8. $x = 1.5$를 대입한다: $2\,\mathrm{ReLU}(1.5) - 4\,\mathrm{ReLU}(0.5) + 2\,\mathrm{ReLU}(-0.5)$
9. [ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8)를 적용한다: $2 \times 1.5 - 4 \times 0.5 + 2 \times 0$
10. 곱셈을 하고 계산한다: 3 − 2 + 0 = 1

**답**: 1, 2, 1. 높이 1 봉우리를 통째로 2배한 것이다. 각 [ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8) 앞의 계수(은닉 유닛의 출력 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98))를 키우면 봉우리가 높아진다.

</details>

### 문제 6
$r(x) = \mathrm{ReLU}(x) - \mathrm{ReLU}(x-1)$의 값을 $x = -1,\ 0.5,\ 3$에서 구하고, 이 함수가 어떤 모양인지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $r(x) = \mathrm{ReLU}(x) - \mathrm{ReLU}(x-1)$
- $x = -1,\ 0.5,\ 3$

**풀이**
1. 식을 그대로 쓴다: $r(x) = \mathrm{ReLU}(x) - \mathrm{ReLU}(x-1)$
2. $x = -1$을 대입한다: $\mathrm{ReLU}(-1) - \mathrm{ReLU}(-1 - 1)$
3. 괄호 안을 계산한다: −1 − 1 = −2 이므로 $\mathrm{ReLU}(-1) - \mathrm{ReLU}(-2)$
4. [ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8)를 적용한다: $0 - 0 = 0$
5. $x = 0.5$를 대입한다: $\mathrm{ReLU}(0.5) - \mathrm{ReLU}(0.5 - 1)$
6. 괄호 안을 계산한다: 0.5 − 1 = −0.5 이므로 $\mathrm{ReLU}(0.5) - \mathrm{ReLU}(-0.5)$
7. [ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8)를 적용하고 뺀다: 0.5 − 0 = 0.5
8. $x = 3$을 대입한다: $\mathrm{ReLU}(3) - \mathrm{ReLU}(3 - 1)$
9. 괄호 안을 계산한다: 3 − 1 = 2 이므로 $\mathrm{ReLU}(3) - \mathrm{ReLU}(2)$
10. [ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8)를 적용하고 뺀다: 3 − 2 = 1

**답**: 0, 0.5, 1. 0 이하에서는 0, 0에서 1까지는 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) 1로 올라가고, 1 이후로는 1에서 평평한 "계단형 경사로"다. 막대 하나의 높이를 부드럽게 올리는 부품이 된다.

</details>

### 문제 7
$f(x) = x^2$의 0~1 넓이를 막대 2개로 어림하되, 높이를 각 칸의 **가운데** 값으로 정하라. 왼쪽 끝 높이(0.125)와 비교하라. 정확한 값은 $\frac{1}{3} \approx 0.3333$이다.

<details><summary>풀이와 답</summary>

**주어진 값**
- $f(x) = x^2$
- $a = 0,\ b = 1$, $n = 2$
- 높이는 각 칸의 가운데에서 잰다

**풀이**
1. 식을 그대로 쓴다: $\sum f(\text{가운데}) \times \Delta x$, $\Delta x = \frac{b-a}{n}$
2. 막대 너비를 구한다: (1 − 0) ÷ 2 = 0.5 이므로 $\Delta x = 0.5$
3. 칸을 나눈다: 첫째 칸은 0~0.5, 둘째 칸은 0.5~1
4. 가운데를 구한다: (0 + 0.5) ÷ 2 = 0.25, (0.5 + 1) ÷ 2 = 0.75
5. 값을 대입한다 (Σ를 두 항으로 펼침): $f(0.25) \times 0.5 + f(0.75) \times 0.5$
6. 높이를 제곱으로 구한다: $0.25^2 = 0.0625$, $0.75^2 = 0.5625$ 이므로 $0.0625 \times 0.5 + 0.5625 \times 0.5$
7. 곱셈을 한다: 0.03125 + 0.28125
8. 더한다: 0.03125 + 0.28125 = 0.3125

**답**: 0.3125. 왼쪽 끝 높이의 0.125보다 정확한 값 0.3333에 훨씬 가깝다([오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 약 0.021). 막대가 같아도 높이를 재는 위치에 따라 [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84)가 달라진다.

</details>

### 문제 8
$f(x) = x^2$을 0~2에서 점 $x = 0, 1, 2$를 직선으로 이은 꺾인 선 $\hat f(x) = \mathrm{ReLU}(x) + 2\,\mathrm{ReLU}(x-1)$로 근사한다. $x = 0.5,\ 1.5,\ 2$에서 근사값과 참값 $x^2$을 비교하라.

<details><summary>풀이와 답</summary>

꺾이는 곳 $x = 1$에서 [ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8) 하나가 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)를 1에서 $1 + 2 = 3$으로 바꿔 준다. 점 (0, 0), (1, 1), (2, 4)를 직선으로 이은 모양이다.

**주어진 값**
- $\hat f(x) = \mathrm{ReLU}(x) + 2\,\mathrm{ReLU}(x-1)$ (근사)
- $f(x) = x^2$ (참값)
- $x = 0.5,\ 1.5,\ 2$

**풀이**
1. 식을 그대로 쓴다: $\hat f(x) = \mathrm{ReLU}(x) + 2\,\mathrm{ReLU}(x-1)$
2. $x = 0.5$를 대입한다: $\mathrm{ReLU}(0.5) + 2\,\mathrm{ReLU}(0.5 - 1)$
3. 괄호 안을 계산한다: 0.5 − 1 = −0.5 이므로 $\mathrm{ReLU}(0.5) + 2\,\mathrm{ReLU}(-0.5)$
4. [ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8)를 적용하고 계산한다: $0.5 + 2 \times 0 = 0.5$. 참값은 $0.5^2 = 0.25$ (차이 0.25)
5. $x = 1.5$를 대입한다: $\mathrm{ReLU}(1.5) + 2\,\mathrm{ReLU}(1.5 - 1)$
6. 괄호 안을 계산한다: 1.5 − 1 = 0.5 이므로 $\mathrm{ReLU}(1.5) + 2\,\mathrm{ReLU}(0.5)$
7. [ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8)를 적용하고 계산한다: $1.5 + 2 \times 0.5 = 1.5 + 1 = 2.5$. 참값은 $1.5^2 = 2.25$ (차이 0.25)
8. $x = 2$를 대입한다: $\mathrm{ReLU}(2) + 2\,\mathrm{ReLU}(2 - 1) = 2 + 2 \times 1$
9. 계산한다: 2 + 2 = 4. 참값은 $2^2 = 4$ (차이 0)

**답**: 근사값 0.5, 2.5, 4 / 참값 0.25, 2.25, 4. 꺾이는 점에서는 정확하고, 그 사이에서는 0.25 어긋난다. [ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8)를 더 달아 꺾이는 점을 늘리면 차이가 준다.

</details>

## 강의와 연결

### 문제 9
[Lec01 6.1](../../Lec01_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%86%8C%EA%B0%9C.md#61-%EA%B7%BC%EC%82%AC-%EC%9D%B4%EB%A1%A0-%EB%AC%B4%EC%97%87%EC%9D%84-%ED%91%9C%ED%98%84%ED%95%A0-%EC%88%98-%EC%9E%88%EB%82%98)에서 강사는 [리만 합](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#riemann-sum-%EB%A6%AC%EB%A7%8C-%ED%95%A9) 그림으로 "은닉 유닛이 많을수록 곡선에 가까워진다"를 설명한다. $x^2$의 0~1 넓이를 막대 $n = 10$개(왼쪽 끝 높이)로 어림하라. 막대 하나가 은닉 유닛 하나에 해당한다. 정확한 값은 $\frac{1}{3}$이다.

<details><summary>풀이와 답</summary>

**주어진 값**
- $f(x) = x^2$
- $a = 0,\ b = 1$, $n = 10$ (막대 수 = 은닉 유닛 수)
- $x_i = i \times \Delta x$ (왼쪽 끝)

**풀이**
1. 식을 그대로 쓴다: $\sum_{i=0}^{n-1} f(x_i)\,\Delta x$, $\Delta x = \frac{b-a}{n}$
2. 값을 대입한다: $\sum_{i=0}^{9} f(x_i) \times \frac{1 - 0}{10}$
3. 막대 너비를 구한다: 1 ÷ 10 = 0.1 이므로 $\sum_{i=0}^{9} f(x_i) \times 0.1$
4. 왼쪽 끝을 구한다: $x_i = 0, 0.1, 0.2, \dots, 0.9$
5. 높이를 제곱으로 구한다: $0^2 = 0$, $0.1^2 = 0.01$, $0.2^2 = 0.04$, $0.3^2 = 0.09$, $0.4^2 = 0.16$, $0.5^2 = 0.25$, $0.6^2 = 0.36$, $0.7^2 = 0.49$, $0.8^2 = 0.64$, $0.9^2 = 0.81$
6. 높이를 모두 더한다: 0 + 0.01 + 0.04 + 0.09 + 0.16 + 0.25 + 0.36 + 0.49 + 0.64 + 0.81 = 2.85
7. 너비를 곱한다: 2.85 × 0.1 = 0.285
8. 정확한 값과 뺄셈으로 비교한다: 0.3333 − 0.285 = 0.0483

**답**: 0.285 ([오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 약 0.048). 막대 4개일 때의 0.21875([오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 0.115)보다 정확하다. 유닛(막대)을 늘릴수록 곡선에 가까워진다.

</details>

### 문제 10
본문 3.1 표에서 막대 수 $n = 10$일 때 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)가 0.0483, $n = 100$일 때 0.0050이었다. 막대를 10배로 늘렸을 때 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)는 몇 분의 1이 되었는가? 이 경향이 계속된다면 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)를 0.001 이하로 만들려면 막대가 약 몇 개 필요한가?

<details><summary>풀이와 답</summary>

[오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)가 막대 수에 거의 반비례해 줄면 "[오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) ≈ 상수 ÷ 막대 수"로 쓸 수 있다.

**주어진 값**
- $n = 10$일 때 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 0.0483
- $n = 100$일 때 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 0.0050
- 목표 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 0.001

**풀이**
1. 식을 쓴다: 줄어든 비율 = 처음 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) ÷ 나중 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)
2. 값을 대입한다: 0.0483 ÷ 0.0050
3. 나눗셈을 한다: 0.0483 ÷ 0.0050 = 9.66, 즉 약 10분의 1
4. 상수를 구한다: [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) ≈ 상수 ÷ n 이므로 상수 ≈ [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) × n = 0.0050 × 100
5. 곱셈을 한다: 0.0050 × 100 = 0.5 이므로 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) ≈ 0.5 ÷ n
6. 목표를 대입한다: 0.001 = 0.5 ÷ n
7. n을 구한다: n = 0.5 ÷ 0.001 = 500

**답**: 약 9.7배, 즉 약 10분의 1로 줄었다. [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 0.001 이하에는 막대(유닛)가 약 500개 필요하다 (실제로 계산하면 $n = 500$에서 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 0.00100). [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84)를 10배 올릴 때마다 유닛이 10배 필요하다는 뜻이다.

</details>
