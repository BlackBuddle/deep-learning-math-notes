## 기본 (직접 대입)

### 문제 1
목표 $g(x) = x^2$를 0~1에서 막대 5개(각 칸 왼쪽 끝 높이)로 근사할 때, 입력 $x = 0.7$에서 근사값 $f(0.7)$과 실제 값 $g(0.7)$을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $g(x) = x^2$ (목표 함수)
- $N = 5$ (막대 수), 칸 너비 $1 \div 5 = 0.2$
- $x_i = 0,\ 0.2,\ 0.4,\ 0.6,\ 0.8$ (칸 왼쪽 끝)
- $x = 0.7$ (입력)

**풀이**
1. 식을 그대로 쓴다: $f(x) = \sum_{i=1}^{N} \alpha_i\,\mathbb{1}_i(x), \quad \alpha_i = g(x_i)$
2. 값을 대입한다: $f(0.7) = 0^2\,\mathbb{1}_1 + 0.2^2\,\mathbb{1}_2 + 0.4^2\,\mathbb{1}_3 + 0.6^2\,\mathbb{1}_4 + 0.8^2\,\mathbb{1}_5$
3. 높이(제곱)를 구한다: $0^2 = 0$, $0.2^2 = 0.04$, $0.4^2 = 0.16$, $0.6^2 = 0.36$, $0.8^2 = 0.64$
4. [지시 함수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#indicator-function-%EC%A7%80%EC%8B%9C-%ED%95%A8%EC%88%98) 값을 정한다: 0.7은 넷째 칸 [0.6, 0.8)에 있으므로 $\mathbb{1}_4 = 1$, 나머지는 0
5. 항별 곱을 쓴다: $0 \times 0 + 0.04 \times 0 + 0.16 \times 0 + 0.36 \times 1 + 0.64 \times 0$
6. 곱셈과 덧셈을 한다: $0 + 0 + 0 + 0.36 + 0 = 0.36$
7. 실제 값을 구한다: $g(0.7) = 0.7^2 = 0.49$
8. 차이를 구한다: 0.49 − 0.36 = 0.13

**답**: $f(0.7) = 0.36$, 실제 $g(0.7) = 0.49$ (0.13 낮다)

</details>

### 문제 2
목표 $g(x) = 2x + 1$ ([기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $L = 2$)을 0~1에서 막대 5개(왼쪽 끝 높이)로 근사한다. $x = 0.5$에서 근사값과 실제 값의 차이를 구하고, 이 차이가 칸 끝까지 벗어날 수 있는 높이 $\frac{L}{N}$ 이하인지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $g(x) = 2x + 1$, $L = 2$
- $N = 5$ (막대 수), 칸 너비 0.2
- $x = 0.5$ (입력)

**풀이**
1. 칸을 찾는다: 칸 경계가 0, 0.2, 0.4, 0.6, 0.8, 1 이므로 0.5는 [0.4, 0.6) 칸에 있고, 왼쪽 끝은 $x_3 = 0.4$
2. 막대 높이 식을 쓴다: $\alpha_3 = g(x_3) = 2x_3 + 1$
3. 값을 대입한다: $\alpha_3 = 2 \times 0.4 + 1$
4. 계산한다: 2 × 0.4 = 0.8, 0.8 + 1 = 1.8 이므로 $f(0.5) = 1.8$
5. 실제 값을 구한다: $g(0.5) = 2 \times 0.5 + 1 = 1 + 1 = 2$
6. 차이를 구한다: 2 − 1.8 = 0.2
7. 상한 식을 쓴다: $\frac{L}{N}$
8. 값을 대입한다: $\frac{2}{5} = 0.4$
9. 비교한다: 0.2는 0.4보다 작다

**답**: 차이 0.2 ≤ 0.4. [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 $L$ 이하이면 칸 안에서 막대 높이와 $\frac{L}{N}$ 넘게 벗어날 수 없다.

</details>

### 문제 3
$L = 4$인 함수를 0~1에서 막대 $N = 8$개로 근사할 때 한 칸 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)의 상한과 전체 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)의 상한을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $L = 4$ (립시츠 상수)
- $N = 8$ (막대 수)

**풀이**
1. 식을 그대로 쓴다: $\text{한 칸 오차} \le \frac{L}{2N^2}, \quad \text{전체 오차} \le \frac{L}{2N}$
2. 값을 대입한다: $\text{한 칸 오차} \le \frac{4}{2 \times 8^2}, \quad \text{전체 오차} \le \frac{4}{2 \times 8}$
3. 제곱을 한다: $8^2 = 64$ 이므로 $\frac{4}{2 \times 64}$
4. 분모의 곱셈을 한다: 2 × 64 = 128 이므로 $\frac{4}{128}$
5. 나눗셈을 한다: 4 ÷ 128 = 0.03125
6. 전체 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)의 분모를 계산한다: 2 × 8 = 16 이므로 $\frac{4}{16}$
7. 나눗셈을 한다: 4 ÷ 16 = 0.25
8. 확인한다: 한 칸 상한 × 칸 수 = 0.03125 × 8 = 0.25

**답**: 한 칸 ≤ 0.03125, 전체 ≤ 0.25

</details>

### 문제 4
$L = 3$인 함수의 [적분 오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#l-error-l1-error-%EC%B5%9C%EB%8C%80-%EC%98%A4%EC%B0%A8%EC%99%80-%EC%A0%81%EB%B6%84-%EC%98%A4%EC%B0%A8)를 $\varepsilon = 0.05$ 이하로 근사하려면 1차원에서 막대가 몇 개 필요한가? (강의 식 $N \ge L/\varepsilon$) 그때 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 상한 $\frac{L}{2N}$은?

<details><summary>풀이와 답</summary>

**주어진 값**
- $L = 3$ (립시츠 상수)
- $\varepsilon = 0.05$ (원하는 [적분 오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#l-error-l1-error-%EC%B5%9C%EB%8C%80-%EC%98%A4%EC%B0%A8%EC%99%80-%EC%A0%81%EB%B6%84-%EC%98%A4%EC%B0%A8))

**풀이**
1. 식을 그대로 쓴다: $N \ge \frac{L}{\varepsilon}$
2. 값을 대입한다: $N \ge \frac{3}{0.05}$
3. 나눗셈을 한다: 3 ÷ 0.05 = 60 이므로 $N \ge 60$ (가장 작은 정수는 60)
4. [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 상한 식을 쓴다: $\frac{L}{2N}$
5. 값을 대입한다: $\frac{3}{2 \times 60}$
6. 분모의 곱셈을 한다: 2 × 60 = 120 이므로 $\frac{3}{120}$
7. 나눗셈을 한다: 3 ÷ 120 = 0.025

**답**: 막대 60개, [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 상한 0.025 ($\varepsilon = 0.05$의 절반)

</details>

### 문제 5
입력이 2차원($d = 2$)이고 $L = 1$인 함수를 [적분 오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#l-error-l1-error-%EC%B5%9C%EB%8C%80-%EC%98%A4%EC%B0%A8%EC%99%80-%EC%A0%81%EB%B6%84-%EC%98%A4%EC%B0%A8) $\varepsilon = 0.25$ 이하로 근사하려면 상자가 몇 개 필요한가? 상자 한 변의 길이와 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 상한도 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $L = 1$, $\varepsilon = 0.25$, $d = 2$

**풀이**
1. 식을 그대로 쓴다: $N \ge \left(\frac{L}{\varepsilon}\right)^d$
2. 값을 대입한다: $N \ge \left(\frac{1}{0.25}\right)^2$
3. 괄호 안 나눗셈을 한다: 1 ÷ 0.25 = 4 이므로 $N \ge 4^2$
4. 제곱을 한다: 4 × 4 = 16
5. 한 변의 식을 쓴다: $N^{-1/d}$ (−1/d 제곱은 d제곱근의 역수)
6. 값을 대입한다: $16^{-1/2}$
7. 제곱근을 구한다: $\sqrt{16} = 4$ (4 × 4 = 16) 이므로 $16^{-1/2} = \frac{1}{4} = 0.25$
8. [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 상한 식을 쓴다: $\frac{L}{N^{1/d}}$
9. 값을 대입한다: $\frac{1}{16^{1/2}} = \frac{1}{4}$
10. 나눗셈을 한다: 1 ÷ 4 = 0.25 = ε

**답**: 상자 16개, 한 변 0.25 (방향마다 4칸씩 나눈 격자), [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 상한 0.25

</details>

### 문제 6
입력이 3차원($d = 3$)이고 $L = 1$, $\varepsilon = 0.1$일 때 상자 수와, 정리의 뉴런 수 $4d(L/\varepsilon)^d$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $L = 1$, $\varepsilon = 0.1$, $d = 3$

**풀이**
1. 식을 그대로 쓴다: $N \ge \left(\frac{L}{\varepsilon}\right)^d$
2. 값을 대입한다: $N \ge \left(\frac{1}{0.1}\right)^3$
3. 괄호 안 나눗셈을 한다: 1 ÷ 0.1 = 10 이므로 $N \ge 10^3$
4. 세제곱을 한다: 10 × 10 × 10 = 1000
5. 뉴런 수 식을 쓴다: $4d\left(\frac{L}{\varepsilon}\right)^d$
6. 값을 대입한다: $4 \times 3 \times 1000$
7. 곱셈을 한다: 4 × 3 = 12, 12 × 1000 = 12000

**답**: 상자 1000개, 뉴런 12000개

</details>

### 문제 7
$L/\varepsilon = 5$일 때 입력 차원이 $d = 1, 2, 3, 10$이면 상자 수는 각각 얼마인가? 차원이 하나 늘 때마다 몇 배가 되는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $L/\varepsilon = 5$
- $d = 1, 2, 3, 10$

**풀이**
1. 식을 그대로 쓴다: $N = \left(\frac{L}{\varepsilon}\right)^d$
2. 값을 대입한다: $N = 5^d$
3. $d = 1$: $5^1 = 5$
4. $d = 2$: 5 × 5 = 25
5. $d = 3$: 25 × 5 = 125
6. $d = 10$: 5를 열 번 곱한다. 5, 25, 125, 625, 3125, 15625, 78125, 390625, 1953125, 9765625
7. 비율을 구한다: 25 ÷ 5 = 5, 125 ÷ 25 = 5

**답**: 5, 25, 125, 9,765,625개. 차원이 하나 늘 때마다 상자 수가 5배($= L/\varepsilon$배)가 된다. 이것이 [차원의 저주](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#curse-of-dimensionality-%EC%B0%A8%EC%9B%90%EC%9D%98-%EC%A0%80%EC%A3%BC)다.

</details>

### 문제 8
$g(x) = x^2$ ($L = 2$)을 막대 $N = 4$개로 근사했을 때 실제 [적분 오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#l-error-l1-error-%EC%B5%9C%EB%8C%80-%EC%98%A4%EC%B0%A8%EC%99%80-%EC%A0%81%EB%B6%84-%EC%98%A4%EC%B0%A8)를 구하고 상한 $\frac{L}{2N}$과 비교하라. (곡선 아래 넓이는 $\frac{1}{3} \approx 0.3333$이다. $x^2$는 올라가는 함수라 막대는 곡선 아래에 놓인다)

<details><summary>풀이와 답</summary>

**주어진 값**
- $g(x) = x^2$, $L = 2$
- $N = 4$, 칸 너비 0.25, 왼쪽 끝 $0,\ 0.25,\ 0.5,\ 0.75$
- 곡선 아래 넓이 $\frac{1}{3} \approx 0.3333$

**풀이**
1. 식을 쓴다: 실제 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) = 곡선 아래 넓이 − 막대 넓이의 합
2. 막대 높이를 구한다: $0^2 = 0$, $0.25^2 = 0.0625$, $0.5^2 = 0.25$, $0.75^2 = 0.5625$
3. 막대 넓이를 쓴다: $(0 + 0.0625 + 0.25 + 0.5625) \times 0.25$
4. 괄호 안을 더한다: 0 + 0.0625 + 0.25 + 0.5625 = 0.875
5. 곱셈을 한다: 0.875 × 0.25 = 0.21875
6. [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)를 구한다: 0.3333 − 0.21875 = 0.1146
7. 상한 식을 쓴다: $\frac{L}{2N}$
8. 값을 대입한다: $\frac{2}{2 \times 4} = \frac{2}{8}$
9. 나눗셈을 한다: 2 ÷ 8 = 0.25
10. 비교한다: 0.1146은 0.25보다 작다

**답**: 실제 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 약 0.1146 ≤ 상한 0.25. 상한은 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 어디서나 최대 $L$인 최악의 경우를 가정해서 실제의 약 2배로 넉넉하다.

</details>

### 문제 9
[Lec03 6절](../../Lec03_%EA%B7%BC%EC%82%AC_%EC%9D%B4%EB%A1%A0.md#6-%EC%A6%9D%EB%AA%85%ED%95%A0-%EC%A0%95%EB%A6%AC)의 정리는 "3층 [ReLU](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu-%EB%A0%90%EB%A3%A8) 망에 뉴런 $4d(L/\varepsilon)^d$개면 [적분 오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#l-error-l1-error-%EC%B5%9C%EB%8C%80-%EC%98%A4%EC%B0%A8%EC%99%80-%EC%A0%81%EB%B6%84-%EC%98%A4%EC%B0%A8)를 $2\varepsilon$ 아래로" 만든다고 말한다. $d = 2$, $L = 1$, $\varepsilon = 0.1$일 때 뉴런 수와 보장되는 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $d = 2$, $L = 1$, $\varepsilon = 0.1$
- 정리: 뉴런 수 $4d(L/\varepsilon)^d$, 보장 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $2\varepsilon$

**풀이**
1. 식을 그대로 쓴다: 뉴런 수 $= 4d\left(\frac{L}{\varepsilon}\right)^d$
2. 값을 대입한다: $4 \times 2 \times \left(\frac{1}{0.1}\right)^2$
3. 괄호 안 나눗셈을 한다: 1 ÷ 0.1 = 10 이므로 $4 \times 2 \times 10^2$
4. 제곱을 한다: 10 × 10 = 100 이므로 $4 \times 2 \times 100$
5. 곱셈을 한다: 4 × 2 = 8, 8 × 100 = 800
6. 보장 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 식을 쓴다: $2\varepsilon$
7. 값을 대입한다: 2 × 0.1 = 0.2

**답**: 뉴런 800개로 [적분 오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#l-error-l1-error-%EC%B5%9C%EB%8C%80-%EC%98%A4%EC%B0%A8%EC%99%80-%EC%A0%81%EB%B6%84-%EC%98%A4%EC%B0%A8) 0.2 아래를 보장한다. 이 800이 상자 수 100에 $4d = 8$을 곱한 값이다.

</details>

### 문제 10
[Lec03 7.2](../../Lec03_%EA%B7%BC%EC%82%AC_%EC%9D%B4%EB%A1%A0.md#72-2%EB%8B%A8%EA%B3%84-%EA%B3%A0%EC%B0%A8%EC%9B%90-%EC%B4%88%EC%A7%81%EC%82%AC%EA%B0%81%ED%98%95)의 [차원의 저주](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#curse-of-dimensionality-%EC%B0%A8%EC%9B%90%EC%9D%98-%EC%A0%80%EC%A3%BC). 28×28 화소의 [MNIST](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#mnist-%EC%86%90%EA%B8%80%EC%94%A8-%EC%88%AB%EC%9E%90-%EB%8D%B0%EC%9D%B4%ED%84%B0%EC%85%8B) 이미지는 입력이 $d = 784$차원이다. $L/\varepsilon = 10$일 때 필요한 상자 수 $(L/\varepsilon)^d$는 몇 자리 수이고, 우주의 원자 수 약 $10^{80}$의 몇 배인가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $d = 28 \times 28 = 784$ (입력 차원)
- $L/\varepsilon = 10$
- 우주의 원자 수 약 $10^{80}$

**풀이**
1. 차원을 구한다: 28 × 28 = 784
2. 식을 그대로 쓴다: $N = \left(\frac{L}{\varepsilon}\right)^d$
3. 값을 대입한다: $N = 10^{784}$
4. 자릿수를 읽는다: $10^k$은 1 뒤에 0이 $k$개 붙은 수이므로 0이 784개, 전체 785자리
5. 원자 수와 나눈다: $\frac{10^{784}}{10^{80}}$
6. 지수끼리 뺀다: 같은 밑의 나눗셈은 [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 빼므로 784 − 80 = 704, 즉 $10^{704}$

**답**: $10^{784}$개 (785자리 수). 우주의 원자 수의 $10^{704}$배라서 만들 수 없다. 그래서 이 [보편 근사](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#universal-approximation-%EB%B3%B4%ED%8E%B8-%EA%B7%BC%EC%82%AC) 정리는 입력이 고차원인 실제 문제에서는 실용적이지 않다.

</details>
