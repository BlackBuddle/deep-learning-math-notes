# 예제: WL 색칠 알고리즘

개념 노트: [MM21_WL_색칠_알고리즘](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/07_%EA%B5%AC%EC%A1%B0_%EC%95%84%ED%82%A4%ED%85%8D%EC%B2%98/MM21_WL_%EC%83%89%EC%B9%A0_%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

> [!NOTE]
> **쓰는 법**
> 풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 쓰는 식: $c^{(t)}(v) = \text{Hash}\big(c^{(t-1)}(v),\ \{\!\{c^{(t-1)}(u) : u \in \mathcal{N}(v)\}\!\}\big)$. 서명 $=$ (내 색, 이웃 색 [멀티셋](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#multiset-%EB%A9%80%ED%8B%B0%EC%85%8B)). Hash는 비교하는 모든 그래프의 서명을 함께 모아 정렬한 뒤 0, 1, 2, ... 번호를 준다. 정렬은 내 색이 작은 쪽이 앞이고, 같으면 이웃 색 목록을 앞에서부터 비교하며, 짧은 목록이 앞이다. 처음 색은 별말이 없으면 모두 0이다.

## 기본 (직접 대입)

### 문제 1
일자 5개 노드 0-1-2-3-4(엣지 0-1, 1-2, 2-3, 3-4)에서 처음 색이 모두 0일 때 1-WL 한 번 뒤의 색 $c^{(1)}$을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathcal{N}(0) = \{1\}$, $\mathcal{N}(1) = \{0, 2\}$, $\mathcal{N}(2) = \{1, 3\}$, $\mathcal{N}(3) = \{2, 4\}$, $\mathcal{N}(4) = \{3\}$
- $c^{(0)}(v) = 0$

**풀이**
1. 식을 그대로 쓴다: $c^{(1)}(v) = \text{Hash}\big(c^{(0)}(v),\ \{\!\{c^{(0)}(u) : u \in \mathcal{N}(v)\}\!\}\big)$
2. 노드 0과 4에 값을 대입한다 (이웃 하나): $\text{Hash}\big(0,\ \{\!\{0\}\!\}\big)$
3. 노드 1, 2, 3에 값을 대입한다 (이웃 둘): $\text{Hash}\big(0,\ \{\!\{0, 0\}\!\}\big)$
4. 서명이 두 종류이므로 정렬한다 (이웃이 적은 쪽이 앞): $(0, \{\!\{0\}\!\}) \to 0$, $(0, \{\!\{0, 0\}\!\}) \to 1$
5. 노드마다 번호를 붙인다: 노드 0, 4는 0, 노드 1, 2, 3은 1

**답**: $c^{(1)} = (0, 1, 1, 1, 0)$ (차수로 나뉜 결과)

</details>

### 문제 2
문제 1의 결과 $c^{(1)} = (0, 1, 1, 1, 0)$에서 한 번 더 색칠한 $c^{(2)}$를 구하라. 가운데 노드 2는 이제 노드 1, 3과 구별되는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- 같은 일자 5개 노드, $c^{(1)} = (0, 1, 1, 1, 0)$

**풀이**
1. 식을 그대로 쓴다: $c^{(2)}(v) = \text{Hash}\big(c^{(1)}(v),\ \{\!\{c^{(1)}(u) : u \in \mathcal{N}(v)\}\!\}\big)$
2. 노드 0에 값을 대입한다: $\text{Hash}\big(0,\ \{\!\{c^{(1)}(1)\}\!\}\big) = \text{Hash}\big(0,\ \{\!\{1\}\!\}\big)$, 노드 4도 같다
3. 노드 1에 값을 대입한다: $\text{Hash}\big(1,\ \{\!\{c^{(1)}(0), c^{(1)}(2)\}\!\}\big) = \text{Hash}\big(1,\ \{\!\{0, 1\}\!\}\big)$, 노드 3도 같다
4. 노드 2에 값을 대입한다: $\text{Hash}\big(1,\ \{\!\{c^{(1)}(1), c^{(1)}(3)\}\!\}\big) = \text{Hash}\big(1,\ \{\!\{1, 1\}\!\}\big)$
5. 서명이 세 종류이므로 정렬한다: 내 색 0인 서명이 앞이고, 내 색 1끼리는 이웃 목록 (0, 1)이 (1, 1)보다 앞이다. $(0, \{\!\{1\}\!\}) \to 0$, $(1, \{\!\{0, 1\}\!\}) \to 1$, $(1, \{\!\{1, 1\}\!\}) \to 2$
6. 노드마다 번호를 붙인다: 노드 0, 4는 0, 노드 1, 3은 1, 노드 2는 2

**답**: $c^{(2)} = (0, 1, 2, 1, 0)$. 노드 2는 이제 노드 1, 3과 다른 색이다 (끝에서 두 칸 떨어진 가운데라는 정보가 퍼졌다).

</details>

### 문제 3
일자 5개 노드(문제 1)와 별 모양(가운데 노드 0에 잎 1, 2, 3, 4가 붙음, 노드 5개)을 1-WL 한 번으로 구별할 수 있는가? 처음 색은 모두 0이다.

<details><summary>풀이와 답</summary>

**주어진 값**
- 일자: $\mathcal{N}(0) = \{1\}$, $\mathcal{N}(1) = \{0, 2\}$, $\mathcal{N}(2) = \{1, 3\}$, $\mathcal{N}(3) = \{2, 4\}$, $\mathcal{N}(4) = \{3\}$
- 별: $\mathcal{N}(0) = \{1, 2, 3, 4\}$, 잎 $\mathcal{N}(1) = \mathcal{N}(2) = \mathcal{N}(3) = \mathcal{N}(4) = \{0\}$

**풀이**
1. 식을 그대로 쓴다: $c^{(1)}(v) = \text{Hash}\big(0,\ \{\!\{0, \dots\}\!\}\big)$ (이웃 수만큼 0이 들어간다)
2. 일자의 서명: 끝 두 노드 $(0, \{\!\{0\}\!\})$, 안쪽 세 노드 $(0, \{\!\{0, 0\}\!\})$
3. 별의 서명: 잎 네 개 $(0, \{\!\{0\}\!\})$, 가운데 $(0, \{\!\{0, 0, 0, 0\}\!\})$
4. 서명이 세 종류이므로 두 그래프를 함께 정렬한다: $(0, \{\!\{0\}\!\}) \to 0$, $(0, \{\!\{0, 0\}\!\}) \to 1$, $(0, \{\!\{0, 0, 0, 0\}\!\}) \to 2$
5. 일자의 색: (0, 1, 1, 1, 0) 이므로 분포 [0, 0, 1, 1, 1]
6. 별의 색: 가운데 2, 잎 0 이므로 분포 [0, 0, 0, 0, 2]
7. 분포를 비교한다: [0, 0, 1, 1, 1]과 [0, 0, 0, 0, 2]는 다르다

**답**: 구별할 수 있다 (반복 1번, 차수 분포가 다르기 때문)

</details>

### 문제 4
정사각형(노드 0-1-2-3이 고리)과 별(가운데 노드 0에 잎 1, 2, 3, 노드 4개)을 1-WL 한 번으로 구별할 수 있는가? 처음 색은 모두 0이다.

<details><summary>풀이와 답</summary>

**주어진 값**
- 정사각형: $\mathcal{N}(v) = \{v-1, v+1\}$ (이웃 수 2)
- 별: 가운데 이웃 3개, 잎 이웃 1개

**풀이**
1. 식을 그대로 쓴다: $c^{(1)}(v) = \text{Hash}\big(0,\ \{\!\{0, \dots\}\!\}\big)$
2. 정사각형의 서명: 네 노드 모두 $(0, \{\!\{0, 0\}\!\})$
3. 별의 서명: 가운데 $(0, \{\!\{0, 0, 0\}\!\})$, 잎 셋 $(0, \{\!\{0\}\!\})$
4. 정렬해 번호를 준다: $(0, \{\!\{0\}\!\}) \to 0$, $(0, \{\!\{0, 0\}\!\}) \to 1$, $(0, \{\!\{0, 0, 0\}\!\}) \to 2$
5. 정사각형의 색은 (1, 1, 1, 1), 별의 색은 가운데 2와 잎 0, 0, 0
6. 분포를 비교한다: [1, 1, 1, 1]과 [0, 0, 0, 2]는 다르다

**답**: 구별할 수 있다 (반복 1번)

</details>

### 문제 5
일자 6개(0-1-2-3-4-5)와 "삼각형(0-1-2) + 일자 3개(3-4-5)"는 노드 6개씩이고 차수 목록이 (1, 1, 2, 2, 2, 2)로 같다. 1-WL 반복 1과 반복 2의 색 분포를 비교하라. 처음 색은 모두 0이다. (일자 6개의 엣지: 0-1, 1-2, 2-3, 3-4, 4-5. 두 번째 그래프의 엣지: 0-1, 1-2, 2-0, 3-4, 4-5)

<details><summary>풀이와 답</summary>

**주어진 값**
- 그래프 A(일자 6개)의 이웃: 0: {1}, 1: {0, 2}, 2: {1, 3}, 3: {2, 4}, 4: {3, 5}, 5: {4}
- 그래프 B(삼각형 + 일자 3개)의 이웃: 0: {1, 2}, 1: {0, 2}, 2: {0, 1}, 3: {4}, 4: {3, 5}, 5: {4}
- $c^{(0)} = 0$

**풀이**
1. 식을 그대로 쓴다: $c^{(t)}(v) = \text{Hash}\big(c^{(t-1)}(v),\ \{\!\{c^{(t-1)}(u)\}\!\}\big)$
2. 반복 1의 서명: A는 끝 노드 0, 5가 $(0, \{\!\{0\}\!\})$, 나머지 네 노드가 $(0, \{\!\{0, 0\}\!\})$. B는 노드 3, 5가 $(0, \{\!\{0\}\!\})$, 나머지 네 노드(삼각형 셋과 노드 4)가 $(0, \{\!\{0, 0\}\!\})$
3. 번호를 준다: $(0, \{\!\{0\}\!\}) \to 0$, $(0, \{\!\{0, 0\}\!\}) \to 1$
4. 반복 1의 색: A = (0, 1, 1, 1, 1, 0), B = (1, 1, 1, 0, 1, 0) 이므로 분포는 둘 다 [0, 0, 1, 1, 1, 1] → 같다
5. 반복 2의 서명 (A): 노드 0 $(0, \{\!\{1\}\!\})$, 노드 1 $(1, \{\!\{0, 1\}\!\})$, 노드 2 $(1, \{\!\{1, 1\}\!\})$, 노드 3 $(1, \{\!\{1, 1\}\!\})$, 노드 4 $(1, \{\!\{1, 0\}\!\})$, 노드 5 $(0, \{\!\{1\}\!\})$
6. 반복 2의 서명 (B): 삼각형 세 노드는 모두 $(1, \{\!\{1, 1\}\!\})$, 노드 3 $(0, \{\!\{1\}\!\})$, 노드 4 $(1, \{\!\{0, 0\}\!\})$ (이웃 3, 5의 색이 모두 0), 노드 5 $(0, \{\!\{1\}\!\})$
7. 정렬해 번호를 준다: $(0, \{\!\{1\}\!\}) \to 0$, $(1, \{\!\{0, 0\}\!\}) \to 1$, $(1, \{\!\{0, 1\}\!\}) \to 2$, $(1, \{\!\{1, 1\}\!\}) \to 3$
8. 반복 2의 색: A = (0, 2, 3, 3, 2, 0), B = (3, 3, 3, 0, 1, 0) 이므로 분포는 A [0, 0, 2, 2, 3, 3], B [0, 0, 1, 3, 3, 3] → 다르다

**답**: 반복 1에서는 분포가 같아 구별되지 않지만 반복 2에서 달라져 구별된다 (A [0,0,2,2,3,3], B [0,0,1,3,3,3]). 반복을 더 해야 갈라지는 쌍도 있다.

</details>

### 문제 6
노드 속성이 있으면 처음 색부터 다르다. 일자 3개 0-1-2에서 그래프 G1의 처음 색이 $(0, 1, 0)$, 그래프 G2의 처음 색이 $(0, 0, 1)$일 때 1-WL 한 번으로 구별되는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- 두 그래프 모두 엣지 0-1, 1-2 ($\mathcal{N}(0) = \{1\}$, $\mathcal{N}(1) = \{0, 2\}$, $\mathcal{N}(2) = \{1\}$)
- G1: $c^{(0)} = (0, 1, 0)$, G2: $c^{(0)} = (0, 0, 1)$

**풀이**
1. 식을 그대로 쓴다: $c^{(1)}(v) = \text{Hash}\big(c^{(0)}(v),\ \{\!\{c^{(0)}(u)\}\!\}\big)$
2. G1의 서명: 노드 0 $(0, \{\!\{1\}\!\})$, 노드 1 $(1, \{\!\{0, 0\}\!\})$, 노드 2 $(0, \{\!\{1\}\!\})$
3. G2의 서명: 노드 0 $(0, \{\!\{0\}\!\})$, 노드 1 $(0, \{\!\{0, 1\}\!\})$, 노드 2 $(1, \{\!\{0\}\!\})$
4. 서명이 다섯 종류이므로 함께 정렬한다: $(0, \{\!\{0\}\!\}) \to 0$, $(0, \{\!\{0, 1\}\!\}) \to 1$, $(0, \{\!\{1\}\!\}) \to 2$, $(1, \{\!\{0\}\!\}) \to 3$, $(1, \{\!\{0, 0\}\!\}) \to 4$
5. 색을 붙인다: G1 = (2, 4, 2), G2 = (0, 1, 3)
6. 분포를 비교한다: G1 [2, 2, 4], G2 [0, 1, 3] → 다르다

**답**: 구별된다 ($c^{(1)}$: G1 = (2, 4, 2), G2 = (0, 1, 3)). 같은 모양이라도 속성의 배치가 다르면 처음부터 달라진다.

</details>

### 문제 7
사다리(엣지 0-1, 1-2, 3-4, 4-5, 0-3, 1-4, 2-5)와 "삼각형 2개 + 다리"(엣지 0-1, 1-2, 2-0, 3-4, 4-5, 5-3, 2-3)를 1-WL로 비교하라. 반복 1에서 색은 차수로 정해진다. 반복 2의 색 분포는 같은가?

<details><summary>풀이와 답</summary>

**주어진 값**
- 사다리의 이웃: 0: {1, 3}, 1: {0, 2, 4}, 2: {1, 5}, 3: {0, 4}, 4: {1, 3, 5}, 5: {2, 4}
- 삼각형+다리의 이웃: 0: {1, 2}, 1: {0, 2}, 2: {0, 1, 3}, 3: {2, 4, 5}, 4: {3, 5}, 5: {3, 4}
- $c^{(0)} = 0$

**풀이**
1. 반복 1의 서명: 이웃이 둘이면 $(0, \{\!\{0, 0\}\!\}) \to 0$, 셋이면 $(0, \{\!\{0, 0, 0\}\!\}) \to 1$
2. 반복 1의 색: 사다리 = (0, 1, 0, 0, 1, 0), 삼각형+다리 = (0, 0, 1, 1, 0, 0) 이므로 분포는 둘 다 [0, 0, 0, 0, 1, 1]
3. 반복 2, 사다리의 서명: 노드 0은 내 색 0, 이웃 1(색 1)과 3(색 0)이라 $(0, \{\!\{0, 1\}\!\})$. 노드 1은 내 색 1, 이웃 0, 2, 4의 색이 0, 0, 1이라 $(1, \{\!\{0, 0, 1\}\!\})$. 노드 2, 3, 5는 노드 0과 같은 모양이고 노드 4는 노드 1과 같은 모양이다.
4. 반복 2, 삼각형+다리의 서명: 노드 0은 내 색 0, 이웃 1(색 0)과 2(색 1)라 $(0, \{\!\{0, 1\}\!\})$. 노드 2는 내 색 1, 이웃 0, 1, 3의 색이 0, 0, 1이라 $(1, \{\!\{0, 0, 1\}\!\})$. 노드 1, 4, 5는 노드 0과 같은 모양이고 노드 3은 노드 2와 같은 모양이다.
5. 번호를 준다: $(0, \{\!\{0, 1\}\!\}) \to 0$, $(1, \{\!\{0, 0, 1\}\!\}) \to 1$
6. 색 분포를 비교한다: 사다리는 서명 $(0, \dots)$ 4개와 $(1, \dots)$ 2개, 삼각형+다리도 4개와 2개 → 둘 다 [0, 0, 0, 0, 1, 1]

**답**: 반복 2의 분포도 같다 (이후에도 새로 갈라지지 않는다). 사다리에는 사각형이, 다른 쪽에는 삼각형이 있지만 1-WL은 구별하지 못한다.

</details>

### 문제 8
노드 번호를 바꿔도 1-WL의 색 분포는 그대로인가? 일자 3개를 엣지 0-1, 1-2로 쓸 때와 번호를 바꿔 엣지 1-0, 0-2(가운데가 노드 0)로 쓸 때 반복 1의 분포를 비교하라. (MM18의 순열과 연결)

<details><summary>풀이와 답</summary>

**주어진 값**
- 번호 매김 1: $\mathcal{N}(0) = \{1\}$, $\mathcal{N}(1) = \{0, 2\}$, $\mathcal{N}(2) = \{1\}$ (가운데 노드 1)
- 번호 매김 2: $\mathcal{N}(0) = \{1, 2\}$, $\mathcal{N}(1) = \{0\}$, $\mathcal{N}(2) = \{0\}$ (가운데 노드 0)
- $c^{(0)} = 0$

**풀이**
1. 식을 그대로 쓴다: $c^{(1)}(v) = \text{Hash}\big(0,\ \{\!\{0, \dots\}\!\}\big)$
2. 번호 매김 1: 노드 0, 2는 $(0, \{\!\{0\}\!\})$, 노드 1은 $(0, \{\!\{0, 0\}\!\})$
3. 번호 매김 2: 노드 1, 2는 $(0, \{\!\{0\}\!\})$, 노드 0은 $(0, \{\!\{0, 0\}\!\})$
4. 번호를 준다: $(0, \{\!\{0\}\!\}) \to 0$, $(0, \{\!\{0, 0\}\!\}) \to 1$
5. 색을 붙인다: 번호 매김 1은 (0, 1, 0), 번호 매김 2는 (1, 0, 0)
6. 분포를 비교한다: 둘 다 [0, 0, 1]

**답**: 색 배치는 (0, 1, 0)과 (1, 0, 0)으로 다르지만 색 분포는 [0, 0, 1]로 같다. 번호는 마음대로 붙인 것이라 분포(순열 불변)만 비교한다.

</details>

<details><summary>풀이와 답</summary>

**주어진 값**
- 일자 5개, $c^{(0)} = (0, 0, 0, 0, 0)$, $c^{(1)} = (0, 1, 1, 1, 0)$, $c^{(2)} = (0, 1, 2, 1, 0)$ (문제 1, 2)
- [GNN](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gnn-graph-neural-network-%EA%B7%B8%EB%9E%98%ED%94%84-%EC%8B%A0%EA%B2%BD%EB%A7%9D) $L$[층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5) $\leftrightarrow$ 1-WL $L$번 반복 (한 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)이 한 홉씩 정보를 퍼뜨린다)

**풀이**
1. 0층(반복 0)에서 노드 1과 노드 2의 색은 $c^{(0)}(1) = 0$, $c^{(0)}(2) = 0$ 으로 같다
2. 1층(반복 1)에서 $c^{(1)}(1) = 1$, $c^{(1)}(2) = 1$ 로 아직 같다 (둘 다 이웃이 두 개)
3. 2층(반복 2)에서 $c^{(2)}(1) = 1$, $c^{(2)}(2) = 2$ 로 달라진다
4. 이유: 노드 1은 이웃 중에 끝 노드(색 0)가 있고, 노드 2는 이웃이 모두 안쪽 노드(색 1)다. 이 차이는 이웃의 색이 한 번 갈라진 뒤에야 보인다.

**답**: 2층부터 구별된다 (색 (0, 0) → (1, 1) → (1, 2)). [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)이 늘수록 더 먼 이웃의 구조가 반영된다.

</details>

### 문제 10
[Lec05 9.3](../../Lec05_%EA%B7%B8%EB%9E%98%ED%94%84_%EC%8B%A0%EA%B2%BD%EB%A7%9D.md#93-gnn%EC%9D%B4-%EA%B5%AC%EB%B3%84%ED%95%98%EC%A7%80-%EB%AA%BB%ED%95%98%EB%8A%94-%EA%B7%B8%EB%9E%98%ED%94%84): 육각형(노드 6개 고리)과 삼각형 2개(노드 3개 고리 둘)를 1-WL로 3번 비교하고, 한쪽에는 "고리가 하나"라는 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5), 다른 쪽에는 "고리가 둘"이라는 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)이 붙어 있을 때 [GNN](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gnn-graph-neural-network-%EA%B7%B8%EB%9E%98%ED%94%84-%EC%8B%A0%EA%B2%BD%EB%A7%9D)이 어떻게 되는지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 육각형: $\mathcal{N}(v) = \{v-1, v+1\}$ (6을 넘으면 0으로 돌아간다), 삼각형 2개: 각 고리 안에서 이웃 2개
- $c^{(0)} = 0$

**풀이**
1. 식을 그대로 쓴다: $c^{(t)}(v) = \text{Hash}\big(c^{(t-1)}(v),\ \{\!\{c^{(t-1)}(u)\}\!\}\big)$
2. 반복 1에 대입한다 (두 그래프의 모든 노드): $\text{Hash}\big(0,\ \{\!\{0, 0\}\!\}\big)$
3. 서명이 한 종류뿐이다: $(0, \{\!\{0, 0\}\!\}) \to 0$ 이므로 색은 두 그래프 모두 (0, 0, 0, 0, 0, 0)
4. 반복 2에 대입한다: $\text{Hash}\big(0,\ \{\!\{0, 0\}\!\}\big)$ → 다시 한 종류, 색은 모두 0
5. 반복 3도 같다: 색은 모두 0
6. 결론: 세 번 모두 두 그래프의 색 분포 [0, 0, 0, 0, 0, 0]이 같다

**답**: 구별하지 못한다. 어떤 [GNN](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gnn-graph-neural-network-%EA%B7%B8%EB%9E%98%ED%94%84-%EC%8B%A0%EA%B2%BD%EB%A7%9D)도 두 그래프에 같은 출력을 내므로 "고리 하나"와 "고리 둘"이라는 서로 다른 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)을 동시에 맞힐 수 없다. ([위치 인코딩](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#positional-encoding-%EC%9C%84%EC%B9%98-%EC%9D%B8%EC%BD%94%EB%94%A9)을 넣는 이유가 이 한계를 깨기 위해서다.)

</details>
