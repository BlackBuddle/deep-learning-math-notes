## 기본 (직접 대입)

### 문제 1

순열 행렬 $P = \begin{pmatrix}0&1\\1&0\end{pmatrix}$와 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 행렬 $T = \begin{pmatrix}1&2\\3&4\end{pmatrix}$에서 $PT$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $P = \begin{pmatrix}0&1\\1&0\end{pmatrix}$ (두 줄을 맞바꾸는 순열 행렬)
- $T = \begin{pmatrix}1&2\\3&4\end{pmatrix}$ ([토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 두 개를 행으로 쌓은 행렬, 1행 = $(1, 2)$, 2행 = $(3, 4)$)

**풀이**
1. 식을 그대로 쓴다 ([행렬 곱](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#matrix-multiplication-%ED%96%89%EB%A0%AC-%EA%B3%B1)의 한 칸): $(PT)_{ij} = P_{i1} T_{1j} + P_{i2} T_{2j}$
2. 값을 대입한다: $PT = \begin{pmatrix}0 \times 1 + 1 \times 3 & 0 \times 2 + 1 \times 4 \\ 1 \times 1 + 0 \times 3 & 1 \times 2 + 0 \times 4\end{pmatrix}$
3. 곱셈을 한다: $0 \times 1 = 0$, $1 \times 3 = 3$, $0 \times 2 = 0$, $1 \times 4 = 4$, $1 \times 1 = 1$, $0 \times 3 = 0$, $1 \times 2 = 2$, $0 \times 4 = 0$ 이므로 $PT = \begin{pmatrix}0 + 3 & 0 + 4 \\ 1 + 0 & 2 + 0\end{pmatrix}$
4. 덧셈을 한다: $PT = \begin{pmatrix}3&4\\1&2\end{pmatrix}$

**답**: $PT = \begin{pmatrix}3&4\\1&2\end{pmatrix}$. 1행과 2행이 맞바뀌었다

</details>

### 문제 2

스케일드 점수가 $\dfrac{QK^\top}{\sqrt{m}} = \begin{pmatrix}1&2\\3&4\end{pmatrix}$이고 인과 마스크가 $M = \begin{pmatrix}0&-\infty\\0&0\end{pmatrix}$일 때, 마스크를 씌운 [어텐션](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#attention-%EC%96%B4%ED%85%90%EC%85%98) 행렬 $A$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\dfrac{QK^\top}{\sqrt{m}} = \begin{pmatrix}1&2\\3&4\end{pmatrix}$ (스케일드 점수)
- $M = \begin{pmatrix}0&-\infty\\0&0\end{pmatrix}$ (1행 2열 = 미래를 보는 칸만 $-\infty$)

**풀이**
1. 식을 그대로 쓴다: $A = \text{softmax}\Big(\dfrac{QK^\top}{\sqrt{m}} + M\Big)$
2. 값을 대입한다: $A = \text{softmax}\Big(\begin{pmatrix}1&2\\3&4\end{pmatrix} + \begin{pmatrix}0&-\infty\\0&0\end{pmatrix}\Big)$
3. 칸끼리 덧셈을 한다 (어떤 수에 $-\infty$를 더해도 $-\infty$): $\begin{pmatrix}1&-\infty\\3&4\end{pmatrix}$
4. $e^{-\infty}$의 뜻: $e$(약 2.7183)의 [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)가 한없이 작아지면 값이 0에 다가가므로 $e^{-\infty} = 0$
5. 1행 [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)에 대입한다 (점수마다 $e^{s}$를 구해 행 합으로 나눈다): $\Big(\dfrac{e^{1}}{e^{1} + e^{-\infty}},\ \dfrac{e^{-\infty}}{e^{1} + e^{-\infty}}\Big) = \Big(\dfrac{2.7183}{2.7183 + 0},\ \dfrac{0}{2.7183 + 0}\Big)$
6. 나눗셈을 한다: $(1, 0)$
7. 2행 [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)에 대입한다: $\Big(\dfrac{e^{3}}{e^{3} + e^{4}},\ \dfrac{e^{4}}{e^{3} + e^{4}}\Big)$
8. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^{3} = 20.0855$, $e^{4} = 54.5982$, 분모 $20.0855 + 54.5982 = 74.6837$
9. 나눗셈을 한다: $20.0855 \div 74.6837 = 0.2689$, $54.5982 \div 74.6837 = 0.7311$

**답**: $A = \begin{pmatrix}1&0\\0.2689&0.7311\end{pmatrix}$. 첫 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)은 자기만 보고, 둘째 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)은 두 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)을 모두 본다

</details>

### 문제 3

[토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)이 $n = 4$개일 때와 $n = 8$개일 때, 인과 마스크를 씌운 [어텐션](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#attention-%EC%96%B4%ED%85%90%EC%85%98) 행렬에서 0이 아닐 수 있는 칸의 수와 전체 칸 중 비율을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $n = 4$, $n = 8$ ([토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 수)
- 전체 칸 수는 $n \times n$ ([어텐션](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#attention-%EC%96%B4%ED%85%90%EC%85%98) 행렬은 정사각형)

**풀이**
1. 식을 그대로 쓴다: $\sum_{i=1}^{n} i = \dfrac{n(n+1)}{2}$ ([토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) $i$는 자기와 앞쪽 $i$개를 본다)
2. $n = 4$를 대입한다: $1 + 2 + 3 + 4 = \dfrac{4 \times (4 + 1)}{2}$
3. 왼쪽 덧셈을 한다: $1 + 2 + 3 + 4 = 10$
4. 오른쪽을 계산한다: $4 + 1 = 5$, $4 \times 5 = 20$, $20 \div 2 = 10$ → 양쪽이 같다. 전체는 $4 \times 4 = 16$칸이므로 비율은 $10 \div 16 = 0.625$
5. $n = 8$을 대입한다: $\dfrac{8 \times (8 + 1)}{2}$
6. 괄호를 먼저 한다: $8 + 1 = 9$ 이므로 $\dfrac{8 \times 9}{2}$
7. 곱셈을 한다: $8 \times 9 = 72$ 이므로 $\dfrac{72}{2}$
8. 나눗셈을 한다: $72 \div 2 = 36$. 전체는 $8 \times 8 = 64$칸이므로 비율은 $36 \div 64 = 0.5625$

**답**: $n = 4$이면 16칸 중 $10$칸 (0.625), $n = 8$이면 64칸 중 $36$칸 (0.5625). $n$이 커질수록 비율이 $1/2$에 가까워진다

</details>

### 문제 4

인과 마스크를 씌운 [어텐션](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#attention-%EC%96%B4%ED%85%90%EC%85%98) 행렬 $A = \begin{pmatrix}1&0&0\\0.4&0.6&0\\0.2&0.3&0.5\end{pmatrix}$와 값 행렬 $V = \begin{pmatrix}1&0\\0&2\\3&3\end{pmatrix}$로 출력 $AV$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $A = \begin{pmatrix}1&0&0\\0.4&0.6&0\\0.2&0.3&0.5\end{pmatrix}$ (아래 삼각 [어텐션](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#attention-%EC%96%B4%ED%85%90%EC%85%98) 행렬, 행 합 1)
- $V = \begin{pmatrix}1&0\\0&2\\3&3\end{pmatrix}$ (값 벡터 $\mathbf{v}_1 = (1, 0)$, $\mathbf{v}_2 = (0, 2)$, $\mathbf{v}_3 = (3, 3)$)

**풀이**
1. 식을 그대로 쓴다: $AV$의 $i$행 $= A_{i1}\mathbf{v}_1 + A_{i2}\mathbf{v}_2 + A_{i3}\mathbf{v}_3$
2. 1행에 대입해 펼친다: $1 \times (1, 0) + 0 \times (0, 2) + 0 \times (3, 3) = (1, 0)$
3. 2행에 대입한다: $0.4 \times (1, 0) + 0.6 \times (0, 2) + 0 \times (3, 3)$
4. 2행을 칸마다 펼친다: 첫 칸 $0.4 \times 1 + 0.6 \times 0 + 0 \times 3 = 0.4$, 둘째 칸 $0.4 \times 0 + 0.6 \times 2 + 0 \times 3 = 1.2$ 이므로 $(0.4, 1.2)$
5. 3행에 대입한다: $0.2 \times (1, 0) + 0.3 \times (0, 2) + 0.5 \times (3, 3)$
6. 3행 첫 칸을 펼친다: $0.2 \times 1 + 0.3 \times 0 + 0.5 \times 3 = 0.2 + 0 + 1.5 = 1.7$
7. 3행 둘째 칸을 펼친다: $0.2 \times 0 + 0.3 \times 2 + 0.5 \times 3 = 0 + 0.6 + 1.5 = 2.1$

**답**: $AV = \begin{pmatrix}1&0\\0.4&1.2\\1.7&2.1\end{pmatrix}$. 1행은 $\mathbf{v}_1$ 하나만, 3행은 세 값을 섞는다

</details>

### 문제 5

[토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 행렬 $T = \begin{pmatrix}2&0\\0&4\end{pmatrix}$에 $P = \begin{pmatrix}0&1\\1&0\end{pmatrix}$를 곱해 순서를 바꾼다. 토큰별 함수 $f(\mathbf{t}) = 2\mathbf{t}$는 $f(PT) = P\,f(T)$인지(등변), [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 평균 $\text{mean}(T)$는 $PT$로 바꿔도 같은지(불변) 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $T = \begin{pmatrix}2&0\\0&4\end{pmatrix}$ ([토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) $(2, 0)$, $(0, 4)$)
- $P$ (두 줄을 맞바꾸는 순열 행렬)
- $f(\mathbf{t}) = 2\mathbf{t}$ ([토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)마다 따로 2배)

**풀이**
1. $PT$를 구한다 (1행에 $T$의 2행, 2행에 $T$의 1행이 온다): $PT = \begin{pmatrix}0&4\\2&0\end{pmatrix}$
2. 등변: $f(T)$를 구한다. 칸마다 2를 곱한다: $f(T) = \begin{pmatrix}4&0\\0&8\end{pmatrix}$
3. 오른쪽 $P\,f(T)$를 구한다 (두 줄을 맞바꾼다): $P\,f(T) = \begin{pmatrix}0&8\\4&0\end{pmatrix}$
4. 왼쪽 $f(PT)$를 구한다. 칸마다 2를 곱한다: $f(PT) = \begin{pmatrix}0&8\\4&0\end{pmatrix}$ → $P\,f(T)$와 같다 (등변)
5. 불변: $T$의 평균을 구한다. 열마다 더해 2로 나눈다: $\big((2 + 0) \div 2,\ (0 + 4) \div 2\big) = (1, 2)$
6. $PT$의 평균을 구한다: $\big((0 + 2) \div 2,\ (4 + 0) \div 2\big) = (1, 2)$ → 같다 (불변)

**답**: $f$는 등변이다 ($f(PT) = P\,f(T) = \begin{pmatrix}0&8\\4&0\end{pmatrix}$). 평균은 순서와 무관하게 $(1, 2)$로 같아 불변이다

</details>

### 문제 6

[토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) $\mathbf{t}_1 = (1, 0)$, $\mathbf{t}_2 = (0, 1)$, $W = I$, $m = 2$인 [셀프 어텐션](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#self-attention-%EC%85%80%ED%94%84-%EC%96%B4%ED%85%90%EC%85%98)에서 순서를 바꾼 입력 $PT$의 출력이 원래 출력의 줄만 바꾼 $P\,\text{attn}(T)$와 같음을 확인하라. ($P$는 두 줄을 맞바꾸는 순열 행렬)

<details><summary>풀이와 답</summary>

**주어진 값**
- $T = \begin{pmatrix}1&0\\0&1\end{pmatrix}$, $PT = \begin{pmatrix}0&1\\1&0\end{pmatrix}$
- $W_Q = W_K = W_V = I$ (사영 없음), $m = 2$

**풀이**
1. 식을 그대로 쓴다: $\text{attn}(X) = \text{softmax}\big(XX^\top/\sqrt{m}\big)\,X$
2. 원래 입력의 점수를 구한다: $TT^\top = \begin{pmatrix}1&0\\0&1\end{pmatrix}$ 이고 $\sqrt{2} = 1.4142$로 나누면 $\begin{pmatrix}0.7071&0\\0&0.7071\end{pmatrix}$
3. [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)를 한다 (1행: $e^{0.7071} = 2.0281$, $e^{0} = 1$, 분모 $3.0281$): $A = \begin{pmatrix}0.6698&0.3302\\0.3302&0.6698\end{pmatrix}$
4. 원래 출력을 구한다 ($V = T$가 단위행렬이므로 $AT = A$): $\text{attn}(T) = \begin{pmatrix}0.6698&0.3302\\0.3302&0.6698\end{pmatrix}$
5. 오른쪽 $P\,\text{attn}(T)$를 구한다 (두 줄을 맞바꾼다): $\begin{pmatrix}0.3302&0.6698\\0.6698&0.3302\end{pmatrix}$
6. 바꾼 입력의 점수를 구한다: $(PT)(PT)^\top = \begin{pmatrix}0&1\\1&0\end{pmatrix}\begin{pmatrix}0&1\\1&0\end{pmatrix} = \begin{pmatrix}1&0\\0&1\end{pmatrix}$ 이므로 점수와 $A$가 위와 같다
7. $A$와 $PT$를 곱한다 (1행: $0.6698 \times (0, 1) + 0.3302 \times (1, 0) = (0.3302, 0.6698)$)
8. 2행을 곱한다: $0.3302 \times (0, 1) + 0.6698 \times (1, 0) = (0.6698, 0.3302)$ 이므로 $\text{attn}(PT) = \begin{pmatrix}0.3302&0.6698\\0.6698&0.3302\end{pmatrix}$

**답**: $\text{attn}(PT) = \begin{pmatrix}0.3302&0.6698\\0.6698&0.3302\end{pmatrix} = P\,\text{attn}(T)$. 입력 순서를 바꾸면 출력도 같은 방식으로 줄만 바뀐다 (순열 등변)

</details>

### 문제 7

같은 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) $(1, 0)$ 두 개가 있다. (a) 위치 벡터 없이 $W = I$, $m = 2$인 [셀프 어텐션](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#self-attention-%EC%85%80%ED%94%84-%EC%96%B4%ED%85%90%EC%85%98)에 넣을 때 두 출력을 구하라. (b) 자리마다 위치 벡터 $(0, 0)$, $(1, 1)$을 더한 입력 $(1, 0)$, $(2, 1)$을 넣을 때 두 출력을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- (a) $X = \begin{pmatrix}1&0\\1&0\end{pmatrix}$ (같은 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 두 개)
- (b) $U = \begin{pmatrix}1&0\\2&1\end{pmatrix}$ ([토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) $(1, 0)$에 위치 벡터 $(0, 0)$, $(1, 1)$을 더한 입력)
- $W = I$, $m = 2$ ($\sqrt{2} = 1.4142$)

**풀이**
1. 식을 그대로 쓴다: $\text{attn}(X) = \text{softmax}\big(XX^\top/\sqrt{m}\big)\,X$
2. (a) 점수를 구한다: 모든 칸이 $(1, 0)\cdot(1, 0) = 1 \times 1 + 0 \times 0 = 1$ 이므로 $\begin{pmatrix}1&1\\1&1\end{pmatrix}$, 나누면 $\begin{pmatrix}0.7071&0.7071\\0.7071&0.7071\end{pmatrix}$
3. (a) 점수가 모두 같으므로 [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)는 $(0.5, 0.5)$ (두 칸 모두 $2.0281 \div 4.0562 = 0.5$)
4. (a) 출력을 구한다: $0.5 \times (1, 0) + 0.5 \times (1, 0) = (1, 0)$ → 두 행 모두 $(1, 0)$
5. (b) 점수를 구한다: $(1, 0)\cdot(1, 0) = 1$, $(1, 0)\cdot(2, 1) = 2$, $(2, 1)\cdot(2, 1) = 2 \times 2 + 1 \times 1 = 5$ 이므로 $UU^\top = \begin{pmatrix}1&2\\2&5\end{pmatrix}$
6. (b) $1.4142$로 나눈다: $\begin{pmatrix}0.7071&1.4142\\1.4142&3.5355\end{pmatrix}$
7. (b) 1행 [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4): $e^{0.7071} = 2.0281$, $e^{1.4142} = 4.1133$, 분모 $6.1414$ 이므로 $(2.0281 \div 6.1414,\ 4.1133 \div 6.1414) = (0.3302, 0.6698)$
8. (b) 2행 [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4): $e^{1.4142} = 4.1133$, $e^{3.5355} = 34.3133$, 분모 $38.4266$ 이므로 $(0.1070, 0.8930)$
9. (b) 1행 출력을 펼친다: $0.3302 \times (1, 0) + 0.6698 \times (2, 1) = (0.3302 + 1.3396,\ 0 + 0.6698) = (1.6698, 0.6698)$
10. (b) 2행 출력을 펼친다: $0.1070 \times (1, 0) + 0.8930 \times (2, 1) = (0.1070 + 1.7860,\ 0 + 0.8930) = (1.8930, 0.8930)$

**답**: (a) 두 출력은 모두 $(1, 0)$으로 같다 (어느 자리인지 구별하지 못한다). (b) 출력은 $(1.6698, 0.6698)$, $(1.8930, 0.8930)$으로 자리마다 다르다. 위치 벡터가 순서 정보를 넣어 준다

</details>

### 문제 8

[토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)이 $n = 6$개인 문장에 인과 마스크를 씌운다. 마스크로 막혀 0이 되는 칸은 모두 몇 개이고, 3번째 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)의 행에서 막히는 칸은 몇 개인가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $n = 6$ ([토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 수, [어텐션](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#attention-%EC%96%B4%ED%85%90%EC%85%98) 행렬은 $6 \times 6 = 36$칸)
- 볼 수 있는 칸의 수는 $\dfrac{n(n+1)}{2}$

**풀이**
1. 식을 그대로 쓴다: 막힌 칸 수 $= n^2 - \dfrac{n(n+1)}{2}$
2. 값을 대입한다: $6^2 - \dfrac{6 \times (6 + 1)}{2}$
3. 제곱을 한다: $6^2 = 36$
4. 볼 수 있는 칸을 구한다: $6 + 1 = 7$, $6 \times 7 = 42$, $42 \div 2 = 21$ 이므로 $36 - 21$
5. 뺄셈을 한다: $36 - 21 = 15$
6. 3번째 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)의 행을 센다: [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 3은 $j \le 3$인 3개를 볼 수 있으므로 막히는 칸은 $6 - 3 = 3$개

**답**: 막혀 0이 되는 칸은 $15$개 (36칸 중 21칸만 남는다), 3번째 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)의 행에서는 $3$개가 막힌다

</details>

<details><summary>풀이와 답</summary>

**주어진 값**
- $x = (1, 2)$ (원래 순서의 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 값), $x' = (2, 1)$ (순서를 바꾼 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 값)

5. 2행 점수를 구한다: $(2 \times 1,\ 2 \times 2) = (2, 4)$, [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)는 $e^{2} = 7.3891$, $e^{4} = 54.5982$, 분모 $61.9873$ 이므로 $(0.1192, 0.8808)$

8. 바꾼 순서의 2행(값 1인 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)) 점수는 $(1 \times 2,\ 1 \times 1) = (2, 1)$, [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)는 $(0.7311, 0.2689)$, 출력 $0.7311 \times 2 + 0.2689 \times 1 = 1.4622 + 0.2689 = 1.7311$

### 문제 10

<details><summary>풀이와 답</summary>

**주어진 값**
- $x = (1, 2)$ 그리고 바꾼 입력 $x' = (1, 4)$ (둘째 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)만 다름)
- $m = 1$ ($\sqrt{m} = 1$), 점수 $= x_i x_j$, 값 $= x_j$

**풀이**
1. 식을 그대로 쓴다: $y_1 = \sum_j a_{1j}\, x_j$, $a_{1\cdot} = \text{softmax}(x_1 x_1 + M_{11},\ x_1 x_2 + M_{12})$
2. (a) 마스크 없음, $x = (1, 2)$: 점수는 $(1 \times 1,\ 1 \times 2) = (1, 2)$, [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)는 $(0.2689, 0.7311)$ ($e^{1} = 2.7183$, $e^{2} = 7.3891$)

4. (b) 인과 마스크, $x = (1, 2)$: 1행은 $M_{12} = -\infty$이므로 점수가 $(1, -\infty)$, $e^{-\infty} = 0$ 이라 [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)는 $(1, 0)$
5. (b) 출력을 구한다: $y_1 = 1 \times 1 + 0 \times 2 = 1$
6. 둘째 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)을 4로 바꾼다. (a)의 점수는 $(1 \times 1,\ 1 \times 4) = (1, 4)$, [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)는 $e^{1} = 2.7183$, $e^{4} = 54.5982$, 분모 $57.3165$ 이므로 $(0.0474, 0.9526)$
7. (a)의 출력을 구한다: $y_1 = 0.0474 \times 1 + 0.9526 \times 4 = 3.8577$ (반올림 전 값으로 계산)
8. (b)의 점수는 여전히 $(1, -\infty)$ 이므로 [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4) $(1, 0)$, 출력 $y_1 = 1 \times 1 + 0 \times 4 = 1$

**답**: 마스크 없이는 $y_1$이 $1.7311$에서 $3.8577$로 바뀌어 미래 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)이 과거 출력에 새어 들어간다. 인과 마스크를 쓰면 $y_1 = 1$로 그대로다. 다음 단어를 맞히는 [학습](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5)에서 답을 미리 보지 않게 하는 장치다
