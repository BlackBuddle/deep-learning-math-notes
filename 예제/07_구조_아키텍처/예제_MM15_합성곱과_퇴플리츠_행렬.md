# 예제: 합성곱과 퇴플리츠 행렬

개념 노트: [MM15_합성곱과_퇴플리츠_행렬](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/07_%EA%B5%AC%EC%A1%B0_%EC%95%84%ED%82%A4%ED%85%8D%EC%B2%98/MM15_%ED%95%A9%EC%84%B1%EA%B3%B1%EA%B3%BC_%ED%87%B4%ED%94%8C%EB%A6%AC%EC%B8%A0_%ED%96%89%EB%A0%AC.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

> [!NOTE]
> **쓰는 법**
> 풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 쓰는 식: $y[n] = b + \sum_{k=-1}^{1} w[k]\,x[n+k]$, $y = Tx + b$, $T_{n,\,n+k} = w[k]$. 끝을 넘는 칸은 0으로 본다([패딩](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#padding-%ED%8C%A8%EB%94%A9)). [필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0)는 $(w[-1], w[0], w[1])$ 순서로 적는다.

## 기본 (직접 대입)

### 문제 1
입력 $x = (3, 1, 2)$, [필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0) $(w[-1], w[0], w[1]) = (1, -1, 2)$, $b = 0$이다. 가운데 출력 $y[1]$과 같은 계산을 하는 행렬 $T$의 1행을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x[0] = 3,\ x[1] = 1,\ x[2] = 2$ (입력)
- $w[-1] = 1,\ w[0] = -1,\ w[1] = 2$ ([필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0))
- $b = 0$ ([편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5)), $n = 1$ (구할 칸)

**풀이**
1. 식을 그대로 쓴다: $y[n] = b + \sum_{k=-1}^{1} w[k]\,x[n+k]$, $T_{n,\,n+k} = w[k]$
2. 값을 대입한다: $y[1] = 0 + \sum_{k=-1}^{1} w[k]\,x[1+k]$
3. 시그마를 k = −1, 0, 1 세 항으로 풀어 쓴다: $y[1] = 0 + w[-1]\,x[0] + w[0]\,x[1] + w[1]\,x[2]$
4. 값을 넣는다: $y[1] = 0 + 1 \times 3 + (-1) \times 1 + 2 \times 2$
5. 곱셈을 먼저 한다: 1 × 3 = 3, (−1) × 1 = −1, 2 × 2 = 4 이므로 $y[1] = 0 + 3 + (-1) + 4$
6. 앞에서부터 더한다: 0 + 3 = 3, 3 + (−1) = 2, 2 + 4 = 6 이므로 $y[1] = 6$
7. T의 1행을 쓴다: $T_{1,0} = w[-1] = 1$, $T_{1,1} = w[0] = -1$, $T_{1,2} = w[1] = 2$ 이므로 1행은 $(1, -1, 2)$
8. [행렬 곱](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#matrix-multiplication-%ED%96%89%EB%A0%AC-%EA%B3%B1)으로 확인한다: $1 \times 3 + (-1) \times 1 + 2 \times 2 = 3 - 1 + 4 = 6$

**답**: $y[1] = 6$, T의 1행 $= (1, -1, 2)$

</details>

### 문제 2
입력 $x = (1, 2, 3, 4)$, [필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0) $(1, 1, 1)$, $b = 0$, 끝은 0 [패딩](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#padding-%ED%8C%A8%EB%94%A9)이다. 출력 $y[0], y[1], y[2], y[3]$을 모두 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x[0] = 1,\ x[1] = 2,\ x[2] = 3,\ x[3] = 4$ (입력)
- $w[-1] = w[0] = w[1] = 1$ ([필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0)), $b = 0$
- $x[-1] = 0,\ x[4] = 0$ ([패딩](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#padding-%ED%8C%A8%EB%94%A9))

**풀이**
1. 식을 그대로 쓴다: $y[n] = w[-1]\,x[n-1] + w[0]\,x[n] + w[1]\,x[n+1]$
2. 값을 대입한다: $y[n] = 1 \times x[n-1] + 1 \times x[n] + 1 \times x[n+1]$
3. $y[0]$: $1 \times x[-1] + 1 \times x[0] + 1 \times x[1] = 1 \times 0 + 1 \times 1 + 1 \times 2 = 0 + 1 + 2 = 3$
4. $y[1]$: $1 \times x[0] + 1 \times x[1] + 1 \times x[2] = 1 \times 1 + 1 \times 2 + 1 \times 3 = 1 + 2 + 3 = 6$
5. $y[2]$: $1 \times x[1] + 1 \times x[2] + 1 \times x[3] = 1 \times 2 + 1 \times 3 + 1 \times 4 = 2 + 3 + 4 = 9$
6. $y[3]$: $1 \times x[2] + 1 \times x[3] + 1 \times x[4] = 1 \times 3 + 1 \times 4 + 1 \times 0 = 3 + 4 + 0 = 7$

**답**: $y = (3, 6, 9, 7)$ (이웃 셋의 합이라 가장자리는 [패딩](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#padding-%ED%8C%A8%EB%94%A9) 때문에 작게 나온다)

</details>

### 문제 3
[필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0) $(w[-1], w[0], w[1]) = (1, 2, 3)$을 길이 4 입력에 쓰는 [퇴플리츠 행렬](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#toeplitz-matrix-%ED%87%B4%ED%94%8C%EB%A6%AC%EC%B8%A0-%ED%96%89%EB%A0%AC) $T$를 적고, $x = (1, 0, 2, 1)$에 곱해 $Tx$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $w[-1] = 1,\ w[0] = 2,\ w[1] = 3$ ([필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0))
- $x = (1, 0, 2, 1)$ (입력), 길이 4이므로 $T$는 4×4

**풀이**
1. 식을 그대로 쓴다: $T_{n,\,n+k} = w[k]$, $Tx$의 $n$번째 칸 = T의 n행과 x를 칸끼리 곱해 더한 값
2. 값을 대입한다: $T_{n,\,n-1} = 1,\quad T_{n,\,n} = 2,\quad T_{n,\,n+1} = 3$
3. 대각선 아래에 1, 대각선에 2, 대각선 위에 3을 놓고 나머지는 0이다: $T = \begin{pmatrix} 2&3&0&0\\ 1&2&3&0\\ 0&1&2&3\\ 0&0&1&2 \end{pmatrix}$
4. 0행: $2 \times 1 + 3 \times 0 + 0 \times 2 + 0 \times 1 = 2 + 0 + 0 + 0 = 2$
5. 1행: $1 \times 1 + 2 \times 0 + 3 \times 2 + 0 \times 1 = 1 + 0 + 6 + 0 = 7$
6. 2행: $0 \times 1 + 1 \times 0 + 2 \times 2 + 3 \times 1 = 0 + 0 + 4 + 3 = 7$
7. 3행: $0 \times 1 + 0 \times 0 + 1 \times 2 + 2 \times 1 = 0 + 0 + 2 + 2 = 4$

**답**: $Tx = (2, 7, 7, 4)$

</details>

### 문제 4
길이 8 입력에 대해 [덴스 층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dense-layer-%EB%8D%B4%EC%8A%A4-%EC%B8%B5)(8 → 8)이 배우는 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) 수와, [필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0) 길이 3 [합성곱](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#convolution-%ED%95%A9%EC%84%B1%EA%B3%B1)([편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5) 제외)이 배우는 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) 수를 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 입력 길이 8, 출력 길이 8
- [필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0) 길이 3 ([합성곱](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#convolution-%ED%95%A9%EC%84%B1%EA%B3%B1)이 배우는 값은 $w[-1], w[0], w[1]$)

**풀이**
1. 식을 그대로 쓴다: 덴스 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) 수 $=$ (입력 길이) × (출력 길이), [합성곱](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#convolution-%ED%95%A9%EC%84%B1%EA%B3%B1) [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) 수 $=$ [필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0) 길이
2. 값을 대입한다: 덴스 $= 8 \times 8$, [합성곱](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#convolution-%ED%95%A9%EC%84%B1%EA%B3%B1) $= 3$
3. 곱셈을 한다: 8 × 8 = 64
4. 비교한다: 64 ÷ 3 ≈ 21.3 (덴스가 약 21배 많다)
5. 입력이 길어져도 [합성곱](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#convolution-%ED%95%A9%EC%84%B1%EA%B3%B1)은 3개 그대로다: 길이 100이면 덴스 100 × 100 = 10,000개, [합성곱](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#convolution-%ED%95%A9%EC%84%B1%EA%B3%B1)은 여전히 3개

**답**: 덴스 64개, [합성곱](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#convolution-%ED%95%A9%EC%84%B1%EA%B3%B1) 3개

</details>

### 문제 5
경계 검출 [필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0) $(-1, 0, 1)$을 입력 $x = (0, 1, 3, 0)$과 한 칸 오른쪽으로 민 입력 $x' = (0, 0, 1, 3)$에 각각 적용하라(끝은 0 [패딩](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#padding-%ED%8C%A8%EB%94%A9)). 두 출력이 한 칸 밀린 관계인지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $w[-1] = -1,\ w[0] = 0,\ w[1] = 1$ ([필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0)), 그래서 $y[n] = -x[n-1] + x[n+1]$
- $x = (0, 1, 3, 0)$, $x' = (0, 0, 1, 3)$ (끝은 [패딩](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#padding-%ED%8C%A8%EB%94%A9) 0: $x[-1] = x[4] = 0$)

**풀이**
1. 식을 그대로 쓴다: $y[n] = w[-1]\,x[n-1] + w[0]\,x[n] + w[1]\,x[n+1]$
2. 값을 대입한다: $y[n] = (-1) \times x[n-1] + 0 \times x[n] + 1 \times x[n+1] = x[n+1] - x[n-1]$
3. $x$의 $y[0]$: $x[1] - x[-1] = 1 - 0 = 1$
4. $x$의 $y[1]$: $x[2] - x[0] = 3 - 0 = 3$
5. $x$의 $y[2]$: $x[3] - x[1] = 0 - 1 = -1$
6. $x$의 $y[3]$: $x[4] - x[2] = 0 - 3 = -3$ 이므로 $y = (1, 3, -1, -3)$
7. $x'$의 $y'[0]$: $x'[1] - x'[-1] = 0 - 0 = 0$
8. $x'$의 $y'[1]$: $x'[2] - x'[0] = 1 - 0 = 1$
9. $x'$의 $y'[2]$: $x'[3] - x'[1] = 3 - 0 = 3$
10. $x'$의 $y'[3]$: $x'[4] - x'[2] = 0 - 1 = -1$ 이므로 $y' = (0, 1, 3, -1)$
11. $y$를 한 칸 오른쪽으로 밀면 앞에 0이 들어오고 마지막 값이 잘린다: $(0, 1, 3, -1)$ 이므로 $y'$와 같다

**답**: $y = (1, 3, -1, -3)$, $y' = (0, 1, 3, -1)$. 입력을 밀면 출력도 같이 밀린다([이동 등변성](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#translation-equivariance-%EC%9D%B4%EB%8F%99-%EB%93%B1%EB%B3%80%EC%84%B1)). 이 예는 $x$의 끝값이 0이라 경계에서도 맞는다.

</details>

<details><summary>풀이와 답</summary>

**주어진 값**
- $K_1 = 3,\ K_2 = 3$ ([필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0) 크기)

### 문제 8
[필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0) $(w[-1], w[0], w[1]) = (2, 1, -1)$을 길이 5 입력에 쓰는 [퇴플리츠 행렬](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#toeplitz-matrix-%ED%87%B4%ED%94%8C%EB%A6%AC%EC%B8%A0-%ED%96%89%EB%A0%AC) $T$에서 0이 아닌 칸은 몇 개인가? 전체 칸 수에 비해 얼마나 되는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- [필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0)의 세 값 2, 1, −1은 모두 0이 아니다
- $T$는 5×5, 전체 칸 5 × 5 = 25개
- $T_{n,\,n+k} = w[k]$ (행마다 대각선과 그 위아래 한 칸에만 값이 있다)

**풀이**
1. 식을 그대로 쓴다: $T_{n,\,n+k} = w[k]$ ($0 \le n+k \le 4$인 칸만 존재한다)
2. 값을 대입해 행렬을 쓴다: $T = \begin{pmatrix} 1&-1&0&0&0\\ 2&1&-1&0&0\\ 0&2&1&-1&0\\ 0&0&2&1&-1\\ 0&0&0&2&1 \end{pmatrix}$ (대각선 $w[0] = 1$, 아래 $w[-1] = 2$, 위 $w[1] = -1$)
3. 대각선 칸을 센다: 5개
4. 대각선 바로 아래 칸을 센다: 한 칸 줄어 4개
5. 대각선 바로 위 칸을 센다: 4개
6. 더한다: 5 + 4 + 4 = 13
7. 비율을 구한다: 13 ÷ 25 = 0.52

**답**: 0이 아닌 칸 13개 (전체 25칸의 52%). 길이가 길어질수록 0의 비율이 커진다.

</details>

### 문제 10
[Lec04 3.2](../../Lec04_%EA%B2%A9%EC%9E%90_%EC%95%84%ED%82%A4%ED%85%8D%EC%B2%98.md#32-%ED%96%89%EB%A0%AC%EB%A1%9C-%EB%B3%B8-%ED%95%A9%EC%84%B1%EA%B3%B1)는 [합성곱](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#convolution-%ED%95%A9%EC%84%B1%EA%B3%B1)을 경계 검출기로 보여 준다. 입력 $x = (2, 2, 2, 6, 6, 6)$(왼쪽 어둡고 오른쪽 밝은 한 줄)에 [필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0) $(-1, 0, 1)$을 0 [패딩](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#padding-%ED%8C%A8%EB%94%A9)으로 적용해 출력을 구하고, 경계가 어디에서 잡히는지, 가장자리 값이 왜 이상한지 설명하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x[0..5] = 2, 2, 2, 6, 6, 6$ (입력)
- $w[-1] = -1,\ w[0] = 0,\ w[1] = 1$, 그래서 $y[n] = x[n+1] - x[n-1]$
- $x[-1] = 0,\ x[6] = 0$ ([패딩](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#padding-%ED%8C%A8%EB%94%A9))

**풀이**
1. 식을 그대로 쓴다: $y[n] = w[-1]\,x[n-1] + w[0]\,x[n] + w[1]\,x[n+1]$
2. 값을 대입한다: $y[n] = (-1) \times x[n-1] + 0 \times x[n] + 1 \times x[n+1] = x[n+1] - x[n-1]$
3. $y[0] = x[1] - x[-1] = 2 - 0 = 2$
4. $y[1] = x[2] - x[0] = 2 - 2 = 0$
5. $y[2] = x[3] - x[1] = 6 - 2 = 4$
6. $y[3] = x[4] - x[2] = 6 - 2 = 4$
7. $y[4] = x[5] - x[3] = 6 - 6 = 0$
8. $y[5] = x[6] - x[4] = 0 - 6 = -6$
9. 읽는다: 값이 2에서 6으로 뛰는 곳(칸 2와 3 사이)의 양쪽에서 4가 나온다. 평평한 곳(y[1], y[4])은 0이다.

**답**: $y = (2, 0, 4, 4, 0, -6)$. 경계는 $y[2], y[3]$에서 잡힌다. $y[0] = 2$와 $y[5] = -6$은 [패딩](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#padding-%ED%8C%A8%EB%94%A9) 0 때문에 입력 끝이 "0에서 2로", "6에서 0으로" 뛰는 것처럼 보여 생긴 가짜 경계다.

</details>
