## 기본 (직접 대입)

### 문제 1

$w = 0.5$, $u = 2$, 처음 기억 $h_0 = 4$, 1단계 입력 $x_1 = 3$일 때 $h_1$을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $w = 0.5$ (기억을 다음 단계로 넘길 때 곱하는 배율)
- $u = 2$ (새 입력을 받아들이는 배율)
- $h_0 = 4$ (처음 기억), $x_1 = 3$ (1단계 입력)

**풀이**
1. 식을 그대로 쓴다: $h_t = w\, h_{t-1} + u\, x_t$
2. 값을 대입한다 ($t = 1$): $h_1 = 0.5 \times 4 + 2 \times 3$
3. 곱셈을 한다: $0.5 \times 4 = 2$, $2 \times 3 = 6$ 이므로 $h_1 = 2 + 6$
4. 덧셈을 한다: $h_1 = 8$

**답**: $h_1 = 8$

</details>

### 문제 2

$w = 0.5$, $u = 1$, $h_0 = 0$이고 입력이 $x = (2, 4, 6)$일 때 한 단계씩 계산해 $h_1, h_2, h_3$을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $w = 0.5$, $u = 1$ (배율)
- $h_0 = 0$ (처음 기억)
- $x_1 = 2$, $x_2 = 4$, $x_3 = 6$ (세 단계의 입력)

**풀이**
1. 식을 그대로 쓴다: $h_t = w\, h_{t-1} + u\, x_t$
2. $h_1$에 대입한다: $h_1 = 0.5 \times 0 + 1 \times 2$
3. 곱셈과 덧셈을 한다: $0.5 \times 0 = 0$, $1 \times 2 = 2$ 이므로 $h_1 = 0 + 2 = 2$
4. $h_2$에 대입한다 (방금 구한 $h_1$을 쓴다): $h_2 = 0.5 \times 2 + 1 \times 4$
5. 곱셈과 덧셈을 한다: $0.5 \times 2 = 1$, $1 \times 4 = 4$ 이므로 $h_2 = 1 + 4 = 5$
6. $h_3$에 대입한다: $h_3 = 0.5 \times 5 + 1 \times 6$
7. 곱셈과 덧셈을 한다: $0.5 \times 5 = 2.5$, $1 \times 6 = 6$ 이므로 $h_3 = 2.5 + 6 = 8.5$

**답**: $h_1 = 2$, $h_2 = 5$, $h_3 = 8.5$

</details>

### 문제 3

배율을 단계 수만큼 곱한 $w^t$를 $0.9^5$, $1.1^5$, $0.5^6$에 대해 한 번에 하나씩 곱해 가며 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $0.9^5$: 0.9를 5번 곱한다
- $1.1^5$: 1.1을 5번 곱한다
- $0.5^6$: 0.5를 6번 곱한다

**풀이**
1. 식을 그대로 쓴다: $w^t = \underbrace{w \times w \times \cdots \times w}_{t\text{개}}$
2. $0.9^5$를 구한다: $0.9^2 = 0.81$, $0.9^3 = 0.81 \times 0.9 = 0.729$, $0.9^4 = 0.729 \times 0.9 = 0.6561$, $0.9^5 = 0.6561 \times 0.9 = 0.59049$
3. $1.1^5$를 구한다: $1.1^2 = 1.21$, $1.1^3 = 1.21 \times 1.1 = 1.331$, $1.1^4 = 1.331 \times 1.1 = 1.4641$, $1.1^5 = 1.4641 \times 1.1 = 1.61051$
4. $0.5^6$를 구한다: $0.5^2 = 0.25$, $0.5^3 = 0.125$, $0.5^4 = 0.0625$, $0.5^5 = 0.03125$, $0.5^6 = 0.03125 \times 0.5 = 0.015625$

**답**: $0.9^5 = 0.59049$ (조금 줄어든다), $1.1^5 = 1.61051$ (조금 커진다), $0.5^6 = 0.015625$ (거의 사라진다). 1보다 작으면 줄고 크면 는다

</details>

### 문제 4

$w = 0.5$, $u = 1$, $h_0 = 4$, $x = (2, 6)$일 때 펼친 식 $h_t = w^t h_0 + \sum_{k=1}^{t} w^{t-k} u\, x_k$로 $h_2$를 구하고, 한 단계씩 계산한 값과 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $w = 0.5$, $u = 1$, $h_0 = 4$ (처음 기억)
- $x_1 = 2$, $x_2 = 6$ (입력), $t = 2$

**풀이**
1. 식을 그대로 쓴다: $h_t = w^t h_0 + \sum_{k=1}^{t} w^{t-k}\, u\, x_k$
2. 값을 대입한다: $h_2 = 0.5^2 \times 4 + \sum_{k=1}^{2} 0.5^{2-k} \times 1 \times x_k$
3. $\sum$을 두 항으로 펼친다 ($k = 1, 2$): $h_2 = 0.5^2 \times 4 + 0.5^1 \times 1 \times 2 + 0.5^0 \times 1 \times 6$
4. 거듭제곱을 계산한다 ($0.5^0$은 아무것도 곱하지 않은 것이라 1): $0.5^2 = 0.25$, $0.5^1 = 0.5$, $0.5^0 = 1$
5. 항마다 곱한다: $0.25 \times 4 = 1$, $0.5 \times 1 \times 2 = 1$, $1 \times 1 \times 6 = 6$
6. 더한다: $h_2 = 1 + 1 + 6 = 8$
7. 한 단계씩 확인한다: $h_1 = 0.5 \times 4 + 1 \times 2 = 2 + 2 = 4$, $h_2 = 0.5 \times 4 + 1 \times 6 = 2 + 6 = 8$

**답**: $h_2 = 8$. 펼친 식과 한 단계씩 계산한 값이 같다

</details>

### 문제 5

$w = 0.8$, $u = 1$일 때 10단계까지 돌린 $h_{10}$에서 입력 $x_1$, $x_5$, $x_{10}$이 각각 몇 배($w^{10-k}$)로 들어오는지 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $w = 0.8$ (순환 배율), $u = 1$
- $t = 10$, $k = 1, 5, 10$ (입력의 단계)

**풀이**
1. 식을 그대로 쓴다: $x_k$가 $h_t$에 들어오는 배율 $= w^{\,t-k}$ ($u = 1$이라 $u$는 생략)
2. $x_1$을 대입한다: $w^{10-1} = 0.8^{9}$
3. 거듭제곱을 한다 (0.8을 9번 곱한다): $0.8^2 = 0.64$, $0.8^3 = 0.512$, $0.8^4 = 0.4096$, $0.8^5 = 0.32768$, $0.8^6 = 0.262144$, $0.8^7 = 0.2097152$, $0.8^8 = 0.16777216$, $0.8^9 = 0.134217728$
4. $x_5$를 대입한다: $w^{10-5} = 0.8^{5} = 0.32768$ (위에서 구한 값)
5. $x_{10}$을 대입한다: $w^{10-10} = 0.8^{0} = 1$ (0제곱은 1)
6. 비교한다: $1 \div 0.1342 = 7.45$

**답**: $x_1$은 $0.1342$배, $x_5$는 $0.3277$배, $x_{10}$은 $1$배로 들어온다. 가장 오래된 입력은 가장 최근 입력의 $1/7.45$로 흐려진다

</details>

### 문제 6

$\dfrac{\partial h_t}{\partial h_k} = w^{t-k}$에서 20단계 전($t - k = 20$) 상태의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) 배율을 $w = 0.9$와 $w = 1.1$에 대해 구하고 소실인지 폭주인지 판단하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $t - k = 20$ (거슬러 올라가는 단계 수)
- $w = 0.9$ 또는 $w = 1.1$ (한 고리의 [미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#derivative-%EB%AF%B8%EB%B6%84) $\partial h_j / \partial h_{j-1}$)

**풀이**
1. 식을 그대로 쓴다: $\dfrac{\partial h_t}{\partial h_k} = \prod_{j=k+1}^{t} \dfrac{\partial h_j}{\partial h_{j-1}} = w^{\,t-k}$
2. $w = 0.9$를 대입한다: $0.9^{20}$ (0.9를 20번 곱한 값, 계산기의 $x^y$ 키)
3. 계산한다: $0.9^{20} = 0.1216$
4. $w = 1.1$을 대입한다: $1.1^{20}$
5. 계산한다: $1.1^{20} = 6.7275$
6. 판단한다: $0.1216 < 1$ 이므로 줄어들고 (소실), $6.7275 > 1$ 이므로 커진다 (폭주)

**답**: $w = 0.9$이면 $0.1216$배로 [기울기 소실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#vanishing-gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0-%EC%86%8C%EC%8B%A4), $w = 1.1$이면 $6.7275$배로 [기울기 폭주](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#exploding-gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0-%ED%8F%AD%EC%A3%BC)다. 20단계만 거슬러도 이만큼 달라진다

</details>

### 문제 7

$w = 2$, $u = 1$, $h_0 = 1$, $x = (1, 0, 1)$일 때 $h_1, h_2$를 구하고, 공유 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $\dfrac{\partial h_3}{\partial w} = \sum_{k=1}^{3} w^{3-k} h_{k-1}$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $w = 2$, $u = 1$, $h_0 = 1$
- $x_1 = 1$, $x_2 = 0$, $x_3 = 1$ (입력)

**풀이**
1. 식을 그대로 쓴다: $h_t = w\, h_{t-1} + u\, x_t$
2. $h_1$을 구한다: $2 \times 1 + 1 \times 1 = 2 + 1 = 3$
3. $h_2$를 구한다: $2 \times 3 + 1 \times 0 = 6 + 0 = 6$
4. [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) 식을 쓴다: $\dfrac{\partial h_3}{\partial w} = \sum_{k=1}^{3} w^{3-k}\, h_{k-1}$
5. 값을 대입해 $\sum$을 세 항으로 펼친다: $2^{2} \times h_0 + 2^{1} \times h_1 + 2^{0} \times h_2$
6. 기억 값을 넣는다: $2^{2} \times 1 + 2^{1} \times 3 + 2^{0} \times 6$
7. 거듭제곱을 계산한다: $2^2 = 4$, $2^1 = 2$, $2^0 = 1$ 이므로 $4 \times 1 + 2 \times 3 + 1 \times 6$
8. 곱셈과 덧셈을 한다: $4 + 6 + 6 = 16$

**답**: $h_1 = 3$, $h_2 = 6$이고 $\partial h_3 / \partial w = 16$이다 (펼친 식 $h_3 = w^3 + w^2 + 1$을 $w$로 미분한 $3w^2 + 2w = 12 + 4 = 16$과 같다)

</details>

### 문제 8

대각 행렬 $W = \mathrm{diag}(0.5, 2)$를 10번 곱한 $W^{10}$을 구하고, 처음 기억 $h_0 = (1, 1)$에 입력 없이 $W$만 10번 적용한 $W^{10} h_0$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $W = \begin{pmatrix}0.5&0\\0&2\end{pmatrix}$ (대각선에 0.5와 2가 있고 나머지는 0인 행렬)
- $t = 10$ (곱하는 횟수)
- $h_0 = (1, 1)$ (처음 기억)

**풀이**
1. 식을 그대로 쓴다: $W^{t} = \mathrm{diag}(a^{t}, b^{t})$ (대각 행렬끼리 곱하면 대각선 칸끼리만 곱해진다)
2. 값을 대입한다: $W^{10} = \mathrm{diag}(0.5^{10},\ 2^{10})$
3. 첫째 칸을 구한다 (0.5를 10번 곱한다): $0.5^{10} = 0.0009766$
4. 둘째 칸을 구한다 (2를 10번 곱한다): $2^{10} = 1024$ ($2^5 = 32$, $32 \times 32 = 1024$)
5. 행렬을 쓴다: $W^{10} = \begin{pmatrix}0.0009766&0\\0&1024\end{pmatrix}$
6. $h_0$에 곱한다: $W^{10} h_0 = (0.0009766 \times 1 + 0 \times 1,\ 0 \times 1 + 1024 \times 1)$
7. 계산한다: $(0.0009766 + 0,\ 0 + 1024) = (0.0009766, 1024)$

**답**: $W^{10} = \mathrm{diag}(0.0009766,\ 1024)$, $W^{10}h_0 = (0.0009766, 1024)$. 첫째 방향의 기억은 사라지고 둘째 방향은 1024배로 폭주한다

</details>

### 문제 9

[Lec10 5.2](../../Lec10_%EA%B8%B0%EC%96%B5%EA%B3%BC_%EC%8B%9C%ED%80%80%EC%8A%A4.md#52-w%EC%9D%98-%EA%B1%B0%EB%93%AD%EC%A0%9C%EA%B3%B1%EA%B3%BC-%EA%B8%B0%EC%9A%B8%EA%B8%B0-%EC%86%8C%EC%8B%A4)에서 순환 배율이 $w = 0.5$일 때, 옛 정보의 배율 $w^t$가 처음 크기의 1%($0.01$) 아래로 떨어지려면 몇 단계가 지나야 하는지 $t = 1, 2, \ldots$를 하나씩 곱해 가며 찾아라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $w = 0.5$ (순환 배율)
- 기준값 $0.01$ (처음의 1%)

**풀이**
1. 식을 그대로 쓴다: $w^{t} < 0.01$을 만족하는 가장 작은 $t$ (한 단계마다 앞 값에 $0.5$를 곱한다)
2. $t = 1, 2, 3$: $0.5^1 = 0.5$, $0.5^2 = 0.5 \times 0.5 = 0.25$, $0.5^3 = 0.25 \times 0.5 = 0.125$
3. $t = 4, 5$: $0.5^4 = 0.125 \times 0.5 = 0.0625$, $0.5^5 = 0.0625 \times 0.5 = 0.03125$
4. $t = 6$: $0.5^6 = 0.03125 \times 0.5 = 0.015625$ (아직 0.01보다 크다)
5. $t = 7$: $0.5^7 = 0.015625 \times 0.5 = 0.0078125$ (처음으로 0.01보다 작다)

**답**: $7$단계. 배율 $0.5$만 되어도 7단계 만에 기억이 1% 아래로 사라진다. 이것이 [RNN](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#rnn-recurrent-neural-network-%EC%88%9C%ED%99%98-%EC%8B%A0%EA%B2%BD%EB%A7%9D)이 오래된 입력을 잊는 이유다

</details>

### 문제 10

[Lec10 4.2](../../Lec10_%EA%B8%B0%EC%96%B5%EA%B3%BC_%EC%8B%9C%ED%80%80%EC%8A%A4.md#42-%EA%B3%B5%EC%9C%A0-%EA%B0%80%EC%A4%91%EC%B9%98%EC%9D%98-%EA%B8%B0%EC%9A%B8%EA%B8%B0%EB%8A%94-%EB%8D%94%ED%95%9C%EB%8B%A4)의 "공유 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)는 단계마다 더한다"를 확인한다. $w = 0.5$, $u = 1$, $h_0 = 2$, $x = (1, 3)$일 때 $\dfrac{\partial h_2}{\partial w} = \sum_{k=1}^{2} w^{2-k} h_{k-1}$를 구하고, $w$를 $0.51$로 살짝 바꿔 실제로 $h_2$가 얼마나 변하는지로 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $w = 0.5$, $u = 1$, $h_0 = 2$ (처음 기억)
- $x_1 = 1$, $x_2 = 3$ (입력)

**풀이**
1. 한 단계씩 기억을 구한다: $h_1 = 0.5 \times 2 + 1 \times 1 = 1 + 1 = 2$, $h_2 = 0.5 \times 2 + 1 \times 3 = 1 + 3 = 4$
2. [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) 식을 쓴다: $\dfrac{\partial h_2}{\partial w} = \sum_{k=1}^{2} w^{2-k}\, h_{k-1}$
3. 값을 대입해 $\sum$을 두 항으로 펼친다: $0.5^{1} \times h_0 + 0.5^{0} \times h_1$
4. 기억 값을 넣는다: $0.5^{1} \times 2 + 0.5^{0} \times 2$
5. 거듭제곱과 곱셈을 한다: $0.5 \times 2 = 1$, $1 \times 2 = 2$ 이므로 $1 + 2$
6. 덧셈을 한다: $\dfrac{\partial h_2}{\partial w} = 3$
7. $w = 0.51$로 다시 돌린다: $h_1 = 0.51 \times 2 + 1 = 2.02$, $h_2 = 0.51 \times 2.02 + 3 = 1.0302 + 3 = 4.0302$
8. 변화율을 구한다: $(4.0302 - 4) \div (0.51 - 0.5) = 0.0302 \div 0.01 = 3.02$

**답**: $\partial h_2 / \partial w = 3$이고 실제 변화율은 $3.02$로 거의 같다. 단계마다 $w$가 한 번씩 쓰이므로 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)는 두 단계 몫($1$과 $2$)의 합이다
