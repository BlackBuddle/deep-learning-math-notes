## 기본 (직접 대입)

### 문제 1

쿼리 $\mathbf{q} = (2, 1)$, 키 $\mathbf{k} = (1, 3)$, 쿼리·키 차원 $m = 2$일 때 점수 $\mathbf{q}\cdot\mathbf{k}$와 $\sqrt{m}$으로 나눈 점수를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{q} = (2, 1)$ (쿼리 벡터)
- $\mathbf{k} = (1, 3)$ (키 벡터)
- $m = 2$ (쿼리·키 차원)

**풀이**
1. 식을 그대로 쓴다: $\mathbf{q}\cdot\mathbf{k} = q_1 k_1 + q_2 k_2$, $s_{\text{scaled}} = \dfrac{\mathbf{q}\cdot\mathbf{k}}{\sqrt{m}}$
2. 값을 대입한다: $\mathbf{q}\cdot\mathbf{k} = 2 \times 1 + 1 \times 3$, $s_{\text{scaled}} = \dfrac{2 \times 1 + 1 \times 3}{\sqrt{2}}$
3. 곱셈을 먼저 한다: $2 \times 1 = 2$, $1 \times 3 = 3$ 이므로 $\mathbf{q}\cdot\mathbf{k} = 2 + 3$
4. 덧셈을 한다: $\mathbf{q}\cdot\mathbf{k} = 2 + 3 = 5$
5. $\sqrt{\ }$의 뜻: 제곱하면 그 수가 되는 양수다. 코드 `np.sqrt(2)`로 구하면 $\sqrt{2} = 1.4142$
6. 나눗셈을 한다: $s_{\text{scaled}} = 5 \div 1.4142 = 3.5355$

**답**: $\mathbf{q}\cdot\mathbf{k} = 5$, $s_{\text{scaled}} = 3.5355$

</details>

### 문제 2

두 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)에 대한 점수가 $(3, 1)$일 때 [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)로 [어텐션](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#attention-%EC%96%B4%ED%85%90%EC%85%98) [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{s} = (3, 1)$ (점수, 이미 $\sqrt{m}$으로 나눈 값이라고 본다)

**풀이**
1. 식을 그대로 쓴다: $a_j = \dfrac{e^{s_j}}{\sum_i e^{s_i}}$ (점수마다 $e^{s}$를 구해 합으로 나눈다. $e$는 약 2.7183인 수이고 코드 `np.exp`로 구한다)
2. 값을 대입한다: $\mathbf{a} = \Big(\dfrac{e^{3}}{e^{3} + e^{1}},\ \dfrac{e^{1}}{e^{3} + e^{1}}\Big)$
3. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^{3} = 20.0855$, $e^{1} = 2.7183$
4. 분모의 덧셈을 한다: $20.0855 + 2.7183 = 22.8038$ (반올림 전 값으로 더한다)
5. 나눗셈을 한다: $20.0855 \div 22.8038 = 0.8808$, $2.7183 \div 22.8038 = 0.1192$
6. 합을 확인한다: $0.8808 + 0.1192 = 1$

**답**: $\mathbf{a} = (0.8808, 0.1192)$. 점수가 2 큰 쪽이 약 7.4배($e^2$배) 많이 반영된다

</details>

### 문제 3

[어텐션](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#attention-%EC%96%B4%ED%85%90%EC%85%98) [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)가 $(0.8, 0.2)$이고 값 벡터가 $\mathbf{v}_1 = (1, 0)$, $\mathbf{v}_2 = (0, 5)$일 때 출력 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{a} = (0.8, 0.2)$ ([가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98), 합이 1)
- $\mathbf{v}_1 = (1, 0)$, $\mathbf{v}_2 = (0, 5)$ (값 벡터)

**풀이**
1. 식을 그대로 쓴다: $\mathbf{t}_{\text{out}} = a_1 \mathbf{v}_1 + a_2 \mathbf{v}_2$ ([가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)를 곱해 더하는 [가중합](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weighted-sum-%EA%B0%80%EC%A4%91%ED%95%A9))
2. 값을 대입한다: $\mathbf{t}_{\text{out}} = 0.8 \times (1, 0) + 0.2 \times (0, 5)$
3. 첫 칸을 펼친다 (같은 자리끼리 곱해 더한다): $0.8 \times 1 + 0.2 \times 0 = 0.8 + 0 = 0.8$
4. 둘째 칸을 펼친다: $0.8 \times 0 + 0.2 \times 5 = 0 + 1 = 1$

**답**: $\mathbf{t}_{\text{out}} = (0.8, 1)$

</details>

### 문제 4

쿼리 $\mathbf{q} = (2, 0)$, 키 $\mathbf{k}_1 = (1, 0)$, $\mathbf{k}_2 = (0, 1)$, 값 $\mathbf{v}_1 = (1, 0)$, $\mathbf{v}_2 = (0, 1)$, 차원 $m = 4$일 때 출력 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)을 구하라. (점수, $\sqrt{m}$으로 나누기, [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4), [가중합](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weighted-sum-%EA%B0%80%EC%A4%91%ED%95%A9) 순서)

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{q} = (2, 0)$ (쿼리)
- $\mathbf{k}_1 = (1, 0)$, $\mathbf{k}_2 = (0, 1)$ (키)
- $\mathbf{v}_1 = (1, 0)$, $\mathbf{v}_2 = (0, 1)$ (값)
- $m = 4$ (차원이므로 $\sqrt{m} = 2$, $2 \times 2 = 4$)

**풀이**
1. 식을 그대로 쓴다: $s_j = \dfrac{\mathbf{q}\cdot\mathbf{k}_j}{\sqrt{m}}$, $a = \text{softmax}(s)$, $\mathbf{t}_{\text{out}} = \sum_j a_j \mathbf{v}_j$
2. 점수에 대입한다: $\mathbf{s} = \Big(\dfrac{(2, 0)\cdot(1, 0)}{2},\ \dfrac{(2, 0)\cdot(0, 1)}{2}\Big)$
3. [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)을 펼친다: $(2, 0)\cdot(1, 0) = 2 \times 1 + 0 \times 0 = 2$, $(2, 0)\cdot(0, 1) = 2 \times 0 + 0 \times 1 = 0$
4. 나눗셈을 한다: $2 \div 2 = 1$, $0 \div 2 = 0$ 이므로 $\mathbf{s} = (1, 0)$
5. [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)에 대입한다: $\mathbf{a} = \Big(\dfrac{e^{1}}{e^{1} + e^{0}},\ \dfrac{e^{0}}{e^{1} + e^{0}}\Big)$ ($e^{0} = 1$, 0제곱은 1)
6. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^{1} = 2.7183$, 분모 $2.7183 + 1 = 3.7183$
7. 나눗셈을 한다: $2.7183 \div 3.7183 = 0.7311$, $1 \div 3.7183 = 0.2689$
8. [가중합](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weighted-sum-%EA%B0%80%EC%A4%91%ED%95%A9)에 대입한다: $\mathbf{t}_{\text{out}} = 0.7311 \times (1, 0) + 0.2689 \times (0, 1)$
9. 칸마다 펼친다: 첫 칸 $0.7311 \times 1 + 0.2689 \times 0 = 0.7311$, 둘째 칸 $0.7311 \times 0 + 0.2689 \times 1 = 0.2689$

**답**: $\mathbf{t}_{\text{out}} = (0.7311, 0.2689)$. 쿼리와 더 잘 맞는 첫 값이 더 많이 섞인다

</details>

### 문제 5

[토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)이 $n = 2000$개이고 $d = m = 32$인 [어텐션](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#attention-%EC%96%B4%ED%85%90%EC%85%98) [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)에서 [어텐션](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#attention-%EC%96%B4%ED%85%90%EC%85%98) 행렬 $A$를 직접 배울 때의 [파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0) 수와 $W_Q, W_K, W_V$를 배울 때의 [파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0) 수를 구하고 몇 배 차이인지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $n = 2000$ ([토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 수)
- $d = 32$ ([토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 벡터 차원)
- $m = 32$ (쿼리·키·값 차원)

**풀이**
1. 식을 그대로 쓴다: $\#A = n^2$, $\#(W_Q, W_K, W_V) = 3dm$
2. 값을 대입한다: $\#A = 2000^2$, $\#(W_Q, W_K, W_V) = 3 \times 32 \times 32$
3. 제곱(같은 수를 두 번 곱함)을 한다: $2000 \times 2000 = 4{,}000{,}000$
4. 앞의 곱셈을 한다: $3 \times 32 = 96$ 이므로 $96 \times 32$
5. 곱셈을 한다: $96 \times 32 = 3{,}072$
6. 나눗셈으로 비율을 구한다: $4{,}000{,}000 \div 3{,}072 = 1302.08$

**답**: 직접 배우면 $4{,}000{,}000$개, 사영 행렬로 배우면 $3{,}072$개로 약 $1302$배 차이이고, 사영 행렬의 수는 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 수와 무관하다

</details>

### 문제 6

[토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) $\mathbf{t}_1 = (1, 1)$, $\mathbf{t}_2 = (1, -1)$을 행으로 쌓은 $T$를 $W_Q = W_K = W_V = I_2$, $m = 2$인 [셀프 어텐션](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#self-attention-%EC%85%80%ED%94%84-%EC%96%B4%ED%85%90%EC%85%98)에 넣어 [어텐션](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#attention-%EC%96%B4%ED%85%90%EC%85%98) 행렬 $A$와 출력 $T_{\text{out}}$을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $T = \begin{pmatrix}1&1\\1&-1\end{pmatrix}$ ([토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)을 행으로 쌓은 행렬)
- $W_Q = W_K = W_V = I_2$ (단위행렬이므로 $Q = K = V = T$)
- $m = 2$ (쿼리·키 차원)

**풀이**
1. 식을 그대로 쓴다: $A = \text{softmax}\big(QK^\top/\sqrt{m}\big)$, $T_{\text{out}} = AV$
2. 값을 대입한다: $A = \text{softmax}\Big(\begin{pmatrix}1&1\\1&-1\end{pmatrix}\begin{pmatrix}1&1\\1&-1\end{pmatrix}^\top \Big/ \sqrt{2}\Big)$
3. [전치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#transpose-%EC%A0%84%EC%B9%98)(행과 열을 바꿈)를 한다: $K^\top = \begin{pmatrix}1&1\\1&-1\end{pmatrix}$ (이 행렬은 대칭이라 그대로다)
4. $QK^\top$의 (1,1)칸을 펼친다: $1 \times 1 + 1 \times 1 = 2$
5. (1,2)칸: $1 \times 1 + 1 \times (-1) = 1 - 1 = 0$
6. (2,1)칸: $1 \times 1 + (-1) \times 1 = 1 - 1 = 0$
7. (2,2)칸: $1 \times 1 + (-1) \times (-1) = 1 + 1 = 2$ 이므로 $QK^\top = \begin{pmatrix}2&0\\0&2\end{pmatrix}$
8. $\sqrt{2}$(제곱하면 2가 되는 양수, 1.4142)로 나눈다: $2 \div 1.4142 = 1.4142$ 이므로 점수 $\begin{pmatrix}1.4142&0\\0&1.4142\end{pmatrix}$
9. 1행 [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)에 대입한다: $\Big(\dfrac{e^{1.4142}}{e^{1.4142} + e^{0}},\ \dfrac{e^{0}}{e^{1.4142} + e^{0}}\Big)$
10. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^{1.4142} = 4.1133$, $e^{0} = 1$, 분모 $4.1133 + 1 = 5.1133$
11. 나눗셈을 한다: $4.1133 \div 5.1133 = 0.8044$, $1 \div 5.1133 = 0.1956$
12. 2행은 두 점수의 자리만 바뀐 꼴이라 $(0.1956, 0.8044)$ 이므로 $A = \begin{pmatrix}0.8044&0.1956\\0.1956&0.8044\end{pmatrix}$
13. $AV$의 1행을 펼친다: $0.8044 \times (1, 1) + 0.1956 \times (1, -1) = (0.8044 + 0.1956,\ 0.8044 - 0.1956) = (1, 0.6089)$ (반올림 전 값으로 계산)
14. $AV$의 2행을 펼친다: $0.1956 \times (1, 1) + 0.8044 \times (1, -1) = (0.1956 + 0.8044,\ 0.1956 - 0.8044) = (1, -0.6089)$

**답**: $A = \begin{pmatrix}0.8044&0.1956\\0.1956&0.8044\end{pmatrix}$, $T_{\text{out}} = \begin{pmatrix}1&0.6089\\1&-0.6089\end{pmatrix}$. 각 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)은 자기 자신을 약 80%의 비중으로 본다

</details>

### 문제 7

쿼리·키 차원이 $m = 16$이고 두 키에 대한 [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81) 점수가 $(8, 4)$일 때, $\sqrt{m}$으로 나누지 않은 [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)와 나눈 [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)를 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{s}_{\text{raw}} = (8, 4)$ (나누기 전 [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81) 점수)
- $m = 16$ (차원이므로 $\sqrt{16} = 4$, $4 \times 4 = 16$)

**풀이**
1. 식을 그대로 쓴다: $a_j = \dfrac{e^{s_j}}{\sum_i e^{s_i}}$ (나누지 않은 경우는 $s = s_{\text{raw}}$, 나눈 경우는 $s = s_{\text{raw}}/\sqrt{m}$)
2. 나누지 않은 경우에 대입한다: $\mathbf{a} = \Big(\dfrac{e^{8}}{e^{8} + e^{4}},\ \dfrac{e^{4}}{e^{8} + e^{4}}\Big)$
3. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^{8} = 2980.958$, $e^{4} = 54.5982$, 분모 $2980.958 + 54.5982 = 3035.556$
4. 나눗셈을 한다: $2980.958 \div 3035.556 = 0.9820$, $54.5982 \div 3035.556 = 0.0180$
5. 나눈 점수를 구한다: $8 \div 4 = 2$, $4 \div 4 = 1$ 이므로 $\mathbf{s} = (2, 1)$
6. 나눈 경우에 대입한다: $\mathbf{a} = \Big(\dfrac{e^{2}}{e^{2} + e^{1}},\ \dfrac{e^{1}}{e^{2} + e^{1}}\Big)$
7. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^{2} = 7.3891$, $e^{1} = 2.7183$, 분모 $7.3891 + 2.7183 = 10.1074$
8. 나눗셈을 한다: $7.3891 \div 10.1074 = 0.7311$, $2.7183 \div 10.1074 = 0.2689$

**답**: 나누지 않으면 $(0.9820, 0.0180)$으로 한 칸에 쏠리고, 나누면 $(0.7311, 0.2689)$로 두 번째 칸도 반영된다. 쏠리면 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 거의 0이 되어 [학습](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5)이 어렵다

</details>

### 문제 8

점수 $(1, 2)$, 여기에 같은 수 10을 더한 $(11, 12)$, 그리고 2를 곱한 $(2, 4)$에 [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)를 하라. 더하기와 곱하기 중 어느 쪽이 결과를 바꾸는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{s}_A = (1, 2)$ (원래 점수)
- $\mathbf{s}_B = (11, 12)$ (10을 더한 점수)
- $\mathbf{s}_C = (2, 4)$ (2를 곱한 점수)

**풀이**
1. 식을 그대로 쓴다: $a_j = \dfrac{e^{s_j}}{\sum_i e^{s_i}}$
2. $\mathbf{s}_A$에 대입한다: $\Big(\dfrac{e^{1}}{e^{1} + e^{2}},\ \dfrac{e^{2}}{e^{1} + e^{2}}\Big)$, [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)는 $e^{1} = 2.7183$, $e^{2} = 7.3891$ 이므로 분모 $10.1074$
3. 나눗셈을 한다: $2.7183 \div 10.1074 = 0.2689$, $7.3891 \div 10.1074 = 0.7311$
4. $\mathbf{s}_B$에 대입한다: $\Big(\dfrac{e^{11}}{e^{11} + e^{12}},\ \dfrac{e^{12}}{e^{11} + e^{12}}\Big)$, [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)는 $e^{11} = 59874.14$, $e^{12} = 162754.79$ 이므로 분모 $222628.93$
5. 나눗셈을 한다: $59874.14 \div 222628.93 = 0.2689$, $162754.79 \div 222628.93 = 0.7311$
6. 왜 같은지 본다: $e^{11} = e^{10} \times e^{1}$, $e^{12} = e^{10} \times e^{2}$ 처럼 모든 항에 $e^{10}$이 곱해져 분자와 분모에서 약분된다
7. $\mathbf{s}_C$에 대입한다: $\Big(\dfrac{e^{2}}{e^{2} + e^{4}},\ \dfrac{e^{4}}{e^{2} + e^{4}}\Big)$, [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)는 $e^{2} = 7.3891$, $e^{4} = 54.5982$ 이므로 분모 $61.9873$
8. 나눗셈을 한다: $7.3891 \div 61.9873 = 0.1192$, $54.5982 \div 61.9873 = 0.8808$

**답**: $\mathbf{s}_A$와 $\mathbf{s}_B$는 모두 $(0.2689, 0.7311)$로 같고, $\mathbf{s}_C$는 $(0.1192, 0.8808)$로 달라진다. 더한 수는 결과를 바꾸지 않고 곱한 수는 바꾸므로 $\sqrt{m}$으로 나누는 것이 의미가 있다

</details>

### 문제 9

[Lec08 5.3](../../Lec08_%ED%8A%B8%EB%9E%9C%EC%8A%A4%ED%8F%AC%EB%A8%B8.md#53-%EC%BF%BC%EB%A6%AC-%ED%82%A4-%EA%B0%92-%EC%96%B4%ED%85%90%EC%85%98)의 "임팔라 머리는 무슨 색인가?" 그림처럼, 질문 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)의 쿼리 $\mathbf{q} = (3, 0)$이고 이미지 패치 세 개의 키가 $(1, 0)$, $(0, 1)$, $(0.5, 0.5)$, 값이 $(1, 0)$, $(0, 1)$, $(1, 1)$이다. 스케일 없이 출력 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{q} = (3, 0)$ (질문 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)의 쿼리)
- $\mathbf{k}_1 = (1, 0)$, $\mathbf{k}_2 = (0, 1)$, $\mathbf{k}_3 = (0.5, 0.5)$ (패치 키)
- $\mathbf{v}_1 = (1, 0)$, $\mathbf{v}_2 = (0, 1)$, $\mathbf{v}_3 = (1, 1)$ (패치 값)

**풀이**
1. 식을 그대로 쓴다: $s_j = \mathbf{q}\cdot\mathbf{k}_j$, $a = \text{softmax}(s)$, $\mathbf{t}_{\text{out}} = \sum_j a_j \mathbf{v}_j$
2. 점수에 대입한다: $\mathbf{s} = \big((3, 0)\cdot(1, 0),\ (3, 0)\cdot(0, 1),\ (3, 0)\cdot(0.5, 0.5)\big)$
3. [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)을 펼친다: $3 \times 1 + 0 \times 0 = 3$, $3 \times 0 + 0 \times 1 = 0$, $3 \times 0.5 + 0 \times 0.5 = 1.5$ 이므로 $\mathbf{s} = (3, 0, 1.5)$
4. [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)에 대입한다: $\mathbf{a} = \Big(\dfrac{e^{3}}{e^{3} + e^{0} + e^{1.5}},\ \dfrac{e^{0}}{e^{3} + e^{0} + e^{1.5}},\ \dfrac{e^{1.5}}{e^{3} + e^{0} + e^{1.5}}\Big)$
5. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^{3} = 20.0855$, $e^{0} = 1$, $e^{1.5} = 4.4817$
6. 분모의 덧셈을 한다: $20.0855 + 1 + 4.4817 = 25.5672$ (반올림 전 값으로 더한다)
7. 나눗셈을 한다: $20.0855 \div 25.5672 = 0.7856$, $1 \div 25.5672 = 0.0391$, $4.4817 \div 25.5672 = 0.1753$
8. [가중합](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weighted-sum-%EA%B0%80%EC%A4%91%ED%95%A9)에 대입한다: $\mathbf{t}_{\text{out}} = 0.7856 \times (1, 0) + 0.0391 \times (0, 1) + 0.1753 \times (1, 1)$
9. 첫 칸을 펼친다: $0.7856 \times 1 + 0.0391 \times 0 + 0.1753 \times 1 = 0.7856 + 0 + 0.1753 = 0.9609$ (반올림 전 값으로 계산)
10. 둘째 칸을 펼친다: $0.7856 \times 0 + 0.0391 \times 1 + 0.1753 \times 1 = 0 + 0.0391 + 0.1753 = 0.2144$

**답**: $\mathbf{t}_{\text{out}} = (0.9609, 0.2144)$. 쿼리와 방향이 가장 맞는 첫 패치([가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) 0.7856)의 값이 가장 많이 섞였다

</details>

### 문제 10

[Lec08 5.5](../../Lec08_%ED%8A%B8%EB%9E%9C%EC%8A%A4%ED%8F%AC%EB%A8%B8.md#55-%EC%96%B4%ED%85%90%EC%85%98-%EC%8B%9D)의 [셀프 어텐션](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#self-attention-%EC%85%80%ED%94%84-%EC%96%B4%ED%85%90%EC%85%98) 식에 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) $\mathbf{t}_1 = (1, 0)$, $\mathbf{t}_2 = (0, 1)$, $W_Q = W_K = W_V = I_2$, $m = 2$를 넣어 [어텐션](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#attention-%EC%96%B4%ED%85%90%EC%85%98) 행렬 $A$와 출력 $T_{\text{out}}$을 구하고 각 행의 합이 1인지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $T = \begin{pmatrix}1&0\\0&1\end{pmatrix}$ ([토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)을 행으로 쌓은 행렬, 단위행렬)
- $W_Q = W_K = W_V = I_2$ (그대로 통과)
- $m = 2$ (쿼리·키 차원)

**풀이**
1. 식을 그대로 쓴다: $T_{\text{out}} = \text{softmax}\big(QK^\top/\sqrt{m}\big)\,V$
2. 값을 대입한다: $Q = K = V = T$ 이므로 $T_{\text{out}} = \text{softmax}\Big(T T^\top \Big/ \sqrt{2}\Big)\,T$
3. 단위행렬끼리 곱한다 (단위행렬은 곱해도 그대로): $TT^\top = \begin{pmatrix}1&0\\0&1\end{pmatrix}$
4. $\sqrt{2} = 1.4142$로 나눈다: $1 \div 1.4142 = 0.7071$, $0 \div 1.4142 = 0$ 이므로 점수 $\begin{pmatrix}0.7071&0\\0&0.7071\end{pmatrix}$
5. 1행 [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)에 대입한다: $\Big(\dfrac{e^{0.7071}}{e^{0.7071} + e^{0}},\ \dfrac{e^{0}}{e^{0.7071} + e^{0}}\Big)$
6. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^{0.7071} = 2.0281$, $e^{0} = 1$, 분모 $2.0281 + 1 = 3.0281$
7. 나눗셈을 한다: $2.0281 \div 3.0281 = 0.6698$, $1 \div 3.0281 = 0.3302$
8. 2행은 점수 자리만 바뀐 꼴이라 $(0.3302, 0.6698)$ 이므로 $A = \begin{pmatrix}0.6698&0.3302\\0.3302&0.6698\end{pmatrix}$
9. $AV$의 1행을 펼친다: $0.6698 \times (1, 0) + 0.3302 \times (0, 1) = (0.6698, 0.3302)$
10. $AV$의 2행을 펼친다: $0.3302 \times (1, 0) + 0.6698 \times (0, 1) = (0.3302, 0.6698)$
11. 행 합을 확인한다: $0.6698 + 0.3302 = 1$, $0.3302 + 0.6698 = 1$

**답**: $A = T_{\text{out}} = \begin{pmatrix}0.6698&0.3302\\0.3302&0.6698\end{pmatrix}$, 두 행의 합은 모두 1이다 ($V$가 단위행렬이라 출력이 $A$와 같다)

</details>
