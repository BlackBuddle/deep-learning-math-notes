# 예제: 수용 영역과 출력 크기

개념 노트: [MM16_수용_영역과_출력_크기](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/07_%EA%B5%AC%EC%A1%B0_%EC%95%84%ED%82%A4%ED%85%8D%EC%B2%98/MM16_%EC%88%98%EC%9A%A9_%EC%98%81%EC%97%AD%EA%B3%BC_%EC%B6%9C%EB%A0%A5_%ED%81%AC%EA%B8%B0.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

> [!NOTE]
> **쓰는 법**
> 풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 쓰는 식: $r_l = r_{l-1} + D_l(K_l - 1)\,j_{l-1}$, $j_l = j_{l-1}S_l$, $r_0 = j_0 = 1$ ([수용 영역](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#receptive-field-%EC%88%98%EC%9A%A9-%EC%98%81%EC%97%AD)), $N_{\text{out}} = \lfloor (N + 2P - D(K-1) - 1)/S \rfloor + 1$ (출력 크기). $\lfloor a \rfloor$는 소수 부분을 버리는 내림이다.

## 기본 (직접 대입)

### 문제 1
5×5 [필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0)([스트라이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#stride-%EC%8A%A4%ED%8A%B8%EB%9D%BC%EC%9D%B4%EB%93%9C) 1) 다음에 3×3 [필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0)([스트라이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#stride-%EC%8A%A4%ED%8A%B8%EB%9D%BC%EC%9D%B4%EB%93%9C) 1)를 쌓았다. 2층 출력 한 칸의 [수용 영역](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#receptive-field-%EC%88%98%EC%9A%A9-%EC%98%81%EC%97%AD) $r_2$는? (팽창은 모두 1)

<details><summary>풀이와 답</summary>

**주어진 값**
- 1층: $K_1 = 5,\ S_1 = 1,\ D_1 = 1$
- 2층: $K_2 = 3,\ S_2 = 1,\ D_2 = 1$
- $r_0 = 1,\ j_0 = 1$ (입력 자체)

**풀이**
1. 식을 그대로 쓴다: $r_l = r_{l-1} + D_l\,(K_l - 1)\,j_{l-1},\qquad j_l = j_{l-1}\,S_l$
2. 1층 값을 대입한다: $r_1 = 1 + 1\,(5 - 1)\,1,\qquad j_1 = 1 \times 1$
3. 괄호 안 뺄셈을 한다: 5 − 1 = 4 이므로 $r_1 = 1 + 1 \times 4 \times 1$
4. 곱셈과 덧셈을 한다: 1 × 4 × 1 = 4, 1 + 4 = 5 이므로 $r_1 = 5$, $j_1 = 1$
5. 2층 값을 대입한다: $r_2 = 5 + 1\,(3 - 1)\,1$
6. 괄호 안 뺄셈을 한다: 3 − 1 = 2 이므로 $r_2 = 5 + 1 \times 2 \times 1$
7. 곱셈과 덧셈을 한다: 1 × 2 × 1 = 2, 5 + 2 = 7

**답**: $r_2 = 7$칸

</details>

### 문제 2
입력 한 변 $N = 32$, 3×3 [필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0), [패딩](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#padding-%ED%8C%A8%EB%94%A9) $P = 1$, 팽창 $D = 1$일 때 [스트라이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#stride-%EC%8A%A4%ED%8A%B8%EB%9D%BC%EC%9D%B4%EB%93%9C) $S = 1$과 $S = 2$의 출력 크기를 각각 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $N = 32,\ K = 3,\ P = 1,\ D = 1$
- $S = 1$ 과 $S = 2$ 두 경우

**풀이**
1. 식을 그대로 쓴다: $N_{\text{out}} = \left\lfloor \frac{N + 2P - D(K-1) - 1}{S} \right\rfloor + 1$
2. 값을 대입한다 ($S = 1$): $N_{\text{out}} = \left\lfloor \frac{32 + 2 \times 1 - 1 \times (3-1) - 1}{1} \right\rfloor + 1$
3. 괄호 안 뺄셈과 곱셈을 한다: 3 − 1 = 2, 2 × 1 = 2, 1 × 2 = 2 이므로 $\left\lfloor \frac{32 + 2 - 2 - 1}{1} \right\rfloor + 1$
4. 분자를 계산한다: 32 + 2 = 34, 34 − 2 = 32, 32 − 1 = 31 이므로 $\lfloor 31 / 1 \rfloor + 1 = 31 + 1 = 32$
5. $S = 2$를 대입한다: $N_{\text{out}} = \left\lfloor \frac{31}{2} \right\rfloor + 1$ (분자는 위와 같이 31)
6. 나눗셈과 내림을 한다: 31 ÷ 2 = 15.5, ⌊15.5⌋ = 15 이므로 $15 + 1 = 16$

**답**: $S = 1$이면 32, $S = 2$이면 16 ([스트라이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#stride-%EC%8A%A4%ED%8A%B8%EB%9D%BC%EC%9D%B4%EB%93%9C) 2는 크기를 절반으로 줄인다)

</details>

### 문제 3
입력 한 변 $N = 28$에 5×5 [필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0)를 [패딩](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#padding-%ED%8C%A8%EB%94%A9) 없이($P = 0$), [스트라이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#stride-%EC%8A%A4%ED%8A%B8%EB%9D%BC%EC%9D%B4%EB%93%9C) 1, 팽창 1로 적용하면 출력 크기는?

<details><summary>풀이와 답</summary>

**주어진 값**
- $N = 28,\ K = 5,\ P = 0,\ S = 1,\ D = 1$

**풀이**
1. 식을 그대로 쓴다: $N_{\text{out}} = \left\lfloor \frac{N + 2P - D(K-1) - 1}{S} \right\rfloor + 1$
2. 값을 대입한다: $N_{\text{out}} = \left\lfloor \frac{28 + 2 \times 0 - 1 \times (5-1) - 1}{1} \right\rfloor + 1$
3. 괄호 안 뺄셈과 곱셈을 한다: 5 − 1 = 4, 2 × 0 = 0, 1 × 4 = 4 이므로 $\left\lfloor \frac{28 + 0 - 4 - 1}{1} \right\rfloor + 1$
4. 분자를 계산한다: 28 + 0 = 28, 28 − 4 = 24, 24 − 1 = 23 이므로 $\lfloor 23 / 1 \rfloor + 1$
5. 나눗셈과 덧셈을 한다: 23 ÷ 1 = 23, 23 + 1 = 24

**답**: $N_{\text{out}} = 24$ ([패딩](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#padding-%ED%8C%A8%EB%94%A9)이 없으면 $K - 1 = 4$칸 줄어든다)

</details>

### 문제 4
입력 $N = 10$에 3×3 [필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0), [패딩](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#padding-%ED%8C%A8%EB%94%A9) 0, [스트라이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#stride-%EC%8A%A4%ED%8A%B8%EB%9D%BC%EC%9D%B4%EB%93%9C) 3, 팽창 1을 쓰면 출력 크기는? 입력 끝에서 버려지는 칸이 있는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $N = 10,\ K = 3,\ P = 0,\ S = 3,\ D = 1$

**풀이**
1. 식을 그대로 쓴다: $N_{\text{out}} = \left\lfloor \frac{N + 2P - D(K-1) - 1}{S} \right\rfloor + 1$
2. 값을 대입한다: $N_{\text{out}} = \left\lfloor \frac{10 + 2 \times 0 - 1 \times (3-1) - 1}{3} \right\rfloor + 1$
3. 괄호 안 뺄셈과 곱셈을 한다: 3 − 1 = 2, 2 × 0 = 0, 1 × 2 = 2 이므로 $\left\lfloor \frac{10 + 0 - 2 - 1}{3} \right\rfloor + 1$
4. 분자를 계산한다: 10 + 0 = 10, 10 − 2 = 8, 8 − 1 = 7 이므로 $\lfloor 7 / 3 \rfloor + 1$
5. 나눗셈을 한다: 7 ÷ 3 ≈ 2.33 이므로 $\lfloor 2.33 \rfloor + 1$
6. 내림과 덧셈을 한다: ⌊2.33⌋ = 2, 2 + 1 = 3
7. 버려지는 칸을 확인한다: [필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0)가 칸 0~2, 3~5, 6~8을 보고 칸 9는 한 번도 보지 못한다 (나누어떨어지지 않으면 끝이 버려진다)

**답**: $N_{\text{out}} = 3$, 입력의 마지막 칸 1개가 버려진다

</details>

### 문제 5
3×3 [필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0), [스트라이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#stride-%EC%8A%A4%ED%8A%B8%EB%9D%BC%EC%9D%B4%EB%93%9C) 1을 3층 쌓되 팽창을 $D = 1, 2, 4$로 키운다. 층마다의 [수용 영역](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#receptive-field-%EC%88%98%EC%9A%A9-%EC%98%81%EC%97%AD) $r_1, r_2, r_3$을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $K = 3,\ S = 1$ (모든 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)), $D_1 = 1,\ D_2 = 2,\ D_3 = 4$
- $r_0 = 1,\ j_0 = 1$, [스트라이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#stride-%EC%8A%A4%ED%8A%B8%EB%9D%BC%EC%9D%B4%EB%93%9C)가 1이라 $j$는 계속 1

**풀이**
1. 식을 그대로 쓴다: $r_l = r_{l-1} + D_l\,(K_l - 1)\,j_{l-1}$
2. 1층 값을 대입한다: $r_1 = 1 + 1\,(3 - 1)\,1$
3. 계산한다: 3 − 1 = 2, 1 × 2 × 1 = 2, 1 + 2 = 3 이므로 $r_1 = 3$
4. 2층 값을 대입한다: $r_2 = 3 + 2\,(3 - 1)\,1$
5. 계산한다: 3 − 1 = 2, 2 × 2 × 1 = 4, 3 + 4 = 7 이므로 $r_2 = 7$
6. 3층 값을 대입한다: $r_3 = 7 + 4\,(3 - 1)\,1$
7. 계산한다: 3 − 1 = 2, 4 × 2 × 1 = 8, 7 + 8 = 15 이므로 $r_3 = 15$

**답**: $r_1 = 3,\ r_2 = 7,\ r_3 = 15$ (팽창을 두 배씩 키우면 [파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0)는 그대로 9개씩인데 [수용 영역](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#receptive-field-%EC%88%98%EC%9A%A9-%EC%98%81%EC%97%AD)이 거의 두 배씩 는다)

</details>

### 문제 6
3×3 [필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0), [스트라이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#stride-%EC%8A%A4%ED%8A%B8%EB%9D%BC%EC%9D%B4%EB%93%9C) 2, 팽창 1인 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)을 4개 쌓았다. [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)마다 $r_l$과 $j_l$을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $K = 3,\ S = 2,\ D = 1$ (모든 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5))
- $r_0 = 1,\ j_0 = 1$

**풀이**
1. 식을 그대로 쓴다: $r_l = r_{l-1} + D_l\,(K_l - 1)\,j_{l-1},\qquad j_l = j_{l-1}\,S_l$
2. 값을 대입하면 $D(K-1) = 1 \times (3 - 1) = 2$ 이므로 $r_l = r_{l-1} + 2\,j_{l-1},\qquad j_l = 2\,j_{l-1}$
3. 1층: $r_1 = 1 + 2 \times 1 = 3$, $j_1 = 2 \times 1 = 2$
4. 2층: $r_2 = 3 + 2 \times 2 = 7$, $j_2 = 2 \times 2 = 4$
5. 3층: $r_3 = 7 + 2 \times 4 = 15$, $j_3 = 2 \times 4 = 8$
6. 4층: $r_4 = 15 + 2 \times 8 = 31$, $j_4 = 2 \times 8 = 16$

**답**: $r = 3, 7, 15, 31$ 이고 $j = 2, 4, 8, 16$ (한 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)마다 거의 두 배)

</details>

### 문제 7
[수용 영역](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#receptive-field-%EC%88%98%EC%9A%A9-%EC%98%81%EC%97%AD) 9를 얻는 두 방법을 비교하라. (가) 9×9 [필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0) 1층, (나) 3×3 [필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0) 4층([스트라이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#stride-%EC%8A%A4%ED%8A%B8%EB%9D%BC%EC%9D%B4%EB%93%9C) 1). 입력·출력 [채널](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#channel-%EC%B1%84%EB%84%90)은 1개, [편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5)은 뺀다. [파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0) 수는 각각 몇 개인가?

<details><summary>풀이와 답</summary>

**주어진 값**
- (가) $K = 9$ 한 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5), (나) $K = 3$ 네 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5), [스트라이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#stride-%EC%8A%A4%ED%8A%B8%EB%9D%BC%EC%9D%B4%EB%93%9C) 1, 팽창 1
- 한 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)의 [파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0) 수 $= K \times K$ ([채널](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#channel-%EC%B1%84%EB%84%90) 1개)

**풀이**
1. 식을 그대로 쓴다: $r_l = r_{l-1} + D_l\,(K_l - 1)\,j_{l-1}$
2. (가)를 대입한다: $r_1 = 1 + 1\,(9 - 1)\,1 = 1 + 8 = 9$
3. ### 문제 8
입력 $N = 33$에 3×3 [필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0), [패딩](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#padding-%ED%8C%A8%EB%94%A9) $P = 2$, [스트라이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#stride-%EC%8A%A4%ED%8A%B8%EB%9D%BC%EC%9D%B4%EB%93%9C) $S = 2$, 팽창 $D = 2$를 쓰면 출력 크기는?

<details><summary>풀이와 답</summary>

**주어진 값**
- $N = 33,\ K = 3,\ P = 2,\ S = 2,\ D = 2$

**풀이**
1. 식을 그대로 쓴다: $N_{\text{out}} = \left\lfloor \frac{N + 2P - D(K-1) - 1}{S} \right\rfloor + 1$
2. 값을 대입한다: $N_{\text{out}} = \left\lfloor \frac{33 + 2 \times 2 - 2 \times (3-1) - 1}{2} \right\rfloor + 1$
3. 괄호 안 뺄셈을 한다: 3 − 1 = 2 이므로 $\left\lfloor \frac{33 + 2 \times 2 - 2 \times 2 - 1}{2} \right\rfloor + 1$
4. 곱셈을 한다: 2 × 2 = 4 ([패딩](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#padding-%ED%8C%A8%EB%94%A9) 쪽), 2 × 2 = 4 (팽창 쪽) 이므로 $\left\lfloor \frac{33 + 4 - 4 - 1}{2} \right\rfloor + 1$
5. 분자를 계산한다: 33 + 4 = 37, 37 − 4 = 33, 33 − 1 = 32 이므로 $\lfloor 32 / 2 \rfloor + 1$
6. 나눗셈과 덧셈을 한다: 32 ÷ 2 = 16, 16 + 1 = 17

**답**: $N_{\text{out}} = 17$

</details>

(나) 3×3 [필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0), [스트라이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#stride-%EC%8A%A4%ED%8A%B8%EB%9D%BC%EC%9D%B4%EB%93%9C) 2를 쌓을 때는?
