> **쓰는 법**
> 풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 쓰는 식: $d_v^{(k)} = \min\Big(d_v^{(k-1)},\ \min_{u \in \mathcal{N}(v)} \big(d_u^{(k-1)} + \text{cost}(u, v)\big)\Big)$. 처음에는 목표만 0이고 나머지는 ∞(아직 길을 모름, 무엇을 더해도 ∞)다. 반복마다 모든 노드를 지난 반복의 값으로 한꺼번에 갱신한다.

## 기본 (직접 대입)

### 문제 1
노드 T, X, Y가 T-X (비용 2), X-Y (비용 5)로 한 줄로 이어져 있다. 목표는 T다. 반복 1, 2, 3의 거리 추정값 $d_T, d_X, d_Y$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 엣지: T-X 비용 2, X-Y 비용 5 (방향 없음)
- $d^{(0)}$: $d_T = 0,\ d_X = \infty,\ d_Y = \infty$
- 이웃: $\mathcal{N}(X) = \{T, Y\}$, $\mathcal{N}(Y) = \{X\}$

**풀이**
1. 식을 그대로 쓴다: $d_v^{(k)} = \min\Big(d_v^{(k-1)},\ \min_{u \in \mathcal{N}(v)} \big(d_u^{(k-1)} + \text{cost}(u, v)\big)\Big)$
2. 반복 1, X: $d_X^{(1)} = \min\big(\infty,\ \min(d_T^{(0)} + 2,\ d_Y^{(0)} + 5)\big) = \min\big(\infty,\ \min(0 + 2,\ \infty + 5)\big)$
3. 더하고 고른다: 0 + 2 = 2, ∞ + 5 = ∞ 이므로 $\min(\infty, \min(2, \infty)) = 2$. 그래서 $d_X^{(1)} = 2$
4. 반복 1, Y: $d_Y^{(1)} = \min\big(\infty,\ d_X^{(0)} + 5\big) = \min(\infty,\ \infty + 5) = \infty$
5. 반복 2, Y (반복 1의 $d_X = 2$ 사용): $d_Y^{(2)} = \min\big(\infty,\ d_X^{(1)} + 5\big) = \min(\infty,\ 2 + 5)$
6. 더하고 고른다: 2 + 5 = 7 이므로 $\min(\infty, 7) = 7$. 그래서 $d_Y^{(2)} = 7$
7. 반복 2, X: $d_X^{(2)} = \min\big(2,\ \min(0 + 2,\ \infty + 5)\big) = \min(2, 2) = 2$ (그대로)
8. 반복 3: Y는 $\min(7,\ 2 + 5) = 7$, X는 $\min(2,\ \min(0 + 2,\ 7 + 5)) = 2$ (바뀐 것 없음)

**답**: 반복 1: $(d_T, d_X, d_Y) = (0, 2, \infty)$, 반복 2: $(0, 2, 7)$, 반복 3: $(0, 2, 7)$ (소식이 한 홉씩 퍼진다)

</details>

### 문제 2
노드 v의 지금 추정값이 $d_v = 5$이고 이웃 $u_1$은 $d = 2$ (엣지 비용 4), $u_2$는 $d = 4$ (비용 3), $u_3$는 $d = \infty$ (비용 1)이다. 한 번 갱신한 $d_v$는?

<details><summary>풀이와 답</summary>

**주어진 값**
- $d_v^{(k-1)} = 5$
- $d_{u_1} = 2,\ \text{cost}(u_1, v) = 4$; $d_{u_2} = 4,\ \text{cost}(u_2, v) = 3$; $d_{u_3} = \infty,\ \text{cost}(u_3, v) = 1$

**풀이**
1. 식을 그대로 쓴다: $d_v^{(k)} = \min\Big(d_v^{(k-1)},\ \min_{u} \big(d_u + \text{cost}(u, v)\big)\Big)$
2. 값을 대입한다: $d_v^{(k)} = \min\big(5,\ \min(2 + 4,\ 4 + 3,\ \infty + 1)\big)$
3. 더한다: 2 + 4 = 6, 4 + 3 = 7, ∞ + 1 = ∞ 이므로 $\min\big(5,\ \min(6, 7, \infty)\big)$
4. 안쪽 min을 고른다: 6, 7, ∞ 중 가장 작은 값은 6 이므로 $\min(5, 6)$
5. 바깥 min을 고른다: 5와 6 중 작은 값은 5

**답**: $d_v = 5$ (바뀌지 않는다. 이웃을 거치는 길 6, 7이 지금 값 5보다 길다)

</details>

### 문제 3
노드 v의 지금 추정값이 $d_v = 9$이고 이웃 $u_1$은 $d = 3$ (비용 2), $u_2$는 $d = 1$ (비용 7)이다. 한 번 갱신한 $d_v$는?

<details><summary>풀이와 답</summary>

**주어진 값**
- $d_v^{(k-1)} = 9$
- $d_{u_1} = 3,\ \text{cost}(u_1, v) = 2$; $d_{u_2} = 1,\ \text{cost}(u_2, v) = 7$

**풀이**
1. 식을 그대로 쓴다: $d_v^{(k)} = \min\Big(d_v^{(k-1)},\ \min_{u} \big(d_u + \text{cost}(u, v)\big)\Big)$
2. 값을 대입한다: $d_v^{(k)} = \min\big(9,\ \min(3 + 2,\ 1 + 7)\big)$
3. 더한다: 3 + 2 = 5, 1 + 7 = 8 이므로 $\min\big(9,\ \min(5, 8)\big)$
4. 안쪽 min을 고른다: min(5, 8) = 5 이므로 $\min(9, 5)$
5. 바깥 min을 고른다: 9와 5 중 작은 값은 5

**답**: $d_v = 5$ (이웃 $u_1$을 거치는 길이 가장 짧아 9에서 5로 줄었다)

</details>

### 문제 4
네 노드 T, P, Q, R이 T-P, P-Q, Q-R, R-T로 고리를 이루고 모든 비용이 1이다. 목표는 T. 거리가 모두 확정되려면 반복이 몇 번 필요한가? 반복마다 $(d_P, d_Q, d_R)$을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 엣지: T-P, P-Q, Q-R, R-T (각 비용 1)
- $d^{(0)}$: $d_T = 0$, 나머지 ∞
- 이웃: $\mathcal{N}(P) = \{T, Q\}$, $\mathcal{N}(Q) = \{P, R\}$, $\mathcal{N}(R) = \{Q, T\}$

**풀이**
1. 식을 그대로 쓴다: $d_v^{(k)} = \min\Big(d_v^{(k-1)},\ \min_{u} \big(d_u^{(k-1)} + 1\big)\Big)$
2. 반복 1, P: $\min\big(\infty,\ \min(0 + 1,\ \infty + 1)\big) = \min(\infty, 1) = 1$
3. 반복 1, R: 이웃이 Q(∞)와 T(0)이므로 $\min\big(\infty,\ \min(\infty + 1,\ 0 + 1)\big) = 1$
4. 반복 1, Q: 이웃 P, R이 모두 ∞였으므로 $\min\big(\infty,\ \min(\infty + 1,\ \infty + 1)\big) = \infty$
5. 반복 2, Q (반복 1의 $d_P = 1,\ d_R = 1$ 사용): $\min\big(\infty,\ \min(1 + 1,\ 1 + 1)\big) = \min(\infty, 2) = 2$
6. 반복 3: 모든 노드가 $\min$을 해도 바뀌지 않는다 (P는 min(1, ...) = 1, Q는 min(2, 1 + 1) = 2, R은 1)

**답**: 반복 1: $(d_P, d_Q, d_R) = (1, \infty, 1)$, 반복 2: $(1, 2, 1)$. 반복 2번이면 확정된다 (가장 먼 노드 Q까지 2홉).

</details>

### 문제 5
노드 T, A, B에서 엣지가 T-A (비용 5), T-B (비용 1), B-A (비용 2)이다. 목표는 T. 반복 1과 2의 $d_A, d_B$를 구하고, A에서 T로 직접 가는 길과 B를 거치는 길을 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 엣지: T-A 5, T-B 1, B-A 2
- $d^{(0)}$: $d_T = 0,\ d_A = \infty,\ d_B = \infty$
- 이웃: $\mathcal{N}(A) = \{T, B\}$, $\mathcal{N}(B) = \{T, A\}$

**풀이**
1. 식을 그대로 쓴다: $d_v^{(k)} = \min\Big(d_v^{(k-1)},\ \min_{u} \big(d_u^{(k-1)} + \text{cost}(u, v)\big)\Big)$
2. 반복 1, A: $\min\big(\infty,\ \min(d_T + 5,\ d_B + 2)\big) = \min\big(\infty,\ \min(0 + 5,\ \infty + 2)\big)$
3. 더하고 고른다: 0 + 5 = 5, ∞ + 2 = ∞ 이므로 $d_A^{(1)} = 5$
4. 반복 1, B: $\min\big(\infty,\ \min(d_T + 1,\ d_A + 2)\big) = \min\big(\infty,\ \min(0 + 1,\ \infty + 2)\big) = 1$
5. 반복 2, A (반복 1의 $d_B = 1$ 사용): $\min\big(5,\ \min(0 + 5,\ 1 + 2)\big)$
6. 더하고 고른다: 0 + 5 = 5, 1 + 2 = 3 이므로 $\min(5, \min(5, 3)) = 3$
7. 반복 2, B: $\min\big(1,\ \min(0 + 1,\ 5 + 2)\big) = \min(1, 1) = 1$

**답**: 반복 1: $(d_A, d_B) = (5, 1)$, 반복 2: $(3, 1)$. 직접 가는 길은 5, B를 거치는 길은 2 + 1 = 3이라 돌아가는 길이 더 짧다.

</details>

### 문제 6
노드 6개 T, N1, N2, N3, N4, N5가 한 줄(T-N1-N2-N3-N4-N5)로 이어져 있고 비용이 모두 1이다. 목표는 T. 반대쪽 끝 N5의 $d$가 처음으로 유한해지는 반복은 몇 번째이고 그 값은? 노드 수 $n$과 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 한 줄 그래프, 모든 비용 1, $n = 6$
- $d^{(0)}$: $d_T = 0$, 나머지 ∞

**풀이**
1. 식을 그대로 쓴다: $d_v^{(k)} = \min\Big(d_v^{(k-1)},\ \min_{u} \big(d_u^{(k-1)} + 1\big)\Big)$
2. 반복 1: N1만 이웃 T(0)를 가져 $d_{N1} = 0 + 1 = 1$. 나머지는 ∞
3. 반복 2: N2는 이웃 N1(1)에서 $1 + 1 = 2$
4. 반복 3: N3는 이웃 N2(2)에서 $2 + 1 = 3$
5. 반복 4: N4는 이웃 N3(3)에서 $3 + 1 = 4$
6. 반복 5: N5는 이웃 N4(4)에서 $4 + 1 = 5$
7. 비교한다: 반복 횟수의 상한은 $n - 1 = 6 - 1 = 5$

**답**: 5번째 반복에서 $d_{N5} = 5$. 한 반복에 한 홉씩 퍼지므로 한 줄 그래프는 상한 $n - 1$번이 꼭 필요하다.

</details>

### 문제 7
노드 T, X, Y, Z가 한 줄(T-X-Y-Z)로 이어지고 비용이 모두 1이다. (가) 모든 노드를 지난 반복의 값으로 한꺼번에 갱신할 때 반복 1, 2 뒤의 $(d_X, d_Y, d_Z)$를 구하라. (나) X, Y, Z 순서로 갱신하면서 방금 바뀐 값을 바로 쓰면 반복 1 뒤에는 어떻게 되는가? 어느 쪽이 [GNN](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gnn-graph-neural-network-%EA%B7%B8%EB%9E%98%ED%94%84-%EC%8B%A0%EA%B2%BD%EB%A7%9D) 한 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)과 같은가?

<details><summary>풀이와 답</summary>

**주어진 값**
- 한 줄 그래프, 모든 비용 1, $d^{(0)}$: $d_T = 0$, 나머지 ∞
- 이웃: $\mathcal{N}(X) = \{T, Y\}$, $\mathcal{N}(Y) = \{X, Z\}$, $\mathcal{N}(Z) = \{Y\}$

**풀이**
1. 식을 그대로 쓴다: $d_v \leftarrow \min\big(d_v,\ \min_u (d_u + 1)\big)$
2. (가) 반복 1: X는 $\min(\infty,\ \min(0 + 1,\ \infty + 1)) = 1$, Y는 이웃 X, Z가 ∞였으므로 ∞, Z도 ∞ 이므로 $(1, \infty, \infty)$
3. (가) 반복 2: Y는 $\min(\infty,\ \min(1 + 1,\ \infty + 1)) = 2$, Z는 이웃 Y가 ∞였으므로 ∞ 이므로 $(1, 2, \infty)$
4. (나) 순서대로 갱신한다: X는 $\min(\infty,\ \min(0 + 1,\ \infty + 1)) = 1$
5. 바뀐 $d_X = 1$을 바로 써서 Y를 갱신한다: $\min(\infty,\ \min(1 + 1,\ \infty + 1)) = 2$
6. 바뀐 $d_Y = 2$를 바로 써서 Z를 갱신한다: $\min(\infty,\ 2 + 1) = 3$

**답**: (가) 반복 1은 $(1, \infty, \infty)$, 반복 2는 $(1, 2, \infty)$. (나) 반복 1만으로 $(1, 2, 3)$. [GNN](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gnn-graph-neural-network-%EA%B7%B8%EB%9E%98%ED%94%84-%EC%8B%A0%EA%B2%BD%EB%A7%9D) 한 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)은 (가)처럼 모든 노드를 이전 값으로 한꺼번에 갱신하므로 한 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)에 한 홉씩만 퍼진다. (나)는 빨리 끝나지만 층별 계산과 맞지 않는다.

</details>

### 문제 8
본문의 그래프(엣지: S-A 1, S-B 4, A-B 2, A-C 5, B-C 1, C-T 3, B-T 6)에서 수렴한 거리는 $d_S = 7,\ d_A = 6,\ d_B = 4,\ d_C = 3,\ d_T = 0$이다. S에서 T까지 가는 최단 경로를 복원하라. (각 노드에서 $d_u + \text{cost}(u, v) = d_v$ 가 되는 이웃 u가 다음 노드)

<details><summary>풀이와 답</summary>

**주어진 값**
- 수렴한 $d$: S 7, A 6, B 4, C 3, T 0
- 규칙: v의 다음 노드는 $d_u + \text{cost}(u, v) = d_v$ 인 이웃 u

**풀이**
1. S의 이웃은 A와 B. $d_A + \text{cost}(A, S) = 6 + 1 = 7 = d_S$ 이므로 A가 다음 노드 (B는 $4 + 4 = 8 \ne 7$)
2. A의 이웃은 S, B, C. $d_B + \text{cost}(B, A) = 4 + 2 = 6 = d_A$ 이므로 B가 다음 노드 (C는 $3 + 5 = 8 \ne 6$)
3. B의 이웃은 S, A, C, T. $d_C + \text{cost}(C, B) = 3 + 1 = 4 = d_B$ 이므로 C가 다음 노드 (T는 $0 + 6 = 6 \ne 4$)
4. C의 이웃은 A, B, T. $d_T + \text{cost}(T, C) = 0 + 3 = 3 = d_C$ 이므로 T가 다음 노드
5. 경로의 길이를 더한다: S-A 1, A-B 2, B-C 1, C-T 3 이므로 1 + 2 + 1 + 3 = 7

**답**: S → A → B → C → T, 총 길이 7 ($d_S = 7$과 같다)

</details>

### 문제 9
[Lec05 6.3](../../Lec05_%EA%B7%B8%EB%9E%98%ED%94%84_%EC%8B%A0%EA%B2%BD%EB%A7%9D.md#63-%EC%B5%9C%EC%86%8C-%EC%A7%91%EA%B3%84%EB%A1%9C-%EC%B5%9C%EB%8B%A8-%EA%B2%BD%EB%A1%9C-%ED%92%80%EA%B8%B0)은 벨만-포드를 [GNN](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gnn-graph-neural-network-%EA%B7%B8%EB%9E%98%ED%94%84-%EC%8B%A0%EA%B2%BD%EB%A7%9D) 한 [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)으로 본다. 본문 그래프에서 반복 2 뒤의 값이 $d_S = 10,\ d_A = 8,\ d_B = 4,\ d_C = 3,\ d_T = 0$일 때, 반복 3의 $d_A$를 구하라. 어느 부분이 메시지, 집계, 갱신인가?

<details><summary>풀이와 답</summary>

**주어진 값**
- 지난 반복 값: $d_S = 10,\ d_B = 4,\ d_C = 3,\ d_A^{(2)} = 8$
- $\mathcal{N}(A) = \{S, B, C\}$, $\text{cost}(S, A) = 1,\ \text{cost}(B, A) = 2,\ \text{cost}(C, A) = 5$

**풀이**
1. 식을 그대로 쓴다: $d_v^{(k)} = \min\Big(d_v^{(k-1)},\ \min_{u \in \mathcal{N}(v)} \big(d_u^{(k-1)} + \text{cost}(u, v)\big)\Big)$
2. 값을 대입한다: $d_A^{(3)} = \min\big(8,\ \min(10 + 1,\ 4 + 2,\ 3 + 5)\big)$
3. 메시지를 더한다: 10 + 1 = 11, 4 + 2 = 6, 3 + 5 = 8 이므로 $\min\big(8,\ \min(11, 6, 8)\big)$
4. 안쪽 min(집계)을 고른다: 11, 6, 8 중 가장 작은 값은 6 이므로 $\min(8, 6)$
5. 바깥 min(갱신)을 고른다: 8과 6 중 작은 값은 6

**답**: $d_A^{(3)} = 6$. 메시지는 $d_u + \text{cost}(u, v)$ (11, 6, 8), 집계는 안쪽 $\min$, 갱신은 자기 값 8과 비교하는 바깥 $\min$이다.

</details>

### 문제 10
같은 6.3절의 이야기: 최단 거리를 구하는 집계로 왜 합이나 평균이 아니라 min이어야 하는가? 어떤 노드가 이웃 두 곳에서 메시지 4와 6을 받았을 때 min, 합, 평균, 최댓값을 구하고 어느 것이 "그 노드에서 목표까지의 최단 거리"인지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 메시지 $\{4, 6\}$ (이웃 u를 거쳐 갈 때의 거리 $d_u + \text{cost}(u, v)$)
- 최단 거리 = 여러 길 중 가장 짧은 길의 길이

**풀이**
1. min: $\min(4, 6) = 4$
2. 합: 4 + 6 = 10
3. 평균: $\frac{1}{2}(4 + 6) = \frac{1}{2} \times 10 = 5$
4. 최댓값: $\max(4, 6) = 6$
5. 비교한다: 길이 4인 길과 길이 6인 길이 있으니 가장 짧은 길은 4

**답**: min = 4만 최단 거리다. 합 10, 평균 5, 최댓값 6은 실제로 존재하는 어떤 길의 길이도 가장 짧은 값도 아니다. 알고리즘의 모양에 맞는 집계를 골라야 [GNN](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gnn-graph-neural-network-%EA%B7%B8%EB%9E%98%ED%94%84-%EC%8B%A0%EA%B2%BD%EB%A7%9D)이 그 알고리즘을 흉내 낼 수 있다.
