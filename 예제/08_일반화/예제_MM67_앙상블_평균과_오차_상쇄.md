# 예제: 앙상블 평균과 오차 상쇄

개념 노트: [MM67_앙상블_평균과_오차_상쇄](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/08_%EC%9D%BC%EB%B0%98%ED%99%94/MM67_%EC%95%99%EC%83%81%EB%B8%94_%ED%8F%89%EA%B7%A0%EA%B3%BC_%EC%98%A4%EC%B0%A8_%EC%83%81%EC%87%84.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 쓰는 식은 셋이다. 평균 [앙상블](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#ensemble-%EC%95%99%EC%83%81%EB%B8%94) $\bar p = \dfrac{1}{M}\sum_m p_m$, [평균 오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#average-error-%ED%8F%89%EA%B7%A0-%EC%98%A4%EC%B0%A8)의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $\operatorname{Var}(\bar\varepsilon) = \rho\sigma^2 + \dfrac{(1-\rho)\sigma^2}{M}$ ($\rho$는 모델 오차끼리의 상관, 0이면 서로 [독립](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#independence-%EB%8F%85%EB%A6%BD)), 다수결 [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84) $P = \sum_{k > M/2} \binom{M}{k} p^k (1-p)^{M-k}$ ($\binom{M}{k}$는 $M$개 중 $k$개를 고르는 경우의 수).

## 기본 (직접 대입)

### 문제 1

네 모델이 같은 사진에 "고양이일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)"을 $0.6$, $0.8$, $0.4$, $0.8$로 냈다. 평균 [앙상블](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#ensemble-%EC%95%99%EC%83%81%EB%B8%94)의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $M = 4$ (모델 수)
- $p_1 = 0.6$, $p_2 = 0.8$, $p_3 = 0.4$, $p_4 = 0.8$ (각 모델의 고양이 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))

**풀이**
1. 식을 그대로 쓴다: $\bar p = \dfrac{1}{M}\sum_{m=1}^{M} p_m$
2. 값을 대입한다: $\bar p = \dfrac{1}{4}\sum_{m=1}^{4} p_m$
3. Σ를 풀어 쓴다: $\bar p = \dfrac{1}{4}(0.6 + 0.8 + 0.4 + 0.8)$
4. 앞의 둘을 더한다: $0.6 + 0.8 = 1.4$ 이므로 $\bar p = \dfrac{1}{4}(1.4 + 0.4 + 0.8)$
5. 나머지를 더한다: $1.4 + 0.4 = 1.8$, $1.8 + 0.8 = 2.6$ 이므로 $\bar p = \dfrac{2.6}{4}$
6. 나눈다: $2.6 / 4 = 0.65$

**답**: $\bar p = 0.65$.

</details>

### 문제 2

세 모델이 세 범주에 낸 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 $(0.7, 0.2, 0.1)$, $(0.3, 0.5, 0.2)$, $(0.5, 0.3, 0.2)$이다. 평균 [앙상블](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#ensemble-%EC%95%99%EC%83%81%EB%B8%94)의 분포를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $M = 3$ (모델 수)
- $p_1 = (0.7, 0.2, 0.1)$, $p_2 = (0.3, 0.5, 0.2)$, $p_3 = (0.5, 0.3, 0.2)$ (모델별 분포)

**풀이**
1. 식을 그대로 쓴다: $\bar p = \dfrac{1}{M}\sum_{m=1}^{M} p_m$ (칸마다 따로 평균한다)
2. 값을 대입한다: $\bar p = \dfrac{1}{3}\big[(0.7, 0.2, 0.1) + (0.3, 0.5, 0.2) + (0.5, 0.3, 0.2)\big]$
3. 첫째 칸을 더한다: $0.7 + 0.3 + 0.5 = 1.5$
4. 둘째 칸을 더한다: $0.2 + 0.5 + 0.3 = 1.0$
5. 셋째 칸을 더한다: $0.1 + 0.2 + 0.2 = 0.5$ 이므로 합은 $(1.5, 1.0, 0.5)$
6. 3으로 나눈다: $1.5 / 3 = 0.5$, $1.0 / 3 = 0.3333$, $0.5 / 3 = 0.1667$

**답**: $\bar p = (0.5, 0.3333, 0.1667)$. 합은 $0.5 + 0.3333 + 0.1667 = 1$로 평균도 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 분포다.

</details>

### 문제 3

[오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)이 $\sigma^2 = 2$인 모델 4개를 평균한다. [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)가 서로 [독립](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#independence-%EB%8F%85%EB%A6%BD)($\rho = 0$)일 때 [평균 오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#average-error-%ED%8F%89%EA%B7%A0-%EC%98%A4%EC%B0%A8)의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\sigma^2 = 2$ (모델 하나의 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0))
- $M = 4$ (모델 수)
- $\rho = 0$ ([오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)의 상관)

**풀이**
1. 식을 그대로 쓴다: $\operatorname{Var}(\bar\varepsilon) = \rho\,\sigma^2 + \dfrac{(1 - \rho)\,\sigma^2}{M}$
2. 값을 대입한다: $\operatorname{Var} = 0 \times 2 + \dfrac{(1 - 0) \times 2}{4}$
3. 곱셈을 한다: $0 \times 2 = 0$, $(1 - 0) \times 2 = 2$ 이므로 $\operatorname{Var} = 0 + \dfrac{2}{4}$
4. 나눈다: $2 / 4 = 0.5$
5. 더한다: $0 + 0.5 = 0.5$

**답**: $0.5$. [독립](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#independence-%EB%8F%85%EB%A6%BD)이면 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)이 $\sigma^2 / M = 2/4$로 모델 수만큼 나뉜다.

</details>

### 문제 4

[오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)이 $\sigma^2 = 1$인 모델 5개를 평균하고 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)의 상관이 $\rho = 0.2$일 때 [평균 오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#average-error-%ED%8F%89%EA%B7%A0-%EC%98%A4%EC%B0%A8)의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\sigma^2 = 1$, $M = 5$, $\rho = 0.2$

**풀이**
1. 식을 그대로 쓴다: $\operatorname{Var}(\bar\varepsilon) = \rho\,\sigma^2 + \dfrac{(1 - \rho)\,\sigma^2}{M}$
2. 값을 대입한다: $\operatorname{Var} = 0.2 \times 1 + \dfrac{(1 - 0.2) \times 1}{5}$
3. 곱셈과 괄호를 계산한다: $0.2 \times 1 = 0.2$, $1 - 0.2 = 0.8$ 이므로 $\operatorname{Var} = 0.2 + \dfrac{0.8}{5}$
4. 나눈다: $0.8 / 5 = 0.16$ 이므로 $\operatorname{Var} = 0.2 + 0.16$
5. 더한다: $0.2 + 0.16 = 0.36$

**답**: $0.36$. 독립일 때의 $1/5 = 0.2$보다 크다. 공유된 몫 $\rho\sigma^2 = 0.2$는 평균으로 줄지 않는다.

</details>

### 문제 5

$\sigma^2 = 2$, $\rho = 0.3$인 모델을 $M = 10$개 평균하면 [평균 오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#average-error-%ED%8F%89%EA%B7%A0-%EC%98%A4%EC%B0%A8)의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)은? 모델을 무한히 늘리면 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)은 어디까지 내려가는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $\sigma^2 = 2$, $\rho = 0.3$, $M = 10$ (그리고 $M \to \infty$)

**풀이**
1. 식을 그대로 쓴다: $\operatorname{Var}(\bar\varepsilon) = \rho\,\sigma^2 + \dfrac{(1 - \rho)\,\sigma^2}{M}$
2. 값을 대입한다: $\operatorname{Var} = 0.3 \times 2 + \dfrac{(1 - 0.3) \times 2}{10}$
3. 곱셈과 괄호를 계산한다: $0.3 \times 2 = 0.6$, $(1 - 0.3) \times 2 = 0.7 \times 2 = 1.4$ 이므로 $\operatorname{Var} = 0.6 + \dfrac{1.4}{10}$
4. 나눈다: $1.4 / 10 = 0.14$ 이므로 $\operatorname{Var} = 0.6 + 0.14$
5. 더한다: $0.6 + 0.14 = 0.74$
6. $M \to \infty$를 본다: $\dfrac{(1 - \rho)\sigma^2}{M}$은 분모가 한없이 커져 $0$에 가까워지므로 $\operatorname{Var} \to \rho\sigma^2 = 0.3 \times 2 = 0.6$

**답**: $M = 10$에서 $0.74$, 아무리 늘려도 $0.6$ 밑으로는 내려가지 않는다. 한 모델의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) 2에 비하면 70% 줄지만 그 이상은 상관 때문에 막힌다.

</details>

### 문제 6

각각 $60\%$ [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)로 맞히는 [독립](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#independence-%EB%8F%85%EB%A6%BD) 모델 3개가 다수결로 답한다. 다수결이 맞힐 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구하라.

<details><summary>풀이와 답</summary>

모델이 [독립](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#independence-%EB%8F%85%EB%A6%BD)이고 맞힐 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 같으므로 이항 분포로 센다. 과반은 $k = 2, 3$이다.

**주어진 값**
- $p = 0.6$ (모델 하나의 [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84)), $M = 3$ (모델 수)

**풀이**
1. 식을 그대로 쓴다: $P = \sum_{k > M/2} \binom{M}{k}\, p^{k} (1 - p)^{M - k}$
2. 값을 대입한다 ($k > 1.5$이므로 $k = 2, 3$): $P = \binom{3}{2}\, 0.6^{2} \times 0.4^{1} + \binom{3}{3}\, 0.6^{3} \times 0.4^{0}$
3. 경우의 수를 센다: $\binom{3}{2} = 3$ (셋 중 맞힌 둘을 고르는 방법), $\binom{3}{3} = 1$
4. 거듭제곱을 계산한다: $0.6^2 = 0.36$, $0.6^3 = 0.216$, $0.4^0 = 1$
5. 첫 항을 곱한다: $3 \times 0.36 \times 0.4 = 0.432$
6. 둘째 항을 곱한다: $1 \times 0.216 \times 1 = 0.216$
7. 더한다: $0.432 + 0.216 = 0.648$

**답**: $0.648$ (64.8%). 모델 하나(60%)보다 높다.

</details>

### 문제 7

각각 $70\%$ [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)로 맞히는 [독립](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#independence-%EB%8F%85%EB%A6%BD) 모델 5개가 다수결로 답한다. 다수결이 맞힐 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구하라.

<details><summary>풀이와 답</summary>

다섯 중 과반은 $k = 3, 4, 5$이다.

**주어진 값**
- $p = 0.7$, $M = 5$

**풀이**
1. 식을 그대로 쓴다: $P = \sum_{k > M/2} \binom{M}{k}\, p^{k} (1 - p)^{M - k}$
2. 값을 대입한다 ($k > 2.5$이므로 $k = 3, 4, 5$): $P = \binom{5}{3}\, 0.7^{3} \times 0.3^{2} + \binom{5}{4}\, 0.7^{4} \times 0.3^{1} + \binom{5}{5}\, 0.7^{5} \times 0.3^{0}$
3. 경우의 수를 센다: $\binom{5}{3} = \dfrac{5 \times 4 \times 3}{3 \times 2 \times 1} = 10$, $\binom{5}{4} = 5$, $\binom{5}{5} = 1$
4. 거듭제곱을 계산한다: $0.7^3 = 0.343$, $0.7^4 = 0.2401$, $0.7^5 = 0.16807$, $0.3^2 = 0.09$
5. 첫 항을 곱한다: $10 \times 0.343 \times 0.09 = 0.3087$
6. 둘째 항을 곱한다: $5 \times 0.2401 \times 0.3 = 0.36015$
7. 셋째 항을 곱한다: $1 \times 0.16807 \times 1 = 0.16807$
8. 더한다: $0.3087 + 0.36015 + 0.16807 = 0.83692$

**답**: $0.8369$ (83.7%). 모델 3개일 때의 $0.784$보다 더 높다.

</details>

### 문제 8

각각 $40\%$ 확률로만 맞히는(찍기보다 못한) [독립](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#independence-%EB%8F%85%EB%A6%BD) 모델 3개가 다수결로 답하면 다수결이 맞힐 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)은 40%보다 높아지는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $p = 0.4$, $M = 3$

**풀이**
1. 식을 그대로 쓴다: $P = \sum_{k > M/2} \binom{M}{k}\, p^{k} (1 - p)^{M - k}$
2. 값을 대입한다 ($k = 2, 3$): $P = \binom{3}{2}\, 0.4^{2} \times 0.6^{1} + \binom{3}{3}\, 0.4^{3} \times 0.6^{0}$
3. 경우의 수를 센다: $\binom{3}{2} = 3$, $\binom{3}{3} = 1$
4. 거듭제곱을 계산한다: $0.4^2 = 0.16$, $0.4^3 = 0.064$
5. 첫 항을 곱한다: $3 \times 0.16 \times 0.6 = 0.288$
6. 둘째 항을 곱한다: $1 \times 0.064 \times 1 = 0.064$
7. 더한다: $0.288 + 0.064 = 0.352$
8. 비교한다: $0.352 < 0.4$

**답**: $0.352$로 오히려 낮아진다. 다수결이 이득을 주려면 모델 하나가 절반(50%)보다는 잘 맞혀야 한다.

</details>

### 문제 9

Lec18 5.3의 [앙상블](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#ensemble-%EC%95%99%EC%83%81%EB%B8%94) 증류다. 네 모델이 어떤 사진에 "고양이일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)"을 $0.9$, $0.7$, $0.6$, $0.8$로 냈다. (a) 학생이 따라갈 평균 [앙상블](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#ensemble-%EC%95%99%EC%83%81%EB%B8%94)의 분포(고양이, 고양이 아님)를 구하라. (b) 각 모델의 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)이 $0.04$이고 서로 [독립](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#independence-%EB%8F%85%EB%A6%BD)이면 [평균 오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#average-error-%ED%8F%89%EA%B7%A0-%EC%98%A4%EC%B0%A8)의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)은?

<details><summary>풀이와 답</summary>

(a)는 평균 [앙상블](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#ensemble-%EC%95%99%EC%83%81%EB%B8%94) 식, (b)는 $\rho = 0$일 때의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) 식을 쓴다.

**주어진 값**
- $M = 4$, $p = (0.9, 0.7, 0.6, 0.8)$ (모델별 고양이 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0))
- $\sigma^2 = 0.04$, $\rho = 0$ ([오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)과 상관)

**풀이**
1. 식을 그대로 쓴다: $\bar p = \dfrac{1}{M}\sum_{m=1}^{M} p_m$, $\operatorname{Var}(\bar\varepsilon) = \rho\sigma^2 + \dfrac{(1 - \rho)\sigma^2}{M}$
2. 값을 대입한다 (a): $\bar p = \dfrac{1}{4}(0.9 + 0.7 + 0.6 + 0.8)$
3. 더한다: $0.9 + 0.7 = 1.6$, $1.6 + 0.6 = 2.2$, $2.2 + 0.8 = 3.0$ 이므로 $\bar p = 3.0 / 4$
4. 나눈다: $3.0 / 4 = 0.75$, 그래서 "고양이 아님"은 $1 - 0.75 = 0.25$
5. 값을 대입한다 (b): $\operatorname{Var} = 0 \times 0.04 + \dfrac{(1 - 0) \times 0.04}{4}$
6. 곱셈과 나눗셈을 한다: $0 \times 0.04 = 0$, $(1 - 0) \times 0.04 = 0.04$, $0.04 / 4 = 0.01$
7. 더한다: $0 + 0.01 = 0.01$

**답**: (a) 교사 분포 $(0.75, 0.25)$, (b) $0.01$. 모델 하나의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $0.04$가 4분의 1로 줄어든다. 학생은 이 평균 분포 하나만 따라 배우면 되므로 모델 4개를 늘 돌릴 필요가 없다.

</details>

### 문제 10

Lec18 5.3에서 강사는 "모두가 틀리는 구석 사례는 [앙상블](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#ensemble-%EC%95%99%EC%83%81%EB%B8%94)로도 못 고친다"고 말한다. 이를 상관으로 읽자. $\sigma^2 = 1$, $M = 10$일 때 (a) [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)가 완전히 같은 경우 $\rho = 1$, (b) 거의 같은 경우 $\rho = 0.9$의 [평균 오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#average-error-%ED%8F%89%EA%B7%A0-%EC%98%A4%EC%B0%A8) [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\sigma^2 = 1$, $M = 10$
- $\rho = 1$ 또는 $\rho = 0.9$

**풀이**
1. 식을 그대로 쓴다: $\operatorname{Var}(\bar\varepsilon) = \rho\,\sigma^2 + \dfrac{(1 - \rho)\,\sigma^2}{M}$
2. (a)를 대입한다: $\operatorname{Var} = 1 \times 1 + \dfrac{(1 - 1) \times 1}{10}$
3. 계산한다: $1 \times 1 = 1$, $(1 - 1) \times 1 = 0$ 이므로 $\operatorname{Var} = 1 + 0 = 1$
4. (b)를 대입한다: $\operatorname{Var} = 0.9 \times 1 + \dfrac{(1 - 0.9) \times 1}{10}$
5. 곱셈과 괄호를 계산한다: $0.9 \times 1 = 0.9$, $1 - 0.9 = 0.1$ 이므로 $\operatorname{Var} = 0.9 + \dfrac{0.1}{10}$
6. 나눈다: $0.1 / 10 = 0.01$ 이므로 $\operatorname{Var} = 0.9 + 0.01$
7. 더한다: $0.9 + 0.01 = 0.91$

**답**: (a) $1$, (b) $0.91$. 모델 10개를 평균해도 한 모델의 [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) $1$이 거의 그대로 남는다. 모두 같은 데이터에서 같은 [편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5)을 배우면 [앙상블](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#ensemble-%EC%95%99%EC%83%81%EB%B8%94)도, [앙상블](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#ensemble-%EC%95%99%EC%83%81%EB%B8%94)을 증류한 학생도 그 몫은 고치지 못한다.

</details>
