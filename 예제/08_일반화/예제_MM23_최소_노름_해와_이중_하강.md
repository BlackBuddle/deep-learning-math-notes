# 예제: 최소 노름 해와 이중 하강

## 기본 (직접 대입)

### 문제 1

벡터 $\mathbf{w} = (3, 4)$의 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84) $\lVert \mathbf{w} \rVert$를 구하라. ([노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)은 벡터의 길이이고 $\lVert \mathbf{w} \rVert = \sqrt{w_1^2 + w_2^2}$ 이다.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $w_1 = 3$, $w_2 = 4$ (벡터의 두 칸)

**풀이**
1. 식을 그대로 쓴다: $\lVert \mathbf{w} \rVert = \sqrt{w_1^2 + w_2^2}$
2. 값을 대입한다: $\lVert \mathbf{w} \rVert = \sqrt{3^2 + 4^2}$
3. 제곱한다: $3^2 = 9$, $4^2 = 16$ 이므로 $\lVert \mathbf{w} \rVert = \sqrt{9 + 16}$
4. 더한다: $9 + 16 = 25$ 이므로 $\lVert \mathbf{w} \rVert = \sqrt{25}$
5. 제곱근을 구한다 ($\sqrt{25}$는 제곱하면 25가 되는 양수): $5 \times 5 = 25$ 이므로 $\lVert \mathbf{w} \rVert = 5$

**답**: $\lVert \mathbf{w} \rVert = 5$

</details>

### 문제 2

벡터 $\mathbf{w} = (1, 2, 2)$의 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $w_1 = 1$, $w_2 = 2$, $w_3 = 2$ (벡터의 세 칸)

**풀이**
1. 식을 그대로 쓴다: $\lVert \mathbf{w} \rVert = \sqrt{w_1^2 + w_2^2 + w_3^2}$
2. 값을 대입한다: $\lVert \mathbf{w} \rVert = \sqrt{1^2 + 2^2 + 2^2}$
3. 제곱한다: $1^2 = 1$, $2^2 = 4$, $2^2 = 4$ 이므로 $\lVert \mathbf{w} \rVert = \sqrt{1 + 4 + 4}$
4. 더한다: $1 + 4 + 4 = 9$ 이므로 $\lVert \mathbf{w} \rVert = \sqrt{9}$
5. 제곱근을 구한다: $3 \times 3 = 9$ 이므로 $\lVert \mathbf{w} \rVert = 3$

**답**: $\lVert \mathbf{w} \rVert = 3$

</details>

### 문제 3

식 $w_1 + w_2 = 4$를 만족하는 해가 무수히 많다. 그중 $(4, 0)$, $(3, 1)$, $(2, 2)$는 모두 식을 만족한다. 세 해의 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)을 구해 어느 것이 가장 짧은지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 후보 해 $(4, 0)$, $(3, 1)$, $(2, 2)$ (식 $w_1 + w_2 = 4$ 확인: $4 + 0$, $3 + 1$, $2 + 2$ 모두 4)
- [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84) 식 $\lVert \mathbf{w} \rVert = \sqrt{w_1^2 + w_2^2}$

**풀이**
1. 식을 그대로 쓴다: $\lVert \mathbf{w} \rVert = \sqrt{w_1^2 + w_2^2}$
2. 값을 대입한다: $\sqrt{4^2 + 0^2}$, $\sqrt{3^2 + 1^2}$, $\sqrt{2^2 + 2^2}$
3. 제곱한다: $4^2 = 16$, $0^2 = 0$ / $3^2 = 9$, $1^2 = 1$ / $2^2 = 4$, $2^2 = 4$ 이므로 $\sqrt{16 + 0}$, $\sqrt{9 + 1}$, $\sqrt{4 + 4}$
4. 더한다: $\sqrt{16}$, $\sqrt{10}$, $\sqrt{8}$
5. 제곱근을 구한다 (계산기): $\sqrt{16} = 4$, $\sqrt{10} = 3.1623$, $\sqrt{8} = 2.8284$
6. 크기를 비교한다: $2.8284 < 3.1623 < 4$

**답**: [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)은 순서대로 $4$, $3.1623$, $2.8284$. 가장 짧은 해는 $(2, 2)$ (두 칸이 짐을 똑같이 나눠 든 해)

</details>

### 문제 4

식 $3w_1 + 4w_2 = 25$를 만족하는 해 중 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)이 가장 작은 [최소 노름 해](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#minimum-norm-solution-%EC%B5%9C%EC%86%8C-%EB%85%B8%EB%A6%84-%ED%95%B4)와 그 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)을 구하라. (식이 하나(데이터 한 점)이면 $\mathbf{w}^\star = \dfrac{y}{\lVert \mathbf{a} \rVert^2}\,\mathbf{a}$ 이다. $\mathbf{a}$는 식의 계수 벡터.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{a} = (3, 4)$ (식의 계수)
- $y = 25$ ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5))

**풀이**
1. 식을 그대로 쓴다: $\mathbf{w}^\star = \dfrac{y}{\lVert \mathbf{a} \rVert^2}\,\mathbf{a}$, $\lVert \mathbf{a} \rVert^2 = a_1^2 + a_2^2$
2. 값을 대입한다: $\mathbf{w}^\star = \dfrac{25}{3^2 + 4^2}\,(3, 4)$
3. 길이의 제곱을 구한다: $3^2 = 9$, $4^2 = 16$, $9 + 16 = 25$ 이므로 $\mathbf{w}^\star = \dfrac{25}{25}\,(3, 4)$
4. 나눗셈을 한다: $25 \div 25 = 1$ 이므로 $\mathbf{w}^\star = 1 \times (3, 4)$
5. 칸마다 곱한다: $1 \times 3 = 3$, $1 \times 4 = 4$ 이므로 $\mathbf{w}^\star = (3, 4)$
6. 식을 확인한다: $3 \times 3 + 4 \times 4 = 9 + 16 = 25$
7. [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)을 구한다: $\sqrt{3^2 + 4^2} = \sqrt{9 + 16} = \sqrt{25} = 5$ (공식으로 $|y| / \lVert \mathbf{a} \rVert = 25 / 5 = 5$ 와 같다)

**답**: $\mathbf{w}^\star = (3, 4)$, [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84) $5$

</details>

### 문제 5

식 $w_1 + 2w_2 + 2w_3 = 6$ (특징 3개, 데이터 1개)의 [최소 노름 해](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#minimum-norm-solution-%EC%B5%9C%EC%86%8C-%EB%85%B8%EB%A6%84-%ED%95%B4)와 그 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\mathbf{a} = (1, 2, 2)$ (식의 계수)
- $y = 6$ ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5))

**풀이**
1. 식을 그대로 쓴다: $\mathbf{w}^\star = \dfrac{y}{\lVert \mathbf{a} \rVert^2}\,\mathbf{a}$
2. 값을 대입한다: $\mathbf{w}^\star = \dfrac{6}{1^2 + 2^2 + 2^2}\,(1, 2, 2)$
3. 길이의 제곱을 구한다: $1^2 = 1$, $2^2 = 4$, $2^2 = 4$, $1 + 4 + 4 = 9$ 이므로 $\mathbf{w}^\star = \dfrac{6}{9}\,(1, 2, 2)$
4. 약분한다: $6 \div 9 = \dfrac23$ 이므로 $\mathbf{w}^\star = \dfrac23\,(1, 2, 2)$
5. 칸마다 곱한다: $\frac23 \times 1 = \frac23$, $\frac23 \times 2 = \frac43$, $\frac23 \times 2 = \frac43$ 이므로 $\mathbf{w}^\star = (\frac23, \frac43, \frac43)$
6. 식을 확인한다: $\frac23 + 2 \times \frac43 + 2 \times \frac43 = \frac23 + \frac83 + \frac83 = \frac{18}{3} = 6$
7. [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)을 공식으로 구한다: $\lVert \mathbf{w}^\star \rVert = |y| / \lVert \mathbf{a} \rVert = 6 / \sqrt{9} = 6 / 3 = 2$

**답**: $\mathbf{w}^\star = (\frac23, \frac43, \frac43) = (0.6667, 1.3333, 1.3333)$, [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84) $2$

</details>

### 문제 6

[정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) $y = 6$을 특징 2개 $\mathbf{a} = (1, 1)$로 맞출 때와 특징 6개 $\mathbf{a} = (1, 1, 1, 1, 1, 1)$로 맞출 때 [최소 노름 해](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#minimum-norm-solution-%EC%B5%9C%EC%86%8C-%EB%85%B8%EB%A6%84-%ED%95%B4)의 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)을 각각 구하고 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $y = 6$ ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5))
- $\mathbf{a}_2 = (1, 1)$ (특징 2개), $\mathbf{a}_6 = (1, 1, 1, 1, 1, 1)$ (특징 6개)

**풀이**
1. 식을 그대로 쓴다: $\mathbf{w}^\star = \dfrac{y}{\lVert \mathbf{a} \rVert^2}\,\mathbf{a}$, [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)은 $\sqrt{\sum w_k^2}$
2. 특징 2개를 대입한다: $\mathbf{w}^\star = \dfrac{6}{1^2 + 1^2}\,(1, 1)$
3. 계산한다: $1 + 1 = 2$, $6 \div 2 = 3$ 이므로 $\mathbf{w}^\star = 3 \times (1, 1) = (3, 3)$
4. 특징 2개의 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84): $\sqrt{3^2 + 3^2} = \sqrt{9 + 9} = \sqrt{18} = 4.2426$ (계산기)
5. 특징 6개를 대입한다: $\mathbf{w}^\star = \dfrac{6}{1^2 + 1^2 + 1^2 + 1^2 + 1^2 + 1^2}\,(1, 1, 1, 1, 1, 1)$
6. 계산한다: 분모는 $1 + 1 + 1 + 1 + 1 + 1 = 6$, $6 \div 6 = 1$ 이므로 $\mathbf{w}^\star = (1, 1, 1, 1, 1, 1)$
7. 특징 6개의 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84): $\sqrt{1 + 1 + 1 + 1 + 1 + 1} = \sqrt{6} = 2.4495$ (계산기)
8. 비교한다: $2.4495 < 4.2426$

**답**: 특징 2개: $4.2426$, 특징 6개: $2.4495$. 같은 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)을 맞춰도 특징이 많을수록 짐을 나눠 들어 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)이 작아진다

</details>

### 문제 7

데이터 2개, 특징 3개일 때 $A = \begin{pmatrix}1&0&1\\0&1&1\end{pmatrix}$, $\mathbf{y} = (3, 0)$이다. [최소 노름 해](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#minimum-norm-solution-%EC%B5%9C%EC%86%8C-%EB%85%B8%EB%A6%84-%ED%95%B4) $\mathbf{w}^\star = A^\top (A A^\top)^{-1}\mathbf{y}$와 그 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $A = \begin{pmatrix}1&0&1\\0&1&1\end{pmatrix}$ (행 2개 = 데이터 2개, 열 3개 = 특징 3개)
- $A^\top = \begin{pmatrix}1&0\\0&1\\1&1\end{pmatrix}$ (A의 행과 열을 바꾼 것)
- $\mathbf{y} = (3, 0)$ (두 데이터의 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5))

**풀이**
1. 식을 그대로 쓴다: $\mathbf{w}^\star = A^\top (A A^\top)^{-1}\mathbf{y}$
2. 값을 대입한다: $\mathbf{w}^\star = \begin{pmatrix}1&0\\0&1\\1&1\end{pmatrix}\left(\begin{pmatrix}1&0&1\\0&1&1\end{pmatrix}\begin{pmatrix}1&0\\0&1\\1&1\end{pmatrix}\right)^{-1}\begin{pmatrix}3\\0\end{pmatrix}$
3. $AA^\top$를 칸마다 펼친다 (칸 (i, j) = A의 i행과 $A^\top$의 j열을 짝지어 곱해 더함): $AA^\top = \begin{pmatrix}1 \times 1 + 0 \times 0 + 1 \times 1 & 1 \times 0 + 0 \times 1 + 1 \times 1\\0 \times 1 + 1 \times 0 + 1 \times 1 & 0 \times 0 + 1 \times 1 + 1 \times 1\end{pmatrix}$
4. 곱셈을 한다: $AA^\top = \begin{pmatrix}1 + 0 + 1 & 0 + 0 + 1\\0 + 0 + 1 & 0 + 1 + 1\end{pmatrix}$
5. 더한다: $AA^\top = \begin{pmatrix}2&1\\1&2\end{pmatrix}$
6. 역행렬을 구한다 (2×2 행렬 $\begin{pmatrix}a&b\\c&d\end{pmatrix}$의 역행렬은 $\frac{1}{ad - bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}$): $\begin{pmatrix}2&1\\1&2\end{pmatrix}^{-1} = \frac{1}{2 \times 2 - 1 \times 1}\begin{pmatrix}2&-1\\-1&2\end{pmatrix}$
7. 분모를 계산한다: $2 \times 2 - 1 \times 1 = 4 - 1 = 3$ 이므로 역행렬은 $\frac{1}{3}\begin{pmatrix}2&-1\\-1&2\end{pmatrix}$
8. 역행렬과 $\mathbf{y}$의 곱을 행마다 펼친다: $\frac{1}{3}\begin{pmatrix}2 \times 3 + (-1) \times 0\\(-1) \times 3 + 2 \times 0\end{pmatrix}$
9. 곱셈을 한다: $\frac{1}{3}\begin{pmatrix}6 + 0\\-3 + 0\end{pmatrix} = \frac{1}{3}\begin{pmatrix}6\\-3\end{pmatrix}$
10. $\frac13$을 곱한다: $\begin{pmatrix}2\\-1\end{pmatrix}$ 이므로 $\mathbf{w}^\star = \begin{pmatrix}1&0\\0&1\\1&1\end{pmatrix}\begin{pmatrix}2\\-1\end{pmatrix}$
11. 마지막 [행렬 곱](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#matrix-multiplication-%ED%96%89%EB%A0%AC-%EA%B3%B1)을 행마다 펼친다: $\mathbf{w}^\star = \begin{pmatrix}1 \times 2 + 0 \times (-1)\\0 \times 2 + 1 \times (-1)\\1 \times 2 + 1 \times (-1)\end{pmatrix}$
12. 곱셈과 덧셈을 한다: $2 + 0 = 2$, $0 - 1 = -1$, $2 - 1 = 1$ 이므로 $\mathbf{w}^\star = (2, -1, 1)$
13. 확인한다: $A\mathbf{w}^\star = (1 \times 2 + 0 \times (-1) + 1 \times 1,\ 0 \times 2 + 1 \times (-1) + 1 \times 1) = (3, 0)$ 으로 $\mathbf{y}$와 같다
14. [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)을 구한다: $\sqrt{2^2 + (-1)^2 + 1^2} = \sqrt{4 + 1 + 1} = \sqrt{6} = 2.4495$ (계산기)

**답**: $\mathbf{w}^\star = (2, -1, 1)$, [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84) $\sqrt{6} = 2.4495$

</details>

### 문제 8

문제 7의 같은 $A$, $\mathbf{y} = (3, 0)$에서 $\mathbf{u} = (3, 0, 0)$도 식 $A\mathbf{u} = \mathbf{y}$를 만족하는지 확인하고, $\mathbf{u}$의 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)을 [최소 노름 해](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#minimum-norm-solution-%EC%B5%9C%EC%86%8C-%EB%85%B8%EB%A6%84-%ED%95%B4) $(2, -1, 1)$의 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84) $\sqrt{6} = 2.4495$와 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $A = \begin{pmatrix}1&0&1\\0&1&1\end{pmatrix}$, $\mathbf{y} = (3, 0)$
- $\mathbf{u} = (3, 0, 0)$ (후보 해)
- [최소 노름 해](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#minimum-norm-solution-%EC%B5%9C%EC%86%8C-%EB%85%B8%EB%A6%84-%ED%95%B4)의 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84) $2.4495$ (문제 7의 결과)

**풀이**
1. 식을 그대로 쓴다: $A\mathbf{u} = \begin{pmatrix}1&0&1\\0&1&1\end{pmatrix}\begin{pmatrix}3\\0\\0\end{pmatrix}$
2. 행마다 짝지어 곱한 것을 펼친다: $A\mathbf{u} = \begin{pmatrix}1 \times 3 + 0 \times 0 + 1 \times 0\\0 \times 3 + 1 \times 0 + 1 \times 0\end{pmatrix}$
3. 곱셈을 한다: $A\mathbf{u} = \begin{pmatrix}3 + 0 + 0\\0 + 0 + 0\end{pmatrix}$
4. 더한다: $A\mathbf{u} = \begin{pmatrix}3\\0\end{pmatrix} = \mathbf{y}$ 이므로 $\mathbf{u}$도 해다
5. [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)의 식에 대입한다: $\lVert \mathbf{u} \rVert = \sqrt{3^2 + 0^2 + 0^2}$
6. 제곱하고 더한다: $9 + 0 + 0 = 9$ 이므로 $\lVert \mathbf{u} \rVert = \sqrt{9} = 3$
7. 비교한다: $3 > 2.4495$

**답**: $\mathbf{u}$도 해이지만 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84) $3$이 [최소 노름 해](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#minimum-norm-solution-%EC%B5%9C%EC%86%8C-%EB%85%B8%EB%A6%84-%ED%95%B4)의 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84) $2.4495$보다 크다 ([최소 노름 해](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#minimum-norm-solution-%EC%B5%9C%EC%86%8C-%EB%85%B8%EB%A6%84-%ED%95%B4)가 가장 짧다)

</details>

### 문제 9

[Lec06 5.5](../../Lec06_%EC%9D%BC%EB%B0%98%ED%99%94_%EC%9D%B4%EB%A1%A0.md#55-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0-%EB%85%B8%EB%A6%84)는 특징이 많을수록 해의 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)이 작아진다고 말한다. [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) $y = 5$를 특징 $\mathbf{a} = (1, 2)$, $(1, 2, 2)$, $(1, 2, 2, 4)$로 각각 맞출 때 [최소 노름 해](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#minimum-norm-solution-%EC%B5%9C%EC%86%8C-%EB%85%B8%EB%A6%84-%ED%95%B4)의 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84) $\lVert \mathbf{w}^\star \rVert = |y| / \lVert \mathbf{a} \rVert$를 구해 줄어드는지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $y = 5$ ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5))
- $\mathbf{a} = (1, 2)$, $(1, 2, 2)$, $(1, 2, 2, 4)$ (특징 값)
- $\sqrt{5} = 2.2361$ (계산기 값)

**풀이**
1. 식을 그대로 쓴다: $\lVert \mathbf{w}^\star \rVert = \dfrac{|y|}{\lVert \mathbf{a} \rVert}$, $\lVert \mathbf{a} \rVert = \sqrt{\sum a_k^2}$
2. 값을 대입한다: $\dfrac{5}{\sqrt{1^2 + 2^2}}$, $\dfrac{5}{\sqrt{1^2 + 2^2 + 2^2}}$, $\dfrac{5}{\sqrt{1^2 + 2^2 + 2^2 + 4^2}}$
3. 제곱한다: $\dfrac{5}{\sqrt{1 + 4}}$, $\dfrac{5}{\sqrt{1 + 4 + 4}}$, $\dfrac{5}{\sqrt{1 + 4 + 4 + 16}}$
4. 더한다: $\dfrac{5}{\sqrt{5}}$, $\dfrac{5}{\sqrt{9}}$, $\dfrac{5}{\sqrt{25}}$
5. 제곱근을 구한다: $\sqrt{5} = 2.2361$, $\sqrt{9} = 3$, $\sqrt{25} = 5$ 이므로 $\dfrac{5}{2.2361}$, $\dfrac{5}{3}$, $\dfrac{5}{5}$
6. 나눗셈을 한다: $5 \div 2.2361 = 2.2361$, $5 \div 3 = 1.6667$, $5 \div 5 = 1$

**답**: [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)은 $2.2361 \to 1.6667 \to 1$ 로 특징이 늘수록 줄어든다 (이때 [최소 노름 해](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#minimum-norm-solution-%EC%B5%9C%EC%86%8C-%EB%85%B8%EB%A6%84-%ED%95%B4)는 세 번째 경우 $(0.2, 0.4, 0.4, 0.8)$)

</details>

### 문제 10

[Lec06 5.4](../../Lec06_%EC%9D%BC%EB%B0%98%ED%99%94_%EC%9D%B4%EB%A1%A0.md#54-%EC%9D%B4%EC%A4%91-%ED%95%98%EA%B0%95)의 [이중 하강](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#double-descent-%EC%9D%B4%EC%A4%91-%ED%95%98%EA%B0%95) 실험(데이터 $n = 20$개, 특징 $p$개)에서 시험 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)는 $p = 15$일 때 $0.0256$, $p = 19$일 때 $0.955$, $p = 20$일 때 $1.25$, $p = 21$일 때 $1.61$, $p = 25$일 때 $0.0353$이었다. (1) 특징 수가 데이터 수와 같은 $p$는 얼마이고 그 이름은? (2) 시험 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)가 가장 큰 $p$에서 $p = 25$로 가면 시험 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)가 얼마나 줄었나?

<details><summary>풀이와 답</summary>

**주어진 값**
- $n = 20$ ([학습 데이터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-data-test-data-%ED%95%99%EC%8A%B5-%EB%8D%B0%EC%9D%B4%ED%84%B0%EC%99%80-%EC%8B%9C%ED%97%98-%EB%8D%B0%EC%9D%B4%ED%84%B0) 수)
- 시험 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8): $p = 15 \to 0.0256$, $19 \to 0.955$, $20 \to 1.25$, $21 \to 1.61$, $25 \to 0.0353$

**풀이**
1. (1) 식 $p = n$을 쓴다. 값을 대입한다: $p = 20$
2. 이 자리는 맞추는 해가 사실상 하나뿐이라 그 해가 크게 출렁이는 [보간](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#interpolation-%EB%B3%B4%EA%B0%84) 문턱이다 (본문 3절)
3. (2) 가장 큰 시험 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)를 찾는다: $0.0256$, $0.955$, $1.25$, $1.61$, $0.0353$ 중 가장 큰 것은 $1.61$ ($p = 21$)
4. 식을 쓴다: 줄어든 양 $= (p = 21$의 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)$) - (p = 25$의 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)$)$

6. 뺄셈을 한다: $1.61 - 0.0353 = 1.5747$

</details>
