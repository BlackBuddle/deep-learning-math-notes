## 기본 (직접 대입)

### 문제 1

$(1 + x/L)^L$에서 $x = 1$, $L = 5$일 때 값을 구하고 극한 $e = 2.7183$과 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x = 1$ (전체 변화량)
- $L = 5$ (곱하는 항의 개수)
- $e = 2.7183$ (극한값)

**풀이**
1. 식을 그대로 쓴다: $\left(1 + \dfrac{x}{L}\right)^L$
2. 값을 대입한다: $\left(1 + \dfrac{1}{5}\right)^{5}$
3. 나눗셈을 먼저 한다: $1 \div 5 = 0.2$ 이므로 $(1 + 0.2)^5$
4. 괄호 안을 더한다: $1 + 0.2 = 1.2$ 이므로 $1.2^5$
5. 거듭제곱을 한다 (1.2를 5번 곱한다): $1.2^2 = 1.44$, $1.2^3 = 1.44 \times 1.2 = 1.728$, $1.2^4 = 1.728 \times 1.2 = 2.0736$, $1.2^5 = 2.0736 \times 1.2 = 2.48832$
6. 극한과의 차이를 잰다: $2.7183 - 2.4883 = 0.2300$

**답**: $2.4883$ (극한 $e = 2.7183$보다 $0.23$ 작다. $L$을 키울수록 가까워진다)

</details>

### 문제 2

$(1 + x/L)^L$에서 $x = 2$, $L = 4$일 때 값을 구하고 극한 $e^2 = 7.3891$과 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x = 2$ (전체 변화량)
- $L = 4$ (곱하는 항의 개수)
- $e^2 = 7.3891$ (극한값, 계산기)

**풀이**
1. 식을 그대로 쓴다: $\left(1 + \dfrac{x}{L}\right)^L$
2. 값을 대입한다: $\left(1 + \dfrac{2}{4}\right)^{4}$
3. 나눗셈을 한다: $2 \div 4 = 0.5$ 이므로 $(1 + 0.5)^4$
4. 괄호 안을 더한다: $1 + 0.5 = 1.5$ 이므로 $1.5^4$
5. 거듭제곱을 한다 (1.5를 4번 곱한다): $1.5^2 = 2.25$, $1.5^3 = 2.25 \times 1.5 = 3.375$, $1.5^4 = 3.375 \times 1.5 = 5.0625$
6. 극한과의 차이를 잰다: $7.3891 - 5.0625 = 2.3266$

**답**: $5.0625$ (극한 $7.3891$보다 $2.3266$ 작다)

</details>

### 문제 3

나누는 값을 $L^2$로 바꾼 $(1 + 1/L^2)^L$에서 $L = 5$일 때 값을 구하고 극한값 1과 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $L = 5$ (곱하는 항의 개수)
- 나누는 값 $L^2 = 25$

**풀이**
1. 식을 그대로 쓴다: $\left(1 + \dfrac{1}{L^2}\right)^L$
2. 값을 대입한다: $\left(1 + \dfrac{1}{5^2}\right)^{5}$
3. 제곱을 먼저 한다: $5^2 = 25$ 이므로 $\left(1 + \dfrac{1}{25}\right)^5$
4. 나눗셈을 한다: $1 \div 25 = 0.04$ 이므로 $(1 + 0.04)^5$
5. 괄호 안을 더한다: $1 + 0.04 = 1.04$ 이므로 $1.04^5$
6. 거듭제곱을 한다 (1.04를 5번 곱한다): $1.04^2 = 1.0816$, $1.04^3 = 1.124864$, $1.04^4 = 1.169859$, $1.04^5 = 1.216653$

**답**: $1.2167$ ($L$이 커질수록 $1$로 간다. $L^2$로 나누면 항 하나가 바꾸는 양이 너무 작아 입력의 영향이 사라진다)

</details>

### 문제 4

블록이 입력을 그대로 내보내고($\mathrm{Block}(h) = h$) 처음 값이 $h_0 = 1$일 때, 블록 $L = 3$개를 배율 $1/L$($\alpha = 1$)로 지난 마지막 값 $h_3$를 구하라. ($h_{l+1} = h_l + \dfrac{1}{L^\alpha}\, \mathrm{Block}(h_l)$.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $h_0 = 1$ (처음 값)
- $L = 3$ (블록 개수)
- $\alpha = 1$ (배율 $1/L^1 = \frac13$)

**풀이**
1. 식을 그대로 쓴다: $h_{l+1} = h_l + \dfrac{1}{L^\alpha}\, h_l$
2. 값을 대입한다 (첫 블록): $h_1 = 1 + \dfrac{1}{3^1} \times 1$
3. 거듭제곱과 나눗셈을 한다: $3^1 = 3$ 이므로 $h_1 = 1 + \frac13 \times 1 = 1 + \frac13 = \frac43$
4. 둘째 블록: $h_2 = \frac43 + \frac13 \times \frac43 = \frac43 + \frac49 = \frac{12}{9} + \frac49 = \frac{16}{9}$
5. 셋째 블록: $h_3 = \frac{16}{9} + \frac13 \times \frac{16}{9} = \frac{16}{9} + \frac{16}{27} = \frac{48}{27} + \frac{16}{27} = \frac{64}{27}$
6. 소수로 바꾼다: $64 \div 27 = 2.3704$

**답**: $h_3 = \frac{64}{27} = 2.3704$ (매 블록 $\frac43$배이므로 $(1 + \frac13)^3$과 같다)

</details>

### 문제 5

$x = -1$일 때 $(1 + x/L)^L = (1 - 1/L)^L$에서 $L = 5$이면 값은? 극한 $e^{-1} = 0.3679$와 비교하라. ($e^{-1} = 1/e$.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $x = -1$ (전체 변화량, 음수)
- $L = 5$ (곱하는 항의 개수)
- $e^{-1} = 0.3679$ (극한값, 계산기)

**풀이**
1. 식을 그대로 쓴다: $\left(1 + \dfrac{x}{L}\right)^L$
2. 값을 대입한다: $\left(1 + \dfrac{-1}{5}\right)^{5}$
3. 나눗셈을 한다: $-1 \div 5 = -0.2$ 이므로 $(1 - 0.2)^5$
4. 괄호 안을 계산한다: $1 - 0.2 = 0.8$ 이므로 $0.8^5$
5. 거듭제곱을 한다 (0.8을 5번 곱한다): $0.8^2 = 0.64$, $0.8^3 = 0.512$, $0.8^4 = 0.4096$, $0.8^5 = 0.32768$
6. 극한과의 차이를 잰다: $0.3679 - 0.3277 = 0.0402$

**답**: $0.3277$ (극한 $0.3679$보다 $0.04$ 작다. 음수 $x$에서는 곱이 $0$과 $1$ 사이로 줄어든다)

</details>

### 문제 6

나누는 값을 $\sqrt{L}$로 바꾼 $(1 + 1/\sqrt{L})^L$에서 $L = 16$일 때 값을 구하고, 나누는 값이 $L$인 $(1 + 1/L)^L$과 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $L = 16$ (곱하는 항의 개수)
- $\sqrt{16} = 4$ ($4 \times 4 = 16$)

**풀이**
1. 식을 그대로 쓴다: $\left(1 + \dfrac{1}{\sqrt{L}}\right)^L$
2. 값을 대입한다: $\left(1 + \dfrac{1}{\sqrt{16}}\right)^{16}$
3. 제곱근을 먼저 구한다: $\sqrt{16} = 4$ 이므로 $\left(1 + \dfrac14\right)^{16}$
4. 나눗셈과 덧셈을 한다: $1 \div 4 = 0.25$, $1 + 0.25 = 1.25$ 이므로 $1.25^{16}$
5. 거듭제곱을 한다 (1.25를 16번 곱한다, 계산기): $1.25^{16} = 35.5271$
6. 비교할 값을 구한다: $(1 + 1/16)^{16} = 1.0625^{16} = 2.6379$ (계산기)
7. 배수를 구한다: $35.5271 \div 2.6379 = 13.47$

**답**: $\sqrt{L}$로 나누면 $35.5271$, $L$로 나누면 $2.6379$ (약 $13.5$배). $L$을 키울수록 격차가 폭발적으로 벌어진다 ($L = 100$이면 $13780.61$)

</details>

### 문제 7

블록 $L = 36$개의 출력이 서로 무작위($\pm 1$ 동전 던지기)이면 합의 표준편차는 $\sqrt{L}$이다. [블록 배율](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#block-multiplier-%EB%B8%94%EB%A1%9D-%EB%B0%B0%EC%9C%A8)이 $1/L$($\alpha = 1$)일 때와 $1/\sqrt{L}$($\alpha = 0.5$)일 때 배율을 곱한 합의 표준편차를 각각 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $L = 36$ (블록 개수)
- 무작위 합의 표준편차 $= \sqrt{L} = \sqrt{36}$
- 배율 $\dfrac{1}{L^\alpha}$, $\alpha = 1$ 또는 $0.5$

**풀이**
1. 식을 그대로 쓴다: 표준편차 $= \sqrt{L} \times \dfrac{1}{L^\alpha}$
2. $\sqrt{L}$을 구한다: $\sqrt{36} = 6$ ($6 \times 6 = 36$)
3. $\alpha = 1$을 대입한다: $6 \times \dfrac{1}{36^1} = 6 \times \dfrac{1}{36}$
4. 계산한다: $6 \div 36 = 0.1667$
5. $\alpha = 0.5$를 대입한다: $36^{0.5} = \sqrt{36} = 6$ 이므로 $6 \times \dfrac{1}{6}$
6. 계산한다: $6 \div 6 = 1$

**답**: $\alpha = 1$이면 $0.1667$ (점점 줄어든다), $\alpha = 0.5$이면 $1$ (일정). 무작위 블록에는 $1/\sqrt{L}$이 맞다

</details>

### 문제 8

블록 $L = 100$개의 출력이 모두 같은 방향이면 합은 $L$이다. [블록 배율](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#block-multiplier-%EB%B8%94%EB%A1%9D-%EB%B0%B0%EC%9C%A8) $\dfrac{1}{L^\alpha}$를 곱한 합 $L \times \dfrac{1}{L^\alpha}$를 $\alpha = 1$, $\alpha = 0.5$, $\alpha = 0$(배율 없음)에서 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $L = 100$ (블록 개수)
- 같은 방향이므로 합 $= L = 100$
- $\alpha = 1, 0.5, 0$

**풀이**
1. 식을 그대로 쓴다: 합 $= L \times \dfrac{1}{L^\alpha}$
2. $\alpha = 1$을 대입한다: $100 \times \dfrac{1}{100^1}$, 계산하면 $100 \div 100 = 1$
3. $\alpha = 0.5$를 대입한다: $100^{0.5} = \sqrt{100} = 10$ 이므로 $100 \times \dfrac{1}{10}$, 계산하면 $100 \div 10 = 10$
4. $\alpha = 0$을 대입한다: $100^0 = 1$ 이므로 $100 \times \dfrac{1}{1} = 100$

**답**: $\alpha = 1$이면 $1$, $\alpha = 0.5$이면 $10$, $\alpha = 0$이면 $100$. 같은 방향이면 $1/L$이 합을 일정하게 지킨다

</details>

### 문제 9

[Lec07 9](../../Lec07_%EC%B5%9C%EC%A0%81%ED%99%94%EC%9D%98_%EC%8A%A4%EC%BC%80%EC%9D%BC%EB%A7%81_%EA%B7%9C%EC%B9%99.md#9-%EA%B9%8A%EC%9D%B4-%EC%8A%A4%EC%BC%80%EC%9D%BC%EB%A7%81)의 잔차 블록 $h_{l+1} = h_l + \dfrac{1}{L^\alpha}\,\mathrm{Block}(h_l)$에서 $\mathrm{Block}(h) = h$, $h_0 = 1$, $L = 3$일 때 $\alpha = 1$, $\alpha = 0.5$, $\alpha = 0$(배율 없음)의 마지막 값 $h_3$를 비교하라. (블록이 입력을 그대로 내보내면 한 블록마다 $\left(1 + \dfrac{1}{L^\alpha}\right)$배가 되므로 $h_L = \left(1 + \dfrac{1}{L^\alpha}\right)^L$.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $h_0 = 1$, $L = 3$
- $\alpha = 1$: 배율 $\frac13$, $\alpha = 0.5$: 배율 $\dfrac{1}{\sqrt{3}} = 0.5774$, $\alpha = 0$: 배율 $1$
- $\sqrt{3} = 1.7321$ (계산기)

**풀이**
1. 식을 그대로 쓴다: $h_3 = \left(1 + \dfrac{1}{L^\alpha}\right)^3$
2. $\alpha = 1$을 대입한다: $\left(1 + \dfrac{1}{3}\right)^3 = \left(\dfrac43\right)^3$
3. 거듭제곱을 한다: $\dfrac43 \times \dfrac43 \times \dfrac43 = \dfrac{64}{27} = 2.3704$
4. $\alpha = 0.5$를 대입한다: $\left(1 + \dfrac{1}{\sqrt{3}}\right)^3 = (1 + 0.5774)^3 = 1.5774^3$
5. 거듭제곱을 한다 (반올림 전 값으로, 계산기): $1.5774^3 = 3.9245$
6. $\alpha = 0$을 대입한다: $\left(1 + \dfrac{1}{3^0}\right)^3 = (1 + 1)^3 = 2^3$
7. 거듭제곱을 한다: $2 \times 2 \times 2 = 8$

**답**: $\alpha = 1$: $2.3704$, $\alpha = 0.5$: $3.9245$, $\alpha = 0$: $8$. 배율이 약할수록 블록을 쌓을 때 값이 더 크게 부푼다 ($L$이 커지면 $\alpha = 1$만 $e$로 수렴한다)

</details>

### 문제 10

[Lec07 9](../../Lec07_%EC%B5%9C%EC%A0%81%ED%99%94%EC%9D%98_%EC%8A%A4%EC%BC%80%EC%9D%BC%EB%A7%81_%EA%B7%9C%EC%B9%99.md#9-%EA%B9%8A%EC%9D%B4-%EC%8A%A4%EC%BC%80%EC%9D%BC%EB%A7%81)의 깊이 스케일링에서 $x = -1$(블록이 신호를 줄이는 방향)일 때 $L = 25$에서 나누는 값이 $L$인 곱 $(1 - 1/L)^L$과 $\sqrt{L}$인 곱 $(1 - 1/\sqrt{L})^L$을 구해 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x = -1$ (전체 변화량)
- $L = 25$ (곱하는 항의 개수), $\sqrt{25} = 5$ ($5 \times 5 = 25$)

**풀이**
1. 식을 쓴다: $\left(1 - \dfrac{1}{s}\right)^L$ ($s = L$ 또는 $s = \sqrt{L}$)
2. $s = L$을 대입한다: $\left(1 - \dfrac{1}{25}\right)^{25}$
3. 나눗셈과 뺄셈을 한다: $1 \div 25 = 0.04$, $1 - 0.04 = 0.96$ 이므로 $0.96^{25}$
4. 거듭제곱을 한다 (0.96을 25번 곱한다, 계산기): $0.96^{25} = 0.3604$
5. $s = \sqrt{L}$을 대입한다: $\left(1 - \dfrac{1}{5}\right)^{25}$
6. 나눗셈과 뺄셈을 한다: $1 \div 5 = 0.2$, $1 - 0.2 = 0.8$ 이므로 $0.8^{25}$
7. 거듭제곱을 한다 (0.8을 25번 곱한다, 계산기): $0.8^{25} = 0.003778$
8. 비교한다: $0.3604 \div 0.003778 = 95.4$

**답**: $s = L$이면 $0.3604$ ($e^{-1} = 0.3679$에 가깝다), $s = \sqrt{L}$이면 $0.003778$ (0으로 사라진다. 약 $95$배 작다). 신호가 사라지는 [기울기 소실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#vanishing-gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0-%EC%86%8C%EC%8B%A4)과 같은 꼴

</details>
