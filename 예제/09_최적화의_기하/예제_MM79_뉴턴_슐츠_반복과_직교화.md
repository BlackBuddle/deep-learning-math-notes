# 예제: 뉴턴-슐츠 반복과 직교화

개념 노트: [MM79_뉴턴_슐츠_반복과_직교화](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/09_%EC%B5%9C%EC%A0%81%ED%99%94%EC%9D%98_%EA%B8%B0%ED%95%98/MM79_%EB%89%B4%ED%84%B4_%EC%8A%90%EC%B8%A0_%EB%B0%98%EB%B3%B5%EA%B3%BC_%EC%A7%81%EA%B5%90%ED%99%94.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 3차 반복은 $\sigma \leftarrow 1.5\sigma - 0.5\sigma^3$, 5차([Muon](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#muon-%EB%AE%A4%EC%98%A8-%EC%98%B5%ED%8B%B0%EB%A7%88%EC%9D%B4%EC%A0%80)) 반복은 $\sigma \leftarrow a\sigma - b\sigma^3 + c\sigma^5$ ($a = 3.4445$, $b = 4.775$, $c = 2.0315$)이다.

## 기본 (직접 대입)

### 문제 1

특잇값 $\sigma = 0.4$에 3차 [뉴턴-슐츠 반복](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#newton-schulz-iteration-%EB%89%B4%ED%84%B4-%EC%8A%90%EC%B8%A0-%EB%B0%98%EB%B3%B5)을 한 번 하면 얼마가 되는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $\sigma_t = 0.4$ (지금 특잇값)

**풀이**
1. 식을 그대로 쓴다: $\sigma_{t+1} = 1.5\,\sigma_t - 0.5\,\sigma_t^3$
2. 값을 대입한다: $\sigma_{t+1} = 1.5 \times 0.4 - 0.5 \times 0.4^3$
3. 세제곱을 한다: $0.4^3 = 0.4 \times 0.4 \times 0.4 = 0.064$ 이므로 $1.5 \times 0.4 - 0.5 \times 0.064$
4. 앞 곱셈을 한다: $1.5 \times 0.4 = 0.6$ 이므로 $0.6 - 0.5 \times 0.064$
5. 뒤 곱셈을 한다: $0.5 \times 0.064 = 0.032$ 이므로 $0.6 - 0.032$
6. 뺀다: $0.6 - 0.032 = 0.568$

**답**: $0.568$ (0.4보다 1에 가까워졌다)

</details>

### 문제 2

특잇값 $\sigma = 0.8$에 3차 반복을 한 번 하면 얼마가 되는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $\sigma_t = 0.8$ (지금 특잇값)

**풀이**
1. 식을 그대로 쓴다: $\sigma_{t+1} = 1.5\,\sigma_t - 0.5\,\sigma_t^3$
2. 값을 대입한다: $\sigma_{t+1} = 1.5 \times 0.8 - 0.5 \times 0.8^3$
3. 세제곱을 한다: $0.8^3 = 0.8 \times 0.8 \times 0.8 = 0.512$ 이므로 $1.5 \times 0.8 - 0.5 \times 0.512$
4. 앞 곱셈을 한다: $1.5 \times 0.8 = 1.2$ 이므로 $1.2 - 0.5 \times 0.512$
5. 뒤 곱셈을 한다: $0.5 \times 0.512 = 0.256$ 이므로 $1.2 - 0.256$
6. 뺀다: $1.2 - 0.256 = 0.944$

**답**: $0.944$ (1에 가까울수록 한 번에 더 정밀하게 다가간다)

</details>

### 문제 3

특잇값 $\sigma = 1$과 $\sigma = 0$은 3차 반복을 해도 그대로인지 확인하라. (이런 값을 고정점이라 한다.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $\sigma_t = 1$ 과 $\sigma_t = 0$ (두 경우)

**풀이**
1. 식을 그대로 쓴다: $\sigma_{t+1} = 1.5\,\sigma_t - 0.5\,\sigma_t^3$
2. $\sigma_t = 1$을 대입한다: $\sigma_{t+1} = 1.5 \times 1 - 0.5 \times 1^3$
3. 거듭제곱을 한다: $1^3 = 1$ 이므로 $1.5 \times 1 - 0.5 \times 1$
4. 곱셈을 한다: $1.5 - 0.5$
5. 뺀다: $1.5 - 0.5 = 1$
6. $\sigma_t = 0$을 대입한다: $\sigma_{t+1} = 1.5 \times 0 - 0.5 \times 0^3 = 0 - 0 = 0$

**답**: 둘 다 그대로다 ($1 \to 1$, $0 \to 0$). 그래서 반복은 0이 아닌 특잇값만 1로 끌어당기고, 특잇값 0인 방향은 0으로 둔다.

</details>

### 문제 4

행렬 $G = \begin{pmatrix}3&0\\0&4\end{pmatrix}$를 [프로베니우스 노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#frobenius-norm-%ED%94%84%EB%A1%9C%EB%B2%A0%EB%8B%88%EC%9A%B0%EC%8A%A4-%EB%85%B8%EB%A6%84)으로 나눈 $X_0 = G / \lVert G \rVert_F$의 특잇값을 구하라. (대각 행렬의 특잇값은 대각 칸의 절댓값. [프로베니우스 노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#frobenius-norm-%ED%94%84%EB%A1%9C%EB%B2%A0%EB%8B%88%EC%9A%B0%EC%8A%A4-%EB%85%B8%EB%A6%84)은 성분 제곱합의 제곱근.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $G = \begin{pmatrix}3&0\\0&4\end{pmatrix}$ ([기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) 행렬, 특잇값 3과 4)

**풀이**
1. 식을 그대로 쓴다: $\lVert G \rVert_F = \sqrt{\sum G_{ij}^2}$, $X_0 = G / \lVert G \rVert_F$
2. 값을 대입한다: $\lVert G \rVert_F = \sqrt{3^2 + 0^2 + 0^2 + 4^2}$
3. 제곱한다: $3^2 = 9$, $0^2 = 0$, $4^2 = 16$ 이므로 $\sqrt{9 + 0 + 0 + 16}$
4. 더하고 제곱근을 구한다: $9 + 16 = 25$ 이므로 $\sqrt{25} = 5$ ($5 \times 5 = 25$)
5. 특잇값을 5로 나눈다: $3 \div 5 = 0.6$, $4 \div 5 = 0.8$

**답**: $X_0 = \begin{pmatrix}0.6&0\\0&0.8\end{pmatrix}$, 특잇값 $0.6$과 $0.8$ (모두 1 이하라서 반복을 시작할 수 있다)

</details>

### 문제 5

문제 4의 $X_0 = \begin{pmatrix}0.6&0\\0&0.8\end{pmatrix}$에 행렬 식 $X_1 = 1.5\,X_0 - 0.5\,X_0 X_0^\top X_0$를 한 번 적용하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $X_0 = \begin{pmatrix}0.6&0\\0&0.8\end{pmatrix}$ (대각 행렬이라 $X_0^\top = X_0$)

**풀이**
1. 식을 그대로 쓴다: $X_1 = 1.5\,X_0 - 0.5\,X_0 X_0^\top X_0$
2. 값을 대입한다: $X_0 X_0^\top X_0 = \begin{pmatrix}0.6&0\\0&0.8\end{pmatrix}\begin{pmatrix}0.6&0\\0&0.8\end{pmatrix}\begin{pmatrix}0.6&0\\0&0.8\end{pmatrix}$
3. 대각 행렬의 곱은 칸마다 곱하면 된다: 첫 칸 $0.6 \times 0.6 \times 0.6 = 0.216$, 둘째 칸 $0.8 \times 0.8 \times 0.8 = 0.512$ 이므로 $X_0 X_0^\top X_0 = \begin{pmatrix}0.216&0\\0&0.512\end{pmatrix}$
4. 첫 칸을 계산한다: $1.5 \times 0.6 - 0.5 \times 0.216 = 0.9 - 0.108 = 0.792$
5. 둘째 칸을 계산한다: $1.5 \times 0.8 - 0.5 \times 0.512 = 1.2 - 0.256 = 0.944$
6. 모은다: $X_1 = \begin{pmatrix}0.792&0\\0&0.944\end{pmatrix}$

**답**: $X_1 = \begin{pmatrix}0.792&0\\0&0.944\end{pmatrix}$. 특잇값마다 따로 3차 식이 적용되어 두 값 모두 1에 가까워졌다.

</details>

### 문제 6

[기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $G = \begin{pmatrix}3&0\\0&-2\end{pmatrix}$의 쌍대 사상(특잇값을 모두 1로 바꾼 행렬) $UV^\top$는 $\begin{pmatrix}1&0\\0&-1\end{pmatrix}$이다. 행렬 [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81) $\langle G, UV^\top \rangle$이 특잇값의 합과 같은지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $G = \begin{pmatrix}3&0\\0&-2\end{pmatrix}$ (특잇값은 절댓값 3, 2)
- $UV^\top = \begin{pmatrix}1&0\\0&-1\end{pmatrix}$ (부호는 그대로, 크기만 1)

**풀이**
1. 식을 그대로 쓴다: $\langle G, UV^\top \rangle = \sum_{i,j} G_{ij}\,(UV^\top)_{ij}$
2. 값을 대입한다: $3 \times 1 + 0 \times 0 + 0 \times 0 + (-2) \times (-1)$
3. 곱셈을 한다: $3 + 0 + 0 + 2$ (음수 × 음수는 양수)
4. 더한다: $3 + 0 + 0 + 2 = 5$
5. 특잇값을 더한다: $3 + 2 = 5$

**답**: 둘 다 $5$. 쌍대 사상은 기울기와의 [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)을 특잇값의 합만큼 가장 크게 만든다.

</details>

### 문제 7

[기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $G = \begin{pmatrix}0&4\\2&0\end{pmatrix}$ (특잇값 4, 2), [날카로움](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sharpness-%EB%82%A0%EC%B9%B4%EB%A1%9C%EC%9B%80) $\lambda = 3$이다. 쌍대 사상은 $UV^\top = \begin{pmatrix}0&1\\1&0\end{pmatrix}$이다. [스펙트럼 노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#spectral-norm-%EC%8A%A4%ED%8E%99%ED%8A%B8%EB%9F%BC-%EB%85%B8%EB%A6%84) 아래 최급강하의 걸음 $\Delta W = -\frac{\sum_i \sigma_i}{\lambda}\, UV^\top$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\sigma_1 = 4$, $\sigma_2 = 2$ (특잇값)
- $UV^\top = \begin{pmatrix}0&1\\1&0\end{pmatrix}$ (쌍대 사상)
- $\lambda = 3$ ([날카로움](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sharpness-%EB%82%A0%EC%B9%B4%EB%A1%9C%EC%9B%80))

**풀이**
1. 식을 그대로 쓴다: $\Delta W = -\dfrac{\sum_i \sigma_i}{\lambda}\, UV^\top$
2. 값을 대입한다: $\Delta W = -\dfrac{4 + 2}{3} \begin{pmatrix}0&1\\1&0\end{pmatrix}$
3. 특잇값을 더한다: $4 + 2 = 6$ 이므로 $-\dfrac{6}{3}\begin{pmatrix}0&1\\1&0\end{pmatrix}$
4. 나눗셈을 한다: $6 \div 3 = 2$ 이므로 $-2 \times \begin{pmatrix}0&1\\1&0\end{pmatrix}$
5. 성분마다 −2를 곱한다: $\begin{pmatrix}0&-2\\-2&0\end{pmatrix}$

**답**: $\Delta W = \begin{pmatrix}0&-2\\-2&0\end{pmatrix}$. 두 방향 모두 같은 크기 2로 움직인다 ([기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) 그대로였다면 4와 2로 달랐을 것).

</details>

### 문제 8

[Muon](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#muon-%EB%AE%A4%EC%98%A8-%EC%98%B5%ED%8B%B0%EB%A7%88%EC%9D%B4%EC%A0%80)의 5차 반복을 특잇값 $\sigma = 0.5$에 한 번 하면 얼마가 되는가? ($a = 3.4445$, $b = 4.775$, $c = 2.0315$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $\sigma_t = 0.5$ (지금 특잇값)
- $a = 3.4445$, $b = 4.775$, $c = 2.0315$ (계수)

**풀이**
1. 식을 그대로 쓴다: $\sigma_{t+1} = a\,\sigma_t - b\,\sigma_t^3 + c\,\sigma_t^5$
2. 값을 대입한다: $\sigma_{t+1} = 3.4445 \times 0.5 - 4.775 \times 0.5^3 + 2.0315 \times 0.5^5$
3. 거듭제곱을 한다: $0.5^3 = 0.125$, $0.5^5 = 0.03125$ 이므로 $3.4445 \times 0.5 - 4.775 \times 0.125 + 2.0315 \times 0.03125$
4. 첫 곱셈을 한다: $3.4445 \times 0.5 = 1.72225$
5. 둘째 곱셈을 한다: $4.775 \times 0.125 = 0.596875$
6. 셋째 곱셈을 한다: $2.0315 \times 0.03125 = 0.0634844$
7. 앞의 뺄셈을 한다: $1.72225 - 0.596875 = 1.125375$
8. 더한다: $1.125375 + 0.0634844 = 1.1889$ (소수 넷째 자리까지)

**답**: $1.1889$. 1을 넘어섰다. 5차 계수는 수렴하지 않고 대략 0.7~1.1 사이를 오가도록 고른 것이다.

</details>

### 문제 9

[Lec23 10.2](../../Lec23_%EA%B3%84%EB%9F%89_%EB%94%A5%EB%9F%AC%EB%8B%9D.md#102-%EB%89%B4%ED%84%B4-%EC%8A%90%EC%B8%A0-%EB%B0%98%EB%B3%B5)에서 3차 반복은 작은 특잇값을 느리게 키운다. 시작 특잇값 $0.1$에 3차 반복을 두 번 손으로 계산하라. (반올림은 소수 넷째 자리)

<details><summary>풀이와 답</summary>

**주어진 값**
- $\sigma_0 = 0.1$ (시작 특잇값)

**풀이**
1. 식을 그대로 쓴다: $\sigma_{t+1} = 1.5\,\sigma_t - 0.5\,\sigma_t^3$
2. 첫 반복에 대입한다: $\sigma_1 = 1.5 \times 0.1 - 0.5 \times 0.1^3$
3. 세제곱을 한다: $0.1^3 = 0.001$ 이므로 $1.5 \times 0.1 - 0.5 \times 0.001$
4. 곱셈을 한다: $1.5 \times 0.1 = 0.15$, $0.5 \times 0.001 = 0.0005$ 이므로 $0.15 - 0.0005$
5. 뺀다: $0.15 - 0.0005 = 0.1495$
6. 둘째 반복에 대입한다: $\sigma_2 = 1.5 \times 0.1495 - 0.5 \times 0.1495^3$
7. 세제곱을 한다: $0.1495^3 = 0.003341$ 이므로 $1.5 \times 0.1495 - 0.5 \times 0.003341$
8. 곱셈을 한다: $1.5 \times 0.1495 = 0.22425$, $0.5 \times 0.003341 = 0.00167$ 이므로 $0.22425 - 0.00167$
9. 뺀다: $0.22425 - 0.00167 = 0.22258$, 소수 넷째 자리로 반올림하면 $0.2226$

**답**: $\sigma_1 = 0.1495$, $\sigma_2 = 0.2226$. 한 번에 약 1.5배밖에 못 키워서 1에 가까워지려면 9번 가까이 걸린다.

</details>

### 문제 10

같은 시작값 0.1에서 [Muon](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#muon-%EB%AE%A4%EC%98%A8-%EC%98%B5%ED%8B%B0%EB%A7%88%EC%9D%B4%EC%A0%80)의 5차 반복은 첫 걸음에 $0.3397$이 된다. [Lec23 10.2](../../Lec23_%EA%B3%84%EB%9F%89_%EB%94%A5%EB%9F%AC%EB%8B%9D.md#102-%EB%89%B4%ED%84%B4-%EC%8A%90%EC%B8%A0-%EB%B0%98%EB%B3%B5)처럼 두 번째 걸음을 구하고, 3차 반복의 두 번째 값 $0.2226$과 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\sigma_1 = 0.3397$ (5차 반복의 첫 걸음 뒤 특잇값)
- $a = 3.4445$, $b = 4.775$, $c = 2.0315$ (계수)

**풀이**
1. 식을 그대로 쓴다: $\sigma_2 = a\,\sigma_1 - b\,\sigma_1^3 + c\,\sigma_1^5$
2. 값을 대입한다: $\sigma_2 = 3.4445 \times 0.3397 - 4.775 \times 0.3397^3 + 2.0315 \times 0.3397^5$
3. 거듭제곱을 한다: $0.3397^3 = 0.0392$, $0.3397^5 = 0.00452$ 이므로 $3.4445 \times 0.3397 - 4.775 \times 0.0392 + 2.0315 \times 0.00452$
4. 첫 곱셈을 한다: $3.4445 \times 0.3397 = 1.1701$
5. 둘째 곱셈을 한다: $4.775 \times 0.0392 = 0.1872$
6. 셋째 곱셈을 한다: $2.0315 \times 0.00452 = 0.0092$
7. 앞의 뺄셈을 한다: $1.1701 - 0.1872 = 0.9829$
8. 더한다: $0.9829 + 0.0092 = 0.9921$
9. 비교한다: $0.9921$ 대 $0.2226$

**답**: 5차 반복은 두 걸음 만에 $0.9921$로 거의 1에 닿았고, 3차는 같은 두 걸음에 $0.2226$이다. 5차는 속도를 얻는 대신 1에 정확히 멈추지 않고 0.7~1.1을 오간다.

</details>
