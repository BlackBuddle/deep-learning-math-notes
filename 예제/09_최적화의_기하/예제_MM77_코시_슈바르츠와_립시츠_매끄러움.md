# 예제: 코시-슈바르츠 부등식과 립시츠 매끄러움

개념 노트: [MM77_코시_슈바르츠와_립시츠_매끄러움](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/09_%EC%B5%9C%EC%A0%81%ED%99%94%EC%9D%98_%EA%B8%B0%ED%95%98/MM77_%EC%BD%94%EC%8B%9C_%EC%8A%88%EB%B0%94%EB%A5%B4%EC%B8%A0%EC%99%80_%EB%A6%BD%EC%8B%9C%EC%B8%A0_%EB%A7%A4%EB%81%84%EB%9F%AC%EC%9B%80.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 문제 번호 순서는 쉬운 것에서 어려운 것, 마지막 둘은 강의 내용과 잇는 문제다. $\sqrt{x}$는 제곱해서 $x$가 되는 양수이고, $\tanh$ 값은 계산기로 구한다. $\tanh$의 매끄러움 상수는 $\alpha = 0.7698$, 연속 상수는 $\delta = 1$이다.

## 기본 (직접 대입)

### 문제 1
[기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $g = (1, 2)$와 걸음 $v = (3, -1)$의 [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)의 크기가 유클리드 상한(두 길이의 곱)을 넘지 않는지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $g = (1, 2)$ ([기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0))
- $v = (3, -1)$ (걸음)

**풀이**
1. 식을 그대로 쓴다: $|g^\top v| \le \lVert g \rVert_2\, \lVert v \rVert_2$
2. 값을 대입한다: $|1 \times 3 + 2 \times (-1)| \le \sqrt{1^2 + 2^2} \times \sqrt{3^2 + (-1)^2}$
3. 왼쪽 곱셈을 한다: $1 \times 3 = 3$, $2 \times (-1) = -2$ 이므로 왼쪽 $= |3 + (-2)|$
4. 더한다: $3 - 2 = 1$, 절댓값은 $1$
5. 오른쪽 제곱합을 한다: $1 + 4 = 5$, $9 + 1 = 10$
6. 제곱근을 구한다: $\sqrt{5} = 2.2361$, $\sqrt{10} = 3.1623$
7. 곱한다: $2.2361 \times 3.1623 = 7.0711$
8. 비교한다: $1 \le 7.0711$

**답**: [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)의 크기 **1**은 상한 **7.0711**보다 작다. 두 벡터가 거의 직각이라 [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)이 작다.

</details>

### 문제 2
$g = (1, -2, 3)$, $v = (2, 1, -1)$이다. 짝이 맞는 상한 $|g^\top v| \le \lVert g \rVert_1\, \lVert v \rVert_\infty$를 확인하라. ($L_1$ [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)은 성분 절댓값의 합, $L_\infty$ [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)은 성분 절댓값의 최댓값이다.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $g = (1, -2, 3)$ ([기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0))
- $v = (2, 1, -1)$ (걸음)

**풀이**
1. 식을 그대로 쓴다: $|g^\top v| \le \lVert g \rVert_1\, \lVert v \rVert_\infty$
2. 값을 대입한다: $|1 \times 2 + (-2) \times 1 + 3 \times (-1)| \le (|1| + |-2| + |3|) \times \max(|2|, |1|, |-1|)$
3. 왼쪽 곱셈을 한다: $1 \times 2 = 2$, $(-2) \times 1 = -2$, $3 \times (-1) = -3$ 이므로 왼쪽 $= |2 + (-2) + (-3)|$
4. 더한다: $2 - 2 - 3 = -3$, 절댓값은 $3$
5. $L_1$ [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)을 구한다: $1 + 2 + 3 = 6$
6. $L_\infty$ [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)을 구한다: $\max(2, 1, 1) = 2$
7. 곱한다: $6 \times 2 = 12$
8. 비교한다: $3 \le 12$

**답**: [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)의 크기 **3**은 상한 **12**보다 작다.

</details>

### 문제 3
$g = (6, 8)$이고 걸음 $v$를 $g$와 같은 방향의 길이 1짜리 $v = (0.6, 0.8)$로 잡으면 [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)과 유클리드 상한은 어떻게 되는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $g = (6, 8)$ ([기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0))
- $v = (0.6, 0.8)$ ($g$와 같은 방향의 단위 벡터)

**풀이**
1. 식을 그대로 쓴다: $|g^\top v| \le \lVert g \rVert_2\, \lVert v \rVert_2$
2. 값을 대입한다: $|6 \times 0.6 + 8 \times 0.8| \le \sqrt{6^2 + 8^2} \times \sqrt{0.6^2 + 0.8^2}$
3. 왼쪽 곱셈을 한다: $6 \times 0.6 = 3.6$, $8 \times 0.8 = 6.4$
4. 더한다: $3.6 + 6.4 = 10$
5. 오른쪽 제곱합을 한다: $36 + 64 = 100$, $0.36 + 0.64 = 1$
6. 제곱근을 구한다: $\sqrt{100} = 10$, $\sqrt{1} = 1$
7. 곱한다: $10 \times 1 = 10$
8. 비교한다: $10 \le 10$

**답**: [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81) **10**, 상한 **10**으로 **등호**가 성립한다. 두 벡터가 같은 방향일 때만 상한이 딱 맞는다.

</details>

### 문제 4
행렬 $A = \begin{pmatrix}3&1\\1&3\end{pmatrix}$(연산자 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84) 4)을 벡터 $v = (1, 2)$로 양쪽에서 끼운 값 $v^\top A v$가 상한 $\lVert A \rVert_{\mathrm{op}} \lVert v \rVert^2$ 안에 드는지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $A = \begin{pmatrix}3&1\\1&3\end{pmatrix}$ (휘어짐 행렬, 가장 큰 특잇값 4)
- $v = (1, 2)$ (방향 벡터)

**풀이**
1. 식을 그대로 쓴다: $v^\top A\, v \le \lVert A \rVert_{\mathrm{op}}\, \lVert v \rVert^2$
2. 값을 대입한다: $(1, 2)\begin{pmatrix}3&1\\1&3\end{pmatrix}\begin{pmatrix}1\\2\end{pmatrix} \le 4 \times (1^2 + 2^2)$
3. [행렬 곱](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#matrix-multiplication-%ED%96%89%EB%A0%AC-%EA%B3%B1) 첫째 줄을 펼친다: $3 \times 1 + 1 \times 2 = 3 + 2 = 5$
4. 둘째 줄을 펼친다: $1 \times 1 + 3 \times 2 = 1 + 6 = 7$ 이므로 $Av = (5, 7)$
5. 왼쪽 [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)을 펼친다: $1 \times 5 + 2 \times 7 = 5 + 14 = 19$
6. 오른쪽 제곱합을 한다: $1 + 4 = 5$
7. 곱한다: $4 \times 5 = 20$
8. 비교한다: $19 \le 20$

**답**: 왼쪽 **19**, 상한 **20**. 상한을 넘지 않는다.

</details>

### 문제 5
$f = \tanh$, $\alpha = 0.7698$일 때 $w = 0$에서 $\Delta = 0.5$만큼 움직이면 1차 근사의 나머지 $|f(w + \Delta) - f(w) - f'(w)\Delta|$가 상한 $\frac{\alpha}{2}\Delta^2$ 안에 드는지 확인하라. ($\tanh 0 = 0$, $\tanh 0.5 = 0.4621$, $f'(w) = 1 - \tanh^2 w$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $f(0) = \tanh 0 = 0$ (지금 값)
- $f(0.5) = \tanh 0.5 = 0.4621$ (움직인 뒤 값)
- $f'(0) = 1 - 0^2 = 1$ (지금 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0))
- $\Delta = 0.5$ (이동), $\alpha = 0.7698$ (매끄러움 상수)

**풀이**
1. 식을 그대로 쓴다: $|f(w + \Delta) - f(w) - f'(w)\Delta| \le \frac{\alpha}{2}\Delta^2$
2. 값을 대입한다: $|0.4621 - 0 - 1 \times 0.5| \le \frac{0.7698}{2} \times 0.5^2$
3. 왼쪽 곱셈을 먼저 한다: $1 \times 0.5 = 0.5$ 이므로 $|0.4621 - 0 - 0.5|$
4. 뺀다: $0.4621 - 0 = 0.4621$, $0.4621 - 0.5 = -0.0379$, 절댓값은 $0.0379$
5. 오른쪽 나눗셈을 한다: $0.7698 / 2 = 0.3849$
6. 제곱을 한다: $0.5^2 = 0.25$
7. 곱한다: $0.3849 \times 0.25 = 0.0962$
8. 비교한다: $0.0379 \le 0.0962$

**답**: 나머지 **0.0379**는 상한 **0.0962** 안에 든다.

</details>

### 문제 6
$f = \sin$은 $|f''| = |\sin| \le 1$이므로 $\alpha = 1$이다. $w = 0$에서 $\Delta = 1$만큼 움직일 때 1차 근사의 나머지가 상한 $\frac{\alpha}{2}\Delta^2$ 안에 드는지 확인하라. ($\sin 0 = 0$, $\sin 1 = 0.8415$, $f'(w) = \cos w$, $\cos 0 = 1$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $f(0) = \sin 0 = 0$, $f(1) = \sin 1 = 0.8415$ (지금 값, 움직인 뒤 값)
- $f'(0) = \cos 0 = 1$ (지금 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0))
- $\Delta = 1$ (이동), $\alpha = 1$ (매끄러움 상수)

**풀이**
1. 식을 그대로 쓴다: $|f(w + \Delta) - f(w) - f'(w)\Delta| \le \frac{\alpha}{2}\Delta^2$
2. 값을 대입한다: $|0.8415 - 0 - 1 \times 1| \le \frac{1}{2} \times 1^2$
3. 곱셈을 먼저 한다: $1 \times 1 = 1$ 이므로 $|0.8415 - 0 - 1|$
4. 뺀다: $0.8415 - 0 = 0.8415$, $0.8415 - 1 = -0.1585$, 절댓값은 $0.1585$
5. 오른쪽을 계산한다: $\frac{1}{2} \times 1 = 0.5$
6. 비교한다: $0.1585 \le 0.5$

**답**: 나머지 **0.1585**는 상한 **0.5** 안에 든다. 상한은 틀리지 않는 대신 꽤 느슨할 수 있다.

</details>

### 문제 7
$f = \tanh(w)$, 제곱 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8), [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) $y = 0.5$, $w = 0$에서 [날카로움](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sharpness-%EB%82%A0%EC%B9%B4%EB%A1%9C%EC%9B%80)의 상한 $\lambda = \alpha\, \lVert \nabla_f \ell \rVert + \delta\, \lVert \nabla_f^2 \ell \rVert$를 구하고, 실제 휘어짐 $f'(w)^2 + (f - y) f''(w)$와 비교하라. ($f'' = -2 f f'$, 제곱 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)의 휘어짐은 1)

<details><summary>풀이와 답</summary>

**주어진 값**
- $f(0) = \tanh 0 = 0$, $f'(0) = 1 - 0^2 = 1$, $f''(0) = -2 \times 0 \times 1 = 0$
- $\lVert \nabla_f \ell \rVert = |f - y| = |0 - 0.5| = 0.5$ ([오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 척도의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) 크기)
- $\lVert \nabla_f^2 \ell \rVert = 1$ (제곱 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)의 휘어짐)
- $\alpha = 0.7698$, $\delta = 1$

**풀이**
1. 식을 그대로 쓴다: $\lambda = \alpha\, \lVert \nabla_f \ell \rVert_\ast + \delta\, \lVert \nabla_f^2 \ell \rVert_{\mathrm{op}}$
2. 값을 대입한다: $\lambda = 0.7698 \times 0.5 + 1 \times 1$
3. 첫 곱셈을 한다: $0.7698 \times 0.5 = 0.3849$ 이므로 $\lambda = 0.3849 + 1 \times 1$
4. 둘째 곱셈을 한다: $1 \times 1 = 1$ 이므로 $\lambda = 0.3849 + 1$
5. 더한다: $0.3849 + 1 = 1.3849$
6. 실제 휘어짐의 식을 쓰고 대입한다: $f'^2 + (f - y) f'' = 1^2 + (0 - 0.5) \times 0$
7. 계산한다: $1 + 0 = 1$
8. 비교한다: $1 \le 1.3849$

**답**: $\lambda = $ **1.3849**, 실제 휘어짐은 **1**. 상한이 실제보다 크므로 상한 노릇을 한다.

</details>

### 문제 8
출력을 3배로 키운 모델 $f = 3\tanh(w)$에서 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 척도의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) 크기가 $0.2$, 휘어짐이 1이다. 1차, 2차 [미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#derivative-%EB%AF%B8%EB%B6%84)이 모두 3배가 된다. $\alpha$, $\delta$, $\lambda$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\tanh$의 $\alpha = 0.7698$, $\delta = 1$
- $f = 3\tanh(w)$ (모델, 출력이 3배라 1차, 2차 [미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#derivative-%EB%AF%B8%EB%B6%84)도 3배)
- $\lVert \nabla_f \ell \rVert = 0.2$, $\lVert \nabla_f^2 \ell \rVert = 1$

**풀이**
1. 매끄러움 상수는 2차 [미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#derivative-%EB%AF%B8%EB%B6%84)의 최대 크기라 3배다: $\alpha = 3 \times 0.7698 = 2.3094$
2. 연속 상수는 1차 [미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#derivative-%EB%AF%B8%EB%B6%84) 제곱의 최대라 $3^2 = 9$배다: $\delta = 9 \times 1 = 9$
3. 식을 그대로 쓴다: $\lambda = \alpha\, \lVert \nabla_f \ell \rVert_\ast + \delta\, \lVert \nabla_f^2 \ell \rVert_{\mathrm{op}}$
4. 값을 대입한다: $\lambda = 2.3094 \times 0.2 + 9 \times 1$
5. 첫 곱셈을 한다: $2.3094 \times 0.2 = 0.4619$ 이므로 $\lambda = 0.4619 + 9 \times 1$
6. 둘째 곱셈을 한다: $9 \times 1 = 9$ 이므로 $\lambda = 0.4619 + 9$
7. 더한다: $0.4619 + 9 = 9.4619$

**답**: $\alpha = $ **2.3094**, $\delta = $ **9**, $\lambda = $ **9.4619**. 출력이 3배가 되면 [날카로움](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sharpness-%EB%82%A0%EC%B9%B4%EB%A1%9C%EC%9B%80)이 9배 남짓 커진다. 출력 크기를 키울수록 걸음을 작게 해야 한다.

</details>

### 문제 9
[Lec23 3.2](../../Lec23_%EA%B3%84%EB%9F%89_%EB%94%A5%EB%9F%AC%EB%8B%9D.md#32-%EA%B0%80%EC%9A%B0%EC%8A%A4-%EB%89%B4%ED%84%B4-%EB%B6%84%ED%95%B4%EB%A1%9C-%EC%83%81%ED%95%9C-%EC%9E%A1%EA%B8%B0)에서 [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)을 [쌍대 노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dual-norm-%EC%8C%8D%EB%8C%80-%EB%85%B8%EB%A6%84)으로 누른다. $g = (1, -3)$, $v = (2, 1)$에서 [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)의 크기, $L_2$-$L_2$ 상한, $L_1$-$L_\infty$ 상한을 구하고 어느 쪽이 더 딱 맞는지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $g = (1, -3)$ ([기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)), $v = (2, 1)$ (걸음)

**풀이**
1. [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81) 식을 쓰고 대입한다: $|g^\top v| = |1 \times 2 + (-3) \times 1|$
2. 곱하고 더한다: $2 + (-3) = -1$, 절댓값은 $1$
3. $L_2$ 상한 식을 쓰고 대입한다: $\lVert g \rVert_2 \lVert v \rVert_2 = \sqrt{1^2 + (-3)^2} \times \sqrt{2^2 + 1^2}$
4. 제곱합을 한다: $1 + 9 = 10$, $4 + 1 = 5$
5. 제곱근을 구하고 곱한다: $\sqrt{10} \times \sqrt{5} = 3.1623 \times 2.2361 = 7.0711$
6. $L_1$-$L_\infty$ 상한 식을 쓰고 대입한다: $\lVert g \rVert_1 \lVert v \rVert_\infty = (|1| + |-3|) \times \max(|2|, |1|)$
7. 계산한다: $1 + 3 = 4$, $\max(2, 1) = 2$ 이므로 $4 \times 2 = 8$
8. 비교한다: $1 \le 7.0711 \le 8$

**답**: [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)의 크기 **1**, $L_2$ 상한 **7.0711**, $L_1$-$L_\infty$ 상한 **8**. 이 예에서는 $L_2$ 상한이 조금 더 딱 맞는다. 어느 자를 쓰든 짝([쌍대 노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dual-norm-%EC%8C%8D%EB%8C%80-%EB%85%B8%EB%A6%84))만 맞추면 상한이 성립한다.

</details>

### 문제 10
[Lec23 3.3](../../Lec23_%EA%B3%84%EB%9F%89_%EB%94%A5%EB%9F%AC%EB%8B%9D.md#33-%EC%8B%A0%EA%B2%BD%EB%A7%9D%EC%9D%98-%EB%A6%BD%EC%8B%9C%EC%B8%A0-%EC%A1%B0%EA%B1%B4)의 예를 처음부터 확인한다. $f = \tanh(w)$, [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) $y = 0.5$, $w = 0.2$에서 실제 휘어짐 $H = f'(w)^2 + (f - y) f''(w)$를 구하고, [날카로움](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sharpness-%EB%82%A0%EC%B9%B4%EB%A1%9C%EC%9B%80) 상한 $\lambda = \alpha|f - y| + \delta \times 1 = 1.233$이 $H$보다 몇 % 큰지 구하라. ($\tanh 0.2 = 0.1974$, $f' = 1 - f^2$, $f'' = -2 f f'$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $f = \tanh 0.2 = 0.1974$ (지금 출력), $y = 0.5$ ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5))
- $\lambda = 1.233$ ([날카로움](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sharpness-%EB%82%A0%EC%B9%B4%EB%A1%9C%EC%9B%80) 상한, 노트 3.4)

**풀이**
1. 식을 그대로 쓴다: $H = f'(w)^2 + (f - y)\, f''(w)$
2. 1차 [미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#derivative-%EB%AF%B8%EB%B6%84)을 구한다: $f' = 1 - f^2 = 1 - 0.1974^2 = 1 - 0.0390 = 0.9610$
3. 2차 [미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#derivative-%EB%AF%B8%EB%B6%84)을 구한다: $f'' = -2 \times 0.1974 \times 0.9610 = -0.3794$
4. [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)를 구한다: $f - y = 0.1974 - 0.5 = -0.3026$
5. 값을 대입한다: $H = 0.9610^2 + (-0.3026) \times (-0.3794)$
6. 첫 제곱을 한다: $0.9610^2 = 0.9235$
7. 둘째 곱셈을 한다: $(-0.3026) \times (-0.3794) = 0.1148$ (음수끼리 곱하면 양수)
8. 더한다: $H = 0.9235 + 0.1148 = 1.0383$ (반올림 전 값은 1.0384)
9. 비교한다: $1.0383 \le 1.233$
10. 비율을 구한다: $1.233 / 1.0383 = 1.1875$

**답**: 실제 휘어짐 $H = $ **약 1.038**은 상한 $\lambda = 1.233$ 안에 들고, 상한이 **약 19%** 더 크다. 상한이 틀리지는 않지만 꼭 딱 맞지는 않는다. 강의가 딱 맞는 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)을 찾자고 하는 이유다.

</details>
