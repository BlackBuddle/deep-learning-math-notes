# 예제: 그래디언트 벡터

개념 노트: [MM02_그래디언트_벡터](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/02_%EB%AF%B8%EB%B6%84/MM02_%EA%B7%B8%EB%9E%98%EB%94%94%EC%96%B8%ED%8A%B8_%EB%B2%A1%ED%84%B0.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. [편미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#partial-derivative-%ED%8E%B8%EB%AF%B8%EB%B6%84) 규칙은 하나만 쓴다: $(w - a)^2$을 $w$로 미분하면 $2(w - a)$이고, $c\,w^2$을 $w$로 미분하면 $2c\,w$이다. 다른 변수는 상수로 보고 미분하지 않는다.

## 기본 (직접 대입)

### 문제 1

$J(w, b) = (w-3)^2 + (b+2)^2$의 그래디언트 $\nabla J$를 구하고, $(w, b) = (5, 0)$에서의 값을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $J(w, b) = (w-3)^2 + (b+2)^2$ ([손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98))
- $(w, b) = (5, 0)$ (값을 구할 점)

**풀이**
1. 식을 그대로 쓴다: $\nabla J(w, b) = \left(\frac{\partial J}{\partial w},\ \frac{\partial J}{\partial b}\right)$
2. $w$로 편미분한다 ($b$는 고정이라 $(b+2)^2$은 상수, 미분하면 0): $\frac{\partial J}{\partial w} = 2(w-3)$
3. $b$로 편미분한다 ($w$는 고정이라 $(w-3)^2$은 상수): $\frac{\partial J}{\partial b} = 2(b+2)$
4. 값을 대입한다: $\nabla J(5, 0) = \big(2(5 - 3),\ 2(0 + 2)\big)$
5. 괄호를 계산한다: 5 − 3 = 2, 0 + 2 = 2 이므로 $\nabla J(5, 0) = (2 \times 2,\ 2 \times 2)$
6. 곱셈을 한다: 2 × 2 = 4 (두 칸 모두) 이므로 $\nabla J(5, 0) = (4, 4)$

**답**: $\nabla J = \big(2(w-3),\ 2(b+2)\big)$, $\nabla J(5, 0) = (4, 4)$

</details>

### 문제 2

$J(w, b) = w^2 + b^2$의 그래디언트를 구하고 $(w, b) = (3, -4)$에서의 값을 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $J(w, b) = w^2 + b^2$ ([손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98))
- $(w, b) = (3, -4)$ (값을 구할 점)

**풀이**
1. 식을 그대로 쓴다: $\nabla J(w, b) = \left(\frac{\partial J}{\partial w},\ \frac{\partial J}{\partial b}\right)$
2. 각 변수로 편미분한다 ($w^2$을 미분하면 $2w$, $b^2$을 미분하면 $2b$): $\nabla J = (2w,\ 2b)$
3. 값을 대입한다: $\nabla J(3, -4) = (2 \times 3,\ 2 \times (-4))$
4. 곱셈을 한다: 2 × 3 = 6, 2 × (−4) = −8 이므로 $\nabla J(3, -4) = (6, -8)$

**답**: $\nabla J(3, -4) = (6, -8)$

</details>

### 문제 3

$J(w, b) = (w-2)^2 + (b+1)^2$에서 지금 $(w, b) = (4, 1)$이고 [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0)이 $\eta = 0.1$이다. [경사하강법](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-descent-%EA%B2%BD%EC%82%AC%ED%95%98%EA%B0%95%EB%B2%95)으로 한 번 갱신한 $(w, b)$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\theta = (w, b) = (4, 1)$ (지금 [파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0))
- $\eta = 0.1$ ([학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0))
- $\nabla J = \big(2(w-2),\ 2(b+1)\big)$ (그래디언트 식)

**풀이**
1. 식을 그대로 쓴다: $\theta \leftarrow \theta - \eta\, \nabla J(\theta)$
2. 값을 대입한다: $\theta \leftarrow (4, 1) - 0.1 \times \big(2(4 - 2),\ 2(1 + 1)\big)$
3. 괄호를 계산한다: 4 − 2 = 2, 1 + 1 = 2 이므로 $\theta \leftarrow (4, 1) - 0.1 \times (2 \times 2,\ 2 \times 2)$
4. 그래디언트 곱셈을 한다: 2 × 2 = 4 (두 칸 모두) 이므로 $\theta \leftarrow (4, 1) - 0.1 \times (4, 4)$
5. [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0)을 칸마다 곱한다: 0.1 × 4 = 0.4 (두 칸 모두) 이므로 $\theta \leftarrow (4, 1) - (0.4, 0.4)$
6. 칸끼리 뺀다: 4 − 0.4 = 3.6, 1 − 0.4 = 0.6 이므로 $\theta = (3.6, 0.6)$

**답**: $(w, b) = (3.6, 0.6)$

</details>

### 문제 4

같은 $J(w, b) = (w-2)^2 + (b+1)^2$에서 점 $(1, -3)$의 그래디언트를 구하라. 그 부호를 보고 $w$와 $b$를 늘려야 하는지 줄여야 하는지 말하고, $\eta = 0.1$로 한 번 갱신한 뒤 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 줄었는지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $(w, b) = (1, -3)$ (지금 [파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0))
- $\eta = 0.1$ ([학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0))

**풀이**
1. 그래디언트 식을 쓴다: $\nabla J = \big(2(w-2),\ 2(b+1)\big)$
2. 값을 대입한다: $\nabla J(1, -3) = \big(2(1 - 2),\ 2(-3 + 1)\big)$
3. 괄호를 계산한다: 1 − 2 = −1, −3 + 1 = −2 이므로 $\nabla J(1, -3) = (2 \times (-1),\ 2 \times (-2))$
4. 곱셈을 한다: 2 × (−1) = −2, 2 × (−2) = −4 이므로 $\nabla J(1, -3) = (-2, -4)$
5. 부호를 읽는다: 두 칸 모두 음수라서 $w$와 $b$를 늘리면 $J$가 줄어든다 (그래디언트는 올라가는 방향이므로 그 반대로 간다)
6. 갱신 식을 쓰고 대입한다: $\theta \leftarrow (1, -3) - 0.1 \times (-2, -4)$
7. [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0)을 칸마다 곱한다: 0.1 × (−2) = −0.2, 0.1 × (−4) = −0.4 이므로 $\theta \leftarrow (1, -3) - (-0.2, -0.4)$
8. 칸끼리 뺀다: 1 − (−0.2) = 1.2, −3 − (−0.4) = −2.6 이므로 $\theta = (1.2, -2.6)$
9. 갱신 전 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 구한다: $(1-2)^2 + (-3+1)^2 = (-1)^2 + (-2)^2 = 1 + 4 = 5$
10. 갱신 후 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 구한다: $(1.2-2)^2 + (-2.6+1)^2 = (-0.8)^2 + (-1.6)^2 = 0.64 + 2.56 = 3.2$

**답**: $\nabla J(1, -3) = (-2, -4)$, $w$와 $b$를 늘려야 한다. 갱신 뒤 $\theta = (1.2, -2.6)$이고 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은 5에서 3.2로 줄었다

</details>

### 문제 5

$J(w, b) = w^2 + 2b^2$의 그래디언트를 구하고 $(w, b) = (1, 2)$에서의 값을 구하라. ($b$의 계수 2 때문에 $b$ 쪽 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 어떻게 달라지는지 본다.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $J(w, b) = w^2 + 2b^2$ ([손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98))
- $(w, b) = (1, 2)$ (값을 구할 점)

**풀이**
1. 식을 그대로 쓴다: $\nabla J(w, b) = \left(\frac{\partial J}{\partial w},\ \frac{\partial J}{\partial b}\right)$
2. $w$로 편미분한다: $\frac{\partial J}{\partial w} = 2w$
3. $b$로 편미분한다 ($2b^2$을 미분하면 $2 \times 2b$): $\frac{\partial J}{\partial b} = 4b$
4. 값을 대입한다: $\nabla J(1, 2) = (2 \times 1,\ 4 \times 2)$
5. 곱셈을 한다: 2 × 1 = 2, 4 × 2 = 8 이므로 $\nabla J(1, 2) = (2, 8)$

**답**: $\nabla J(1, 2) = (2, 8)$ ($b$ 쪽이 4배 가파르다)

</details>

### 문제 6

$J(w, b) = w^2 + b^2$에서 $(w, b) = (2, -2)$, $\eta = 0.25$로 두 번 갱신한 $(w, b)$를 구하고, [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 어떻게 변하는지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\theta^0 = (2, -2)$ (출발점)
- $\eta = 0.25$ ([학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0))
- $\nabla J = (2w,\ 2b)$ (그래디언트 식)

**풀이**
1. 갱신 식을 쓴다: $\theta \leftarrow \theta - \eta\, \nabla J(\theta)$
2. 첫 번째 그래디언트를 구한다: $\nabla J(2, -2) = (2 \times 2,\ 2 \times (-2)) = (4, -4)$
3. 첫 번째 갱신에 값을 대입한다: $\theta \leftarrow (2, -2) - 0.25 \times (4, -4)$
4. [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0)을 칸마다 곱한다: 0.25 × 4 = 1, 0.25 × (−4) = −1 이므로 $\theta \leftarrow (2, -2) - (1, -1)$
5. 칸끼리 뺀다: 2 − 1 = 1, −2 − (−1) = −1 이므로 $\theta^1 = (1, -1)$
6. 두 번째 그래디언트를 구한다: $\nabla J(1, -1) = (2 \times 1,\ 2 \times (-1)) = (2, -2)$
7. 두 번째 갱신에 값을 대입한다: $\theta \leftarrow (1, -1) - 0.25 \times (2, -2)$
8. [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0)을 칸마다 곱한다: 0.25 × 2 = 0.5, 0.25 × (−2) = −0.5 이므로 $\theta \leftarrow (1, -1) - (0.5, -0.5)$
9. 칸끼리 뺀다: 1 − 0.5 = 0.5, −1 − (−0.5) = −0.5 이므로 $\theta^2 = (0.5, -0.5)$
10. [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 구한다: $J(2, -2) = 4 + 4 = 8$, $J(1, -1) = 1 + 1 = 2$, $J(0.5, -0.5) = 0.25 + 0.25 = 0.5$

**답**: $\theta^2 = (0.5, -0.5)$, [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은 8 → 2 → 0.5로 갱신마다 4분의 1이 된다

</details>

### 문제 7

변수가 세 개인 $J(w, b, c) = w^2 + b^2 + c^2$에서 $(w, b, c) = (1, 2, 2)$, $\eta = 0.25$로 한 번 갱신한 값을 구하라. (그래디언트는 변수 개수만큼의 칸을 가진 벡터다.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $\theta = (w, b, c) = (1, 2, 2)$ (지금 [파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0))
- $\eta = 0.25$ ([학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0))
- $\nabla J = (2w,\ 2b,\ 2c)$ (그래디언트 식)

**풀이**
1. 식을 그대로 쓴다: $\theta \leftarrow \theta - \eta\, \nabla J(\theta)$
2. 값을 대입한다: $\theta \leftarrow (1, 2, 2) - 0.25 \times (2 \times 1,\ 2 \times 2,\ 2 \times 2)$
3. 그래디언트 곱셈을 한다: 2 × 1 = 2, 2 × 2 = 4, 2 × 2 = 4 이므로 $\theta \leftarrow (1, 2, 2) - 0.25 \times (2, 4, 4)$
4. [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0)을 칸마다 곱한다: 0.25 × 2 = 0.5, 0.25 × 4 = 1, 0.25 × 4 = 1 이므로 $\theta \leftarrow (1, 2, 2) - (0.5, 1, 1)$
5. 칸끼리 뺀다: 1 − 0.5 = 0.5, 2 − 1 = 1, 2 − 1 = 1 이므로 $\theta = (0.5, 1, 1)$

**답**: $(w, b, c) = (0.5, 1, 1)$

</details>

### 문제 8

$J(w, b) = (w-2)^2 + (b+1)^2$의 바닥 $(2, -1)$에서 그래디언트를 구하고, $\eta = 0.5$로 갱신하면 어떻게 되는지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $(w, b) = (2, -1)$ (바닥)
- $\eta = 0.5$ ([학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0))

**풀이**
1. 그래디언트 식을 쓴다: $\nabla J = \big(2(w-2),\ 2(b+1)\big)$
2. 값을 대입한다: $\nabla J(2, -1) = \big(2(2 - 2),\ 2(-1 + 1)\big)$
3. 괄호를 계산한다: 2 − 2 = 0, −1 + 1 = 0 이므로 $\nabla J(2, -1) = (2 \times 0,\ 2 \times 0)$
4. 곱셈을 한다: 2 × 0 = 0 이므로 $\nabla J(2, -1) = (0, 0)$
5. 갱신 식을 쓰고 대입한다: $\theta \leftarrow (2, -1) - 0.5 \times (0, 0)$
6. [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0)을 곱한다: 0.5 × 0 = 0 이므로 $\theta \leftarrow (2, -1) - (0, 0)$
7. 칸끼리 뺀다: 2 − 0 = 2, −1 − 0 = −1 이므로 $\theta = (2, -1)$

**답**: $\nabla J(2, -1) = (0, 0)$이고 갱신해도 $(2, -1)$ 그대로다 (바닥에서는 올라가는 방향이 없어 멈춘다)

</details>

### 문제 9

[Lec06 8.4](../../Lec06_%EC%9D%BC%EB%B0%98%ED%99%94_%EC%9D%B4%EB%A1%A0.md#84-%EC%B5%9C%EC%A0%81%ED%99%94%EC%9D%98-%EC%95%94%EB%AC%B5%EC%A0%81-%EA%B7%9C%EC%A0%9C)는 좁은 우물 $f(w) = 25w^2$에서 보폭 $\eta = 0.1$의 경사하강이 튕겨 나간다고 보여 준다. $w = 1$에서 시작해 두 번 갱신한 $w$와 그때의 $f$ 값을 구하라. ($f$의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)는 $\frac{df}{dw} = 50w$이고, 갱신식은 $w \leftarrow w - \eta \frac{df}{dw}$이다.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $w^0 = 1$ (출발점)
- $\eta = 0.1$ (보폭, [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0))
- $\frac{df}{dw} = 50w$ ([기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0))

**풀이**
1. 식을 그대로 쓴다: $w \leftarrow w - \eta\, \frac{df}{dw}$
2. 첫 번째 갱신에 값을 대입한다: $w \leftarrow 1 - 0.1 \times (50 \times 1)$
3. [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)를 계산한다: 50 × 1 = 50 이므로 $w \leftarrow 1 - 0.1 \times 50$
4. 곱셈을 한다: 0.1 × 50 = 5 이므로 $w \leftarrow 1 - 5$
5. 뺄셈을 한다: 1 − 5 = −4 이므로 $w^1 = -4$
6. 두 번째 갱신에 값을 대입한다: $w \leftarrow -4 - 0.1 \times (50 \times (-4))$
7. [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)를 계산한다: 50 × (−4) = −200 이므로 $w \leftarrow -4 - 0.1 \times (-200)$
8. 곱셈을 한다: 0.1 × (−200) = −20 이므로 $w \leftarrow -4 - (-20)$
9. 뺄셈을 한다: −4 − (−20) = 16 이므로 $w^2 = 16$
10. [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 구한다: $f(1) = 25 \times 1^2 = 25$, $f(-4) = 25 \times 16 = 400$, $f(16) = 25 \times 256 = 6400$

**답**: $w$가 1 → −4 → 16으로 바닥 0을 넘나들며 커지고, $f$도 25 → 400 → 6400으로 커진다 (보폭 0.1이 이 우물에는 너무 크다)

</details>

### 문제 10

[Lec02 9.3](../../Lec02_%EC%8B%A0%EA%B2%BD%EB%A7%9D_%ED%95%99%EC%8A%B5.md#93-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0-%EC%B5%9C%EC%A0%81%ED%99%94%EC%99%80-%EC%9E%85%EB%A0%A5-%EC%B5%9C%EC%A0%81%ED%99%94)은 [파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0)를 고정하고 입력을 바꿔 점수를 키우는 **그래디언트 상승** $x \leftarrow x + \eta \nabla S(x)$을 소개한다. 점수가 $S(x_1, x_2) = 4x_1 - 2x_1^2 + 2x_2 - x_2^2$이고 지금 $x = (0.5, 0)$, $\eta = 0.1$일 때 한 번 갱신한 $x$를 구하라. (그래디언트는 $\nabla S = (4 - 4x_1,\ 2 - 2x_2)$이다.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $x = (x_1, x_2) = (0.5, 0)$ (지금 입력)
- $\eta = 0.1$ (한 걸음의 크기)
- $\nabla S = (4 - 4x_1,\ 2 - 2x_2)$ (그래디언트 식)

**풀이**
1. 식을 그대로 쓴다: $x \leftarrow x + \eta\, \nabla S(x)$ (올라가는 방향이므로 더한다)
2. 값을 대입한다: $x \leftarrow (0.5, 0) + 0.1 \times (4 - 4 \times 0.5,\ 2 - 2 \times 0)$
3. 그래디언트의 곱셈을 한다: 4 × 0.5 = 2, 2 × 0 = 0 이므로 $x \leftarrow (0.5, 0) + 0.1 \times (4 - 2,\ 2 - 0)$
4. 그래디언트의 뺄셈을 한다: 4 − 2 = 2, 2 − 0 = 2 이므로 $x \leftarrow (0.5, 0) + 0.1 \times (2, 2)$
5. [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0)을 칸마다 곱한다: 0.1 × 2 = 0.2 (두 칸 모두) 이므로 $x \leftarrow (0.5, 0) + (0.2, 0.2)$
6. 칸끼리 더한다: 0.5 + 0.2 = 0.7, 0 + 0.2 = 0.2 이므로 $x = (0.7, 0.2)$

**답**: $x = (0.7, 0.2)$ (그래디언트가 0이 되는 $x = (1, 1)$, 곧 $\arg\max S$ 쪽으로 다가간다)

</details>
