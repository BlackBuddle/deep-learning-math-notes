# 예제: 최솟값과 볼록 함수

개념 노트: [M09_최솟값과_볼록함수](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/02_%EB%AF%B8%EB%B6%84/M09_%EC%B5%9C%EC%86%9F%EA%B0%92%EA%B3%BC_%EB%B3%BC%EB%A1%9D%ED%95%A8%EC%88%98.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 문제 10개, 쉬운 것부터 어려운 것 순서다. 노트의 비볼록 함수 $g(x) = x^4 - 3x^2 + x$ ([기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $g'(x) = 4x^3 - 6x + 1$)를 자주 쓴다.

## 기본 (직접 대입)

### 문제 1
$g(x) = x^4 - 3x^2 + x$에서 $x = 1$과 $x = -1$의 높이 $g(1)$, $g(-1)$을 구하고 어느 쪽이 더 낮은지 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $g(x) = x^4 - 3x^2 + x$ (높이를 주는 식)
- $x = 1$, $x = -1$ (넣는 값)

**풀이**
1. 식을 그대로 쓴다: $g(x) = x^4 - 3x^2 + x$
2. $x = 1$을 대입한다: $g(1) = 1^4 - 3 \times 1^2 + 1$
3. 거듭제곱을 한다: $1^4 = 1$, $1^2 = 1$ 이므로 $g(1) = 1 - 3 \times 1 + 1$
4. 곱셈을 한다: $3 \times 1 = 3$ 이므로 $g(1) = 1 - 3 + 1$
5. 계산한다: $1 - 3 = -2$, $-2 + 1 = -1$ 이므로 $g(1) = -1$
6. $x = -1$을 대입한다: $g(-1) = (-1)^4 - 3 \times (-1)^2 + (-1)$
7. 거듭제곱을 한다: $(-1)^4 = 1$, $(-1)^2 = 1$ 이므로 $g(-1) = 1 - 3 \times 1 + (-1)$
8. 곱셈을 한다: $3 \times 1 = 3$ 이므로 $g(-1) = 1 - 3 + (-1)$
9. 계산한다: $1 - 3 = -2$, $-2 + (-1) = -3$ 이므로 $g(-1) = -3$
10. 비교한다: $-3 < -1$ 이므로 $x = -1$이 더 낮다.

**답**: $g(1) = -1$, $g(-1) = -3$. $x = -1$ 쪽이 더 낮다 (숫자가 작을수록 낮은 곳)

</details>

### 문제 2
$g'(x) = 4x^3 - 6x + 1$에서 $x = 1$과 $x = 0$의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)를 구하라. 두 곳이 바닥($g' = 0$)인가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $g'(x) = 4x^3 - 6x + 1$ ([기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)를 주는 식)
- $x = 1$, $x = 0$

**풀이**
1. 식을 그대로 쓴다: $g'(x) = 4x^3 - 6x + 1$
2. $x = 1$을 대입한다: $g'(1) = 4 \times 1^3 - 6 \times 1 + 1$
3. 거듭제곱을 한다: $1^3 = 1$ 이므로 $g'(1) = 4 \times 1 - 6 \times 1 + 1$
4. 곱셈을 한다: $4 \times 1 = 4$, $6 \times 1 = 6$ 이므로 $g'(1) = 4 - 6 + 1$
5. 계산한다: $4 - 6 = -2$, $-2 + 1 = -1$ 이므로 $g'(1) = -1$
6. $x = 0$을 대입한다: $g'(0) = 4 \times 0^3 - 6 \times 0 + 1$
7. 거듭제곱과 곱셈을 한다: $0^3 = 0$, $4 \times 0 = 0$, $6 \times 0 = 0$ 이므로 $g'(0) = 0 - 0 + 1$
8. 계산한다: $0 - 0 + 1 = 1$ 이므로 $g'(0) = 1$

**답**: $g'(1) = -1$, $g'(0) = 1$. 둘 다 0이 아니므로 바닥이 아니다 ($x = 1$은 내리막이라 오른쪽에 바닥 $x \approx 1.13$이 있다)

</details>

### 문제 3
볼록 판별 $f\!\left(\frac{a+b}{2}\right) \le \frac{f(a) + f(b)}{2}$를 $f(x) = x^2$, $a = 1$, $b = 5$로 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $f(x) = x^2$
- $a = 1$, $b = 5$ (그래프 위 두 점의 x 위치)

**풀이**
1. 식을 그대로 쓴다: $f\!\left(\frac{a+b}{2}\right) \le \frac{f(a) + f(b)}{2}$
2. 값을 대입한다: $f\!\left(\frac{1+5}{2}\right) \le \frac{f(1) + f(5)}{2}$
3. 가운데 위치를 계산한다: $\frac{1 + 5}{2} = 3$ 이므로 왼쪽은 $f(3)$
4. 왼쪽 값을 구한다: $f(3) = 3^2 = 9$
5. 두 점의 높이를 구한다: $f(1) = 1^2 = 1$, $f(5) = 5^2 = 25$
6. 오른쪽(평균)을 구한다: $\frac{1 + 25}{2} = \frac{26}{2} = 13$
7. 비교한다: $9 \le 13$ 이므로 가운데가 평균 이하이다.

**답**: $9 \le 13$ 이므로 이 두 점에서는 그래프가 직선보다 아래이다 (볼록 조건을 만족)

</details>

### 문제 4
[볼록 함수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#convex-function-%EB%B3%BC%EB%A1%9D-%ED%95%A8%EC%88%98) $f(x) = (x-3)^2$ ([기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $2(x-3)$)에서 $x = 0$에서 출발해 [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0) 0.1로 한 걸음 가라. 새 x를 구하고, 바닥 3까지의 거리 $3 - x$가 처음 거리의 몇 배가 되었는지 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x = 0$ (출발점)
- [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0) $0.1$
- [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $f'(x) = 2(x-3)$

**풀이**
1. [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)를 구한다. 식을 그대로 쓴다: $f'(x) = 2(x-3)$
2. 값을 대입한다: $f'(0) = 2 \times (0 - 3)$
3. 괄호 안을 계산한다: $0 - 3 = -3$ 이므로 $f'(0) = 2 \times (-3)$
4. 곱셈을 한다: $2 \times (-3) = -6$
5. 갱신식을 그대로 쓴다: $\text{새 } x = x - \text{학습률} \times f'(x)$
6. 값을 대입한다: $\text{새 } x = 0 - 0.1 \times (-6)$
7. 곱셈을 한다: $0.1 \times (-6) = -0.6$ 이므로 $\text{새 } x = 0 - (-0.6)$
8. 빼기 음수는 더하기와 같다: $0 + 0.6 = 0.6$
9. 거리를 비교한다. 처음 거리: $3 - 0 = 3$, 새 거리: $3 - 0.6 = 2.4$
10. 나눗셈을 한다: $2.4 \div 3 = 0.8$

**답**: 새 $x = 0.6$. 바닥까지의 거리가 3에서 2.4로, 0.8배가 되었다 ([볼록 함수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#convex-function-%EB%B3%BC%EB%A1%9D-%ED%95%A8%EC%88%98)는 한 걸음마다 바닥에 꾸준히 다가간다)

</details>

### 문제 5
$g(x) = x^4 - 3x^2 + x$가 볼록인지 두 점 $x = -1$, $x = 1$로 확인하라. (문제 1에서 $g(-1) = -3$, $g(1) = -1$을 구했다)

<details><summary>풀이와 답</summary>

**주어진 값**
- $g(x) = x^4 - 3x^2 + x$
- $a = -1$, $b = 1$
- $g(-1) = -3$, $g(1) = -1$

**풀이**
1. 식을 그대로 쓴다: $g\!\left(\frac{a+b}{2}\right) \le \frac{g(a) + g(b)}{2}$
2. 값을 대입한다: $g\!\left(\frac{-1+1}{2}\right) \le \frac{g(-1) + g(1)}{2}$
3. 가운데 위치를 계산한다: $\frac{-1 + 1}{2} = 0$ 이므로 왼쪽은 $g(0)$
4. 왼쪽 값을 구한다: $g(0) = 0^4 - 3 \times 0^2 + 0 = 0$
5. 오른쪽(평균)을 구한다: $\frac{-3 + (-1)}{2} = \frac{-4}{2} = -2$
6. 비교한다: $0 \le -2$ 인가? $0$은 $-2$보다 크므로 성립하지 않는다.

**답**: $0 > -2$ 로 판별 식이 깨지므로 $g$는 **볼록이 아니다** (두 바닥 사이에 언덕이 있어 그래프가 직선보다 위로 솟는다)

</details>

### 문제 6
$g(x) = x^4 - 3x^2 + x$의 언덕 꼭대기($x \approx 0.17$) 양쪽에서 출발해 [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0) 0.01로 한 걸음씩 가 보라. $x = 1$과 $x = -1$에서 출발하면 각각 어느 쪽으로 움직이는가? ($g'(-1) = 3$, $g'(1) = -1$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $g'(1) = -1$, $g'(-1) = 3$ (문제 2와 같은 식으로 구한 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0))
- [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0) $0.01$

**풀이**
1. 갱신식을 그대로 쓴다: $\text{새 } x = x - \text{학습률} \times g'(x)$
2. $x = 1$에서 출발한다. 값을 대입한다: $\text{새 } x = 1 - 0.01 \times (-1)$
3. 곱셈을 한다: $0.01 \times (-1) = -0.01$ 이므로 $\text{새 } x = 1 - (-0.01)$
4. 빼기 음수는 더하기와 같다: $1 + 0.01 = 1.01$
5. $x = -1$에서 출발한다. 값을 대입한다: $\text{새 } x = -1 - 0.01 \times 3$
6. 곱셈을 한다: $0.01 \times 3 = 0.03$ 이므로 $\text{새 } x = -1 - 0.03$
7. 뺄셈을 한다: $-1 - 0.03 = -1.03$

**답**: $x = 1$은 $1.01$로 오른쪽(지역 바닥 1.13 쪽), $x = -1$은 $-1.03$으로 왼쪽(전역 바닥 −1.30 쪽)으로 간다. 언덕의 어느 쪽에서 출발했느냐가 도착할 바닥을 정한다.

</details>

### 문제 7
데이터 하나에서 [시그모이드](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sigmoid-%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C) 뒤에 [MSE](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#mse-mean-squared-error-%ED%8F%89%EA%B7%A0-%EC%A0%9C%EA%B3%B1-%EC%98%A4%EC%B0%A8)를 붙인 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 $L(-6) = 0.9951$, $L(0) = 0.25$, $L(-3) = 0.9074$이다. 두 점 $w = -6$, $w = 0$과 가운데 $w = -3$으로 볼록 판별을 하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $L(-6) = 0.9951$, $L(0) = 0.25$ (두 점의 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98))
- $L(-3) = 0.9074$ (가운데 점의 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98))
- 두 점의 가운데 위치 $\frac{-6 + 0}{2} = -3$

**풀이**
1. 식을 그대로 쓴다: $L\!\left(\frac{a+b}{2}\right) \le \frac{L(a) + L(b)}{2}$
2. 값을 대입한다: $L(-3) \le \frac{L(-6) + L(0)}{2}$
3. 오른쪽(두 점의 평균)을 구한다: $\frac{0.9951 + 0.25}{2}$
4. 분자를 더한다: $0.9951 + 0.25 = 1.2451$ 이므로 $\frac{1.2451}{2}$
5. 2로 나눈다: $1.2451 \div 2 = 0.6225$ (소수 넷째 자리까지)
6. 왼쪽 값을 비교한다: $L(-3) = 0.9074$
7. 비교한다: $0.9074 \le 0.6225$ 인가? $0.9074$가 더 크므로 성립하지 않는다.

**답**: 가운데 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) 0.9074가 평균 0.6225보다 위에 있어 판별 식이 깨진다. 이 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은 **볼록이 아니다** (그래서 [로지스틱 회귀](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#logistic-regression-%EB%A1%9C%EC%A7%80%EC%8A%A4%ED%8B%B1-%ED%9A%8C%EA%B7%80)에는 [MSE](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#mse-mean-squared-error-%ED%8F%89%EA%B7%A0-%EC%A0%9C%EA%B3%B1-%EC%98%A4%EC%B0%A8) 대신 [교차 엔트로피](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cross-entropy-%EA%B5%90%EC%B0%A8-%EC%97%94%ED%8A%B8%EB%A1%9C%ED%94%BC)를 쓴다)

</details>

### 문제 8
같은 세 점에서 이진 [교차 엔트로피](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cross-entropy-%EA%B5%90%EC%B0%A8-%EC%97%94%ED%8A%B8%EB%A1%9C%ED%94%BC)(BCE) [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 $L(-6) = 6.0025$, $L(0) = 0.6931$, $L(-3) = 3.0486$이다. 문제 7과 같은 방법으로 볼록 판별을 하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $L(-6) = 6.0025$, $L(0) = 0.6931$ (두 점의 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98))
- $L(-3) = 3.0486$ (가운데 점의 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98))

**풀이**
1. 식을 그대로 쓴다: $L\!\left(\frac{a+b}{2}\right) \le \frac{L(a) + L(b)}{2}$
2. 값을 대입한다: $L(-3) \le \frac{L(-6) + L(0)}{2}$
3. 오른쪽(두 점의 평균)을 구한다: $\frac{6.0025 + 0.6931}{2}$
4. 분자를 더한다: $6.0025 + 0.6931 = 6.6956$ 이므로 $\frac{6.6956}{2}$
5. 2로 나눈다: $6.6956 \div 2 = 3.3478$
6. 왼쪽 값을 비교한다: $L(-3) = 3.0486$
7. 비교한다: $3.0486 \le 3.3478$ 이므로 성립한다.

**답**: 가운데 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) 3.0486이 평균 3.3478보다 아래이므로 이 세 점에서는 볼록 조건을 만족한다 (BCE는 볼록이다. 한 번의 확인으로 증명되지는 않지만, 어긋나지 않았다)

</details>

### 문제 9
[Lec02 3.1](../../Lec02_%EC%8B%A0%EA%B2%BD%EB%A7%9D_%ED%95%99%EC%8A%B5.md#31-%EC%96%B4%EB%96%A4-%EC%A7%80%ED%98%95%EC%9D%B4-%EC%B5%9C%EC%A0%81%ED%99%94%ED%95%98%EA%B8%B0-%EC%96%B4%EB%A0%A4%EC%9A%B4%EA%B0%80)은 지형에 따라 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 달라 최적화의 어려움이 다르다고 설명한다. $\theta = 2$에서 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 (가) 가파른 그릇 4, (나) 거의 평평한 곳 0.02, (다) 완전히 평평한 계단 0일 때, [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0) 0.5로 한 걸음 간 새 $\theta$를 각각 구하라. ($\theta \leftarrow \theta - \eta\,\text{기울기}$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $\theta = 2$ (지금 위치)
- $\eta = 0.5$ ([학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0))
- [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0): (가) 4, (나) 0.02, (다) 0

**풀이**
1. 식을 그대로 쓴다: $\theta \leftarrow \theta - \eta \times \text{기울기}$
2. (가)를 대입한다: $\theta \leftarrow 2 - 0.5 \times 4$
3. 곱셈을 한다: $0.5 \times 4 = 2$ 이므로 $\theta \leftarrow 2 - 2$
4. 뺄셈을 한다: $2 - 2 = 0$
5. (나)를 대입한다: $\theta \leftarrow 2 - 0.5 \times 0.02$
6. 곱셈을 한다: $0.5 \times 0.02 = 0.01$ 이므로 $\theta \leftarrow 2 - 0.01$
7. 뺄셈을 한다: $2 - 0.01 = 1.99$
8. (다)를 대입한다: $\theta \leftarrow 2 - 0.5 \times 0$
9. 곱셈과 뺄셈을 한다: $0.5 \times 0 = 0$ 이므로 $\theta \leftarrow 2 - 0 = 2$

**답**: (가) $\theta = 0$, (나) $\theta = 1.99$, (다) $\theta = 2$. 거의 평평하면 걸음이 아주 작아 진행이 느리고([기울기 소실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#vanishing-gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0-%EC%86%8C%EC%8B%A4)), 완전히 평평하면 전혀 움직이지 않는다.

</details>

### 문제 10
[Lec01 5.1](../../Lec01_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%86%8C%EA%B0%9C.md#51-%EA%B2%BD%EC%82%AC%ED%95%98%EA%B0%95%EB%B2%95)의 목표 $\theta^* = \arg\min_\theta J(\theta)$는 $J$가 가장 작은 $\theta$를 찾는 것이다. $J(\theta) = (\theta - 2)^2 + 1$일 때 후보 $\theta = 0, 1, 2, 3$의 $J$를 구하고 $\theta^*$를 고르라. 이 $J$는 바닥이 몇 개인가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $J(\theta) = (\theta - 2)^2 + 1$ ([손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98))
- 후보 $\theta = 0, 1, 2, 3$

**풀이**
1. 식을 그대로 쓴다: $J(\theta) = (\theta - 2)^2 + 1$
2. $\theta = 0$을 대입한다: $J(0) = (0 - 2)^2 + 1$
3. 괄호 안을 계산한 뒤 제곱한다: $0 - 2 = -2$, $(-2)^2 = 4$ 이므로 $J(0) = 4 + 1 = 5$
4. $\theta = 1$을 대입한다: $J(1) = (1 - 2)^2 + 1$
5. 계산한다: $1 - 2 = -1$, $(-1)^2 = 1$ 이므로 $J(1) = 1 + 1 = 2$
6. $\theta = 2$를 대입한다: $J(2) = (2 - 2)^2 + 1$
7. 계산한다: $2 - 2 = 0$, $0^2 = 0$ 이므로 $J(2) = 0 + 1 = 1$
8. $\theta = 3$을 대입한다: $J(3) = (3 - 2)^2 + 1$
9. 계산한다: $3 - 2 = 1$, $1^2 = 1$ 이므로 $J(3) = 1 + 1 = 2$
10. 가장 작은 값을 고른다: 5, 2, 1, 2 중 가장 작은 것은 1이고 그때의 $\theta$는 2이다.

**답**: $J$는 5, 2, 1, 2이고 $\theta^* = 2$ (최솟값 $J = 1$). 그릇 모양의 [볼록 함수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#convex-function-%EB%B3%BC%EB%A1%9D-%ED%95%A8%EC%88%98)라 바닥이 하나뿐이고, [지역 최솟값](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#local-minimum-%EC%A7%80%EC%97%AD-%EC%B5%9C%EC%86%9F%EA%B0%92)이 곧 [전역 최솟값](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#global-minimum-%EC%A0%84%EC%97%AD-%EC%B5%9C%EC%86%9F%EA%B0%92)이다.

</details>
