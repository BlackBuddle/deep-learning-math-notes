# 예제: argmin과 argmax

개념 노트: [MM01_argmin과_argmax](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/02_%EB%AF%B8%EB%B6%84/MM01_argmin%EA%B3%BC_argmax.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 칸 번호는 0부터 센다.

## 기본 (직접 대입)

### 문제 1

값 $v = [5,\ 2,\ 7,\ 2]$에서 최솟값 $\min$과 그 위치 $\arg\min$을 구하라. (같은 값이 여럿이면 맨 앞 칸을 고른다.)

<details><summary>풀이와 답</summary>

**주어진 값**
- $v = [5, 2, 7, 2]$ (칸 0 = 5, 칸 1 = 2, 칸 2 = 7, 칸 3 = 2)

**풀이**
1. 식을 그대로 쓴다: $\min = \text{가장 작은 값}$, $\arg\min = \text{그 값의 위치}$
2. 값을 대입한다: $\min$ = (5, 2, 7, 2 중 가장 작은 값)
3. 앞에서부터 둘씩 비교한다: 5와 2 중 작은 것은 2, 2와 7 중 작은 것은 2, 2와 2 중 작은 것은 2 이므로 $\min = 2$
4. 그 값이 있는 칸을 찾는다: 칸 1과 칸 3 (후보 두 곳)
5. 맨 앞 칸을 고른다: 1 < 3 이므로 $\arg\min = 1$

**답**: $\min = 2$, $\arg\min = 1$

</details>

### 문제 2

고양이, 개, 새 세 범주의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 $[0.1,\ 0.6,\ 0.3]$이다. 예측 범주의 칸 번호 $\arg\max$와 그 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) $\max$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 칸 0 (고양이) = 0.1
- 칸 1 (개) = 0.6
- 칸 2 (새) = 0.3

**풀이**
1. 식을 그대로 쓴다: $\max = \text{가장 큰 값}$, $\arg\max = \text{그 값의 위치}$
2. 값을 대입한다: $\max$ = (0.1, 0.6, 0.3 중 가장 큰 값)
3. 앞에서부터 둘씩 비교한다: 0.1과 0.6 중 큰 것은 0.6, 0.6과 0.3 중 큰 것은 0.6 이므로 $\max = 0.6$
4. 그 값이 있는 칸을 찾는다: 0.6은 칸 1에 있으므로 $\arg\max = 1$ (개)

**답**: $\arg\max = 1$ (개), $\max = 0.6$

</details>

### 문제 3

$f(x) = (x-4)^2 + 2$를 $x = 0, 1, 2, 3, 4, 5, 6$에서 계산해 $\min f$와 $\arg\min f$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $f(x) = (x-4)^2 + 2$ (함수)
- $x = 0, 1, 2, 3, 4, 5, 6$ (입력 후보)

**풀이**
1. 식을 그대로 쓴다: $f(x) = (x-4)^2 + 2$
2. $x = 0$을 대입한다: $f(0) = (0-4)^2 + 2 = (-4)^2 + 2 = 16 + 2 = 18$
3. $x = 1$을 대입한다: $f(1) = (1-4)^2 + 2 = (-3)^2 + 2 = 9 + 2 = 11$
4. $x = 2$를 대입한다: $f(2) = (2-4)^2 + 2 = (-2)^2 + 2 = 4 + 2 = 6$
5. $x = 3$을 대입한다: $f(3) = (3-4)^2 + 2 = (-1)^2 + 2 = 1 + 2 = 3$
6. $x = 4$를 대입한다: $f(4) = (4-4)^2 + 2 = 0^2 + 2 = 0 + 2 = 2$
7. $x = 5$를 대입한다: $f(5) = (5-4)^2 + 2 = 1^2 + 2 = 1 + 2 = 3$
8. $x = 6$을 대입한다: $f(6) = (6-4)^2 + 2 = 2^2 + 2 = 4 + 2 = 6$
9. 값을 모아 비교한다: 18, 11, 6, 3, 2, 3, 6 중 가장 작은 것은 2 이고, 그 값은 $x = 4$에서 나온다.

**답**: $\min f = 2$, $\arg\min f = 4$

</details>

### 문제 4

$h(x) = 5 - (x-2)^2$를 $x = 0, 1, 2, 3, 4$에서 계산해 $\max h$와 $\arg\max h$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $h(x) = 5 - (x-2)^2$ (함수, 제곱을 빼므로 위로 볼록한 모양)
- $x = 0, 1, 2, 3, 4$ (입력 후보)

**풀이**
1. 식을 그대로 쓴다: $h(x) = 5 - (x-2)^2$
2. $x = 0$을 대입한다: $h(0) = 5 - (0-2)^2 = 5 - (-2)^2 = 5 - 4 = 1$
3. $x = 1$을 대입한다: $h(1) = 5 - (1-2)^2 = 5 - (-1)^2 = 5 - 1 = 4$
4. $x = 2$를 대입한다: $h(2) = 5 - (2-2)^2 = 5 - 0^2 = 5 - 0 = 5$
5. $x = 3$을 대입한다: $h(3) = 5 - (3-2)^2 = 5 - 1^2 = 5 - 1 = 4$
6. $x = 4$를 대입한다: $h(4) = 5 - (4-2)^2 = 5 - 2^2 = 5 - 4 = 1$
7. 값을 모아 비교한다: 1, 4, 5, 4, 1 중 가장 큰 것은 5 이고, 그 값은 $x = 2$에서 나온다.

**답**: $\max h = 5$, $\arg\max h = 2$

</details>

### 문제 5

[가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) $w$를 바꿔 가며 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 재 보니 $J(1) = 5$, $J(2) = 3$, $J(3) = 4$였다. [학습](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5)의 목표 $w^* = \arg\min_w J(w)$와 그때의 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $\min_w J(w)$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $J(1) = 5$ ($w = 1$일 때 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98))
- $J(2) = 3$ ($w = 2$일 때 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98))
- $J(3) = 4$ ($w = 3$일 때 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98))

**풀이**
1. 식을 그대로 쓴다: $w^* = \arg\min_w J(w)$ ([손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 가장 작아지는 $w$ 자체), $\min_w J(w)$ (그때의 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) 값)
2. [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)만 모아 쓴다: 5, 3, 4
3. 가장 작은 값을 찾는다: 5, 3, 4 중 가장 작은 것은 3 이므로 $\min_w J(w) = 3$
4. 그 값을 만드는 $w$를 찾는다: 3은 $w = 2$에서 나왔으므로 $w^* = 2$

**답**: $w^* = 2$, $\min_w J(w) = 3$ (우리가 원하는 것은 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) 3이 아니라 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) 2다)

</details>

### 문제 6

점수 $s = [1.0,\ 3.0,\ 2.0]$에 [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)를 씌워 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구하고, 점수의 $\arg\max$와 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)의 $\arg\max$가 같은지 확인하라. ([소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4): $p_k = \frac{e^{s_k}}{\sum_j e^{s_j}}$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $s_0 = 1.0$, $s_1 = 3.0$, $s_2 = 2.0$ (점수)

**풀이**
1. 식을 그대로 쓴다: $p_k = \frac{e^{s_k}}{\sum_j e^{s_j}}$
2. 값을 대입한다 (Σ를 j = 0, 1, 2 세 항으로 펼친다): $p_k = \frac{e^{s_k}}{e^{1} + e^{3} + e^{2}}$
3. e의 거듭제곱을 구한다 (e는 약 2.718): $e^{1} = 2.7183$, $e^{3} = 20.0855$, $e^{2} = 7.3891$ 이므로 분모는 2.7183 + 20.0855 + 7.3891
4. 분모를 더한다: 2.7183 + 20.0855 = 22.8038, 22.8038 + 7.3891 = 30.1929
5. 칸 0의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0): $p_0 = \frac{2.7183}{30.1929}$ = 0.0900
6. 칸 1의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0): $p_1 = \frac{20.0855}{30.1929}$ = 0.6652
7. 칸 2의 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0): $p_2 = \frac{7.3891}{30.1929}$ = 0.2447
8. 점수의 [argmax](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#argmax-%EC%B5%9C%EB%8C%93%EA%B0%92-%EC%9C%84%EC%B9%98)를 구한다: 1.0, 3.0, 2.0 중 가장 큰 것은 3.0 이므로 칸 1
9. [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)의 [argmax](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#argmax-%EC%B5%9C%EB%8C%93%EA%B0%92-%EC%9C%84%EC%B9%98)를 구한다: 0.0900, 0.6652, 0.2447 중 가장 큰 것은 0.6652 이므로 칸 1

**답**: [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) $[0.0900, 0.6652, 0.2447]$, 두 [argmax](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#argmax-%EC%B5%9C%EB%8C%93%EA%B0%92-%EC%9C%84%EC%B9%98)는 모두 1로 같다 ([소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)는 크기 순서를 바꾸지 않는다)

### 문제 7

두 [파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0)의 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 $J(w, b) = (w-1)^2 + (b+2)^2$이다. 후보 $(w, b)$ = (0, 0), (1, −2), (2, −1), (1, 0) 중 $\arg\min$은 어느 것인가?

<details><summary>풀이와 답</summary>

**주어진 값**
- $J(w, b) = (w-1)^2 + (b+2)^2$ ([손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98))
- 후보 (0, 0), (1, −2), (2, −1), (1, 0)

**풀이**
1. 식을 그대로 쓴다: $J(w, b) = (w-1)^2 + (b+2)^2$
2. (0, 0)을 대입한다: $J = (0-1)^2 + (0+2)^2 = (-1)^2 + 2^2 = 1 + 4 = 5$
3. (1, −2)를 대입한다: $J = (1-1)^2 + (-2+2)^2 = 0^2 + 0^2 = 0 + 0 = 0$
4. (2, −1)을 대입한다: $J = (2-1)^2 + (-1+2)^2 = 1^2 + 1^2 = 1 + 1 = 2$
5. (1, 0)을 대입한다: $J = (1-1)^2 + (0+2)^2 = 0^2 + 2^2 = 0 + 4 = 4$
6. 값을 비교한다: 5, 0, 2, 4 중 가장 작은 것은 0 이고, 두 번째 후보에서 나온다.

**답**: $\arg\min = (1, -2)$, $\min = 0$ (위치가 한 칸이 아니라 두 값의 쌍일 수도 있다)

</details>

### 문제 8

$v = [3,\ 1,\ 3,\ 1]$에서 $\arg\max v$와 $\arg\min v$를 구하라. 또 $-v$의 $\arg\max$가 $v$의 $\arg\min$과 같은지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $v = [3, 1, 3, 1]$ (칸 0 = 3, 칸 1 = 1, 칸 2 = 3, 칸 3 = 1)

**풀이**
1. 식을 그대로 쓴다: $\arg\max v = \text{가장 큰 값의 위치}$, $\arg\min v = \text{가장 작은 값의 위치}$ (같은 값이 여럿이면 맨 앞 칸)
2. 가장 큰 값을 찾는다: 3, 1, 3, 1 중 가장 큰 것은 3, 3이 있는 칸은 칸 0과 칸 2 이므로 맨 앞인 칸 0, $\arg\max v = 0$
3. 가장 작은 값을 찾는다: 가장 작은 것은 1, 1이 있는 칸은 칸 1과 칸 3 이므로 맨 앞인 칸 1, $\arg\min v = 1$
4. 부호를 바꾼다: $-v = [-3, -1, -3, -1]$
5. $-v$에서 가장 큰 값을 찾는다: −3, −1, −3, −1 중 가장 큰 것은 −1, −1이 있는 칸은 칸 1과 칸 3 이므로 맨 앞인 칸 1, $\arg\max(-v) = 1$
6. 비교한다: $\arg\max(-v) = 1 = \arg\min v$

**답**: $\arg\max v = 0$, $\arg\min v = 1$, $\arg\max(-v) = 1$로 $\arg\min v$와 같다

</details>

### 문제 9

[Lec01 5.1](../../Lec01_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%86%8C%EA%B0%9C.md#51-%EA%B2%BD%EC%82%AC%ED%95%98%EA%B0%95%EB%B2%95)의 [학습](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5) 목표는 $\theta^* = \arg\min_\theta \frac{1}{N}\sum_i L(f_\theta(x_i), y_i)$이다. 데이터가 $N = 3$개이고, 후보 $\theta = 1$의 데이터별 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 $[0.5,\ 1.0,\ 1.5]$, 후보 $\theta = 2$의 데이터별 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 $[0.2,\ 0.4,\ 1.2]$일 때, 두 후보의 평균 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 구하고 $\theta^*$를 고르라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $N = 3$ (데이터 개수)
- $\theta = 1$: $L_1 = 0.5$, $L_2 = 1.0$, $L_3 = 1.5$ (데이터별 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98))
- $\theta = 2$: $L_1 = 0.2$, $L_2 = 0.4$, $L_3 = 1.2$

**풀이**
1. 식을 그대로 쓴다: $J(\theta) = \frac{1}{N}\sum_i L_i$ (Σ는 모든 데이터의 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)을 더하라는 뜻)
2. $\theta = 1$에 값을 대입한다 (Σ를 i = 1, 2, 3 세 항으로 펼친다): $J(1) = \frac{1}{3}(0.5 + 1.0 + 1.5)$
3. 괄호 안을 더한다: 0.5 + 1.0 + 1.5 = 3.0 이므로 $J(1) = \frac{1}{3} \times 3.0$
4. 나눗셈을 한다: 3.0 ÷ 3 = 1.0 이므로 $J(1) = 1.0$
5. $\theta = 2$에 값을 대입한다: $J(2) = \frac{1}{3}(0.2 + 0.4 + 1.2)$
6. 괄호 안을 더한다: 0.2 + 0.4 + 1.2 = 1.8 이므로 $J(2) = \frac{1}{3} \times 1.8$
7. 나눗셈을 한다: 1.8 ÷ 3 = 0.6 이므로 $J(2) = 0.6$
8. 비교한다: 1.0과 0.6 중 작은 것은 0.6 이고, $\theta = 2$에서 나온다.

**답**: $J(1) = 1.0$, $J(2) = 0.6$ 이므로 $\theta^* = 2$ (우리가 얻고 싶은 것은 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) 0.6이 아니라 그 [파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0) 2다)

</details>

### 문제 10

[Lec05 6.3](../../Lec05_%EA%B7%B8%EB%9E%98%ED%94%84_%EC%8B%A0%EA%B2%BD%EB%A7%9D.md#63-%EC%B5%9C%EC%86%8C-%EC%A7%91%EA%B3%84%EB%A1%9C-%EC%B5%9C%EB%8B%A8-%EA%B2%BD%EB%A1%9C-%ED%92%80%EA%B8%B0)의 벨만-포드는 $d_v \leftarrow \min_u (d_u + \text{cost}(u, v))$로 거리를 갱신한다. 노드 $v$의 이웃 세 개가 $(d_u, \text{cost}) = (3, 2),\ (1, 5),\ (2, 2)$일 때 새 $d_v$를 구하고, 어느 이웃(칸 번호)이 그 값을 줬는지 $\arg\min$으로 말하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 이웃 0: $d_u = 3$, $\text{cost} = 2$
- 이웃 1: $d_u = 1$, $\text{cost} = 5$
- 이웃 2: $d_u = 2$, $\text{cost} = 2$

**풀이**
1. 식을 그대로 쓴다: $d_v \leftarrow \min_u (d_u + \text{cost}(u, v))$
2. 값을 대입한다 (이웃 세 개를 펼친다): $d_v \leftarrow \min(3 + 2,\ 1 + 5,\ 2 + 2)$
3. 이웃마다 더한다: 3 + 2 = 5, 1 + 5 = 6, 2 + 2 = 4 이므로 $d_v \leftarrow \min(5, 6, 4)$
4. 가장 작은 값을 찾는다: 5, 6, 4 중 가장 작은 것은 4 이므로 $d_v = 4$
5. 그 값이 있는 칸을 찾는다: 4는 칸 2에 있으므로 $\arg\min = 2$

**답**: $d_v = 4$, $\arg\min = 2$ (이웃 2를 거치는 길이 가장 짧다. 이웃 1은 $d_u$가 가장 작아도 cost가 커서 진다)

</details>
