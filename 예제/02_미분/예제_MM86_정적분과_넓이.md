# 예제: 정적분과 넓이

개념 노트: [MM86_정적분과_넓이](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/02_%EB%AF%B8%EB%B6%84/MM86_%EC%A0%95%EC%A0%81%EB%B6%84%EA%B3%BC_%EB%84%93%EC%9D%B4.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 문제 번호 순서는 쉬운 것에서 어려운 것, 마지막 둘은 강의 내용과 잇는 문제다. 역도함수 공식은 $\int x^n\,dx = \frac{x^{n+1}}{n+1}$, $\int e^x\,dx = e^x$이다.

## 기본 (직접 대입)

### 문제 1
$f(x) = x$, 구간 $[0, 2]$를 직사각형 $n = 4$개(오른쪽 끝 높이)로 나눈 [리만 합](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#riemann-sum-%EB%A6%AC%EB%A7%8C-%ED%95%A9)을 구하고, 삼각형 넓이와 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**:
- $f(x) = x$ (곡선: 원점에서 오르는 직선)
- $a = 0,\ b = 2$ (구간의 양 끝)
- $n = 4$ (직사각형 개수)

**풀이**
1. 식을 그대로 쓴다: $\sum_{i=1}^{n} f(x_i)\,\Delta x$, $\Delta x = \frac{b-a}{n}$, $x_i = a + i\,\Delta x$
2. 값을 대입한다: $\Delta x = \frac{2 - 0}{4}$
3. 폭을 계산한다: 2 ÷ 4 = 0.5 이므로 $\Delta x = 0.5$
4. 오른쪽 끝 x를 구한다: $x_i = 0 + i \times 0.5$ 이므로 $x_1 = 0.5,\ x_2 = 1,\ x_3 = 1.5,\ x_4 = 2$
5. 높이를 구한다 ($f(x) = x$라서 높이는 x 그대로): 0.5, 1, 1.5, 2
6. 더한다: 0.5 + 1 + 1.5 + 2 = 5 이므로 합 $= 5 \times 0.5$
7. 폭을 곱한다: 5 × 0.5 = 2.5
8. 삼각형 넓이로 확인한다: (밑변 2 × 높이 2) ÷ 2 = 2

**답**: [리만 합](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#riemann-sum-%EB%A6%AC%EB%A7%8C-%ED%95%A9) 2.5, 참값(삼각형) 2. 오른쪽 끝 높이는 오르는 곡선에서 계단 4개만큼 부풀려 0.5 크다

</details>

### 문제 2
$\int_0^2 x^3\,dx$를 기본 정리로 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**:
- $f(x) = x^3$ (곡선)
- $a = 0,\ b = 2$ (구간의 양 끝)

**풀이**
1. 역도함수를 구한다 ($n = 3$): $F(x) = \frac{x^{3+1}}{3+1} = \frac{x^4}{4}$
2. 식을 그대로 쓴다: $\int_a^b f(x)\,dx = F(b) - F(a)$
3. 값을 대입한다: $\int_0^2 x^3\,dx = \frac{2^4}{4} - \frac{0^4}{4}$
4. 네제곱한다: 2⁴ = 16, 0⁴ = 0 이므로 $\frac{16}{4} - \frac{0}{4}$
5. 나눈다: 16 ÷ 4 = 4, 0 ÷ 4 = 0 이므로 $4 - 0$
6. 뺀다: 4 − 0 = 4

**답**: 4

</details>

### 문제 3
$\int_0^1 e^x\,dx$를 구하라. ($e = 2.7183$, $e^0 = 1$)

<details><summary>풀이와 답</summary>

**주어진 값**:
- $f(x) = e^x$ (곡선)
- $a = 0,\ b = 1$ (구간의 양 끝)
- $e^1 = 2.7183$, $e^0 = 1$ (끝값 계산에 쓴다)

**풀이**
1. 역도함수를 구한다: $F(x) = e^x$ ($e^x$는 미분해도 자기 자신이라 적분해도 자기 자신)
2. 식을 그대로 쓴다: $\int_a^b f(x)\,dx = F(b) - F(a)$
3. 값을 대입한다: $\int_0^1 e^x\,dx = e^1 - e^0$
4. 숫자를 넣는다: $e^1 = 2.7183$, $e^0 = 1$ 이므로 $2.7183 - 1$
5. 뺀다: 2.7183 − 1 = 1.7183

**답**: 1.7183

</details>

### 문제 4
$\int_1^3 (2x + 1)\,dx$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**:
- $f(x) = 2x + 1$ (곡선)
- $a = 1,\ b = 3$ (구간의 양 끝)

**풀이**
1. 항마다 역도함수를 구한다: $2x = 2 \cdot x^1$이라 $2 \times \frac{x^2}{2} = x^2$, 상수 $1 = x^0$이라 $\frac{x^1}{1} = x$ 이므로 $F(x) = x^2 + x$
2. 식을 그대로 쓴다: $\int_a^b f(x)\,dx = F(b) - F(a)$
3. 값을 대입한다: $\int_1^3 (2x + 1)\,dx = (3^2 + 3) - (1^2 + 1)$
4. 제곱한다: 3² = 9, 1² = 1 이므로 $(9 + 3) - (1 + 1)$
5. 괄호를 계산한다: 9 + 3 = 12, 1 + 1 = 2 이므로 $12 - 2$
6. 뺀다: 12 − 2 = 10

**답**: 10 (밑변 2, 높이 3과 7 사이의 사다리꼴 넓이 (3 + 7) ÷ 2 × 2 = 10과 같다)

</details>

### 문제 5
수도꼭지에서 나오는 물의 세기가 $f(t) = 2t$ 리터/분이다($t$는 분). 0분부터 3분까지 나온 물의 총량은? (총량은 세기 그래프 아래 넓이이므로 $\int_0^3 f(t)\,dt$이고, $2t$의 역도함수는 $t^2$이다.)

<details><summary>풀이와 답</summary>

**주어진 값**:
- $f(t) = 2t$ (물의 세기, 리터/분)
- $a = 0,\ b = 3$ (분)
- $F(t) = t^2$ (역도함수)

**풀이**
1. 식을 그대로 쓴다: $\text{총량} = \int_a^b f(t)\,dt = F(b) - F(a)$
2. 값을 대입한다: $\int_0^3 2t\,dt = 3^2 - 0^2$
3. 제곱한다: 3² = 9, 0² = 0 이므로 $9 - 0$
4. 뺀다: 9 − 0 = 9
5. 삼각형 넓이로 확인한다: 밑변 3, 높이 $f(3) = 6$이라 (3 × 6) ÷ 2 = 9

**답**: 9 리터

</details>

### 문제 6
$[0, 1]$에서 $p(x) = 2(1 - x)$가 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 밀도인지(넓이 1인지) 확인하고 $P(x \le 0.5)$를 구하라. ($2(1-x) = 2 - 2x$의 역도함수는 $2x - x^2$이다.)

<details><summary>풀이와 답</summary>

**주어진 값**:
- $p(x) = 2(1-x)$ (밀도 후보, 0에서 1로 내려가는 직선)
- $F(x) = 2x - x^2$ (역도함수)
- $c = 0,\ d = 0.5$ ([확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구할 구간)

**풀이**
1. 식을 그대로 쓴다: $\int_0^1 p(x)\,dx = F(1) - F(0)$, $P(c \le x \le d) = F(d) - F(c)$
2. 전체 넓이에 대입한다: $F(1) - F(0) = (2 \times 1 - 1^2) - (2 \times 0 - 0^2)$
3. 계산한다: 2 × 1 − 1 = 1, 2 × 0 − 0 = 0 이므로 $1 - 0 = 1$
4. [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)에 대입한다: $P(0 \le x \le 0.5) = F(0.5) - F(0) = (2 \times 0.5 - 0.5^2) - 0$
5. 계산한다: 2 × 0.5 = 1, 0.5² = 0.25 이므로 $(1 - 0.25) - 0$
6. 뺀다: 1 − 0.25 = 0.75

**답**: 전체 넓이 1이라 밀도가 맞고, $P(x \le 0.5) = 0.75$ (작은 값 쪽에 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)이 몰려 있다)

</details>

### 문제 7
$[0, 2]$에서 $p(x) = c\,x$가 밀도가 되도록 상수 $c$를 구하고, 그 $c$로 $P(x \le 1)$을 구하라. ($c\,x$의 역도함수는 $c \cdot \frac{x^2}{2}$)

<details><summary>풀이와 답</summary>

**주어진 값**:
- $p(x) = c\,x$ (밀도, $c$는 모르는 상수)
- $[0, 2]$ (값의 범위)
- $F(x) = c \cdot \frac{x^2}{2}$ (역도함수)

**풀이**
1. 식을 그대로 쓴다: $\int_0^2 p(x)\,dx = F(2) - F(0) = 1$
2. 값을 대입한다: $c \cdot \frac{2^2}{2} - c \cdot \frac{0^2}{2} = 1$
3. 제곱한다: 2² = 4, 0² = 0 이므로 $c \cdot \frac{4}{2} - 0 = 1$
4. 나눈다: 4 ÷ 2 = 2 이므로 $2c = 1$
5. $c$를 구한다: 1 ÷ 2 = 0.5 이므로 $c = 0.5$
6. [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 식을 쓴다: $P(x \le 1) = F(1) - F(0)$, $F(x) = 0.5 \cdot \frac{x^2}{2} = \frac{x^2}{4}$
7. 대입한다: $P(x \le 1) = \frac{1^2}{4} - \frac{0^2}{4}$
8. 계산한다: 1 ÷ 4 = 0.25 이므로 $0.25 - 0$
9. 뺀다: 0.25 − 0 = 0.25

**답**: $c = 0.5$, $P(x \le 1) = 0.25$

</details>

### 문제 8
문제 6의 밀도 $p(x) = 2(1 - x)$ ($[0, 1]$)의 [기댓값](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#expectation-%EA%B8%B0%EB%8C%93%EA%B0%92) $E[x] = \int x\,p(x)\,dx$를 구하라. ($x \cdot 2(1-x) = 2x - 2x^2$의 역도함수는 $x^2 - \frac{2x^3}{3}$이다.)

<details><summary>풀이와 답</summary>

**주어진 값**:
- $p(x) = 2(1-x)$ (밀도)
- $x\,p(x) = 2x - 2x^2$ (피적분 함수)
- $G(x) = x^2 - \frac{2x^3}{3}$ (그 역도함수)

**풀이**
1. 식을 그대로 쓴다: $E[x] = \int_0^1 x\,p(x)\,dx = G(1) - G(0)$
2. 값을 대입한다: $E[x] = \left(1^2 - \frac{2 \times 1^3}{3}\right) - \left(0^2 - \frac{2 \times 0^3}{3}\right)$
3. 거듭제곱한다: 1² = 1, 1³ = 1, 0² = 0, 0³ = 0 이므로 $\left(1 - \frac{2 \times 1}{3}\right) - \left(0 - \frac{2 \times 0}{3}\right)$
4. 곱한다: 2 × 1 = 2, 2 × 0 = 0 이므로 $\left(1 - \frac{2}{3}\right) - (0 - 0)$
5. 괄호를 계산한다: 1 − 2/3 = 1/3, 0 − 0 = 0 이므로 $\frac{1}{3} - 0$
6. 나눈다: 1 ÷ 3 = 0.3333

**답**: $E[x] = \frac{1}{3} = 0.3333$ (작은 값 쪽에 몰린 밀도라 평균이 구간의 가운데 0.5보다 왼쪽이다)

</details>

### 문제 9
[MM50_확률_밀도와_정규분포](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/04_%ED%99%95%EB%A5%A0%EA%B3%BC_%EC%A0%95%EB%B3%B4/MM50_%ED%99%95%EB%A5%A0_%EB%B0%80%EB%8F%84%EC%99%80_%EC%A0%95%EA%B7%9C%EB%B6%84%ED%8F%AC.md)의 균등 분포: $[0, 0.5]$에서 $p(x) = 2$이다. 전체 넓이가 1인지 확인하고 $P(0.1 \le x \le 0.3)$과 $E[x]$를 구하라. (상수 2의 역도함수는 $2x$, $x \cdot 2 = 2x$의 역도함수는 $x^2$)

<details><summary>풀이와 답</summary>

**주어진 값**:
- $p(x) = 2$ ($[0, 0.5]$에서 높이가 일정한 밀도)
- $F(x) = 2x$ (밀도의 역도함수), $G(x) = x^2$ ($x\,p(x)$의 역도함수)
- $c = 0.1,\ d = 0.3$ ([확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 구할 구간)

**풀이**
1. 전체 넓이 식을 쓰고 대입한다: $\int_0^{0.5} 2\,dx = F(0.5) - F(0) = 2 \times 0.5 - 2 \times 0$
2. 계산한다: 2 × 0.5 = 1, 2 × 0 = 0 이므로 $1 - 0 = 1$
3. [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 식을 쓰고 대입한다: $P(0.1 \le x \le 0.3) = F(0.3) - F(0.1) = 2 \times 0.3 - 2 \times 0.1$
4. 곱한다: 2 × 0.3 = 0.6, 2 × 0.1 = 0.2 이므로 $0.6 - 0.2$
5. 뺀다: 0.6 − 0.2 = 0.4
6. [기댓값](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#expectation-%EA%B8%B0%EB%8C%93%EA%B0%92) 식을 쓰고 대입한다: $E[x] = \int_0^{0.5} x \cdot 2\,dx = G(0.5) - G(0) = 0.5^2 - 0^2$
7. 제곱한다: 0.5² = 0.25, 0² = 0 이므로 $0.25 - 0$
8. 뺀다: 0.25 − 0 = 0.25

**답**: 전체 넓이 1(밀도가 맞다), $P(0.1 \le x \le 0.3) = 0.4$ (밀도 2 × 폭 0.2), $E[x] = 0.25$ (구간 $[0, 0.5]$의 가운데)

</details>

### 문제 10
[MM07_리만_합과_보편_근사](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/06_%EA%B7%BC%EC%82%AC_%EC%9D%B4%EB%A1%A0/MM07_%EB%A6%AC%EB%A7%8C_%ED%95%A9%EA%B3%BC_%EB%B3%B4%ED%8E%B8_%EA%B7%BC%EC%82%AC.md)처럼 곡선을 직사각형으로 근사한다. $f(x) = x^2$, $[0, 1]$, $n = 4$에서 **왼쪽 끝** 높이를 쓴 [리만 합](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#riemann-sum-%EB%A6%AC%EB%A7%8C-%ED%95%A9)을 구하고, 오른쪽 끝 합 0.46875와 평균을 낸 값을 참값 $1/3 = 0.3333$과 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**:
- $f(x) = x^2$ (곡선)
- $a = 0,\ b = 1$, $n = 4$ (구간과 직사각형 개수)
- 오른쪽 끝 [리만 합](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#riemann-sum-%EB%A6%AC%EB%A7%8C-%ED%95%A9) $= 0.46875$ (개념 노트에서 구한 값)

**풀이**
1. 식을 그대로 쓴다: $\sum f(x_i)\,\Delta x$, $\Delta x = \frac{b-a}{n}$ (왼쪽 끝이라 $x_i = a + (i-1)\,\Delta x$)
2. 폭을 구한다: $\Delta x = \frac{1 - 0}{4} = 0.25$
3. 왼쪽 끝 x를 구한다: 0, 0.25, 0.5, 0.75
4. 높이를 구한다 ($x^2$에 넣는다): 0² = 0, 0.25² = 0.0625, 0.5² = 0.25, 0.75² = 0.5625
5. 더한다: 0 + 0.0625 + 0.25 + 0.5625 = 0.875 이므로 합 $= 0.875 \times 0.25$
6. 폭을 곱한다: 0.875 × 0.25 = 0.21875
7. 두 합을 더해 반으로 나눈다: (0.21875 + 0.46875) ÷ 2 = 0.6875 ÷ 2 = 0.34375
8. 참값과 비교한다: 0.21875 < 0.3333 < 0.46875 이고, 평균 0.34375는 참값 0.3333에 가깝다

**답**: 왼쪽 합 0.21875(모자람), 오른쪽 합 0.46875(넘침), 평균 0.34375. 참값 1/3이 두 합 사이에 있고, 직사각형을 늘릴수록 두 합이 참값으로 모인다

</details>
