## 기본 (직접 대입)

### 문제 1
x가 1에서 4로 바뀌는 동안 y가 3에서 15로 바뀌었다. 이 구간의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)는?

<details><summary>풀이와 답</summary>

**주어진 값**
- 처음 $x = 1$, 나중 $x = 4$ (가로 위치)
- 처음 $y = 3$, 나중 $y = 15$ (세로 위치)

**풀이**
1. 식을 그대로 쓴다: $\text{기울기} = \frac{\Delta y}{\Delta x} = \frac{y\text{가 변한 양}}{x\text{가 변한 양}}$
2. 값을 대입한다(Δ는 나중 − 처음): $\text{기울기} = \frac{15 - 3}{4 - 1}$
3. 분자(위)의 뺄셈을 한다: $15 - 3 = 12$ 이므로 $\frac{12}{4 - 1}$
4. 분모(아래)의 뺄셈을 한다: $4 - 1 = 3$ 이므로 $\frac{12}{3}$
5. 나눗셈을 한다: $12 \div 3 = 4$

**답**: [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) = 4

</details>

### 문제 2
직선 $y = 3x + 2$에서 $x = 1$일 때와 $x = 3$일 때의 y를 구해 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)를 계산하고, 식의 $x$ 앞의 수와 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $y = 3x + 2$ (직선)
- $x = 1$, $x = 3$ (두 점의 x)

**풀이**
1. y를 구한다. 식을 그대로 쓴다: $y = 3x + 2$
2. $x = 1$을 대입한다: $y = 3 \times 1 + 2$
3. 곱셈을 한 뒤 더한다: $3 \times 1 = 3$ 이므로 $y = 3 + 2 = 5$
4. $x = 3$을 대입한다: $y = 3 \times 3 + 2$
5. 곱셈을 한 뒤 더한다: $3 \times 3 = 9$ 이므로 $y = 9 + 2 = 11$
6. 두 점은 (1, 5)와 (3, 11)이다. [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) 식을 쓴다: $\text{기울기} = \frac{\Delta y}{\Delta x}$
7. 값을 대입한다: $\text{기울기} = \frac{11 - 5}{3 - 1}$
8. 뺄셈을 한다: $11 - 5 = 6$, $3 - 1 = 2$ 이므로 $\frac{6}{2}$
9. 나눗셈을 한다: $6 \div 2 = 3$

**답**: [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) = 3. 식의 $x$ 앞의 수 3과 같다 (직선은 어디서 재도 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 같다)

</details>

### 문제 3
$f(x) = x^3 + 2x + 5$를 미분한 $f'(x)$를 구하고, $x = 2$에서의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $f'(2)$를 구하라. (공식: $x^n$의 [미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#derivative-%EB%AF%B8%EB%B6%84)은 $n x^{n-1}$, $ax$의 [미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#derivative-%EB%AF%B8%EB%B6%84)은 $a$, 상수의 [미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#derivative-%EB%AF%B8%EB%B6%84)은 0, 더하기로 이어진 식은 하나씩 미분해 더한다)

<details><summary>풀이와 답</summary>

**주어진 값**
- $f(x) = x^3 + 2x + 5$ (세 항)
- 공식 $x^n \to n x^{n-1}$, $ax \to a$, 상수 $\to 0$
- $x = 2$ ([기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)를 구할 자리)

**풀이**
1. 식을 그대로 쓴다: $f'(x) = (x^3)' + (2x)' + (5)'$
2. 첫째 항에 $x^n \to n x^{n-1}$을 쓴다($n = 3$): $(x^3)' = 3 \times x^{3-1} = 3x^2$
3. 둘째 항에 $ax \to a$를 쓴다($a = 2$): $(2x)' = 2$
4. 셋째 항은 상수라 변하지 않으므로: $(5)' = 0$
5. 세 항을 더한다: $f'(x) = 3x^2 + 2 + 0 = 3x^2 + 2$
6. $x = 2$를 대입한다: $f'(2) = 3 \times 2^2 + 2$
7. 제곱을 먼저 한다: $2^2 = 4$ 이므로 $f'(2) = 3 \times 4 + 2$
8. 곱셈을 한다: $3 \times 4 = 12$ 이므로 $f'(2) = 12 + 2$
9. 덧셈을 한다: $12 + 2 = 14$

**답**: $f'(x) = 3x^2 + 2$, $f'(2) = 14$

</details>

### 문제 4
$y = x^2$의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)는 $2x$이다. $x = -3$에서의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)를 구하고, 값을 줄이려면 x를 늘려야 하는지 줄여야 하는지 판단하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $y = x^2$, [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) 공식 $2x$
- $x = -3$ (지금 자리)

**풀이**
1. 식을 그대로 쓴다: $\text{기울기} = 2x$
2. 값을 대입한다: $\text{기울기} = 2 \times (-3)$
3. 곱셈을 한다: $2 \times (-3) = -6$ (양수에 음수를 곱하면 음수)
4. 부호를 읽는다: [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 음수이므로 이 자리는 내리막이다.
5. 값을 줄이려면 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)와 반대로 움직인다: [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 음수(−)이므로 반대는 오른쪽(+), 곧 x를 늘린다.

**답**: [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) = −6 (내리막). x를 **늘려야** 값이 줄어든다 (x = 0의 바닥 쪽으로 간다)

</details>

### 문제 5
$y = x^2$의 $x = 2$에서의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)를 간격 $h$를 줄여 가며 구하라. $\frac{(2+h)^2 - 2^2}{h}$에서 $h = 1$, $h = 0.1$일 때 값을 구하고, 식을 정리해 $h$가 0에 가까워질 때 다가가는 값을 찾아라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $y = x^2$, [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)를 구할 자리 $x = 2$
- 간격 $h = 1$, $h = 0.1$

**풀이**
1. 식을 그대로 쓴다: $\frac{(2+h)^2 - 2^2}{h}$ (x가 2에서 2+h로 갈 때 y가 변한 양 ÷ x가 변한 양)
2. $h = 1$을 대입한다: $\frac{(2+1)^2 - 2^2}{1}$
3. 괄호 안을 계산한다: $2 + 1 = 3$ 이므로 $\frac{3^2 - 2^2}{1}$
4. 제곱을 한다: $3^2 = 9$, $2^2 = 4$ 이므로 $\frac{9 - 4}{1}$
5. 뺄셈과 나눗셈을 한다: $9 - 4 = 5$, $5 \div 1 = 5$
6. $h = 0.1$을 대입한다: $\frac{(2+0.1)^2 - 2^2}{0.1}$
7. 괄호 안과 제곱을 계산한다: $2.1^2 = 4.41$ 이므로 $\frac{4.41 - 4}{0.1}$
8. 뺄셈과 나눗셈을 한다: $4.41 - 4 = 0.41$, $0.41 \div 0.1 = 4.1$
9. 식을 정리한다. 괄호를 푼다($(a+b)^2 = a^2 + 2ab + b^2$에서 $a = 2$, $b = h$): $(2+h)^2 = 4 + 4h + h^2$
10. 4를 뺀다: $(2+h)^2 - 4 = 4h + h^2$
11. $h$로 나눈다: $\frac{4h + h^2}{h} = \frac{4h}{h} + \frac{h^2}{h} = 4 + h$
12. $h$가 0에 가까워지면 $4 + h$는 4에 가까워진다 ($h = 1$이면 5, $h = 0.1$이면 4.1로 앞의 값과 같다)

**답**: $h = 1$이면 5, $h = 0.1$이면 4.1, $h \to 0$이면 **4**. 공식 $2x$에 $x = 2$를 넣은 값과 같다.

</details>

### 문제 6
$y = x^2$의 가장 낮은 곳을 경사하강으로 찾는다. $x = 4$에서 출발해 [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0) 0.1로 두 걸음 가면 x는? 갱신식은 $\text{새 } x = x - 0.1 \times \text{기울기}(2x)$이다.

<details><summary>풀이와 답</summary>

**주어진 값**
- 처음 $x = 4$ (출발점)
- $0.1$ ([학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0))
- [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $2x$ (곡선 $y = x^2$의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) 공식)

**풀이**
1. 식을 그대로 쓴다: $\text{새 } x = x - 0.1 \times \text{기울기}(2x)$
2. 첫 걸음의 값을 대입한다: $\text{새 } x = 4 - 0.1 \times (2 \times 4)$
3. 괄호 안 곱셈([기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0))을 한다: $2 \times 4 = 8$ 이므로 $\text{새 } x = 4 - 0.1 \times 8$
4. 곱셈(보폭)을 한다: $0.1 \times 8 = 0.8$ 이므로 $\text{새 } x = 4 - 0.8$
5. 뺄셈을 한다: $4 - 0.8 = 3.2$
6. 둘째 걸음의 값을 대입한다(지금 $x = 3.2$): $\text{새 } x = 3.2 - 0.1 \times (2 \times 3.2)$
7. 괄호 안 곱셈을 한다: $2 \times 3.2 = 6.4$ 이므로 $\text{새 } x = 3.2 - 0.1 \times 6.4$
8. 곱셈을 한다: $0.1 \times 6.4 = 0.64$ 이므로 $\text{새 } x = 3.2 - 0.64$
9. 뺄셈을 한다: $3.2 - 0.64 = 2.56$

**답**: 첫 걸음 뒤 $x = 3.2$, 둘째 걸음 뒤 $x = 2.56$ (바닥 0에 가까워지고, [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 작아져 걸음도 작아진다)

</details>

### 문제 7
같은 곡선 $y = x^2$에서 [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0)을 1.1로 너무 크게 잡고 $x = 1$에서 두 걸음 가면 x는 어떻게 움직이는가?

<details><summary>풀이와 답</summary>

**주어진 값**
- 처음 $x = 1$
- [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0) $1.1$ (너무 큰 값)
- [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $2x$

**풀이**
1. 식을 그대로 쓴다: $\text{새 } x = x - 1.1 \times \text{기울기}(2x)$
2. 첫 걸음의 값을 대입한다: $\text{새 } x = 1 - 1.1 \times (2 \times 1)$
3. 괄호 안 곱셈을 한다: $2 \times 1 = 2$ 이므로 $\text{새 } x = 1 - 1.1 \times 2$
4. 곱셈을 한다: $1.1 \times 2 = 2.2$ 이므로 $\text{새 } x = 1 - 2.2$
5. 뺄셈을 한다: $1 - 2.2 = -1.2$
6. 둘째 걸음의 값을 대입한다(지금 $x = -1.2$): $\text{새 } x = -1.2 - 1.1 \times (2 \times (-1.2))$
7. 괄호 안 곱셈을 한다: $2 \times (-1.2) = -2.4$ 이므로 $\text{새 } x = -1.2 - 1.1 \times (-2.4)$
8. 곱셈을 한다: $1.1 \times (-2.4) = -2.64$ 이므로 $\text{새 } x = -1.2 - (-2.64)$
9. 빼기 음수는 더하기와 같다: $-1.2 + 2.64 = 1.44$

**답**: $x$는 $1 \to -1.2 \to 1.44$로 바닥(0)을 지나쳐 반대편으로 튀고, 걸음마다 0에서 더 멀어진다. [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0)이 너무 크면 이렇게 된다.

</details>

### 문제 8
$y = x^2$ 위의 두 점 $x = 1$과 $x = 3$ 사이의 평균 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)를 구하고, 두 점의 한가운데 $x = 2$에서의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $2x$와 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- 두 점의 x: $1$, $3$ (y는 $x^2$로 구한다)
- 한가운데 $x = 2$, [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) 공식 $2x$

**풀이**
1. 두 점의 y를 구한다. 식을 쓴다: $y = x^2$
2. 값을 대입한다: $x = 1$이면 $y = 1^2 = 1$, $x = 3$이면 $y = 3^2 = 9$. 두 점은 (1, 1)과 (3, 9)
3. [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) 식을 쓴다: $\text{기울기} = \frac{\Delta y}{\Delta x}$
4. 값을 대입한다: $\text{기울기} = \frac{9 - 1}{3 - 1}$
5. 뺄셈을 한다: $9 - 1 = 8$, $3 - 1 = 2$ 이므로 $\frac{8}{2}$
6. 나눗셈을 한다: $8 \div 2 = 4$
7. 한가운데의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)를 구한다. 식을 쓴다: $\text{기울기} = 2x$
8. 값을 대입한다: $\text{기울기} = 2 \times 2$
9. 곱셈을 한다: $2 \times 2 = 4$

**답**: 평균 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) 4, $x = 2$에서의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)도 4. 같은 값이다 ($x^2$에서는 두 점 사이 평균 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 한가운데의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)와 같다)

</details>

## 강의와 연결

### 문제 9
[Lec02 2.1](../../Lec02_%EC%8B%A0%EA%B2%BD%EB%A7%9D_%ED%95%99%EC%8A%B5.md#21-%EA%B2%BD%EC%82%AC%ED%95%98%EA%B0%95%EB%B2%95)의 갱신식 $\theta^{k+1} \leftarrow \theta^k - \eta\, \nabla_\theta J(\theta^k)$를 비용 $J(\theta) = (\theta - 3)^2$ ([기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $2(\theta - 3)$)에 쓴다. $\theta^0 = 1$, [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0) $\eta = 0.25$일 때 두 걸음 뒤 $\theta^2$는?

<details><summary>풀이와 답</summary>

**주어진 값**
- $\theta^0 = 1$ (출발점)
- $\eta = 0.25$ ([학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0))
- $\nabla_\theta J(\theta) = 2(\theta - 3)$ ([기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0))

**풀이**
1. 식을 그대로 쓴다: $\theta^{k+1} \leftarrow \theta^k - \eta\, \nabla_\theta J(\theta^k)$
2. 첫 걸음의 값을 대입한다: $\theta^1 = 1 - 0.25 \times 2(1 - 3)$
3. 괄호 안 뺄셈을 한다: $1 - 3 = -2$ 이므로 $\theta^1 = 1 - 0.25 \times 2 \times (-2)$
4. [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)를 곱한다: $2 \times (-2) = -4$ 이므로 $\theta^1 = 1 - 0.25 \times (-4)$
5. [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0)을 곱한다: $0.25 \times (-4) = -1$ 이므로 $\theta^1 = 1 - (-1)$
6. 빼기 음수는 더하기와 같다: $\theta^1 = 1 + 1 = 2$
7. 둘째 걸음의 값을 대입한다: $\theta^2 = 2 - 0.25 \times 2(2 - 3)$
8. 괄호 안 뺄셈을 한다: $2 - 3 = -1$ 이므로 $\theta^2 = 2 - 0.25 \times 2 \times (-1)$
9. [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)를 곱한다: $2 \times (-1) = -2$ 이므로 $\theta^2 = 2 - 0.25 \times (-2)$
10. [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0)을 곱한다: $0.25 \times (-2) = -0.5$ 이므로 $\theta^2 = 2 - (-0.5)$
11. 빼기 음수는 더하기와 같다: $\theta^2 = 2 + 0.5 = 2.5$

**답**: $\theta^1 = 2$, $\theta^2 = 2.5$ (바닥 $\theta = 3$으로 다가가며, [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 작아질수록 걸음도 작아진다)

</details>

### 문제 10
[Lec02 3.1](../../Lec02_%EC%8B%A0%EA%B2%BD%EB%A7%9D_%ED%95%99%EC%8A%B5.md#31-%EC%96%B4%EB%96%A4-%EC%A7%80%ED%98%95%EC%9D%B4-%EC%B5%9C%EC%A0%81%ED%99%94%ED%95%98%EA%B8%B0-%EC%96%B4%EB%A0%A4%EC%9A%B4%EA%B0%80)은 "거의 평평한" 지형에서 [기울기 소실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#vanishing-gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0-%EC%86%8C%EC%8B%A4) 때문에 진행이 느리다고 설명한다. 가파른 지형 $J_1(\theta) = \theta^2$ ([기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $2\theta$)와 완만한 지형 $J_2(\theta) = 0.01\theta^2$ ([기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $0.02\theta$)에서, $\theta = 5$, [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0) 0.1로 한 걸음 갈 때 이동량과 새 $\theta$를 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $\theta = 5$ (지금 위치)
- $\eta = 0.1$ ([학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0))
- $J_1$의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $2\theta$, $J_2$의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $0.02\theta$

**풀이**
1. 식을 그대로 쓴다: $\text{이동량} = \eta \times \text{기울기}$, $\text{새 } \theta = \theta - \text{이동량}$
2. $J_1$의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)를 구한다. 값을 대입한다: $2 \times 5$
3. 곱셈을 한다: $2 \times 5 = 10$ 이므로 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $= 10$
4. 이동량을 구한다: $0.1 \times 10 = 1$
5. 새 $\theta$를 구한다: $5 - 1 = 4$
6. $J_2$의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)를 구한다. 값을 대입한다: $0.02 \times 5$
7. 곱셈을 한다: $0.02 \times 5 = 0.1$ 이므로 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $= 0.1$
8. 이동량을 구한다: $0.1 \times 0.1 = 0.01$
9. 새 $\theta$를 구한다: $5 - 0.01 = 4.99$

**답**: $J_1$은 이동량 1, 새 $\theta = 4$. $J_2$는 이동량 0.01, 새 $\theta = 4.99$. 평평할수록 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 작아 걸음이 100배 작다. 그래서 진행이 느리다.

</details>
