# 예제: 편미분

개념 노트: [M04_편미분](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/02_%EB%AF%B8%EB%B6%84/M04_%ED%8E%B8%EB%AF%B8%EB%B6%84.md) · [목차](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md)

풀이는 접혀 있으니 먼저 풀어 보고 펼쳐 확인한다. 문제 10개, 쉬운 것부터 어려운 것 순서다. [편미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#partial-derivative-%ED%8E%B8%EB%AF%B8%EB%B6%84)에서는 **움직이지 않는 변수를 숫자(상수)처럼** 다룬다.

## 기본 (직접 대입)

### 문제 1
$f(w, b) = w^2 + 5b + 4$의 [편미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#partial-derivative-%ED%8E%B8%EB%AF%B8%EB%B6%84) $\frac{\partial f}{\partial w}$와 $\frac{\partial f}{\partial b}$를 구하고, $(w, b) = (3, 2)$에서의 값을 구하라. (공식: $x^2 \to 2x$, $ax \to a$, 상수 $\to 0$)

<details><summary>풀이와 답</summary>

**주어진 값**
- $f(w, b) = w^2 + 5b + 4$ (세 항)
- $w = 3$, $b = 2$ ([기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)를 구할 자리)

**풀이**
1. w로 편미분한다. b를 숫자 취급하므로 $5b$는 상수이다. 식을 그대로 쓴다: $\frac{\partial f}{\partial w} = (w^2)' + (5b)' + (4)'$
2. 각 항을 미분한다: $(w^2)' = 2w$, $(5b)' = 0$ (w를 움직여도 변하지 않는다), $(4)' = 0$
3. 더한다: $\frac{\partial f}{\partial w} = 2w + 0 + 0 = 2w$
4. 값을 대입한다: $\frac{\partial f}{\partial w} = 2 \times 3$
5. 곱셈을 한다: $2 \times 3 = 6$
6. b로 편미분한다. w를 숫자 취급하므로 $w^2$은 상수이다. 식을 그대로 쓴다: $\frac{\partial f}{\partial b} = (w^2)' + (5b)' + (4)'$
7. 각 항을 미분한다: $(w^2)' = 0$ (b를 움직여도 변하지 않는다), $(5b)' = 5$ ($ax \to a$), $(4)' = 0$
8. 더한다: $\frac{\partial f}{\partial b} = 0 + 5 + 0 = 5$ (b 값 2와 상관없이 5)

**답**: $\frac{\partial f}{\partial w} = 2w$이고 $(3, 2)$에서 6, $\frac{\partial f}{\partial b} = 5$

</details>

### 문제 2
$f(w, b) = w \times b$에서 $(w, b) = (3, 2)$일 때 $\frac{\partial f}{\partial w}$와 $\frac{\partial f}{\partial b}$는?

<details><summary>풀이와 답</summary>

**주어진 값**
- $f(w, b) = w \times b$ (두 변수의 곱)
- $w = 3$, $b = 2$

**풀이**
1. w로 편미분한다. b는 숫자(상수)로 보면 $f = b \times w$ 는 $a \times w$ 꼴이다. 공식 $ax \to a$에서 $a$ 자리가 $b$이다: $\frac{\partial f}{\partial w} = b$
2. 값을 대입한다: $\frac{\partial f}{\partial w} = 2$
3. b로 편미분한다. w를 숫자로 보면 $f = w \times b$ 는 $a \times b$ 꼴이다. $ax \to a$에서 $a$ 자리가 $w$이다: $\frac{\partial f}{\partial b} = w$
4. 값을 대입한다: $\frac{\partial f}{\partial b} = 3$

**답**: $\frac{\partial f}{\partial w} = b = 2$, $\frac{\partial f}{\partial b} = w = 3$

</details>

### 문제 3
데이터 1개 $x = 3$, [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) $y = 4$에서 $\text{cost} = (wx + b - y)^2$이다. 지금 $w = 1$, $b = 0$일 때 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $e$와 두 [편미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#partial-derivative-%ED%8E%B8%EB%AF%B8%EB%B6%84) $\frac{\partial\, \text{cost}}{\partial w} = 2e \cdot x$, $\frac{\partial\, \text{cost}}{\partial b} = 2e$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x = 3$ (입력)
- $y = 4$ ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5))
- $w = 1$ ([가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98))
- $b = 0$ ([편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5))

**풀이**
1. [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 식을 그대로 쓴다: $e = wx + b - y$
2. 값을 대입한다: $e = 1 \times 3 + 0 - 4$
3. 곱셈을 먼저 한다: $1 \times 3 = 3$ 이므로 $e = 3 + 0 - 4$
4. 앞에서부터 계산한다: $3 + 0 = 3$, $3 - 4 = -1$ 이므로 $e = -1$
5. w [편미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#partial-derivative-%ED%8E%B8%EB%AF%B8%EB%B6%84) 식을 그대로 쓴다: $\frac{\partial\, \text{cost}}{\partial w} = 2e \cdot x$
6. 값을 대입한다: $\frac{\partial\, \text{cost}}{\partial w} = 2 \times (-1) \times 3$
7. 앞쪽 곱셈을 한다: $2 \times (-1) = -2$ 이므로 $-2 \times 3$
8. 뒤쪽 곱셈을 한다: $-2 \times 3 = -6$
9. b [편미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#partial-derivative-%ED%8E%B8%EB%AF%B8%EB%B6%84) 식을 그대로 쓴다: $\frac{\partial\, \text{cost}}{\partial b} = 2e$
10. 값을 대입한 뒤 곱한다: $2 \times (-1) = -2$

**답**: $e = -1$, $\frac{\partial\, \text{cost}}{\partial w} = -6$, $\frac{\partial\, \text{cost}}{\partial b} = -2$

</details>

### 문제 4
문제 3과 같은 값에서 w만 0.001 올려(b는 그대로) cost가 얼마나 변하는지 직접 재서, 문제 3의 $\frac{\partial\, \text{cost}}{\partial w} = -6$과 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x = 3$, $y = 4$, $b = 0$ (고정)
- $w$: $1 \to 1.001$ (0.001만 올린다)

**풀이**
1. 처음 cost를 구한다. 식을 그대로 쓴다: $\text{cost} = (wx + b - y)^2$
2. 값을 대입한다: $\text{cost} = (1 \times 3 + 0 - 4)^2$
3. 괄호 안을 계산한다: $1 \times 3 = 3$, $3 + 0 - 4 = -1$ 이므로 $(-1)^2$
4. 제곱을 한다: $(-1)^2 = 1$ 이므로 처음 cost $= 1$
5. 새 cost를 구한다. 값을 대입한다: $\text{cost} = (1.001 \times 3 + 0 - 4)^2$
6. 괄호 안 곱셈을 한다: $1.001 \times 3 = 3.003$ 이므로 $(3.003 + 0 - 4)^2$
7. 괄호 안을 계산한다: $3.003 - 4 = -0.997$ 이므로 $(-0.997)^2$
8. 제곱을 한다: $(-0.997)^2 = 0.994009$ 이므로 새 cost $= 0.994009$
9. 변한 양을 구한다: $0.994009 - 1 = -0.005991$
10. 움직인 양으로 나눈다: $-0.005991 \div 0.001 = -5.991$

**답**: 약 $-5.991$, 곧 약 $-6$. 공식으로 구한 $\frac{\partial\, \text{cost}}{\partial w} = -6$과 같다 (움직인 양이 0.001로 아주 작을수록 더 가까워진다)

</details>

### 문제 5
데이터 2개 $(x_1, y_1) = (1, 2)$, $(x_2, y_2) = (3, 4)$에서 $w = 1$, $b = 0$일 때, 평균 cost의 [편미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#partial-derivative-%ED%8E%B8%EB%AF%B8%EB%B6%84) $\frac{\partial\, \text{cost}}{\partial w} = \frac{1}{m}\sum 2(wx_i + b - y_i)\,x_i$와 $\frac{\partial\, \text{cost}}{\partial b} = \frac{1}{m}\sum 2(wx_i + b - y_i)$를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $m = 2$ (데이터 개수)
- $x_1 = 1$, $y_1 = 2$ / $x_2 = 3$, $y_2 = 4$
- $w = 1$, $b = 0$

**풀이**
1. 먼저 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)를 구한다. 식을 쓴다: $e_i = wx_i + b - y_i$
2. 첫째 데이터를 대입한다: $e_1 = 1 \times 1 + 0 - 2 = 1 - 2 = -1$
3. 둘째 데이터를 대입한다: $e_2 = 1 \times 3 + 0 - 4 = 3 - 4 = -1$
4. w [편미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#partial-derivative-%ED%8E%B8%EB%AF%B8%EB%B6%84) 식을 그대로 쓴다: $\frac{\partial\, \text{cost}}{\partial w} = \frac{1}{m}\sum_{i=1}^{m} 2e_i\,x_i$
5. 값을 대입한다(Σ는 i = 1, 2 항을 펼친다): $\frac{1}{2}\left(2 \times (-1) \times 1 + 2 \times (-1) \times 3\right)$
6. 첫째 항을 곱한다: $2 \times (-1) \times 1 = -2$ 이므로 $\frac{1}{2}\left(-2 + 2 \times (-1) \times 3\right)$
7. 둘째 항을 곱한다: $2 \times (-1) \times 3 = -6$ 이므로 $\frac{1}{2}\left(-2 + (-6)\right)$
8. 괄호 안을 더한다: $-2 + (-6) = -8$ 이므로 $\frac{1}{2} \times (-8)$
9. 2로 나눈다: $-8 \div 2 = -4$
10. b [편미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#partial-derivative-%ED%8E%B8%EB%AF%B8%EB%B6%84) 식을 그대로 쓴다: $\frac{\partial\, \text{cost}}{\partial b} = \frac{1}{m}\sum_{i=1}^{m} 2e_i$
11. 값을 대입한다: $\frac{1}{2}\left(2 \times (-1) + 2 \times (-1)\right)$
12. 곱셈을 한다: $2 \times (-1) = -2$ 이므로 $\frac{1}{2}\left(-2 + (-2)\right)$
13. 괄호 안을 더한다: $-2 + (-2) = -4$ 이므로 $\frac{1}{2} \times (-4)$
14. 2로 나눈다: $-4 \div 2 = -2$

**답**: $\frac{\partial\, \text{cost}}{\partial w} = -4$, $\frac{\partial\, \text{cost}}{\partial b} = -2$ (둘 다 음수이므로 w와 b를 둘 다 올려야 cost가 준다)

</details>

### 문제 6
문제 5의 [편미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#partial-derivative-%ED%8E%B8%EB%AF%B8%EB%B6%84)으로 [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0) $\eta = 0.1$의 [경사하강](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-descent-%EA%B2%BD%EC%82%AC%ED%95%98%EA%B0%95%EB%B2%95)을 한 번 하라 ($w \leftarrow w - \eta \frac{\partial\, \text{cost}}{\partial w}$, $b$도 같은 모양). 새 $w$, $b$를 구하고, 평균 cost가 줄었는지 확인하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $w = 1$, $b = 0$ (지금 값)
- $\frac{\partial\, \text{cost}}{\partial w} = -4$, $\frac{\partial\, \text{cost}}{\partial b} = -2$ (문제 5의 결과)
- $\eta = 0.1$ ([학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0))
- 데이터 $(1, 2)$, $(3, 4)$, $m = 2$

**풀이**
1. w 갱신식을 그대로 쓴다: $w \leftarrow w - \eta \frac{\partial\, \text{cost}}{\partial w}$
2. 값을 대입한다: $w \leftarrow 1 - 0.1 \times (-4)$
3. 곱셈을 한다: $0.1 \times (-4) = -0.4$ 이므로 $w \leftarrow 1 - (-0.4)$
4. 빼기 음수는 더하기와 같다: $1 + 0.4 = 1.4$
5. b 갱신식을 그대로 쓴다: $b \leftarrow b - \eta \frac{\partial\, \text{cost}}{\partial b}$
6. 값을 대입한다: $b \leftarrow 0 - 0.1 \times (-2)$
7. 곱셈을 한다: $0.1 \times (-2) = -0.2$ 이므로 $b \leftarrow 0 - (-0.2) = 0.2$
8. 처음 평균 cost를 구한다: 문제 5에서 두 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)가 $-1$, $-1$ 이므로 $\frac{1}{2}\left((-1)^2 + (-1)^2\right) = \frac{1}{2}(1 + 1) = 1$
9. 새 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)를 구한다: $e_1 = 1.4 \times 1 + 0.2 - 2 = 1.6 - 2 = -0.4$
10. 둘째 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)를 구한다: $e_2 = 1.4 \times 3 + 0.2 - 4 = 4.2 + 0.2 - 4 = 0.4$
11. 새 평균 cost를 구한다: $\frac{1}{2}\left((-0.4)^2 + 0.4^2\right) = \frac{1}{2}(0.16 + 0.16) = \frac{1}{2} \times 0.32 = 0.16$

**답**: 새 $w = 1.4$, 새 $b = 0.2$. 평균 cost는 1에서 0.16으로 줄었다.

</details>

### 문제 7
EX\_02 노트북의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) 식은 정식의 $2$가 빠져 $\frac{1}{m}\sum e_i\,x_i$이다. 문제 5의 데이터에서 노트북 $w$ [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)를 구하고, 정식 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)($-4$)와 비교하라. 노트북 [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0) 0.2의 한 걸음과 정식 [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0) 0.1의 한 걸음도 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $e_1 = -1$, $e_2 = -1$, 입력 $x_1 = 1$, $x_2 = 3$, $m = 2$ (문제 5)
- 정식 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $-4$
- [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0): 노트북 $0.2$, 정식 $0.1$

**풀이**
1. 노트북 식을 그대로 쓴다: $\text{노트북 기울기} = \frac{1}{m}\sum_{i=1}^{m} e_i\,x_i$
2. 값을 대입한다(Σ는 i = 1, 2 항을 펼친다): $\frac{1}{2}\left((-1) \times 1 + (-1) \times 3\right)$
3. 곱셈을 한다: $(-1) \times 1 = -1$, $(-1) \times 3 = -3$ 이므로 $\frac{1}{2}\left(-1 + (-3)\right)$
4. 괄호 안을 더한다: $-1 + (-3) = -4$ 이므로 $\frac{1}{2} \times (-4)$
5. 2로 나눈다: $-4 \div 2 = -2$
6. 정식과 비교한다: $-4$의 절반이 $-2$이다.
7. 노트북 한 걸음을 구한다. 식을 쓴다: $\text{한 걸음} = \text{학습률} \times \text{기울기}$
8. 값을 대입한 뒤 곱한다: $0.2 \times (-2) = -0.4$
9. 정식 한 걸음을 구한다: $0.1 \times (-4) = -0.4$
10. 두 값을 비교한다: $-0.4 = -0.4$ 로 같다.

**답**: 노트북 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)는 $-2$로 정식($-4$)의 절반이다. [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0)을 2배(0.2)로 쓰면 한 걸음이 $-0.4$로 정식 [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0) 0.1의 한 걸음과 같다.

</details>

### 문제 8
$\text{cost} = (wx + b - y)^2$에서 입력이 $x = 0$이고 $y = 2$, $w = 3$, $b = 1$이다. 두 [편미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#partial-derivative-%ED%8E%B8%EB%AF%B8%EB%B6%84) $2e \cdot x$, $2e$를 구하고, 왜 한쪽이 0인지 설명하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $x = 0$ (입력)
- $y = 2$ ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5))
- $w = 3$, $b = 1$

**풀이**
1. [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 식을 그대로 쓴다: $e = wx + b - y$
2. 값을 대입한다: $e = 3 \times 0 + 1 - 2$
3. 곱셈을 먼저 한다: $3 \times 0 = 0$ 이므로 $e = 0 + 1 - 2$
4. 앞에서부터 계산한다: $0 + 1 = 1$, $1 - 2 = -1$ 이므로 $e = -1$
5. w [편미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#partial-derivative-%ED%8E%B8%EB%AF%B8%EB%B6%84) 식을 그대로 쓴다: $\frac{\partial\, \text{cost}}{\partial w} = 2e \cdot x$
6. 값을 대입한다: $2 \times (-1) \times 0$
7. 곱셈을 한다: $2 \times (-1) = -2$, $-2 \times 0 = 0$
8. b [편미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#partial-derivative-%ED%8E%B8%EB%AF%B8%EB%B6%84) 식을 그대로 쓴다: $\frac{\partial\, \text{cost}}{\partial b} = 2e$
9. 값을 대입한 뒤 곱한다: $2 \times (-1) = -2$

**답**: $\frac{\partial\, \text{cost}}{\partial w} = 0$, $\frac{\partial\, \text{cost}}{\partial b} = -2$. 입력이 0이면 $wx = w \times 0 = 0$이라 w를 바꿔도 예측이 변하지 않으므로 cost도 변하지 않는다. b는 예측에 직접 더해지므로 cost에 영향을 준다.

</details>

### 문제 9
[Lec02 8.1](../../Lec02_%EC%8B%A0%EA%B2%BD%EB%A7%9D_%ED%95%99%EC%8A%B5.md#81-%ED%95%A9%EC%B9%98%EA%B8%B0%EC%99%80-%EA%B0%80%EC%A7%80%EC%B9%98%EA%B8%B0)에서 [가지치기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#pruning-%EA%B0%80%EC%A7%80%EC%B9%98%EA%B8%B0)(한 값 $x$를 두 갈래로 복제)를 하면 역방향에서 두 가지의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)를 **더해서** $x$로 보낸다: $\frac{\partial J}{\partial x} = \sum_i \frac{\partial J}{\partial x^i}$. $x^a = x$, $x^b = x$이고 $J = (x^a)^2 + 4x^b$일 때 $x = 3$에서 $\frac{\partial J}{\partial x}$를 구하고, $J$를 $x$ 하나로 쓴 식을 직접 미분한 값과 비교하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $J = (x^a)^2 + 4x^b$ (두 가지에서 온 값)
- $x^a = x$, $x^b = x$ (복제)
- $x = 3$

**풀이**
1. 식을 그대로 쓴다: $\frac{\partial J}{\partial x} = \frac{\partial J}{\partial x^a} + \frac{\partial J}{\partial x^b}$
2. 가지 a의 [편미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#partial-derivative-%ED%8E%B8%EB%AF%B8%EB%B6%84)을 구한다. $x^b$는 고정이므로 $4x^b$는 상수이다: $\frac{\partial J}{\partial x^a} = 2x^a$ ($x^2 \to 2x$)
3. 값을 대입한다: $2 \times 3 = 6$
4. 가지 b의 [편미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#partial-derivative-%ED%8E%B8%EB%AF%B8%EB%B6%84)을 구한다. $x^a$는 고정이므로 $(x^a)^2$은 상수이다: $\frac{\partial J}{\partial x^b} = 4$ ($ax \to a$)
5. 두 가지를 더한다: $\frac{\partial J}{\partial x} = 6 + 4 = 10$
6. 직접 확인한다. $x^a = x^b = x$를 넣어 한 식으로 쓴다: $J = x^2 + 4x$
7. 미분한다: $\frac{dJ}{dx} = 2x + 4$
8. 값을 대입한다: $2 \times 3 + 4 = 6 + 4 = 10$

**답**: $\frac{\partial J}{\partial x} = 10$. 두 가지의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $6$과 $4$를 더한 값이 직접 미분한 값과 같다.

</details>

### 문제 10
[Lec02 5.1](../../Lec02_%EC%8B%A0%EA%B2%BD%EB%A7%9D_%ED%95%99%EC%8A%B5.md#51-%EB%8F%84%ED%95%A8%EC%88%98%EC%9D%98-%EB%AA%A8%EC%96%91)에 따르면 $y$가 스칼라이고 $x$가 $[n \times 1]$ 열벡터일 때 도함수 $\partial y / \partial x$는 원소가 $\partial y / \partial x_j$인 $[1 \times n]$ 행벡터이다. $y = x_1^2 + 3x_2$, $x = (2, 5)$일 때 이 행벡터를 구하라.

<details><summary>풀이와 답</summary>

**주어진 값**
- $y = x_1^2 + 3x_2$ (스칼라)
- $x = (x_1, x_2) = (2, 5)$ ($n = 2$인 열벡터)

**풀이**
1. 식을 그대로 쓴다: $\frac{\partial y}{\partial x} = \left[\frac{\partial y}{\partial x_1},\ \frac{\partial y}{\partial x_2}\right]$
2. 첫째 원소를 구한다. $x_2$는 고정이라 $3x_2$는 상수이다: $\frac{\partial y}{\partial x_1} = 2x_1$ ($x^2 \to 2x$)
3. 값을 대입한 뒤 곱한다: $2 \times 2 = 4$
4. 둘째 원소를 구한다. $x_1$은 고정이라 $x_1^2$은 상수이다: $\frac{\partial y}{\partial x_2} = 3$ ($ax \to a$)
5. 두 원소를 가로로 묶는다: $\frac{\partial y}{\partial x} = [4,\ 3]$

**답**: $\frac{\partial y}{\partial x} = [4,\ 3]$, 모양은 $[1 \times 2]$ 행벡터

</details>
