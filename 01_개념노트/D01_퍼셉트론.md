# 퍼셉트론 (EX\_01)

[목차로 돌아가기](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D%EC%88%98%ED%95%99_MOC.md) · 예제: `01_ML_DL_Basic/EX_01_Perceptron.ipynb` · 코드 풀이: [E01_퍼셉트론_예제](../03_%EC%98%88%EC%A0%9C%ED%92%80%EC%9D%B4/E01_%ED%8D%BC%EC%85%89%ED%8A%B8%EB%A1%A0_%EC%98%88%EC%A0%9C.md)

> [!NOTE]
> **3줄 요약**
> - 퍼셉트론은 입력마다 중요도(가중치)를 곱해 더하고([가중합](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EA%B0%80%EC%A4%91%ED%95%A9)), 그 합이 기준을 넘으면 1, 아니면 0을 내는 가장 단순한 인공 뉴런이다.
> - 필요한 수학: 함수, Σ(같은 자리끼리 곱해서 더하기)
> - 예제에서는 [1, 2, 3]과 [4, 5, 6]을 곱해 더하고 10을 더한 **42**가 기준 10을 넘어서 **1**이 나온다.

## 1. 이게 하는 일 (말로)

여러 신호를 받아서 "켤까, 말까"를 정한다.

> 비유: 합격 판정. 과목 점수(입력)에 과목별 반영 비율(가중치)을 곱해 더하고, 기본 점수([편향](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%ED%8E%B8%ED%96%A5))를 얹은 뒤, 커트라인을 넘으면 합격(1), 아니면 불합격(0).

## 3. 수학 하나씩 풀기

<details><summary>미니 복습: Σ</summary>

$\sum_{i=1}^{3} w_i x_i = w_1x_1 + w_2x_2 + w_3x_3$
for문으로 i = 1, 2, 3을 돌며 곱해서 더한 것이다. 자세히: [M02_시그마와_평균](../02_%EC%88%98%ED%95%99%EB%85%B8%ED%8A%B8/M02_%EC%8B%9C%EA%B7%B8%EB%A7%88%EC%99%80_%ED%8F%89%EA%B7%A0.md)

</details>

<details><summary>미니 복습: 함수</summary>

넣는 값 하나 → 나오는 값 하나. 계단 함수는 기준을 넘으면 1, 아니면 0이다. 자세히: [M01_함수와_일차함수](../02_%EC%88%98%ED%95%99%EB%85%B8%ED%8A%B8/M01_%ED%95%A8%EC%88%98%EC%99%80_%EC%9D%BC%EC%B0%A8%ED%95%A8%EC%88%98.md)

</details>

## 4. 다시 합치기: 숫자 → 식 → 코드

### 숫자

| i | 입력 $x_i$ | 가중치 $w_i$ | 곱 |
|---|---|---|---|
| 1 | 1 | 4 | 4 |
| 2 | 2 | 5 | 10 |
| 3 | 3 | 6 | 18 |
| | | 합 | **32** |

32 + 편향 10 = **42** → 42 > 10 → 출력 **1**

### 식

노트북 맨 위의 식:

$$y = \sigma\left(\sum_{i=1}^{3} w_i x_i + b\right)$$

| 기호 | 뜻 | 예제 값 |
|---|---|---|
| $x_i$ | i번째 입력 | 1, 2, 3 |
| $w_i$ | i번째 가중치(중요도) | 4, 5, 6 |
| $b$ | 편향(기본 점수) | 10 |
| $\sigma$ | [활성화 함수](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%ED%99%9C%EC%84%B1%ED%99%94-%ED%95%A8%EC%88%98). 여기서는 계단 함수 | s > 10이면 1 |
| $y$ | 출력 | 1 |

> [!WARNING]
> **⚠ σ 기호가 두 뜻으로 쓰인다**
> 이 노트북은 σ를 "활성화 함수"라는 넓은 뜻으로 썼다. 뒤의 EX\_05부터는 σ가 보통 **[시그모이드](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C)**([D04_시그모이드와_이진분류](D04_%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C%EC%99%80_%EC%9D%B4%EC%A7%84%EB%B6%84%EB%A5%98.md))라는 특정 함수를 가리킨다. 문맥으로 구분한다.

> [!WARNING]
> **⚠ 기준값이 10인 이유**
> 교과서의 퍼셉트론은 보통 "합이 **0**보다 크면 1"이다. 이 예제 코드는 `s > 10`으로 기준을 10으로 잡았다.
> s > 10은 (s − 10) > 0과 같다. 즉 편향 b를 10 줄이고 기준을 0으로 둔 것과 똑같다. **기준을 어디에 두느냐는 편향 b로 조절할 수 있다.**

### 코드

```python
X = np.array([1,2,3])   # 입력
W = np.array([4,5,6])   # 가중치
B = 10                  # 편향

mul = W * X             # 같은 자리끼리 곱 → [ 4 10 18]
s = np.sum(mul) + B     # Σ w_i x_i + b → 42
y = np.float32(s > 10)  # 계단 함수: True → 1.0, False → 0.0
```

**실행 결과** (노트북 기록, 이 PC에서 다시 돌려도 같음):

```
mul = W * X : [ 4 10 18]
s = 42
y = 1.0
```

C로 쓰면:

```c
int X[3] = {1, 2, 3}, W[3] = {4, 5, 6}, B = 10, s = 0;
for (int i = 0; i < 3; i++) s += W[i] * X[i];   // Σ w_i x_i
s += B;                                          // + b
float y = (s > 10) ? 1.0f : 0.0f;               // 계단 함수
```

`np.float32(s > 10)`은 비교 결과(True/False)를 1.0/0.0으로 바꾼다. C의 삼항연산자와 같은 역할이다.

## 5. 스스로 확인

<details><summary>1. X = [1, 0, 1], W = [4, 5, 6], B = 10이면 s와 y는?</summary>

4 + 0 + 6 + 10 = **20** → 20 > 10 → y = **1**

</details>

<details><summary>2. 원래 예제에서 B만 −30으로 바꾸면?</summary>

32 − 30 = **2** → 2 > 10은 거짓 → y = **0**

</details>

<details><summary>3. 가중치가 큰 입력은 결과에 어떤 영향을 주나?</summary>

그 입력이 조금만 변해도 합이 크게 변한다. 즉 **더 중요한 입력**이다. 학습이란 이 가중치를 데이터에 맞게 정하는 일이다([D02_경사하강법으로_직선찾기](D02_%EA%B2%BD%EC%82%AC%ED%95%98%EA%B0%95%EB%B2%95%EC%9C%BC%EB%A1%9C_%EC%A7%81%EC%84%A0%EC%B0%BE%EA%B8%B0.md)).

</details>
