# 소프트맥스와 다중 분류 (EX\_06)

[목차로 돌아가기](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D%EC%88%98%ED%95%99_MOC.md) · 예제: `EX_06_Blood_Pressure_Softmax_Classification.ipynb` · 코드 풀이: [E06_혈압_소프트맥스분류_예제](../03_%EC%98%88%EC%A0%9C%ED%92%80%EC%9D%B4/E06_%ED%98%88%EC%95%95_%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4%EB%B6%84%EB%A5%98_%EC%98%88%EC%A0%9C.md)

> [!NOTE]
> **3줄 요약**
> - 등급마다 점수([가중합](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EA%B0%80%EC%A4%91%ED%95%A9))를 하나씩 내고, **소프트맥스** $p_k = \frac{e^{z_k}}{\sum_j e^{z_j}}$로 "합이 1인 [확률](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%ED%99%95%EB%A5%A0)"로 바꾼 뒤, 가장 큰 칸(**argmax**)을 답으로 고른다.
> - [비용](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은 **categorical [cross-entropy](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cross-entropy)** = 정답 칸 확률의 $-\ln$ 평균. 노트북 확률로 직접 계산하면 0.7290(노트북 loss 0.7291).
> - [시그모이드](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C)는 사실 "등급 2개짜리 소프트맥스"다.

## 1. 이게 하는 일 (말로)

정상·주의·경고 세 등급 중 하나를 고른다. 등급마다 "이 등급다움 점수"를 매기고, 점수를 확률로 바꿔 가장 높은 등급을 답한다.

> 비유: 오디션 심사위원 3명이 각자 점수를 낸다(가중합 3개). 점수를 "득표율"로 바꾸면 합이 100%가 되고, 득표율 1위가 합격이다.

## 4. 다시 합치기: 숫자 → 식 → 코드

### 4.1 소프트맥스

$$p_k = \frac{e^{z_k}}{\sum_{j=1}^{K} e^{z_j}}$$

| 기호 | 뜻 | EX\_06에서 |
|---|---|---|
| $K$ | 등급 수 | 3 |
| $z_k$ | k번째 등급의 점수(가중합) | [Dense](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dense-%EC%B8%B5)(3)의 출력 3개 |
| $e^{z_k}$ | 점수를 양수로 | |
| $\sum_j e^{z_j}$ | 그 양수들의 합 | |
| $p_k$ | k번째 등급의 확률 | |

점수 [2, 1, 0]으로 손계산:

| 단계 | 정상 | 주의 | 경고 | 합 |
|---|---|---|---|---|
| 점수 z | 2 | 1 | 0 | |
| $e^z$ | 7.389 | 2.718 | 1 | 11.107 |
| ÷ 합 | **0.665** | **0.245** | **0.090** | 1 |

- 점수 차이가 2배([4, 2, 0])가 되면 [0.867, 0.117, 0.016]으로 1등에게 훨씬 몰린다. $e^x$가 차이를 **벌려 주기** 때문에 "부드러운(soft) 최댓값(max)"이라는 이름이 붙었다.

### 4.2 모든 점수에 같은 수를 더해도 결과는 같다

[12, 11, 10]으로 계산해도 [0.665, 0.245, 0.090]으로 같다. 분자·분모에 똑같이 $e^{10}$이 곱해져 약분되기 때문이다([M06_지수와_e](../02_%EC%88%98%ED%95%99%EB%85%B8%ED%8A%B8/M06_%EC%A7%80%EC%88%98%EC%99%80_e.md)의 [지수](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e%EC%99%80-%EC%A7%80%EC%88%98) 규칙 $e^{a+b} = e^a e^b$).

→ 점수가 [1000, 999, 998]처럼 커서 $e^{1000}$이 넘칠 때는 **가장 큰 점수를 빼고** [0, −1, −2]로 계산하면 된다. Keras는 내부에서 이렇게 한다.

### 4.3 시그모이드 = 2등급 소프트맥스

점수 [z, 0]으로 소프트맥스를 하면 첫 칸은 $\frac{e^z}{e^z + 1} = \frac{1}{1 + e^{-z}} = \sigma(z)$가 된다.

숫자로: 소프트맥스([2, 0]) = [0.8808, 0.1192], σ(2) = 0.8808 ✓

그래서 [D04_시그모이드와_이진분류](D04_%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C%EC%99%80_%EC%9D%B4%EC%A7%84%EB%B6%84%EB%A5%98.md)는 "출력 1개 + 시그모이드", EX\_06은 "출력 3개 + 소프트맥스"로 같은 일을 등급 수만 다르게 한 것이다.

### 4.4 categorical cross-entropy

$$L = -\sum_{k=1}^{K} y_k \ln p_k$$

정답 $y$가 원-핫이라 정답 칸만 1이고 나머지는 0이다. 그래서 Σ 안에서 **정답 칸 하나만 남는다**:

$$L = -\ln p_{\text{정답}}$$

예: 정답 정상 `[1, 0, 0]`, 모델 [0.783, 0.206, 0.010] → $-\ln 0.783$ = **0.244**

- 아무것도 모를 때(세 칸 모두 1/3) 벌점은 $-\ln \frac{1}{3}$ = 1.099. EX\_06의 첫 loss 1.1564가 이 근처인 이유다.

### 4.5 노트북 결과로 직접 계산해 보기

```python
import numpy as np
P = np.array([[0.78338385,0.20631845,0.01029762],[0.6014961,0.32550704,0.0729968],[0.30936924,0.34400824,0.34662253],
              [0.7022972,0.27652046,0.02118231],[0.479042,0.3875645,0.1333935],[0.19108751,0.31766313,0.49124932],
              [0.6031927,0.3550628,0.04174442],[0.35106853,0.42462453,0.22430705],[0.10656394,0.2648425,0.6285936],
              [0.49048164,0.43163306,0.07788522],[0.23395847,0.42305303,0.34298858],[0.05479377,0.20358758,0.7416187],
              [0.37313625,0.4909104,0.13595329],[0.14150004,0.3825212,0.4759787],[0.02658846,0.14769171,0.82571983],
              [0.2838529,0.5151603,0.20098683],[0.08876073,0.3310046,0.5802347],[0.01448969,0.11102898,0.8744813]])  # 노트북에 찍힌 확률
labels = np.array([0,1,2,0,1,0,0,0,1,0,1,2,1,2,2,1,2,2])   # 정답 번호 (원-핫의 argmax)
Y = np.eye(3)[labels]                                      # 번호 → 원-핫 (3×3 단위행렬에서 줄을 골라옴)
print((-(Y * np.log(P)).sum(axis=1)).mean())               # Σ y·ln p 를 사람마다 → 평균
print((np.argmax(P, axis=1) == labels).mean())             # 정확도
```

**실행 결과**:

```
0.7289930693822264
0.7222222222222222
```

노트북 마지막 loss **0.7291**, [정확도](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EC%A0%95%ED%99%95%EB%8F%84) **0.7222**와 같다(출력 자릿수 반올림 차이만 있다).

### 4.6 argmax

`np.argmax([0.358, 0.443, 0.199])` = **1** → 가장 큰 값의 자리 번호. 확률을 계산하지 않고 점수 z의 argmax를 봐도 답은 같다($e^x$는 큰 수일수록 크므로 순서가 안 바뀐다).
