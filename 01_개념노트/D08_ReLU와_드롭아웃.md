# ReLU와 드롭아웃 (CNN EX_03)

[목차로 돌아가기](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D%EC%88%98%ED%95%99_MOC.md) · 예제: `02_CNN/EX_03_MNIST_ReLU_Dropout.ipynb` · 코드 풀이: [E10_CNN_ReLU_Dropout_예제](../03_%EC%98%88%EC%A0%9C%ED%92%80%EC%9D%B4/E10_CNN_ReLU_Dropout_%EC%98%88%EC%A0%9C.md)

> [!NOTE]
> **3줄 요약**
> - **ReLU** $= \max(0, x)$: 음수는 0, 양수는 그대로. 양수 쪽 [기울기](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 항상 1이라, 층을 쌓아도 기울기가 사라지지 않는다.
> - [시그모이드](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C)의 기울기는 최대 0.25라서 층마다 곱해지면 3층에 0.0156, 10층에 약 0.000001로 줄어든다(**기울기 소실**).
> - **드롭아웃(0.4)**: 학습 중에만 값의 40%를 무작위로 끄고 남은 값을 1.67배 키운다. 몇몇 값에만 기대지 못하게 해서 **[과적합](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EA%B3%BC%EC%A0%81%ED%95%A9)**을 줄인다.

## 1. 이게 하는 일 (말로)

- **ReLU**: "음수면 0, 아니면 그대로"라는 아주 단순한 [활성화 함수](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%ED%99%9C%EC%84%B1%ED%99%94-%ED%95%A8%EC%88%98). 시그모이드 대신 쓰면 깊은 모델이 훨씬 빨리 배운다.
- **드롭아웃**: 학습할 때마다 일부를 무작위로 빼고 연습시킨다.

> 비유(드롭아웃): 축구팀이 연습 때마다 무작위로 4할을 벤치에 앉히고 경기한다. 특정 에이스에게만 공을 주는 습관이 사라지고 누구나 제 몫을 하게 된다. 실제 경기(시험)에는 전원이 뛴다.

## 4. 다시 합치기: 숫자 → 식 → 코드

### 4.1 ReLU와 그 기울기

$$\text{ReLU}(x) = \max(0, x)$$

| x | −2 | −0.5 | 0 | 1.5 | 3 |
|---|---|---|---|---|---|
| ReLU(x) | 0 | 0 | 0 | 1.5 | 3 |
| 기울기 | 0 | 0 | — | **1** | **1** |

- 양수 쪽은 직선 $y = x$라서 기울기 1([M03_미분_기울기](../02_%EC%88%98%ED%95%99%EB%85%B8%ED%8A%B8/M03_%EB%AF%B8%EB%B6%84_%EA%B8%B0%EC%9A%B8%EA%B8%B0.md)의 $(ax)' = a$에서 a = 1).
- 음수 쪽은 수평선 $y = 0$이라서 기울기 0.

### 4.2 시그모이드의 기울기와 기울기 소실

시그모이드의 기울기는 $\sigma(z)(1 - \sigma(z))$이다(유도는 생략, 숫자로 확인).

| z | 0 | 2 | 5 |
|---|---|---|---|
| σ(z) | 0.5 | 0.881 | 0.993 |
| 기울기 σ(1 − σ) | **0.25** (최대) | 0.105 | 0.0066 |

층이 쌓이면 학습 신호(기울기)가 층마다 이 값을 **곱하며** 앞쪽 층으로 전달된다(**[역전파](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EC%97%AD%EC%A0%84%ED%8C%8C)**). 실제로는 [가중치](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EA%B0%80%EC%A4%91%EC%B9%98)도 함께 곱해지지만, 활성화 함수 몫만 떼어 보면 가장 좋은 경우(0.25)만 곱해도:

| 층 수 | 1 | 2 | 3 | 5 | 10 |
|---|---|---|---|---|---|
| $0.25^n$ | 0.25 | 0.0625 | 0.0156 | 0.00098 | 0.00000095 |

앞쪽 층은 기울기가 거의 0이라 가중치가 거의 안 바뀐다. 이것이 **기울기 소실**이다. ReLU는 양수 쪽에서 1을 곱하므로 줄지 않는다.

**예제에서 확인**: 구조가 같은 E09(시그모이드)와 E10(ReLU)의 1번째 바퀴 학습 [정확도](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EC%A0%95%ED%99%95%EB%8F%84)

| | E09 시그모이드 | E10 ReLU |
|---|---|---|
| 1번째 바퀴 학습 정확도 | 0.4930 | **0.8756** |

### 4.3 드롭아웃

학습 중, 값 하나하나를 확률 0.4로 0으로 만들고, 남은 값은 $\frac{1}{1 - 0.4} ≈ 1.667$배 한다.

$$\text{평균} = 0.6 × 1.667 + 0.4 × 0 = 1.0$$

평균이 그대로 유지되므로 시험 때(드롭아웃 끔) 값의 크기가 학습 때와 맞는다. numpy 시뮬레이션: [M08_확률_기초](../02_%EC%88%98%ED%95%99%EB%85%B8%ED%8A%B8/M08_%ED%99%95%EB%A5%A0_%EA%B8%B0%EC%B4%88.md) 6절 (꺼진 비율 0.399, 평균 1.002).

**과적합과의 관계** (E09 → E10):

| | E09 (드롭아웃 없음) | E10 (드롭아웃 0.4) |
|---|---|---|
| 10번째 학습 정확도 | 0.9947 | 0.9904 |
| 10번째 시험 정확도 | 0.9889 | **0.9915** |
| 학습 − 시험 | +0.0058 | **−0.0011** |

- E09는 학습 정확도가 시험보다 높다([학습 데이터](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%ED%95%99%EC%8A%B5-%EB%8D%B0%EC%9D%B4%ED%84%B0%EC%99%80-%EC%8B%9C%ED%97%98-%EB%8D%B0%EC%9D%B4%ED%84%B0)에 더 맞춤).
- E10은 오히려 시험이 더 높다. 학습 때는 40%를 끈 채 어렵게 풀고, 시험 때는 전부 켜고 풀기 때문이다.

### 4.4 코드

```python
model.add(tf.keras.layers.Conv2D(filters=64, kernel_size=3, padding='same', activation='relu'))  # 가중합 → ReLU
model.add(tf.keras.layers.Dropout(rate=0.4))     # 학습 때만 40% 끄기 (가중치 없음)
model.add(tf.keras.layers.MaxPool2D(pool_size=2, strides=2))
```

ReLU를 numpy로:

```python
import numpy as np
x = np.array([-2, -0.5, 0, 1.5, 3])
print(np.maximum(0, x))       # 칸마다 0과 비교해 큰 쪽
```

**실행 결과**:

```
[0.  0.  0.  1.5 3. ]
```

> [!WARNING]
> **⚠ 출력층에는 ReLU를 쓰지 않는다**
> 예제에서도 마지막 [Dense](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dense-%EC%B8%B5)는 `softmax`다. ReLU는 [중간층](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EC%B8%B5)에서 무늬를 걸러 내는 용도이고, 확률을 내야 하는 출력층은 시그모이드·[소프트맥스](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)를 쓴다.
