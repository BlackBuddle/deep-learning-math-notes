# Dense 층과 정규화 (EX_04)

[목차로 돌아가기](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D%EC%88%98%ED%95%99_MOC.md) · 예제: `EX_04_N-variable_M-output_LR_Keras.ipynb` · 코드 풀이: [E04_다변수_다출력_회귀_예제](../03_%EC%98%88%EC%A0%9C%ED%92%80%EC%9D%B4/E04_%EB%8B%A4%EB%B3%80%EC%88%98_%EB%8B%A4%EC%B6%9C%EB%A0%A5_%ED%9A%8C%EA%B7%80_%EC%98%88%EC%A0%9C.md)

> [!NOTE]
> **3줄 요약**
> - `Dense` 층은 **[퍼셉트론](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%ED%8D%BC%EC%85%89%ED%8A%B8%EB%A1%A0)([가중합](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EA%B0%80%EC%A4%91%ED%95%A9)) 여러 개를 나란히 둔 것**이고, 계산은 [행렬 곱](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%ED%96%89%EB%A0%AC-%EA%B3%B1) $XW + b$ 한 줄이다.
> - [가중치](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EA%B0%80%EC%A4%91%EC%B9%98) 개수는 "입력 수 × 출력 수 + 출력 수"다. EX_04는 2 × 2 + 2 = 6.
> - Min-Max 정규화로 입력을 0~1로 맞추면 [기울기](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EA%B8%B0%EC%9A%B8%EA%B8%B0) 크기가 고르게 되어 큰 [학습률](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%ED%95%99%EC%8A%B5%EB%A5%A0)로 빨리 배운다(EX_03: 0.0005·20만 번 → EX_04: 0.1·1000번).

## 1. 이게 하는 일 (말로)

**Dense 층**: 입력 여러 개를 받아 출력 여러 개를 낸다. 출력 하나하나가 [D01_퍼셉트론](D01_%ED%8D%BC%EC%85%89%ED%8A%B8%EB%A1%A0.md)처럼 "입력마다 가중치를 곱해 더하고 [편향](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%ED%8E%B8%ED%96%A5)을 더한" 값이다. 모든 입력이 모든 출력에 연결돼 있어서 "빽빽한(dense)" 층이라고 부른다.

> 비유: 심사위원 2명(출력)이 지원자의 나이·BMI(입력)를 보고 각자 점수를 매긴다. 심사위원마다 항목별 반영 비율(가중치)과 기본 점수(편향)가 다르다.

**Min-Max 정규화**: 단위와 범위가 다른 입력(나이 25~73, BMI 22~30)을 모두 0~1 범위로 맞춘다.

## 4. 다시 합치기: 숫자 → 식 → 코드

### 4.1 Dense를 식으로

한 사람의 입력 $x = [x_1, x_2]$ (정규화한 나이, BMI), 출력 $[\hat{y}_1, \hat{y}_2]$ (수축기, 이완기):

$$\hat{y}_1 = w_{11}x_1 + w_{21}x_2 + b_1 \qquad \hat{y}_2 = w_{12}x_1 + w_{22}x_2 + b_2$$

이걸 행렬로 묶으면:

$$\hat{y} = x\,W + b, \qquad W = \begin{bmatrix} w_{11} & w_{12} \\ w_{21} & w_{22} \end{bmatrix}$$

18명을 한 번에 하면 X가 (18 × 2) 행렬이 되고:

$$\underbrace{\hat{Y}}_{18 \times 2} = \underbrace{X}_{18 \times 2}\;\underbrace{W}_{2 \times 2} + \underbrace{b}_{2}$$

| 기호 | 뜻 | EX_04에서 |
|---|---|---|
| $X$ | 입력 행렬 (사람 × 항목) | 18 × 2 |
| $W$ | 가중치 행렬 (입력 × 출력). **열 하나 = 출력 하나** | 2 × 2 = 4개 |
| $b$ | 편향 (출력마다 하나) | 2개 |
| $\hat{Y}$ | 예측 (사람 × 출력) | 18 × 2 |

Param # = 4 + 2 = **6** → `model.summary()`의 6과 같다.

### 4.2 Dense 계산을 numpy로 흉내 내기

가중치를 임의로 정해서 Dense(2)가 하는 계산을 직접 해 본다([M05_벡터와_행렬](../02_%EC%88%98%ED%95%99%EB%85%B8%ED%8A%B8/M05_%EB%B2%A1%ED%84%B0%EC%99%80_%ED%96%89%EB%A0%AC.md) 4절 숫자).

```python
import numpy as np
W = np.array([[3, 1],
              [2, 4]])      # 입력 2 × 출력 2
b = np.array([1, 1])        # 출력마다 편향
X = np.array([[1, 2],
              [0, 1],
              [2, 0]])      # 3명 × 입력 2
print(X @ W + b)            # 3명 × 출력 2  ← Dense(2)가 하는 일
```

**실행 결과**:

```
[[ 8 10]
 [ 3  5]
 [ 7  3]]
```

Keras의 `Dense(2)`는 이 W와 b를 무작위로 시작해서, `fit`이 [경사하강법](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EA%B2%BD%EC%82%AC%ED%95%98%EA%B0%95%EB%B2%95)([D02_경사하강법으로_직선찾기](D02_%EA%B2%BD%EC%82%AC%ED%95%98%EA%B0%95%EB%B2%95%EC%9C%BC%EB%A1%9C_%EC%A7%81%EC%84%A0%EC%B0%BE%EA%B8%B0.md))으로 고쳐 나간다.

### 4.3 출력이 2개일 때의 MSE

$$\text{MSE} = \frac{1}{18 × 2}\sum_{\text{사람}}\sum_{\text{출력}}(\hat{y} - y)^2$$

오차 36개(18명 × 2)를 제곱해 평균 낸다. 학습 시작 때 예측이 0 근처라 정답 평균(수축기 약 126, 이완기 약 79)을 그대로 오차로 갖고, loss가 약 11000에서 출발했다.

### 4.4 Min-Max 정규화

$$x' = \frac{x - \min}{\max - \min}$$

| 원래 값 | 계산 | 정규화 |
|---|---|---|
| 나이 25 (최소) | (25 − 25) ÷ 48 | 0 |
| 나이 50 | (50 − 25) ÷ 48 | 0.5208 |
| 나이 73 (최대) | (73 − 25) ÷ 48 | 1 |
| BMI 25 | (25 − 22) ÷ 8 | 0.375 |

- 식을 풀면 $x' = \frac{1}{\max - \min}x - \frac{\min}{\max - \min}$, 즉 **일차함수**다([M01_함수와_일차함수](../02_%EC%88%98%ED%95%99%EB%85%B8%ED%8A%B8/M01_%ED%95%A8%EC%88%98%EC%99%80_%EC%9D%BC%EC%B0%A8%ED%95%A8%EC%88%98.md)). 값의 순서와 간격 비율은 그대로 두고 범위만 0~1로 옮긴다.

**왜 학습이 빨라지나**: [M04_편미분](../02_%EC%88%98%ED%95%99%EB%85%B8%ED%8A%B8/M04_%ED%8E%B8%EB%AF%B8%EB%B6%84.md)에서 w 방향 기울기에는 입력 x가 곱해졌다. 나이처럼 x가 크면(평균 50) 그 가중치의 기울기만 매우 커서, 학습률을 크게 하면 튀고(폭발) 작게 하면 다른 가중치가 거의 안 움직인다. 0~1로 맞추면 모든 가중치의 기울기 크기가 비슷해져서 큰 학습률을 쓸 수 있다.

| | EX_03 (정규화 없음) | EX_04 (정규화) |
|---|---|---|
| 학습률 | 0.0005 | 0.1 (200배) |
| 반복 | 200,000번 | 1,000번 |

> [!WARNING]
> **⚠ 예측할 때도 같은 min, max로**
> 새 입력도 **[학습 데이터](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%ED%95%99%EC%8A%B5-%EB%8D%B0%EC%9D%B4%ED%84%B0%EC%99%80-%EC%8B%9C%ED%97%98-%EB%8D%B0%EC%9D%B4%ED%84%B0)의** min(25, 22), max(73, 30)으로 바꿔서 넣어야 한다. 새 데이터의 min, max를 따로 구하면 기준이 달라져 엉뚱한 답이 나온다.
