# 딥러닝 수학 노트

딥러닝 강의 예제 노트북 10개(선형 회귀 → 로지스틱 회귀 → 소프트맥스 → MNIST → CNN)를 따라가며, 코드를 이해하는 데 필요한 **개념과 수학**을 정리한 공부 노트입니다.
지수·로그·미분을 잘 모르는 상태에서 출발해서, 모든 수학을 **말 → 작은 숫자 손계산 → 수식 → 코드** 순서로 처음부터 풀어 썼습니다.

## 노트 형식

모든 노트는 같은 순서로 씁니다.

1. **3줄 요약**
2. **왜 필요한가** — 이게 없으면 생기는 문제
3. **작은 숫자로 손계산** — 표로 한 단계씩
4. **수식과 코드** — 식 변형은 한 줄에 한 동작, 기호는 표로 풀이
5. **스스로 확인** — 질문을 펼치면 답이 보입니다

## 출처와 검증

- **예제**: 딥러닝 강의 예제 노트북(`01_ML_DL_Basic` EX_01~07, `02_CNN` EX_01~03)을 바탕으로 정리했습니다. 예제 풀이(E) 노트의 코드·실행 결과와 `attachments`의 그래프는 이 노트북에서 가져온 것입니다. 원래 실행 환경은 Colab(NumPy 2.0.2, TensorFlow 2.19.0, Matplotlib 3.10.0)입니다.
- **숫자 검증**: 노트에서 새로 계산한 숫자(손계산 표, 비용 함수 값, cross-entropy 재계산 등)는 NumPy로 다시 계산해 확인했습니다. Keras 학습 결과는 노트북에 기록된 값을 그대로 옮겼습니다.
- **미실행 코드**: [K02 Keras 예제모음](04_Keras/K02_Keras_예제모음.md)의 🧪 표시 코드(2~6절)는 아직 실행하지 않은 연습용 변형입니다.
