# 딥러닝 수학 노트

딥러닝 강의 예제 노트북 10개(선형 회귀 → 로지스틱 회귀 → 소프트맥스 → MNIST → CNN)를 따라가며 코드를 이해하는 데 필요한 **개념과 수학**을 정리한 공부 노트입니다.
지수·로그·미분을 잘 모르는 상태에서 출발했기 때문에, 모든 수학을 **말 → 작은 숫자 손계산 → 수식 → 코드** 순서로 처음부터 풀어 썼습니다.

## 노트 형식

**개념 노트(D)** 는 모두 같은 순서로 씁니다. 수학 노트(M)도 1·2절과 마지막 절은 같은 이름을 씁니다.

1. **3줄 요약**
2. **개념 설명**: 비유 하나, 바로 뒤에 정확한 정의
3. **필요한 이유**: 이게 없으면 생기는 문제
4. **필요한 수학 개념**: 어떤 수학이 어디에 쓰이는지 표로 정리하고 미니 복습은 접어 둡니다
5. **계산 과정 (숫자 → 식 → 코드)**: 작은 숫자로 손계산하고 식 변형은 한 줄에 한 동작씩 씁니다. 기호(읽는 법·뜻·예제 값)는 접힌 "기호 풀이" 표에 있습니다
6. **개념 재확인**: 질문을 펼치면 요약 표와 단계별 풀이가 나옵니다. 풀이의 ① 코드에는 줄마다 `# ②`처럼 그 줄을 설명하는 단계 번호가 붙어 있습니다

**예제 풀이(E)** 는 `예제 개요 → 셀별 풀이 → 새로 나온 개념 → 개념 재확인` 순서입니다.

용어는 한글 문장에서는 용어 사전의 한글 이름(손실, 에폭, 덴스 층, 교차 엔트로피 등)으로 쓰고 코드와 Keras 인자(`loss=`, `epochs=`)는 영어 그대로 둡니다.

## Obsidian에서 보기 좋게 (CSS 스니펫)

[obsidian-snippets](obsidian-snippets) 폴더의 CSS 파일 2개를 Obsidian에 넣으면 노트가 더 읽기 편해집니다.

| 스니펫 | 하는 일 |
|---|---|
| `glossary-links.css` | 용어 사전으로 가는 링크를 본문 글자색 그대로 두고 옅은 점선 밑줄만 표시합니다. 용어마다 링크가 걸려 있어도 글이 알록달록해지지 않습니다 |
| `dl-readability.css` | 한글에 맞춘 줄 간격, `##` 제목 아래 구분선, 표 머리줄 배경과 줄무늬, 본문 속 코드 배경, 확인 질문 답의 강조색, 접힌 미니 복습·기호 풀이의 회색 처리, 긴 수식 가로 스크롤 |

### 적용 방법

1. 이 저장소를 받아서 폴더째 Obsidian 금고로 엽니다(**Open folder as vault**). 이미 쓰는 금고가 있다면 노트 폴더를 그 금고 안에 복사해도 됩니다.
2. Obsidian에서 **설정 → 외관(Appearance) → CSS 스니펫(CSS snippets)** 오른쪽의 폴더 아이콘을 누르면 금고의 `.obsidian/snippets` 폴더가 열립니다.
3. 열린 폴더에 `obsidian-snippets` 안의 `glossary-links.css`, `dl-readability.css`를 복사합니다.
4. 같은 화면에서 새로고침 아이콘을 누르고 두 스니펫을 켭니다.

`.obsidian` 폴더는 숨김 폴더라 파일 탐색기에서 안 보일 수 있습니다. 2번처럼 Obsidian에서 열면 바로 찾을 수 있습니다.

### 알아 둘 점

- `dl-readability.css`는 속성(frontmatter)에 `cssclasses: [dl-note]`가 있는 노트에만 적용되어 다른 노트의 모양은 바뀌지 않습니다. 이 저장소의 노트에는 이미 들어 있습니다. 내 노트에도 쓰려면 속성에 같은 줄을 넣으면 됩니다.
- 용어 링크에 마우스를 올리면 용어 사전 설명이 뜹니다. **설정 → 코어 플러그인 → 페이지 미리보기(Page preview)** 가 켜져 있어야 합니다. 편집 보기에서는 기본 설정상 `Ctrl`을 누른 채 올려야 뜨고 이 동작은 페이지 미리보기 설정에서 바꿀 수 있습니다.
- `glossary-links.css`의 효과는 **읽기 보기**(`Ctrl+E`로 전환)에서만 보입니다. 편집 보기에서는 Obsidian이 링크가 어디로 가는지 CSS로 구분하지 못합니다. 편집 보기의 모든 내부 링크를 옅게 하고 싶다면 파일 아래쪽의 주석 처리된 규칙을 풀면 됩니다.

## 출처와 검증

- **예제**: 딥러닝 강의 예제 노트북(`01_ML_DL_Basic` EX_01~07, `02_CNN` EX_01~03)을 바탕으로 정리했습니다. 예제 풀이(E) 노트의 코드·실행 결과와 `attachments`의 `E##_cell…` 그래프는 이 노트북에서 가져왔습니다. D10~D14, M11, E11은 강의 교재의 4·5과와 CNN 개요를 보고 새로 쓴 보충 노트입니다. 교재 문장과 그림은 옮기지 않았고 `D##_fig…`·`M##_fig…` 그림은 노트의 숫자로 직접 그렸습니다. 원래 실행 환경은 Colab(NumPy 2.0.2, TensorFlow 2.19.0, Matplotlib 3.10.0)입니다.
- **숫자 검증**: 손계산 표, 손실 함수 값, 교차 엔트로피, 파라미터 수, 개념 재확인 풀이처럼 노트에서 새로 계산한 숫자는 NumPy로 다시 계산해 확인했습니다. Keras 학습 결과는 노트북에 기록된 값을 그대로 옮겼습니다.
- **미실행 코드**: [K02 Keras 예제모음](04_Keras/K02_Keras_예제모음.md)의 🧪 표시 코드(1.5절, 2~6절)는 아직 실행하지 않은 연습용 변형입니다.

## 형식에 대해

원본은 [Obsidian](https://obsidian.md) 노트입니다. 이 저장소는 GitHub에서 바로 읽을 수 있도록 Obsidian 문법을 일반 마크다운으로 바꾼 사본입니다.

- `[[위키링크]]` → 일반 링크, 그림 임베드 → 일반 이미지
- 접히는 콜아웃(미니 복습, 기호 풀이, 개념 재확인) → `<details>` 접기
- 그 밖의 콜아웃 → GitHub 알림 상자(`NOTE`, `TIP`, `WARNING`)

수식(`$...$`)과 다이어그램(Mermaid)은 GitHub에서 그대로 보입니다. Obsidian으로 폴더를 열어도 읽을 수 있습니다.
