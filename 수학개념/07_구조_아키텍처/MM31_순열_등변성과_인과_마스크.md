[토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) (1,0), (1,1)의 출력 (1, 0.5), (1, 0.6698)은 입력을 뒤집으면 (1, 0.6698), (1, 0.5)가 된다.
> - 순서가 중요하면 두 방법이 있다. (1) [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)에 **[위치 인코딩](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#positional-encoding-%EC%9C%84%EC%B9%98-%EC%9D%B8%EC%BD%94%EB%94%A9)**을 더해 같은 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)도 자리마다 다른 벡터로 만든다. (2) **인과 마스크**로 "앞쪽 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)만 보게" 막는다.
> - 인과 마스크는 점수 표의 대각선 위쪽(미래)을 $-\infty$로 바꾼 뒤 [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)를 한다. $e^{-\infty} = 0$이라 그 칸의 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)가 0이 되고, [어텐션](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#attention-%EC%96%B4%ED%85%90%EC%85%98) 행렬은 아래 삼각 모양이 된다. [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 5개면 25칸 중 15칸만 남는다.

## 1. 개념 설명

비유: 회의실에서 모두가 서로의 의견을 듣고 자기 생각을 고친다([셀프 어텐션](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#self-attention-%EC%85%80%ED%94%84-%EC%96%B4%ED%85%90%EC%85%98)). 좌석 배치를 바꿔도 각자가 듣는 내용은 같으니, 각자 내놓는 결론도 같고 좌석만 바뀐다. 이것이 **순열 등변성**이다. 그런데 시험 감독이 "앞사람 답만 볼 수 있다"고 정하면(인과 마스크) 앉은 순서가 결과를 바꾼다. 맨 앞사람은 아무도 못 보고, 맨 뒷사람은 모두를 본다.

- **순열 행렬** $P$를 곱하면 행의 순서가 바뀐다([MM18_인접행렬과_순열](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/07_%EA%B5%AC%EC%A1%B0_%EC%95%84%ED%82%A4%ED%85%8D%EC%B2%98/MM18_%EC%9D%B8%EC%A0%91%ED%96%89%EB%A0%AC%EA%B3%BC_%EC%88%9C%EC%97%B4.md)). [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 행렬 $T$의 순서를 바꾼 것이 $PT$다.
- [어텐션](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#attention-%EC%96%B4%ED%85%90%EC%85%98)은 순열 등변이다: 점수 표가 $PQK^\top P^\top$로 행과 열이 함께 섞이고, 행별 [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)는 이 섞임을 그대로 따른다. 마지막에 $P^\top P = I$가 사라져 $P\,\text{attn}(T)$가 남는다.
- 토큰별 [MLP](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#multi-layer-perceptron-%EB%8B%A4%EC%B8%B5-%ED%8D%BC%EC%85%89%ED%8A%B8%EB%A1%A0)도 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)마다 같은 함수를 따로 쓰므로 순열 등변이다. 그래서 [트랜스포머](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#transformer-%ED%8A%B8%EB%9E%9C%EC%8A%A4%ED%8F%AC%EB%A8%B8) 전체가 순열 등변이다(집합 → 집합 사상).

$$
\text{attn}(PT) = \text{softmax}\!\Big(\frac{PQ(PK)^\top}{\sqrt{m}}\Big)PV = P\,\text{softmax}\!\Big(\frac{QK^\top}{\sqrt{m}}\Big)P^\top P V = P\,\text{attn}(T)
$$

<details><summary>예제와 풀이</summary>

**문제**: [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) (1, 0), (1, 1)의 [셀프 어텐션](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#self-attention-%EC%85%80%ED%94%84-%EC%96%B4%ED%85%90%EC%85%98) 출력은 [MM30_스케일드_내적_어텐션](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/07_%EA%B5%AC%EC%A1%B0_%EC%95%84%ED%82%A4%ED%85%8D%EC%B2%98/MM30_%EC%8A%A4%EC%BC%80%EC%9D%BC%EB%93%9C_%EB%82%B4%EC%A0%81_%EC%96%B4%ED%85%90%EC%85%98.md)에서 $\text{attn}(T) = \begin{pmatrix}1&0.5\\1&0.6698\end{pmatrix}$였다. 순열 행렬 $P$로 두 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)의 순서를 바꾼 입력 $PT$의 출력을 구해, 원래 출력의 순서만 바꾼 $P\,\text{attn}(T)$와 같은지 확인한다.

**주어진 값**:
- $T = \begin{pmatrix}1&0\\1&1\end{pmatrix}$ (원래 순서의 입력 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0))
- $P = \begin{pmatrix}0&1\\1&0\end{pmatrix}$ (두 줄을 맞바꾸는 순열 행렬)
- $W_Q = W_K = W_V = I$ (사영 없음), $m = 2$ (쿼리·키 차원)

**풀이**
1. 식을 그대로 쓴다: $\text{attn}(PT) = \text{softmax}\Big(\dfrac{PQ(PK)^\top}{\sqrt{m}}\Big)PV = P\,\text{attn}(T)$
2. 값을 대입한다: $\text{attn}\Big(\begin{pmatrix}0&1\\1&0\end{pmatrix}\begin{pmatrix}1&0\\1&1\end{pmatrix}\Big) = \text{softmax}\Big(\dfrac{PT\,(PT)^\top}{\sqrt{2}}\Big)PT$
3. 순열 [행렬 곱](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#matrix-multiplication-%ED%96%89%EB%A0%AC-%EA%B3%B1)을 한다 (1행에 $T$의 2행, 2행에 $T$의 1행이 옴): $PT = \begin{pmatrix}1&1\\1&0\end{pmatrix}$
4. [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81) (1,1)칸을 펼친다: $(1,1)\cdot(1,1) = 1 \times 1 + 1 \times 1 = 2$
5. (1,2)칸: $(1,1)\cdot(1,0) = 1 \times 1 + 1 \times 0 = 1$
6. (2,1)칸: $(1,0)\cdot(1,1) = 1 \times 1 + 0 \times 1 = 1$
7. (2,2)칸: $(1,0)\cdot(1,0) = 1 \times 1 + 0 \times 0 = 1$ 이므로 $\begin{pmatrix}2&1\\1&1\end{pmatrix}$
8. $\sqrt{2}$(제곱하면 2가 되는 양수, 1.4142)로 나눈다: $\begin{pmatrix}1.4142&0.7071\\0.7071&0.7071\end{pmatrix}$
9. 1행 softmax(점수마다 $e^{s}$를 구해 행 합으로 나눔, $e$ = 2.7183)에 대입한다: $\Big(\frac{e^{1.4142}}{e^{1.4142} + e^{0.7071}},\ \frac{e^{0.7071}}{e^{1.4142} + e^{0.7071}}\Big)$
10. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^{1.4142} = 4.1133$, $e^{0.7071} = 2.0281$, 분모 $4.1133 + 2.0281 = 6.1414$
11. 나눗셈을 한다: $4.1133 \div 6.1414 = 0.6698$, $2.0281 \div 6.1414 = 0.3302$
12. 2행 softmax: 두 점수가 같으므로 $2.0281 \div (2.0281 + 2.0281) = 0.5$, 곧 $(0.5, 0.5)$
13. 1행 출력을 펼친다: $0.6698 \times (1, 1) + 0.3302 \times (1, 0) = (0.6698 + 0.3302,\ 0.6698 + 0) = (1, 0.6698)$
14. 2행 출력을 펼친다: $0.5 \times (1, 1) + 0.5 \times (1, 0) = (0.5 + 0.5,\ 0.5 + 0) = (1, 0.5)$
15. 오른쪽 $P\,\text{attn}(T)$를 구한다 (원래 출력의 두 줄을 맞바꿈): $\begin{pmatrix}1&0.6698\\1&0.5\end{pmatrix}$ → 13, 14단계와 같다

**답**: $\text{attn}(PT) = \begin{pmatrix}1&0.6698\\1&0.5\end{pmatrix} = P\,\text{attn}(T)$

**인과 마스크.** [언어 모델](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#language-model-%EC%96%B8%EC%96%B4-%EB%AA%A8%EB%8D%B8)은 다음 단어를 맞히도록 학습한다. [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) $i$의 출력이 $i$보다 뒤의 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)을 보면 답을 미리 보는 셈이다. 그래서 점수 표에 마스크 $M$을 더한다.

$$
M_{ij} = \begin{cases} 0 & j \le i \\ -\infty & j > i \end{cases}, \qquad
A = \text{softmax}\!\Big(\frac{QK^\top}{\sqrt{m}} + M\Big)
$$

**주어진 값**:
- $QK^\top/\sqrt{m} = \begin{pmatrix}0.7071&0.7071\\0.7071&1.4142\end{pmatrix}$ (스케일드 점수, [MM30_스케일드_내적_어텐션](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/07_%EA%B5%AC%EC%A1%B0_%EC%95%84%ED%82%A4%ED%85%8D%EC%B2%98/MM30_%EC%8A%A4%EC%BC%80%EC%9D%BC%EB%93%9C_%EB%82%B4%EC%A0%81_%EC%96%B4%ED%85%90%EC%85%98.md)의 예제)
- $M = \begin{pmatrix}0&-\infty\\0&0\end{pmatrix}$ (1행 2열 = [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 1이 미래인 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 2를 보는 칸만 막음)
- $V = \begin{pmatrix}1&0\\1&1\end{pmatrix}$ (값 행렬, $W_V = I$라 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)과 같음)

**풀이**
1. 식을 그대로 쓴다: $A = \text{softmax}\Big(\dfrac{QK^\top}{\sqrt{m}} + M\Big)$, $T_{\text{out}} = AV$
2. 값을 대입한다: $A = \text{softmax}\Big(\begin{pmatrix}0.7071&0.7071\\0.7071&1.4142\end{pmatrix} + \begin{pmatrix}0&-\infty\\0&0\end{pmatrix}\Big)$
3. 칸끼리 덧셈을 한다: $\begin{pmatrix}0.7071&-\infty\\0.7071&1.4142\end{pmatrix}$ (어떤 수에 $-\infty$를 더해도 $-\infty$)
4. $e^{-\infty}$의 뜻: $e$(= 2.7183)의 [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)가 한없이 작아지면 값이 0에 다가가므로 $e^{-\infty} = 0$
5. 1행 softmax에 대입한다: $\Big(\frac{e^{0.7071}}{e^{0.7071} + e^{-\infty}},\ \frac{e^{-\infty}}{e^{0.7071} + e^{-\infty}}\Big) = \Big(\frac{2.0281}{2.0281 + 0},\ \frac{0}{2.0281 + 0}\Big)$
6. 나눗셈을 한다: $(1, 0)$
7. 2행 softmax에 대입한다: $\Big(\frac{e^{0.7071}}{e^{0.7071} + e^{1.4142}},\ \frac{e^{1.4142}}{e^{0.7071} + e^{1.4142}}\Big) = \Big(\frac{2.0281}{6.1414},\ \frac{4.1133}{6.1414}\Big)$
8. 나눗셈을 한다: $(0.3302, 0.6698)$ 이므로 $A = \begin{pmatrix}1&0\\0.3302&0.6698\end{pmatrix}$
9. $AV$의 1행을 펼친다: $1 \times (1, 0) + 0 \times (1, 1) = (1, 0)$ → [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 1은 자기만 본다
10. $AV$의 2행을 펼친다: $0.3302 \times (1, 0) + 0.6698 \times (1, 1) = (0.3302 + 0.6698,\ 0 + 0.6698) = (1, 0.6698)$

**답**: $A = \begin{pmatrix}1&0\\0.3302&0.6698\end{pmatrix}$, 출력 $\begin{pmatrix}1&0\\1&0.6698\end{pmatrix}$

## 4. 코드로 확인

```python
# [함수] def softmax(Z): 행마다 소프트맥스. -inf 칸은 e^-inf = 0이 된다
def softmax(Z):
    # [변수] Z: 행 최댓값을 빼서 넘침을 막는다 (결과는 같다)
    Z = Z - Z.max(axis=1, keepdims=True)
    # [변수] E: 각 칸의 e^z
    E = np.exp(Z)
    # [함수] 행 합으로 나누어 행 합 1
    return E / E.sum(axis=1, keepdims=True)
# [함수] def attn(X, mask): 사영을 단위행렬로 둔 셀프 어텐션. mask=True면 인과 마스크
def attn(X, mask=False):
    # [변수] S: 스케일드 점수 X X^T / √m
    S = X @ X.T / np.sqrt(X.shape[1])
    # [함수] if mask: 인과 마스크를 쓸 때만
    if mask:
        # [함수] np.triu(..., 1): 대각선 바로 위부터의 위 삼각을 -inf로 채운 마스크 M
        # [연결] 본문 1절의 M 식 (j > i 이면 -inf)
        S = S + np.triu(np.full(S.shape, -np.inf), 1)
    # [함수] softmax(S) @ X: 가중치로 값(= X)을 섞는다
    return softmax(S) @ X
# [변수] T: 토큰 (1,0), (0,1), (1,1)
# [연결] 본문 3절 표
T = np.array([[1.0, 0], [0, 1], [1, 1]])
# [변수] P: 토큰 1과 2를 맞바꾸는 순열 행렬
P = np.array([[0, 1, 0], [1, 0, 0], [0, 0, 1.0]])
# [함수] np.allclose: 두 결과가 같은지 확인 → True면 순열 등변
# [연결] 본문 1절 attn(PT) = P attn(T)
print(np.allclose(attn(P @ T), P @ attn(T)))
# [연결] 본문 3절 표의 "마스크 뒤 출력" 열 → (1,0), (0.3302,0.6698), (0.7517,0.7517)
print(attn(T, mask=True).round(4))
# [함수] 마스크를 씌운 뒤의 순열: 이제는 같지 않다 → False
# [쓸모] 인과 마스크가 순서를 중요하게 만든다는 확인
print(np.allclose(attn(P @ T, True), P @ attn(T, True)))
# [변수] pos: 자리마다 더할 위치 벡터 (0,0), (1,1)
pos = np.array([[0.0, 0], [1, 1]])
# [변수] U: 토큰 두 개 (1,0), (0,1)
U = np.array([[1.0, 0], [0, 1]])
# [변수] P2: 두 줄을 맞바꾸는 순열 행렬
P2 = np.array([[0, 1], [1, 0.0]])
# [연결] 본문 3절 "위치 인코딩으로 등변성 깨기": 원래 순서의 출력
print(attn(U + pos).round(4))
# [연결] 토큰 순서만 바꾸고 위치 벡터는 자리에 그대로 둔 출력 → 줄만 바뀐 것과 다르다
print(attn(P2 @ U + pos).round(4))
```

[토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)마다 출력을 내는 [트랜스포머](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#transformer-%ED%8A%B8%EB%9E%9C%EC%8A%A4%ED%8F%AC%EB%A8%B8) [층](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#layer-%EC%B8%B5)은 등변이고, 출력 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)들을 평균 내어 하나로 줄이면 불변이 된다.
> - 코드에서 $-\infty$ 대신 아주 큰 음수(-1e9)를 쓰는 구현도 많다. 결과는 사실상 같다. 다만 한 행이 모두 $-\infty$이면 $0/0$이 되어 계산이 깨지므로, 인과 마스크는 늘 대각선(자기 자신)을 남긴다.
> - 인과 마스크만으로도 순서 정보가 일부 생기지만([토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 1은 늘 자기만 봄), 보통은 [위치 인코딩](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#positional-encoding-%EC%9C%84%EC%B9%98-%EC%9D%B8%EC%BD%94%EB%94%A9)을 함께 쓴다.

<details><summary>1. 토큰이 5개인 문장에 인과 마스크를 씌우면 어텐션 행렬 25칸 중 몇 칸이 0이 아닐 수 있나? 마지막 토큰은 몇 개를 보나?</summary>

| 단계 | 하는 일 | 식 | 계산 | 결과 |
|---|---|---|---|---|
| 1 | 행별 칸 수 | [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) $i$는 $i$개를 봄 | 1, 2, 3, 4, 5 | - |
| 2 | 합 | $n(n+1)/2$ | 5 × 6 / 2 | 15 |
| 3 | 전체 | $n^2$ | 25 | 25 |
| 4 | 마지막 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) | $i = n$ | 5 | 5 |

**① 쓰는 식**
$$\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$$
- 위 식 ← ② (행별 개수), ③ (합)에서 쓴다.
```python
# [변수] n: 토큰 수
n = 5                                                     # ①
# [함수] np.tril(np.ones): 아래 삼각(대각 포함)만 1인 행렬 = 볼 수 있는 칸
allowed = np.tril(np.ones((n, n)))                         # ②
# [연결] 15 25 5 → 남는 칸, 전체 칸, 마지막 행이 보는 토큰 수
print(int(allowed.sum()), n * n, int(allowed[-1].sum()))   # ③④
```

**주어진 값**:
- $n = 5$ (문장의 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 수)

**② 행별 개수**
1. [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) $i$는 자기와 앞쪽, 곧 $i$개를 본다: [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 1은 1개, [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 2는 2개, [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 3은 3개, [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 4는 4개, [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 5는 5개

**③ 합**
1. 식을 그대로 쓴다: $\sum_{i=1}^{n} i = \dfrac{n(n+1)}{2}$
2. $\sum$(시그마, 차례로 더하기)를 펼쳐 대입한다: $1 + 2 + 3 + 4 + 5 = \dfrac{5 \times (5 + 1)}{2}$
3. 왼쪽 덧셈을 한다: $1 + 2 + 3 + 4 + 5 = 15$
4. 오른쪽 괄호를 먼저 한다: $5 + 1 = 6$ 이므로 $\dfrac{5 \times 6}{2}$
5. 곱셈을 한다: $5 \times 6 = 30$ 이므로 $\dfrac{30}{2}$
6. 나눗셈을 한다: $30 \div 2 = 15$ → 양쪽이 같다. 전체 칸 수는 $5 \times 5 = 25$

**④ 마지막 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)**
1. $i = n = 5$를 대입한다: 5개 전부

**답**: **15**칸 (25칸 중), 마지막 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0)은 **5**개를 모두 본다.

<details><summary>2. 토큰 (2, 0), (0, 2)를 $W = I$, $m = 2$인 인과 어텐션에 넣는다. 둘째 출력 토큰을 구하라.</summary>

| 단계 | 하는 일 | 식 | 계산 | 결과 |
|---|---|---|---|---|
| 1 | 2행 점수 | $\mathbf{t}_2 \cdot \mathbf{t}_j / \sqrt2$ | 0/1.4142, 4/1.4142 | (0, 2.8284) |
| 2 | 마스크 | $j \le 2$ | 둘 다 볼 수 있음 | 그대로 |
| 3 | [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4) | $e^{0}, e^{2.8284}$ | 1, 16.9188 | (0.0558, 0.9442) |
| 4 | [가중합](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weighted-sum-%EA%B0%80%EC%A4%91%ED%95%A9) | $0.0558(2,0) + 0.9442(0,2)$ | | (0.1116, 1.8884) |

**① 쓰는 식**
$$\mathbf{t}^{\text{out}}_2 = \sum_{j \le 2} \text{softmax}_j\Big(\frac{\mathbf{t}_2 \cdot \mathbf{t}_j}{\sqrt{2}}\Big)\,\mathbf{t}_j$$
- 위 식 ← ② (점수), ③ (마스크), ④ ([소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)), ⑤ ([가중합](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weighted-sum-%EA%B0%80%EC%A4%91%ED%95%A9))
```python
# [변수] X: 토큰 두 개
X = np.array([[2.0, 0], [0, 2]])                            # ①
# [변수] s: 둘째 토큰의 스케일드 점수 → (0, 2.8284)
s = X @ X[1] / np.sqrt(2)                                   # ②③
# [변수] a: 소프트맥스 가중치
a = np.exp(s) / np.exp(s).sum()                             # ④
# [연결] [0.0558 0.9442] [0.1116 1.8884]
print(a.round(4), (a @ X).round(4))                         # ⑤
```

**주어진 값**:
- $\mathbf{t}_1 = (2, 0)$, $\mathbf{t}_2 = (0, 2)$ (입력 [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0). $W = I$라 쿼리·키·값도 같음)
- $m = 2$ (쿼리·키 차원)

**② 점수**
1. 식을 그대로 쓴다: $s_j = \dfrac{\mathbf{t}_2 \cdot \mathbf{t}_j}{\sqrt{2}}$
2. 값을 대입한다: $\mathbf{s} = \Big(\dfrac{(0, 2)\cdot(2, 0)}{\sqrt{2}},\ \dfrac{(0, 2)\cdot(0, 2)}{\sqrt{2}}\Big)$
3. 첫 [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)을 펼친다: $0 \times 2 + 2 \times 0 = 0$
4. 둘째 [내적](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dot-product-%EB%82%B4%EC%A0%81)을 펼친다: $0 \times 0 + 2 \times 2 = 4$
5. $\sqrt{2}$(제곱하면 2가 되는 양수, 1.4142)로 나눈다: $0 \div 1.4142 = 0$, $4 \div 1.4142 = 2.8284$ 이므로 $\mathbf{s} = (0, 2.8284)$

**③ 마스크**
1. [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 2의 줄에서 $j \le 2$인 칸은 $M_{2j} = 0$ → [토큰](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#token-%ED%86%A0%ED%81%B0) 1과 2를 모두 볼 수 있어 점수가 그대로다

**④ [소프트맥스](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#softmax-%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4)**
1. 식에 대입한다 (점수마다 $e^{s}$를 구해 합으로 나눔, $e$ = 2.7183): $\Big(\frac{e^{0}}{e^{0} + e^{2.8284}},\ \frac{e^{2.8284}}{e^{0} + e^{2.8284}}\Big)$
2. [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다: $e^0 = 1$, $e^{2.8284} = 16.9188$
3. 분모의 덧셈을 한다: $1 + 16.9188 = 17.9188$
4. 나눗셈을 한다: $1 \div 17.9188 = 0.0558$, $16.9188 \div 17.9188 = 0.9442$

**⑤ [가중합](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weighted-sum-%EA%B0%80%EC%A4%91%ED%95%A9)**
1. 대입한다: $\mathbf{t}^{\text{out}}_2 = 0.0558 \times (2, 0) + 0.9442 \times (0, 2)$
2. 첫 칸을 펼친다: $0.0558 \times 2 + 0.9442 \times 0 = 0.1116 + 0 = 0.1116$
3. 둘째 칸을 펼친다: $0.0558 \times 0 + 0.9442 \times 2 = 0 + 1.8884 = 1.8884$

**답**: $\mathbf{t}^{\text{out}}_2 = (0.1116, 1.8884)$. 자기와 닮은 자기 자신을 94%의 비중으로 본다.
