> [!NOTE]
> **3줄 요약**
> - [위치 인코딩](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#positional-encoding-%EC%9C%84%EC%B9%98-%EC%9D%B8%EC%BD%94%EB%94%A9)(Positional encoding)은 **"여기가 어디인지"를 숫자 묶음으로 만들어 입력에 붙이는 것**이다. 사인파 방식은 위치 $p$를 여러 주파수의 $\sin$, $\cos$ 값으로 바꾼다: $\gamma(p) = (\sin 2^0\pi p,\ \cos 2^0\pi p,\ \dots,\ \sin 2^{L-1}\pi p,\ \cos 2^{L-1}\pi p)$.
> - $L = 3$이면 $p = 0.25$는 $(0.7071, 0.7071, 1, 0, 0, -1)$, $p = 0.75$는 $(0.7071, -0.7071, -1, 0, 0, -1)$이 된다. 가까운 위치는 비슷한 묶음, 먼 위치는 다른 묶음이 된다.
> - [합성곱](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#convolution-%ED%95%A9%EC%84%B1%EA%B3%B1)은 위치를 모르기 때문에 같은 무늬에 같은 값을 낸다. 위치 [채널](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#channel-%EC%B1%84%EB%84%90)을 붙이면 같은 무늬라도 위치마다 다른 값을 낼 수 있다(4 → 4.2와 4.8).

## 1. 개념 설명

비유: 시계는 바늘 셋으로 시각을 나타낸다. 초침은 빨리 돌고, 분침은 그보다 느리고, 시침은 가장 느리다. 초침 하나만 보면 몇 분인지 모르고, 시침 하나만 보면 몇 초인지 모른다. **빠르기가 다른 바늘 여러 개를 함께 보면** 시각을 정확히 알 수 있다. 사인파 [위치 인코딩](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#positional-encoding-%EC%9C%84%EC%B9%98-%EC%9D%B8%EC%BD%94%EB%94%A9)은 위치 $p$를 빠르기(주파수)가 두 배씩 다른 바늘 여러 개의 각도로 적는 방법이다. $\sin$과 $\cos$을 짝으로 쓰는 것은 바늘 끝의 가로·세로 좌표를 함께 적는 것과 같다.

- 주파수가 낮은 짝($2^0\pi p$)은 큰 위치 차이를 구분한다.
- 주파수가 높은 짝($2^{L-1}\pi p$)은 작은 위치 차이를 구분한다.
- 값은 늘 $-1$~$1$ 사이라 위치가 커져도 숫자가 폭주하지 않는다.

$$
\gamma(p) = \big(\sin(2^0\pi p),\ \cos(2^0\pi p),\ \sin(2^1\pi p),\ \cos(2^1\pi p),\ \dots,\ \sin(2^{L-1}\pi p),\ \cos(2^{L-1}\pi p)\big)
$$

| 기호 | 읽는 법 | 뜻 | 예제 값 |
| --- | --- | --- | --- |
| $\gamma(p)$ | 감마 피 | 위치 p의 [위치 인코딩](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#positional-encoding-%EC%9C%84%EC%B9%98-%EC%9D%B8%EC%BD%94%EB%94%A9) 묶음 (길이 2L) | (0.8660, 0.5, 0.8660, −0.5) |
| $p$ | 피 | 위치 (0~1로 맞춘 좌표) | 1/3 |
| $\sin,\ \cos$ | 사인, 코사인 | 각도를 바늘 끝의 세로·가로 좌표로 바꾸는 함수 | $\sin(\pi/3) = 0.8660$ |
| $\pi$ | 파이 | 반 바퀴 각도 (180°) | 3.1416 |
| $2^0, 2^1, \dots, 2^{L-1}$ | 이의 영 제곱 … 이의 엘마이너스일 제곱 | 짝마다 두 배씩 빨라지는 주파수 배율 | 1, 2 |
| $L$ | 엘 | sin·cos 짝의 개수 | 2 |
| $\dots$ | 점점점 | 가운데 짝들을 줄여 쓴 것 | - |

</details>

<details><summary>예제와 풀이</summary>

**문제**: 주파수 짝 2개(L = 2)로 위치 p = 1/3을 인코딩한 숫자 묶음 γ(1/3)을 구한다.

**주어진 값**:
- $L = 2$ (sin·cos 짝의 개수. 마지막 짝은 $2^{L-1} = 2^1$)
- $p = 1/3$ (인코딩할 위치, 0~1 좌표)

**풀이**
1. 식을 그대로 쓴다: $\gamma(p) = \big(\sin(2^0\pi p),\ \cos(2^0\pi p),\ \sin(2^1\pi p),\ \cos(2^1\pi p),\ \dots,\ \sin(2^{L-1}\pi p),\ \cos(2^{L-1}\pi p)\big)$
2. 값을 대입한다 (L = 2라 $2^1$ 짝에서 끝나고 $\dots$은 없다): $\gamma(\tfrac{1}{3}) = \big(\sin(2^0\pi \cdot \tfrac{1}{3}),\ \cos(2^0\pi \cdot \tfrac{1}{3}),\ \sin(2^1\pi \cdot \tfrac{1}{3}),\ \cos(2^1\pi \cdot \tfrac{1}{3})\big)$
3. 거듭제곱을 계산한다: $2^0 = 1$, $2^1 = 2$ 이므로 $\big(\sin\tfrac{\pi}{3},\ \cos\tfrac{\pi}{3},\ \sin\tfrac{2\pi}{3},\ \cos\tfrac{2\pi}{3}\big)$
4. $\pi$의 뜻: 반 바퀴 각도, 곧 180°다. 나눗셈을 한다: $\tfrac{\pi}{3} = 180° \div 3 = 60°$
5. 곱셈을 한다: $\tfrac{2\pi}{3} = 2 \times 60° = 120°$ 이므로 $(\sin 60°,\ \cos 60°,\ \sin 120°,\ \cos 120°)$
6. sin, cos의 뜻: 반지름 1인 원에서 그 각도만큼 돈 점의 세로 좌표가 sin, 가로 좌표가 cos다. 60°에서는 $\sin 60° = \tfrac{\sqrt{3}}{2}$, $\cos 60° = \tfrac{1}{2}$ (정삼각형을 반으로 자른 직각삼각형의 변 길이)
7. $\sqrt{3}$의 뜻: 제곱하면 3이 되는 양수로, 계산기(코드 `math.sqrt(3)`)로 구하면 1.7321이다. 나눗셈을 한다: $\tfrac{\sqrt{3}}{2} = 1.7321 \div 2 = 0.8660$
8. 나눗셈을 한다: $\tfrac{1}{2} = 0.5$ 이므로 $\sin 60° = 0.8660$, $\cos 60° = 0.5$
9. 120°를 60°와 비교한다: 120°는 60°를 세로축 반대편으로 뒤집은 자리라 세로 좌표는 같고 가로 좌표는 부호만 바뀐다. 곧 $\sin 120° = 0.8660$, $\cos 120° = -0.5$
10. 순서대로 묶는다: $\gamma(\tfrac{1}{3}) = (0.8660,\ 0.5,\ 0.8660,\ -0.5)$

**답**: $\gamma(1/3) = (0.8660,\ 0.5,\ 0.8660,\ -0.5)$, 길이 $2L = 4$

</details>

## 4. 코드로 확인

```python
# [함수] def gamma(p, L): 위치 p를 길이 2L의 사인파 묶음으로 바꾼다
# [쓸모] 본문 1절 식 γ(p)를 그대로 옮긴 것
def gamma(p, L=3):
    # [함수] np.arange(L): 0, 1, ..., L-1. [변수] ang: 각도 2^i π p (i = 0, 1, 2)
    ang = 2.0 ** np.arange(L) * np.pi * p
    # [함수] np.stack(..., axis=1).ravel(): (sin, cos) 짝을 차례로 한 줄에 늘어놓는다
    # [변수] 반환값: (sin a0, cos a0, sin a1, cos a1, sin a2, cos a2)
    return np.stack([np.sin(ang), np.cos(ang)], axis=1).ravel()
# [함수] np.round(v, 4) + 0.0: 넷째 자리 반올림, + 0.0은 -0.0을 0.0으로 바꾸려는 것
# [연결] 본문 3절 표 γ(0.25), γ(0.75)
print(np.round(gamma(0.25), 4) + 0.0)
print(np.round(gamma(0.75), 4) + 0.0)
# [함수] np.linalg.norm: 두 묶음 차이의 길이(거리)
# [연결] 본문 3절 "가까운 위치와 먼 위치": 0.7103, 2.4495
print(round(np.linalg.norm(gamma(0.25) - gamma(0.30)), 4), round(np.linalg.norm(gamma(0.25) - gamma(0.75)), 4))
# [변수] x: 위치 1과 4에 같은 무늬 2가 있는 신호
x = np.array([0, 2, 0, 0, 2, 0])
# [함수] np.correlate(np.pad(x, 1), [1, 2, 1], "valid"): 0 패딩 후 필터 (1, 2, 1)로 합성곱
# [변수] y: (2, 4, 2, 2, 4, 2). 위치 1과 4가 같다
y = np.correlate(np.pad(x, 1), [1, 2, 1], mode="valid")
# [함수] np.arange(6) / 5: 위치 채널 0, 0.2, ..., 1.0
# [변수] y_pos: 위치 채널을 가중치 1로 더한 출력
y_pos = y + np.arange(6) / 5
# [연결] 본문 3절 마지막: 4와 4 → 4.2와 4.8
print(y, np.round(y_pos, 1))
```

> [!WARNING]
> **⚠ 주의**
> - [위치 인코딩](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#positional-encoding-%EC%9C%84%EC%B9%98-%EC%9D%B8%EC%BD%94%EB%94%A9)은 **학습하는 값이 아니라 정해서 붙이는 값**이다(강의: "학습하지 않고 만들어서 입력에 더한다"). [트랜스포머](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#transformer-%ED%8A%B8%EB%9E%9C%EC%8A%A4%ED%8F%AC%EB%A8%B8) 일부는 위치 벡터 자체를 학습하기도 하는데, 그것은 다른 방식이다.
> - 이 노트의 주파수 $2^i\pi$는 [NeRF](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#nerf-%EC%8B%A0%EA%B2%BD-%EB%B0%A9%EC%82%AC%EC%9E%A5) 방식이다. [트랜스포머](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#transformer-%ED%8A%B8%EB%9E%9C%EC%8A%A4%ED%8F%AC%EB%A8%B8) 원 논문은 $10000^{2i/d}$로 나누는 다른 주파수 배치를 쓴다. 생각은 같다: 여러 빠르기의 사인파.
> - 위치 [채널](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#channel-%EC%B1%84%EB%84%90) 하나($n/5$)만 붙이는 것도 [위치 인코딩](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#positional-encoding-%EC%9C%84%EC%B9%98-%EC%9D%B8%EC%BD%94%EB%94%A9)이지만, 값 하나로는 세밀한 위치 차이를 표현하기 어렵다. 그래서 여러 주파수를 쓴다.
> - 사인파는 주기가 있어서, 가장 느린 짝의 한 주기(여기서는 $p$ 폭 2)를 넘어가면 같은 묶음이 다시 나온다. 위치를 0~1로 맞추는 이유다.

## 5. 개념 재확인

<details><summary>1. $L = 2$일 때 $p = 0.5$의 인코딩 $\gamma(0.5)$는?</summary>

| 단계 | 하는 일 | 식 | 계산 | 결과 |
|---|---|---|---|---|
| 1 | 각도 i = 0 | $2^0 \pi p$ | $\pi \times 0.5$ | $\pi/2$ |
| 2 | 각도 i = 1 | $2^1 \pi p$ | $2\pi \times 0.5$ | $\pi$ |
| 3 | 첫 짝 | $\sin, \cos$ of $\pi/2$ | 90° | (1, 0) |
| 4 | 둘째 짝 | $\sin, \cos$ of $\pi$ | 180° | (0, −1) |

**① 쓰는 식**
$$\gamma(p) = (\sin 2^0\pi p,\ \cos 2^0\pi p,\ \sin 2^1\pi p,\ \cos 2^1\pi p)$$
- 위 식 ← ② ③ (각도 구하기), ④ ⑤ (sin, cos 값)에서 쓴다.
```python
# [변수] p = 0.5, L = 2: 문제에서 준 값
p, L = 0.5, 2                                                  # ①
# [변수] a0 = π/2: 가장 느린 짝의 각도
a0 = 2**0 * np.pi * p                                          # ②
# [변수] a1 = π: 두 배 빠른 짝의 각도
a1 = 2**1 * np.pi * p                                          # ③
# [변수] code: (sin a0, cos a0, sin a1, cos a1). + 0.0은 -0.0 정리
code = np.round([np.sin(a0), np.cos(a0), np.sin(a1), np.cos(a1)], 4) + 0.0   # ④⑤
# [연결] 답 (1, 0, 0, -1)
print(code)
```

**주어진 값**
- $p = 0.5$ (위치)
- $L = 2$ (sin·cos 짝의 개수, 주파수 배율 $2^0, 2^1$)
- $\pi$ = 반 바퀴 = 180° (각도를 도로 바꿀 때 쓴다)

**② 각도 i = 0**
- 식을 쓴다: 각도 $= 2^i \pi p$
- 값을 대입한다: 각도 $= 2^0 \times \pi \times 0.5$
- 거듭제곱을 한다: $2^0 = 1$ (어떤 수의 0제곱은 1) 이므로 각도 $= 1 \times \pi \times 0.5$
- 곱셈을 한다: 1 × 0.5 = 0.5 이므로 각도 $= 0.5\pi = \pi/2$ (180° × 0.5 = 90°)

**③ 각도 i = 1**
- 값을 대입한다: 각도 $= 2^1 \times \pi \times 0.5$
- 거듭제곱을 한다: $2^1 = 2$ 이므로 각도 $= 2 \times \pi \times 0.5$
- 곱셈을 한다: 2 × 0.5 = 1 이므로 각도 $= \pi$ (180°)

**④ 첫 짝**
- 식을 쓴다: (sin 각도, cos 각도). sin은 원 위의 점의 세로 좌표, cos는 가로 좌표다.
- 값을 대입한다: $(\sin 90°,\ \cos 90°)$
- 90°는 원의 맨 위 점이다 (가로 0, 세로 1): $\sin 90° = 1$, $\cos 90° = 0$ 이므로 첫 짝 $= (1, 0)$

**⑤ 둘째 짝**
- 값을 대입한다: $(\sin 180°,\ \cos 180°)$
- 180°는 원의 맨 왼쪽 점이다 (가로 −1, 세로 0): $\sin 180° = 0$, $\cos 180° = -1$ 이므로 둘째 짝 $= (0, -1)$
- 순서대로 묶는다: $\gamma(0.5) = (1, 0, 0, -1)$

**답**: $\gamma(0.5) = $ **(1, 0, 0, −1)**

<details><summary>2. 신호 $x = (0, 3, 0, 3, 0)$, 필터 $(1, 1, 1)$, 끝은 0 패딩. 위치 1과 3의 출력은? 위치 채널 $\text{pos}[n] = n/4$를 가중치 $v = 2$로 더하면?</summary>

| 단계 | 하는 일 | 식 | 계산 | 결과 |
|---|---|---|---|---|
| 1 | 위치 1 [합성곱](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#convolution-%ED%95%A9%EC%84%B1%EA%B3%B1) | $x[0] + x[1] + x[2]$ | $0 + 3 + 0$ | 3 |
| 2 | 위치 3 [합성곱](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#convolution-%ED%95%A9%EC%84%B1%EA%B3%B1) | $x[2] + x[3] + x[4]$ | $0 + 3 + 0$ | 3 |
| 3 | 위치 1 + 위치 [채널](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#channel-%EC%B1%84%EB%84%90) | $3 + 2 \times 1/4$ | $3 + 0.5$ | 3.5 |
| 4 | 위치 3 + 위치 [채널](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#channel-%EC%B1%84%EB%84%90) | $3 + 2 \times 3/4$ | $3 + 1.5$ | 4.5 |

**① 쓰는 식**
$$y'[n] = \sum_{k=-1}^{1} w[k]\,x[n+k] + v \cdot \text{pos}[n]$$
- 위 식 ← 앞부분은 ② ③ ([합성곱](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#convolution-%ED%95%A9%EC%84%B1%EA%B3%B1)), 뒷부분은 ④ ⑤ (위치 [채널](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#channel-%EC%B1%84%EB%84%90) 더하기)에서 쓴다.
```python
# [변수] x: 위치 1과 3에 같은 무늬 3. v = 2: 위치 채널 가중치
x, v = np.array([0, 3, 0, 3, 0]), 2                            # ①
# [변수] y: 합성곱 결과 (3, 3, 6, 3, 3). 위치 1과 3이 같다
y = np.correlate(np.pad(x, 1), [1, 1, 1], mode="valid")       # ②③
# [변수] y_pos: y + 2 × n/4. 위치마다 0, 0.5, 1, 1.5, 2를 더한다
y_pos = y + v * np.arange(5) / 4                               # ④⑤
# [연결] 위치 1과 3: (3, 3) → (3.5, 4.5)
print(y[1], y[3], y_pos[1], y_pos[3])
```

**주어진 값**
- $x = (0, 3, 0, 3, 0)$, 곧 $x[0] = 0,\ x[1] = 3,\ x[2] = 0,\ x[3] = 3,\ x[4] = 0$ (입력)
- $w[-1] = w[0] = w[1] = 1$ ([필터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#filter-%ED%95%84%ED%84%B0)), 끝은 0 [패딩](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#padding-%ED%8C%A8%EB%94%A9)
- $v = 2$ (위치 [채널](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#channel-%EC%B1%84%EB%84%90) [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)), $\text{pos}[n] = n/4$ (위치 [채널](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#channel-%EC%B1%84%EB%84%90))

**② 위치 1 [합성곱](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#convolution-%ED%95%A9%EC%84%B1%EA%B3%B1)**
- 식을 쓴다: $y'[n] = \sum_{k=-1}^{1} w[k]\,x[n+k] + v \cdot \text{pos}[n]$ (여기서는 앞 합 부분만)
- 시그마를 세 항으로 풀어 값을 대입한다 (n = 1): $1 \times x[0] + 1 \times x[1] + 1 \times x[2] = 1 \times 0 + 1 \times 3 + 1 \times 0$
- 곱셈을 한다: $0 + 3 + 0$
- 덧셈을 한다: 0 + 3 = 3, 3 + 0 = 3

**③ 위치 3 [합성곱](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#convolution-%ED%95%A9%EC%84%B1%EA%B3%B1)**
- 값을 대입한다 (n = 3): $1 \times x[2] + 1 \times x[3] + 1 \times x[4] = 1 \times 0 + 1 \times 3 + 1 \times 0$
- 곱셈과 덧셈을 한다: $0 + 3 + 0 = 3$ (같은 무늬라 같은 값)

**④ 위치 1 + 위치 [채널](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#channel-%EC%B1%84%EB%84%90)**
- 식을 쓴다: $y'[n] = (\text{합성곱 값}) + v \cdot \text{pos}[n]$
- 값을 대입한다 (n = 1): $y'[1] = 3 + 2 \times \text{pos}[1]$, $\text{pos}[1] = 1/4$
- 나눗셈을 한다: 1 ÷ 4 = 0.25 이므로 $y'[1] = 3 + 2 \times 0.25$
- 곱셈을 한다: 2 × 0.25 = 0.5 이므로 $y'[1] = 3 + 0.5$
- 덧셈을 한다: 3 + 0.5 = 3.5

**⑤ 위치 3 + 위치 [채널](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#channel-%EC%B1%84%EB%84%90)**
- 값을 대입한다 (n = 3): $y'[3] = 3 + 2 \times \text{pos}[3]$, $\text{pos}[3] = 3/4$
- 나눗셈을 한다: 3 ÷ 4 = 0.75 이므로 $y'[3] = 3 + 2 \times 0.75$
- 곱셈을 한다: 2 × 0.75 = 1.5 이므로 $y'[3] = 3 + 1.5$
- 덧셈을 한다: 3 + 1.5 = 4.5

**답**: [합성곱](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#convolution-%ED%95%A9%EC%84%B1%EA%B3%B1)만 쓰면 둘 다 **3**, 위치 [채널](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#channel-%EC%B1%84%EB%84%90)을 더하면 **3.5와 4.5**로 구분된다
