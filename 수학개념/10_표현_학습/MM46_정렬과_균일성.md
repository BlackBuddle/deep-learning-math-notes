# 정렬과 균일성 (Alignment, Uniformity)

[목차로 돌아가기](../../00_MIT%EB%94%A5%EB%9F%AC%EB%8B%9D_%EB%AA%A9%EC%B0%A8.md) · 먼저 볼 것: [MM44_단위_구와_코사인_유사도](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/03_%EC%84%A0%ED%98%95%EB%8C%80%EC%88%98/MM44_%EB%8B%A8%EC%9C%84_%EA%B5%AC%EC%99%80_%EC%BD%94%EC%82%AC%EC%9D%B8_%EC%9C%A0%EC%82%AC%EB%8F%84.md), [MM22_기댓값과_일반화_간극](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/04_%ED%99%95%EB%A5%A0%EA%B3%BC_%EC%A0%95%EB%B3%B4/MM22_%EA%B8%B0%EB%8C%93%EA%B0%92%EA%B3%BC_%EC%9D%BC%EB%B0%98%ED%99%94_%EA%B0%84%EA%B7%B9.md), [M06_지수와_e](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/01_%EC%88%98%EC%99%80_%ED%95%A8%EC%88%98/M06_%EC%A7%80%EC%88%98%EC%99%80_e.md), [M07_로그](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/01_%EC%88%98%EC%99%80_%ED%95%A8%EC%88%98/M07_%EB%A1%9C%EA%B7%B8.md) · 쓰는 곳: [Lec12 7.2](../../Lec12_%EC%9C%A0%EC%82%AC%EB%8F%84_%EA%B8%B0%EB%B0%98_%ED%91%9C%ED%98%84_%ED%95%99%EC%8A%B5.md#72-%EC%A0%95%EB%A0%AC%EA%B3%BC-%EA%B7%A0%EC%9D%BC%EC%84%B1), [Lec12 7.3](../../Lec12_%EC%9C%A0%EC%82%AC%EB%8F%84_%EA%B8%B0%EB%B0%98_%ED%91%9C%ED%98%84_%ED%95%99%EC%8A%B5.md#73-%EC%9D%8C%EC%84%B1-%ED%91%9C%EB%B3%B8%EC%9D%B4-%EB%AC%B4%ED%95%9C%ED%95%A0-%EB%95%8C)

> [!NOTE]
> **3줄 요약**
> - **정렬(alignment)**: 양성 쌍(같은 것의 두 보기)의 표현이 얼마나 가까운가. 거리 제곱의 평균 $\mathcal{L}_{\text{align}}$으로 재고, 작을수록 좋다. 거리 제곱 0.04와 0.16인 두 쌍이면 0.1.
> - **균일성(uniformity)**: 모든 표현이 구 위에 얼마나 고르게 퍼졌는가. 가우스 퍼텐셜 $e^{-t\|\cdot\|^2}$ 평균의 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8) $\mathcal{L}_{\text{uniform}}$으로 재고, 작을수록 고르다. 단위 원 위 점 4개가 한쪽에 몰리면 -0.1864, 고르게 퍼지면 -4.3963 ($t = 2$).
> - 대조 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은 음성이 무한히 많을 때 정확히 "정렬 항 + 균일성 항"으로 나뉜다(Wang·Isola 2020). 그래서 두 값을 재면 표현의 질을 숫자로 볼 수 있다.

## 1. 개념 설명

비유: 운동장에 반별로 학생을 세운다. **정렬**은 "같은 반 학생끼리 붙어 서 있는가", **균일성**은 "반들이 운동장 전체에 고르게 퍼져 있는가"다. 한 구석에 모두 몰리면 반끼리 구분이 어렵다. 운동장(구)을 남김없이 쓸수록 반 사이가 멀어진다.

- **[정렬](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#alignment-uniformity-%EC%A0%95%EB%A0%AC%EA%B3%BC-%EA%B7%A0%EC%9D%BC%EC%84%B1) 지표**: $\mathcal{L}_{\text{align}} = \mathbb{E}_{(x,y)\sim p_{\text{pos}}}\|f(x) - f(y)\|_2^{\alpha}$. 강의 슬라이드의 일반형은 $\alpha > 0$이고, 보통 $\alpha = 2$(거리 제곱)를 쓴다. 모든 양성 쌍이 같은 점에 놓이면 0이다.
- **[균일성](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#alignment-uniformity-%EC%A0%95%EB%A0%AC%EA%B3%BC-%EA%B7%A0%EC%9D%BC%EC%84%B1) 지표**: 아무 두 표본 $x, y$를 뽑아 가우스 퍼텐셜 $G_t = e^{-t\|f(x) - f(y)\|^2}$의 [기댓값](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#expectation-%EA%B8%B0%EB%8C%93%EA%B0%92)을 구하고 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 씌운다. 가까운 쌍일수록 $G_t$가 1에 가까워 값이 커진다. 즉 **가까운 쌍에 큰 벌**을 준다.
- **최솟값**: 구 위의 균등 분포가 기대 퍼텐셜을 가장 작게 만드는 유일한 분포다. 점을 최대한 서로 멀리 펼치는 배치다.

## 2. 필요한 이유

[Lec12 7.2](../../Lec12_%EC%9C%A0%EC%82%AC%EB%8F%84_%EA%B8%B0%EB%B0%98_%ED%91%9C%ED%98%84_%ED%95%99%EC%8A%B5.md#72-%EC%A0%95%EB%A0%AC%EA%B3%BC-%EA%B7%A0%EC%9D%BC%EC%84%B1)에서 강사는 좋은 표현의 조건 중 "집중(같은 반은 가깝게)"과 "분리(반끼리는 멀게)"를 [정렬과 균일성](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#alignment-uniformity-%EC%A0%95%EB%A0%AC%EA%B3%BC-%EA%B7%A0%EC%9D%BC%EC%84%B1)이라는 잴 수 있는 양으로 바꾼다. [7.3](../../Lec12_%EC%9C%A0%EC%82%AC%EB%8F%84_%EA%B8%B0%EB%B0%98_%ED%91%9C%ED%98%84_%ED%95%99%EC%8A%B5.md#73-%EC%9D%8C%EC%84%B1-%ED%91%9C%EB%B3%B8%EC%9D%B4-%EB%AC%B4%ED%95%9C%ED%95%A0-%EB%95%8C)은 대조 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 이 두 항으로 갈라짐을 보이고, 두 값이 모두 작은 인코더가 [검증](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#validation-data-%EA%B2%80%EC%A6%9D-%EB%8D%B0%EC%9D%B4%ED%84%B0) [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84)도 높다는 실험을 소개한다.

## 3. 숫자로 보기

**정렬** (양성 쌍 두 개, 거리 제곱 0.04와 0.16)
- 평균: $(0.04 + 0.16) / 2 = 0.1$

**균일성** (단위 원 위 점 4개, $t = 2$, 서로 다른 쌍 6개의 평균)

고르게 퍼진 배치 (0°, 90°, 180°, 270°)
- 이웃한 쌍 4개: 거리 제곱 2 → $e^{-2 \times 2} = e^{-4} = 0.0183$
- 마주 보는 쌍 2개: 거리 제곱 4 → $e^{-8} = 0.0003$
- 평균: $(4 \times 0.0183 + 2 \times 0.0003) / 6 = 0.0123$
- [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8): $\ln 0.0123 = -4.3963$

몰린 배치 (0°, 10°, 20°, 30°)
- 쌍들이 가까워 $e^{-2d^2}$가 모두 1에 가깝다 → 평균의 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8) $-0.1864$ (4절 코드)

| 배치 | $\mathcal{L}_{\text{uniform}}$ ($t = 2$) | 뜻 |
|---|---|---|
| 몰림 | -0.1864 | 거의 0. 점들이 뭉쳐 있다 |
| 고르게 퍼짐 | -4.3963 | 훨씬 작다. 구를 고르게 쓴다 |

![MM46_fig_uniformity.png](../../attachments/MM46_fig_uniformity.png)
*▲ 직접 그린 그림: 단위 원 위 점 4개. 왼쪽은 30° 안에 몰린 배치(-0.1864), 오른쪽은 90° 간격 배치(-4.3963)*

두 지표를 식으로 쓰면 다음과 같다.

$$
\mathcal{L}_{\text{align}} = \mathbb{E}_{(x,y)\sim p_{\text{pos}}}\big[\|f(x) - f(y)\|_2^2\big], \qquad
\mathcal{L}_{\text{uniform}} = \log\, \mathbb{E}_{x,y \overset{\text{i.i.d.}}{\sim} p_{\text{data}}}\big[e^{-t\|f(x) - f(y)\|_2^2}\big]
$$

<details><summary>예제와 풀이</summary>

**문제**: 단위 원 위에 점이 두 개만 있다. 두 점이 90° 떨어져 있을 때와 180° 떨어져 있을 때 균일성 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)($t = 2$)은?

**주어진 값**
- 90°일 때 두 점 (1, 0), (0, 1)
- 180°일 때 두 점 (1, 0), (-1, 0)
- $t = 2$: 퍼텐셜의 [날카로움](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sharpness-%EB%82%A0%EC%B9%B4%EB%A1%9C%EC%9B%80)

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_{\text{uniform}} = \log \mathbb{E}\big[e^{-t\|f(x) - f(y)\|_2^2}\big]$
2. 값을 대입한다 (90°): $\mathcal{L}_{\text{uniform}} = \log \mathbb{E}\big[e^{-2\|(1, 0) - (0, 1)\|_2^2}\big]$
3. [기댓값](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#expectation-%EA%B8%B0%EB%8C%93%EA%B0%92) $\mathbb{E}$는 평균인데, 서로 다른 쌍이 하나뿐이라 그 값 하나가 평균이다
4. 칸별로 뺀다: $(1 - 0,\ 0 - 1) = (1, -1)$
5. 칸별로 제곱해 더한다: $1^2 + (-1)^2 = 1 + 1 = 2$
6. $-t$를 곱한다: $-2\times2 = -4$
7. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)와 [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다. $e^{a}$는 약 2.718인 $e$의 $a$제곱이고, $\ln$은 그 반대(몇 제곱인지)라서 $\ln e^{-4} = -4$
8. 180°를 대입한다: $\mathcal{L}_{\text{uniform}} = \log \mathbb{E}\big[e^{-2\|(1, 0) - (-1, 0)\|_2^2}\big]$
9. 칸별로 뺀다: $(1 - (-1),\ 0 - 0) = (2, 0)$
10. 칸별로 제곱해 더한다: $2^2 + 0^2 = 4$
11. $-t$를 곱한다: $-2\times4 = -8$
12. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 계산한다: $\ln e^{-8} = -8$

**답**: 90°는 **-4**, 180°는 **-8**. 점 두 개를 원 위에 가장 고르게 놓는 방법은 정반대에 두는 것이고, 그때 균일성 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 가장 작다.

</details>

## 4. 코드로 확인

```python
# [함수] def unif(deg, t): 단위 원 위 각도 목록의 균일성 손실을 돌려준다
def unif(deg, t=2.0):
    # [함수] np.radians: 도 → 라디안. cos, sin으로 원 위의 점 좌표를 만든다
    # [변수] P: 점들의 (x, y) 좌표를 행으로 쌓은 배열
    P = np.stack([np.cos(np.radians(deg)), np.sin(np.radians(deg))], 1)
    # [변수] d2: 서로 다른 모든 쌍(i < j)의 거리 제곱
    d2 = np.array([((P[i] - P[j]) ** 2).sum() for i in range(len(P)) for j in range(i + 1, len(P))])
    # [함수] np.log(np.mean(np.exp(-t * d2))): 가우스 퍼텐셜 평균의 로그
    # [연결] 본문의 L_uniform 식
    return np.log(np.mean(np.exp(-t * d2)))
# [연결] 본문 3절 정렬 → 양성 쌍 거리 제곱 0.04, 0.16의 평균 0.1
print(round(np.mean([0.04, 0.16]), 4))
# [연결] 본문 3절 표 → 몰림 -0.1864, 고르게 퍼짐 -4.3963
print(round(unif([0, 10, 20, 30]), 4), round(unif([0, 90, 180, 270]), 4))
# [연결] 본문 예제와 풀이 → 두 점 90°는 -4, 180°는 -8
print(round(unif([0, 90]), 4), round(unif([0, 180]), 4))
```

**실행 결과**:

```text
0.1
-0.1864 -4.3963
-4.0 -8.0
```

> [!WARNING]
> **⚠ 주의**
> - 정렬만 좋게 만들기는 쉽다. 모든 입력을 한 점으로 보내면 $\mathcal{L}_{\text{align}} = 0$이지만 표현이 쓸모없다(붕괴, collapse). 균일성 항이 이를 막는다.
> - 균일성 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은 음수일 수 있고 절댓값 자체에는 뜻이 없다. 같은 $t$로 잰 두 표현을 **비교**할 때 쓴다.
> - "고르게 퍼진다"는 데이터 하나하나를 서로 밀어낸다는 뜻이다. 같은 반의 다른 사진까지 밀어내면 해가 될 수 있는데, 이것이 [Lec12 8.3](../../Lec12_%EC%9C%A0%EC%82%AC%EB%8F%84_%EA%B8%B0%EB%B0%98_%ED%91%9C%ED%98%84_%ED%95%99%EC%8A%B5.md#83-%EB%B0%B0%EC%B9%98-%ED%81%AC%EA%B8%B0%EC%99%80-%EA%B1%B0%EC%A7%93-%EC%9D%8C%EC%84%B1)의 거짓 음성 문제다.

## 5. 개념 재확인

<details><summary>1. 양성 쌍 세 개의 표현이 [(1, 0), (0.6, 0.8)], [(0, 1), (0, 1)], [(-1, 0), (-0.8, 0.6)]이다. $\mathcal{L}_{\text{align}}$은?</summary>

| 단계 | 하는 일 | 계산 | 결과 |
|---|---|---|---|
| 1 | 첫 쌍 | $0.4^2 + 0.8^2$ | 0.8 |
| 2 | 둘째 쌍 | 같은 점 | 0 |
| 3 | 셋째 쌍 | $0.2^2 + 0.6^2$ | 0.4 |
| 4 | 평균 | $(0.8 + 0 + 0.4)/3$ | 0.4 |

**① 쓰는 식**
$$\mathcal{L}_{\text{align}} = \frac{1}{n}\sum_{k=1}^{n}\|f(x_k) - f(y_k)\|^2$$
- 위 식 ← ②~④ (쌍마다 거리 제곱), ⑤ (평균)에서 쓴다. [기댓값](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#expectation-%EA%B8%B0%EB%8C%93%EA%B0%92)을 표본 평균으로 바꾼 것이다.
```python
# [변수] X, Y: 쌍의 앞 표현과 뒤 표현을 행으로 쌓은 배열
X = np.array([[1, 0], [0, 1], [-1, 0.0]])                 # ①
Y = np.array([[0.6, 0.8], [0, 1], [-0.8, 0.6]])
# [변수] d2 = [0.8 0. 0.4]: 쌍별 거리 제곱
d2 = ((X - Y) ** 2).sum(1).round(4)                       # ②③④
# [연결] [0.8 0.  0.4] 0.4
print(d2, round(d2.mean(), 4))                            # ⑤
```

**주어진 값**
- 첫 쌍 $f(x_1) = (1, 0)$, $f(y_1) = (0.6, 0.8)$
- 둘째 쌍 $f(x_2) = (0, 1)$, $f(y_2) = (0, 1)$
- 셋째 쌍 $f(x_3) = (-1, 0)$, $f(y_3) = (-0.8, 0.6)$
- $n = 3$: 양성 쌍 개수

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_{\text{align}} = \dfrac{1}{n}\sum_{k=1}^{n}\|f(x_k) - f(y_k)\|^2$
2. 값을 대입한다: $\mathcal{L}_{\text{align}} = \dfrac{1}{3}\sum_{k=1}^{3}\|f(x_k) - f(y_k)\|^2$ (쌍은 위 세 개)
3. Σ를 풀어 쓴다: $\dfrac{1}{3}\big(\|(1, 0) - (0.6, 0.8)\|^2 + \|(0, 1) - (0, 1)\|^2 + \|(-1, 0) - (-0.8, 0.6)\|^2\big)$
4. (②) 첫 쌍을 칸별로 뺀다: $(1 - 0.6,\ 0 - 0.8) = (0.4, -0.8)$
5. (②) 칸별로 제곱해 더한다: $0.4^2 + (-0.8)^2 = 0.16 + 0.64 = 0.8$
6. (③) 둘째 쌍을 칸별로 뺀다: $(0 - 0,\ 1 - 1) = (0, 0)$ → 제곱합 $0$
7. (④) 셋째 쌍을 칸별로 뺀다: $(-1 - (-0.8),\ 0 - 0.6) = (-0.2, -0.6)$
8. (④) 칸별로 제곱해 더한다: $(-0.2)^2 + (-0.6)^2 = 0.04 + 0.36 = 0.4$
9. (⑤) 세 값을 더한다: $0.8 + 0 + 0.4 = 1.2$
10. (⑤) 쌍 개수로 나눈다: $1.2 / 3 = 0.4$

**답**: $\mathcal{L}_{\text{align}} = $ **0.4**.

<details><summary>2. 단위 원 위 점 3개를 120° 간격으로 놓을 때와 한 점에 모두 겹칠 때 $\mathcal{L}_{\text{uniform}}$ ($t = 2$)은?</summary>

| 단계 | 하는 일 | 계산 | 결과 |
|---|---|---|---|
| 1 | 120° 쌍의 거리 제곱 | $2 - 2\cos 120° = 2 + 1$ | 3 |
| 2 | 퍼텐셜 (세 쌍 모두 같음) | $e^{-2 \times 3}$ | $e^{-6}$ |
| 3 | [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8) | $\ln e^{-6}$ | -6 |
| 4 | 겹친 경우 | 거리 0 → $e^0 = 1$ → $\ln 1$ | 0 |

**① 쓰는 식**
$$\mathcal{L}_{\text{uniform}} = \log \frac{1}{\#\text{쌍}}\sum_{i<j} e^{-t\|f_i - f_j\|^2}$$
- 위 식 ← ② (거리 제곱), ③ (퍼텐셜), ④ ([로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)), ⑤ (겹친 경우)에서 쓴다.
```python
# [변수] t = 2, 거리 제곱 = 2 - 2cos120° = 3
t, d2 = 2.0, 2 - 2 * np.cos(np.radians(120))              # ①②
# [연결] 퍼텐셜 e^-6 = 0.0025, 로그 -6
print(round(np.exp(-t * d2), 4), round(np.log(np.exp(-t * d2)), 4))   # ③④
# [연결] 모두 겹치면 거리 0 → 로그 0.0
print(np.log(np.exp(-t * 0.0)))                           # ⑤
```

**주어진 값**
- 점 3개가 단위 원 위에 120° 간격: 서로 다른 쌍 3개, 모든 쌍의 사이각 120°
- $t = 2$: 퍼텐셜의 [날카로움](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#sharpness-%EB%82%A0%EC%B9%B4%EB%A1%9C%EC%9B%80)

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_{\text{uniform}} = \log \dfrac{1}{\#\text{쌍}}\sum_{i<j} e^{-t\|f_i - f_j\|^2}$
2. 값을 대입한다: $\mathcal{L}_{\text{uniform}} = \log \dfrac{1}{3}\sum_{i<j} e^{-2\|f_i - f_j\|^2}$
3. (②) 단위 벡터의 거리 제곱은 $2 - 2\cos\theta$이다(cos는 사이각의 코사인, $\cos 120° = -0.5$): $2 - 2\times(-0.5)$
4. (②) 곱한다: $2\times(-0.5) = -1$
5. (②) 뺀다: $2 - (-1) = 3$ (세 쌍 모두 같음)
6. (③) $-t$를 곱한다: $-2\times3 = -6$
7. (③) [지수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#e-exponent-e%EC%99%80-%EC%A7%80%EC%88%98)를 계산한다($e^{a}$는 약 2.718인 $e$의 $a$제곱): $e^{-6} = 0.0025$
8. (③) Σ를 풀어 쓴다 (쌍 3개): $0.0025 + 0.0025 + 0.0025 = 0.0074$
9. (③) 쌍 개수로 나눈다: $0.0074 / 3 = 0.0025$ ($= e^{-6}$)
10. (④) [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 계산한다($\ln$은 $e$를 몇 제곱해야 그 수가 되는지): $\ln e^{-6} = -6$
11. (⑤) 한 점에 겹친 경우: 모든 쌍의 거리 제곱 0 → $e^{-2\times0} = e^{0} = 1$
12. (⑤) 평균 1의 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8): $\ln 1 = 0$

**답**: 120° 간격 **-6**, 한 점에 겹침 **0**. 고르게 펼칠수록 균일성 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 작다.
