> [!NOTE]
> **3줄 요약**
> - 벡터 $y$ (크기 m)를 벡터 $x$ (크기 n)로 미분하면 $\partial y_i / \partial x_j$를 모은 **m×n 행렬**, [야코비안](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#jacobian-%EC%95%BC%EC%BD%94%EB%B9%84%EC%95%88)이 된다. 스칼라를 벡터로 미분하면 1×n 행벡터다.
> - [연쇄법칙](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#chain-rule-%EC%97%B0%EC%87%84%EB%B2%95%EC%B9%99)은 [야코비안](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#jacobian-%EC%95%BC%EC%BD%94%EB%B9%84%EC%95%88)의 **[행렬 곱](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#matrix-multiplication-%ED%96%89%EB%A0%AC-%EA%B3%B1)**이다: $[m \times n] = [m \times p]\,[p \times n]$. 가운데 크기 p가 맞물려야 곱할 수 있다.
> - 예: $x = (1, 0, 2)$, $u = Wx = (1, -2)$, $z = u_1^2 + u_2^2 = 5$이면 $\partial z/\partial x = (2, -4)\,W = (2, 0, 4)$이고, 수치 [미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#derivative-%EB%AF%B8%EB%B6%84)으로 재도 같다.

## 1. 개념 설명

비유: 공장 두 개가 줄지어 있다. 원료 3가지($x$)가 첫 공장에서 중간재 2가지($u$)가 되고, 중간재가 둘째 공장에서 최종 점수 1개($z$)가 된다.

- 첫 공장의 "민감도 표" $\partial u / \partial x$는 원료 하나를 조금 늘리면 중간재 각각이 얼마나 변하는지 적은 **2×3 표**다.
- 둘째 공장의 표 $\partial z / \partial u$는 중간재 하나를 늘리면 점수가 얼마나 변하는지 적은 **1×2 표**다.
- 원료가 점수에 미치는 영향 $\partial z / \partial x$는 두 표를 **이어 붙여 곱한** 1×3 표다. 원료 → 중간재 → 점수로 가는 모든 경로의 영향을 더한 값이 [행렬 곱](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#matrix-multiplication-%ED%96%89%EB%A0%AC-%EA%B3%B1)의 한 칸이다.

$$
\underbrace{\frac{\partial z}{\partial x}}_{[m \times n]} = \underbrace{\frac{\partial z}{\partial u}}_{[m \times p]}\ \underbrace{\frac{\partial u}{\partial x}}_{[p \times n]}, \qquad
\left(\frac{\partial y}{\partial x}\right)_{ij} = \frac{\partial y_i}{\partial x_j}
$$

<details><summary>예제와 풀이</summary>

**문제**: $u = (x_1^2,\ x_1x_2)$, $z = u_1 + u_2$이고 x = (3, 2)일 때, [야코비안](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#jacobian-%EC%95%BC%EC%BD%94%EB%B9%84%EC%95%88) $\partial u/\partial x$를 만들고 [연쇄법칙](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#chain-rule-%EC%97%B0%EC%87%84%EB%B2%95%EC%B9%99)으로 $\partial z/\partial x$를 구하라.

**주어진 값**:
- $x_1 = 3,\ x_2 = 2$ (입력)
- $\frac{\partial u_1}{\partial x_1} = 2x_1,\ \frac{\partial u_1}{\partial x_2} = 0$ ($x_1^2$을 각 칸으로 [미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#derivative-%EB%AF%B8%EB%B6%84))
- $\frac{\partial u_2}{\partial x_1} = x_2,\ \frac{\partial u_2}{\partial x_2} = x_1$ ($x_1x_2$를 각 칸으로 [미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#derivative-%EB%AF%B8%EB%B6%84))
- $\frac{\partial z}{\partial u} = (1,\ 1)$ ($u_1 + u_2$를 각 칸으로 [미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#derivative-%EB%AF%B8%EB%B6%84))

**풀이**
1. 식을 그대로 쓴다: $\frac{\partial z}{\partial x} = \frac{\partial z}{\partial u}\ \frac{\partial u}{\partial x}, \qquad \left(\frac{\partial u}{\partial x}\right)_{ij} = \frac{\partial u_i}{\partial x_j}$
2. 값을 대입한다: $\frac{\partial z}{\partial x} = (1,\ 1)\begin{pmatrix} 2 \times 3 & 0 \\ 2 & 3 \end{pmatrix}$
3. [야코비안](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#jacobian-%EC%95%BC%EC%BD%94%EB%B9%84%EC%95%88)의 (1, 1) 칸을 곱한다: $2 \times 3 = 6$ 이므로 $\frac{\partial z}{\partial x} = (1,\ 1)\begin{pmatrix} 6 & 0 \\ 2 & 3 \end{pmatrix}$
4. 모양을 확인한다: [1×2][2×2] = [1×2]
5. 1번째 칸: 1번째 열과 같은 자리끼리 곱한다: $1 \times 6 = 6$, $1 \times 2 = 2$
6. 더한다: $6 + 2 = 8$
7. 2번째 칸: 2번째 열과 곱한다: $1 \times 0 = 0$, $1 \times 3 = 3$
8. 더한다: $0 + 3 = 3$
9. 검산: $z = x_1^2 + x_1x_2$를 직접 미분하면 $(2x_1 + x_2,\ x_1) = (6 + 2,\ 3) = (8, 3)$

**답**: [야코비안](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#jacobian-%EC%95%BC%EC%BD%94%EB%B9%84%EC%95%88) $\begin{pmatrix} 6 & 0 \\ 2 & 3 \end{pmatrix}$, $\frac{\partial z}{\partial x} = (8, 3)$

</details>

## 3. 숫자로 보기

$x = (1, 0, 2)$ (n = 3), $W = \begin{pmatrix} 1 & 2 & 0 \\ 0 & 1 & -1 \end{pmatrix}$, $u = Wx$ (p = 2), $z = u_1^2 + u_2^2$ (m = 1).

**① 순서대로 값 구하기** (한 줄에 한 동작)
- $u_1 = 1×1 + 2×0 + 0×2 = 1$
- $u_2 = 0×1 + 1×0 + (-1)×2 = -2$
- $z = 1^2 + (-2)^2 = 1 + 4 = 5$

**② 바깥 함수의 도함수** $\partial z/\partial u$ (모양 1×2)
- $\partial z/\partial u_1 = 2u_1 = 2$
- $\partial z/\partial u_2 = 2u_2 = -4$
- → $(2, -4)$

**③ 안쪽 함수의 [야코비안](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#jacobian-%EC%95%BC%EC%BD%94%EB%B9%84%EC%95%88)** $\partial u/\partial x$ (모양 2×3)
- $u_i = \sum_j W_{ij} x_j$이므로 $\partial u_i/\partial x_j = W_{ij}$ → [야코비안](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#jacobian-%EC%95%BC%EC%BD%94%EB%B9%84%EC%95%88)이 곧 $W$

**④ 곱하기** $(2, -4)\,W$ (모양 1×3)
- 1번째 칸: $2×1 + (-4)×0 = 2$
- 2번째 칸: $2×2 + (-4)×1 = 4 - 4 = 0$
- 3번째 칸: $2×0 + (-4)×(-1) = 4$
- → $\partial z/\partial x = (2, 0, 4)$

| 항 | 모양 | 값 |
|---|---|---|
| $\partial z/\partial u$ | 1×2 | (2, −4) |
| $\partial u/\partial x$ | 2×3 | $W$ |
| $\partial z/\partial x$ | 1×3 | (2, 0, 4) |

- 읽는 법: $x_2$를 조금 늘리면 $u_1$은 늘고(+2배) $u_2$도 늘어(+1배) 두 효과가 $2×2 + (-4)×1 = 0$으로 상쇄된다. 그래서 2번째 칸이 0이다.

<details><summary>기호 풀이</summary>

| --- | --- | --- | --- |
| $\frac{\partial y}{\partial x}$ | 파셜 와이 파셜 엑스 | y의 각 칸을 x의 각 칸으로 [편미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#partial-derivative-%ED%8E%B8%EB%AF%B8%EB%B6%84)해 모은 것 | - |

</details>

## 4. 코드로 확인

```python
# [함수] import numpy as np: 배열 계산 라이브러리 numpy를 np라는 이름으로 불러온다
import numpy as np
# [변수] x: 입력 열벡터 (1, 0, 2), 크기 n = 3
# [연결] 본문 3절의 x
x = np.array([1.0, 0.0, 2.0])
# [변수] W: 2×3 행렬. u = Wx로 크기 3을 크기 2로 바꾼다
W = np.array([[1.0, 2.0, 0.0], [0.0, 1.0, -1.0]])
# [함수] def f(x): x를 받아 z를 돌려주는 전체 함수 z = f(g(x))
def f(x):
    # [변수] u = Wx = (1, -2): 안쪽 함수 g의 출력, 크기 p = 2
    u = W @ x
    # [함수] (u ** 2).sum(): 칸마다 제곱해 더한다. z = u1² + u2² = 5, 크기 m = 1
    return (u ** 2).sum()
# [변수] u: 같은 값을 밖에서도 쓰려고 다시 계산 (1, -2)
u = W @ x
# [변수] dz_du = (2u1, 2u2) = (2, -4): 바깥 함수의 도함수, 모양 [1×2]
# [연결] 본문 3절 ②
dz_du = 2 * u
# [함수] @: 행렬 곱. [1×2] @ [2×3] = [1×3]
# [변수] dz_dx = (2, 0, 4): 연쇄법칙으로 구한 도함수. ∂u/∂x = W (야코비안)
# [연결] 본문 1절 식 ∂z/∂x = ∂z/∂u · ∂u/∂x, Lec02 5.2
dz_dx = dz_du @ W
# [변수] h = 1e-6: 수치 미분용 아주 작은 걸음
h = 1e-6
# [함수] np.eye(3): 3×3 단위행렬. 그 j번째 행 e_j는 x의 j번째 칸만 1인 벡터
# [변수] num: 칸마다 (f(x + h e_j) - f(x)) / h로 잰 수치 기울기
# [쓸모] 손으로 구한 도함수가 맞는지 확인하는 표준 방법 (기울기 검사)
num = np.array([(f(x + h * e) - f(x)) / h for e in np.eye(3)])
# [연결] 출력 1행: u = (1, -2), z = 5 (본문 3절 ①)
print(u, f(x))
# [함수] reshape(1, -1): 1행짜리 행벡터 모양으로 바꾼다. .shape: 모양
# [연결] 출력 2행: (1, 2) (2, 3) (1, 3) → [1×2][2×3] = [1×3]
print(dz_du.reshape(1, -1).shape, W.shape, dz_dx.reshape(1, -1).shape)
# [함수] np.round(num, 4): 수치 기울기를 넷째 자리로 반올림
# [연결] 출력 3행: 연쇄법칙 결과와 수치 결과가 모두 (2, 0, 4)
print(dz_dx, np.round(num, 4))
```

**실행 결과**:

```text
[ 1. -2.] 5.0
(1, 2) (2, 3) (1, 3)
[2. 0. 4.] [2. 0. 4.]
```

> [!WARNING]
> **⚠ 주의**
> - 곱하는 **순서**가 중요하다. $\frac{\partial z}{\partial u}\frac{\partial u}{\partial x}$는 [1×2][2×3]으로 되지만, 거꾸로 [2×3][1×2]는 모양이 맞지 않는다.
> - 이 강의는 "스칼라를 열벡터로 미분하면 **행벡터**"라는 약속(분자 기준 표기)을 쓴다. 어떤 책은 열벡터로 쓰는데(분모 기준 표기), 그러면 모든 식이 전치되어 곱 순서도 뒤집힌다. 강의도 MLP 역방향에서는 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)를 전치해 열벡터로 바꿔 쓴다([Lec02 7.2](../../Lec02_%EC%8B%A0%EA%B2%BD%EB%A7%9D_%ED%95%99%EC%8A%B5.md#72-mlp%EC%99%80-relu-%EA%B2%8C%EC%9D%B4%ED%8A%B8)).
> - 스칼라를 n×m 행렬로 미분한 결과를 강의는 m×n(전치된 모양)으로 정의한다. [PyTorch](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#pytorch-%ED%8C%8C%EC%9D%B4%ED%86%A0%EC%B9%98)의 `.grad`는 원래 행렬과 **같은 모양**으로 돌려준다. 표기 차이일 뿐 숫자는 같다.

## 5. 개념 재확인

<details><summary>1. 강의 슬라이드처럼 |z| = 1, |u| = 2, |x| = 4이면 ∂z/∂u, ∂u/∂x, ∂z/∂x의 모양은? 숫자 예로 확인하라.</summary>

| 단계 | 하는 일 | 규칙 | 계산 | 결과 |
|---|---|---|---|---|
| 1 | ∂z/∂u 모양 | [\|z\| × \|u\|] | [1 × 2] | 1×2 |
| 2 | ∂u/∂x 모양 | [\|u\| × \|x\|] | [2 × 4] | 2×4 |
| 3 | ∂z/∂x 모양 | 가운데 2가 맞물려 사라짐 | [1 × 2][2 × 4] | 1×4 |
| 4 | 숫자로 확인 | 1×2와 2×4를 곱함 | 아래 코드 | (1, 4) |

**① 쓰는 식**
$$\frac{\partial z}{\partial x} = \frac{\partial z}{\partial u}\frac{\partial u}{\partial x}, \qquad \left[\,|z| \times |u|\,\right]\left[\,|u| \times |x|\,\right] = \left[\,|z| \times |x|\,\right]$$
- 위 식 ← 오른쪽 모양 규칙은 ② (∂z/∂u 모양), ③ (∂u/∂x 모양), ④ (∂z/∂x 모양)에서 쓰고, 왼쪽 식은 ⑤ (숫자로 확인)에서 쓴다.
```python
# [함수] import numpy as np: 배열 계산 라이브러리
import numpy as np
# [변수] dz_du: 1×2 행벡터 (아무 값이나 모양만 맞춤), du_dx: 2×4 야코비안
dz_du = np.array([[1.0, -1.0]])           # ②
du_dx = np.arange(8.0).reshape(2, 4)      # ③
# [함수] @: 행렬 곱. [1×2] @ [2×4] = [1×4]
# [변수] dz_dx: (0-4, 1-5, 2-6, 3-7) = (-4, -4, -4, -4)
dz_dx = dz_du @ du_dx                     # ④⑤
# [연결] 출력: 세 모양 (1, 2) (2, 4) (1, 4)와 값
print(dz_du.shape, du_dx.shape, dz_dx.shape, dz_dx)
```

**주어진 값**
- $|z| = 1$, $|u| = 2$, $|x| = 4$ (벡터의 칸 수)
- 모양 규칙: $\frac{\partial y}{\partial x}$의 모양은 $[\,|y| \times |x|\,]$ (행 수 = 분자 칸 수, 열 수 = 분모 칸 수)
- 확인용 숫자: $\frac{\partial z}{\partial u} = (1, -1)$, $\frac{\partial u}{\partial x}$의 두 행은 (0, 1, 2, 3)과 (4, 5, 6, 7)

**② ∂z/∂u 모양**
1. 식을 그대로 쓴다: $\frac{\partial z}{\partial u}$의 모양 $= [\,|z| \times |u|\,]$
2. 값을 대입한다: $[\,1 \times 2\,]$
3. 읽는다: 행 수 = z의 칸 수 1, 열 수 = u의 칸 수 2 이므로 1×2

**③ ∂u/∂x 모양**
1. 식을 그대로 쓴다: $\frac{\partial u}{\partial x}$의 모양 $= [\,|u| \times |x|\,]$
2. 값을 대입한다: $[\,2 \times 4\,]$
3. 읽는다: 행 수 = u의 칸 수 2, 열 수 = x의 칸 수 4 이므로 2×4

**④ ∂z/∂x 모양**
1. 식을 그대로 쓴다: $[\,|z| \times |u|\,]\,[\,|u| \times |x|\,] = [\,|z| \times |x|\,]$
2. 값을 대입한다: $[\,1 \times 2\,]\,[\,2 \times 4\,] = [\,1 \times 4\,]$
3. 가운데 수를 확인한다: 가운데 2와 2가 같아 곱할 수 있고, 맞물린 가운데는 사라진다.
4. 바깥 두 수를 읽는다: 1×4

**⑤ 숫자로 확인**
1. 식을 그대로 쓴다: $\frac{\partial z}{\partial x} = \frac{\partial z}{\partial u}\frac{\partial u}{\partial x}$
2. 값을 대입한다: $\frac{\partial z}{\partial x} = (1,\ -1)\begin{pmatrix} 0 & 1 & 2 & 3 \ 4 & 5 & 6 & 7 \end{pmatrix}$
3. 1번째 칸: 1×0 + (−1)×4 = 0 − 4 = −4
4. 2번째 칸: 1×1 + (−1)×5 = 1 − 5 = −4
5. 3번째 칸: 1×2 + (−1)×6 = 2 − 6 = −4
6. 4번째 칸: 1×3 + (−1)×7 = 3 − 7 = −4
7. 모양을 센다: 칸이 4개인 한 줄이므로 1×4

**답**: ∂z/∂u는 **1×2**, ∂u/∂x는 **2×4**, ∂z/∂x는 **1×4**

<details><summary>2. x = (2, −1), u = (x₁x₂, x₁ + x₂), z = 3u₁ + u₂²일 때 연쇄법칙으로 ∂z/∂x를 구하고 직접 미분과 비교하라.</summary>

| 단계 | 하는 일 | 식 | 계산 | 결과 |
|---|---|---|---|---|
| 1 | u 계산 | $(x_1x_2,\ x_1 + x_2)$ | $(2×(-1),\ 2 - 1)$ | (−2, 1) |
| 2 | ∂z/∂u | $(3,\ 2u_2)$ | $(3,\ 2×1)$ | (3, 2) |
| 3 | ∂u/∂x (2×2) | $\begin{pmatrix} x_2 & x_1 \\ 1 & 1 \end{pmatrix}$ | $\begin{pmatrix} -1 & 2 \\ 1 & 1 \end{pmatrix}$ | [야코비안](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#jacobian-%EC%95%BC%EC%BD%94%EB%B9%84%EC%95%88) |
| 4 | 곱하기 | (2) × (3) | $(3×(-1) + 2×1,\ 3×2 + 2×1)$ | (−1, 8) |
| 5 | 직접 [미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#derivative-%EB%AF%B8%EB%B6%84) | $z = 3x_1x_2 + (x_1 + x_2)^2$ | $(3x_2 + 2(x_1{+}x_2),\ 3x_1 + 2(x_1{+}x_2))$ | (−1, 8) |

**① 쓰는 식**
$$\frac{\partial z}{\partial x} = \frac{\partial z}{\partial u}\frac{\partial u}{\partial x}, \qquad \left(\frac{\partial u}{\partial x}\right)_{ij} = \frac{\partial u_i}{\partial x_j}$$
- 위 식 ← 오른쪽 식은 ④ ([야코비안](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#jacobian-%EC%95%BC%EC%BD%94%EB%B9%84%EC%95%88) 만들기), 왼쪽 식은 ⑤ (곱하기)에서 쓰고, ② (u 계산), ③ (∂z/∂u)은 그 재료이며, ⑥ (직접 [미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#derivative-%EB%AF%B8%EB%B6%84))으로 검산한다.
```python
# [함수] import numpy as np: 배열 계산 라이브러리
import numpy as np
# [변수] x1, x2 = 2, -1: 문제에서 준 입력
x1, x2 = 2.0, -1.0                        # ①
# [변수] u = (x1·x2, x1 + x2) = (-2, 1)
u = np.array([x1 * x2, x1 + x2])          # ②
# [변수] dz_du = (3, 2u2) = (3, 2): z = 3u1 + u2²의 도함수, 1×2
dz_du = np.array([3.0, 2 * u[1]])         # ③
# [변수] J: 야코비안 [[x2, x1], [1, 1]] = [[-1, 2], [1, 1]], 2×2
J = np.array([[x2, x1], [1.0, 1.0]])      # ④
# [함수] @: [1×2] @ [2×2] = [1×2] → (-1, 8)
chain = dz_du @ J                         # ⑤
# [변수] direct: z = 3x1x2 + (x1+x2)²을 직접 편미분한 값 (-1, 8)
direct = np.array([3 * x2 + 2 * (x1 + x2), 3 * x1 + 2 * (x1 + x2)])  # ⑥
# [연결] 출력: 두 방법의 결과가 같다
print(chain, direct)
```

**주어진 값**
- $x_1 = 2,\ x_2 = -1$ (입력)
- $u_1 = x_1x_2,\ u_2 = x_1 + x_2$ (안쪽 함수)
- $z = 3u_1 + u_2^2$ (바깥 함수)

**② u 계산**
1. 식을 그대로 쓴다: $u_1 = x_1x_2,\ u_2 = x_1 + x_2$
2. 값을 대입한다: $u_1 = 2 \times (-1),\ u_2 = 2 + (-1)$
3. 계산한다: 2 × (−1) = −2, 2 + (−1) = 1 이므로 $u = (-2, 1)$

**③ ∂z/∂u**
1. 식을 그대로 쓴다: $\frac{\partial z}{\partial u_1} = 3$, $\frac{\partial z}{\partial u_2} = 2u_2$ ($3u_1$은 $u_1$로 미분하면 3, $u_2^2$은 $u_2$로 미분하면 $2u_2$)
2. 값을 대입한다: $\frac{\partial z}{\partial u_2} = 2 \times 1$
3. 곱셈을 한다: 2 × 1 = 2 이므로 $\frac{\partial z}{\partial u} = (3, 2)$

**④ ∂u/∂x ([야코비안](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#jacobian-%EC%95%BC%EC%BD%94%EB%B9%84%EC%95%88) 만들기)**
1. 식을 그대로 쓴다: $\left(\frac{\partial u}{\partial x}\right)_{ij} = \frac{\partial u_i}{\partial x_j}$
2. 네 칸의 식을 구한다: $\frac{\partial u_1}{\partial x_1} = x_2$, $\frac{\partial u_1}{\partial x_2} = x_1$, $\frac{\partial u_2}{\partial x_1} = 1$, $\frac{\partial u_2}{\partial x_2} = 1$
3. 값을 대입한다: $\begin{pmatrix} x_2 & x_1 \ 1 & 1 \end{pmatrix} = \begin{pmatrix} -1 & 2 \ 1 & 1 \end{pmatrix}$

**⑤ 곱하기**
1. 식을 그대로 쓴다: $\frac{\partial z}{\partial x} = \frac{\partial z}{\partial u}\frac{\partial u}{\partial x}$
2. 값을 대입한다: $\frac{\partial z}{\partial x} = (3,\ 2)\begin{pmatrix} -1 & 2 \ 1 & 1 \end{pmatrix}$
3. 1번째 칸을 펼친다: 3×(−1) + 2×1
4. 계산한다: −3 + 2 = −1
5. 2번째 칸을 펼친다: 3×2 + 2×1
6. 계산한다: 6 + 2 = 8 이므로 $\frac{\partial z}{\partial x} = (-1, 8)$

**⑥ 직접 [미분](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#derivative-%EB%AF%B8%EB%B6%84)**
1. 식을 그대로 쓴다: $z = 3x_1x_2 + (x_1 + x_2)^2$ 이므로 $\frac{\partial z}{\partial x_1} = 3x_2 + 2(x_1 + x_2)$, $\frac{\partial z}{\partial x_2} = 3x_1 + 2(x_1 + x_2)$
2. 값을 대입한다: $3 \times (-1) + 2(2 + (-1))$, $3 \times 2 + 2(2 + (-1))$
3. 괄호를 계산한다: 2 + (−1) = 1 이므로 $-3 + 2 \times 1$, $6 + 2 \times 1$
4. 계산한다: −3 + 2 = −1, 6 + 2 = 8

**답**: $\partial z/\partial x$ = **(−1, 8)** (두 방법이 같다)
