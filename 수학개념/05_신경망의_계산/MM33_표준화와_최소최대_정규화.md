## 1. 개념 설명

비유: 국어 점수(100점 만점)와 달리기 기록(초)을 그냥 더하면 단위가 큰 쪽이 결과를 좌우한다. 각 과목에서 "반 평균보다 표준편차 몇 개만큼 위인가"로 바꾸면 과목끼리 공정하게 비교할 수 있다. 이것이 [표준화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#standardization-%ED%91%9C%EC%A4%80%ED%99%94)(z 점수)다.

- **평균** $\mathbb{E}[x_k]$: k번째 차원 값들의 산술평균 ([M02_시그마와_평균](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/01_%EC%88%98%EC%99%80_%ED%95%A8%EC%88%98/M02_%EC%8B%9C%EA%B7%B8%EB%A7%88%EC%99%80_%ED%8F%89%EA%B7%A0.md)).
- **[분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)** $\mathrm{Var}[x_k]$: 평균에서 떨어진 거리의 제곱의 평균. **표준편차**는 그 제곱근으로, 값들이 평균에서 "보통 얼마나" 떨어져 있는지다.
- **[표준화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#standardization-%ED%91%9C%EC%A4%80%ED%99%94)**: 평균을 빼서 가운데를 0으로 옮기고, 표준편차로 나눠 퍼짐을 1로 맞춘다. 데이터의 단위(센티미터, 미터, 인치)가 결과에서 사라진다.

$$
x_k \leftarrow \frac{x_k - \mathbb{E}[x_k]}{\sqrt{\mathrm{Var}[x_k]}}
$$

<details><summary>예제와 풀이</summary>

**문제**: 키 데이터 (150, 160, 170, 180) cm에서 175 cm인 학생을 표준화하면 얼마인가?

**주어진 값**:
- $x_k = 175$ (표준화할 키)
- $\mathbb{E}[x_k] = 165$ (네 키의 평균: (150 + 160 + 170 + 180) / 4)
- $\mathrm{Var}[x_k] = 125$ (차이 -15, -5, 5, 15의 제곱 225, 25, 25, 225의 평균)

**풀이**
1. 식을 그대로 쓴다: $x_k \leftarrow \dfrac{x_k - \mathbb{E}[x_k]}{\sqrt{\mathrm{Var}[x_k]}}$
2. 값을 대입한다: $\dfrac{175 - 165}{\sqrt{125}}$
3. 분자를 먼저 계산한다: 175 - 165 = 10
4. 분모를 계산한다. √는 "제곱해서 그 수가 되는 양수"다: √125 = 11.1803
5. 나눈다: 10 / 11.1803 = 0.8944

**답**: 0.8944 (평균보다 표준편차 0.89개만큼 크다)

</details>

- **최소-최대 [정규화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#normalization-%EC%A0%95%EA%B7%9C%ED%99%94)**: 최솟값을 빼서 가장 작은 값을 0으로, 범위(최댓값 - 최솟값)로 나눠 가장 큰 값을 1로 만든다. 그림의 픽셀(0~255)을 255로 나누는 것이 이 방법이다.

$$
x_k \leftarrow \frac{x_k - \min x_k}{\max x_k - \min x_k}
$$

<details><summary>기호 풀이</summary>

| 기호 | 읽는 법 | 뜻 | 예제 값 |
| --- | --- | --- | --- |
| $x_k$ | 엑스 케이 | k번째 차원의 값 하나 | 165 cm |
| $\min x_k$ | 민 엑스 케이 | 그 차원의 가장 작은 값 | 150 |
| $\max x_k$ | 맥스 엑스 케이 | 그 차원의 가장 큰 값 | 180 |

</details>

<details><summary>예제와 풀이</summary>

**문제**: 키 데이터 (150, 160, 170, 180) cm로 최소-최대 [정규화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#normalization-%EC%A0%95%EA%B7%9C%ED%99%94)를 할 때, 165 cm는 얼마가 되는가?

**주어진 값**:
- $x_k = 165$ (바꿀 키)
- $\min x_k = 150$ (가장 작은 키)
- $\max x_k = 180$ (가장 큰 키)

**풀이**
1. 식을 그대로 쓴다: $x_k \leftarrow \dfrac{x_k - \min x_k}{\max x_k - \min x_k}$
2. 값을 대입한다: $\dfrac{165 - 150}{180 - 150}$
3. 분자를 계산한다: 165 - 150 = 15
4. 분모를 계산한다: 180 - 150 = 30
5. 나눈다: 15 / 30 = 0.5

**답**: 0.5 (범위의 딱 가운데)

</details>

## 2. 필요한 이유

[Lec09 4절](../../Lec09_%ED%95%B4%EC%BB%A4%EC%9D%98_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EA%B0%80%EC%9D%B4%EB%93%9C.md#4-%ED%91%9C%EC%A4%80%ED%99%94)에서 강사는 데이터를 불러오면 가장 먼저 표준화하라고 권한다. 측정 단위에 대한 의존을 없애고, 크기가 1000만 배씩 차이 나는 특징이 섞여 있을 때 작은 특징의 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 묻히는 일을 막는다. [6.2절](../../Lec09_%ED%95%B4%EC%BB%A4%EC%9D%98_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EA%B0%80%EC%9D%B4%EB%93%9C.md#62-%EC%9E%90%EB%A3%8C%ED%98%95-%EB%B0%94%EA%BE%B8%EA%B8%B0%EC%9D%98-%ED%95%A8%EC%A0%95)의 "표준화하면 음수가 생기는데 uint8로 바꾸면 사라진다"는 버그를 이해하려면 [표준화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#standardization-%ED%91%9C%EC%A4%80%ED%99%94) 결과에 음수가 섞인다는 점도 알아야 한다.

## 3. 숫자로 보기

**(가) [표준화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#standardization-%ED%91%9C%EC%A4%80%ED%99%94)** 키 (150, 160, 170, 180) cm

| 단계 | 계산 | 결과 |
|---|---|---|
| 평균 | (150 + 160 + 170 + 180) / 4 | 165 |
| 차이 | 각 값 - 165 | (-15, -5, 5, 15) |
| [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) | (225 + 25 + 25 + 225) / 4 | 125 |
| 표준편차 | √125 | 11.1803 |
| [표준화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#standardization-%ED%91%9C%EC%A4%80%ED%99%94) | 차이 / 11.1803 | (-1.3416, -0.4472, 0.4472, 1.3416) |

- 미터 (1.5, 1.6, 1.7, 1.8)로 같은 계산을 하면 평균 1.65, 표준편차 0.1118로 둘 다 100배 작아져서 결과가 **완전히 같다**. 단위가 사라진다는 뜻이다.
- 결과에 **음수**가 생긴다. 원래 키는 모두 양수였다.

**(나) 최소-최대 [정규화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#normalization-%EC%A0%95%EA%B7%9C%ED%99%94)** 같은 키: (150 - 150)/30, (160 - 150)/30, ... = (0, 0.3333, 0.6667, 1)

**(다) 크기가 다르면 [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)도 다르다**: 모델 $\hat y = w_1 x_1 + w_2 x_2$, [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $(\hat y - t)^2 / 2$, 입력 $(x_1, x_2) = (1000, 1)$, [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) $t = 1$, 시작 $w = (0, 0)$

- 예측 $\hat y = 0$ → [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) $\hat y - t = -1$
- [기울기](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) $\partial L / \partial w_i = (\hat y - t) x_i$ → $(-1000, -1)$
- 같은 [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0)로는 $w_1$이 1000배 크게 움직인다. $w_1$에 맞춰 [학습률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0)을 줄이면 $w_2$는 거의 안 움직인다. 표준화하면 두 입력의 크기가 비슷해져 이 문제가 사라진다 ([MM02_그래디언트_벡터](../../%EC%88%98%ED%95%99%EA%B0%9C%EB%85%90/02_%EB%AF%B8%EB%B6%84/MM02_%EA%B7%B8%EB%9E%98%EB%94%94%EC%96%B8%ED%8A%B8_%EB%B2%A1%ED%84%B0.md)).

**(라) [자료형](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#dtype-data-type-%EC%9E%90%EB%A3%8C%ED%98%95) 버그** ([Lec09 3](../../Lec09_%ED%95%B4%EC%BB%A4%EC%9D%98_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EA%B0%80%EC%9D%B4%EB%93%9C.md#3-%ED%98%95%EC%8B%9D%EA%B3%BC-%EC%A0%84%EC%B2%98%EB%A6%AC-%EB%B2%84%EA%B7%B8), [6.2](../../Lec09_%ED%95%B4%EC%BB%A4%EC%9D%98_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EA%B0%80%EC%9D%B4%EB%93%9C.md#62-%EC%9E%90%EB%A3%8C%ED%98%95-%EB%B0%94%EA%BE%B8%EA%B8%B0%EC%9D%98-%ED%95%A8%EC%A0%95))

- uint8(부호 없는 8비트 정수, 0~255)은 음수를 못 담는다. -1을 uint8로 바꾸면 **255**가 된다. 표준화한 데이터를 uint8로 "메모리 아끼려고" 바꾸면 음수가 모두 엉뚱한 큰 수가 된다.
- 0~255 픽셀 (0, 37, 128, 255)을 "0~1이겠지" 하고 [0, 1]로 자르면(clamp) (0, 1, 1, 1)이 되어 정보가 거의 다 사라진다.

## 4. 코드로 확인

```python
# [함수] import numpy as np: 배열 계산 라이브러리 numpy를 np라는 이름으로 불러온다
import numpy as np
# [변수] x: 키 네 개 (cm). 본문 3절 (가)의 데이터
x = np.array([150, 160, 170, 180.0])
# [함수] x.mean(), x.std(): 평균과 표준편차 (np.std는 기본으로 N으로 나눈다)
# [변수] z: 표준화한 키
# [연결] 1절의 표준화 식
z = (x - x.mean()) / x.std()
# [변수] m: 같은 키를 미터로 바꾼 값 (100으로 나눔)
m = x / 100
# [변수] zm: 미터로 표준화한 값. z와 같아야 한다
zm = (m - m.mean()) / m.std()
# [함수] np.round(..., 4): 소수 넷째 자리까지 반올림해서 보기 좋게 한다
# [연결] 출력 1행: 평균 165, 분산 125, 표준편차 11.1803 / 2행: z / 3행: zm이 z와 같은지
print(x.mean(), x.var(), np.round(x.std(), 4))
print(np.round(z, 4))
print(np.allclose(z, zm))
# [변수] mm: 최소-최대 정규화 결과 (0 ~ 1)
# [연결] 1절의 둘째 식, 3절 (나)
mm = (x - x.min()) / (x.max() - x.min())
print(np.round(mm, 4))
# [변수] w: 시작 가중치 (0, 0), xin: 크기가 1000배 다른 두 입력, t: 정답 1
w, xin, t = np.zeros(2), np.array([1000.0, 1.0]), 1.0
# [함수] w @ xin: 내적 = 예측 0. (예측 - 정답) * 입력 = 손실 (ŷ-t)²/2의 기울기
# [변수] g: 기울기 (-1000, -1)
# [연결] 3절 (다): 큰 입력 쪽 기울기가 1000배 크다
g = (w @ xin - t) * xin
print(g)
# [함수] astype(np.uint8): 0~255 정수로 바꾼다. int16의 -1은 255로 돌아 감긴다
# [연결] 3절 (라) 첫째 줄
print(np.array([-1, 0, 200], dtype=np.int16).astype(np.uint8))
# [함수] np.clip(v, 0, 1): 0보다 작으면 0, 1보다 크면 1로 자른다
# [연결] 3절 (라) 둘째 줄: 0~255 데이터를 0~1로 착각하고 자르면 정보가 사라진다
print(np.clip(np.array([0, 37, 128, 255.0]), 0, 1))
```

[시험 데이터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-data-test-data-%ED%95%99%EC%8A%B5-%EB%8D%B0%EC%9D%B4%ED%84%B0%EC%99%80-%EC%8B%9C%ED%97%98-%EB%8D%B0%EC%9D%B4%ED%84%B0)로 다시 구하면 [학습](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5) 때와 다른 변환이 된다.
> - 표준편차가 0인 차원(모든 값이 같음)은 0으로 나누게 된다. 실제 코드는 분모에 작은 수 ε를 더한다.
> - [표준화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#standardization-%ED%91%9C%EC%A4%80%ED%99%94)는 "모든 차원이 같은 중요도"라는 [귀납 편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#inductive-bias-%EA%B7%80%EB%82%A9-%ED%8E%B8%ED%96%A5)을 넣는다. 가로·세로 거리처럼 **같은 물리량**인 차원은 따로따로 표준화하면 공간이 찌그러진다(강의의 학생 질문). 이런 차원은 같은 배율로 함께 나눈다.
> - 최소-최대 [정규화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#normalization-%EC%A0%95%EA%B7%9C%ED%99%94)는 튀는 값 하나에 크게 흔들린다. 최댓값이 혼자 10000이면 나머지가 모두 0 근처로 몰린다.

<details><summary>1. 데이터 (2, 4, 6)을 표준화하면?</summary>

| 단계 | 하는 일 | 식 | 계산 | 결과 |
|---|---|---|---|---|
| 1 | 평균 | $\frac1N\sum x$ | (2 + 4 + 6) / 3 | 4 |
| 2 | [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) | $\frac1N\sum (x-\mu)^2$ | (4 + 0 + 4) / 3 | 2.6667 |
| 3 | 표준편차 | $\sqrt{\mathrm{Var}}$ | √2.6667 | 1.633 |
| 4 | [표준화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#standardization-%ED%91%9C%EC%A4%80%ED%99%94) | $(x-\mu)/\sigma$ | (-2, 0, 2) / 1.633 | (-1.2247, 0, 1.2247) |

**① 쓰는 식**
$$x \leftarrow \frac{x - \mathbb{E}[x]}{\sqrt{\mathrm{Var}[x]}}$$
```python
# [변수] a: 문제의 데이터 (2, 4, 6)
a = np.array([2, 4, 6.0])                       # ①
# [함수] a.mean(): 평균 4
mu = a.mean()                                   # ②
# [함수] a.var(): 분산 8/3 = 2.6667
var = a.var()                                   # ③
# [함수] np.sqrt: 제곱근 = 표준편차 1.633
sd = np.sqrt(var)                               # ④
# [연결] 출력: 표준편차와 표준화 결과 (-1.2247, 0, 1.2247)
print(np.round(sd, 4), np.round((a - mu) / sd, 4))   # ⑤
```

**문제**: 어떤 특징의 값 세 개 (2, 4, 6)을 평균 0, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) 1이 되게 바꾼다.

**주어진 값**:
- $x_1 = 2$, $x_2 = 4$, $x_3 = 6$ (특징 값 세 개)
- $N = 3$ (값의 개수)

**② 평균**
1. 식을 그대로 쓴다: $\mu = \frac{1}{N}(x_1 + x_2 + x_3)$
2. 값을 대입한다: $\mu = \frac{1}{3}(2 + 4 + 6)$
3. 괄호 안을 더한다: $2 + 4 + 6 = 12$ 이므로 $\mu = \frac{1}{3} × 12$
4. 3으로 나눈다: $12 / 3 = 4$

**③ [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0)**
1. 식을 그대로 쓴다: $\mathrm{Var} = \frac{1}{N}\big((x_1-\mu)^2 + (x_2-\mu)^2 + (x_3-\mu)^2\big)$
2. 값을 대입한다: $\mathrm{Var} = \frac{1}{3}\big((2-4)^2 + (4-4)^2 + (6-4)^2\big)$
3. 괄호 안 뺄셈을 먼저 한다: $2-4 = -2$, $4-4 = 0$, $6-4 = 2$ 이므로 $\frac13\big((-2)^2 + 0^2 + 2^2\big)$
4. 제곱을 한다: $(-2)^2 = 4$, $0^2 = 0$, $2^2 = 4$ 이므로 $\frac13(4 + 0 + 4)$
5. 더한다: $4 + 0 + 4 = 8$ 이므로 $\frac13 × 8$
6. 3으로 나눈다: $8 / 3 = 2.6667$

**④ 표준편차**
1. 식을 그대로 쓴다: $\sigma = \sqrt{\mathrm{Var}}$
2. 값을 대입한다: $\sigma = \sqrt{2.6667}$
3. 제곱근을 구한다. √는 "제곱해서 그 수가 되는 양수"다: $1.633 × 1.633 = 2.6667$ 이므로 $\sigma = 1.633$

**⑤ [표준화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#standardization-%ED%91%9C%EC%A4%80%ED%99%94)**
1. 식을 그대로 쓴다: $z_i = (x_i - \mu) / \sigma$
2. 값을 대입한다: $z = \big((2-4)/1.633,\ (4-4)/1.633,\ (6-4)/1.633\big)$
3. 괄호 안 뺄셈을 먼저 한다: $z = (-2/1.633,\ 0/1.633,\ 2/1.633)$
4. 나눈다: $-2/1.633 = -1.2247$, $0/1.633 = 0$, $2/1.633 = 1.2247$

**답**: (-1.2247, 0, 1.2247). 평균 0, [분산](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#variance-%EB%B6%84%EC%82%B0) 1이 되었다.

<details><summary>2. 픽셀 (0, 51, 255)를 0~1로 바꾸면? 255로 나누는 것과 같은가?</summary>

| 단계 | 하는 일 | 계산 | 결과 |
|---|---|---|---|
| 1 | 최솟값, 최댓값 | min, max | 0, 255 |
| 2 | 최솟값 빼기 | x - 0 | (0, 51, 255) |
| 3 | 범위로 나누기 | ÷ (255 - 0) | (0, 0.2, 1) |
| 4 | 비교 | 최솟값이 0이고 최댓값이 255라서 | ÷ 255와 같다 |

**① 쓰는 식**
$$x \leftarrow \frac{x - \min x}{\max x - \min x}$$
```python
# [변수] p: 문제의 픽셀 값
p = np.array([0, 51, 255.0])                                # ①
# [함수] min, max: 0과 255
lo, hi = p.min(), p.max()                                   # ②
# [변수] q: 최소-최대 정규화 결과
q = (p - lo) / (hi - lo)                                    # ③
# [연결] 출력: (0, 0.2, 1)과 255로 나눈 결과가 같은지 True
print(np.round(q, 4), np.allclose(q, p / 255))              # ④
```

**문제**: 픽셀 밝기 세 개 (0, 51, 255)를 가장 어두운 값이 0, 가장 밝은 값이 1이 되게 바꾼다.

**주어진 값**:
- $x = 0, 51, 255$ (픽셀 밝기)

**② 최솟값, 최댓값**
1. 가장 작은 값을 찾는다: $\min x = 0$
2. 가장 큰 값을 찾는다: $\max x = 255$

**③ 최소-최대 [정규화](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#normalization-%EC%A0%95%EA%B7%9C%ED%99%94)**
1. 식을 그대로 쓴다: $x \leftarrow \dfrac{x - \min x}{\max x - \min x}$
2. 값을 대입한다: $\Big(\dfrac{0 - 0}{255 - 0},\ \dfrac{51 - 0}{255 - 0},\ \dfrac{255 - 0}{255 - 0}\Big)$
3. 분모의 뺄셈을 먼저 한다: $255 - 0 = 255$ 이므로 $\Big(\dfrac{0 - 0}{255},\ \dfrac{51 - 0}{255},\ \dfrac{255 - 0}{255}\Big)$
4. 분자의 뺄셈을 한다: $\Big(\dfrac{0}{255},\ \dfrac{51}{255},\ \dfrac{255}{255}\Big)$
5. 나눈다: $0/255 = 0$, $51/255 = 0.2$, $255/255 = 1$

**④ 비교**
- 최솟값이 0, 최댓값이 255일 때만 ÷ 255와 같다. 그림에 어두운 픽셀이 하나도 없으면(최솟값이 30이라면) 두 방법의 결과가 달라진다.

**답**: (0, 0.2, 1). 이 데이터에서는 255로 나누는 것과 같다.
