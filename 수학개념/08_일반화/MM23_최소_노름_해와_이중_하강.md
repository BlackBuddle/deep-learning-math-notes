> [!NOTE]
> **3줄 요약**
> - **[노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)** $\lVert \mathbf{w} \rVert$는 벡터의 길이다. $(1, 2)$의 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)은 $\sqrt{1^2 + 2^2} = \sqrt5 ≈ 2.2361$.
> - 식보다 미지수가 많으면 답이 무수히 많다. 그중 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)이 가장 작은 답이 **[최소 노름 해](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#minimum-norm-solution-%EC%B5%9C%EC%86%8C-%EB%85%B8%EB%A6%84-%ED%95%B4)**다. $w_1 + 2w_2 = 5$의 [최소 노름 해](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#minimum-norm-solution-%EC%B5%9C%EC%86%8C-%EB%85%B8%EB%A6%84-%ED%95%B4)는 $(1, 2)$다.
> - 특징을 늘리면 [최소 노름 해](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#minimum-norm-solution-%EC%B5%9C%EC%86%8C-%EB%85%B8%EB%A6%84-%ED%95%B4)의 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)이 줄어든다(5 → 2.2361 → 1.6667). 데이터 수만큼 특징이 있을 때([보간](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#interpolation-%EB%B3%B4%EA%B0%84) 문턱) [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)과 시험 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)가 치솟고, 그보다 많으면 다시 내려간다. 이것이 **[이중 하강](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#double-descent-%EC%9D%B4%EC%A4%91-%ED%95%98%EA%B0%95)**이다.

## 1. 개념 설명

비유: 무게 5kg짜리 짐을 사람 여럿이 나눠 든다. 혼자 들면 5kg을 다 져야 하지만, 둘·셋이 들면 각자의 부담이 줄어든다. "모두의 부담을 합쳐 가장 작게" 나누는 방법이 [최소 노름 해](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#minimum-norm-solution-%EC%B5%9C%EC%86%8C-%EB%85%B8%EB%A6%84-%ED%95%B4)다. 사람(특징)이 많을수록 각자의 부담([가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98))이 작아진다.

- **[노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)(L2 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84))**: $\lVert \mathbf{w} \rVert = \sqrt{w_1^2 + w_2^2 + \cdots}$. [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)가 전체적으로 얼마나 큰지 나타내는 하나의 수다.
- **해가 무수히 많은 경우**: 데이터 한 점에 특징 두 개면 식은 하나 $a_1 w_1 + a_2 w_2 = y$, 미지수는 둘이다. 이 식을 만족하는 $(w_1, w_2)$는 직선 위의 모든 점이다. 모두 [학습 데이터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-data-test-data-%ED%95%99%EC%8A%B5-%EB%8D%B0%EC%9D%B4%ED%84%B0%EC%99%80-%EC%8B%9C%ED%97%98-%EB%8D%B0%EC%9D%B4%ED%84%B0)를 완벽히 맞춘다([보간](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#interpolation-%EB%B3%B4%EA%B0%84)).
- **[최소 노름 해](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#minimum-norm-solution-%EC%B5%9C%EC%86%8C-%EB%85%B8%EB%A6%84-%ED%95%B4)**: 그 직선 위에서 원점에 가장 가까운 점이다. 행렬 $A$(행 = 데이터, 열 = 특징)에 대해 유사역행렬(pseudo-inverse)로 구한다.

$$
\mathbf{w}^\star = A^{+}\mathbf{y} = A^\top (A A^\top)^{-1} \mathbf{y} \quad (\text{특징 수} \ge \text{데이터 수일 때})
$$

<details><summary>예제와 풀이</summary>

**문제**: 데이터 2개([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) 둘 다 2)를 특징 3개로 맞추는 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)는 무수히 많다. 그중 길이가 가장 짧은 [최소 노름 해](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#minimum-norm-solution-%EC%B5%9C%EC%86%8C-%EB%85%B8%EB%A6%84-%ED%95%B4)를 구한다.

**주어진 값**:
- $A = \begin{pmatrix}1&1&0\\0&1&1\end{pmatrix}$ (데이터 행렬: 행 2개 = 데이터 2개, 열 3개 = 특징 3개)
- $\mathbf{y} = (2, 2)$ (두 데이터의 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5))
- $A^\top = \begin{pmatrix}1&0\\1&1\\0&1\end{pmatrix}$ (A의 행과 열을 바꾼 것)

**풀이**
1. 식을 그대로 쓴다: $\mathbf{w}^\star = A^{+}\mathbf{y} = A^\top (A A^\top)^{-1} \mathbf{y} \quad (\text{특징 수} \ge \text{데이터 수일 때})$
2. 값을 대입한다: $\mathbf{w}^\star = \begin{pmatrix}1&0\\1&1\\0&1\end{pmatrix}\left(\begin{pmatrix}1&1&0\\0&1&1\end{pmatrix}\begin{pmatrix}1&0\\1&1\\0&1\end{pmatrix}\right)^{-1}\begin{pmatrix}2\\2\end{pmatrix}$
3. 안쪽 [행렬 곱](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#matrix-multiplication-%ED%96%89%EB%A0%AC-%EA%B3%B1) $AA^\top$를 칸마다 펼친다(칸 (i, j) = A의 i행과 $A^\top$의 j열을 짝지어 곱해 더함): $AA^\top = \begin{pmatrix}1 \times 1 + 1 \times 1 + 0 \times 0 & 1 \times 0 + 1 \times 1 + 0 \times 1\\0 \times 1 + 1 \times 1 + 1 \times 0 & 0 \times 0 + 1 \times 1 + 1 \times 1\end{pmatrix}$
4. 곱셈을 한다: $AA^\top = \begin{pmatrix}1 + 1 + 0 & 0 + 1 + 0\\0 + 1 + 0 & 0 + 1 + 1\end{pmatrix}$
5. 더한다: $AA^\top = \begin{pmatrix}2&1\\1&2\end{pmatrix}$ 이므로 $\mathbf{w}^\star = \begin{pmatrix}1&0\\1&1\\0&1\end{pmatrix}\begin{pmatrix}2&1\\1&2\end{pmatrix}^{-1}\begin{pmatrix}2\\2\end{pmatrix}$
6. 역행렬 공식을 쓴다($M^{-1}$은 M에 곱하면 단위행렬이 되는 행렬이다. 2×2 행렬 $\begin{pmatrix}a&b\\c&d\end{pmatrix}$이면 $\frac{1}{ad - bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}$로 구한다): $\begin{pmatrix}2&1\\1&2\end{pmatrix}^{-1} = \frac{1}{2 \times 2 - 1 \times 1}\begin{pmatrix}2&-1\\-1&2\end{pmatrix}$
7. 분모의 곱셈을 한다: $2 \times 2 = 4$, $1 \times 1 = 1$ 이므로 분모는 $4 - 1$
8. 분모의 뺄셈을 한다: $4 - 1 = 3$ 이므로 역행렬은 $\frac{1}{3}\begin{pmatrix}2&-1\\-1&2\end{pmatrix}$
9. 역행렬과 $\mathbf{y}$의 곱을 칸마다 펼친다: $\frac{1}{3}\begin{pmatrix}2 \times 2 + (-1) \times 2\\(-1) \times 2 + 2 \times 2\end{pmatrix}$
10. 곱셈을 한다: $\frac{1}{3}\begin{pmatrix}4 - 2\\-2 + 4\end{pmatrix}$
11. 더한다: $\frac{1}{3}\begin{pmatrix}2\\2\end{pmatrix}$
12. $\frac{1}{3}$을 곱한다: $\begin{pmatrix}\frac23\\\frac23\end{pmatrix}$ 이므로 $\mathbf{w}^\star = \begin{pmatrix}1&0\\1&1\\0&1\end{pmatrix}\begin{pmatrix}\frac23\\\frac23\end{pmatrix}$
13. 마지막 [행렬 곱](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#matrix-multiplication-%ED%96%89%EB%A0%AC-%EA%B3%B1)을 행마다 펼친다: $\mathbf{w}^\star = \begin{pmatrix}1 \times \frac23 + 0 \times \frac23\\1 \times \frac23 + 1 \times \frac23\\0 \times \frac23 + 1 \times \frac23\end{pmatrix}$
14. 곱셈과 덧셈을 한다: $\frac23 + 0 = \frac23$, $\frac23 + \frac23 = \frac43$, $0 + \frac23 = \frac23$ 이므로 $\mathbf{w}^\star = (\frac23, \frac43, \frac23)$
15. 소수로 바꾼다: $\frac23 = 0.6667$, $\frac43 = 1.3333$
16. 확인한다: $A\mathbf{w}^\star = (\frac23 + \frac43,\ \frac43 + \frac23) = (2, 2)$로 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)과 같다

**답**: $\mathbf{w}^\star = (0.6667, 1.3333, 0.6667)$, 곧 $(\frac23, \frac43, \frac23)$

</details>

## 2. 필요한 이유

[Lec06 5.4](../../Lec06_%EC%9D%BC%EB%B0%98%ED%99%94_%EC%9D%B4%EB%A1%A0.md#54-%EC%9D%B4%EC%A4%91-%ED%95%98%EA%B0%95)의 [이중 하강](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#double-descent-%EC%9D%B4%EC%A4%91-%ED%95%98%EA%B0%95) 그림은 "[파라미터](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#parameter-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0)를 늘리면 과적합한다"는 고전 그림을 뒤집는다. [Lec06 5.5](../../Lec06_%EC%9D%BC%EB%B0%98%ED%99%94_%EC%9D%B4%EB%A1%A0.md#55-%ED%8C%8C%EB%9D%BC%EB%AF%B8%ED%84%B0-%EB%85%B8%EB%A6%84)는 그 이유로 "특징이 많을수록 해의 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)이 작아져 함수가 매끄러워진다"는 관찰을 든다. [경사하강법](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-descent-%EA%B2%BD%EC%82%AC%ED%95%98%EA%B0%95%EB%B2%95)을 0 근처에서 시작하면 선형 모형에서는 [최소 노름 해](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#minimum-norm-solution-%EC%B5%9C%EC%86%8C-%EB%85%B8%EB%A6%84-%ED%95%B4)로 수렴한다는 결과도 있어서([Lec06 8.4](../../Lec06_%EC%9D%BC%EB%B0%98%ED%99%94_%EC%9D%B4%EB%A1%A0.md#84-%EC%B5%9C%EC%A0%81%ED%99%94%EC%9D%98-%EC%95%94%EB%AC%B5%EC%A0%81-%EA%B7%9C%EC%A0%9C)), [최소 노름 해](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#minimum-norm-solution-%EC%B5%9C%EC%86%8C-%EB%85%B8%EB%A6%84-%ED%95%B4)는 [암묵적 규제](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#implicit-regularization-%EC%95%94%EB%AC%B5%EC%A0%81-%EA%B7%9C%EC%A0%9C)를 이해하는 가장 단순한 모형이다.

## 3. 숫자로 보기

## 4. 코드로 확인

```python
# [함수] np.random.default_rng(0): 시드 0으로 난수 생성기를 만든다. 같은 시드면 매번 같은 난수가 나온다
# [변수] rng: 잡음과 랜덤 특징을 뽑을 생성기. 결과를 본문 표와 똑같이 재현하려고 시드를 고정한다
rng = np.random.default_rng(0)
# [함수] np.linspace(-1, 1, 20): -1부터 1까지 같은 간격으로 20개
# [변수] x: 학습 입력 20개 (n = 20). 보간 문턱이 p = 20이 된다
x = np.linspace(-1, 1, 20)
# [변수] y: 정답 sin(πx)에 표준편차 0.2의 잡음을 더한 학습 정답. 잡음이 있어야 "외우기"의 피해가 보인다
y = np.sin(np.pi * x) + 0.2 * rng.standard_normal(20)
# [변수] xt: 시험 입력 401개. 시험 오차를 잴 때 잡음 없는 sin(πx)와 비교한다
xt = np.linspace(-1, 1, 401)
# [변수] W, b: 랜덤 특징 1000개의 주파수(표준편차 20)와 위상(0~2π). 앞에서 p개만 잘라 쓴다
# [연결] 강의 5.5절의 "랜덤 푸리에 특징(random Fourier features)"
W, b = rng.standard_normal(1000) * 20, rng.uniform(0, 2 * np.pi, 1000)
# [함수] lambda t, p: 입력 t에 대해 특징 p개 cos(ω t + b)를 계산해 (입력 수 × p) 행렬로 돌려준다
# [함수] np.outer(t, W[:p]): 입력과 주파수의 모든 곱을 표로 만든다
feat = lambda t, p: np.cos(np.outer(t, W[:p]) + b[:p])
# [함수] for: 특징 수 p를 바꿔 가며 되풀이한다
for p in [5, 10, 15, 19, 20, 21, 25, 40, 100, 1000]:
    # [함수] np.linalg.pinv: 유사역행렬 A⁺. A⁺y가 최소 노름 해다 (p < n이면 최소제곱 해)
    # [변수] w: 학습 데이터를 (p ≥ 20이면 정확히) 맞추는 가중치 중 노름이 가장 작은 것
    # [연결] 본문 1절의 식 w* = A⁺y
    w = np.linalg.pinv(feat(x, p)) @ y
    # [변수] te: 시험 입력에서의 평균 제곱 오차 (예측 - sin(πx))²의 평균
    # [쓸모] p에 따른 이중 하강 모양을 본다
    te = np.mean((feat(xt, p) @ w - np.sin(np.pi * xt)) ** 2)
    # [함수] np.linalg.norm(w): 노름 ||w||. :.3g는 유효숫자 3자리로 출력한다
    # [연결] 출력 한 줄이 본문 3절 표의 한 열 (p, 시험 오차, 노름)
    print(p, f"{te:.3g}", f"{np.linalg.norm(w):.3g}")
```

## 5. 개념 재확인

<details><summary>1. $2w_1 + w_2 = 10$을 만족하는 해 중 노름이 가장 작은 해와 그 노름은?</summary>

| 단계 | 하는 일 | 식 | 계산 | 결과 |
|---|---|---|---|---|
| 1 | 특징 벡터의 길이 제곱 | $\lVert \mathbf{a} \rVert^2$ | $2^2 + 1^2$ | 5 |
| 2 | [최소 노름 해](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#minimum-norm-solution-%EC%B5%9C%EC%86%8C-%EB%85%B8%EB%A6%84-%ED%95%B4) | $\mathbf{a}\, y / \lVert \mathbf{a} \rVert^2$ | $(2, 1) × 10 / 5$ | (4, 2) |
| 3 | 식 확인 | $2w_1 + w_2$ | $8 + 2$ | 10 |
| 4 | [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84) | $\sqrt{w_1^2 + w_2^2}$ | $\sqrt{16 + 4}$ | 4.4721 |

**① 쓰는 식**
$$\mathbf{w}^\star = \frac{y}{\lVert \mathbf{a} \rVert^2}\,\mathbf{a}, \qquad \lVert \mathbf{w}^\star \rVert = \frac{|y|}{\lVert \mathbf{a} \rVert}$$
- 위 식 ← 왼쪽은 ② (길이 제곱)와 ③ ([최소 노름 해](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#minimum-norm-solution-%EC%B5%9C%EC%86%8C-%EB%85%B8%EB%A6%84-%ED%95%B4)), 오른쪽은 ⑤ ([노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84))에서 쓴다. ④에서 식을 만족하는지 확인한다.
```python
# [변수] a = [2 1]: 특징 값 (식의 계수), y = 10: 정답. 문제에서 준 값
a, y = np.array([2.0, 1.0]), 10.0                 # ①
# [함수] a @ a: 내적 2² + 1² = 5
sq = a @ a                                        # ②
# [변수] w = a × 10 / 5 = [4 2]: 최소 노름 해
w = a * y / sq                                    # ③
# [연결] 식 확인 2×4 + 1×2 = 10.0
print(w, a @ w)                                   # ④
# [함수] np.linalg.norm: √(16 + 4) = 4.4721
print(round(np.linalg.norm(w), 4))                # ⑤
```

**문제**: 식 $2w_1 + w_2 = 10$을 만족하는 해 중 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)이 가장 작은 해와 그 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)은?

**주어진 값**:
- $\mathbf{a} = (2, 1)$ (식의 계수)
- $y = 10$ ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5))

**풀이**
1. 식을 그대로 쓴다: $\mathbf{w}^\star = \dfrac{y}{\lVert \mathbf{a} \rVert^2}\,\mathbf{a}$, $\lVert \mathbf{w}^\star \rVert = \dfrac{|y|}{\lVert \mathbf{a} \rVert}$
2. 값을 대입한다: $\mathbf{w}^\star = \dfrac{10}{2^2 + 1^2}\,(2, 1)$
3. (②) 길이의 제곱을 구한다: $2^2 = 4$, $1^2 = 1$, $4 + 1 = 5$ 이므로 $\mathbf{w}^\star = \dfrac{10}{5}\,(2, 1)$
4. (③) 나눗셈을 한다: $10 \div 5 = 2$ 이므로 $\mathbf{w}^\star = 2 \times (2, 1)$
5. 칸마다 곱한다: $2 \times 2 = 4$, $2 \times 1 = 2$ 이므로 $\mathbf{w}^\star = (4, 2)$
6. (④) 식을 확인한다: $2 \times 4 + 1 \times 2 = 8 + 2 = 10$
7. (⑤) [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84) 식에 대입한다 ($\sqrt{\ }$는 제곱하면 그 수가 되는 양수): $\lVert \mathbf{w}^\star \rVert = \sqrt{4^2 + 2^2}$
8. 제곱하고 더한다: $16 + 4 = 20$ 이므로 $\lVert \mathbf{w}^\star \rVert = \sqrt{20}$
9. 제곱근을 구한다 (계산기): $\sqrt{20} = 4.4721$

**답**: $\mathbf{w}^\star = $ **(4, 2)**, [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84) **4.4721** (다른 해, 예를 들어 (5, 0)의 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84) 5보다 작다)

<details><summary>2. 정답 y = 4를 특징 1개 (1)로 맞출 때와 특징 4개 (1, 1, 1, 1)로 맞출 때 최소 노름 해의 노름은?</summary>

| 단계 | 하는 일 | 계산 | 결과 |
|---|---|---|---|
| 1 | 특징 1개의 해 | $w_1 = 4$ | (4) |
| 2 | 특징 1개의 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84) | $\sqrt{16}$ | 4 |
| 3 | 특징 4개의 해 | $(1,1,1,1) × 4 / 4$ | (1, 1, 1, 1) |
| 4 | 특징 4개의 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84) | $\sqrt{1+1+1+1}$ | 2 |

**① 쓰는 식**
$$\mathbf{w}^\star = A^{+} y$$
- 위 식 ← ② (특징 1개)와 ④ (특징 4개)에서 `np.linalg.pinv`로 계산하고, ③과 ⑤에서 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)을 잰다.
```python
# [변수] A1: 특징 1개짜리 1×1 행렬, A4: 특징 4개짜리 1×4 행렬. 데이터는 둘 다 한 점
A1, A4 = np.array([[1.0]]), np.array([[1.0, 1, 1, 1]])   # ①
# [함수] np.linalg.pinv(A) @ [4.0]: 최소 노름 해 → [4.]
w1 = np.linalg.pinv(A1) @ [4.0]                           # ②
# [연결] 노름 4.0
print(w1, np.linalg.norm(w1))                             # ③
# [변수] w4 = [1 1 1 1]: 네 특징이 짐을 똑같이 나눠 든다
w4 = np.linalg.pinv(A4) @ [4.0]                           # ④
# [연결] 노름 2.0 → 특징이 많을수록 노름이 작다 (본문 3절)
print(np.round(w4, 4), round(np.linalg.norm(w4), 4))      # ⑤
```

**문제**: [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) y = 4를 특징 1개 (1)로 맞출 때와 특징 4개 (1, 1, 1, 1)로 맞출 때 [최소 노름 해](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#minimum-norm-solution-%EC%B5%9C%EC%86%8C-%EB%85%B8%EB%A6%84-%ED%95%B4)의 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)은?

**주어진 값**:
- $y = 4$ ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5))
- $\mathbf{a}_1 = (1)$ (특징 1개), $\mathbf{a}_4 = (1, 1, 1, 1)$ (특징 4개)

**풀이**
1. 식을 그대로 쓴다 (데이터가 한 점이면 $A^{+}y$는 이 식과 같다): $\mathbf{w}^\star = \dfrac{y}{\lVert \mathbf{a} \rVert^2}\,\mathbf{a}$, [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)은 $\sqrt{\sum w_k^2}$
2. 특징 1개를 대입한다: $\mathbf{w}^\star = \dfrac{4}{1^2}\,(1)$
3. (②) 계산한다: $1^2 = 1$, $4 \div 1 = 4$ 이므로 $\mathbf{w}^\star = (4)$ (해가 하나뿐)
4. (③) [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)을 구한다: $\sqrt{4^2} = \sqrt{16} = 4$
5. 특징 4개를 대입한다: $\mathbf{w}^\star = \dfrac{4}{1^2 + 1^2 + 1^2 + 1^2}\,(1, 1, 1, 1)$
6. (④) 계산한다: 분모는 $1 + 1 + 1 + 1 = 4$, $4 \div 4 = 1$ 이므로 $\mathbf{w}^\star = 1 \times (1, 1, 1, 1) = (1, 1, 1, 1)$
7. (⑤) [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)을 구한다: $\sqrt{1^2 + 1^2 + 1^2 + 1^2} = \sqrt{1 + 1 + 1 + 1} = \sqrt{4} = 2$

**답**: 특징 1개 **4**, 특징 4개 **2**. 같은 데이터를 맞추는데도 특징이 많으면 [노름](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#norm-%EB%85%B8%EB%A6%84)이 작은 해를 고를 수 있다.
