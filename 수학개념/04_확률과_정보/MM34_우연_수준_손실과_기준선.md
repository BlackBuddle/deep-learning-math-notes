## 1. 개념 설명

비유: 사지선다 시험에서 찍기만 해도 25%는 맞힌다. 내 점수가 30%라면 "공부해서 30%"가 아니라 "찍기보다 5% 나은" 것이다. 모델의 성능도 **아무 생각 없이 내는 답(기준선)** 과 비교해야 의미가 있다.

- **[우연 수준](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#chance-level-%EC%9A%B0%EC%97%B0-%EC%88%98%EC%A4%80)(chance level)**: 입력을 전혀 보지 않고 낼 수 있는 가장 단순한 답의 성능. [분류](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#regression-classification-%ED%9A%8C%EA%B7%80%EC%99%80-%EB%B6%84%EB%A5%98)에서는 "모든 클래스에 같은 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)"이나 "가장 흔한 클래스", [회귀](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#regression-classification-%ED%9A%8C%EA%B7%80%EC%99%80-%EB%B6%84%EB%A5%98)에서는 "[정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)의 평균"이다.
- [교차 엔트로피](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cross-entropy-%EA%B5%90%EC%B0%A8-%EC%97%94%ED%8A%B8%EB%A1%9C%ED%94%BC) [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) 클래스에 준 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) $p$의 $-\ln p$다. 모든 클래스에 $1/K$를 주면 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)에도 $1/K$이므로 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은 아래 식이 된다.

$$
\mathcal{L}_{\text{chance}} = -\ln \frac{1}{K} = \ln K
$$

**문제**: 4개 클래스 [분류](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#regression-classification-%ED%9A%8C%EA%B7%80%EC%99%80-%EB%B6%84%EB%A5%98)에서 모델이 모든 클래스에 같은 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 주면 [교차 엔트로피](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cross-entropy-%EA%B5%90%EC%B0%A8-%EC%97%94%ED%8A%B8%EB%A1%9C%ED%94%BC) [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은 얼마인가?

**주어진 값**:
- $K = 4$ (클래스 수)

**풀이**
1. 식을 그대로 쓴다: $\mathcal{L}_{\text{chance}} = -\ln \frac1K$
2. 값을 대입한다: $-\ln \frac14$
3. 분수를 계산한다: 1 / 4 = 0.25
4. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 구한다. $\ln$은 "$e$(약 2.718)를 몇 제곱해야 그 수가 되나"다: $\ln 0.25 = -1.3863$
5. 부호를 바꾼다: -(-1.3863) = 1.3863

**답**: 1.3863 (= $\ln 4$). [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 1.39 근처에서 안 내려가면 모델은 찍고 있는 것이다.

- **[클래스 불균형](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#class-imbalance-%ED%81%B4%EB%9E%98%EC%8A%A4-%EB%B6%88%EA%B7%A0%ED%98%95)(class imbalance)**: 한 클래스가 압도적으로 많으면 "가장 흔한 클래스"만 답해도 [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84)가 높다. 이때 모델이 입력을 보지 않고도 낼 수 있는 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은 [사전 분포](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#prior-posterior-%EC%82%AC%EC%A0%84-%EB%B6%84%ED%8F%AC%EC%99%80-%EC%82%AC%ED%9B%84-%EB%B6%84%ED%8F%AC)(prior) $p$를 그대로 예측할 때의 이진 [엔트로피](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#entropy-%EC%97%94%ED%8A%B8%EB%A1%9C%ED%94%BC)다.

$$
H(p) = -\big(p \ln p + (1-p)\ln(1-p)\big)
$$

<details><summary>예제와 풀이</summary>

**문제**: 종양 사진의 95%가 양성(benign)이다. 모델이 입력을 보지 않고 늘 "양성일 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0) 0.95"라고 답하면 평균 [교차 엔트로피](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cross-entropy-%EA%B5%90%EC%B0%A8-%EC%97%94%ED%8A%B8%EB%A1%9C%ED%94%BC) [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)은 얼마인가?

**주어진 값**:
- $p = 0.95$ (양성 비율)
- $1 - p = 0.05$ (악성 비율)

**풀이**
1. 식을 그대로 쓴다: $H(p) = -\big(p \ln p + (1-p)\ln(1-p)\big)$
2. 값을 대입한다: $-\big(0.95 \ln 0.95 + 0.05 \ln 0.05\big)$
3. [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)를 먼저 구한다 (계산기의 ln 키): $\ln 0.95 = -0.0513$, $\ln 0.05 = -2.9957$ 이므로 $-\big(0.95 × (-0.0513) + 0.05 × (-2.9957)\big)$
4. 곱셈을 한다: $0.95 × (-0.0513) = -0.0487$, $0.05 × (-2.9957) = -0.1498$ 이므로 $-\big(-0.0487 + (-0.1498)\big)$
5. 괄호 안을 더한다: $-0.0487 + (-0.1498) = -0.1985$ 이므로 $-(-0.1985)$
6. 부호를 바꾼다: $-(-0.1985) = 0.1985$

**답**: 0.1985. [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 0.2라고 좋아하면 안 된다. 이 데이터에서는 그것이 "찍기" 수준이다.

</details>

## 4. 코드로 확인

```python
# [함수] import numpy as np: 배열 계산 라이브러리 numpy를 np라는 이름으로 불러온다
import numpy as np
# [함수] for K in ...: 클래스 수를 바꿔 가며 균등 확률의 손실을 구한다
for K in [2, 4, 10, 100, 1000]:
    # [함수] -np.log(1 / K): 정답에 1/K를 줬을 때의 교차 엔트로피 = ln K
    # [연결] 1절 첫 식, 3절 (가) 표
    print(K, np.round(-np.log(1 / K), 4))
# [함수] def H(p): 비율 p를 그대로 예측할 때의 평균 교차 엔트로피 (이진 엔트로피)
# [연결] 1절 둘째 식
def H(p):
    # [변수] 반환값: -(p ln p + (1-p) ln(1-p))
    return -(p * np.log(p) + (1 - p) * np.log(1 - p))
# [연결] 3절 (나)의 0.056과 1절 예제의 0.1985
print(np.round(H(0.99), 4), np.round(H(0.95), 4))
# [변수] y: 99개 양성(0)과 1개 악성(1)인 정답
y = np.array([0] * 99 + [1])
# [변수] pred: "늘 양성" 예측
pred = np.zeros(100)
# [함수] (pred == y).mean(): 정확도. y == 1인 칸만 보면 악성 재현율
# [연결] 3절 (나): 정확도 0.99, 재현율 0.0
print((pred == y).mean(), (pred[y == 1] == 1).mean())
# [변수] t: 회귀 정답 (1, 2, 3, 6)
t = np.array([1, 2, 3, 6.0])
# [함수] ((t - c) ** 2).mean(): 늘 c를 답할 때의 MSE
# [연결] 3절 (다): 평균을 답하면 3.5, 0을 답하면 12.5
print(((t - t.mean()) ** 2).mean(), ((t - 0) ** 2).mean())
```

**실행 결과**:

```text
2 0.6931
4 1.3863
10 2.3026
100 4.6052
1000 6.9078
0.056 0.1985
0.99 0.0
3.5 12.5
```

> [!WARNING]
> **⚠ 주의**
> - $\ln K$는 **클래스가 고르게 섞인** 데이터에서의 찍기 수준이다. 불균형 데이터의 찍기 수준은 $\ln K$보다 낮다($H(0.99) = 0.056 < \ln 2$).
> - 라이브러리마다 [로그](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#log-ln-%EB%A1%9C%EA%B7%B8)의 밑이 다를 수 있다. 밑 2를 쓰면 [이진 분류](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#binary-classification-%EC%9D%B4%EC%A7%84-%EB%B6%84%EB%A5%98)의 찍기 수준은 1 비트다. [PyTorch](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#pytorch-%ED%8C%8C%EC%9D%B4%ED%86%A0%EC%B9%98)의 `cross_entropy`는 자연로그다.
> - 불균형 데이터에서는 [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84) 대신 클래스별 재현율·정밀도, 또는 소수 클래스의 조건부 정답률을 본다(강의: "악성일 때 맞힐 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)").

<details><summary>1. 4개 클래스 분류 모델의 손실이 1.40에서 멈췄다. 배운 것이 있는가?</summary>

| 단계 | 하는 일 | 식 | 계산 | 결과 |
|---|---|---|---|---|
| 1 | 찍기 수준 | $\ln K$ | $\ln 4$ | 1.3863 |
| 2 | 비교 | [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) - 찍기 | 1.40 - 1.3863 | 0.0137 |
| 3 | 판단 | 차이가 0 이상 | | 찍기보다 못하거나 같다 |

**① 쓰는 식**
$$\mathcal{L}_{\text{chance}} = \ln K$$
```python
# [변수] K, loss: 클래스 수 4, 관측한 손실 1.40
K, loss = 4, 1.40                                   # ①
# [함수] np.log(K): 찍기 수준 1.3863
base = np.log(K)                                    # ②
# [연결] 출력: 찍기 수준과 그 차이 (양수면 찍기보다 못함)
print(np.round(base, 4), np.round(loss - base, 4))  # ③
```

**문제**: 4개 클래스 [분류](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#regression-classification-%ED%9A%8C%EA%B7%80%EC%99%80-%EB%B6%84%EB%A5%98) 모델의 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 1.40에서 멈췄을 때, 모든 클래스에 같은 [확률](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#probability-%ED%99%95%EB%A5%A0)을 주는 "찍기" [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)과 비교한다.

**주어진 값**:
- $K = 4$ (클래스 수)
- 관측 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $= 1.40$ (모델이 멈춘 [교차 엔트로피](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cross-entropy-%EA%B5%90%EC%B0%A8-%EC%97%94%ED%8A%B8%EB%A1%9C%ED%94%BC))

**② 찍기 수준**
1. 식을 그대로 쓴다: $\mathcal{L}_{\text{chance}} = \ln K$
2. 값을 대입한다: $\mathcal{L}_{\text{chance}} = \ln 4$
3. 자연로그를 구한다. $\ln 4$는 "$e$(약 2.718)를 몇 제곱하면 4가 되나"이고 계산기의 ln 키로 구한다: $\ln 4 = 1.3863$

**③ 비교**
1. 식을 그대로 쓴다: 차이 $=$ 관측 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) $- \mathcal{L}_{\text{chance}}$
2. 값을 대입한다: 차이 $= 1.40 - 1.3863$
3. 뺄셈을 한다: $1.40 - 1.3863 = 0.0137$
4. 부호를 본다: $0.0137 > 0$ 이므로 찍기보다 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 크다

**답**: 배운 것이 **없다**. [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 찍기 수준(1.3863)보다도 높다. 데이터 로딩이나 라벨을 의심한다.

| 3 | 이상 재현율 | 이상 5개 중 맞힌 것 0 | 0 / 5 = 0 |

**① 쓰는 식**
$$\text{정확도} = \frac{\text{맞힌 수}}{\text{전체 수}}, \qquad \text{재현율} = \frac{\text{맞힌 이상 수}}{\text{이상 수}}$$
```python
# [변수] y: 정상(0) 95개, 이상(1) 5개
y = np.array([0] * 95 + [1] * 5)                     # ①
# [변수] pred: 늘 정상(0)
pred = np.zeros(100)                                 # ①
# [함수] 맞힌 비율 = 정확도
acc = (pred == y).mean()                             # ②
# [함수] 이상인 칸만 골라 맞힌 비율 = 재현율
rec = (pred[y == 1] == 1).mean()                     # ③
# [연결] 출력: 0.95 0.0
print(acc, rec)
```

**문제**: 정상 95개, 이상 5개인 데이터에서 늘 "정상"이라고 답하는 모델의 [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84)와 이상 재현율을 구한다.

**주어진 값**:
- 정상 95개 (모델이 모두 맞힘)
- 이상 5개 (모델이 하나도 못 맞힘)
- 전체 100개

**② [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84)**
1. 식을 그대로 쓴다: [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84) $= \dfrac{\text{맞힌 수}}{\text{전체 수}}$
2. 값을 대입한다: [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84) $= \dfrac{95 + 0}{100}$
3. 분자를 더한다: $95 + 0 = 95$ 이므로 $\dfrac{95}{100}$
4. 나눈다: $95 / 100 = 0.95$

**③ 재현율**
1. 식을 그대로 쓴다: 재현율 $= \dfrac{\text{맞힌 이상 수}}{\text{이상 수}}$
2. 값을 대입한다: 재현율 $= \dfrac{0}{5}$
3. 나눈다: $0 / 5 = 0$

**답**: [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84) **0.95**, 이상 재현율 **0**. [정확도](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#accuracy-%EC%A0%95%ED%99%95%EB%8F%84)만 보면 좋아 보이지만 정작 찾아야 할 이상은 하나도 못 찾는다.
