> [!NOTE]
> **3줄 요약**
> - Σ(시그마)는 "**전부 더해라**"를 짧게 쓴 기호다. for문 하나와 같다.
> - 평균은 전부 더해서 개수로 나눈 값이고, 식으로는 $\frac{1}{m}\sum$로 쓴다.
> - EX\_01의 [가중합](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weighted-sum-%EA%B0%80%EC%A4%91%ED%95%A9)과 EX\_02의 [손실 함수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)([MSE](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#mse-mean-squared-error-%ED%8F%89%EA%B7%A0-%EC%A0%9C%EA%B3%B1-%EC%98%A4%EC%B0%A8))가 Σ로 쓰여 있다.

## 1. 개념 설명

$\sum$ = 번호를 1부터 끝까지 바꿔 가며 안에 있는 것을 전부 더한다.

## 2. 필요한 이유

데이터가 10개면 `+`를 9번 쓰면 되지만, [MNIST](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#mnist-%EC%86%90%EA%B8%80%EC%94%A8-%EC%88%AB%EC%9E%90-%EB%8D%B0%EC%9D%B4%ED%84%B0%EC%85%8B)처럼 6만 개면 다 쓸 수 없다. 그래서 "1번부터 m번까지 전부 더해라"를 기호 하나로 줄여 쓴다.

## 3. 숫자로 보기

1부터 10까지 더하기:

$$1 + 2 + 3 + \cdots + 10 = 55$$

<details><summary>기호 풀이</summary>

| 기호 | 읽는 법 | 뜻 | 예제 값 |
| --- | --- | --- | --- |
| $1, 2, 3$ | 일, 이, 삼 | 더하는 수(1씩 커진다) | 1, 2, 3 |
| $\cdots$ | 점점점 | 중간 생략. 같은 규칙으로 계속 더한다 | 4, 5 |
| $10$ | 십 | 마지막으로 더하는 수 | 6 |
| $55$ | 오십오 | 모두 더한 합 | 21 |

</details>

<details><summary>예제와 풀이</summary>

**문제**: 1부터 6까지의 자연수를 모두 더하면 얼마인가? (식의 마지막 수 10 자리에 6이 들어간다)

**주어진 값**:
- $1$ (첫 수: 여기서부터 더한다)
- $6$ (마지막 수: 여기까지 더한다)

**풀이**
1. 식을 그대로 쓴다: $1 + 2 + 3 + \cdots + 10$
2. 값을 대입한다: $1 + 2 + 3 + \cdots + 6$
3. 생략된 부분($\cdots$)을 펼쳐 쓴다: $1 + 2 + 3 + 4 + 5 + 6$
4. 앞의 두 수를 더한다: $1 + 2 = 3$ 이므로 $3 + 3 + 4 + 5 + 6$
5. 다음 수를 더한다: $3 + 3 = 6$ 이므로 $6 + 4 + 5 + 6$
6. 다음 수를 더한다: $6 + 4 = 10$ 이므로 $10 + 5 + 6$
7. 다음 수를 더한다: $10 + 5 = 15$ 이므로 $15 + 6$
8. 마지막 수를 더한다: $15 + 6 = 21$

**답**: 21

</details>

같은 걸 Σ로 쓰면:

$$\sum_{i=1}^{10} i = 55$$

<details><summary>예제와 풀이</summary>

**문제**: 번호 i를 1부터 4까지 바꿔 가며 i 자체를 모두 더하면 얼마인가?

**주어진 값**:
- 아래쪽 숫자 $1$ (i가 1부터 시작한다)
- 위쪽 숫자 $4$ (i가 4까지 간다)
- Σ 안의 $i$ (더하는 것은 번호 그 자체)

**풀이**
1. 식을 그대로 쓴다: $\sum_{i=1}^{10} i$
2. 값을 대입한다: $\sum_{i=1}^{4} i$
3. Σ를 항 하나씩 펼친다(i에 1, 2, 3, 4를 차례로 넣는다): $1 + 2 + 3 + 4$
4. 앞의 두 수를 더한다: $1 + 2 = 3$ 이므로 $3 + 3 + 4$
5. 다음 수를 더한다: $3 + 3 = 6$ 이므로 $6 + 4$
6. 마지막 수를 더한다: $6 + 4 = 10$

**답**: 10

## 5. Σ와 for문

```python
total = 0
for i in range(1, 11):   # i = 1, 2, ..., 10  (Σ 아래·위 숫자)
    total += i           # Σ 안에 있는 것을 계속 더함
print(total)
```

**실행 결과**:

```text
55
```

numpy에서는 `np.sum(배열)` 한 줄이다.

## 6. 평균

말로 먼저: 전부 더하고($\sum$) 개수 $m$으로 나눈다. $\frac{1}{m}$을 곱하는 것은 $m$으로 나누는 것과 같다.

$$\text{평균} = \frac{1}{m}\sum_{i=1}^{m} y_i$$

<details><summary>기호 풀이</summary>

| 기호 | 읽는 법 | 뜻 | 예제 값 |
| --- | --- | --- | --- |
| 평균 | 평균 | 전부 더해 개수로 나눈 값 | 5 |
| $m$ | 엠 | 데이터 개수 | 3 |
| $\frac{1}{m}$ | 엠 분의 일 | $m$으로 나누기 | $\frac{1}{3}$ |
| $\sum_{i=1}^{m}$ | 시그마 아이는 일부터 엠까지 | 1번부터 m번까지 전부 더하기 | 2 + 4 + 9 |
| $i$ | 아이 | 번호(몇 번째) | 1, 2, 3 |
| $y_i$ | 와이 아이 | i번째 값 | 2, 4, 9 |

</details>

<details><summary>예제와 풀이</summary>

**문제**: 값 3개 $y_1 = 2$, $y_2 = 4$, $y_3 = 9$의 평균은?

**주어진 값**:
- $m = 3$ (데이터 개수)
- $y_1 = 2$ (첫째 값)
- $y_2 = 4$ (둘째 값)
- $y_3 = 9$ (셋째 값)

**풀이**
1. 식을 그대로 쓴다: $\text{평균} = \frac{1}{m}\sum_{i=1}^{m} y_i$
2. 값을 대입한다(Σ는 i = 1, 2, 3 항을 하나씩 펼친다): $\text{평균} = \frac{1}{3}(2 + 4 + 9)$
3. 괄호 안 앞의 두 수를 더한다: $2 + 4 = 6$ 이므로 $\frac{1}{3}(6 + 9)$
4. 괄호 안 나머지를 더한다: $6 + 9 = 15$ 이므로 $\frac{1}{3} \times 15$
5. $\frac{1}{3}$을 곱하는 것은 3으로 나누는 것이다: $15 \div 3 = 5$

**답**: 평균 = 5

</details>

<details><summary>내 이해</summary>



</details>

EX\_02의 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)(labels) 3, 5, 7, …, 21은 합이 120, 개수가 10이다.

- 합 ÷ 개수 = 120 ÷ 10 = **12** (평균)

```python

```


## 7. 예제에서 쓰이는 곳

### 7.1 EX\_01: 가중합

말로 먼저: 같은 번호끼리 곱해서 전부 더하고, 마지막에 b를 더한다. 이 값 $s$를 [가중합](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weighted-sum-%EA%B0%80%EC%A4%91%ED%95%A9)이라 부른다.

$$s = \sum_{i=1}^{3} w_i x_i + b$$

<details><summary>기호 풀이</summary>

| 기호 | 읽는 법 | 뜻 | 예제 값 |
| --- | --- | --- | --- |
| $s$ | 에스 | [가중합](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weighted-sum-%EA%B0%80%EC%A4%91%ED%95%A9) | 6 |
| $\sum_{i=1}^{3}$ | 시그마 아이는 일부터 삼까지 | 1번부터 3번까지 전부 더하기 | 2 + 0 + 3 |
| $i$ | 아이 | 번호(몇 번째) | 1, 2, 3 |
| $w_i$ | 더블유 아이 | i번째 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) | 1, 2, 3 |
| $x_i$ | 엑스 아이 | i번째 입력 | 2, 0, 1 |
| $b$ | 비 | [편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5) | 1 |

</details>

<details><summary>예제와 풀이</summary>

**문제**: 입력 $x = [2, 0, 1]$에 [가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) $w = [1, 2, 3]$을 번호끼리 곱해 더하고 [편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5) $b = 1$을 더한 [가중합](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weighted-sum-%EA%B0%80%EC%A4%91%ED%95%A9) s는?

**주어진 값**:
- $w_1 = 1$, $w_2 = 2$, $w_3 = 3$ ([가중치](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98))
- $x_1 = 2$, $x_2 = 0$, $x_3 = 1$ (입력)
- $b = 1$ ([편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5))

**풀이**
1. 식을 그대로 쓴다: $s = \sum_{i=1}^{3} w_i x_i + b$
2. 값을 대입한다(Σ는 i = 1, 2, 3 항을 하나씩 펼친다): $s = 1 \times 2 + 2 \times 0 + 3 \times 1 + 1$
3. 첫째 곱셈을 한다: $1 \times 2 = 2$ 이므로 $s = 2 + 2 \times 0 + 3 \times 1 + 1$
4. 둘째 곱셈을 한다: $2 \times 0 = 0$ 이므로 $s = 2 + 0 + 3 \times 1 + 1$
5. 셋째 곱셈을 한다: $3 \times 1 = 3$ 이므로 $s = 2 + 0 + 3 + 1$
6. 앞에서부터 더한다: $2 + 0 = 2$ 이므로 $s = 2 + 3 + 1$
7. 다음 수를 더한다: $2 + 3 = 5$ 이므로 $s = 5 + 1$
8. [편향](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5)을 더한다: $5 + 1 = 6$

**답**: $s = 6$

</details>

### 7.2 EX\_02: 손실 함수 MSE (평균 제곱 오차)

말로 먼저: 데이터마다 "예측 − [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)"([오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8))을 구하고, **제곱**하고, **평균**을 낸다.

$$\text{cost}(w, b) = \frac{1}{m}\sum_{i=1}^{m}\left(h(x_i) - y_i\right)^2$$

<details><summary>기호 풀이</summary>

| 기호 | 읽는 법 | 뜻 | 예 |
| --- | --- | --- | --- |
| cost | 코스트 | [손실 함수](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)의 값(코드의 `cost`) | 177 (W = 0, B = 0일 때) |
| $h(x_i)$ | 에이치 엑스 아이 | i번째 예측 | 아래 3개짜리 예에서 4, 4, 8 |
| $y_i$ | 와이 아이 | i번째 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) | 3, 5, 7 |
| $m$ | 엠 | 데이터 개수 | 3 |

</details>

<details><summary>예제와 풀이</summary>

**문제**: 데이터 2개에서 예측이 $h(x_1) = 3$, $h(x_2) = 1$이고 [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)이 $y_1 = 1$, $y_2 = 2$일 때 [손실](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) cost는?

**주어진 값**:
- $m = 2$ (데이터 개수)
- $h(x_1) = 3$, $h(x_2) = 1$ (모델의 예측)
- $y_1 = 1$, $y_2 = 2$ ([정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5))

**풀이**
1. 식을 그대로 쓴다: $\text{cost}(w, b) = \frac{1}{m}\sum_{i=1}^{m}\left(h(x_i) - y_i\right)^2$
2. 값을 대입한다(Σ는 i = 1, 2 항을 하나씩 펼친다): $\text{cost} = \frac{1}{2}\left((3 - 1)^2 + (1 - 2)^2\right)$
3. 첫째 괄호의 뺄셈을 한다: $3 - 1 = 2$ 이므로 $\frac{1}{2}\left(2^2 + (1 - 2)^2\right)$
4. 둘째 괄호의 뺄셈을 한다: $1 - 2 = -1$ 이므로 $\frac{1}{2}\left(2^2 + (-1)^2\right)$
5. 첫째 제곱을 한다: $2^2 = 2 \times 2 = 4$ 이므로 $\frac{1}{2}\left(4 + (-1)^2\right)$
6. 둘째 제곱을 한다: $(-1)^2 = (-1) \times (-1) = 1$ 이므로 $\frac{1}{2}(4 + 1)$
7. 괄호 안을 더한다: $4 + 1 = 5$ 이므로 $\frac{1}{2} \times 5$
8. $\frac{1}{2}$을 곱하는 것은 2로 나누는 것이다: $5 \div 2 = 2.5$

**답**: cost = 2.5

## 8. 개념 재확인

<details><summary>1. $\sum_{i=1}^{4} 2i$는?</summary>

| 단계 | 하는 일 | 식 | 계산 | 결과 |
|---|---|---|---|---|
| 1 | i = 1, 2, 3, 4 넣기 | $2i$ | 2×1, 2×2, 2×3, 2×4 | 2, 4, 6, 8 |
| 2 | 전부 더하기 | $\sum$ | 2 + 4 + 6 + 8 | 20 |
| 3 | 코드로 확인 | `range(1, 5)`, `total += 2 * i` | i = 1부터 4까지 | 20 |

**① 쓰는 식**
$$\sum_{i=1}^{4} 2i$$
- 위 식 ← ② ($2i$에 $i$ 넣기), ③ ($\sum$ 전부 더하기)
- $\sum$은 "전부 더해라", $i$는 번호, 아래 $i=1$은 1번부터 시작, 위쪽 4는 4번까지, $2i$는 번호마다 더할 값(번호의 2배)이다.
```python
total = 0               # ④ 합계를 0으로 시작
for i in range(1, 5):   # ② i = 1, 2, 3, 4 (range의 끝 5는 포함 안 됨)
    total += 2 * i      # ③ 2i를 계속 더함 (④에서 하나씩 따라가 본다)
```

**주어진 값**
- 아래쪽 숫자 $1$ ($i$가 1부터 시작한다)
- 위쪽 숫자 $4$ ($i$가 4까지 간다)
- Σ 안의 $2i$ (번호마다 더할 값, 번호의 2배)

**② i에 1, 2, 3, 4를 차례로 넣기** ($2i$)
- 식을 그대로 쓴다: $\sum_{i=1}^{4} 2i$
- Σ를 항 하나씩 펼친다(i에 1, 2, 3, 4를 차례로 넣는다): $2 \times 1 + 2 \times 2 + 2 \times 3 + 2 \times 4$
- 첫째 곱셈: $2 \times 1 = 2$ 이므로 $2 + 2 \times 2 + 2 \times 3 + 2 \times 4$
- 둘째 곱셈: $2 \times 2 = 4$ 이므로 $2 + 4 + 2 \times 3 + 2 \times 4$
- 셋째 곱셈: $2 \times 3 = 6$ 이므로 $2 + 4 + 6 + 2 \times 4$
- 넷째 곱셈: $2 \times 4 = 8$ 이므로 $2 + 4 + 6 + 8$

**③ 전부 더하기** ($\sum$)
- 식(② 결과)을 그대로 쓴다: $2 + 4 + 6 + 8$
- 앞의 두 수를 더한다: $2 + 4 = 6$ 이므로 $6 + 6 + 8$
- 다음 수를 더한다: $6 + 6 = 12$ 이므로 $12 + 8$
- 마지막 수를 더한다: $12 + 8 = 20$

**④ 코드로 확인** (`total += 2 * i`)
- 코드를 그대로 쓴다: `total += 2 * i` (total에 $2i$를 더해 다시 total에 넣는다)
- total = 0에서 시작한다
- i = 1을 대입한다: total = $0 + 2 \times 1 = 2$
- i = 2를 대입한다: total = $2 + 2 \times 2 = 6$
- i = 3을 대입한다: total = $6 + 2 \times 3 = 12$
- i = 4를 대입한다: total = $12 + 2 \times 4 = 20$ → 식으로 구한 값과 같다.

**답**: **20**

<details><summary>2. 오차가 <code>[2, −2]</code>이면 MSE는?</summary>

| 단계 | 하는 일 | 식 | 계산 | 결과 |
|---|---|---|---|---|
| 1 | [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 제곱하기 | $e^2$ | $2^2$, $(-2)^2$ | 4, 4 |
| 2 | 전부 더하기 | $\sum e^2$ | 4 + 4 | 8 |
| 3 | 개수 m으로 나누기 | $\frac{1}{m}\sum$ | 8 ÷ 2 | 4 |
| 4 | 코드로 확인 | `np.mean(np.array([2, -2])**2)` | - | 4.0 |

**① 쓰는 식**
$$\text{MSE} = \frac{1}{m}\sum_{i=1}^{m} e_i^2$$
- 위 식 ← ② ($e_i^2$ 제곱), ③ ($\sum$ 전부 더하기), ④ ($\frac{1}{m}$ 개수로 나누기)
- $e_i$는 i번째 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)(예측 − [정답](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)), $m$은 데이터 개수, $\sum$은 전부 더하기, $\frac{1}{m}$을 곱하는 것은 $m$으로 나누는 것(평균)이다.
- 여기서는 [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)가 `[2, -2]`이므로 $e_1 = 2$, $e_2 = -2$, $m = 2$이다.
```python
np.mean(np.array([2, -2])**2)   # ② 오차 제곱 → ③ 더하기 → ④ 개수로 나누기 (⑤에서 확인)
```

**주어진 값**
- $e_1 = 2$, $e_2 = -2$ ([오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 두 개)
- $m = 2$ (데이터 개수)

**② [오차](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 제곱하기** ($e^2$)
- 식을 그대로 쓴다: $e_i^2$
- 값을 대입한다: $e_1^2 = 2^2$, $e_2^2 = (-2)^2$
- 첫째 제곱: $2^2 = 2 \times 2 = 4$
- 둘째 제곱: $(-2)^2 = (-2) \times (-2) = 4$ (음수끼리 곱하면 양수가 된다)
- 제곱한 값: `[4, 4]`

**③ 전부 더하기** ($\sum e^2$)
- 식을 그대로 쓴다: $\sum_{i=1}^{m} e_i^2$
- 값을 대입한다(Σ는 i = 1, 2 항을 펼친다): $e_1^2 + e_2^2 = 4 + 4$
- 덧셈을 한다: $4 + 4 = 8$

**④ 개수 m으로 나누기** ($\frac{1}{m}\sum$)
- 식을 그대로 쓴다: $\text{MSE} = \frac{1}{m}\sum_{i=1}^{m} e_i^2$
- 값을 대입한다(③의 합 8을 Σ 자리에 쓴다): $\text{MSE} = \frac{1}{2} \times 8$
- $\frac{1}{2}$을 곱하는 것은 2로 나누는 것이다: $8 \div 2 = 4$

**⑤ 코드로 확인** (`np.mean(...)`)
- 코드를 그대로 쓴다: `np.mean(np.array([2, -2])**2)`
- `np.array([2, -2])**2`를 계산한다: `[2², (-2)²]` = `[4, 4]`
- 평균을 낸다: $(4 + 4) \div 2 = 4.0$ → ④와 같다.

**답**: [MSE](../../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#mse-mean-squared-error-%ED%8F%89%EA%B7%A0-%EC%A0%9C%EA%B3%B1-%EC%98%A4%EC%B0%A8) = **4**

<details><summary>3. Σ를 파이썬으로 바꾸면 어떤 문법인가?</summary>

| 단계 | 하는 일 | 식 | 계산 | 결과 |
|---|---|---|---|---|
| 1 | 합계 0으로 시작 | `total = 0` | - | 0 |
| 2 | 한 칸씩 더하기 | `for i in range(1, 11): total += i` | 0+1, 1+2, … | i = 10까지 가면 55 |
| 3 | 한 줄로 줄이기 | `np.sum(배열)`, `sum(...)` | - | 같은 합계 |

Σ의 아래·위 숫자가 `range`, Σ 안의 것이 `+=`로 더하는 값이다.

**① 쓰는 식**
$$\sum_{i=1}^{10} i = 55$$
- 위 식 ← ② (합계 시작), ③ (한 칸씩 더하기), ④ (한 줄로 줄이기)
- 번호 $i$를 1부터 10까지 바꿔 가며 $i$ 자체를 전부 더한다.
```python
total = 0                # ② 합계를 0으로 시작
for i in range(1, 11):   # ③ i = 1, 2, ..., 10 (Σ 아래·위 숫자)
    total += i           # ③ Σ 안에 있는 것을 계속 더함
print(total)             # ③ 마지막 합계 55를 출력 (④는 이 반복을 한 줄로 줄인 것)
```

**주어진 값**
- Σ의 아래쪽 1, 위쪽 10 (`range(1, 11)`로 옮긴다. `range`의 끝 숫자 11은 포함하지 않는다)
- Σ 안의 $i$ (더하는 것은 번호 그 자체, `total += i`)

**② 합계 0으로 시작** (`total = 0`)
- 코드를 그대로 쓴다: `total = 0`
- 의미: 아직 아무것도 더하지 않았으므로 0이다. 덧셈에서 0은 값을 바꾸지 않는다.

**③ 한 칸씩 더하기** (`total += i`)
- 코드를 그대로 쓴다: `total += i` ("total에 i를 더해서 다시 total에 넣는다"는 뜻이다)
- i = 1을 대입한다: total = $0 + 1 = 1$
- i = 2를 대입한다: total = $1 + 2 = 3$
- i = 3을 대입한다: total = $3 + 3 = 6$
- i = 4를 대입한다: total = $6 + 4 = 10$
- i = 5를 대입한다: total = $10 + 5 = 15$
- i = 6을 대입한다: total = $15 + 6 = 21$
- i = 7을 대입한다: total = $21 + 7 = 28$
- i = 8을 대입한다: total = $28 + 8 = 36$
- i = 9를 대입한다: total = $36 + 9 = 45$
- i = 10을 대입한다: total = $45 + 10 = 55$

**④ 한 줄로 줄이기** (`np.sum(배열)`, `sum(...)`)
- 코드를 그대로 쓴다: `sum(range(1, 11))`
- 의미: 반복문 없이 값을 전부 더해 주는 함수이다. $1 + 2 + \cdots + 10 = 55$로 ③과 같은 합계가 나온다.

**답**: **for문 + 누적 더하기(`total += …`)**. 짧게는 `sum()`, numpy면 `np.sum()`을 쓴다.

</details>
