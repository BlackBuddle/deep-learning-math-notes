# 엔트로피 (Entropy)

[목차로 돌아가기](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D%EC%88%98%ED%95%99_MOC.md) · 먼저 볼 것: [M07_로그](M07_%EB%A1%9C%EA%B7%B8.md), [M08_확률_기초](M08_%ED%99%95%EB%A5%A0_%EA%B8%B0%EC%B4%88.md)

> [!NOTE]
> **3줄 요약**
> - **정보량**(놀람의 크기)은 [확률](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%ED%99%95%EB%A5%A0) p인 일이 일어났을 때 $-\ln p$다. 흔한 일은 덜 놀랍고(작음), 드문 일은 많이 놀랍다(큼).
> - **엔트로피**는 정보량의 평균 = "결과가 얼마나 예측하기 어려운가"다. 공정한 동전은 ln 2 = 0.693, 늘 앞면만 나오는 동전은 0.
> - **cross-entropy**는 진짜 분포 대신 **모델의 확률**로 놀람을 잰 평균이다. 모델이 진짜와 같을 때 가장 작아지므로, 이것을 줄이는 것이 [분류](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%ED%9A%8C%EA%B7%80%EC%99%80-%EB%B6%84%EB%A5%98) 학습이다.

## 1. 한 줄 뜻

엔트로피 = 불확실함의 크기. 결과를 맞히기 어려울수록 크다.

## 2. 왜 필요한가

EX_05·06의 [비용](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98) 이름이 **cross-entropy**다. 이름이 왜 그런지, 그리고 학습 첫 loss가 왜 0.69 근처(EX_05)와 1.1 근처(EX_06)에서 시작하는지가 엔트로피로 설명된다.

## 3. 숫자로 보기

### 3.1 정보량(놀람): $-\ln p$

| 일어난 일의 확률 p | 1 (반드시) | 0.5 | 0.1 | 0.01 |
|---|---|---|---|---|
| 놀람 $-\ln p$ | 0 | 0.693 | 2.303 | 4.605 |

- 해가 동쪽에서 떴다(p ≈ 1) → 놀랍지 않다, 정보 0
- 로또 당첨(p 아주 작음) → 아주 놀랍다, 정보 큼
- [M07_로그](M07_%EB%A1%9C%EA%B7%B8.md) 7절의 벌점 표와 같은 숫자다.

### 3.2 엔트로피 = 놀람의 평균

$$H(p) = \sum_k p_k \times (-\ln p_k)$$

"각 결과의 놀람에 그 결과가 나올 확률을 곱해 더한다" = 평균 놀람.

| 상황 | 확률 분포 | 엔트로피 H |
|---|---|---|
| 늘 앞면만 나오는 동전 | [1, 0] | **0** (맞히기 쉬움) |
| 거의 앞면 | [0.99, 0.01] | 0.056 |
| 앞면이 잘 나옴 | [0.9, 0.1] | 0.325 |
| 공정한 동전 | [0.5, 0.5] | **0.693** = ln 2 |
| 3등급 모두 같은 확률 | [1/3, 1/3, 1/3] | **1.099** = ln 3 |
| 주사위 | 1/6씩 6개 | 1.792 = ln 6 |
| 숫자 0~9 모두 같은 확률 | 1/10씩 10개 | 2.303 = ln 10 |

- 결과가 한쪽으로 쏠릴수록 작고, **모두 같은 확률일 때 가장 크다**(ln 경우의 수).
- 공정한 동전 손계산: 0.5 × 0.693 + 0.5 × 0.693 = 0.693

> 밑을 2로 쓰면($\log_2$) 단위가 **비트**가 된다. 공정한 동전 = 1비트. 딥러닝은 보통 ln을 쓴다.

### 3.3 cross-entropy = 모델의 확률로 잰 놀람의 평균

$$H(p, q) = \sum_k p_k \times (-\ln q_k)$$

- $p$: 진짜 분포 (정답)
- $q$: 모델이 낸 확률

진짜가 공정한 동전 [0.5, 0.5]일 때, 모델이 낸 확률 q에 따라:

| 모델의 q | cross-entropy H(p, q) |
|---|---|
| [0.5, 0.5] (진짜와 같음) | **0.693** = H(p) |
| [0.6, 0.4] | 0.714 |
| [0.9, 0.1] | 1.204 |

- 모델이 진짜와 같을 때 **가장 작고**, 그때 값이 엔트로피 H(p)와 같다.
- 모델이 틀릴수록 커진다. 그래서 cross-entropy를 줄이면 모델의 확률이 진짜에 가까워진다.
- 차이 H(p, q) − H(p)를 **KL 발산**이라고 부른다(위 [0.9, 0.1]이면 1.204 − 0.693 = 0.511). "모델이 진짜와 얼마나 다른가"의 순수한 크기다.

### 3.4 정답이 원-핫일 때

분류 문제의 정답은 [원-핫](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EC%9B%90-%ED%95%AB-%EC%9D%B8%EC%BD%94%EB%94%A9)(예: [1, 0, 0])이라 엔트로피가 **0**이다(결과가 정해져 있음). 그러면:

$$H(p, q) = 1 × (-\ln q_{\text{정답}}) + 0 + 0 = -\ln q_{\text{정답}}$$

[D05_소프트맥스와_다중분류](../01_%EA%B0%9C%EB%85%90%EB%85%B8%ED%8A%B8/D05_%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4%EC%99%80_%EB%8B%A4%EC%A4%91%EB%B6%84%EB%A5%98.md) 4.4절의 "정답 칸 확률만 본다"가 바로 이것이다. 예: 정답 [1, 0, 0], 모델 [0.7, 0.2, 0.1] → −ln 0.7 = 0.357

## 4. 예제에서 만나는 곳: 첫 loss의 의미

학습 직전의 모델은 아무것도 모르니 대체로 모든 등급에 비슷한 확률을 준다. 그러면 cross-entropy ≈ "모두 같은 확률"의 엔트로피다.

| 예제 | 등급 수 | 모두 같은 확률일 때 | 노트북의 첫 loss |
|---|---|---|---|
| EX_05 (이진) | 2 | ln 2 = 0.693 | 0.6566 |
| EX_06 (3등급) | 3 | ln 3 = 1.099 | 1.1564 |

첫 loss가 이 값 근처라면 "모델이 아직 찍는 수준"이라는 뜻이다. 여기서 얼마나 내려가는지가 학습이 된 정도다.

## 5. 코드로

```python
import numpy as np
H  = lambda p: -(np.array(p) * np.log(np.array(p))).sum()                 # 엔트로피
CE = lambda p, q: -(np.array(p) * np.log(np.array(q))).sum()              # cross-entropy
print(H([0.5, 0.5]), H([0.9, 0.1]), H([1/3, 1/3, 1/3]))
print(CE([0.5, 0.5], [0.9, 0.1]), CE([1, 0, 0], [0.7, 0.2, 0.1]))
```

**실행 결과**:

```
0.6931471805599453 0.3250829733914482 1.0986122886681096
1.203972804325936 0.35667494393873245
```

> [!WARNING]
> **⚠ 확률 0이 있으면**
> `H([1, 0])`처럼 0이 들어가면 0 × ln 0 계산에서 경고(`divide by zero encountered in log`, `invalid value encountered in multiply`)와 함께 `nan`이 나온다. 수학에서는 0 × ln 0을 0으로 약속한다. 코드에서는 0인 칸을 빼고 더하면 된다.

<details><summary>1. 엔트로피가 가장 큰 동전은?</summary>

앞뒤 확률이 같은 **공정한 동전** (ln 2 = 0.693)

</details>

<details><summary>2. 10등급 분류 모델의 학습 직전 loss는 대략 얼마일까?</summary>

모두 1/10이면 ln 10 ≈ **2.303**

</details>

<details><summary>3. cross-entropy가 엔트로피보다 작아질 수 있나?</summary>

**없다.** 모델이 진짜와 같을 때 같아지고, 다르면 더 크다.

</details>
