# 함수와 일차함수

[목차로 돌아가기](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D%EC%88%98%ED%95%99_MOC.md)

> [!NOTE]
> **3줄 요약**
> - 함수는 **값을 넣으면 정해진 규칙대로 값 하나가 나오는 기계**다.
> - 일차함수 $y = wx + b$는 그래프가 **직선**이다. $w$는 [기울기](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EA%B8%B0%EC%9A%B8%EA%B8%B0)(얼마나 가파른가), $b$는 절편(x가 0일 때의 y)이다.
> - 예제 EX_02·EX_03의 `Hypothesis(x)`가 바로 이 일차함수이고, EX_01의 계단 함수도 함수다.

## 1. 한 줄 뜻

함수 = 입력 하나를 넣으면 출력 하나가 나오는 규칙.

## 2. 왜 필요한가

딥러닝 모델은 통째로 하나의 큰 함수다. 손글씨 사진(입력)을 넣으면 "이건 7"(출력)이 나온다. 이 큰 함수는 작은 함수를 여러 개 이어 붙여서 만든다. 그 가장 작은 부품이 일차함수다.

## 3. 숫자로 보기

규칙: "2를 곱하고 1을 더한다"

| 넣는 값 x | 계산 | 나오는 값 y |
|---|---|---|
| 0 | 2×0 + 1 | 1 |
| 1 | 2×1 + 1 | 3 |
| 2 | 2×2 + 1 | 5 |
| 3 | 2×3 + 1 | 7 |
| 4 | 2×4 + 1 | 9 |

- x가 1 늘 때마다 y는 항상 **2씩** 는다. 이 2가 **기울기**다.
- x가 0일 때 y는 **1**이다. 이 1이 **절편**이다.

> [!TIP]
> **예제와 연결**
> EX_02의 데이터가 정확히 이 규칙이다. x = 1~10, 정답(labels) = 3, 5, 7, …, 21 → $y = 2x + 1$.
> 모델은 이 규칙(w = 2, b = 1)을 모르는 채로 데이터만 보고 찾아내야 한다. 그 과정이 [D02_경사하강법으로_직선찾기](../01_%EA%B0%9C%EB%85%90%EB%85%B8%ED%8A%B8/D02_%EA%B2%BD%EC%82%AC%ED%95%98%EA%B0%95%EB%B2%95%EC%9C%BC%EB%A1%9C_%EC%A7%81%EC%84%A0%EC%B0%BE%EA%B8%B0.md)다.

## 4. 기호와 식

$$y = wx + b$$

| 기호 | 읽는 법 | 뜻 | 위 표의 값 |
|---|---|---|---|
| $x$ | 엑스 | 넣는 값(입력) | 3 |
| $w$ | 더블유 | 기울기. 딥러닝에서는 **[가중치](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EA%B0%80%EC%A4%91%EC%B9%98)**(weight) | 2 |
| $b$ | 비 | 절편. 딥러닝에서는 **편향**(bias) | 1 |
| $y$ | 와이 | 나오는 값(출력) | 7 |

- 함수에 이름을 붙이면 $f(x) = 2x + 1$로 쓰고 "에프 오브 엑스"라고 읽는다.
- $f(3) = 7$은 "f에 3을 넣으면 7이 나온다"는 뜻이다.
- 예제 코드에서는 이름이 `h(x)`다. h는 hypothesis([가설](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EA%B0%80%EC%84%A4)), "아마 이런 직선일 것이다"라는 뜻이다.

### 기울기 w를 바꾸면

| w | x=0 | x=1 | x=2 | 모양 |
|---|---|---|---|---|
| 0 | 1 | 1 | 1 | 수평선 |
| 2 | 1 | 3 | 5 | 오르막 |
| -1 | 1 | 0 | -1 | 내리막 |

### 절편 b를 바꾸면

기울기는 그대로이고 직선 전체가 위아래로 평행 이동한다. b = 1 → b = 5로 바꾸면 모든 y가 4씩 커진다.

### 그래프 읽는 법

- 가로축(x축) = 넣는 값, 세로축(y축) = 나오는 값
- 점 (2, 5) = "2를 넣으면 5가 나온다"
- 위 표의 점들을 이으면 직선이 된다. 그래서 "일차함수 = 직선"이다.

## 5. 이미 아는 것과 연결

C에서 짠 함수와 구조가 같다.

```c
double h(double x) {      // 입력 x
    return 2 * x + 1;     // 규칙: 2를 곱하고 1을 더함
}
```

`C_Study`의 `max_robot_speed()`도 값을 계산해서 `return`하는 함수였다. 수학의 함수도 "넣으면 나온다"는 점에서 같다.

> [!WARNING]
> **⚠ 차이 하나**
> 수학의 함수는 **같은 입력에는 항상 같은 출력**이 나온다. `rand()`를 쓰는 C 함수처럼 부를 때마다 다른 값이 나오면 수학에서는 함수라고 하지 않는다.

## 6. 예제 코드에서 만나는 곳

### EX_02, EX_03: 가설

```python
def Hypothesis(x):
    return W*x + B      # 일차함수 y = wx + b
```

### EX_01: 계단 함수

```python
y = np.float32(s > 10)  # s가 10보다 크면 1.0, 아니면 0.0
```

계단 함수도 함수다. 넣는 값은 s, 나오는 값은 0 또는 1이다. 그래프를 그리면 10에서 뚝 올라가는 계단 모양이다.

| s | 5 | 10 | 10.1 | 42 |
|---|---|---|---|---|
| y | 0 | 0 | 1 | 1 |

> 뒤에 나올 [시그모이드](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C)([D04_시그모이드와_이진분류](../01_%EA%B0%9C%EB%85%90%EB%85%B8%ED%8A%B8/D04_%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C%EC%99%80_%EC%9D%B4%EC%A7%84%EB%B6%84%EB%A5%98.md))와 [ReLU](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#relu)([D08_ReLU와_드롭아웃](../01_%EA%B0%9C%EB%85%90%EB%85%B8%ED%8A%B8/D08_ReLU%EC%99%80_%EB%93%9C%EB%A1%AD%EC%95%84%EC%9B%83.md))도 모두 "넣으면 나오는" 함수다. 모양만 다르다.
