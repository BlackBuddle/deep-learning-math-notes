# 확률 기초

[목차로 돌아가기](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D%EC%88%98%ED%95%99_MOC.md)

> [!NOTE]
> **3줄 요약**
> - 확률은 **0~1 사이 값**이고, 일어날 수 있는 경우를 전부 더하면 **1**이다.
> - [분류](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%ED%9A%8C%EA%B7%80%EC%99%80-%EB%B6%84%EB%A5%98) 모델의 출력([시그모이드](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EC%8B%9C%EA%B7%B8%EB%AA%A8%EC%9D%B4%EB%93%9C), [소프트맥스](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4))은 "각 정답일 확률"이고, 정확도는 "맞힌 비율"이다.
> - 따로따로 일어나는 일이 **둘 다** 일어날 확률은 곱한다. [드롭아웃](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EB%93%9C%EB%A1%AD%EC%95%84%EC%9B%83)이 이 규칙으로 동작한다.

## 1. 한 줄 뜻

확률 = 어떤 일이 일어날 가능성을 0(절대 안 일어남) ~ 1(반드시 일어남) 사이 숫자로 나타낸 것.

## 2. 왜 필요한가

- 분류 모델은 "7이다"라고 단정하지 않고 "7일 확률 0.95"처럼 말한다.
- [비용 함수](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)([cross-entropy](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#cross-entropy))는 그 확률로 벌점을 매긴다.
- 드롭아웃은 "40% 확률로 끄기"다.

## 3. 숫자로 보기

### 비율로서의 확률

| 상황 | 계산 | 확률 |
|---|---|---|
| 동전 앞면 | 1 ÷ 2 | 0.5 |
| 주사위 6 | 1 ÷ 6 | 0.167 |
| EX_05에서 정답이 1인 사람 | 9 ÷ 18 | 0.5 |
| EX_07 시험 정확도 | 9257 ÷ 10000 | 0.9257 |

정확도도 확률처럼 읽을 수 있다: "이 모델에 새 그림을 주면 약 92.57% 확률로 맞힌다".

### 규칙 1: 모든 경우를 더하면 1

| 상황 | 경우들 | 합 |
|---|---|---|
| 동전 | 앞 0.5 + 뒤 0.5 | 1 |
| EX_05 출력 | 1일 확률 p + 0일 확률 (1 − p) | 1 |
| EX_06 출력 | 정상 0.783 + 주의 0.206 + 경고 0.010 | 1 |

- 그래서 EX_05는 출력이 하나(p)뿐이어도 된다. 0일 확률은 1 − p로 자동으로 정해진다.
- 소프트맥스는 이 규칙이 지켜지도록 만든 함수다([D05_소프트맥스와_다중분류](../01_%EA%B0%9C%EB%85%90%EB%85%B8%ED%8A%B8/D05_%EC%86%8C%ED%94%84%ED%8A%B8%EB%A7%A5%EC%8A%A4%EC%99%80_%EB%8B%A4%EC%A4%91%EB%B6%84%EB%A5%98.md)).

### 규칙 2: 따로 일어나는 일이 둘 다 일어날 확률은 곱한다

| 상황 | 계산 | 확률 |
|---|---|---|
| 동전 두 번 모두 앞면 | 0.5 × 0.5 | 0.25 |
| 드롭아웃(0.4)에서 두 칸이 모두 꺼짐 | 0.4 × 0.4 | 0.16 |
| 세 칸이 모두 켜져 있음 | 0.6 × 0.6 × 0.6 | 0.216 |

- 여러 번 곱하면 빠르게 작아진다. 이걸 다루려고 [로그](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EB%A1%9C%EA%B7%B8-ln)를 쓴다([M07_로그](M07_%EB%A1%9C%EA%B7%B8.md) 6절).

## 4. 기호

| 기호 | 뜻 | 예 |

| $1 - p$ | 일어나지 **않을** 확률 | 0.5749 |

## 5. 원-핫 = "정답일 확률이 1인" 분포

[원-핫](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#%EC%9B%90-%ED%95%AB-%EC%9D%B8%EC%BD%94%EB%94%A9) `[0, 1, 0]`은 "주의일 확률 1, 나머지 0"이라는 확률 분포로 볼 수 있다. 모델의 출력 [0.36, 0.44, 0.20]과 **같은 모양**이라서, 둘이 얼마나 다른지를 cross-entropy로 잴 수 있다. 정답 칸이 1, 나머지가 0이라 결국 **정답 칸의 확률만** 벌점에 들어간다.

## 6. 평균으로 맞춰 주기: 드롭아웃의 1.67배

드롭아웃(0.4)은 값 하나하나를 40% 확률로 0으로 만든다. 그대로 두면 평균이 0.6배로 줄어든다. 그래서 남은 값을 $\frac{1}{1 - 0.4} ≈ 1.667$배 키운다.

$$\text{평균} = 0.6 × (1 × 1.667) + 0.4 × 0 = 1.0$$

```python
import numpy as np
rng = np.random.default_rng(0)            # 무작위 생성기 (0으로 고정해 매번 같은 결과)
a = np.ones(100000)                       # 1이 10만 개
keep = rng.random(100000) >= 0.4          # 0~1 무작위 수가 0.4 이상이면 남김 → 약 60% 남음
d = a * keep / (1 - 0.4)                  # 꺼진 칸은 0, 남은 칸은 1.667배
print(1 - keep.mean(), d.mean())          # 꺼진 비율, 평균
```

**실행 결과**:

```
0.39854999999999996 1.0024166666666665
```

꺼진 비율은 약 0.4, 평균은 약 1.0으로 유지된다. 자세히: [D08_ReLU와_드롭아웃](../01_%EA%B0%9C%EB%85%90%EB%85%B8%ED%8A%B8/D08_ReLU%EC%99%80_%EB%93%9C%EB%A1%AD%EC%95%84%EC%9B%83.md)
