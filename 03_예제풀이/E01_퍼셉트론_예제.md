# EX_01 예제 풀이 — 퍼셉트론 구현

[목차](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D%EC%88%98%ED%95%99_MOC.md) · 개념: [D01_퍼셉트론](../01_%EA%B0%9C%EB%85%90%EB%85%B8%ED%8A%B8/D01_%ED%8D%BC%EC%85%89%ED%8A%B8%EB%A1%A0.md) · 다음 예제: [E02_가설최적화_예제](E02_%EA%B0%80%EC%84%A4%EC%B5%9C%EC%A0%81%ED%99%94_%EC%98%88%EC%A0%9C.md)

> [!NOTE]
> **3줄 요약**
> - 입력 3개에 가중치 3개를 곱해 더하고 편향을 얹은 뒤, 기준(10)을 넘는지로 0/1을 정하는 **인공 뉴런 하나**를 numpy로 직접 만든다.
> - 핵심 코드는 `np.sum(W * X) + B`(가중합)와 `np.float32(s > 10)`(계단 함수) 두 줄이다.
> - 결과: 가중합 42 → 10보다 크므로 출력 1.0

## 0. 한눈에 보기

| 항목 | 내용 |
|---|---|
| 입력 | X = [1, 2, 3] |
| 가중치·편향 | W = [4, 5, 6], B = 10 (사람이 정한 값, 학습 없음) |
| 계산 | 가중합 s = Σ wᵢxᵢ + b |
| 활성화 함수 | 계단 함수 (s > 10이면 1) |
| 결과 | s = 42, y = 1.0 |

> 이 예제에는 **학습이 없다**. 가중치를 사람이 정해 놓고 계산만 한다. 가중치를 데이터로 찾는 학습은 다음 예제([E02_가설최적화_예제](E02_%EA%B0%80%EC%84%A4%EC%B5%9C%EC%A0%81%ED%99%94_%EC%98%88%EC%A0%9C.md))부터다.

## 1. 셀별 풀이

### 1-1. 수식

노트북 맨 위의 식:

$$y = \sigma\left(\sum_{i=1}^{3} w_i x_i + b\right)$$

"입력과 가중치를 같은 번호끼리 곱해 다 더하고(Σ), b를 더한 뒤, 활성화 함수(σ)에 넣는다". 기호 풀이는 [D01_퍼셉트론](../01_%EA%B0%9C%EB%85%90%EB%85%B8%ED%8A%B8/D01_%ED%8D%BC%EC%85%89%ED%8A%B8%EB%A1%A0.md) 4절, Σ는 [M02_시그마와_평균](../02_%EC%88%98%ED%95%99%EB%85%B8%ED%8A%B8/M02_%EC%8B%9C%EA%B7%B8%EB%A7%88%EC%99%80_%ED%8F%89%EA%B7%A0.md).

### 1-2. 모듈 불러오기

```python
import numpy as np                                   # 배열 계산 도구 numpy를 np라는 짧은 이름으로 불러옴

print("NumPy Version :{}".format(np.__version__))    # 설치된 numpy 버전 출력 ({} 자리에 버전이 들어감)
```

**실행 결과**:

```
NumPy Version :2.0.2
```

### 1-3. 입력, 가중치, 편향

```python
# Input, Weight, Bias
X = np.array([1,2,3])   # 입력 3개를 numpy 배열로 (C의 int X[3] = {1,2,3}과 비슷)
W = np.array([4,5,6])   # 입력마다 하나씩, 가중치 3개
B = 10                  # 편향: 배열이 아니라 숫자 하나
```

> [!TIP]
> **numpy 배열을 쓰는 이유**
> 파이썬 리스트끼리는 `*`로 곱할 수 없지만, numpy 배열은 `W * X` 한 줄로 같은 자리끼리 곱해 준다. for문을 직접 쓰지 않아도 된다.

### 1-4. 곱하고 더하기 (가중합)

```python
# Element-wise multiply (같은 자리끼리 곱하기)
mul = W * X                                  # [4*1, 5*2, 6*3] = [4, 10, 18]
print("mul = W * X : {}".format(mul))

# Summation array and Add bias (전부 더하고 편향 더하기)
s = np.sum(mul) + B                          # 4 + 10 + 18 = 32, 여기에 B(10)를 더해 42
print("s = {}".format(s))
```

**실행 결과**:

```
mul = W * X : [ 4 10 18]
s = 42
```

### 1-5. 활성화 함수 (계단 함수)

```python
# Activation Function : Step Function
y = np.float32(s > 10)          # s > 10 이 참(True)이면 1.0, 거짓(False)이면 0.0
print("y = {}".format(y))
```

**실행 결과**:

```
y = 1.0
```

- `s > 10`은 True 또는 False를 돌려준다.
- `np.float32(...)`는 그걸 실수 1.0 또는 0.0으로 바꾼다. C의 `(s > 10) ? 1.0f : 0.0f`와 같은 일이다.

> [!WARNING]
> **⚠ 기준값 10**
> 교과서의 퍼셉트론은 보통 기준이 0이다. 이 예제는 10을 기준으로 썼다. s > 10은 (s − 10) > 0과 같으므로, 편향을 10 줄이고 기준을 0으로 둔 것과 똑같다([D01_퍼셉트론](../01_%EA%B0%9C%EB%85%90%EB%85%B8%ED%8A%B8/D01_%ED%8D%BC%EC%85%89%ED%8A%B8%EB%A1%A0.md) 4절).

## 3. 스스로 확인

<details><summary>1. X = [0, 0, 0]이면 y는?</summary>

s = 0 + 10 = 10 → `10 > 10`은 거짓 → **0.0**

</details>

<details><summary>2. `W * X` 대신 for문으로 쓰면?</summary>

`s = 0` 후 `for i in range(3): s += W[i] * X[i]`, 마지막에 `s += B`

</details>
