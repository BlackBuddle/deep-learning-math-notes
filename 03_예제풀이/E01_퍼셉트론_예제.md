# EX\_01 예제 풀이 — 퍼셉트론 구현

[목차](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D%EC%88%98%ED%95%99_MOC.md) · 개념: [D01_퍼셉트론](../01_%EA%B0%9C%EB%85%90%EB%85%B8%ED%8A%B8/D01_%ED%8D%BC%EC%85%89%ED%8A%B8%EB%A1%A0.md) · 다음 예제: [E02_가설최적화_예제](../03_%EC%98%88%EC%A0%9C%ED%92%80%EC%9D%B4/E02_%EA%B0%80%EC%84%A4%EC%B5%9C%EC%A0%81%ED%99%94_%EC%98%88%EC%A0%9C.md)

> [!NOTE]
> **3줄 요약**
> - 입력 3개에 [가중치](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) 3개를 곱해 더하고 [편향](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5)을 얹은 뒤, 기준(10)을 넘는지로 0/1을 정하는 **인공 뉴런 하나**를 numpy로 직접 만든다.
> - 핵심 코드는 `np.sum(W * X) + B`([가중합](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weighted-sum-%EA%B0%80%EC%A4%91%ED%95%A9))와 `np.float32(s > 10)`(계단 함수) 두 줄이다.
> - 결과: [가중합](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weighted-sum-%EA%B0%80%EC%A4%91%ED%95%A9) 42 → 10보다 크므로 출력 1.0

## 0. 예제 개요

| 계산 | [가중합](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weighted-sum-%EA%B0%80%EC%A4%91%ED%95%A9) s = Σ wᵢxᵢ + b |
| [활성화 함수](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#activation-function-%ED%99%9C%EC%84%B1%ED%99%94-%ED%95%A8%EC%88%98)(activation function, [가중합](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weighted-sum-%EA%B0%80%EC%A4%91%ED%95%A9)을 최종 출력으로 바꾸는 함수) | 계단 함수 (s > 10이면 1) |
| 결과 | s = 42, y = 1.0 |

> 이 예제에는 **[학습](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5)이 없다**. [가중치](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)를 사람이 정해 놓고 계산만 한다. [가중치](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)를 데이터로 찾는 [학습](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#training-%ED%95%99%EC%8A%B5)은 다음 예제([E02_가설최적화_예제](../03_%EC%98%88%EC%A0%9C%ED%92%80%EC%9D%B4/E02_%EA%B0%80%EC%84%A4%EC%B5%9C%EC%A0%81%ED%99%94_%EC%98%88%EC%A0%9C.md))부터다.

## 1. 셀별 풀이

### 1-1. 수식

노트북 맨 위의 식은 이 예제가 하는 일 전체를 한 줄로 쓴 것이다. 말로 풀면 이렇다. 입력과 [가중치](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)를 같은 번호끼리 곱해 모두 더하고, [편향](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5) b를 더한 뒤, 그 값을 [활성화 함수](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#activation-function-%ED%99%9C%EC%84%B1%ED%99%94-%ED%95%A8%EC%88%98)에 넣는다.

$$y = \sigma\left(\sum_{i=1}^{3} w_i x_i + b\right)$$

<details><summary>기호 풀이</summary>

| 기호 | 읽는 법 | 뜻 | 이 예제의 값 |
| ---------------- | --- | -------------------------- | ------- |
| $y$ | 와이 | 최종 출력 | 1.0 |
| $\sigma$ | 시그마(소문자) | [활성화 함수](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#activation-function-%ED%99%9C%EC%84%B1%ED%99%94-%ED%95%A8%EC%88%98) | 계단 함수 |
| $\sum_{i=1}^{3}$ | 시그마(대문자) | i = 1, 2, 3을 차례로 넣어 모두 더하기 | 3개 합 |
| $w_i$ | 더블유 아이 | i번째 [가중치](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98) | 4, 5, 6 |
| $x_i$ | 엑스 아이 | i번째 입력 | 1, 2, 3 |
| $b$ | 비 | [편향](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5) | 10 |

</details>

기호 풀이는 [D01_퍼셉트론](../01_%EA%B0%9C%EB%85%90%EB%85%B8%ED%8A%B8/D01_%ED%8D%BC%EC%85%89%ED%8A%B8%EB%A1%A0.md) 4절, Σ는 [M02_시그마와_평균](../02_%EC%88%98%ED%95%99%EB%85%B8%ED%8A%B8/M02_%EC%8B%9C%EA%B7%B8%EB%A7%88%EC%99%80_%ED%8F%89%EA%B7%A0.md)에 있다.

### 1-2. 모듈 불러오기

```python
import numpy as np                                   # 배열 계산 도구 numpy를 np라는 짧은 이름으로 불러옴

print("NumPy Version :{}".format(np.__version__))    # 설치된 numpy 버전 출력 ({} 자리에 버전이 들어감)
```

**실행 결과**:

```text
NumPy Version :2.0.2
```

### 1-3. 입력, 가중치, 편향

```python
# Input, Weight, Bias
X = np.array([1,2,3])   # 입력 3개를 numpy 배열로
W = np.array([4,5,6])   # 입력마다 하나씩, 가중치 3개
B = 10                  # 편향: 배열이 아니라 숫자 하나
```

> [!TIP]
> **numpy 배열을 쓰는 이유**
> 파이썬 리스트끼리는 `*`로 곱할 수 없지만, numpy 배열은 `W * X` 한 줄로 같은 자리끼리 곱해 준다. for문을 직접 쓰지 않아도 된다.

### 1-4. 가중합 계산

```python
# Element-wise multiply (같은 자리끼리 곱하기)
mul = W * X                                  # [4*1, 5*2, 6*3] = [4, 10, 18]
print("mul = W * X : {}".format(mul))

# Summation array and Add bias (전부 더하고 편향 더하기)
s = np.sum(mul) + B                          # 4 + 10 + 18 = 32, 여기에 B(10)를 더해 42
print("s = {}".format(s))
```

**실행 결과**:

```text
mul = W * X : [ 4 10 18]
s = 42
```

### 1-5. 활성화 함수 (계단 함수)

```python
# Activation Function : Step Function
y = np.float32(s > 10)          # s > 10 이 참(True)이면 1.0, 거짓(False)이면 0.0
print("y = {}".format(y))
```

**실행 결과**:

```text
y = 1.0
```

- `s > 10`은 True 또는 False를 돌려준다.
- `np.float32(...)`는 그걸 실수 1.0 또는 0.0으로 바꾼다.

> [!WARNING]
> **⚠ 주의: 기준값이 10**
> 교과서의 [퍼셉트론](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#perceptron-%ED%8D%BC%EC%85%89%ED%8A%B8%EB%A1%A0)은 보통 기준이 0이다. 이 예제는 10을 기준으로 썼다.
> s > 10은 (s − 10) > 0과 같다. 그래서 [편향](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5)에서 10을 빼고 기준을 0으로 둔 것과 결과가 똑같다([D01_퍼셉트론](../01_%EA%B0%9C%EB%85%90%EB%85%B8%ED%8A%B8/D01_%ED%8D%BC%EC%85%89%ED%8A%B8%EB%A1%A0.md) 4절).

## 3. 개념 재확인

<details><summary>1. X = <code>[0, 0, 0]</code>이면 y는?</summary>

| 단계 | 하는 일 | 코드 | 계산 | 결과 |
|---|---|---|---|---|
| 1 | 같은 자리끼리 곱하기 | `W * X` | 4×0, 5×0, 6×0 | `[0, 0, 0]` |
| 2 | 모두 더하기 | `np.sum(mul)` | 0 + 0 + 0 | 0 |
| 3 | [편향](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5) 더하기 | `+ B` | 0 + 10 | s = 10 |
| 4 | 기준과 비교 | `s > 10` | 10 > 10 → 거짓 | y = 0.0 |

입력이 전부 0이면 [가중치](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#weight-%EA%B0%80%EC%A4%91%EC%B9%98)가 얼마든 [편향](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5) B만 남는다.

**① 바꿀 코드**
```python
X = np.array([0,0,0])        # ② 입력 [1,2,3] → [0,0,0]
W = np.array([4,5,6])        # ② 가중치는 그대로
B = 10                       # ③ 편향도 그대로
mul = W * X                  # ② 같은 자리끼리 곱하기
s = np.sum(mul) + B          # ③ 전부 더하고 편향 더하기
y = np.float32(s > 10)       # ④ 10보다 크면 1.0, 아니면 0.0
```

**② 같은 자리끼리 곱하기** (`mul = W * X`)
- 4 × 0 = 0
- 5 × 0 = 0
- 6 × 0 = 0
- 결과: `[0, 0, 0]`

**③ 모두 더하고 [편향](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5) 더하기** (`np.sum(mul) + B`)
- 0 + 0 + 0 = 0
- 0 + 10 = 10 → s = 10

**④ 기준과 비교** (`np.float32(s > 10)`)
- 10 > 10은 거짓(False). 같다고 해서 "넘는" 것은 아니다
- False를 실수로 바꾸면 0.0 → y = 0.0

**답**: y = **0.0** (s = 10이 기준 10과 같아서 "넘지 못함")

</details>

<details><summary>2. <code>W * X</code> 대신 for문으로 쓰면?</summary>

| 단계 | 하는 일 | 코드 | 계산 | 결과 |
|---|---|---|---|---|
| 1 | 합계 0으로 시작 | `s = 0` | - | 0 |
| 2 | 첫째 칸 곱해 더하기 | `s += W[0] * X[0]` | 0 + 4×1 | 4 |
| 3 | 둘째 칸 곱해 더하기 | `s += W[1] * X[1]` | 4 + 5×2 | 14 |
| 4 | 셋째 칸 곱해 더하기 | `s += W[2] * X[2]` | 14 + 6×3 | 32 |
| 5 | [편향](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5) 더하기 | `s += B` | 32 + 10 | s = 42 |

2~4단계는 `for i in range(3):` 안에서 반복되며, `W * X`와 `np.sum`이 한 번에 하던 일을 한 칸씩 푼 것이다.

**① 바꿀 코드**
```python
X = np.array([1,2,3])        # ③④⑤ 입력 (노트와 같음)
W = np.array([4,5,6])        # ③④⑤ 가중치 (노트와 같음)
B = 10                       # ⑥ 편향 (노트와 같음)
s = 0                        # ② 합계를 담을 칸, 0으로 시작
for i in range(3):           # ③④⑤ i = 0, 1, 2 를 차례로 (칸 3개)
    s += W[i] * X[i]         # ③④⑤ i번째 칸끼리 곱해 s에 더하기
s += B                       # ⑥ 마지막에 편향 더하기
```

**② 합계 0으로 시작** (`s = 0`)
- 아직 아무것도 더하지 않았으므로 s = 0

**③ 첫 번째 반복, i = 0** (`s += W[0] * X[0]`)
- W`[0]` = 4, X`[0]` = 1 이므로 4 × 1 = 4
- s = 0 + 4 = 4

**④ 두 번째 반복, i = 1** (`s += W[1] * X[1]`)
- W`[1]` = 5, X`[1]` = 2 이므로 5 × 2 = 10
- s = 4 + 10 = 14

**⑤ 세 번째 반복, i = 2** (`s += W[2] * X[2]`)
- W`[2]` = 6, X`[2]` = 3 이므로 6 × 3 = 18
- s = 14 + 18 = 32

**⑥ [편향](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#bias-%ED%8E%B8%ED%96%A5) 더하기** (`s += B`)
- s = 32 + 10 = 42
- 노트의 `np.sum(mul) + B` = 32 + 10 = 42 와 같다

**답**: `for i in range(3): s += W[i] * X[i]` 뒤에 `s += B`를 하면 numpy 코드와 같은 **s = 42**

</details>
