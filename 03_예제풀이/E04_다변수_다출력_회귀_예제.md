> [!NOTE]
> **3줄 요약**
> - 나이·BMI(입력 2개)로 수축기·이완기 혈압(출력 2개)을 한 번에 예측한다.
> - [E03_혈압_선형회귀_예제](E03_%ED%98%88%EC%95%95_%EC%84%A0%ED%98%95%ED%9A%8C%EA%B7%80_%EC%98%88%EC%A0%9C.md)에서 손으로 짠 가설·비용·기울기·반복을 **Keras가 대신 해 준다**(`Dense`, `compile`, `fit`).
> - 입력을 0~1로 줄이는 **Min-Max 정규화** 덕분에 학습률 0.1, 1000번이면 충분하다(EX_03은 0.0005, 200000번).

## 0. 한눈에 보기

| 항목 | 내용 |
|---|---|
| 입력 | 나이, BMI (2개) × 18명 |
| 정답 | 수축기(HIGH), 이완기(LOW) 혈압 (2개) |
| 전처리 | Min-Max 정규화 (입력을 0~1로) |
| 모델 | `Dense(2)` — 직선 식 2개, 가중치·편향 6개 |
| 비용 | MSE (`mean_squared_error`) |
| 학습 | SGD(경사하강법), 학습률 0.1, 1000번 |
| 결과 | loss 11027.59 → 5.36, 50세·BMI 25 → 125.2 / 78.72 |

### EX_03과 비교

| | EX_03 (손으로) | EX_04 (Keras) |
|---|---|---|
| 가설 | `def Hypothesis(x): return W*x + B` | `tf.keras.layers.Dense(2)` |
| 비용 | `def Cost(): ...` | `loss='mean_squared_error'` |
| 기울기 | `def Gradient(x, y): ...` | Keras가 자동으로 계산 |
| 반복 | `for cnt in range(...)` | `model.fit(..., epochs=1000)` |
| 학습률 | `learning_rate = 0.0005` | `SGD(learning_rate=0.1)` |

## 1. 셀별 풀이

### 1-1. 모듈 불러오기

```python
import numpy as np                 # 배열 계산
import tensorflow as tf            # 딥러닝 라이브러리 (Keras가 이 안에 들어 있음)
import matplotlib.pyplot as plt    # 그래프 그리기

print("NumPy Version :{}".format(np.__version__))
print("TensorFlow Version :{}".format(tf.__version__))
print("Matplotlib Version :{}".format(plt.matplotlib.__version__))
```

**실행 결과**:

```
NumPy Version :2.0.2
TensorFlow Version :2.19.0
Matplotlib Version :3.10.0
```

### 1-2. 입력과 정답

```python
#Input(AGE, BMI) and Labels(HIGH, LOW)
x_input = tf.constant([[25,22],[25,26],[25,30],[35,22],[35,26],[35,30],[45,22],[45,26],[45,30],
                       [55,22],[55,26],[55,30],[65,22],[65,26],[65,30],[73,22],[73,26],[73,30]],
                      dtype= tf.float32)   # 18행 × 2열: 한 행 = 한 사람 [나이, BMI]
labels = tf.constant([[118,72],[125,80],[130,80],[118,76],[126,75],[123,79],[120,80],[124,85],[130,83],
                      [122,78],[125,80],[130,81],[127,75],[130,79],[130,81],[125.5,80],[130,80],[138,82]],
                     dtype= tf.float32)    # 18행 × 2열: 한 행 = 한 사람 [수축기, 이완기]
```

- `tf.constant(...)`: TensorFlow용 배열(텐서). numpy 배열과 거의 같다고 보면 된다.
- 이제 데이터가 **표 모양(행렬)**이다. 행 = 사람, 열 = 항목. 모양(shape)은 (18, 2).

### 1-3. Min-Max 정규화

$$x' = \frac{x - \min}{\max - \min}$$

```python
x_input_org = x_input                                      # 원래 값을 따로 보관 (나중에 결과 출력용)
x_min, x_max = np.min(x_input, axis=0), np.max(x_input, axis=0)   # 열마다 최솟값·최댓값
x_input = (x_input-x_min)/(x_max-x_min)                    # 모든 값을 0~1 사이로 바꿈
```

- `axis=0`: **세로 방향(열마다)** 계산하라는 뜻. 나이 열의 최솟값, BMI 열의 최솟값을 따로 구한다.
  - x_min = [25, 22], x_max = [73, 30]

| 원래 값 | 계산 | 정규화 값 |
|---|---|---|
| 나이 25 | (25 − 25) ÷ (73 − 25) | 0 |
| 나이 50 | (50 − 25) ÷ 48 | 0.5208 |
| 나이 73 | (73 − 25) ÷ 48 | 1 |
| BMI 22 | (22 − 22) ÷ (30 − 22) | 0 |
| BMI 25 | (25 − 22) ÷ 8 | 0.375 |
| BMI 30 | (30 − 22) ÷ 8 | 1 |

> [!TIP]
> **왜 정규화하나**
> EX_03에서 나이(25~73)가 그대로 들어가니 기울기가 커서 학습률을 0.0005까지 줄여야 했다. 입력을 0~1로 줄이면 기울기 크기가 적당해져서 **큰 학습률(0.1)로 빨리** 학습할 수 있다. 나이와 BMI처럼 범위가 다른 항목의 크기도 맞춰진다.

### 1-4. 모델 정의

```python
model = tf.keras.models.Sequential([     # Sequential: 층을 순서대로 쌓는 모델
  tf.keras.Input(shape=(2,)),            # 입력 한 개가 숫자 2개짜리 (나이, BMI)
  tf.keras.layers.Dense(2)               # 출력 2개짜리 층 (수축기, 이완기), 활성화 함수 없음 = 직선 그대로
])

model.summary()                          # 모델 구조와 가중치 개수 출력
```

**실행 결과**:

```
Model: "sequential"
┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┳━━━━━━━━━━━━━━━━━━━━━━━━┳━━━━━━━━━━━━━━━┓
┃ Layer (type)                    ┃ Output Shape           ┃       Param # ┃
┡━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━╇━━━━━━━━━━━━━━━━━━━━━━━━╇━━━━━━━━━━━━━━━┩
│ dense (Dense)                   │ (None, 2)              │             6 │
└─────────────────────────────────┴────────────────────────┴───────────────┘
 Total params: 6 (24.00 B)
```

`Dense(2)`는 직선 식 **2개**를 한꺼번에 만든다.

$$\text{수축기} = w_{1} \cdot \text{나이}' + w_{2} \cdot \text{BMI}' + b_1$$
$$\text{이완기} = w_{3} \cdot \text{나이}' + w_{4} \cdot \text{BMI}' + b_2$$

- 가중치 4개(입력 2 × 출력 2) + 편향 2개(출력마다 1개) = **6** → `Param # 6`과 같다.
- `Output Shape (None, 2)`: None은 "사람 수는 아직 정해지지 않음", 2는 출력 2개.
- 각 식은 [D01_퍼셉트론](../01_%EA%B0%9C%EB%85%90%EB%85%B8%ED%8A%B8/D01_%ED%8D%BC%EC%85%89%ED%8A%B8%EB%A1%A0.md)의 가중합(곱해서 더하고 b)과 같은 계산이다. 이걸 여러 개 한 번에 하는 계산이 **행렬 곱**이다([M05_벡터와_행렬](../02_%EC%88%98%ED%95%99%EB%85%B8%ED%8A%B8/M05_%EB%B2%A1%ED%84%B0%EC%99%80_%ED%96%89%EB%A0%AC.md)).

### 1-5. 컴파일 (학습 방법 정하기)

```python
model.compile(optimizer= tf.keras.optimizers.SGD(learning_rate=0.1),   # 경사하강법(SGD), 학습률 0.1
              loss='mean_squared_error')                               # 비용 함수: MSE
```

- **optimizer**(최적화 방법): W, B를 어떻게 고칠지. SGD = 경사하강법. EX_02의 `W -= learning_rate * grad_w`를 Keras가 해 준다.
- **loss**(손실 = 비용): 얼마나 틀렸는지 재는 방법. EX_02의 `Cost()`와 같은 MSE.

### 1-6. 학습

```python
%%time
history = model.fit(x_input, labels, epochs=1000)   # 입력·정답을 주고 1000번 반복 학습, 기록을 history에 저장
```

H_x = model.predict(x_input)                       # 18명 모두 예측 → (18, 2) 배열

### 1-9. 새 사람 예측

```python
def predict(x):
  return model.predict((x-x_min)/(x_max-x_min))     # ⚠ 새 입력도 학습 때와 같은 min, max로 정규화해서 넣는다

x_test = tf.constant([[50.0, 25.0]], dtype= tf.float32)   # 50세, BMI 25 한 명 (2차원 모양 (1, 2)로)
H_x = predict(x_test)
print("Age : {}, BMI : {} = > BP : {:>7.4}, {:>7.4}".format(x_test[0,0],x_test[0,1],H_x[0,0],H_x[0,1]))
```

**실행 결과**:

```
Age : 50.0, BMI : 25.0 = > BP :   125.2,   78.72
```

> [!WARNING]
> **⚠ 예측할 때도 정규화**
> 모델은 0~1 값만 보고 배웠다. 50을 그대로 넣으면 엉뚱한 답이 나온다. 반드시 **학습 데이터의 min, max**로 바꿔서 넣는다: 50 → 0.5208, 25 → 0.375.

## 3. 스스로 확인

<details><summary>1. 입력이 3개, 출력이 2개인 Dense 층의 Param #는?</summary>

가중치 3 × 2 = 6, 편향 2 → **8**

</details>

<details><summary>2. 나이 61세를 정규화하면?</summary>

(61 − 25) ÷ 48 = 36 ÷ 48 = **0.75**

</details>

<details><summary>3. EX_03보다 학습률을 200배(0.0005 → 0.1) 키울 수 있었던 이유는?</summary>

입력을 0~1로 **정규화**해서 기울기가 커지지 않기 때문이다.

</details>
