> 이전 예제와 달라진 점: 실제 데이터라 점들이 직선 위에 딱 놓이지 않는다. 그래서 [손실](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 0까지 내려가지 않고 **17.07에서 멈춘다**. 직선 하나로 설명할 수 있는 최선이 그 정도라는 뜻이다.

## 1. 셀별 풀이

### 1-1. 입력과 정답

```python
# Input(AGE) and Labels(BP)
x_input = np.array([25,25,25,35,35,35,45,45,45,55,55,55,65,65,65,73,73,73], dtype= np.float32)  # 나이 18명 (같은 나이 3명씩)
labels = np.array([118,125,130,118,126,123,120,124,130,122,125,130,127,130,130,125.5,130,138], dtype= np.float32)  # 각 사람의 혈압

# Weights
W = np.random.normal()   # 무작위로 시작
B = np.random.normal()
```

- 같은 나이(25세)인데 혈압이 118, 125, 130으로 다르다. 그래서 어떤 직선도 모든 점을 지날 수 없다.

### 1-2. 가설·손실·기울기

[E02_가설최적화_예제](../03_%EC%98%88%EC%A0%9C%ED%92%80%EC%9D%B4/E02_%EA%B0%80%EC%84%A4%EC%B5%9C%EC%A0%81%ED%99%94_%EC%98%88%EC%A0%9C.md) 1-3 ~ 1-5와 **완전히 같은 코드**다.

```python
def Hypothesis(x):
    return W*x + B                                         # 혈압 예측 = W × 나이 + B

def Cost():
    return np.mean((Hypothesis(x_input) - labels)**2)      # 오차 제곱 평균

def Gradient(x, y):
    return np.mean(x*(x*W+(B-y))), np.mean((W*x-y+B))     # w 방향, b 방향 기울기
```

### 1-3. 학습

아래 `epochs`는 [에폭](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#epoch-%EC%97%90%ED%8F%AD)(epoch, 전체 데이터를 한 바퀴 다 보는 것)의 수다. 여기서는 18명 전체로 4단계를 한 번 하는 것이 1에폭이다.

```python
%%time
# Parameter Set
# epochs = 100
# learning_rate = 0.01           ← 처음 시도했던 값 (주석 처리됨)
epochs = 200000          # learning_rate 값 변경에 따라 조정해야 할 수 있음
learning_rate = 0.0005   # 값을 줄여가면서 실험 0.005, 0.001, 0.0005, 0.0003 ..

# 학습 (Training)
for cnt in range(0, epochs+1):
    if cnt % (epochs//20) == 0:                    # 200000//20 = 10000번마다 출력
      print("[{:>5}] cost = {:>10.4}, W = {:>7.4}, B = {:>7.4}".format(cnt, Cost(), W, B))

    grad_w, grad_b = Gradient(x_input, labels)     # 기울기 계산
    W -= learning_rate * grad_w                    # 기울기 반대로 이동
    B -= learning_rate * grad_b
```

**실행 결과** (노트북 기록, 일부):

```text
[    0] cost =  1.179e+04, W =  0.3454, B =  0.5978
[10000] cost =      525.8, W =   1.449, B =   47.06
[20000] cost =      203.4, W =  0.9407, B =   75.15
[50000] cost =      26.22, W =  0.3337, B =   108.7
[100000] cost =      17.13, W =  0.1749, B =   117.4
[150000] cost =      17.07, W =  0.1622, B =   118.1
[200000] cost =      17.07, W =  0.1622, B =   118.1
CPU times: user 5.29 s, sys: 7.03 ms, total: 5.3 s
```

- `1.179e+04` = 1.179 × 10⁴ = 11790
- W가 처음엔 크게 올라갔다가(10000번째에도 아직 1.449) 0.1622로 **내려온다**.
- 이유: B가 아직 작을 때는 W가 혈압 118을 혼자 만들어 내려고 커진다. B가 118까지 자라면 W는 제 크기로 돌아온다.
- 손계산: W = B = 0에서 시작하면 첫 걸음에 W는 0.0005 × mean(나이 × 혈압) ≈ 0.0005 × 6312 ≈ 3.156만큼 커진다. 위 기록은 무작위 시작값 때문에 W = 0.3454에서 시작했으므로 이 숫자와 다르다.
- 150000번 이후로는 소수 4자리까지 더 바뀌지 않는다. 더 돌려도 소용없는 지점([수렴](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#convergence-%EC%88%98%EB%A0%B4))이다.

> [!WARNING]
> **⚠ [학습률](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0)을 왜 이렇게 줄였나**
> 나이(평균 약 50)처럼 입력이 크면 w 방향 [기울기](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)가 매우 커진다. [학습률](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0) 0.001만 돼도 [손실](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 15949 → 45571 → 135591 …로 폭발한다([D02_경사하강법으로_직선찾기](../01_%EA%B0%9C%EB%85%90%EB%85%B8%ED%8A%B8/D02_%EA%B2%BD%EC%82%AC%ED%95%98%EA%B0%95%EB%B2%95%EC%9C%BC%EB%A1%9C_%EC%A7%81%EC%84%A0%EC%B0%BE%EA%B8%B0.md)의 '실제 데이터').
> 그래서 [학습률](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#learning-rate-%ED%95%99%EC%8A%B5%EB%A5%A0)을 0.0005로 낮췄고, 보폭이 작아진 만큼 200000번을 돌려야 했다. 이 문제를 푸는 방법이 다음 예제의 **Min-Max [정규화](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#normalization-%EC%A0%95%EA%B7%9C%ED%99%94)**다.

### 1-4. 예측

```python
# Predict
def Predict(x):
    return Hypothesis(x)              # 학습이 끝난 W, B로 계산

age = np.array([50.0])                # 50세 한 명 (배열로 넣음)
print("{} Years : {:>7.4}mmHg".format(age[0], Predict(age)[0]))   # 결과 배열의 0번 칸을 출력
```

**실행 결과**:

```text
50.0 Years :   126.2mmHg
```

손계산: 0.1622 × 50 + 118.1 = 8.11 + 118.1 ≈ **126.2**

## 3. 개념 재확인

<details><summary>1. 30세의 예측 혈압은? (W = 0.1622, B = 118.1)</summary>

| 단계 | 하는 일 | 코드 | 계산 | 결과 |
|---|---|---|---|---|
| 1 | 나이에 [기울기](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) 곱하기 | `W*x` | 0.1622 × 30 | 4.866 |
| 2 | 절편 더하기 | `+ B` | 4.866 + 118.1 | 122.966 |
| 3 | 유효숫자 4자리로 표시 | `{:>7.4}` | 122.966 → 123.0 | 123.0 |

**① 쓰는 코드**
```python
def Hypothesis(x):                       # ②③ 가설 정의
    return W*x + B                       # ②③ 혈압 예측 = W × 나이 + B (W = 0.1622, B = 118.1)

age = np.array([30.0])                   # ②⑤ 50.0 → 30.0 (30세 한 명)
print("{} Years : {:>7.4}mmHg".format(age[0], Predict(age)[0]))   # ④ {:>7.4}로 유효숫자 4자리 표시
```

**② 나이에 [기울기](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0) 곱하기** (`W*x`)
- 0.1622 × 30 = 4.866

**③ 절편 더하기** (`W*x + B`)
- 4.866 + 118.1 = 122.966

**④ 화면 표시** (`{:>7.4}`)
- `.4`는 유효숫자 4자리만 남기는 서식 (맨 앞 0이 아닌 숫자부터 4개)
- 122.966의 유효숫자 4자리는 1, 2, 2, 9 → 다섯 번째 숫자 6에서 반올림해 123.0
- 7칸 오른쪽 정렬이라 출력은 `30.0 Years :   123.0mmHg`

**⑤ 확인: 50세와 비교**
- 나이 차이 50 − 30 = 20살
- 혈압 차이 = 0.1622 × 20 = 3.244 ≈ 3.2
- 126.2 − 3.2 = 123.0

**답**: 약 **123.0 mmHg** (50세 126.2보다 나이 20살 적은 만큼 0.1622 × 20 ≈ 3.2 낮다)

</details>

| 4 | 제곱 평균 | `np.mean(...)` | (17.26 + 8.09 + 61.54) ÷ 3 | 28.97 (0이 아님) |
| 5 | 최선의 경우 | - | 예측을 [정답](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) 평균 124.33으로 옮겨도 | 24.22 (여전히 0이 아님) |

같은 나이에 [정답](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)이 셋인데 직선은 값 하나만 내므로 셋을 동시에 맞출 수 없고, 나이 25~73 전체에서도 같아서 150000번 이후에는 grad_w가 거의 0이 되어 W, B가 안 바뀐다([수렴](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#convergence-%EC%88%98%EB%A0%B4)).

**① 쓰는 코드**
```python
x_input = np.array([25,25,25,35,35,35,45,45,45,55,55,55,65,65,65,73,73,73], dtype= np.float32)  # ②⑦ 나이 18명 (같은 나이 3명씩, 앞 25세 셋만 사용)
labels = np.array([118,125,130,118,126,123,120,124,130,122,125,130,127,130,130,125.5,130,138], dtype= np.float32)  # ③⑥ 각 사람의 혈압 (25세 정답은 118, 125, 130)
def Cost():                                                # ④⑤⑦ 손실 함수 정의
    return np.mean((Hypothesis(x_input) - labels)**2)      # ④⑤⑦ 오차 제곱 평균
```
아래는 18명 중 25세 셋([정답](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) 118, 125, 130)만 따로 떼어 계산한다.

**② 25세의 예측 하나** (`Hypothesis(25)`)
- 직선은 나이 하나에 값 하나만 낸다
- 0.1622 × 25 + 118.1 = 4.055 + 118.1 = 122.155

**③ [정답](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) 셋과의 [오차](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)** (`Hypothesis(x_input) - labels`)
- 122.155 − 118 = 4.155
- 122.155 − 125 = −2.845
- 122.155 − 130 = −7.845

**④ [오차](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) 제곱** (`(...)**2`)
- 4.155² = 17.26
- (−2.845)² = 8.09
- (−7.845)² = 61.54

**⑤ 제곱 평균** (`np.mean(...)`)
- (17.26 + 8.09 + 61.54) ÷ 3 = 86.89 ÷ 3 = 28.97 → 0이 아니다

**⑥ 예측을 옮겨도 0이 안 된다**
- 세 [정답](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5)의 평균 = (118 + 125 + 130) ÷ 3 = 124.33
- 예측을 124.33으로 옮기면 [오차](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8) = −6.33, 0.67, 5.67
- 제곱 평균 = (40.11 + 0.44 + 32.11) ÷ 3 = 24.22 → 여전히 0이 아니다
- 값이 하나인 예측으로 서로 다른 [정답](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#label-%EC%A0%95%EB%8B%B5) 셋을 동시에 맞출 수는 없다

**⑦ 멈추는 이유**
- 18명 전체로 같은 계산을 하면 [손실](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)의 최솟값이 17.07
- 이 지점에서는 grad_w, grad_b가 거의 0이라 W, B가 안 바뀐다 (150000번 이후 소수 4자리까지 같은 값)

**답**: 같은 나이에도 혈압이 제각각이라 **직선 하나로 모든 점을 지날 수 없어서 [손실](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 17.07 밑으로 내려가지 않는다**.

0.0005는 한계 안이고 0.001은 한계 밖이라, 걸음마다 [손실](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#loss-function-%EC%86%90%EC%8B%A4-%ED%95%A8%EC%88%98)이 약 3배가 된다.

**① 바꿀 코드**
```python
W = 0                                        # ② 시작값 W = 0 (설명을 위해 고정)
B = 0                                        # ② 시작값 B = 0
learning_rate = 0.001                        # ③④⑤⑥⑦ 0.0005 → 0.001
grad_w, grad_b = Gradient(x_input, labels)   # ②⑤⑥ 지금 W, B에서의 기울기 두 개
W -= learning_rate * grad_w                  # ③④⑤⑥ W = W − 학습률 × w 방향 기울기
B -= learning_rate * grad_b                  # ④ B = B − 학습률 × b 방향 기울기
```

**② 첫 [기울기](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#gradient-%EA%B8%B0%EC%9A%B8%EA%B8%B0)** (`Gradient(x_input, labels)`, W = 0, B = 0)

- grad_b = [오차](../00_%EB%94%A5%EB%9F%AC%EB%8B%9D_%EC%9A%A9%EC%96%B4%EC%82%AC%EC%A0%84.md#error-%EC%98%A4%EC%B0%A8)의 평균 = −(혈압 평균) = −126.19
